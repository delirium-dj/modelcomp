## Model card

- **Name:** Ling-3.0-Flash-Sante (OpenRouter `inclusionai/ling-3.0-flash-sante` and `…:free`; curated id `opencode/ling-3.0-flash-sante`). *Sante* is the vendor's spelling for the health-and-medicine line (French/Italian for "health"), not an acronym disclosed anywhere in the trail.
- **Short description:** Ant's inclusionAI lab announced it on X as "**Ling-3.0-flash-Sante — an MoE model enhanced for health and medicine, built on Ling-3.0-flash**". Distributor listings expand the positioning as "**a health and medicine-focused mixture-of-experts model from InclusionAI, built on Ling 3.0 Flash with 5.1B active parameters out of 124B**", aimed at **medical reasoning, professional healthcare tasks, deep research and evidence-based retrieval**, while claiming the base model's general reasoning, coding and agentic abilities are retained. It is the medical sibling of the finance-tuned `Ling 3.0 Flash Fin` (tracked out of production scope at `models_finance/ling-3.0-flash-fin-free/`) — the same "specialist on a generalist skeleton" play, pointed at medicine.
- **Provider / access:** **Closed / API-only.** This is the decisive fact about the folder: **no weights have been published.** A direct fetch of `huggingface.co/inclusionAI/Ling-3.0-flash-sante` (and the capitalised `-Sante` variant) returns **401 — no repository**, whereas the base `inclusionAI/Ling-3.0-flash` (MIT, BF16/FP8/int4/VL/FP8 variants) is fully open. Access routes found: **OpenRouter** (paid-slug + **`:free`** variant, with a documented Chat Completions API whose capability list accepts **`tools`, `tool_choice` and `reasoning`** parameters), **Novita AI** (`inclusionai/ling-3.0-flash-sante`), and the Command Code coding agent (`cmd --model inclusionai/ling-3.0-flash-sante:free`). A third-party comparison states the asymmetry plainly: Sante "**has none of that … no Artificial Analysis page, no arena result, no third-party benchmark of any kind … it also cannot be reproduced from weights, because there are no weights to download**."
- **Release / knowledge:** Vendor announcement on X plus distributor records date the launch to **2026-09-03** (Command Code: "Released September 3, 2026"; third-party write-up: "reached commercial APIs on September 4"), i.e. **~5–6 weeks after the open-weight base model** (Ling-3.0-flash, MIT, announced July 24 / AA-released August 2026). **No knowledge cutoff published** and no technical report, model card PDF, licence text, evaluation protocol or data-handling policy is reachable for this ID — disclosure exists only through the base family's `inclusionAI/AI-Transparency/Ling-3.0-LLM_TDS-Summary.pdf`, which covers *Ling-3.0*, not the Sante tuning.
- **IDs:** `inclusionai/ling-3.0-flash-sante` / `…:free` (OpenRouter), `opencode/ling-3.0-flash-sante` (curated). **Aggregator coverage flag — zero independent evaluation of this ID:** **BenchLM 404** (`ling-3-0-flash-sante` — its Ling-3.0 family page lists VL / FP8 / Tiny / Fin siblings but **not Sante**); **Artificial Analysis 404** (`ling-3-0-flash-sante`); **Hugging Face 401** (no repo); Command Code shows "**Intelligence index: not yet scored**" and "**Coding index: not yet scored**" for this exact slug. Everything capability-related in this report therefore comes from the **vendor's own announcement** or from **the base model's** measurements, which are labelled as such throughout.
- **Context window:** **262,144 tokens in, ~32K out.** Two independent listings agree on **262K** (OpenRouter-derived metadata; Command Code's spec row "Context window 262K tokens"), matching the backbone's documented `--context-length 262144`, and a third-party spec-sheet comparison records "**Sante: 262K in / ~32K out**". **The curated `meta.json` says "128K total" — understated by half**, and its "Standard pricing" is a scaffold placeholder. Note the sub-64 K output ceiling explicitly: ~32 K max output, so long clinical documents plus long generated reports do not fit the advertised window.
- **Modalities:** **text in / text out.** AA has no page for this ID to confirm, but every listing describes a text MoE with no encoder, and the medical harnesses it is scored on (**DiagnosisArena-MCQ**, **MedXpertQA-Text**) are text-only — the vendor's own benchmark choice is itself evidence of modality. Vision in this family is a separate model (`model/ling-3.0-flash-vl/`, 124 B/5.5 B active). No audio, no image input for radiology/pathology, no non-text output.
- **Pricing (as of 2026-10-08):** **$0.00 per 1M input, output *and* cache reads** on the `:free` route — "Every request on Ling 3.0 Flash Sante is billed $0.00 … FREE while it lasts" — with **no list price ever published** for the paid slug. Third-party coverage describes it as "**a launch promotion into early October, no list price**", which means the free window is at or past its stated expiry **as of this report's date**. Practical limits on the free tier: **~100 requests/day per account**, and access gated to a paid agent plan tier ("Available on **Go** and above" in the Command Code front-end). The base model's measured economics — **$0.075 / $0.22 per 1M with an 80 % cache discount** — are the only price reference in the family, and they belong to a **different ID**.
- **Architecture:** **identical backbone to the base model:** 124 B total / **~5.1 B active** per token, hybrid-linear MoE (5:1 Kimi Delta Attention : gated MLA, 512 routed + 1 shared experts, top-8), 262 K window, native reasoning mode (the OpenRouter capability list accepts `reasoning`). "Same 124-billion-parameter mixture-of-experts architecture … this is **one backbone re-tuned, not a new model family**." Post-training is the only difference — health/medicine tuning over medical reasoning, drug knowledge and evidence-based retrieval — with **no published method, dataset list or hyperparameters**.
- **Identity flags:** (1) **Scaffolded entry:** `meta.json` is `"scaffolded": true` with boilerplate `short`, placeholder `"Standard pricing"` and a wrong (half-size) context figure. (2) **Do not inherit scores from `model/ling-3.0-flash/`.** The base model is independently measured (AA Index **20**, #3/65 in class; BenchLM Overall **45.18**, #116/888 with Vals AI reproductions); Sante is **not measured at all**. Scores recorded here are for the Sante ID only. (3) **AA-figure discrepancy worth orchestrator attention:** a September third-party comparison cites AA's Ling 3.0 Flash page as "**Intelligence Index 38** … median 9 … ~380 tok/s", while this researcher's live fetch of the same page on 2026-10-08 returns **Index 20, #3/65, class median 8, 333.6 tok/s**. The live AA page is treated as authoritative for `ling-3.0-flash`; the 38 figure is neither propagated to this folder nor explained by anything published. (4) **Regulatory framing is explicit and must survive curation:** "**neither model is a medical device** … Ant's positioning stops at *supporting* professional healthcare work, and the platforms serving Sante carry the same 'not a substitute for professional medical judgment' caveat." (5) **Slug check:** `ling-3.0-flash-sante` follows the family convention (compare `ling-3.0-flash-vl`) and has no hyphen twin — rule-7 clean.

### Normalized scores (1–100)

- **Tool use: 52/100.** The interface is real — OpenRouter's advertised capability list for this exact slug accepts **`tools`, `tool_choice` and `reasoning`**, the "deep research / evidence-based retrieval" framing is agentic by construction, and the backbone is the one InclusionAI trained in **10,000+ interactive environments** and ships with dedicated `ling3` tool/reasoning parsers. But nothing is **measured for this ID**: no BFCL, no MCP-Atlas, no τ-bench, no Terminal-Bench, no AutomationBench, no GDPval row, and **no weights with which to run any of them**. A closed derivative inherits tool-calling *plumbing*, not evidence, so this sits in the lower half of the mid band with the gap stated rather than filled.
- **Reasoning: 58/100.** The only reasoning evidence is two vendor numbers on medical harnesses, and they point in opposite directions: **DiagnosisArena-MCQ 83.8** beating GPT-5.6 Sol, Kimi K3 and Gemini 3.6 Flash is a striking domain spike, while **MedXpertQA-Text 53.9** — the harder expert-level set — **trails both** of those competitors (60.2 / 62.4). That pattern (spike on multiple-choice diagnosis, fall behind on open expert questions) is exactly what a narrow tuning pass produces, and it is **unreplicated**. No general-reasoning composite exists for this ID, and the base model's own faithfulness result (AA-Omniscience **−17.9**, 44.1 % hallucination) is a warning rather than a credential in a clinical setting: scored mid-band-low, well below the frontier anchors, with the vendor's cherry-pick asymmetry priced in.
- **Context window: 70/100.** **262,144 tokens** — consistent across two independent listings and identical to the backbone's documented `--context-length 262144` and its 8 K→32 K→256 K training curriculum, which puts it squarely in the 200 K–500 K band (65–84) near the 200 K ≈ 70 anchor, and matters here because whole-folder patient records and literature sets are the stated workload. Discounted by two things the methodology penalises: an explicit **~32 K max-output ceiling** (sub-64 K caveat — a long generated clinical note plus retrieved context will not fit), and **zero long-context verification for this ID** (no AA-LCR, no MRCR/AI-Needle, no retrieval run of any kind). The curated sheet's "128K" is wrong and would have halved the tier.
- **Multimodal: 15/100.** **Text-only.** No encoder is claimed or found, the two published harnesses are text benchmarks (`MedXpertQA-**Text**`), and real medical workloads are overwhelmingly **images and waveforms** — radiology, pathology, ECG, fundus — none of which this ID touches. Vision breadth in the family lives in `model/ling-3.0-flash-vl/`, and even there the vendor has published nothing for Sante. 10–20 band, no lift, and especially relevant to flag because "health and medicine" invites a false expectation of document/image competence.
- **Coding: 50/100.** Nothing measures coding for this ID, yet two facts keep it off the floor: the distributor's own one-liner calls it a "**health & medicine tuned lightweight-MoE, still strong on code**", and the backbone it is built on is independently measured at **LiveCodeBench 84.0 % (Vals) / 82.8 % (vendor)**, **SWE-bench 65.2 % (Vals)**, **AA Coding Index 50.6 %** — so "retained general capability" is plausible rather than aspirational. But a coding agent would be better served by the open base checkpoint, which is cheaper to verify, MIT-licensed and actually scored. Scored near the top of the low band, on architecture inheritance alone, with no benchmark credit.
- **Cost efficiency: 85/100.** On paper this is the cheapest option in the registry: **$0.00 per 1M for input, output *and* cache reads** on `inclusionai/ling-3.0-flash-sante:free`, on a 5.1 B-active MoE that needs only ~4 GPUs' worth of serving capacity upstream. The caveats are structural, not cosmetic: the free rate is a **launch promotion "into early October"** with **no list price ever published** — and this report is dated October 8, so the deal may already be gone; the free tier is throttled to roughly **100 requests/day per account** and gated behind a paid agent plan; **no weights exist**, so there is no self-host path to escape whatever price lands (unlike the MIT base model, and unlike `solar-open-2`); and a free medical endpoint carries **unspecified data-retention terms**, which is a real cost in a regulated health context. Cost of a wrong answer is also not priced in here at all.
- **Overall Score: 49/100.** Mean of the five quality dimensions (52 + 58 + 70 + 15 + 50) / 5 = 245 / 5 = 49.0 → 49; Cost excluded per `RULES.md`. Best fit: **medical-adjacent experimentation while the free tier lasts** — clinical-document summarisation, evidence retrieval, drug-knowledge drafting — run **behind a verified fallback** and inside a self-built eval, because there is no external score to rely on. It is **not** fit for regulated clinical use (**"neither model is a medical device"**; not a substitute for professional medical judgment), not for anything needing reproducibility or auditability (**no weights, no licence, no report, no independent benchmark**), and not obviously better than its own base model on medicine — **the head-to-head has never been published, and the vendor chart omits the Flash baseline**. **Re-search triggers:** (1) a weight release or model card, (2) the first independent medical benchmark, (3) the post-promo price list, (4) an Artificial Analysis page. Until then this is the least verifiable folder in the Ling family.
