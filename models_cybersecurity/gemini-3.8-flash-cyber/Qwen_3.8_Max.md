## Model card

- **Name:** Gemini 3.8 Flash Cyber
- **Short description:** Google DeepMind's **cybersecurity fine-tune of Gemini 3.8 Flash** (released 2026-09-02, same day as the base model) — "our most capable cybersecurity model with frontier-level performance in vulnerability detection and automated patching." It shares the base 3.8 Flash foundation (which Google calls "our best reasoning and coding model yet," AA Index 59) but is **tuned for defensive security** **[2026-11-02: the inherited "AA Index 59" does NOT replicate — AA now measures base Gemini 3.8 Flash (high) at Intelligence Index 31 (#38/58 class, below the class median 37), BenchLM #27/1004 (66.22); the core is solid-upper-mid, not near-frontier. Its specialized cells stay strong though: GPQA-D 95.3, ARC-AGI-2 89.2, AA Coding Index 76.3, DeepSWE 73.8 independent]** and bundled with the **CodeMender** harness for finding/verifying/fixing vulnerabilities at agentic scale. In its specialty it is **frontier-leading**: **CyberGym 86.2% pass@1** (autonomous vuln discovery — ahead of GPT-5.5 Cyber 85.6%, Claude Mythos 5 83.8%, GPT-5.6 Sol 83.6%), **CWE-Bench 47.2%** patching (Pareto-optimal vs a frontier model's 47.8% at ~3× the cost), and **71.0%** on an internal 20-language vuln-discovery benchmark. Trade-offs: it is **hard-gated** (Fairwind Program — vetted government/critical-infrastructure/software-maintainer defenders only, **no public pricing**), it is a **code/text specialist** (no documented vision/audio, unlike the strongly-multimodal base 3.8 Flash), general long-horizon agency is weak (inherited Terminal-bench 4.0 19.1%), and **every Cyber figure is Google vendor-run or partner-reported** (no independent harness has evaluated the gated variant).
- **Provider / access:** **Fairwind Program only** — prioritized access for trusted government authorities, critical-infrastructure operators and software maintainers (roster includes Armadin, Menlo Security, Palo Alto Networks, Snowflake, Wiz). **Not** a public API; no checkout, `noFreeId`. Bundled with Google's **CodeMender** harness. Base 3.8 Flash (the general twin) is public via the Gemini API / AI Studio / Antigravity / Gemini Enterprise.
- **Release / knowledge:** Released **2026-09-02** (third Flash release in six weeks, after 3.6 Flash Jul 21 and 3.7 Flash Aug 13). Announced by Tulsee Doshi (Sr. Dir. PM) and **Raluca Ada Popa (Gemini Security Lead, Google DeepMind)**. Knowledge cutoff not stated in the sources reviewed.
- **IDs:** `gemini-3.8-flash-cyber` / `google/gemini-3-8-flash-cyber` (variant of Gemini 3.8 Flash; predecessor Gemini 3.5 Flash Cyber).
- **Context window:** **1,048,576 (1M) tokens / 65,536 (65K) max output** (same spec as base 3.8 Flash; three thinking levels, default medium). The 65K output cap is below the 128–131K leaders. Base 3.8 Flash "works harder" (~30% more output tokens/task at higher effort).
- **Modalities:** **Text + code in → text + code out** (per the folder's meta.json). ⚠ **No image/video/audio documented for the Cyber product surface and no Cyber-specific multimodal benchmark was published** — this is a code/security specialist. Note the *base* 3.8 Flash core is strongly multimodal (CharXiv 86.2%, LVBench 87.8%), so latent vision may exist in the shared foundation, but it is neither surfaced nor benchmarked for Cyber. **[2026-11-02: AA now independently confirms the base foundation is fully omni (text+image+speech+video, AA-MMMU-Pro 85.6) — the "latent vision" is real in the core, but the gated Cyber deliverable is still text/code-only and unbenchmarked for vision, so the Multimodal score is held at 52 with the conditional upside now better grounded.]**
- **Pricing (as of 2026-10-23):** **No public price** — Fairwind-gated. Google argues it is **Pareto-optimal**: on CWE-Bench the leading frontier model's point sits at ~**3× Cyber's cost per rollout**; **Wiz measured 2.3–5.2× lower cost** than other leading frontier models on its internal pen-test benchmark. (The base 3.8 Flash twin is cheap: $0.75/$3.75 intro through 2026-12-31, then $1.50/$7.50; cached $0.075.)
- **Architecture:** Undisclosed proprietary (Google DeepMind); the base 3.8 Flash core runs ~**305 output tok/s** (fastest AA has measured). Cyber is the security-tuned variant with **more permissive cyber mitigations** (hence the gating) and top-tier prompt-injection robustness (**Gray Swan IPI 6.0%** attack-success, vs Opus 5's 4.8%, 3.7 Flash's 9.2%, GPT-5.6 Sol's 27.0%).

### Normalized scores (1–100)

- **Tool use: 85/100.** **Holds 85.** Frontier **autonomous security agency** on vendor/partner cells (CyberGym 86.2% #1, CodeMender find/verify/fix, a <2-hour real critical-vuln discovery) plus **independently-corroborated agentic terminal strength** — base **Terminal-Bench 2.1 AA 87.6** sits right at the vendor 89.4. Held at (not above) 85 because **general long-horizon agency is independently confirmed weak** (base **Terminal-Bench 4.0 AA 19.7** ≈ the vendor 19.1; OSWorld-2.0 59.0; AA Agentic Index 41.1 mid, ApprenticeBench 24, MazeBench 4), and **every Cyber agentic figure remains vendor-only** (gated, unreplicated).
- **Reasoning: 83/100.** **Trimmed 86 → 83 — the draft's "inherited near-frontier core (AA Index 59)" premise is falsified.** AA now measures base Gemini 3.8 Flash (high) at **Intelligence Index 31 (#38/58 class, below the median 37)** — solid-upper-mid, not near-frontier. Two offsets keep it in the low-80s: the core's **specialized cells are genuinely strong** (**GPQA-D AA 95.3 / Vals 94.4, ARC-AGI-2 89.2, MMLU-Pro 90.2, FrontierMath v2 68.4**), and the adversarial security reasoning (71.0% vuln discovery, best-in-class prompt-injection robustness) is real — but the HLE-Verified 54.9 "best in table" is a **vendor base-card** figure, **CritPt 18.3** is weak, and the **hallucination 55.1** plus the collapsed composite index cap it below the draft's 86.
- **Context window: 87/100.** **Holds 87 — now measured rather than assumed.** A **1M-token native window** with the draft's discount "no long-context-recall figure published" is resolved by base **AA-LCR 81.3** (good, not elite). Still capped below the 89–93 leaders by the modest **65K output cap**, the "works-harder" **~30% token burn / AA verbosity 130M**, and because 81.3 is good rather than top-tier.
- **Multimodal: 52/100.** **Holds 52 — the structural weakness of a code/text specialist.** The gated **Cyber product surface is documented text + code only** with **no Cyber vision benchmark**, so it is scored as delivered, not on the foundation's latent capability. The re-check **strengthens the draft's conditional note**: AA now independently confirms the **base core is fully omni (text+image+speech+video, MMMU-Pro 85.6)** — so the latent vision is real and, *if Google surfaces/benchmarks Cyber vision*, this dimension and the Overall would rise materially — but that upside stays uncredited while Cyber ships text/code-only.
- **Coding: 89/100.** **Holds 89 — the standout, and now independently corroborated.** Frontier **security** coding on vendor/partner cells (CyberGym 86.2 #1; CWE-Bench 47.2 Pareto; 71.0% across 20 languages; Chrome 2.6×) plus **independently-verified general coding on the shared core**: **AA Coding Index 76.3**, **DeepSWE 73.8 on the datacurve independent leaderboard** (confirming the vendor's 73.7), **LiveCodeBench (Vals) 89.5**, SWE-bench (Vals) 80.0. Still discounted from the low-90s by the confirmed **Terminal-Bench 4.0 19.7** long-horizon weakness and because the security margins themselves are vendor-only (base independent cyber probes — CyberGym-E2E-AA 8.4, DeepsecBench-AA 14.5 — are weak, so Cyber's lead rests on the gated fine-tune, not the base).
- **Cost efficiency: 85/100.** **Holds 85.** Genuinely strong *for its capability* on the vendor's account — **Pareto-optimal on CWE-Bench** (~1/3 a frontier model's cost per rollout), Wiz 2.3–5.2× lower — and the **base core is cheap** ($0.75/$3.75, 90% cache, AA-confirmed). Still tempered because there is **no public Cyber price** (Fairwind-gated, so $/token cannot be independently verified) and the base is actually costly per task (**AA $7.77/task, #52/57 — expensive for its intelligence**). Scored but **not** counted in the Overall per methodology.
- **Overall Score: 79/100.** **Trimmed 80 → 79.** Mean of Tool 85 + Reasoning 83 + Context 87 + Multimodal 52 + Coding 89 = 396 / 5 = 79.2 → **79** (the only change is Reasoning −3, from the falsified AA-59 core). Best fit unchanged: **vetted defensive-security teams** (Fairwind + CodeMender) doing autonomous vuln discovery and automated patching at scale, where frontier security coding, Flash speed and prompt-injection robustness matter; **not** a general-purpose or multimodal API, and general long-horizon agency should route to Opus 5 / a frontier model. Independent read: my 79 sits **well below the queue's curated 87.9** for three compounding reasons — (a) the **Multimodal 52** (a code/text specialist, the Overall's biggest drag), (b) the **Fairwind gating / no public price / vendor-only, independently-unverified** Cyber benchmarks, and (c) the newly-falsified "near-frontier core" (base AA Index **31**, not 59). On its *specialty* it is plausibly world-class (#1 CyberGym), and its general coding is now independently solid (Coding Index 76.3, DeepSWE 73.8) — but a general-composite mean honestly understates a gated specialist, and this pass declines to credit unbenchmarked inherited vision or an unreverifiable vendor lead.
