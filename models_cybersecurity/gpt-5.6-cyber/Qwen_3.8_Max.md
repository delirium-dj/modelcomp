## Model card

- **Name:** GPT-5.6 Cyber
- **Short description:** OpenAI's **dedicated offense-capable cybersecurity model**, a fine-tune **built on GPT-5.6 Sol** and released **2026-08-10** when OpenAI split its cyber-defense program **Daybreak** into two tiers — **Blue** (unguardrailed GPT-5.6 Sol for defensive work: vuln discovery, secure code review, malware analysis) and **Red** (this model, for authorized vulnerability research and exploit validation). It is the **first model rated High for cybersecurity capability under OpenAI's Preparedness Framework**. Headline evidence: **95.0%** completion on OpenAI's internal *advanced cybersecurity benchmark* (vs **57.3%** for the prior GPT-5.5-Cyber and **~2%** for unguardrailed Sol), and **two previously-unknown Chrome V8 0-days found pre-release** that chain into a heap-sandbox escape (one is **CVE-2026-15903**, already patched by Google; Chrome <150.0 affected). Trade-offs: it is **hard-gated** (application-vetted Daybreak Red — identity verification, usage monitoring, lawful-use commitment; no self-serve API), it is a **text/code specialist** (no documented vision/audio), it is **expensive** ($12.5/$75), OpenAI itself notes **Cyber performs *worse* than GPT-5.6 Sol on a general evaluation** (specialization cost), and — because it is gated — **no neutral harness has independently ranked it** (BenchLM: *unranked*, 3 vendor rows of 811; the AA Cyber Index leaderboard does not publish a confirmed neutral cell for it in the sources reviewed).
- **Provider / access:** **Daybreak Red only** — application-vetted via `openai.com/daybreak/partners`; identity verification + monitoring + lawful-use terms; TAC members need a hardware passkey. **Not** a public self-serve API. From **2026-08-13** both Daybreak tiers are available to qualified customers via **Amazon Bedrock**; launch partner program spans 16 security vendors (IBM, CrowdStrike, Accenture, Cisco, Cloudflare, …). For defensive-only work OpenAI steers users to Daybreak Blue / GPT-5.6 Sol.
- **Release / knowledge:** Released **2026-08-10** (developer changelog dates the two-tier launch to 2026-08-07). **Knowledge cutoff 2026-02-16.** Aliases `gpt-daybreak-red-latest` / `gpt-daybreak-blue-latest` are now **deprecated** on OpenAI's model pages (they point to the latest cyber model). Predecessor: GPT-5.5-Cyber (57.3% on the internal advanced bench). A newer **GPT-6 Cyber** now exists (BenchLM: score not computed).
- **IDs:** `gpt-5.6-cyber` / `openai/gpt-5.6-cyber` (variant: `cyber` / daybreak-red; family GPT-5.6; siblings Sol, Terra, Luna).
- **Context window:** **400,000 total / 272,000 max input / 128,000 max output** per OpenAI's official model page (fetched 2026-10-20) — the standard GPT-5.x configuration; requests above 272K input tokens are billed at **2× input / 1.5× output** for the full request. ⚠ **DISCREPANCY:** this folder's `meta.json` states "**1,048,576 total; 128K max output**"; the 1M figure is **not** corroborated by OpenAI's model page and appears to be a scaffolding error (272K in + 128K out = 400K is internally consistent and matches the >272K billing rule). I score Context on the verified **400K**; if 1M were confirmed, Context would rise to ~95 and the Overall with it.
- **Modalities:** **Text + code in → text + code out** (per `meta.json`). ⚠ **No image/video/audio documented for the Cyber surface and no Cyber-specific multimodal benchmark was published** — it is a code/security specialist. The GPT-5.x base family generally accepts image input, so latent vision *may* exist in the Sol foundation, but it is neither surfaced nor benchmarked for Cyber (conditional upside, uncredited here).
- **Pricing (as of 2026-10-20, OpenAI model page):** **$12.5 input / $1.25 cached input / $75 output per 1M tokens.** On the Aug-2026 basis this was **2.5× GPT-5.6 Sol's** then-price ($5/$30); Sol is now $4/$20 (promotional to 2026-11-30). Premium, gated pricing — no public checkout.
- **Architecture:** Undisclosed proprietary (OpenAI); a security-tuned derivative of GPT-5.6 Sol with **more permissive offensive-cyber mitigations** (hence the Red-tier gating) and a High cybersecurity rating under the Preparedness Framework. Reasoning-type model.

### Raw benchmarks found

Security / agentic — Cyber-specific (**OpenAI vendor-run** unless noted):

- **OpenAI internal advanced cybersecurity benchmark: 95.0% completion** — vs GPT-5.5-Cyber **57.3%**, unguardrailed GPT-5.6 Sol **~2%** (corroborated by Gloqo: "Standard GPT-5.6 Sol completed 1.5% … Daybreak Blue 2% … GPT-5.6-Cyber completed 95%")
- **2 Chrome V8 0-days found pre-release** — chain into a heap-sandbox escape; **CVE-2026-15903** (patched by Google, Chrome <150.0) — real-world autonomous vuln discovery
- **ExploitGym: 32.1%** — the single agentic row BenchLM surfaces (attributed to an OpenAI cyber page); modest, and BenchLM otherwise leaves Cyber **unranked**
- First model rated **High for cybersecurity capability** under OpenAI's Preparedness Framework

Independent / base-core context (BenchLM aggregator + Artificial Analysis):

- **BenchLM: GPT-5.6 Cyber = UNRANKED** — "3 source-displayable benchmark rows but no public overall score," coverage **3 of 811**, context "Coming soon"
- **BenchLM base GPT-5.6 Sol = 74.34** (the core Cyber inherits) — solid-upper-mid; siblings Terra 69.41, Luna 63.79; for scale the newer GPT-6 Sol = 77.74, GPT-6.1 Sol = 85, GPT-6 Astra = 85.18
- **AA Cyber Index v1** (CWE-Bench-AA · DeepsecBench-AA · CyberGym-E2E-AA on the Stirrup harness) is the neutral cyber standard, but it reports that frontier general models (**GPT-6 Astra/Sol, Claude Opus 5.5, Qwen3.8 …**) **refuse ≥98%** of CyberGym-E2E-AA tasks — the ungated Cyber variant is the class of model built to attempt them; no confirmed neutral Cyber cell was published in the sources reviewed

> Provenance: **All Cyber-specific capability figures (95.0% internal bench, the V8 0-days, ExploitGym 32.1%, the High Preparedness rating) are OpenAI vendor-run/self-reported** and, because the model is **Daybreak-Red-gated, no neutral harness has independently ranked it** (BenchLM unranked; AA Cyber Index cell unconfirmed here). Per methodology the vendor cells are treated as an **upper bound and discounted**. The **base-core read is grounded on GPT-5.6 Sol's independent BenchLM overall (74.34)**, which caps the inherited general Reasoning/Coding at solid-upper-mid rather than frontier. OpenAI's own note that **Cyber scores *below* Sol on a general evaluation** is applied as a specialization-cost discount. No benchmark was invented.

### Normalized scores (1–100)

- **Tool use: 85/100.** Frontier **autonomous security agency** on vendor cells — **95.0%** advanced-cyber task completion (vs 57.3% prior gen, ~2% unguardrailed Sol) and, decisively, **two real Chrome V8 0-days discovered pre-release** (CVE-2026-15903 chained heap-sandbox escape) covering the discover→reproduce→patch loop. Held at (not above) 85 because every agentic figure is **vendor-only and gated** (no neutral replication; BenchLM unranked), the one surfaced independent row (**ExploitGym 32.1%**) is modest, and general long-horizon agency is unverified for the Cyber surface.
- **Reasoning: 83/100.** Strong **adversarial security reasoning** (exploit chaining, 95% advanced tasks) on a **frontier-flagship-derived core**, but the base **GPT-5.6 Sol is independently solid-upper-mid, not frontier** (BenchLM **74.34**, below GPT-6 Sol 77.74 / GPT-6.1 Sol 85), and OpenAI states **Cyber performs *worse* than Sol on a general evaluation** — so the specialty is discounted and the general composite is capped well below the peer's 92.
- **Context window: 81/100.** **400K total / 272K max input / 128K max output** (OpenAI model page) sits in the upper-middle of the 200K–500K band, with a genuinely strong **128K output** (no output-cap caveat). Scored on the verified 400K, **not** `meta.json`'s uncorroborated 1M (flagged above); had 1M been confirmed this would be ~95.
- **Multimodal: 30/100.** The structural weakness of a **text + code specialist**: no image/video/audio documented for the Cyber surface and **no Cyber vision benchmark**. Nudged just above the text-only floor because code input is a distinct modality and the GPT-5.x Sol foundation *likely* accepts images — but that latent vision is neither surfaced nor benchmarked for Cyber, so it stays **uncredited conditional upside** (the peer's 60 assumes multimodality the gated product does not document).
- **Coding: 85/100.** **Frontier security coding** on vendor cells (95.0% advanced tasks, patch verification, the V8 0-days) plus **Sol-derived general coding** that is independently solid-upper-mid (BenchLM base 74.34). Discounted from the low-90s because the security margins are **vendor-only/gated with no neutral replication** and OpenAI's own general-eval note puts Cyber **below Sol** outside its specialty.
- **Cost efficiency: 28/100.** **Expensive and gated:** $12.5 input / $75 output per 1M (2.5× Sol at launch), no public checkout; the $1.25 cached-input tier and OpenAI's "Pareto for authorized vuln research vs human cost" argument are the only mitigants. Scored but **not** counted in the Overall per methodology.
- **Overall Score: 72.8/100.** Mean of Tool 85 + Reasoning 83 + Context 81 + Multimodal 30 + Coding 85 = 364 / 5 = **72.8**. Best fit: **vetted offensive-security / vulnerability-research teams** (Daybreak Red + Bedrock) doing authorized exploit validation and automated patching at frontier scale, where the 95% internal bench and real V8 0-days matter and the premium price is acceptable; **not** a general-purpose or multimodal API, and general reasoning/coding should route to GPT-5.6 Sol or the newer GPT-6.x gen. Independent read: my 72.8 sits **below the cohort's 86.2** (which rests on a **single** qualifying peer rater) for four evidence-based reasons — (a) **Context 81 not 95** (I use OpenAI's verified **400K/272K/128K**, not `meta.json`'s uncorroborated 1M); (b) **Multimodal 30 not 60** (text/code-only documented surface, no Cyber vision benchmark); (c) **Reasoning 83 / Coding 85 not 92 / 94** (base Sol's independent BenchLM overall is **74.34**, and OpenAI notes Cyber scores *below* Sol on a general eval — the specialty cells are vendor-only and gated); (d) **Tool 85 not 90** (real 0-days are strong but vendor-only, ExploitGym 32.1% modest). As a narrow gated specialist, a general-composite mean honestly understates its world-class *security* capability.
