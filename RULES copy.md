## Research rules

- "model/<slug>/<STEM>.md" is forbiden to be deleted. It can only be renamed to "<STEM>.md.excluded" if there are not enough data for computing the "Overall" score. Any deletion is strictly forbiden!
- When AI models is doing research - it will "model/<slug>/<STEM>.md" if that file already exist. If AI model finds "model/<slug>/<STEM>.md.excluded" - it will perform additional researches in order to find reliable data and convert "model/<slug>/<STEM>.md.excluded" to "model/<slug>/<STEM>.md".

## Scoring rules

- Only up to top ten (10) models, with highest scores for that particular model, can be counted for the "Overall" score for some model.
- There is a "cap" rule that only models who has highest score than 84.9 for themselfs can be counted in "Overall" calculation for other models. Example 1: If some model has "Overall" score = 92 -> its findings (research) will be considered for "Overall" scores of the other models but only in case that its average score of 92 is among top ten models whose are evaluated particular model. Example 2: If some model has "Overall" score = 92 -> its findings (research) will NOT be considered for "Overall" scores of the other models but its findings should be displayed for particular model and never deleted because of any reason.
