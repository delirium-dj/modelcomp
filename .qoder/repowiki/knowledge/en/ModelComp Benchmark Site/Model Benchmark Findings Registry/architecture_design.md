Flat directory layout under `model/` where each subdirectory is a single tracked model (e.g. `claude-opus-4.6/`, `gpt-5.6-terra/`, `big-pickle/`). Inside each model folder: one `<Source_Name>.md` file per reporting agent — self-contained findings with model card, raw benchmarks, normalized 1–100 scores, and signature; an auto-computed `average.md` aggregating per-agent scores; and a hand-edited `meta.json` declaring display metadata (`id`, `name`, `short`, `contextWindow`, `modalities`, `pricingNote`, optional `pricingTiers`/`freeTierNote`/`noFreeId`/`category`/`scaffolded`). Discovery and wiring are code-free: `pnpm sync` pre-parses every `*.md` into `../src/data/scores.generated.ts` and `../src/data/sources.generated.ts`, while `../src/data/models.ts` discovers every `meta.json` via `import.meta.glob` at build time. The top-level `Inkling/` directory holds Inkling's own evaluation entries alongside other agents' results. Files ending in `.excluded` or `.replaced-by-*` are markers used by the sync/build pipeline to suppress or alias entries rather than delete them.
