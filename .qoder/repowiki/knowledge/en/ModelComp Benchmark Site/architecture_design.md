Three layers are wired together from this root: the Data layer (model_data_text, model_data_finance, model_data_voice) stores per-model Markdown reports plus a curated meta.json manifest per slug; the Tooling layer (scripts_tooling) is invoked via pnpm sync, scans those directories, validates/quarantines reports, recomputes averages, and emits TypeScript registry + scores modules alongside the data; the Presentation layer (frontend_app) is a QwikCity SSR/SSG site built with Vite that imports the generated registry rather than reading disk at runtime. The root package.json is the single entry point for all three layers, vercel.json configures CDN cache headers for the deployed static output, and agent workflow definitions under .agents/workflows and .antigravity/workflows guide delegated research runs against the registries.
