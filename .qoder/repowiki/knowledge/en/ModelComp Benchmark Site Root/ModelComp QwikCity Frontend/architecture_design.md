Built on QwikCity with three entry points: `entry.ssr.tsx` (SSR via `renderToString` with `containerTagName: 'html'`), plus `entry.dev.tsx` and `entry.preview.tsx`. `src/root.tsx` is the app root wrapping everything in `QwikCityProvider`, injecting an inline anti-flash script that sets `document.documentElement.classList.toggle('dark')` before first paint and conditionally linking `public/manifest.json` for PWA. `src/routes/layout.tsx` is the shared layout composing `<Header />`, `<main id="top">`, and `<Footer />` around a `<Slot />`. Route modules (`routes/index.tsx`, `routes/model/[slug]/index.tsx`) are page components; the homepage composes `Hero`, `CompareSection`, `Methodology`, and `ModelCards`, driving URL query params (`a`, `b`, `c`, `source`) through `useStore` + `useVisibleTask$` for deep-linkable state. Static data lives under `src/data/`: `models.ts` hydrates `AiModel[]` from `model/*/meta.json` files globbed at build time combined with pre-parsed numeric scores from `scores.generated.ts` and the source registry from `sources.generated.ts`; `catalog.generated.ts`, `rankings.generated.ts` are additional generated assets. All generated files are emitted by an external `pnpm sync` step so adding a new model folder requires no code changes. Styling uses Tailwind CSS with CSS custom properties (`--color-bg`) toggled via `html.dark` rather than class-based backgrounds, and a `theme-toggle` component persists the preference in `localStorage`.
