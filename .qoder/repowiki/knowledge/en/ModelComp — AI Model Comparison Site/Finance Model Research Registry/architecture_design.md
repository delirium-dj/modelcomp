Two-level layout: a top-level `Ling_3.0_Flash_Fin.md` acts as a single-edit delegator that pins an `AGENT_SOURCE_STEM` and instructs the orchestrator to run `tasks/research.md` against a target model; a `ling-3.0-flash-fin-free/` subdirectory holds the actual model report tree — one `.md` file per contributing rater model (e.g. Gemini, GLM, Kimi, Muse Spark), plus an `average.md` aggregating cross-rater scores and an agreement notes section listing qualifying raters (Overall > 84.9) and ignored ones, and a `meta.json` declaring the canonical model identity (`opencode/ling-3-0-flash-fin-free`) with pricing tiers and modality metadata. Files marked `.excluded` or `.replaced-by-Flash` are intentionally omitted from scoring. The directory is consumed by the broader `model-comparison.md` / `model-findings.md` aggregation pipeline referenced from `average.md`.
