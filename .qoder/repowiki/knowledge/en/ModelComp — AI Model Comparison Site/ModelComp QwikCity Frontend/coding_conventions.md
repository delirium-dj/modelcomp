- Components are defined as Qwik `component$()` functions exported from single-file `.tsx` modules under `src/components/`, with inter-component communication via `$`-prefixed event handlers (e.g. `onSelect$`, `onSource$`).
- Generated benchmark data is never hand-edited: numeric scores come from `scores.generated.ts` and the source registry from `sources.generated.ts`, both produced by `pnpm sync`, while human-curated metadata stays in `model/*/meta.json` files globbed at build time.
- URL-driven state on the homepage is kept in sync with the address bar using `useStore` plus `useVisibleTask$` with `track()`, replacing the history via `window.history.replaceState` only when selections differ from defaults.
- Dark mode is applied by toggling the `dark` class on `document.documentElement` (via an inline anti-flash script and the `ThemeToggle` component); body colors follow from CSS variables under `:root` / `html.dark` rather than competing Tailwind background classes.
- Per-route SEO metadata is declared by exporting a `head: DocumentHead` object from route modules, consumed by `RouterHead` which maps `head.meta`/`head.links`/`head.styles`/`head.scripts` into `<meta>`/`<link>`/`<style>`/`<script>` tags.
