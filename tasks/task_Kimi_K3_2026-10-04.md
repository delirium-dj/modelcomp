## PART B — Bugs found while scanning

### B1. The `voicemodels/` tripwire can never fire (variable shadowing) — **highest value**
`scripts/sync-data.mjs:150–154`:
```js
for (const root of FORBIDDEN_ROOTS) {      // shadows repo root from line 82
  if (existsSync(join(root, root))) {      // => existsSync("voicemodels/voicemodels")
    fail(forbiddenRootMessage(root));
  }
}
```
Line 82 defines `const root = <repo root>`. The loop variable is *also* named
`root`, so `join(root, root)` evaluates to `"voicemodels/voicemodels"` — a
relative path that can never exist. `RULES.md:48` states as an absolute
guarantee: *"pnpm sync FAILs loudly while voicemodels/ exists."* **It does not.**
The pure-helper test passes because it only covers `forbiddenRootMessage()`,
never the call site.
**Guidance:** one-line fix —
```js
for (const forbidden of FORBIDDEN_ROOTS) {
  if (existsSync(join(root, forbidden))) fail(forbiddenRootMessage(forbidden));
}
```
Then add a sync-level regression test (create a temp `voicemodels/` dir, assert
non-zero exit) so the call site is covered too.
*Mitigating:* `.githooks/pre-commit:11–18` independently blocks staged additions
under `voicemodels/`, so the second line of defence is live — but the sync gate
RULES.md promises is currently fiction. *(Also found independently by the prior
audit — still unfixed at HEAD.)*

### B2. Canonical URLs + sitemap point at `localhost` — **verified in `dist/`**
- `dist/model/big-pickle/index.html`: `rel="canonical" href="http://localhost:4173/model/big-pickle/"`
- `dist/sitemap.xml`: **136** `<loc>http://localhost:4173/…` entries.
Cause: `adapters/static/vite.config.ts:15` hardcodes `origin: "http://localhost:4173"`,
and `router-head.tsx:11` emits `loc.url.href` verbatim. `vercel.json` shows a
real deployment is intended, so every page self-canonicalises to localhost and
the sitemap advertises 136 unreachable URLs.
**Guidance:** read the origin from the environment with a localhost fallback:
```ts
staticAdapter({ origin: process.env.SITE_ORIGIN ?? "http://localhost:4173" })
```
and document `SITE_ORIGIN` in `README.md`. Re-verify by grepping
`dist/sitemap.xml` after the next build.

### B3. `<link rel="manifest">` is emitted twice on every page — **verified in `dist/`**

### B4. All 134 model pages share one `<title>` — **verified in `dist/`**

`dist/model/big-pickle/index.html`; the export at
`src/routes/model/[slug]/index.tsx:437–445` is a static object). Duplicate titles
hurt SEO and tab usability; the generic `description` meta likewise repeats.
**Guidance:** make `head` a resolver:
```ts
export const head: DocumentHead = ({ params }) => {

    ? { title: `${m.name} — scores & agent ratings | ModelComp`,
        meta: [{ name: "description", content: `${m.name}: Overall ${m.scores.overall}/100. ${m.short}` }] }
    : { title: "Model not found — ModelComp" };
};
```
*(Both B3 and B4 coincide with the prior audit's findings and are still open.)*
