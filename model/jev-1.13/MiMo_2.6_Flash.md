## Model card

- **Name:** Jev 1.13 (TypeSafe "System One" model — first public release, named after economist W. Stanley Jevons)
- **Short description:** A non-generative structured-decision model: unstructured `state` + typed questions in, calibrated `choice`/`score`/`noul` probabilities out, all fields sampled in one parallel pass. Cannot emit text, code, or rationales at all — a "frontier-intelligence function call" built for classify/route/score/extract/branch automation, not chat. Standalone model, not a variant of another tracked entry. Family update: sibling **Jev 1.14.0** shipped 2026-10-14 (Jev Day, new `box` type; `jev-preview` alias) — this folder tracks `jev-1.13.0`.
- **Provider / access:** TypeSafe AI (San Francisco; founded by ex-OpenAI researcher Diogo Almeida after 2 years in stealth). First-party API `POST https://api.typesafe.ai/v1/systemone` (`/v1/models` lists routes) plus Python/JS SDKs and browser console. Gateways: OpenRouter `typesafe/jev-1.13` (dedicated decision route), Vercel AI Gateway, OpenCode Zen (`jev-1.13` paid, `jev-1.13-free` limited-time free), and LiteLLM (Day-0 proxy, 2026-10-15, forwards both danger-zone headers). Not open weights.
- **Release / knowledge:** Early access 2026-09-15 behind waitlist; GA ~2026-09-21. `jev-1.13.0` remains the stable `jev-latest` target as of 2026-10-16 00:28 UTC (jevainews live check); TypeSafe promises 60 days' warning before formal deprecation and says 1.13 "will be available for a while". Training data / knowledge cutoff not disclosed.
- **IDs:** `jev-1.13.0` (TypeSafe), `typesafe/jev-1.13` (OpenRouter, dated builds e.g. `typesafe/jev-1.13-20260917`), `jev-1.13` / `jev-1.13-free` (OpenCode Zen), OpenCode usage data `jev-1.13`.
- **Context window:** Defaults unchanged: **64K per request / 32K per state+longest-question** (official models page, checked 2026-10-15). **NEW opt-in: `TypeSafe-Danger-Zone-Long-Context: true` raises BOTH caps to 262,144 tokens** on jev-1.13 and jev-1.14 (official docs `docs.typesafe.ai/models#long-context` + live HTTP-200 tests 2026-10-15); same per-token price, but TypeSafe warns it is "slower and less accurate than staying within the default limits", and no public test has yet filled 262K. Max output is not applicable — responses are typed answer objects, not generated text.
- **Modalities:** **UPDATED — image input now exists.** Text in (string, JSON object, array) **plus PNG/JPEG still frames behind `TypeSafe-Danger-Zone-Images: true`** (official Jev Day blog 2026-10-14: "the Jev you all know and love (jev-1.13.0) was multimodal all along"; limits: 16 MiB/file, 256–1568 px/side, 78,400–2,458,624 total px, 32 MiB body, images placed via top-level `assets` map; image tokens bill at the text input rate ≈ 10,000 images/$1 per Wes Bos). Experimental/"dreamer-ready", default-off (HTTP 400 without the header); the docs models page still prints "Input Text"; TypeSafe notes all models perform worse on multimodal than pure text; audio/video remain unsupported. Decision-typed out (choice/score/noul — no text, no images).
- **Pricing (as of 2026-10-16):** unchanged — $0.042 per 1M input tokens ($42/Btok), **output tokens free** ("too cheap to meter"); ≈$0.0004 per decision case in vendor evals. Independent corroboration: Vals AI measured **1/498th of GPT-6 Astra's cost** (TypeSafe claims 444.6× — "headline holds up"). Zen `jev-1.13-free` = $0/$0 limited-time (not re-verified this pass; free-tier usage consents to training per repo convention).
- **Architecture:** proprietary; parallel sampler emits every field in a single forward pass (vs autoregressive token-by-token), trained with TypeSafe's Reinforcement Learning for Calibrated Decisions (RLCD); parameter count undisclosed.

### Raw benchmarks found

Agent / tool use:

- Structured-output error rate: **0%**, tool-call error rate: **0%** (TypeSafe structured-output test; same harness: OpenAI luna/terra 0.58%, Claude Opus 5 5.73%, Claude Haiku 4.5 45.5%; worst tool-call error GPT-5.6 Sol 17.0%) — vendor-run
- Terminal-Bench 2.1 / Tau3 / GDPval-AA / OSWorld / Claw-Eval: **N/A — model cannot invoke tools or generate text**; it sits beside agents as judge/router instead
- Vendor home-page claim: 193.6x faster and 444.6x cheaper than LLM reference on their workflows (self-reported; Vals AI independently corroborates: 194× latency at 32 judgments, 1/498 cost)
- **NEW independent:** VulcanBench Verdict v1 (2026-09-22, corrected 09-23; 2,641 queries over 745 agent-written patches, pinned to `jev-1.13.0`): patch-pass accuracy at dev-fitted cutoff **68.9%** vs **72.4%** majority floor (below floor by 3.5 pts; the first-run 40.8% was withdrawn as a 0.5-cutoff artifact); style-pair AUROC **0.962**; probabilities compressed (max "pass" 0.42) = calibration failure (https://vulcanbench.com/benchmarks/verdict-v1-jev.html)
- **NEW independent reliability:** Vals AI (2026-10-06): zero malformed responses, zero service failures, fully deterministic (identical answers across 5 repeats of 25 items); median latency **0.10 s**, 194× lower than GPT-6 Astra at 32 judgments (https://www.vals.ai/blogs/independent-evaluation-of-jev)

Reasoning / knowledge:

- TypeSafe 4-workflow decision eval (security incident response, agent-trace observability, invoice processing, customer service; reference = average of GPT-6 Astra + Fable 5.1): **Jev 67.8% mean agreement** (61.7–76.0% per workflow), $0.0004/case, 0.4s — vs GPT-5.6 Terra 67.9% ($0.0304, 10.1s), GPT-5.6 Sol 74.1% ($0.0836, 23.3s), Claude Opus 5 73.1% ($0.1761, 37.8s) — vendor-run, no independent large-scale reproduction yet
- GPQA / HLE / MRCR / LCR / Intelligence Index: no score exists (no public text-generation path to run them)
- Official documented failure modes (`docs.typesafe.ai/model-jaggedness/jev-1.13`, reviewed 2026-09-16/17): literal reading of instructions, **not a calculator** (no counting, no date ordering, no numeric precision), weak on multi-hop indirection, context rot on large irrelevant state, steerable by adversarial content, English-primary (CJK weaker)
- **NEW independent (academic):** arXiv 2609.37647, Deußer/Sparrenberg/Sifa (submitted 2026-09-29) — `jev-1.13.0` zero-shot on **37 datasets / 346,009 requests / <$10** with one frozen template per dataset: **95–99%** on IMDB/SST-2/HellaSwag/ARC, **86.7%** Belebele across 122 languages; beats Qwen3.8-27B on **27/37** datasets (none of Qwen's 9 leads outside bootstrap intervals) and Gemma-4-E4B on **37/37**; choice probabilities well-calibrated and support selective prediction (threshold-tuned micro-F1 on UNFAIR-ToS **0.50 → 0.75**); MMLU calculation-heavy items 94% vs 91% non-calc; option-rotation invariant, question-withholding → near chance (rules out shallow memorization) (https://arxiv.org/abs/2609.37647)
- **NEW independent:** Vals AI (2026-10-06) claim verification on 400 SEC-10K items: Jev 1.13.0 scores **0.975** at **$0.02/1,000 cases** — statistically tied with GPT-6 Astra, GPT-6.1 Sol, GPT-6 Luna (all 12 systems 0.953–0.995); **last of 12** on the preregistered LegalBench 12-subtask slice (every other system's lead statistically reliable, Bonferroni-corrected bootstrap); exceeded a 1% error budget (95% automated at 1.6% error on held-out items) (https://www.vals.ai/blogs/independent-evaluation-of-jev)
- **NEW independent:** TrueStandard 108-claim test (2026-09-18; `jev-1.13.0` reproduced 2026-10-16): **96.3%** accuracy (identical rerun — same four wrong claims), hardest tier **91.7%** vs chat models in the low 80s; Brier 0.0331; calibration error **0.066** ≈ Gemini 3.1 Flash Lite 0.061 / Claude Haiku 4.5 0.067 → **the "calibrated-probability" claim did not hold on this corpus**; whole run cost $0.00033 (8× cheaper than Flash Lite, 27× cheaper than Haiku at equal-or-better accuracy) (https://truestandard.ai/blog/jev-accuracy-tested)

Coding:

- SWE-bench / DeepSWE / LiveCodeBench / SciCode / Terminal-Bench: no score — model cannot write code or strings
- Independent reproduction (`github.com/rorshopping/jev-on-a-laptop`): reimplemented Jev-style parallel constrained decoding on stock 1.5B–8B models — schema validity 100% by construction, but values still wrong sometimes and local "confidence" was raw softmax (not trained calibration); confirms the decoupling of *type safety* from *accuracy*
- Code *judgment* (not generation): VulcanBench Verdict v1 shows mixed results — patch-pass judgment 68.9% at fitted cutoff (below the 72.4% floor) but strong style ranking (AUROC 0.962); Jev cannot take VulcanBench Frontier v4 because it cannot write code (https://vulcanbench.com/benchmarks/verdict-v1-jev.html)

Multimodal: image input added 2026-10-14 behind `TypeSafe-Danger-Zone-Images` (official blog; live-verified 2026-10-15: HTTP 400 without header → 200 with, noul 0.90 on a 400×400 red-square PNG on jev-1.13.0) — but no image *benchmark* (MMMU/ChartQA) exists for Jev, quality is unproven at scene level (community Jev4Mellea: 5/12 scenes covered on 1.14; Aviz Maeir Box 82%/180 scenes is 1.14-only), and TypeSafe itself says multimodal degrades vs pure text (https://jevainews.com/news/jev-images/)

Long context:

- Danger-zone long context verified accepted (HTTP 200 at 2,122 tokens on 2026-10-15) but **never publicly filled to 262K**; official caveat "slower and less accurate"; default production caps remain 64K request / 32K per question (https://jevainews.com/news/jev-long-context/, https://docs.typesafe.ai/models)

### Normalized scores (1–100)

- **Tool use: 35/100.** (Was 30 on 2026-10-01.) Still cannot invoke tools or run agentic benchmarks (N/A by construction) and keeps credit for 0% tool-call/structured-output errors by design — but the judge role now has independent evidence: VulcanBench Verdict v1 ran 2,641 code-judgment queries against `jev-1.13.0` (real agent patches, published methodology) and Vals verified zero malformed responses/no failures/determinism at 0.10 s; capped in the 30s because results are mixed (patch-pass 68.9% below its 72.4% floor) and no standard agentic harness applies.
- **Reasoning: 55/100.** (Was 45.) Three independent evaluations replaced vendor-only evidence: arXiv 2609.37647 (37 datasets, 346K requests — beats open models 27/37 and 37/37, 95–99% on core classification/reasoning sets), Vals claim-verification tie with GPT-6 Astra at 1/498 cost, TrueStandard 96.3% (91.7% on hard claims vs chat low-80s) — a strong bounded-judgment profile. Held at the mid band's floor by LegalBench last-of-12, below-floor patch judgment, TrueStandard's debunked calibration gap (ECE 0.066 ≈ peers), and documented multi-hop/math/negation failures (GPQA/HLE remain inapplicable).
- **Context window: 70/100.** (Was 40.) Default caps unchanged (64K/32K → would stay <100K tier), but the official `TypeSafe-Danger-Zone-Long-Context` opt-in now verifiably raises both caps to **262,144 tokens** — a 200K–500K tier value scored at the band's 200K anchor (70); capped there because the feature is explicitly experimental ("slower and less accurate"), default-off, and no public test has filled 262K or measured accuracy at depth.
- **Multimodal: 40/100.** (Was 10.) Image input genuinely exists on `jev-1.13.0` (official Jev Day blog + live HTTP-200 verification 2026-10-15), moving it off the below-band floor — but well under the +image-in band (60–70) because support is a default-off "dreamer-ready" danger-zone flag, the official docs still print "Input Text", zero image benchmarks (MMMU/ChartQA) exist, community scene tests are weak (5/12), and TypeSafe concedes multimodal degrades vs text. Output remains decision-only; no audio/video.
- **Coding: 10/100.** Unchanged — structurally incapable of generating code or strings, so no coding benchmark can ever apply; the new VulcanBench row measures code *judgment* (a judge/router capability, already credited under Tool use), not generation.
- **Cost efficiency: 100/100.** Unchanged — $0.042/M in and free output still beat the $0.10/$0.20 anchor ~3×, plus the limited-time $0/$0 Zen `jev-1.13-free` tier (training-data caveat); independently strengthened this pass by Vals' 1/498-of-Astra measurement. Not counted in Overall.
- **Overall Score: 42/100.** (Was 27 on 2026-10-01.) Mean of the five non-cost dims (35 + 55 + 70 + 40 + 10) / 5 = 42.0 → 42 — every dim change is evidence-backed: independent evals (Tool +5, Reasoning +10), verified danger-zone capabilities (Context +30, Multimodal +30), Coding unchanged. Best fit: pair-it niche judge/router for structured decisions, guardrails, claim-verification, and cheap calibrated-at-selective-prediction scoring — with prose, code, math, multi-hop reasoning, production-grade vision, and tight error budgets handed to a generative model.
