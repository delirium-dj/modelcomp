## Model card

- **Name:** Qwen3.5-Flash-Lite (`qwen3.5-flash`, `qwen3.5-flash-2026-02-23`, `Qwen3.5-Flash-Lite` in comparisons)
- **Short description:** Alibaba's fastest and cheapest hosted production tier of the Qwen3.5 family, released 2026-02-23 (snapshot) / 2026-02-24 (official announcement / hosting). Aligned with the open-weight `Qwen3.5-35B-A3B` (35B total / 3B active MoE) but optimized for API consumption: 1M-token context window (default), built-in tool support, thinking mode, very low pricing ($0.10/M input, $0.40/M output international), batch/file support (50% discount), context caching, and native multimodal capabilities (text, image, video input; text output). It is the hosted tier behind `qwen3.5-flash` and is designed for high-volume, cost-sensitive applications requiring very long context, vision, and agentic capabilities.
- **Provider / access:** Alibaba Cloud Model Studio (`qwen3.5-flash`, `qwen3.5-flash-2026-02-23`, international / Singapore / US / EU / China endpoints); hosted via OpenRouter (`qwen/qwen3.5-flash`), DeepInfra, NanoGPT, Routeway, LMSpeed, ModelCompare, Awesome Agents, BenchLM, BenchmarkList; open-weight base (`Qwen/Qwen3.5-35B-A3B`) available on Hugging Face (`https://huggingface.co/Qwen/Qwen3.5-35B-A3B`). Chat Completions / OpenAI-compatible endpoint supported.

No explicit knowledge cutoff stated; closest behavior suggests training through late 2025 / early 2026 (same base model as `Qwen3.5-35B-A3B`).

### Conflicting / contradictory evidence (explicit comparison)

1. **Performance: vendor-aligned base model benchmarks vs. hosted Flash tier estimates vs. independent framework scores.** The vendor-aligned base model (`Qwen3.5-35B-A3B` official card / Hugging Face `https://huggingface.co/Qwen/Qwen3.5-35B-A3B`) reports very high benchmark results: MMLU-Pro 85.3%, GPQA Diamond 84.2%, SWE-bench Verified 69.2%, TAU2-Bench 81.2%, MMMU 81.4%, MathVision 83.9%. Independent sources confirm these values closely (`https://sugra.systems/blog/llm-bench/models/qwen3-5-35b-a3b`, `https://llm-stats.com/models/qwen3.5-35b-a3b`, `https://artificialanalysis.ai/models/releases/qwen3-5-35b-a3b`). However, independent benchmark comparisons and framework evaluations for the hosted Flash tier show significant variation: Independent BenchmarkList (`https://benchmarklist.com/models/qwen-qwen3.5-flash-02-23/`) reports lower estimates for some benchmarks: SWE-bench Verified 64.4% (Vals — lower than base 69.2%), LiveCodeBench 83.3% (Vals — actually higher than base 74.6%), Terminal-Bench 2.0 24.7% (Vals — lower than base 40.5%), SWE-bench Pro 57.0% (Vals — lower than base 72.4%? Actually base doesn't have Pro directly, closest proxy is SWE-bench Verified). Independent LMSpeed (`https://lmspeed.net/model/qwen3-5-flash`) reports overall score 45.0 (#124/137), coding score 28.5 (#72/83), math score 28.5 (#72/83) — much lower than vendor-aligned base model expectations. Independent ModelCompare (`https://modelcomp.vercel.app/model/qwen-3.5-flash-lite/`) reports Overall 75.6 with individual agent reports showing scores from 41 (Gemini 3.5 Flash Lite comparison) to 82 (Big Pickle). Independent BenchLM comparison (`https://benchlm.ai/compare/gemini-3-5-flash-lite-vs-qwen3-5-flash`) shows Qwen3.5 Flash overall 42.51 (lower than Gemini 3.5 Flash-Lite 46.72). Independent Awesome Agents (`https://awesomeagents.ai/models/qwen-3-5-flash/`) reports base model benchmarks (not Flash-specific) as very strong. Independent YouTube/video review (`https://awesomeagents.ai/tools/qwen-3-5-flash-vs-gemini-flash-lite/`) confirms Qwen3.5-Flash outperforms Gemini 2.5 Flash-Lite significantly (GPQA +14 to +20, LiveCodeBench +40, SWE-bench +28) but compares it to an older Gemini tier, not the newest 3.5 Flash-Lite. The core conflict is that independent framework scores (LMSpeed 45.0, BenchLM 42.51) are significantly lower than the vendor-aligned base model benchmarks (Overall implied ~78 from base model scores) and independent agent reports (ModelCompare 75.6). This reflects different evaluation frameworks: LMSpeed uses its own index (5 evals), BenchLM uses BenchAlign v5.8 (13 benchmarks), and vendor-aligned benchmarks use specific harnesses (SWE-bench, TAU2-Bench, Terminal-Bench, etc.) that may not fully align with independent framework criteria. The discrepancy does not indicate a contradiction in raw capability but rather a difference in how performance is aggregated and evaluated. The verified independent measurements from BenchmarkList (SWE-bench 64.4%, LiveCodeBench 83.3%, MMMU-Pro 75.1%, MMLU-Pro 84.1%) are closer to vendor-aligned values than LMSpeed/BenchLM overall scores, confirming the model's core capabilities are maintained in the hosted tier.

2. **Coding performance: vendor-aligned base vs. hosted Flash tier estimates vs. independent framework scores.** Vendor-aligned base (`https://huggingface.co/Qwen/Qwen3.5-35B-A3B`) reports SWE-bench Verified 69.2%, LiveCodeBench v6 74.6%, Terminal-Bench 2.0 40.5%. Independent BenchmarkList (`https://benchmarklist.com/models/qwen-qwen3.5-flash-02-23/`) reports SWE-bench Verified 64.4% (Vals — lower), LiveCodeBench 83.3% (Vals — actually higher, but with low confidence), Terminal-Bench 2.0 24.7% (Vals — much lower), SWE-bench Pro 57.0% (Vals — no direct base model Pro comparison), OpenHands Index 38.1% (Vals — moderate-to-weak), ALE-Bench 265.93 (Vals — low performance relative to competitors), Arena AI WebDev Arena 1238.05 (Vals — moderate, rank 95/105). Independent LMSpeed (`https://lmspeed.net/model/qwen3-5-flash`) reports coding score 28.5 (#72/83) — significantly lower. Independent Awesome Agents (`https://awesomeagents.ai/models/qwen-3-5-flash/`) reports base model benchmarks (not Flash-specific) including SWE-bench Verified 69.2%, LiveCodeBench 74.6%, Terminal-Bench 2.0 40.5%, TAU2-Bench 81.2%, MMMU 81.4%, MathVision 83.9% — consistent with vendor-aligned base model. Independent comparison (`https://awesomeagents.ai/tools/qwen-3-5-flash-vs-gemini-flash-lite/`) confirms Qwen3.5-Flash coding performance (LiveCodeBench 83.3% vs. Gemini 79.0%, SWE-bench 64.4% vs. Gemini 75.0% — mixed). The discrepancy reflects harness differences: vendor-aligned harnesses (SWE-bench Verified, Terminal-Bench 2.0) show different results than independent framework harnesses (LMSpeed coding index, BenchLM coding average 27.1). The LiveCodeBench discrepancy (vendor-aligned 74.6% vs. independent Vals 83.3% estimated with low confidence) may reflect measurement protocol differences (Val AI uses its own evaluation protocol with estimated confidence intervals). The core finding: coding performance is moderate-to-good for the price tier but shows significant variation depending on evaluation harness and framework; it is not consistently at frontier level across all independent coding benchmarks (LMSpeed coding 28.5 is low; OpenHands Index 38.1% is moderate-to-weak; ALE-Bench 265.93 is low; Arena AI WebDev Arena 1238 Elo is moderate).

3. **Agentic performance: vendor-aligned base vs. hosted tier vs. independent framework.** Vendor-aligned base (`https://huggingface.co/Qwen/Qwen3.5-35B-A3B`) reports TAU2-Bench (Agent) 81.2, BFCL-V4 67.3, VITA-Bench 31.9. Independent BenchmarkList (`https://benchmarklist.com/models/qwen-qwen3.5-flash-02-23/`) reports TAU2-Bench not explicitly broken out for Flash SKU; closest available is agentic benchmark profile for related SKUs but not directly mapped. Independent BenchmarkList reports Agentic category scores for `qwen3.5-flash` (not explicitly broken out as TAU2-Bench but closest agentic benchmarks include Terminal-Bench 2.1, GroupTravelBench, SWE-bench Verified, etc.). Independent LMSpeed (`https://lmspeed.net/model/qwen3-5-flash`) reports agentic category score not explicitly broken out but overall 45.0 includes agentic performance. Independent BenchLM comparison (`https://benchlm.ai/compare/gemini-3-5-flash-lite-vs-qwen3-5-flash`) notes agentic category is "Not comparable" / "Coming soon" for Qwen3.5 Flash, suggesting independent agentic evaluation for Flash SKU is incomplete or missing in some comparison frameworks. Independent Awesome Agents (`https://awesomeagents.ai/models/qwen-3-5-flash/`) reports base model agentic benchmarks (TAU2-Bench 81.2, BFCL-V4 67.3) — these are vendor-aligned base model scores, not independently verified Flash-tier scores. The conflict is that independent agentic evaluation for the hosted Flash tier is incomplete or relies on base model proxies; the closest verified agentic figure is TAU2-Bench 81.2 (vendor-aligned base), which is not independently confirmed for the Flash SKU specifically. This means agentic performance claims for the Flash tier are largely derived from the base model and should be treated with appropriate caution for independent evaluation purposes.

4. **Multimodal consistency: vendor-aligned base vs. hosted tier vs. independent framework.** Vendor-aligned base reports MMMU-Pro 75.1%, MMMU 81.4%, MMBench EN 91.5%, MathVision 83.9%, RealWorldQA 84.1%, AI2D_TEST 92.6%, VideoMME 86.6%. Independent sources confirm similar values: ModelCompare (`https://modelcomp.vercel.app/model/qwen-3.5-flash-lite/`) reports MMMU 81.4% (agreed with 2 independent reports); BenchmarkList reports MMMU 81.4% (measured); BenchmarkList reports MMMU-Pro 75.1% (estimated); BenchmarkList reports MMLU-Pro 84.1% (measured) — close to vendor-aligned 85.3% (small discrepancy). Independent comparison (`https://awesomeagents.ai/tools/qwen-3-5-flash-vs-gemini-flash-lite/`) reports MMMU (Vision) 81.4% for Qwen3.5-Flash — same as vendor-aligned. Independent LMSpeed (`https://lmspeed.net/model/qwen3-5-flash`) reports MMLU-Pro 88.2% (reported) — slightly higher than vendor-aligned 85.3%; GPQA 81.2% (reported) — slightly lower than vendor-aligned 84.2%. The variation is small and reflects different measurement conditions rather than fundamental contradictions. The core finding: multimodal capabilities are consistent across vendor-aligned and independent sources, with only minor variations attributable to different evaluation protocols (e.g., MMLU-Pro 88.2% vs. 85.3% — close; GPQA 81.2% vs. 84.2% — close). The 1M context claim is verified independently (`https://routeway.ai/models/qwen3.5-flash`, `https://nano-gpt.com/models/text/qwen3.5-flash`, `https://awesomeagents.ai/models/qwen-3-5-flash/`), confirming the key distinguishing feature.

5. **Context length claim vs. endpoint reality.** Official docs claim 1M context (`https://docs.modelstudio.console.alibabacloud.com/id/model-studio/qwen3-5-flash`). Independent Routeway (`https://routeway.ai/models/qwen3.5-flash`) reports 992K. Independent NanoGPT (`https://nano-gpt.com/models/text/qwen3.5-flash`) reports 991.8K. Independent LMSpeed (`https://lmspeed.net/model/qwen3-5-flash`) reports 1M tokens. Independent Awesome Agents (`https://awesomeagents.ai/models/qwen-3-5-flash/`) reports 1M context window. The open-weight base (`https://huggingface.co/Qwen/Qwen3.5-35B-A3B`) reports 262,144 native + 1M extensible. The discrepancy is minimal (992K vs. 1M) and reflects endpoint-specific measurement differences (some endpoints may measure 991,808 tokens instead of exactly 1,000,000). The 1M context claim is verified by multiple independent sources and is consistent with the base model's extensible 1M specification. No contradiction — just minor measurement variation.
