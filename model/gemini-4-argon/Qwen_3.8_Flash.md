## Model card

- **Name:** Gemini 4 Argon
- **Short description:** Google's Gemini 4-generation flagship (base variant) — near-top Terminal-Bench 4.0 and OSWorld agency, best-in-class factuality (15.1% hallucination), elite DeepSWE, with sparse published coverage so far.
- **Provider / access:** Google DeepMind, proprietary hosted model. *(Second pass 2026-10-09: access is the single biggest caveat. Google's launch post (Sep 30, 2026) says Argon was rolling out **only to trusted cyber defenders through the Fairwind Program**, taking part in the U.S. government's voluntary pre-release access process, with developers/enterprises/consumers "as soon as possible", **starting with paid API customers and Google AI Ultra subscribers** — no GA date published. NeuralTrust (quoting DataCamp) found **no published API model ID** on launch day and no listing on OpenRouter, Vertex AI, Gemini CLI, Cursor or GitHub Copilot. Artificial Analysis now shows the id served by **1 API provider** (Google's own), and its model page is tracked as \`gemini-4-argon\`, effort **"(high)"** — the highest available setting and the only one AA measured.)* OpenCode Zen entry (`opencode/gemini-4-argon`) remains curated. Reasoning + tool calls; **Google has not documented how reasoning tokens are billed** (DataCamp via NeuralTrust).
- **Release / knowledge:** announced and launched **September 30, 2026** (Google blog; Artificial Analysis: "released September 2026", FAQ: September 30, 2026) — Google DeepMind's first proprietary model above the Flash class in over 7 months and the first Gemini with a codename instead of the Pro/Flash/Flash-Lite tiers; knowledge cutoff not disclosed.
- **IDs:** `opencode/gemini-4-argon` / `google/gemini-4-argon`.
- **Context window:** **1,000,000 tokens combined** (Artificial Analysis technical specifications: "Context window 1M", "1.0M tokens"; Google's launch post confirms a **1M-token output limit**, "up from the previous 64K tokens"). *(Second pass 2026-10-09: pass 1 recorded a **128K** curated figure that no source supports — the curated \`meta.json\` now reads "1M total (262K output; 1M via continuation)", so the curation has already moved toward the same conclusion; the **262K native per-request output cap** appears only in the curated entry and could not be traced to a Google or AA source. Google's announcement states an output limit but **no input context window**, and NeuralTrust explicitly flags the 1M-input figure as un-traceable to Google. AA explains the mechanism: **Long Decode Continuation**, a new Gemini API feature that pauses and resumes long responses, is what lets reasoning run to 1M output tokens without timeouts.)* The **GraphWalks BFS 256K–1M row (84.2%)** is now corroborated as genuine ≥1M-class long-range work, not a marketing extrapolation.
- **Modalities:** text, image and video in; text out (curated `meta.json`, matching Google's blog claims of "professional chart analysis", "details from long videos" and "a series of documents"). *(Second pass 2026-10-09 conflict: Artificial Analysis' **model-page tech spec** lists only **text and image** input, while AA's **launch article** lists **text, image, video and speech** input — both from the same measurement pass, and the model page carries no video/audio benchmark row. No non-text output on any source.)* Scored at the image/video band with audio input treated as **stated but unverified**.
- **Pricing (verified 2026-10-09):** **introductory $2.00 in / $10.00 out per 1M tokens**, i.e. a **50% launch discount off the standard $4.00 / $20.00** (Google blog footnote; AA; NeuralTrust/Fello AI). **Cached input at a 95% discount → $0.10/M discounted ($0.20/M at standard)** — up from 90% on Gemini 3.8 Flash. Blended 7:2:1 rate **$1.47/M** (AA). AA cost per Intelligence-Index task **$1.99 (#80 of 226)**, rising to **~$3.98** when the promotion ends (AA: "Google has not yet confirmed the promotion end date"). At standard rates Argon matches Claude Opus 5.5's $4/$20 and undercuts GPT-6 Astra's $10/$50. No free tier (`noFreeId: true`); model not on the Gemini Developer API public pricing table as of Oct 9.
- **Architecture:** proprietary, hosted only.

### Normalized scores (1–100)

> Derived from the raw numbers above using `model-comparison.md` v4 methodology. Overall = half-up mean of the five quality dims; Cost excluded.

- **Tool use: 90/100.** *(re-confirmed 2026-10-09, not raised.)* TB 4.0 57.4% (AA 57.1%), OSWorld 2.0 69.2%, **AutomationBench-AA #1 at 77.5–78%** and CWE-bench 68.0% are near-frontier, and the **Vals Index #1 of 41 (68.9%)** plus a **65% AA-Briefcase rubric pass rate (the highest AA records)** are new supporting evidence. It stays at the band floor because **GDPval-AA 1626 is still well under the 1750 reference**, Briefcase Elo drifted *down* (1494 → 1490) on weak analytical/presentation quality, and Terminal-Bench remains ~9 points behind the vendor's own comparison to Opus 5.5 (66.4%).
- **Reasoning: 90/100.** *(re-confirmed 2026-10-09.)* HLE 57.1%, **Index 53 (#8 of 226** — the pass-1 52.6 was BenchLM's rounded AA row), GraphWalks 99.7/84.2 and the **15.1% hallucination rate — "the lowest of any model scoring 45+ on the Intelligence Index"** (AA) — clear the high bars. CritPt 27.1%, **no GPQA row**, AA-Omniscience *accuracy* of only 49.9% (5 points below Gemini 3.1 Pro Preview) and the **partial 31-of-625 coverage** cap it; AA's own framing is "matches Astra, trails Opus 5.5 (57.6)".
- **Context window: 92/100.** *(re-scored 2026-10-09 from 88, which was held mid-band purely because the vendor window was unconfirmed.)* The window is now **verified at 1M** (AA tech specs) and Google's announcement adds an **industry-leading 1M-token output limit** (up from 64K) delivered through **Long Decode Continuation** — the single strongest long-generation spec in this registry. It is *not* the 95–100 band, because that requires a **≥98% retrieval figure at 512K+** and none exists: GraphWalks falls **99.7% @128K → 84.2% @256K–1M** and AA-LCR is 79.7%. Top of the 500K–1M band (85–94), and Google's own rival chart makes 84.2% the best long-range row against Astra (71.8) / Opus 5.5 (66.8) / Fable 5.1 (65.0). Residual caveat: Google states an output limit but never an input window, and the curated "262K output" figure is un-traceable.
- **Multimodal: 85/100.** *(re-confirmed 2026-10-09, deliberately not raised.)* Published video (LVBench 91.7, SOTA per Google) and chart (Chartography 71.6) evals plus "a series of documents" put it squarely in the +video/PDF band (75–90). AA's launch article asserts **speech input**, which would open the audio band — but AA's own **model-page tech spec for this id lists only text and image input and carries no video or audio benchmark row**, and there is no audio-input benchmark anywhere. Output remains **text-only** on every source, which floors the dimension regardless of input breadth. Held at 85 until the modality conflict is settled by a vendor spec sheet.
- **Coding: 88/100.** *(re-confirmed 2026-10-09.)* DeepSWE v1.1 **77.9% is the published state of the art** (Google) and clears the 74 frontier reference; Vibe Code Bench 91.9% is elite and the documented use cases (800K+ line C/C++→Rust migrations, libgav1 port 2.7× faster) are real-world corroboration. FrontierSWE v2 **55.0%** (Proximal's own board; pass 1 logged 55.1) trails Astra's 65.5%, **SWE-bench Pro and the AA Coding Index are still unpublished for this id**, and DataCamp records that **"no third party had reproduced Google's table at launch"** — so no move to the 90+ band.
- **Cost efficiency: 65/100.** *(re-scored 2026-10-09 from 60, which was an unverified $3/$15 placeholder.)* Verified card: **intro $2.00 in / $10.00 out per 1M** — a 50% launch discount off **standard $4.00 / $20.00** — with **cached input at 95% off ($0.10/M, $0.20 at standard)** and blended 7:2:1 **$1.47/M**. The intro rate sits just below this registry's ~$2/$12 ≈ 70 anchor; the standard rate is ~$4/$20, i.e. between the $3/$15 (60) and $5/$25 (45–50) anchors (~55). AA measures **$1.99 per Intelligence-Index task (#80 of 226)** — "60% of GPT-6 Astra (max, $3.26) for a comparable level of intelligence", rising to **~$3.98** when the promotion ends — and the saving comes from **token prices, not token use** (62k output tokens/task vs Astra's 27k; **110 M Index tokens, #76 of 226**, above the 81 M median). Two-sided: the 95% cache discount and "at least one month" intro window are genuinely favourable, while **the end date is unconfirmed, reasoning-token billing is undocumented, and there is no free tier**. Midpoint of verified intro and scheduled standard rates, weighted to the price actually in force → 65. Cost is excluded from Overall.
- **Overall Score: 89/100.** *(re-derived 2026-10-09: Tool 90 + Reasoning 90 + **Context 92** + Multimodal 85 + Coding 88 = **445 / 5 = 89.0 → 89**, up from the first pass's 88.2 → 88; the only quality-dimension change was Context (+4), absorbed almost entirely by rounding. Cost 65 is excluded.)* Best fit: high-stakes autonomous GUI/terminal work where trust matters — its 15.1% hallucination rate and prompt-injection resistance remain the standout safety story, now joined by a verified 1M context / 1M-generation window for very large migrations. **The binding constraint is not capability but access:** Argon was still a Fairwind-only, pre-general-availability model with no published GA date and no third-party reproduction of Google's table as of 2026-10-09, and the curated queue score (90.4) still sits above what the independently reproduced rows support.

**Conflicts found and how they were resolved:**

1. **128K vs "1M total / 262K output" vs 1M.** Pass 1 recorded the curated **128K**, which no source supports; the curated `meta.json` has since moved to **"1M total (262K output; 1M via continuation)"**; AA's tech spec says **1M context**; Google says **1M output**; NeuralTrust says Google gives **no input figure** and treats the 1M-input reportage as un-traceable. Scored on the convergence of AA + Google on **1M** with the 262K-output caveat recorded → **Context 88 → 92** (top of the 500K–1M band, not the ≥1M/98%-retrieval band).
2. **Modality matrix — three different answers from two vendors.** Curated meta: text/image/video in. AA model page: **text + image in**. AA launch article: **text, image, video + speech in**. Google blog: long-video, chart and multi-document understanding. Resolution: keep the **+video/PDF band (85)** and record audio input as *stated but unverified*, since no audio-input benchmark exists and output is text-only everywhere.
3. **Intelligence Index 52.6 vs 53.** BenchLM's AA row (52.6) vs the AA model page and launch article (53, #8/226). Same measurement at different rounding/snapshot; both far above the class median (26) and below the 60+ frontier reference → **Reasoning 90 unchanged**.
4. **GDPval-AA 1611 → 1626; normalized 55.6% → 56.3%.** Live Elo drift as the model pool grows; still under the 1750 band reference, so **Tool 90 holds** despite the new #1 placements on AutomationBench-AA and the Vals Index.
5. **AA Briefcase 1494 (pass 1 / AA article) vs 1490 (Oct 9 BenchLM row).** Minor leaderboard restatement; AA's decomposition (65% rubric pass — its highest — but analytical 1576 / presentation 1308) explains why the composite did not move Tool use up.
6. **FrontierSWE v2 55.1% vs 55.0%.** Proximal's board reads 55.0%; Google's own table also reads 55.0 against Astra 65.5 — the pass-1 55.1 was a stale scrape. Coding unchanged at 88.
7. **"$3/$15 standard pricing" (pass-1 placeholder) vs the real card.** Verified: **intro $2/$10 (50% off), standard $4/$20, cache 95% off ($0.10/M)**. Cost **60 → 65**, deliberately not the 70+ that the intro rate alone would earn, because the discount's end date is unconfirmed, there is no free tier, reasoning-token billing is undocumented, and AA's absolute cost/task ($1.99, #80/226) is well above the class median ($0.27).
8. **Vendor lead claims vs reproduction status.** Google's "state of the art"/"#1" rows (DeepSWE, Vals, AutomationBench, CWE-bench, LVBench, Gray Swan) are vendor-reported; DataCamp records no third-party reproduction at launch and NeuralTrust notes Opus 5.5/Fable 5.1 were separately reported as tying the same Gray Swan lead. 9. **BenchLM "Context Window: Coming soon" vs AA 1M.** BenchLM has simply not ingested the field for this id (31/625 coverage); scored on AA + Google.
