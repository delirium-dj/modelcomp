## Model card

- **Name:** Gemini 4 Argon
- **Short description:** Google DeepMind's frontier model for real-world coding, enterprise knowledge work and cyber defense — the first Gemini with a codename instead of Pro/Flash/Flash-Lite tiers, headlined by a 1M-token output limit.
- **Provider / access:** At launch (2026-09-30) limited to trusted cyber defenders via the Fairwind Program; paid API customers and Google AI Ultra subscribers follow (no date). Absent from OpenRouter/Vertex/Cursor at launch (DataCamp). Model card: `deepmind.google/models/model-cards/gemini-4-argon/`.
- **Release / knowledge:** Announced 2026-09-30; knowledge cutoff not published. Part of the U.S. government voluntary pre-release review.
- **IDs:** `google/gemini-4-argon` (no published API model ID at launch; no free Zen ID).
- **Context window:** 1,000,000-token **output** limit (up from 64,000) — the headline spec. Google does **not** state an input context window; some outlets report 1M input but NeuralTrust could not trace it to a Google source (treat input window as unconfirmed).
- **Modalities:** text + image + video in, text out; LVBench 91.7% (long video understanding); reasoning yes (High/max effort settings); tool calls yes; up to 1M-token single responses for huge code migrations.
- **Pricing (as of 2026-10-20):** $2 / 1M input, $10 / 1M output introductory; $4 / $20 standard; cached input $0.10 intro / $0.20 standard (95% cache discount). Artificial Analysis measured $1.99 cost per average task (cheapest of the frontier trio).
- **Architecture:** proprietary (closed weights); verbose — used 110M tokens to run the AA index vs an 82M median.
- **Independently measured (Artificial Analysis, `gemini-4-argon`, High variant, added 2026-11-01):** Intelligence Index v5.0 **50 — #13 of 58** (class median 37; "well above average") · Speed **82.9 tok/s, #95 of 196** ("faster than average", 81) · **Cost per Index task $7.68 — #50 of 57** at the **$4.00 / $20.00** rates AA currently lists, with a **95% cache discount** · Verbosity **110 M tokens — #41 of 57** (median 70 M; "somewhat verbose") · context **1M confirmed by AA** · **AA's input-modality table lists text and image only**. AA's characterisation: *"amongst the leading models in intelligence, but somewhat expensive … faster than average, however somewhat verbose."*
- **Pricing schedule (added 2026-11-01, BenchLM citing Google's Gemini API pricing page, effective 2026-09-30, registry updated 2026-10-29):** **$2.00 in / $10.00 out per 1M through 2026-11-30, then $4.00 / $20.00 from 2026-12-01**; cached input $0.10 → $0.20; **Batch/Flex $1.00 / $5.00 → $2.00 / $10.00**; Priority $3.60 / $18.00 → $7.20 / $36.00. Explicit caching unsupported; paid tier only (no free tier). API model ID `gemini-4-argon` is now published.

### Normalized scores (1–100)

- **Tool use: 91/100.** *(90 → 91.)* AutomationBench 51.3%, Harvey's Legal Agent 19.6% (wide lead) and CWE-bench 68.0% hold, and the important change is provenance: **CWE-bench 68.0% is now confirmed on Collinear's independent leaderboard**, and AA measures **AutomationBench-AA 77.5%** and **GDPval-AA 56.2%** — leads on workflow automation that a competitor's launch table had credited it with. Capped by **Terminal-Bench 4.0 57.4% (AA run 57.1%) trailing Opus 5.5's 66.4%**, plus two weak third-party results: **MazeBench 12%** and **ExtractBench Pro 30%**.
- **Reasoning: 91/100.** *(89 → 91 — the best-supported raise in this report.)* Now rests on independently administered evidence rather than vendor tables: **ARC-AGI-1 98.5% / ARC-AGI-2 91.3% / ARC-AGI-3 46.3% (ARC Prize)** and **FrontierMath v2 86.0% Tiers 1–3 / 78.0% Tier 4 (Epoch AI)** are exceptional abstract-reasoning and mathematics results, AA's **Omniscience hallucination rate of 4.3%** is the lowest in the leading set, and **CritPt 27.1%** and **AA Index 50 (#13/58)** confirm it survived the v5 rebasketing intact. Held below 93 by **middling factual recall (Omniscience accuracy 48.3%)**, **HLE 57.1% vs Opus 5.5's 61.4%**, and **no GPQA Diamond row anywhere**.
- **Context window: 98/100.** *(97 → 98.)* The draft's only stated cap was "the input window is officially unstated" — **AA now lists a 1M-token context window**, closing it. Retention is corroborated independently at **AA-LCR 79.7%** and on the vendor's own degradation curve (GraphWalks BFS **99.7% at 128K → 84.2% at 256K–1M**, still the best tracked). Not 100: the long-context rows are still Google-run and the headline **1M-token output** claim remains unverified by any tracker.
- **Multimodal: 91/100.** *(92 → 91.)* The draft's cap ("no broad image-in benchmark") is **lifted — Chartography 71.6% (no tools) exists now**, a respectable but not leading vision result, alongside LVBench 91.7%. Against that, **AA's spec table records input as text and image only, with no video** — so the video modality that justified the 92 is **vendor-claimed and tracker-unsupported**. Scored as a strong vision model with one unconfirmed modality, not the 92 the capability list implied.
- **Coding: 88/100.** *(92 → 88 — the material adverse revision.)* DeepSWE v1.1 **77.9% remains a Google number with no independent reproduction** (BenchLM's row cites Google's own methodology page), and while **FrontierSWE v2 55.0% is confirmed on Proximal's leaderboard**, that confirmation *also confirms it is 10.5 points behind Astra*. The decisive new fact is **FrontierCode 2.0 at 26.3% on Cognition's independent run** — inside AA's own v5 basket — against **AA-SciCode 61.8%** (mid) and **PostTrainBench 45.3%**. Argon is a first-rate *document-and-analysis* coder whose repo-agent performance does not match its vendor headline.
- **Cost efficiency: 64/100.** *(90 → 64 — the largest single revision in this report, and it is a date problem, not a measurement dispute.)* The draft's 90 rested on the **introductory $2/$10** pricing and AA's then-measured **$1.99 per task ("cheapest of the frontier trio")**. Google's published schedule moves to **$4/$20 on 2026-12-01 (30 days away)** — cached input to $0.20, Batch/Flex to $2/$10, Priority to $7.20/$36 — and **AA has already re-costed the model at $7.68 per Intelligence Index task, #50 of 57**, i.e. worse than GPT-6 Astra's $6.24 and only ahead of Claude Opus 5.5's $10.04. The 95% cache discount and 1M-output batching economics still make it competitive for long-document pipelines, and Batch pricing ($1/$5 today, $2/$10 after) is a genuine escape hatch. **Not counted in the Overall mean.**
- **Overall Score: 92/100.** *(unchanged at 92, but materially re-shaped.)* Mean of Tool 91 + Reasoning 91 + Context 98 + Multimodal 91 + Coding 88 = 91.8 → 92. The draft got the *level* right and the *reasons* wrong: it scored high on a vendor table nobody had reproduced, and independent measurement rewards it on **reasoning and long context** (ARC, FrontierMath, AA-LCR, Omniscience) while correcting it on **coding** (FrontierCode 2.0 26.3%) and leaving a modality claim unsupported. Best fit: **long, document-heavy legal/finance/analysis agents at 1M-window scale where low confabulation matters** — where its verified strengths live. Not the pick for **repo-agent coding** (Opus 5.5 / Astra lead independently) or for **cost-sensitive pipelines priced beyond 2026-11-30**, where the standard-rate step-up lands.
