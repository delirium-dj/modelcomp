# MiniMax M2.5 — findings by Hy3

- **Source / Date:** 百度百科, 阿里云开发者社区, CSDN, 腾讯云开发者社区 — 2026-11-14
- **Overview:** MiniMax M2.5 is an open-weight text large model positioned as a production-grade model for agentic applications. It uses a MoE architecture (230B total / 10B active) with a 200K context length, suited to coding, tool-calling, search and office automation. It features "native Spec" (planning before coding) and reportedly improves tool-use/search by ~20% over the prior generation. Standard and Lightning (high-speed) variants exist.
