# Gemini 3.8 Flash — Model Evaluation

- **Research Date:** 2026-10-20
- **Researcher:** Gemini 3.8 Flash
- **Model Name:** Gemini 3.8 Flash (Google DeepMind)
- **Model Type:** Frontier agentic multimodal speed-tier foundation model

---

### Executive Summary

Gemini 3.8 Flash is Google DeepMind's flagship speed and agentic reasoning model released on September 2, 2026, engineered as the pinnacle of the Gemini 3 Flash family. Designed specifically for autonomous software development loops, multi-agent orchestration, complex command-line interaction, and real-time omnimodal reasoning, Gemini 3.8 Flash pairs near-zero latency with frontier-grade reasoning fidelity.

Operating across a native 1,048,576-token (1M) context window with up to 65,536 output tokens, Gemini 3.8 Flash achieves **89.4%–90.8% on Terminal-Bench 2.1**, **73.7% on DeepSWE v1.1**, **61.6% on SWE-bench Pro**, and an Artificial Analysis Intelligence Index of 59. Offered at promotional pricing of $0.75 per million input tokens and $3.75 per million output tokens (with prompt caching discounts down to $0.075/1M), it represents the primary workhorse across developer tools like Antigravity, Google AI Studio, and production autonomous agents.

### Key Strengths

1. **Terminal-Bench Leadership:** 89.4%–90.8% on Terminal-Bench 2.1 demonstrates unmatched terminal command execution and shell scripting capability.
2. **Deep Software Engineering:** 73.7% on DeepSWE v1.1 and 61.6% on SWE-bench Pro rival heavy frontier models on multi-file refactoring.
3. **1M Native Context Window:** Handles large-scale application workspaces and extensive multi-turn agent telemetry in a single prompt.
4. **Accessible Economics:** $0.75 / $3.75 per 1M tokens with $0.075/1M prompt caching enables continuous, cost-effective autonomous development loops.

---

### Trade-offs & Limitations

1. **Promotional Window:** Introductory rates ($0.75/$3.75) are scheduled to adjust to standard $1.50/$7.50 rates after the promotional period.
2. **Audio Streaming Fees:** Native streaming audio inputs carry separate usage fees requiring prompt caching for audio-heavy pipelines.
3. **Theoretical Proof Depth:** While elite on software and engineering tasks, extreme mathematical Olympiad proofs benefit from specialized heavy models like Gemini 3.1 Pro.
