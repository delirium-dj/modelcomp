## Model card

- **Name:** Gemini 3.8 Flash
- **Short description:** Google's most intelligent Flash-tier "workhorse" model — best reasoning and coding of the Flash line at the same speed and introductory price as 3.7 Flash, built for long-horizon coding and autonomous agents. Distinct from the cybersecurity-tuned `gemini-3.8-flash-cyber` (separate folder); both share the same foundational intelligence.
- **Provider / access:** Gemini API (Google AI Studio, Android Studio), Google Antigravity, Stitch, Gemini Enterprise; consumers via Google AI Pro/Ultra. OpenRouter `google/gemini-3.8-flash`.
- **Release / knowledge:** Released 2026-09-02 (third Flash release in six weeks, three weeks after 3.7 Flash); knowledge cutoff not published.
- **IDs:** `google/gemini-3.8-flash` (no free Zen ID confirmed; introductory price expires 2026-12-31).
- **Context window:** 1,000,000 tokens (Gemini 3.x Flash-line API standard; not restated in the launch post — treat as provisional for this exact SKU).
- **Modalities:** text + image (+ audio/video in per Gemini line) in, text out; reasoning yes (variable effort levels, "works harder" at higher effort); tool calls yes (iterative tool calling); image-gen via Nano Banana companion, not native text-out image.
- **Pricing (as of 2026-10-20):** $0.75 / 1M input, $3.75 / 1M output (introductory; same as 3.7 Flash, expires 2026-12-31).
- **Architecture:** proprietary (closed weights); accelerated by long-running agentic loops that recursively evaluate and refine the model.
- **Independently measured (Artificial Analysis, `gemini-3-8-flash`, High effort, added 2026-11-01):** Intelligence Index v5.0 **31 — #38 of 58** (class median 37; AA: *"below average in intelligence"*; BenchLM records the same cell as **30.6%**) · Speed **120.3 tok/s, #44 of 196** ("notably fast", median 81) · **Cost per Index task $7.77 — #52 of 57** at **$0.75 in / $3.75 out per 1M with a 90% cache discount** · Verbosity **130 M tokens — #47 of 57** ("very verbose", median 70 M) · **input modality text, image, speech and video**, output text, reasoning **Yes**, **context 1M**. AA's summary: *"below average in intelligence, but well priced when comparing to other models of similar price. It's also notably fast, however very verbose."*

### Normalized scores (1–100)

- **Tool use: 85/100.** *(88 → 85 — now measured rather than inferred.)* The draft's 88 rested on chart-only claims; the numbers are in and they cut both ways. **Terminal-Bench 2.1 is elite and triple-sourced (89.4% card / 87.6% AA / 81.3% Vals)**, with **AA AutomationBench 59.9%**, **Tau3-Banking 44.9%**, **ITBench 52.5%** and **GDPval-AA 1545 Elo** as respectable mid-field agent results. Cut because **Terminal-Bench 4.0 is 19.7% (AA) against the model card's own 19.1%** — vendor and tracker agree that the current-generation terminal harness is where this model falls off — plus **AA Agentic Index 41.1%**, **GDP.pdf 21.0%**, **AA Briefcase 1202 Elo**, **ApprenticeBench 24%** and **MazeBench 4%**.
- **Reasoning: 88/100.** *(89 → 88.)* Genuinely excellent in the skills axis for a Flash-tier model: **GPQA Diamond 95.3% (AA) / 94.4% (Vals)**, **ARC-AGI-1 98.5% / ARC-AGI-2 89.2% (ARC Prize, independent)**, **FrontierMath v2 68.4% Tiers 1–3**, **MMLU-Pro 90.2%**, HLE 54.9% card / 47.8% AA. Held down by **AA-Omniscience: 55.1% hallucination rate against 50.5% accuracy (Index 23.3%)** — the worst honesty profile measured in this batch, and a decisive problem for autonomous use — plus **CritPt 18.3%**, **MLCR-AA 10.6%** and **FrontierMath Tier 4 collapsing to 22.0%**.
- **Context window: 95/100.** *Unchanged, now better evidenced.* The 1M window is **AA-confirmed** (the draft hedged it as "provisional for this exact SKU"). Supporting measurements split: **AA-LCR 81.3%** strong, **MLCR-AA 10.6%** weak, and Google still publishes no MRCR/RULER figure for this SKU — the multi-document retrieval result is what keeps it from rising.
- **Multimodal: 94/100.** *(90 → 94.)* The draft's stated cap — "no vision-specific benchmark reported" — is **gone**: **AA-MMMP-Pro 85.6%** is an independent, leading-tier result, joined by CharXiv 86.2% and LVBench 87.1%, and **AA's spec table confirms text + image + speech + video input** (the same confirmation that rescued Gemini 3.1 Pro's profile). Not higher: native image *generation* is still external (Nano Banana), and there is no audio-specific score anywhere.
- **Coding: 89/100.** *(90 → 89.)* Substantially better evidenced at the same level: **DeepSWE 73.8% on DataCurve's public board** (the draft's provisional chart claim, now real), **SWE-bench 80.0%** and **LiveCodeBench 89.5%** (both Vals AI), **AA Coding Index 76.3%**, **CursorBench 3.2 69.2%**. Offsetting: **FrontierSWE v2 19.6% (Proximal)** against Argon 55.0% / Astra 65.5%, **CursorBench 4.0 39.6%**, **AA-SciCode 56.6%**, **Bug Hunt Bench 18.0 fixes**. A very strong algorithmic and single-repo coder that does not scale to current-generation long-horizon engineering.
- **Cost efficiency: 76/100.** *(92 → 76 — the report's sharpest reversal, and a measurement effect, not a price change.)* The draft scored the **list price** ($0.75/$3.75 — genuinely the cheapest in this batch, and AA agrees: "competitively priced", medians $2/$10). **AA's per-task measurement says something different: $7.77 per Intelligence Index task, #52 of 57**, because the model emits **130 M tokens on the Index run vs a 70 M median** — it is "very verbose" and burns agent-loop tokens. Practical reading: cheap for short, bounded calls; near the worst in its comparison class for long-horizon agentic work, which is the exact workload it was marketed for. Add the **introductory expiry (2026-12-31)** and the fact that its AA composite is below-median, and value-per-task is not the story the per-token price suggests. **Not counted in the Overall mean.**
- **Overall Score: 90/100.** *Unchanged at 90 — mean of Tool 85 + Reasoning 88 + Context 95 + Multimodal 94 + Coding 89 = 90.2 → 90.* The level survived; the reason for it changed. This is now characterised as a **sharp bimodal model**: world-class on *knowledge, vision and single-repo/legacy-generation terminal work* (GPQA 95.3%, MMMU-Pro 85.6%, ARC-AGI-2 89.2%, Terminal-Bench 2.1 87.6%, DeepSWE 73.8%), and poor on *current-generation long-horizon engineering and honesty* (Terminal-Bench 4.0 19.7%, FrontierSWE v2 19.6%, Omniscience hallucination 55.1%, AA Index 31 at #38/58). Best fit: **multimodal document/extractive work, competition-style coding, and high-volume short-horizon agent calls where per-token price dominates**. Not fit for: unsupervised multi-hour engineering, or any pipeline that must trust its factual claims without verification. Note AA's "below average in intelligence" composite (#38/58) — the corpus's 90-level standing is carried by specific axes, not by general capability.
