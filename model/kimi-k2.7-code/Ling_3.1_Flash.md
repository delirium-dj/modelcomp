## Model card

- **Name:** Kimi K2.7 Code
- **Short description:** Moonshot AI's open-source, coding-focused agentic model built on Kimi K2.6 — stronger long-horizon coding and agentic execution with ~30% less thinking-token usage; thinking is forced on (instant mode not supported).
- **Provider / access:** Moonshot AI — pay-per-token API at platform.moonshot.ai (OpenAI/Anthropic-compatible, base `https://api.moonshot.ai/v1`, model id `kimi-k2.7-code`); Kimi Code subscription (`kimi-for-coding`, 7-day quota); open weights on Hugging Face / ModelScope under a Modified MIT license (code and weights); also on Azure (Microsoft Foundry, Global Standard).
- **Release / knowledge:** 2026-06-13. Knowledge cutoff not stated in captured sources.
- **IDs:** `opencode/kimi-k2.7-code` (repo meta.json, stale stub); `kimi-k2.7-code` / `kimi-k2.7-code-highspeed` (Moonshot API); `kimi-for-coding` (Kimi Code subscription); `moonshotai/Kimi-K2.7-Code` (HF).
- **Context window:** 262,144 tokens (256K native per model card; vendor evals ran at 262,144 via Kimi Code CLI).
- **Modalities:** Text, image, video in (video input experimental, official API only); text out. 400M-param MoonViT vision encoder. Forced thinking with `preserve_thinking` always on; interleaved thinking and multi-step tool calls.
- **Pricing (as of 2026-10):** $0.95 input / $4.00 output per 1M, cache hit $0.19 — same headline rate as Kimi K2.6; Highspeed tier $1.90 / $8.00 (cache $0.38, ~180 tok/s, up to ~260 short-run); Azure Global Standard $0.95 / $4.00 / $0.19.
- **Architecture:** Sparse MoE — 1T total / 32B active, 61 layers (1 dense), 384 experts (8 selected per token + 1 shared), MLA attention, SwiGLU, 160K vocabulary; native INT4 quantization (same method as Kimi K2-Thinking); 29 quantized variants listed on HF.

### Raw benchmarks found

Vendor card (Kimi K2.7 Code and K2.6 tested via Kimi Code CLI, thinking enabled, temperature 1.0, top-p 0.95, 262,144-token context; GPT-5.5 in Codex xhigh; Claude Opus 4.8 in Claude Code xhigh):

Coding:

- Kimi Code Bench v2 (in-house; 10+ languages, full production tech stack): **62.0%** (K2.6: 50.9%; GPT-5.5: 69.0%; Opus 4.8: 67.4%).
- Program Bench (recreate program behavior from compiled binary + docs only; 200 tasks, 248K+ fuzz tests, no internet): **53.6%** (K2.6: 48.3%; GPT-5.5: 69.1%; Opus 4.8: 63.8%).
- MLS Bench Lite (official 30-task MLS-Bench subset; 5-hour exploration budget): **35.1%** (K2.6: 26.7%; GPT-5.5: 35.5%; Opus 4.8: 42.8%).

Agentic / tool use:

- Kimi Claw 24/7 Bench (in-house; 17 scenarios, 610 evaluation points, OpenClaw harness, avg of 3 runs): **46.9%** (K2.6: 42.9%; GPT-5.5: 52.8%; Opus 4.8: 50.4%).
- MCP Atlas (Scale; official config, 100 tool-call budget, 32K max tokens/step, avg of 3 runs): **76.0%** (K2.6: 69.4%; GPT-5.5: 79.4%; Opus 4.8: 81.3%).
- MCP Mark Verified (human-verified MCPMark: Notion, GitHub, Filesystem, Postgres, Playwright; 100-step budget, 32K max tokens/step, avg of 3 runs): **81.1%** (K2.6: 72.8%; GPT-5.5: 92.9%; Opus 4.8: 76.4%).
- τ²-Bench Telecom: **90.1%** (theresanaiforthat.com, third-party verified, 2026-06-12) — the strongest independent agentic read; Android Bench: **70.4%** (63.4–77.1 range, 31.8h, $48.1/task, BenchmarkList); APEX-Accounting: **37.0%** (unverified); VITA-Bench: **46.6%** (benchgap est); CursorBench 3.1/3.2: **49.7%** (0th percentile — last of 15/17 ranked); GDPval-AA: **Elo 1,187** (BenchmarkList, rank 74/352, 79th pct; field leader GPT-5.6 Sol 1,861).

Independent / third-party (Artificial Analysis via aggregator listings; not vendor-confirmed for K2.7 Code):

- GPQA Diamond (thinking, no tools): **89.6%** (AA; benchgap est 89.3%). HLE (thinking, no tools, text-only): **35.0%** (AA) / **32.8%** (theresanaiforthat.com, verified) / **42.1%** (benchgap est) / **45.3%** (benchgap est, w/ tools) — kept as a conflict cluster, not averaged. AA Intelligence Index: **25.8–26** (#24/117, median 18 for similar open-weight size; 120M tokens per Index run — concise vs the 140M median); AA Omniscience accuracy 39.6% / hallucination rate 82.4% / Omniscience Index −10.2.
- AA-LCR: **79.3%** (benchgap, measured) and **79%** (AA's own K2.7-Code-vs-K2.6 comparison) vs **66.3%** (theresanaiforthat.com, third-party verified) — conflict leans ~79% on two-of-three reads. IFBench: **63.1%** (verified) / 64.7% (est); IFEval: **92.8%** (est, high confidence); Math (theresanaiforthat.com normalized): 61.2; BrowseComp: **79.5%** (est).
- Terminal-Bench: **44.7%** (Terminal-Bench Hard, verified); Terminal-Bench 2.1: **67.04%** (Vals, measured — Vals' #1 open-weight model on TB 2.1) vs **72.7%** (BenchmarkList, rank 7/7 — last of the seven ranked models) vs **82.6%** (benchgap est, ±6.9pp) — three-way conflict kept; LiveCodeBench: **82.05%** ±1.07 (Vals, measured — #8 among open-weight models) / **82.0%** (BenchmarkList, rank 48/123) / **86.8%** (benchgap est, low confidence).
- SWE-bench Verified: **78.20%** ±1.85 (Vals, measured 2026-06-13 — the #1 open-weight model on SWE-bench Verified, matching Claude Opus 4.6 (Thinking) and GPT-5.4 (xhigh), narrowly edging GPT-5.3 Codex); **78.2%** (BenchmarkList, rank 18/72, 76th pct); SWE-bench Multilingual: **73.5%** (rank 26/49); Vibe Code Bench v1.1: **47.21%** (#3 among open-weight models, rank 30/75); Code Migration: **25.4%** (rank 20/33); FrontierCode: **30.1%** (rank 24/36); DeepSWE 1.1: **30.5%** (rank 46/52 — vs K2.6's 24%, tied with GPT-5.4-mini, per the VentureBeat exchange); KernelBench Hard: **6.5%/5.2%** (two configs); KernelBench Mega: **2.59**; ReactBench: **20.5%**; Arena AI WebDev Arena: **1473** (rank 42/105).
- Hugging Face eval results: WildClawBench overall **46.9** (avg time 674 s); Long-Horizon Terminal Bench (LHTB) listed, value not captured.
- Other aggregators: SciCode **47.8%**, CritPt **10.0%**, DeepSWE **31.0%** (LLMLearner); SWE-Bench **78.2%**, AIME 2025 **91.5%**, HumanEval **94.2%**, GPQA **65.8%** (full 448-question set), HLE **38.2%** (automatio — conflicts with AA's Diamond/no-tools figures; treat as unverified).
- SemiAnalysis: Moonshot published the broader public suites (SWE-bench Verified, LiveCodeBench, AIME, HMMT, GPQA, MMLU-Pro) for K2.6/K2.5 but did not re-run them for K2.7 Code (K2.6 baselines: HLE-Full w/tools 54.0%, no tools 34.7%; AIME 2026 96.4%; GPQA Diamond 90.5%).
- VentureBeat (2026-06-12): all three headline gains are on Moonshot's proprietary suites; K2.7 Code was not submitted to DeepSWE at launch (K2.6: 24%, tied with GPT-5.4-mini); researcher Elliot Arledge's KernelBench-Hard run (full logs at kernelbench.com): "K2.7 is more honest but not more capable" — on 5/6 problems K2.7-Code produced real authored Triton kernels where K2.6 used library wrappers, two kernels failed on the model's own bugs, and the MoE kernel regressed from K2.6's 0.222 to 0.157; "Fable tops every cell it doesn't honestly fail."
- Awesome Agents (2026-06-13): thinking mode can't be disabled (token overhead on simple tasks); sampling locked server-side (temperature 1.0, top_p 0.95, no override); 595 GB disk requirement limits self-hosting to well-resourced teams; trails GPT-5.5 by 4–17 points across the agentic benchmarks.
- AA head-to-head (K2.7 Code vs K2.6 Reasoning): Intelligence Index **26 vs 27** (K2.6 marginally ahead); AA-Briefcase v1.1 859 vs 820; GDPval-AA v2.1 1,037 vs 1,038; AutomationBench-AA **24%** vs 13%; SciCode 48% vs 52%; HLE 35% vs 37%; AA-Omniscience −10 vs +5; AA-LCR 79% vs 81%; cost per task **$0.54 vs $0.80**; cost to run the Index $993 vs $1,528; output tokens/task 30k vs 47k; reasoning tokens/task **19k vs 37k** (~49% fewer — the 30%-reduction claim is conservative); 65 vs 42 tok/s; time to first answer 37.05s vs 108.48s; time per task 445s vs 1,002s.
- Practitioner ecosystem (pureailabs, 2026-06-16): 200–300 sequential tool calls in a single agentic workflow (a higher ceiling than most competitors at this price); recurring verbosity complaints ("ask it a yes/no question and it writes three paragraphs"); reported 75–90% API-spend reductions vs GPT-5.2-class backends; ~1/8 the cost of Claude.
- Third-round fills (2026-10-12): SWE-bench Pro **54.8%** (benchgap est, high conf); BFCL v4 **73.8%** (est, high conf); AutomationBench **28.4%** (est); JobBench **46.4%** (est); CyberGym **62.8%** (est); DeepSearchQA **85.8%** (est, high conf); MMLU-Pro **86.8%** (Vals est, high conf); GPQA Diamond **88.0%** (Vals est); BioMysteryBench 40.7% (est). sdd.sh/ChatForest launch reviews (2026-06-13/14): "30% fewer thinking tokens, 100% proprietary benchmarks" — at launch no independent results existed on any publicly audited leaderboard; SWE-bench Verified itself is saturating (59% of tasks flagged flawed; OpenAI retired it over contamination concerns), making SWE-bench Pro and DeepSWE the more discriminating signals.
- Multimodal benchmarks (MMMU, MathVision, VideoMME), SWE-bench Verified (official), GPQA/HLE vendor-run: no verified public score found.

- **Reasoning: 69/100.** GPQA Diamond 89.6% (AA, no tools) is frontier-tier and the AA Intelligence Index of 25.8–26 (#24/117) is a solid open-weight composite, but HLE 32.8–35.0% (verified reads) trails the 40%+ frontier band; SciCode 47.8%, IFBench 63.1% and the AA-LCR conflict (79.3% benchgap + 79% AA vs 66.3% verified — leans ~79%) temper the score; AIME 2025 91.5% is aggregator-sourced, not vendor-run. Revised 68→69 on the AA Index/IFBench fills.
- **Context window: 75/100.** 262,144-token native context; the retrieval figures conflict — AA-LCR 79.3% (benchgap, measured) and 79% (AA's own comparison) vs 66.3% (theresanaiforthat.com, third-party verified) — two-of-three reads at ~79% lift the score to the top of the 262K band. Revised 74→75 on the AA head-to-head read.
- **Multimodal: 75/100.** Native text/image/video input via a 400M MoonViT encoder (video experimental, official API only); no public multimodal benchmark scores for this checkpoint.
- **Coding: 73/100.** SWE-bench Verified 78.20% ±1.85 (Vals-measured, #1 open-weight; 78.2% BenchmarkList rank 18/72), SWE-bench Multilingual 73.5%, LiveCodeBench 82.05% ±1.07 (Vals-measured) and Terminal-Bench 2.1 67.04–72.7% (Vals/BenchmarkList measured cluster) are strong independent fills, and DeepSWE 1.1 30.5% answers the launch-period challenge (K2.6: 24%); Kimi Code Bench v2 62.0%, Program Bench 53.6% and MLS Bench Lite 35.1% trail GPT-5.5 and Opus 4.8, and KernelBench Hard 5.2–6.5%, ReactBench 20.5%, Code Migration 25.4%, FrontierCode 30.1%, DeepSWE 30.5%, Vibe Code 47.2% and CursorBench 49.7% (last place) hold the score down. Revised 70→73 on the SWE-bench Verified/Multilingual and LiveCodeBench fills.
- **Cost efficiency: 90/100.** $0.95/$4.00 per 1M hosted (below the $1.25/$4.25 frontier-adjacent anchor; BenchmarkList lists a $0.74/$3.50 provider variant — price variance noted, not averaged) with $0.19 cache hits and ~30% fewer thinking tokens; open Modified MIT weights make self-hosting a zero-license-cost option for steady volume (595 GB disk requirement). Stands at 90.
- **Overall Score: 73.2/100.** Mean of the five quality dimensions (74+69+75+75+73)/5 = 73.2. Revised from 71.6 on the Tool (+3), Reasoning (+1), Coding (+3) and Context (+1) fills; third-party figures remain partially conflicting (AA-LCR, HLE, Terminal-Bench 2.1) and are documented as clusters, not averaged; the vendor card covers only coding and agentic suites.
