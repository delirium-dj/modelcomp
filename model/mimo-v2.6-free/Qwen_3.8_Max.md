## Model card

- **Name:** MiMo V2.6 Free
- **Short description:** **Xiaomi's open-weight MiMo-V2.6-Flash served through OpenCode Zen's $0 free tier.** It is the *same* 309B-total / 15B-active sparse-MoE omnimodal reasoning model as `mimo-v2.6-flash`, delivered at **zero dollar cost** — the standout is *"a verified-software-engineering beast behind a zero-dollar meter … punching at frontier weight."* The family flagship **MiMo-V2.6-Pro scores 46.32 on the Artificial Analysis Intelligence Index**, which Xiaomi frames as **"surpassing Kimi K3 and Qwen3.8 Max to become the strongest open-source"** model — though on the current (v4.3) AA basket that 46.32 still sits **below the closed frontier** (Muse Spark 1.3 48, GPT-6 Sol 48, Astra 53, Muse Wonder 52/Full 56, Opus 5.5 58, Gemini 3.8 Flash 59), and the Flash tier this slug serves is below the Pro. Flash-level coding is elite (**SWE-bench Verified 92.0%**). The defining trade-off of *this* SKU: the **free lane is capped at ~200K context / 32K output** (the underlying model supports 1M/128K on paid Xiaomi hosts), so long-horizon work must fit the window or move to a paid tier ($0.14/$0.28 fallback).
- **Provider / access:** **Xiaomi MiMo** (open weights on Hugging Face) served **free via OpenCode Zen's $0 tier**; also on the Xiaomi MiMo Open Platform API and OpenRouter. **Free tier $0 in/out**, **paid fallback $0.14/$0.28 per 1M**. Open-weight download requires accepting the **Xiaomi Community License** (meta.json lists MIT). Listed here as `opencode/mimo-v2-6-free`.
- **Release / knowledge:** MiMo-V2.6 series released **2026-09-21/22**. Knowledge cutoff not stated in the sources reviewed.
- **IDs:** `mimo-v2.6-free` / `opencode/mimo-v2-6-free` (same model as `mimo-v2.6-flash`; family: Distill-Qwen-9B < **Flash** [this] < Pro [1.02T/42B-active] < Pro-RL).
- **Context window:** **Free Zen lane: ~200,000 (200K) tokens / 32,000 (32K) max output** (capped). The **underlying MiMo-V2.6-Flash model supports 1,048,576 (1M) / 128K output** on paid Xiaomi hosts — but *this free SKU* is delivered at the capped 200K/32K, which is the honest context reality for this slug and the reason long-horizon runs must fit the window or upgrade.
- **Modalities:** **Text, image, video, audio in → text out** (omnimodal input; text-only output). "Visual coding" is a named capability of the series. ⚠ Documented weakness: performance **degrades in non-Latin scripts** (Japanese/Arabic), with higher hallucination on non-English technical documentation.
- **Pricing (as of 2026-10-23):** **Free tier $0 in/out** (OpenCode Zen); **paid fallback $0.14 / $0.28 per 1M in/out** — among the cheapest frontier-weight coding available. Self-hosting shifts cost to fixed GPU overhead (the 309B/15B Flash needs substantial VRAM; the Pro needs an HGX cluster).
- **Architecture:** **Sparse Mixture-of-Experts**, ~**309B total / 15B active** (Flash tier; the Pro is 1.02T/42B-active), **RL-tuned** for high-efficiency reasoning ("maximize logic throughput per parameter"), open-weight. Allocates heavy compute to internal chain-of-thought, so it excels at multi-step deduction but has higher latency than managed commodity models (Pro measured 3.5s median vs GPT-5.4-mini's 0.7s on an internal automation task).

> Provenance: The **AA Intelligence Index 46.32 (Pro)** is an **independent Artificial Analysis** figure quoted by Xiaomi's launch page (2026-09-22) — but it is for the **Pro**, not the Flash this slug serves, and **AA Index scores are version/basket-specific and not convertible across baskets**, so I use it only as a relative anchor (strongest open-source; below the closed v4.3 frontier), never as a Flash score. **SWE-bench Verified 92.0% and the modality/context/pricing specs are vendor/aggregator-reported** (Xiaomi MiMo pages, meta.json, activepieces) and discounted as an upper bound; no neutral harness has published a *Flash-specific* index in the sources reviewed. The activepieces internal A/B is a **single-vendor-run, small-n (3-task) latency/cost snapshot**, not a capability benchmark. This slug is documented as the **same model as `mimo-v2.6-flash`** at $0 with a capped context, so I score capability consistently with the Flash and adjust Context (free-lane cap) and Cost ($0). No benchmark was invented; where a Flash-specific absolute figure was not published I state the Pro/family result and label it as such.

### Normalized scores (1–100)

- **Tool use: 85/100.** Strong agentic tool use — the series is explicitly built for **general-purpose agent tasks, visual coding and cybersecurity**, RL-tuned for multi-step work, and MCP-frontable as an active tool user (read/write a DB or repo). The flagship Pro's **AA Index 46.32 (strongest open-source)** signals genuine agency. Held below the frontier because the Flash tier is below the Pro, the index still trails the closed frontier (48-59 on v4.3), and the tool-use evidence is largely vendor/aggregator-reported.
- **Reasoning: 83/100.** A capable open-weight reasoner — RL-scaled self-improvement, heavy chain-of-thought allocation, "maximize logic throughput per parameter," and a family flagship that Xiaomi claims beats Kimi K3 and Qwen3.8 Max on the AA Index. Capped because the **Flash is below the Pro (46.32)**, that index is itself **below the closed frontier** on the current basket, and there is a **documented non-Latin-script reasoning degradation** with higher hallucination on non-English technical docs.
- **Context window: 80/100.** Scored on the **free-lane reality: ~200K context / 32K output** — still a large, usable window, but a real cap versus the model's native **1M/128K** (available only on paid Xiaomi hosts) and below the 1M/131K leaders (87-88). The 32K output ceiling is modest for long-horizon generation. ⚠ This cap is the defining constraint of the `-free` SKU; the same model on a paid host would score ~88 here.
- **Multimodal: 82/100.** Broad **omnimodal input — text, image, video, audio → text out** — matching the multimodal leaders' modality coverage, with **"visual coding"** a named series strength. Held below 85+ because **output is text-only**, no dedicated multimodal benchmark (MMMU/MathVision) was published for the Flash, and the documented **non-Latin-script degradation** implies uneven real-world multimodal robustness.
- **Coding: 88/100.** The standout — **elite, frontier-competitive coding at open weight**: **SWE-bench Verified 92.0%** (in the same band as Kimi K3-Max 93.2% and Ember-1 92.2%), plus named strengths in coding, visual coding and cybersecurity, and RL-tuned multi-step engineering depth. Discounted from the low-90s because the figure is **vendor-reported without a neutral-harness Flash replication**, the Flash sits below the Pro, and coding-agent rows beyond SWE-bench Verified were not independently transcribed.
- **Cost efficiency: 97/100.** The entire point of this SKU — **$0 in/out on the OpenCode Zen free tier** with a **$0.14/$0.28** paid fallback, i.e. near-free access to a frontier-weight (309B/15B) omnimodal coder with SWE-bench Verified 92.0%. Essentially the cheapest elite-coding access in the dataset (cheaper per token than qwen-3.8-flash's $0.16/$0.47). Minor caveats: the free lane is **capped (200K/32K) and rate-limited**, and self-hosting shifts cost to GPU capex. Scored but **not** counted in the Overall per methodology.
- **Overall Score: 84/100.** Mean of Tool 85 + Reasoning 83 + Context 80 + Multimodal 82 + Coding 88 = 418/5 = 83.6 → 84. Best fit: **cost-sensitive agentic-coding and visual-coding workloads** that want frontier-weight SWE-bench-Verified-class quality for **$0** and can live inside a **200K/32K** window — hobbyists, high-volume pipelines, and OpenCode Zen users; long-horizon or non-Latin-heavy work should move to the paid Flash (1M/128K) or the Pro. Independent read: my **84 sits below the queue's curated 86.7** — the gap is driven by the **free-lane context cap (200K/32K → Context 80)**, the **Flash-below-Pro / open-source-below-closed-frontier** AA-Index reality, the **vendor-reported** coding figure, and the **non-Latin-script weakness**, weighed against genuinely elite open-weight coding and the best-in-class $0 cost. Internally consistent: this lands **1 point below `mimo-v2.6-flash`** (same model, full 1M/128K context → ~85), the delta being exactly the free-tier context cap (Cost, where the free SKU wins outright, is not counted), and level with ember-1 (84) — both are elite-coding specialists whose general-composite mean is tempered by vendor-only evidence and a narrow/capped delivery.
