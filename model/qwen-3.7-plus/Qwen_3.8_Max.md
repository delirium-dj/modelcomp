## Model card

- **Name:** Qwen 3.7 Plus (Qwen3.7-Plus)
- **Short description:** **Alibaba's multimodal GUI-agent model** — the **vision/video sibling of the text-only Qwen3.7-Max flagship**, built on the same Qwen3.7 backbone and released GA **2026-06-02** (preview on leaderboards ~May 14). It is a **perception-and-action agent, not a generator**: it takes **text + image + video in → text out**, reads screens, grounds GUI elements, operates apps, and writes code from visual references (mockups/screenshots/wireframes) in a single autonomous loop. On **Alibaba's own harness** it **leads GUI-grounding** — **ScreenSpot Pro 79.0** (vs GPT-5.4's 67.4), **AndroidWorld 81.0** (vs Gemini 3.1 Pro's 70.7) and **MRCR-v2 128k long-context retrieval 91.7** (vs Claude Opus 4.6 Max's 84.0) — at **~5–6× lower price than Qwen3.7-Max**. ⚠ But the **independent signal is mid-tier**: **Artificial Analysis ranks its Intelligence Index #53/164** ("well above average for its price tier, not the absolute frontier"), **slow (~52.9 tok/s, #101)** and **very verbose (~110M output tokens vs a 29M median)**; the standout GUI numbers were measured **with reasoning disabled on Alibaba's own harness**. It is **proprietary / API-only — no open weights** (a departure from Alibaba's open-source Qwen tradition).
- **Provider / access:** **Alibaba Qwen team**. GA via **Alibaba Cloud Model Studio (DashScope) / Bailian**, OpenAI-compatible API (Beijing, Singapore, US-Virginia); also OpenRouter (**$0.32/$1.28**), AI/ML API, Together and other aggregators. Supports the **Anthropic API protocol** and integrates with **Claude Code** + third-party coding tools. Free preview via Alibaba's web chat. **No open-weight checkpoint** (`noFreeId`; no confirmed self-host roadmap). Listed here as `opencode/qwen-3.7-plus`.
- **Release / knowledge:** GA **2026-06-02**; preview variant on public leaderboards ~**2026-05-14** (#16 Vision Arena, Alibaba #5 lab in vision). The text-only **Qwen3.7-Max** predecessor launched 2026-05-21. Knowledge cutoff not stated in the sources reviewed.
- **IDs:** `qwen-3.7-plus` / `opencode/qwen-3.7-plus` / `qwen/qwen3.7-plus` (Alibaba line: Qwen3.7-Max [text-only flagship] → **Qwen3.7-Plus** [multimodal agent]).
- **Context window:** **1,000,000 (1M) tokens input / 65,536 (64K) max output**, with an internal **chain-of-thought reasoning budget of up to 256,000 tokens**. Vendor-reported **MRCR-v2 128k multi-needle retrieval = 91.7** (> Claude Opus 4.6 Max 84.0) supports the long-context claim, though it is Alibaba-harness. The **64K output cap is modest** (below the 128–131K leaders).
- **Modalities:** **Text + image + video in → text out.** A genuine **multimodal perception** model — reads screens/diagrams/scanned pages/charts, watches short clips, and acts (code, clicks, answers). Visual understanding reportedly **~75% higher than the previous-gen Plus** (internal). ⚠ **No image/video *generation*** (Alibaba has separate tools for that); no audio.
- **Pricing (as of 2026-10-23):** **$0.40 / $1.60 per 1M in/out** (≤256K input; cached **$0.04–$0.08**); **$1.20 / $4.80** for 256K–1M input; **$0.32 / $1.28** via OpenRouter/OpenCode Go. **~5–6× cheaper than Qwen3.7-Max** ($2.50/$7.50) — a decisive edge for high-volume agent loops where input tokens dominate. ⚠ Verbosity (output is the pricier side) can quietly erode the advantage without response-length constraints.
- **Architecture:** Built on the **Qwen3.7 text backbone** (same lineage as Qwen3.7-Max) with a tightly-integrated vision path; **explicit reasoning mode** with a large CoT budget. Key feature: **`preserve_thinking`** — retains the model's `<think>` reasoning blocks **across turns/tool calls** so a long-horizon agent loop doesn't reset its chain of thought after each tool result (shipped at a lower price than comparable mechanisms from other labs). Proprietary; parameter count undisclosed.

### Raw benchmarks found

GUI-grounding / agentic (**Alibaba vendor-reported**, own harness, some with reasoning disabled):

- **ScreenSpot Pro: 79.0** (GUI element grounding; vs GPT-5.4 67.4) — leads several frontier competitors on this task
- **AndroidWorld: 81.0** (mobile-app task completion; vs Gemini 3.1 Pro 70.7)
- **MRCR-v2 128k: 91.7** (long-context multi-needle retrieval; vs Claude Opus 4.6 Max 84.0)
- Leads on **Terminal-Bench-style** agentic terminal coding and **tool/MCP-server integration**; trails on **OSWorld-style desktop GUI** (at least one frontier competitor edges it)
- Demo: autonomously built an English-vocabulary app over **11 hours** (10,000+ lines, 1,000+ agent calls); recreated Apple's Stocks app from screenshots (SwiftUI + APIs + tests)

Reasoning / coding (vendor unless noted):

- **GPQA Diamond: 90.3** (Alibaba; slightly below Claude Opus 4.6 Max's 91.3) — "more mixed on pure reasoning"
- **LiveCodeBench: 89.6%** (meta.json / Alibaba)
- **SWE-bench Pro: ~57.6** (trails its own text-only sibling **Qwen3.7-Max ~60.6** by ~3 pts, and a couple of competing reasoning models)

Independent (**Artificial Analysis / LM Arena** — weighted highest):

- **AA Intelligence Index: #53 / 164** (≈ top third; "well above average for its price tier, **not at the absolute frontier**")
- **Output speed: ~52.9 tokens/sec (#101** among models tested) — comparatively slow
- **Verbosity: ~110M output tokens vs a 29M median** — substantially more than its class
- **LM Arena: mid-teens** for both text and coding, similarly placed for vision — solid, competitive, **not class-leading**

> Provenance: The **standout GUI-grounding and long-context numbers (ScreenSpot Pro 79.0, AndroidWorld 81.0, MRCR-v2 91.7), GPQA 90.3 and SWE-bench Pro ~57.6 are Alibaba vendor-reported on the company's own harness, several with reasoning disabled** — directional signals, discounted as an upper bound and flagged for independent validation before wiring into critical automation. The **independent Artificial Analysis rows (Intelligence Index #53/164, ~52.9 tok/s #101, verbosity) and LM Arena mid-teens placements** are the honest core and are weighted highest: they describe a **genuinely capable, cost-effective, somewhat slow mid-tier model — not the across-the-board leader a quick skim of the launch suggests**. Release/pricing/context/modality/`preserve_thinking`/no-open-weights from the qwen.ai blog, mlq.ai, aimlapi.com, llm-stats.com, together.ai, openrouter.ai and The Decoder/MarkTechPost/Digital Applied. The meta.json specs (GPQA 90.0% ≈ vendor 90.3; LiveCodeBench 89.6%; 1M/131K vs the more-cited 1M/64K) were **verified against coverage rather than inherited** — note the **max-output discrepancy** (meta.json says 131K; the launch materials and guides consistently say **65,536**), so I scored against 64K. **No benchmark was invented.**

### Normalized scores (1–100)

- **Tool use: 84/100.** Its designed strength — a genuine **GUI-agent** that grounds screens (**ScreenSpot Pro 79.0**, ahead of GPT-5.4's 67.4), completes mobile tasks (**AndroidWorld 81.0**), leads **Terminal-Bench-style** agentic coding and **tool/MCP-server integration**, and keeps reasoning alive across tool calls via **`preserve_thinking`** (11-hour autonomous app build). Held to 84 because these GUI numbers are **vendor-harness with reasoning disabled** (unvalidated), it **trails on OSWorld-style desktop GUI**, and the **independent AA Intelligence Index is only #53/164** — strong agentic design, mid-tier independently-measured execution.
- **Reasoning: 82/100.** **GPQA Diamond 90.3** (vendor; just below Opus 4.6 Max 91.3), **LiveCodeBench 89.6%** and a large **256K-token CoT budget** with an explicit reasoning mode. Capped by the **independent AA Intelligence Index #53/164** ("not at the absolute frontier") and coverage that it **"trails on pure reasoning tasks"** and on SWE-bench Pro vs its own text-only sibling — capable, cost-effective reasoning, but mid-tier on neutral composites.
- **Context window: 86/100.** A class-leading **1M-token input** with a **256K reasoning budget** and a strong vendor **MRCR-v2 128k = 91.7** (> Opus 4.6 Max 84.0) supporting real long-document/mixed text-image ingestion in one pass. Discounted below the 88–89 leaders because the **max output is ~64K** (meta.json's 131K could not be confirmed; launch materials say 65,536) and the retrieval figure is Alibaba-harness — same 1M/64K profile as step-5-preview (86).
- **Multimodal: 82/100.** A real **text + image + video → text** perception model with a tight vision/backbone integration (**~75% visual-understanding jump** over the prior Plus, Vision Arena #16 preview), strong **GUI/screen/diagram/mockup** reading and code-from-screenshot ability. Held at 82 (with the omnimodal muse-wonder/mimo and audio-capable inkling-small) rather than higher because there is **no generative output and no audio**, the vision benchmarks are **vendor-reported**, and **LM Arena vision is mid-teens** — a distinctive GUI/visual-agent strength, not a class-leading general-vision score.
- **Coding: 84/100.** Strong **agentic + visual coding** — **LiveCodeBench 89.6%**, code-from-screenshot/mockup, Claude Code integration, leading Terminal-Bench-style results and the 11-hour autonomous build. Discounted because **SWE-bench Pro ~57.6 trails its own text-only sibling Qwen3.7-Max (~60.6)** and a couple of competing reasoning models — i.e. you trade a little pure-text coding depth for vision/video and a ~6× lower price.
- **Cost efficiency: 90/100.** The commercial headline — **$0.40/$1.60** (cached $0.04–$0.08; **$0.32/$1.28** on OpenRouter), **~5–6× cheaper than Qwen3.7-Max** while *adding* vision/video, which makes high-volume screenshot-heavy agent loops (RPA, browser automation, long-document processing) economically viable at scale. Tempered by **verbosity** (~110M vs 29M-median output tokens — output is the pricier side, so real cost-per-task is higher than sticker), **slow throughput (~52.9 tok/s)** and **no open weights / no self-host** option. Scored but **not** counted in the Overall per methodology.
- **Overall Score: 84/100.** Mean of Tool 84 + Reasoning 82 + Context 86 + Multimodal 82 + Coding 84 = 418/5 = 83.6 → 84. Best fit: **budget-sensitive, vision-heavy agentic work** — browser/desktop/RPA automation, mobile-app QA/navigation, UI-to-code and design handoff, and long mixed text-image/document agents where the 1M window, GUI grounding, `preserve_thinking` and ~6×-lower price are decisive. **Not** the pick for pure-text SWE depth (use Qwen3.7-Max), low-latency work (it's slow), token-frugal budgets (it's verbose), self-hosting (no open weights) or absolute-frontier general intelligence. Independent read: my **84 sits ~2.3 below the queue's curated 86.3** — the gap driven by the **independent AA Intelligence Index #53/164 (mid-tier)**, the **vendor-harness / reasoning-disabled** nature of the headline GUI numbers, **slowness and verbosity**, the **modest ~64K output**, and **no open weights**, weighed against genuinely strong (if vendor-reported) GUI-grounding, a class-leading 1M window, real video perception and excellent sticker price. Internally consistent: Qwen3.7-Plus (84) clusters with the other cost-effective multimodal/agentic generalists (inkling-small, grok-4.6, ember-1, mimo-v2.6-free, minimax-m3 at 84), below the frontier computer-use GPT-5.4 (85) — an accurate portrait of a value-first visual GUI agent whose independent general-intelligence showing is mid-tier even though its own GUI benchmarks lead.
