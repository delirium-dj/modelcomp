## Model card

- **Name:** Claude Opus 5.5 (no "Free"-tier variant; paid API plus Pro/Max/Team/Enterprise subscription access — free-plan availability was not stated at launch and could not be confirmed)
- **Short description:** Anthropic's current default flagship for long-running agentic coding and knowledge work, released 2026-09-22 as the first model of the Claude 5.5 family. It is simultaneously a 20% list-price cut and a capability jump over Claude Opus 5, and Anthropic's docs now direct most workloads to it instead of the more expensive Claude Fable 5.1. Variant/alias flag: not a variant of anything — but do not confuse `claude-opus-5-5` with `claude-opus-5`; they are separate models with different prices, defaults and breaking API differences.
- **Provider / access:** Claude API (`claude-opus-5-5`, Messages API), Amazon Bedrock (`anthropic.claude-opus-5-5`), Claude Platform on AWS, Google Cloud Vertex AI and Microsoft Foundry — all from launch day. Also in the Claude apps (Pro/Max/Team/Enterprise), Claude Code and Cowork. Native surface is the Messages API, not OpenAI Chat Completions/Responses. Zero data retention is available. No OpenCode Zen `opencode/*` free ID verified.
- **Release / knowledge:** Released 2026-09-22 (about two months after Opus 5 on 2026-07-24). Reliable knowledge/training cutoff: **June 2026**. Retirement not sooner than 2027-09-22.
- **IDs:** `claude-opus-5-5` (Claude API / Vertex AI / Microsoft Foundry / Claude Platform on AWS), `anthropic.claude-opus-5-5` (Amazon Bedrock). Fixed ID, no date-suffixed snapshot. **No free-tier API ID exists.**
- **Context window:** 1,000,000 tokens input, 128,000 tokens max output on the Messages API (300,000 on the Message Batches API with the `output-300k-2026-03-24` beta header). Verified from the Claude Platform documentation spec table and corroborated by two independent write-ups. Important caveat: Claude models since Opus 4.7 use a tokenizer that produces roughly 30% more tokens for the same text, so the 1M window holds about **555k English words** rather than the ~750k an older 1M-token model would fit. Minimum cacheable prompt: 512 tokens.
- **Modalities:** Input: **text and images only**. Output: text only. Reasoning: yes — adaptive thinking is **always on and cannot be disabled** (`thinking: {"type": "disabled"}` or a manual `budget_tokens` returns 400); depth is controlled by five effort levels (`low`, `medium`, `high`, `xhigh`, `max`) with **medium as the new default** (Opus 5 defaulted to high). Tool calls: yes, with vision-driven computer use (`computer_toolset_20260801`); **forced tool use is retired** (`tool_choice: "any"` or a named tool returns 400). JSON mode / structured outputs: supported as the recommended replacement for forced tool use. No audio, video or PDF input path verified for this ID.
- **Pricing (as of 2026-10-03):** **$4 / 1M input, $20 / 1M output** (20% below Opus 5's $5/$25). Cache read **$0.20 / 1M — a 0.05x multiplier rather than the usual 0.10x**, a 60% cut versus Opus 5. 5-minute cache write $5, 1-hour cache write $8. Batch API $2 / $10. Fast mode $8 / $40 (research preview, `speed: "fast"` + `fast-mode-2026-02-01` header, up to 2.5x faster, first-party API only, no Bedrock/Vertex/Foundry, does not combine with Batch). `inference_geo: "us"` applies a 1.1x multiplier to every token category. **No long-context premium** — a 900k-token request bills at the same per-token rate as a 9k one. Anthropic claims ~40% lower cost than Opus 5 on typical workloads (list cut plus fewer tokens/steps); an independent worked example on identical token counts came out 26% cheaper.
- **Architecture:** Proprietary, closed weights. Parameter count (total/active) and MoE structure: not disclosed — no verified public figure found. Ships with Fable-5.1-class cyber and biology safety classifiers; flagged cyber requests fall back to Opus 4.8 and biology requests to Opus 5, with 2.5–3.9% of requests hitting the fallback in Anthropic's own benchmark runs.

### Raw benchmarks found

> Anthropic's figures come from system card §8 / Table 8.1.A, using adaptive thinking at **max** effort averaged over five trials, except Terminal-Bench 4.0 which was run at **xhigh**. Independent Artificial Analysis figures use AA's own harness at max effort and are labelled as such. Benchmark versions matter: Terminal-Bench is now v4.0 and OSWorld 2.0, so scores are not comparable with TB2.1 / OSWorld 1.x results elsewhere in this dataset.

Agent / tool use:

- Terminal-Bench 4.0 (**agentic coding/terminal**): **66.4%** vendor-reported at xhigh (Claude Code `--bare` mode, safeguards on, ±2.6-point standard error; 64.8% at max effort) — a new state of the art on that version, 8.5 points over GPT-6 Astra's 57.9%. **Independent Artificial Analysis run: 59.6%**, a 6.8-point trim that pulls it level with GPT-6 Astra rather than clearly ahead.
- Terminal-Bench-Science 0.1: **58.7%** (loses to GPT-6 Astra's 64.6%; roughly doubles Opus 5's 29.0%)
- Tau3-Banking / Tau2-Bench: **no verified public score found** — Anthropic explicitly did not report tau-bench for this model
- GDPval-AA v2.1 (Elo): **1846** (Fable 5.1 1735, Opus 5 1708, GPT-5.6 Sol 1588, GPT-6 Astra 1542) — over 300 Elo ahead of Astra on professional deliverables across 44 occupations
- AA-Briefcase v1.1 (Elo): **1822** (Fable 5.1 1678, Opus 5 1673) — private AA knowledge-work test
- Claw-Eval / ClawProBench: no verified public score found
- Toolathon / MCP-Atlas / SWE Atlas Codebase QnA: **Toolathlon Verified 77.8% pass@1** (system card §8); MCP-Atlas and SWE-Atlas Codebase QnA: no verified public score found
- OSWorld 2.0 (computer use): **81.8% partial credit / 48.7% strict** (Opus 5: 74.0 / 37.2; Fable 5.1: 80.7 / 42.8)
- AutomationBench (Zapier, business workflows): **40.0%** — loses to GPT-6 Astra's 41.4%; Zapier ran it without fallback models so every safeguard interruption counted as a failure, which Anthropic says depressed the score
- Tool-call efficiency (vendor-selected customer data, not independent): Kiro ~40% fewer calls and half the tokens; Optiver matched Opus 5 quality in about half the turns, time and output tokens; Deloitte caught 72% of known bugs at the lowest effort setting versus 56% for Opus 5 at high; Hebbia 86.6% coverage on finance workflows, up from 60.3%

Reasoning / knowledge:

- GPQA Diamond: **no verified public score found** — Anthropic did not publish GPQA Diamond, MMMLU, tau-bench or ARC-AGI for this model, and the ARC Prize site had no Opus 5.5 entry at launch
- HLE: **64.4% without tools, 67.7% with tools** (vendor; Fable 5.1 65.6%, Opus 5 63.6%, GPT-6 Astra 57.2% with tools). **Independent AA run: 61.4%** (GPT-6 Astra 54.7%, Fable 5.1 59.1%) — a 6.3-point gap to the vendor figure
- LCR / MLCR: no verified public score found. Closest published long-context result: **ProgramBench 91.2%** (Fable 5.1 87.6%, Opus 5 85.4%)
- CritPt: no verified public score found
- Artificial Analysis Intelligence Index / BenchLM overall: **58 (v4.3.2, max effort) — ranked #1 of 212 models**, five points ahead of GPT-6 Astra and Fable 5.1 (both 53) and seven ahead of Opus 5 (51). It leads six of the ten evaluations inside that index. Token-usage catch: ~**119k output tokens per index task** versus ~27k for GPT-6 Astra; the full index run consumed 260M output tokens and cost $8,708.20.
- Omniscience Accuracy / Hallucination Rate: no verified public score found
- Other published reasoning rows: **GMMLU (42 languages) 94.3%**; **ArXivMath (Aug 2026) 91.2% without tools, 96.9% with tools** (Fable 5.1: 82.9 / 92.1); **HealthBench Professional 65.6%** (Opus 5 59.8, Fable 5.1 62.1, GPT-6 Astra 63.4)

Coding:

- SWE-bench Verified / SWE-Pro: **SWE-bench Verified — no verified public score found and none will come from Anthropic** (replaced in its reporting by Pro / Multilingual / Multimodal; any Verified figure circulating for this model is third-party). **SWE-bench Pro 89.9%** (Opus 5 79.2, Fable 5.1 81.2 — a 10.7-point generational jump), **SWE-bench Multilingual 93.9%**, **SWE-bench Multimodal 61.4%**
- LiveCodeBench: no verified public score found
- SciCode / AA-SciCode: **66.9%** (independent Artificial Analysis; GPT-6 Astra 56.5%, Fable 5.1 63.1%)
- Vibe Code Bench: no verified public score found
- DeepSWE / Coding Index / other: **DeepSWE v1.1 74.2%** (system card §8). **FrontierCode v1.1 Main 54.4%** at max (Astra 53.3, Fable 5.1 50.3, Opus 5 48.0; the card also reports a 54.6% best result at *medium* effort, with scores dipping above medium before recovering at max). **FrontierSWE v2 62.3% — behind GPT-6 Astra's 65.5%.** **CursorBench 4.0 57.8%** at max, 56.0% at high (~$4/task), 52.5% at medium (~$3/task) — even the medium result beats Fable 5.1 at max effort (51.8% at $17.28/task); measured and reported by Cursor. **Chartography 89.0% with tools / 64.4% without** (Fable 5.1 44.8%, Opus 5 29.8% without tools — the largest single jump in the card).

Long context:

- **ProgramBench 91.2%** is the only published long-context result. **No MRCR, RULER or GraphWalks figure found at any window length** for `claude-opus-5-5`, so the 1M window has no published needle-in-a-haystack retrieval rate.

### Normalized scores (1–100)

- **Tool use: 94/100.** **GDPval-AA v2.1 at 1846 Elo** is far above the methodology's ~1750+ frontier reference and over 300 Elo clear of GPT-6 Astra, AA-Briefcase 1822 Elo corroborates it on a private harness, Terminal-Bench 4.0 is state of the art on its version (66.4% vendor / 59.6% independent), Toolathlon Verified reaches 77.8% pass@1, and OSWorld 2.0 computer use hits 81.8% partial credit. Independently confirmed customer data shows large tool-call reductions. Capped below 95+ by three real gaps: **tau-bench and Claw-Eval were never published** (the methodology's explicit missing-Claw-Eval penalty), the independent Terminal-Bench run erases the headline lead over Astra, and it **loses AutomationBench (40.0 vs 41.4) and Terminal-Bench-Science (58.7 vs 64.6)** outright. OSWorld's strict-completion rate of 48.7% also shows computer use is far from solved.
- **Reasoning: 95/100.** HLE at **64.4% without tools / 67.7% with tools** is more than 20 points above the methodology's 40%+ frontier reference and survives independent re-testing at 61.4%; the **Artificial Analysis Intelligence Index of 58 ranks #1 of 212 models**; GMMLU 94.3% across 42 languages and ArXivMath 91.2%/96.9% confirm breadth. Held at 95 rather than higher because the Index of 58 still sits **below the 60+ frontier marker**, **GPQA Diamond, MRCR/LCR and CritPt were never published**, the independent harness trims every vendor figure by 6+ points, and the #1 placement is bought with ~119k output tokens per task — four times Astra's — which is a reasoning-efficiency weakness the raw score hides.
- **Context window: 95/100.** Verified 1,000,000-token input with 128K output (300K on Batch) places it in the ≥1M tier (95–100), strengthened by there being **no long-context premium** and by cache reads at a 0.05x multiplier making repeated large prefixes genuinely affordable. It sits at the tier floor because the 100 condition (≥98% retrieval at 512K+) **cannot be verified at all** — no MRCR/RULER/GraphWalks figure exists, only ProgramBench 91.2% — and because the post-4.7 tokenizer makes this 1M window hold roughly 30% less text (~555k words) than a 1M window on older models, so the nominal number overstates usable capacity.
- **Multimodal: 70/100.** Input is **text and images only**, output is text only, which is squarely the methodology's "+image in = 60–70" band — no audio, no video and no PDF path is documented for this ID, and there is no non-text output. It takes the **top of that band** because the verified visual quality is the best in the family: Chartography 89.0% with tools and 64.4% without (against Opus 5's 29.8%, the single largest jump in the system card), SWE-bench Multimodal 61.4%, and screenshot-driven computer use at 81.8% partial credit on OSWorld 2.0. Frontier-grade vision cannot lift the score into the 75–90 band when the input surface simply does not include video, PDF or audio.
- **Coding: 96/100.** The strongest coding evidence of any model I have scored: **SWE-bench Pro 89.9%**, **SWE-bench Multilingual 93.9%**, **DeepSWE v1.1 74.2%** (at the 74%+ frontier reference), **Terminal-Bench 4.0 66.4% SOTA**, **SciCode 66.9% independently measured** (above the 55%+ reference), CursorBench 4.0 57.8% with the *medium*-effort result still beating Fable 5.1 at max for a fifth of the cost, and FrontierCode v1.1 54.4% leading the table. Three points of deduction, not more, because **SWE-bench Verified and LiveCodeBench are absent**, **FrontierSWE v2 (62.3%) loses to GPT-6 Astra (65.5%)**, SWE-bench Multimodal at 61.4% is comparatively weak, and Anthropic itself cautions that at this capability level benchmark margins no longer track real-world differences.
- **Cost efficiency: 58/100.** $4 in / $20 out is modestly worse than the $3/$15 anchor that maps to ~60, but three structural factors pull it back up: **cache reads at $0.20 / 1M (a 0.05x multiplier, 60% below Opus 5)**, Batch at $2/$10, no long-context surcharge, and a **medium default effort that already delivers most of the capability** — Deloitte caught more bugs at lowest effort than Opus 5 did at high. Against that: there is no free tier, fast mode costs $8/$40, US-pinned inference adds 10%, and the 40%-cheaper claim **fails at max effort**, where ~119k output tokens per task put cost per task back at Opus 5 levels (AA's full index run cost $8,708.20). Net: better value than its predecessor, still an expensive frontier model.
- **Overall Score: 90/100.** Mean of the five non-cost dimensions (94 + 95 + 95 + 70 + 96) / 5 = 90 — the best-fit default for long-running agentic coding, repository-scale refactors and professional knowledge-work deliverables, where SWE-bench Pro 89.9%, GDPval-AA 1846 Elo and $0.20 cache reads compound; run it at **medium** effort and only escalate deliberately, reach for GPT-6 Astra instead on agentic science or SaaS-workflow automation, and do not pick it for audio/video/PDF pipelines, latency-critical no-think calls (thinking cannot be disabled) or anything still depending on forced tool use.
