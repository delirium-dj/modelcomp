### Raw benchmarks found

> Provenance, stated plainly: **no vendor benchmark report exists** — the anonymous provider has published nothing. Every number below is **third-party measured against the exact serving ID**, from two independent harnesses with **different, non-comparable reasoning settings**, plus one qualitative evaluation. **Artificial Analysis has no page for it** (`artificialanalysis.ai/models/crouton-alpha` → 404 today), **BenchLM has none** (404), and **LMArena has no entry** — so there is **no Intelligence Index, GPQA, SWE-bench Verified or Terminal-Bench absolute** for this model, and none is invented here. Cold Iron is a 157-test suite of short pass/fail tasks, not a frontier leaderboard; its coding answers topped out at **566 tokens**, so as AI/ML API warns, "its perfect coding score says little about work on large codebases."

**1) Cold Iron (SMF Works, run 2026-11-03, `reasoning_effort: minimal`, result files on GitHub; tabulated by AI/ML API and echoed by i-scoop):**

- Overall: **140 of 157 (89.2%)** — **ranked 10th of 26** models on that board
- Coding: **30/30** · Tool calling: **2/2** · Instructions: **29/30** · Reasoning: **29/30** · Prose: **28/30** · **Math: 19/30** · Writing: **3/5**
- Run took **371.7 s** total; **median answer 2.12 s**; **none** of the 11 math misses hit the token limit
- Board context (same harness, different settings — **not** apples-to-apples): **Grok 4.6 153/157** and **Gemini 4 Argon 152/157** above; **Claude Fable 5.1 142/157** just above (only 2 tests); **MiniMax M3.1 Flash 136/157** below. Grok 4.6 and Claude Fable 5.1 ran with reasoning **off**, Crouton at **minimal** (which still permits reasoning). SMF Works notes **every higher-scoring run took ≥900 s** — Crouton got within 2 tests of Claude Fable 5.1 in a fraction of the time.
- Corroborating lineage note: **Union Alpha**, ranked 12th on the same board, was later revealed as **Pareto** (Unbiased) — Cold Iron has a track record of tracking real pre-release models.

**2) AI/ML API independent suite (2026-11-04, default effort, vs the *released* GLM 5.3 Flash and MiniMax M3.1 Flash):**

- Coding tasks passed **6/6**; **median 3.8 s/task** vs 32.6 s (GLM 5.3 Flash) and 4.7 s (MiniMax M3.1 Flash) — **fastest in the sample**
- Tool tasks **2/2**; multi-step tool-chain task completed with correct tools and data
- Long-log retrieval: found **both facts in a 3,600-line log** in **6.7 s** (vs 10.9 s GLM, 6.3 s MiniMax)
- **Tokenization efficiency:** the same log consumed **100,063 tokens** vs 139,229 / 133,450 — **25–28% fewer input tokens** than both siblings
- Multimodal: **read a chart in an image correctly**, **correctly described a time-lapse video**; **failed audio** (both formats rejected by the API)
- Effort sweep on short coding tasks: **6/6 passed at every level** (minimal 2.1 s median → xhigh 4.2 s, max 3.8 s) — no quality gain visible on short tasks, so minimal is the rational default for sub-agent work
- Speed: **114–129 tokens/s**; TTFT **1.5–1.8 s** at minimal, **8.5–9.6 s** at default effort

**3) MindStudio hands-on (2026-11-03/04, Hermes Agent + sub-agent skill):**

- Split a 3-task work order across fresh sub-agents, ran spec-review then quality-review passes, self-reported "20 passing tests, 3 clean commits" — and **the independent re-run confirmed all 20 tests passed** (self-report was accurate, not inflated)
- Sketch→web: hand-drawn kebab with messy handwriting ("spin slowly", "slices fall here") → single animated HTML file in ~3 min, **motion cues from handwriting correctly implemented**; flaws: knife misaligned, rough geometry
- Science-under-visual-noise: dense wind-tunnel poster, unguided "find the 3 most serious errors" → identified **Reynolds/Mach inconsistency between tables**, **wrong units on stall angle and CL max**, and **an invalid equation, proposing the correct one** — genuine structured-technical parsing, not OCR-level
- Weak spot: **lower-resource languages** — Kurdish translation wrong, Odia inaccurate, major languages fine

**Conflicting results I had to reconcile (throughput):** OpenRouter's own model page showed **~72 tok/s** (median, 2 s TTFT) on 11-04; Sumus recorded **~150 tok/s, 2.27 s P50** on 11-05; AI/ML API measured **114–129 tok/s** on 11-04; yet an OpenRouter **compare page** renders Crouton at **3.0 tok/s** against Pareto 26.9's 79.0. The low outliers are consistent with **peak-load degradation during the free preview** (documented ~67% availability in the first days), not a different model. I score on the **cluster of instrumented measurements (114–150 tok/s)** and treat 3.0 as a degraded-window artifact.

**4) StealthMark 1.8.10 (Stealth Models / stealthmodels.com, published on `huggingface.co/stealth-model/crouton-alpha`) — found later the same day while calibrating a sibling report:**

- **Benchmark score 48.0** · **General Intelligence 43.5** · **Visual Intelligence 56.0**; per task: **Beach 60.7, Selfie 60.0, Latch 59.5, Raccoon 57.9, Ground Truth 50.5, Mona Lisa 44.9, Newton's Mirror 35.2, Foresight 32.3**
- Their case file: first seen **3 Nov 2026**, developer "unknown, likely Meta", **1,048,576** context, input **text, images, audio, video, files**, tool calls yes, **speed in their tests ~175 tok/s**, "free preview on OpenRouter and OpenCode, blocked in Europe"
- Their identity finding is a **third independent counter-datapoint to the Meta hypothesis**, and the strongest yet: among **454 OpenRouter models**, only **Muse Wonder** and **Muse Spark 1.3** expose the same six reasoning levels — but **"its token counts match no model we know, and the Muse models agree with it on 2 of 24 phrases"**. Their stated lead is therefore "a new model from Meta", **not** a known Muse — which is exactly the position this report took ("*a* new model", unattributable), and it means **no Muse number may be imported here**
- ⚠️ **Conflict with my own audio correction, left on record rather than resolved:** Stealth Models' catalog row lists **audio input** as a modality, matching OpenRouter's catalog, while **AI/ML API's live test had both audio formats rejected**. Two catalogs agreeing is not a working measurement; the rejection stands as the only *tested* result, so Multimodal stays at 72 and audio remains flagged advertised-not-verified
- Suite meaning and calibration: StealthMark is a **hard SVG/planning/physics/design** suite (Foresight alone: 51 models, median **40.3**, top **76.1** = GPT-6 Astra). Crouton's **48.0** is **above that median**, with **Latch 59.5 / Foresight 32.3** — solid state-tracking, weak-to-mid anticipatory planning — and it slots in as **2.5× Iceman Contributor's 19.2**, ~2.5× Glyph Cluster's 18.9, and **below** the revealed MiniMax M3.1 Flash band on the same build (Space Bunny Alpha: Selfie 78.9 / Raccoon 74.3 / Beach 67.8). Their ~175 tok/s also lands inside the **114–150 tok/s instrumented cluster plus quiet-window headroom**, so the throughput reconciliation above holds. **No score on this file changed as a result** — the suite is non-agentic and adds no tool-chain, repo-scale or math signal, and its ordering agrees with the Cold Iron board this report already leans on.

**Attribution evidence — deliberately not used for scoring:** *For Meta/Muse:* identical **6-level effort setting set** as Muse Wonder and Muse Spark 1.3; identical advertised modalities/token limits and "mandatory reasoning"/"tokenizer: Other" catalog labels; a **rare Japanese word** it fails that "every Muse model fails and 93 other models get right"; a 21-country block list matching Meta's. *Against:* **AI/ML API's 23-string tokenizer test matched neither Muse model** (no comparison model matched more than 4 counts; 7 models tested), Muse models default to **medium** effort while Crouton defaults to **max**, Meta normally launches Muse in its own apps first, and **pokebench's 12-model tokenizer probe ruled out Google, Qwen, Mistral and GLM with no match at all**. Other live guesses: **Google Gemini Flash-class** (speed/1M/audio-video feel) and **Mistral** (an r/MistralAI thread, "Crouton alpha (mistral) is cooked" — uncorroborated, and the tokenizer probe explicitly *ruled out* Mistral). **OpenCode still lists it as Lab: Unknown on 2026-11-09.** Any score below is therefore measured-behavior-only; borrowing Muse Spark or Gemini numbers here would be a lineage proxy and is prohibited.

### Normalized scores (1–100)

- **Tool use: 70/100.** Measured 2/2 (Cold Iron) and 2/2 (AI/ML API) multi-step tool chains, JSON/JSON-Schema output works, and it is being consumed as a tool-execution engine at industrial scale — **#7 by tokens on OpenCode**, **2.1T tokens**, **538,527 sessions**, **40K unique users**, avg **4M tokens/session**, with Hermes Agent, Claude Code and Kilo Code the top callers. Docked hard for two real defects: **`tool_choice` only honors `auto`** (you cannot force a tool, which breaks deterministic agent harnesses) and early **~67% availability** with reports of stopping mid-response / shipping incomplete files. Two 2-task samples are thin evidence for a 70, so this leans on scale-of-adoption, not on the sample.
- **Reasoning: 76/100.** Cold Iron's abstract-reasoning subset was near-perfect (**29/30**) and instruction-following **29/30**, and the unguided wind-tunnel error detection shows it can check internal consistency across a dense document — genuinely above "worker model" expectations. The discount is **math 19/30**: **11 of its 17 total failures were math**, i.e. formal quantitative reasoning is where this model actually breaks, and the run used **minimal** effort (higher effort may close some of that gap, untested). No GPQA / HLE / AA Index exists for the ID.
- **Context window: 85/100.** **1,048,576 in / 943,718 advertised out**, and — unusually — that window is *proven under load*: 2.1T tokens served, avg 4M tokens per session, and an independent 3,600-line/100K-token retrieval pass in **6.7 s** at **25–28% fewer input tokens** than two released sibling-class models. Held below 90 because **no MRCR/RULER absolute** exists to characterize position-dependence, and OpenCode telemetry shows **0% cache-read rate**, so million-token loops re-pay full input cost once pricing returns.
- **Multimodal: 72/100.** Verified working: **image** (chart reading correct), **video** (time-lapse described correctly), **PDF/file** input, plus strong handwriting and dense-technical-figure parsing. Not a general multimodal model: **text-only output**, no image/audio generation, **audio input advertised but rejected** in independent testing, visual polish is weak (misaligned geometry), and lower-resource language accuracy drops off.
- **Coding: 78/100.** Perfect on every bounded measure available — **30/30** Cold Iron, **6/6** with the **lowest median time** in its comparison set, **20/20** unit tests independently re-verified with clean commits — which is exactly the profile of a strong agentic sub-task coder. Capped because the coding tasks were **short** (longest answer 566 tokens), so **repo-scale engineering is entirely unevidenced**: no SWE-bench Verified/Pro, no LiveCodeBench, no Terminal-Bench row exists for this ID.
- **Cost efficiency: 95/100.** The headline while it lasts: **$0 in / $0 out / $0 cache read** at **114–150 tok/s**, 25–28% leaner input tokenization than comparable models, and prompts **retained 30 days but not trained on** — the friendliest data terms of any stealth preview to date (13 of 14 earlier listings trained by default). Discounted only because **the price is temporary and unannounced for post-reveal**, and free-tier caps (20 rpm / 50 rpd) throttle real workloads.
- **Overall Score: 76.2/100.** Half-up mean of the five quality dims (70+76+85+72+78)/5 = **76.2** (Cost excluded). Best fit: **the worker slot in an agent system** — bounded coding steps, tool calls, structured extraction, and long-document/chart/video reading under a frontier planner, where it is near-perfect and remarkably fast. Avoid it as a **math/quantitative reasoner** (19/30), as a **deterministic tool-forcing harness** (`tool_choice` is auto-only), and for anything needing **audio input, generative media, or guaranteed availability**. Read this score as "strong bounded-task worker measured on a 157-test suite", **not** as a frontier-intelligence claim: it has no Intelligence Index, no SWE-bench, no Terminal-Bench row, and it beat nothing on an independent leaderboard — its Cold Iron standing (10/26, ahead of MiniMax M3.1 Flash, two tests behind Claude Fable 5.1 at a fraction of the runtime) is the only cross-model signal, measured with **mismatched reasoning settings**. This entry also presumes the route stays live: stealth previews vanish without notice, and **8 of OpenCode's 13 stealth codenames were never named at all** (Exo, Pulse Alpha, Union Alpha, Omen Alpha among them) — if Crouton disappears unnamed, this report becomes history, not a recommendation.
