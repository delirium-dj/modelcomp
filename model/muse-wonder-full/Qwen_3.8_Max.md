> **Verdict:** Muse Wonder Full is **Meta's largest and most capable frontier model** — the subscription-only top of the two-model Muse Wonder series launched **2026-10-12** (Alexandr Wang: "our largest and most capable model yet"), built for **long-running professional agents and ultra-long-horizon software engineering**. It is a **proprietary, reasoning (Max-effort)** model with a **1M context** and the broadest input (**text + image + audio/speech + video (+PDF) in → text out**). Independently, **Artificial Analysis scores it 50 on the current v5.0 Intelligence Index (#15/86, well above the 30 median, 4/4 units)** — and at launch it was **v4.3 Index 56, #2 overall behind only Claude Opus 5.5 (58)**. On Meta's own 14-row max-effort table the Wonder family leads 7 rows (Opus 5.5 six, GPT-6 Astra one), and **Wonder Full leads the long-horizon/agentic work: DeepSWE 1.1 79.0, SWE-Marathon 57.5 (xhigh), MemoryBench 85.5, AutomationBench-AA 45.4, Harvey LAB-AA 13.1% (would top AA's legal board), Vals Finance Agent V2 59.1, Personal Superintelligence Index 59.1** — while **trailing Opus 5.5 on Terminal-Bench 4.0 (57.1 vs 59.6), OSWorld V2.1 (78.4 vs 81.8), ProgramBench (59.0 vs 70.5) and the AA Index**. Catches: **subscription-only (Muse Code Power/Maximum), no per-token price** (so AA shows Speed/Cost = N/A), **knowledge is a weak spot (AA-Omniscience ~30)** and it is **verbose (110M tokens/task)**. Net: **Overall 86 (divergence −3.7 vs the curated 89.7)** — a genuine top-tier frontier agent model whose long-horizon coding/agentic leadership I credit heavily, held just below the very top by its second-place AA Index, from-scratch-coding/terminal/computer-use gaps versus Opus 5.5, weak knowledge and gated, token-opaque access.

- **Tool use: 87/100.** Its defining strength — **leads the frontier set on long-horizon agentic work**: **SWE-Marathon 57.5** (independently confirmed "strongest" by Abundant AI), **AutomationBench-AA 45.4**, **Harvey LAB-AA 13.1%** (would top AA's legal board), **Vals Finance Agent V2 59.1**, **MemoryBench 85.5**, **DeepSWE 1.1 79.0**, plus **OSWorld V2.1 78.4** computer use (2nd). - **Reasoning: 86/100.** **AA v5.0 Index 50 (#15/86, 4/4, well above the 30 median)** and **launch v4.3 Index 56 (#2 overall behind Opus 5.5)** with **Personal Superintelligence Index 59.1** (leads) — a bona-fide frontier reasoner. Capped by the **knowledge short board (AA-Omniscience ~30)**, GDP.pdf/HealthBench trailing, and sitting second-best rather than first.
- **Context window: 87/100.** **1M (1,048,576)** with **MemoryBench 85.5 — the leader** of the compared frontier set (Opus 81.5, Astra 81.4, Fable 79.0), evidencing genuinely strong long-context retention for multi-hundred-turn agent runs. Proven-1M tier.
- **Multimodal: 84/100.** **Text + image + audio/speech + video (+PDF) input** (AA-confirmed 4-modal) — the broadest input tier — but **text-only output** (no native image/audio generation), which caps it at the 4-modal-input/text-output ceiling.
- **Coding: 85/100.** **Elite long-horizon/agentic coding** — **DeepSWE 1.1 79.0** and **SWE-Marathon 57.5** both **lead** the frontier set, **Terminal-Bench 4.0-AA 57.1** is a close 2nd — but **ProgramBench 59.0 trails Opus 5.5's 70.5** (from-scratch coding gap) and one hard **SWE-bench CLI** harness reads only 11.4%. Strong-but-not-uniform.
- **Cost efficiency: 58/100.** *(Not counted in Overall.)* Weak — **subscription-only (Muse Code Power/Maximum), no per-token price**, sibling priced at a premium **$4/$20** (= Opus 5.5), and **verbose (110M tokens/task, #58/85)** which inflates real cost/time. Gated, token-opaque frontier access.
- **Overall Score: 86/100.** Half-up mean of the five quality dims: (87 + 86 + 87 + 84 + 85) / 5 = 429 / 5 = **85.8 → 86**. **Divergence −3.7** vs the curated 89.7. Muse Wonder Full is a **top-tier frontier agent model** — AA-verified #15/86 (v5.0) and #2-at-launch (v4.3 56), leading the independent field on long-horizon SWE (DeepSWE/SWE-Marathon), agentic (AutomationBench/Harvey LAB/Vals Finance) and memory (MemoryBench) work over a 1M, 4-modal-input context. My **−3.7** below the curator reflects that it is **second-best, not first** (Opus 5.5 leads the AA Index, Terminal-Bench, OSWorld and ProgramBench), plus a **weak knowledge/Omniscience score, verbosity, and subscription-only token-opaque access** — real limits the curated 89.7 appears to under-weight.
