## Model card

- **Name:** Qwen3.5 2B — Alibaba's **smallest-but-one open-weights multimodal model in the Qwen3.5 line**, with the repo folder recording the dotted spelling `qwen-3.5-2b`. **A negative finding governs this report: BenchLM carries no page for this model in any spelling** (`qwen-3.5-2b`, `qwen3-5-2b`, `qwen3.5-2b`, `qwen-3-5-2b` and `Qwen3.5-2B` all 404), so the 2026-11-06 re-research had no catalog to check against.
- **Short description:** A **262K-native multimodal edge model whose strong numbers are mostly locked behind a non-default thinking mode.** Apache-2.0, text/image/video in, Gated DeltaNet hybrid attention, and a card full of mid-tier figures: **MMLU-Pro 55.3, MMMU 64.2, MMMU-Pro 50.3, MathVista-mini 76.7, VideoMME 75.6, OCRBench 84.5, BFCL-V4 43.6, τ²-Bench 48.8, AA-LCR 25.6, HMMT 22.9/19.6.**
- **Provider / access:** Self-hostable, **Apache-2.0** weights at `huggingface.co/Qwen/Qwen3.5-2B`. models.dev records **2 providers at $0.00/$0.00**. **Not listed on OpenRouter**, so no metered API route exists — like its siblings **qwen3.5-0.8b** and **qwen3.5-4b**, both of which are also absent while **qwen3.5-9b is present** (a family-availability pattern recorded below).
- **Release / knowledge:** released **2026-03-02** (models.dev, Alibaba, Artificial Analysis). **Knowledge cutoff not disclosed.**
- **IDs:** `alibaba/qwen3.5-2b` (models.dev); `Qwen/Qwen3.5-2B` (Hugging Face); repo id `qwen-3.5-2b`.
- **Context window:** **262,144 tokens natively** (models.dev and the HF card agree). **Max output 81,920** (models.dev; the card's thinking-mode examples use 81,920, with **32,768 as the non-thinking recommendation**). **No YaRN extension figure is published for this size**, unlike the 4B which documents 1,010,000 via YaRN.
- **Modalities:** **text, image and video in; text out** (HF pipeline tag `image-text-to-text`; AA confirms text/image/video input). **Non-thinking mode is the default**, with thinking available via `enable_thinking`. Reasoning model; tool calling documented and measured (BFCL-V4 and τ²-Bench both reported).
- **Pricing (as of 2026-11-06):** **$0.00 / $0.00** per 1M (models.dev) — open Apache-2.0 weights, self-hosted, with **no served paid route** (OpenRouter does not list it).
- **Architecture:** open weights, **Apache-2.0**; **Gated DeltaNet hybrid attention**; parameter count per the model name (2B class).

### Normalized scores (1–100)

- **Tool use: 48/100.** Below the methodology's mid band. **BFCL-V4 43.6 and τ²-Bench 48.8 are both mid-to-low, and both are thinking-mode figures** — so the default (non-thinking) mode is likely weaker than the only numbers that exist. **No Terminal-Bench, τ³-bench, MCP-Atlas, OSWorld, Toolathlon, Claw-Eval, JobBench, GDPval-AA or AA Agentic Index figure exists**, so all three frontier references are unmeasured and no composite exists. Held above the floor because tool calling is documented and two benchmarks measure it.
- **Reasoning: 48/100.** Below the methodology's mid band, and the most mode-sensitive dimension in the file. **MMLU-Pro 55.3, MMLU-Redux 69.2, C-Eval 65.2 and MMMLU 56.9** in the default non-thinking mode are mid-low, and **HMMT 22.9 / 19.6 are near-floor**. **The thinking-mode gains are large (+11.2 MMLU-Pro, +17.4 IFEval) but thinking is not the default**, so the score reflects the default configuration rather than the best one. **GPQA, HLE, CritPt, ARC-AGI, the AA Intelligence Index and AA-Omniscience are all absent**, so composite depth and reliability are unknown.
- **Context window: 72/100.** **262,144 tokens natively** places it in the methodology's 200K–500K band (65–84) above its floor, **docked to 72 by weak retrieval at depth: AA-LCR 25.6 and LongBench v2 38.7** — the only long-context figures that exist. **No MRCR or RULER figure at a stated length exists**, and unlike the 4B sibling **no YaRN extension is documented for this size**, so the window is native but shallow.
- **Multimodal: 78/100.** **Text, image and video in; text out** — the methodology's 90–100 band on input breadth, docked to 78 because the measured quality is small-model-tier and because **several strong rows are thinking-only**: **MMMU 64.2, MMMU-Pro 50.3/47.7, MathVista-mini 76.7/73.9, VideoMME 75.6/69.0, MLVU 76.2, OCRBench 84.5/85.4, CC-OCR 72.9/75.8**. **The OCR and document rows (OCRBench 84.5, CC-OCR 75.8) are the strongest multimodal evidence in the file** and are real document-understanding capability; **the video rows are genuinely broad for a 2B model** and are the reason the score is 78 rather than mid-tier.
- **Coding: 42/100.** Below the methodology's mid band, and **entirely unmeasured — the card has no coding section at all for this model.** No LiveCodeBench, OJBench, SWE-bench, AA-SciCode, AA Coding Index, DeepSWE, Terminal-Bench or Vibe Code Bench figure exists, so all three coding frontier references are unmeasured. Held at 42 rather than the neutral floor because the model documents tool calling and reaches IFEval 78.6 in thinking mode, which is adjacent evidence of instruction-following precision if not of coding.
- **Cost efficiency: 97/100.** **$0.00/$0.00 per 1M with Apache-2.0 weights and no served metered route** — self-hosting is the only access path, which is the methodology's $0 anchor at its purest. Held at 97 rather than 100 because **no served route exists to verify the price against** and the model must be self-hosted, so the $0 is a licence fact rather than a measured rate.
- **Overall Score: 58/100.** (48 + 48 + 72 + 78 + 42) / 5 = 57.6 → **58**. **A near-agreement is recorded: this report's 58 sits within 3.1 points of the repo queue's 54.9**, and both are consistent with BenchLM carrying no page for the model. Recommendation: **a free, Apache-2.0, 262K-native multimodal edge model with unusually broad input for its size and unusually weak retrieval.** OCRBench 84.5, VideoMME 75.6, MathVista 76.7 and text/image/video input at $0.00/$0.00 with no metered route is a real proposition for on-device document, OCR and video-frame understanding. Three cautions: **most strong numbers are thinking-mode figures while non-thinking is the default**, so the deployed configuration is weaker than the card suggests — the single most important operational fact in this file; **AA-LCR 25.6 and LongBench v2 38.7 mean the 262K window is native but shallow**, with no YaRN extension documented for this size; and **coding is entirely unmeasured**, so it cannot be assessed as a code model at all. Prefer the **4B sibling** for a capability step or the **9B** which is the only Qwen3.5 small size OpenRouter actually lists.
