## Model card

- **Name:** GPT-5.5 — OpenAI's documentation calls it "a new class of intelligence for coding and professional work" and "a flagship model for the most complex professional work". No free tier. Variant/alias flag: **`gpt-5.5-pro` is a separate entry in this dataset** — the same base model running parallel test-time compute at $30/$180; this report covers the base model only. Superseded by the GPT-5.6 family (Sol/Terra/Luna, 2026-07-09) and then GPT-6 Astra (2026-09-03).
- **Short description:** Released **2026-04-23** and notable as **OpenAI's first fully retrained base model since GPT-4.5** rather than a post-training refinement like GPT-5.1 through 5.4. It shipped in two variants — base `gpt-5.5` and `gpt-5.5-pro` — and in ChatGPT across Plus, Pro, Business and Enterprise plus Codex. The headline claims were agentic: Terminal-Bench 2.0 leadership, a #2 Artificial Analysis Intelligence Index placement, and roughly 40% fewer output tokens per task than GPT-5.4. Buried in the same evaluation data is the number that defines it: **an 86% hallucination rate on AA-Omniscience, the worst of any flagship measured.**
- **Provider / access:** OpenAI, on **both Chat Completions and Responses**, plus the Batch API. Not supported: Realtime, Live, Assistants, fine-tuning, embeddings, image/video/speech generation, moderation, legacy completions. Supported features: streaming, structured outputs, function calling, file search, **file uploads**, image input, web search, prompt caching. Responses-API tools are the complete agentic set — function calling, web search, file search, **tool search**, image generation, code interpreter, **hosted shell, apply patch, skills, computer use and MCP**. In **Codex** it ships with a **400K context window** (not the API's 1.05M) and a separate **"Fast mode" that generates tokens 1.5x faster for 2.5x the cost**. ChatGPT Pro subscribers ($200/month) additionally get GPT-5.5 Pro.
- **Release / knowledge:** Released 2026-04-23. **Knowledge cutoff 2025-12-01.**
- **IDs:** `gpt-5.5`, with a **dated default snapshot `gpt-5.5-2026-04-23`** — unlike GPT-5.6 Sol, GPT-5.6 Terra and GPT-6 Astra, which offer no dated snapshot at all, so this model **can actually be pinned for reproducibility**. No free-tier ID.
- **Context window:** **1,050,000 tokens context with 128,000 max output.** A meaningful distinction from its own successors: OpenAI's documentation lists **no separate maximum-input cap** for GPT-5.5, whereas GPT-5.6 Sol, GPT-5.6 Terra and GPT-6 Astra are all capped at **922,000 input tokens**. Two counterweights: published retrieval is mediocre (**MRCR v2 74% at 1M**), and using the window is penalised twice over — see pricing and rate limits.
- **Modalities:** Input: **text and image only**. Output: text only. No audio or video in either direction; image generation exists only as a hosted Responses-API tool. Reasoning: yes, with reasoning-token support and **five effort levels — `none`, `low`, `medium` (default), `high`, `xhigh`**. Note the ladder differs from its successors in both directions: it **has `none`** (which GPT-6 Astra removed) but **lacks `max`** (which GPT-5.6 Sol and Terra added). Tool calls: yes (full surface above). JSON mode / structured outputs: yes.
- **Pricing (as of 2026-10-03):** **$5.00 / 1M input, $0.50 / 1M cached input, $30.00 / 1M output.** Two structural penalties, both documented by OpenAI: **prompts over 272K input tokens are priced at 2x input and 1.5x output for the *full session* — across standard, batch *and* flex** (the broadest formulation of this rule anywhere in this dataset; its successors apply it per request), and **regional processing (data residency) endpoints carry a 10% uplift**. Batch and Flex otherwise run at roughly half the standard rate, and Priority processing at ~2.5x. Family comparison from OpenAI's own table: GPT-5.4 $2.50 / $0.25 / $15; GPT-5.4 Mini $0.75 / $0.075 / $4.50.
- **Rate limits:** Standard Tier 1 begins at **500 RPM / 500K TPM**, rising to 15,000 RPM / 40M TPM at Tier 5. Uniquely among the OpenAI models documented in this dataset, GPT-5.5 publishes a **separate and materially lower Long Context schedule for requests over 272K input tokens: Tier 1 drops to 200 RPM / 400K TPM** and Tier 5 to 8,000 RPM / 20M TPM — a documented throughput penalty of roughly 50–60% for using the long window.
- **Architecture:** Proprietary, closed weights. Parameter count and topology: not disclosed. Serving infrastructure is disclosed: **NVIDIA GB200 NVL72** rack-scale systems, which NVIDIA claims deliver 35x lower cost per million tokens and 50x higher output per megawatt than prior systems. OpenAI also states that **Codex running GPT-5.5 wrote load-balancing and partitioning heuristics for OpenAI's own serving stack, raising token generation speed by over 20%**. System-card Preparedness ratings: Biological and Chemical **High**; Cybersecurity **High, below Critical** (increased from GPT-5.4); AI Self-Improvement **below High**.

### Raw benchmarks found

> The benchmark sweep below was **published by OpenAI** against GPT-5.4, Claude Opus 4.7 and Gemini 3.1 Pro, and was **partially verified by independent outlets** at the time. Index, hallucination and cost figures are **independent Artificial Analysis measurements**. Both provenances are labelled.

Agent / tool use:

- **Terminal-Bench 2.0: 82.7%** (OpenAI-reported; GPT-5.4 75.1%, **Claude Opus 4.7 69.4%, Gemini 3.1 Pro 68.5%**) — a 13.3-point lead over Claude and the cleanest agentic win in the set. **Terminal-Bench 2.1: 85.6%** (OpenAI-reported in the later GPT-5.6 family comparison; GPT-5.6 Sol 88.8%, Terra 87.4%, Luna 84.7%) — just under the methodology's ~88% frontier anchor.
- **Tau2-Bench Telecom: 98.0%** (OpenAI-reported; GPT-5.4 92.8%) — far above the methodology's Tau-family ~50% frontier reference, though **Telecom is the most tractable tau2 domain** and **no Tau3-Banking figure exists**, so this is not a general agentic result.
- **GDPval (wins or ties): 84.9%** (OpenAI-reported; GPT-5.4 83.0%, Claude Opus 4.7 80.3%, Gemini 3.1 Pro 67.3%) — a win-rate, **not** comparable to the Elo scale the methodology's ~1750+ reference uses.
- Claw-Eval / ClawProBench: no verified public score found
- Toolathon / MCP-Atlas / SWE Atlas Codebase QnA: no verified public score found
- **OSWorld-Verified: 78.7%** (OpenAI-reported; GPT-5.4 75.0%, Claude Opus 4.7 78.0% — effectively a tie)
- **BrowseComp: 84.4%** (OpenAI-reported; GPT-5.4 82.7%, Claude Opus 4.7 79.3%, **Gemini 3.1 Pro 85.9% ahead**)

Reasoning / knowledge:

- **GPQA Diamond: 93.6%** (OpenAI-reported; GPT-5.4 92.8%, **Claude Opus 4.7 94.2% and Gemini 3.1 Pro 94.3% both ahead**) — above the 90%+ reference but last of three frontier models.
- **HLE: 41.4% without tools, 52.2% with tools** (OpenAI-reported; **Claude Opus 4.7 46.9% / 54.7% and Gemini 3.1 Pro 44.4% / 51.4%** — GPT-5.5 is last on the no-tools row). Above the 40%+ reference, but only just.
- LCR / MLCR: no verified public score found
- CritPt: no verified public score found
- **Artificial Analysis Intelligence Index: 59 at high effort — ranked #2 of 141 evaluated models** (independent), against a median comparable score of 33. Running the full index cost **$2,159.38**. Just below the 60+ frontier marker.
- **Omniscience Accuracy / Hallucination Rate — the defining weakness: on AA-Omniscience it answered more questions correctly than any model Artificial Analysis had tested (57% accuracy) while posting an 86% hallucination rate, the worst of any flagship** (Claude Opus 4.7 max: 36%; Gemini 3.1 Pro Preview: 50%). AA's own framing: better at the right answer when it knows it, more willing to confabulate when it doesn't — with no signal in the output distinguishing the two. **On SimpleQA the hallucination rate is 47% without web search, dropping to 9.6% with web search enabled**, so the model is only reliable when grounded.
- **FrontierMath Tier 1–3: 51.7%** and **Tier 4: 35.4%** (OpenAI-reported; Tier 4: GPT-5.4 27.1%, Claude Opus 4.7 22.9%, Gemini 3.1 Pro 16.7%) — **an 8.3-point lead on the hardest tier and the most decisive reasoning win in the set**.
- **ARC-AGI-2: 85%** (OpenAI-reported)
- **OfficeQA Pro: 54.1%** (OpenAI-reported; Claude Opus 4.7 43.6%, Gemini 3.1 Pro 18.1%) — leads by a wide margin.

Coding:

- SWE-bench Verified: no verified public score found. **SWE-Bench Pro (public): 58.6%** (OpenAI-reported; GPT-5.4 57.7%, **Claude Opus 4.7 64.3% leads**, Gemini 3.1 Pro 54.2%) — the one benchmark that best predicts fixing real bugs in real repositories, and GPT-5.5 loses it by 5.7 points.
- LiveCodeBench: no verified public score found
- SciCode / AA-SciCode: no verified public score found
- Vibe Code Bench: no verified public score found
- DeepSWE: no verified public score found. **Expert-SWE (OpenAI internal): 73.1%** (GPT-5.4 68.5%) — no external comparison possible. OpenAI separately claims **state of the art on the Artificial Analysis Coding Index at half the cost of competitive frontier coding models** — a vendor claim with no number attached.
- **Token efficiency: roughly 40% fewer output tokens than GPT-5.4** on the same tasks (OpenAI-reported), which is the basis of its cost argument on output-heavy agentic work.
- Documented qualitative weakness — **"the card problem"**: asked to generate a UI from a plain-language prompt, GPT-5.5 reaches for the same rounded-card grid regardless of domain (bakery storefronts, SaaS dashboards, news sites all came back the same shape), with reviewers preferring Claude Opus 4.7 for layout hierarchy and typography.

Long context:

- **MRCR v2: 74% at the 1M window** (OpenAI-reported) — the only published long-context retrieval figure, and well short of a frontier recall rate. No RULER or GraphWalks result found.

### Normalized scores (1–100)

- **Tool use: 89/100.** The strongest part of this model. **Terminal-Bench 2.0 at 82.7% leads Claude Opus 4.7 by 13.3 points and Gemini 3.1 Pro by 14.2**, Terminal-Bench 2.1 at 85.6% sits close to the ~88% frontier anchor, **Tau2-Bench Telecom at 98.0% clears the Tau-family reference by a wide margin**, GDPval wins-or-ties at 84.9% beats both rivals, OSWorld-Verified at 78.7% matches Claude, and the Responses tool surface is complete (hosted shell, apply patch, skills, computer use, MCP, tool search) with 500 RPM from Tier 1. Four deductions: **Tau3-Banking is unreported and Telecom is the easiest tau2 domain**, so the 98% does not generalise; **Claw-Eval, Toolathon and MCP-Atlas are all unreported** (explicit methodology penalty); GDPval is published as a win-rate rather than the Elo the frontier reference uses, so it cannot be checked against ~1750+; and BrowseComp loses to Gemini 3.1 Pro.
- **Reasoning: 90/100.** **FrontierMath Tier 4 at 35.4% is an 8.3-point lead over the next model** and the clearest reasoning win here; the independent **Intelligence Index of 59 ranked #2 of 141** against a median of 33; **GPQA Diamond 93.6%** clears the 90%+ reference; **HLE 41.4%/52.2%** clears the 40%+ reference; ARC-AGI-2 85% and OfficeQA Pro 54.1% (leading by 10.5 and 36 points) round it out. The deduction is large and entirely evidence-based: **an 86% AA-Omniscience hallucination rate — the worst of any flagship measured — alongside 47% on SimpleQA without web search.** Record accuracy bought with record confabulation is a reasoning-reliability defect, not a presentation quibble. It also **loses GPQA Diamond and no-tools HLE to both Claude Opus 4.7 and Gemini 3.1 Pro**, the Index sits below the 60+ marker, MRCR v2 74% is far from the 95%+ reference, and CritPt and LCR/MLCR are unreported.
- **Context window: 94/100.** A verified **1,050,000-token context with 128,000 output** reaches the ≥1M tier, and GPT-5.5 is actually **better specified than its own successors on this axis** — OpenAI documents no separate maximum-input cap, where GPT-5.6 Sol, GPT-5.6 Terra and GPT-6 Astra are all limited to 922,000 input tokens. Three documented constraints hold it to 94 rather than higher: **MRCR v2 at 74% means roughly a quarter of needles are missed at full length**, nowhere near the ≥98%-retrieval condition for 100; the **272K threshold reprices the full *session* at 2x input and 1.5x output across standard, batch and flex** — the harshest formulation of this rule in the dataset; and uniquely, **long-context requests are rate-limited separately and far lower** (Tier 1 drops from 500 RPM / 500K TPM to 200 RPM / 400K TPM), so the window costs throughput as well as money.
- **Multimodal: 68/100.** Input is **text and images only** with text-only output and no audio or video path, placing it in the methodology's "+image in = 60–70" band. It does not reach the band ceiling because **not a single multimodal benchmark was published for this model** — no MMMU, no chart or document-understanding figure, no vision result of any kind was found — so unlike peers scored at 70, the image capability is documented in the spec sheet and entirely unquantified. It sits two points above the floor-of-band reasoning on the strength of documented `file_uploads` and `file_search` support plus a hosted image-generation tool, which are real document-pipeline capabilities even though they are orchestration rather than model output modalities.
- **Coding: 87/100.** **Terminal-Bench 2.0 at 82.7% leads its entire cohort by 13+ points** and Terminal-Bench 2.1 at 85.6% meets the methodology's 85%+ coding reference, Expert-SWE reaches 73.1% internally, and the **~40% output-token reduction versus GPT-5.4** is a genuine efficiency gain on agentic coding. Four deductions: **SWE-Bench Pro at 58.6% loses to Claude Opus 4.7's 64.3%**, which is the row that predicts real repository bug-fixing; **SWE-bench Verified, DeepSWE, LiveCodeBench, SciCode and Vibe Code Bench are all absent**, so three of the band's four references cannot be checked and OpenAI's AA Coding Index SOTA claim carries no number; the reproducible **"card problem"** makes it a poor choice for UI-first work; and the 86% confabulation rate lands directly in developer workflows as **hallucinated library and API names**.
- **Cost efficiency: 48/100.** At **$5 / $30** it is meaningfully worse than the $3/$15 anchor that maps to ~60 — and it is the more expensive of two OpenAI models at similar capability. Four factors argue up: **cached input at $0.50 is a true 10% rate**, Batch and Flex run at roughly half, the **`none` reasoning effort lets thinking be switched off entirely**, and the **~40% output-token reduction versus GPT-5.4** genuinely lowers bills on output-heavy agentic work. Five argue down: the **272K cliff reprices the full session across standard, batch and flex** rather than per request; **long-context throughput is separately capped 50–60% lower**; data-residency endpoints add 10%; Codex Fast mode costs 2.5x; and the intra-family comparison is unflattering — **GPT-5.4 at $2.50/$15 is half the price, and GPT-5.6 Terra at $2/$12 is cheaper still while scoring higher on the Artificial Analysis Index (57 vs this model's 59 on a different version, with Terra topping its own comparison table)**. There is no free tier.
- **Overall Score: 85.6/100.** Mean of the five non-cost dimensions (89 + 90 + 94 + 68 + 87) / 5 = 85.6 — a strong agentic and mathematical reasoner that needs a verification layer bolted on. Choose it for **long-horizon agentic coding and terminal work** (Terminal-Bench 2.0 82.7%, 13 points clear of its cohort), **hard mathematics** (FrontierMath Tier 4 35.4%, an 8.3-point lead), **professional document and office work** (GDPval wins-or-ties 84.9%, OfficeQA Pro 54.1%), and **workloads that need a pinnable dated snapshot** — `gpt-5.5-2026-04-23` is reproducible where its own successors are not. Do not choose it for repository bug-fixing (SWE-Bench Pro loses to Claude Opus 4.7), UI-first generation (the card problem), any multimodal or audio/video work (no vision benchmark exists), or **anything factual without retrieval enabled** — an 86% AA-Omniscience hallucination rate collapsing to 9.6% on SimpleQA once web search is on means grounding is not optional, it is the product requirement. Finally, be clear that it has been superseded twice: **GPT-5.6 Terra costs 60% less and scores higher on general intelligence**, and GPT-6 Astra leads the agentic rows — GPT-5.5's remaining argument is its reproducible snapshot and its uncapped 1.05M input window.
