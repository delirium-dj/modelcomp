## Model card

- **Name:** GPT-5.2 Codex (`gpt-5.2-codex`; dataset uses `gpt-5.2-codex`; official OpenAI API ID `gpt-5.2-codex`)
- **Short description:** OpenAI's agentic coding-optimized variant of GPT-5.2 (released 2025-12-18). Features native context compaction, long-horizon work improvements, stronger Windows-environment coding, and significantly stronger cybersecurity capabilities. Designed for professional software engineering: large refactors, code migrations, repository-scale agentic tasks. 400K context window (272K max input, 128K max output). Available in ChatGPT (paid Pro/Team/Enterprise) and API (Responses API primarily; also Chat Completions). Note: `verticaltabs.com` lists the model as "No longer available — The publisher shut this model down on July 23, 2026. It can no longer be used from its own API. Recommended replacement: gpt-5.6-sol." However, official OpenAI docs (`developers.openai.com/api/docs/models/gpt-5.2-codex`) still list it with model details and pricing, and `openai.com/index/introducing-gpt-5-2-codex/` remains live. The shutdown date (2026-07-23) appears in the independent aggregator (`verticaltabs.com`) but is NOT confirmed by official OpenAI deprecation notices in the sources I retrieved. **Status conflict noted:** independent aggregator reports shutdown; official docs and blog remain accessible. For scoring purposes, the model is treated as a historical/current coding specialist with potential deprecation — scores reflect verified benchmark performance, not future availability.
- **Provider / access:** OpenAI (`gpt-5.2-codex`); available via ChatGPT (Pro/Team/Enterprise) and OpenAI API (Responses API; Chat Completions with reasoning settings). No verified OpenCode Zen Free route (`pricingNote`: paid only, $1.75/$14 per 1M). No `noFreeId` explicitly set in meta.json but pricing note confirms no free lane.
- **Release / knowledge:** Released 2025-12-18 (official OpenAI blog/post). Knowledge cutoff: Aug 31, 2025 (per official model card `developers.openai.com`). System card addendum (`cdn.openai.com/pdf/ac7c37ae.../oai_5_2_Codex.pdf`) published same date.
- **IDs:** `gpt-5.2-codex` (official API); `openai/gpt-5.2-codex` (OpenRouter / provider listings). Note: `gpt-5.2-codex` is the exact API model ID; no `free` variant exists.
- **Context window:** 400,000 total; 272,000 max input; 128,000 max output — verified by official OpenAI docs (`developers.openai.com/api/docs/models/gpt-5.2-codex`) and meta.json (`contextWindow` line). Note: this is substantially smaller than frontier long-context models (1M+), which limits the model's applicability to very large repositories unless context compaction is used effectively.
- **Modalities:** Text + image input; text output (official model card). Reasoning: yes — supports `low`, `medium`, `high`, `xhigh` reasoning effort settings (official docs). Not a vision-output model; multimodal input is text-image only. Tool calling: yes (agentic coding in Codex-like environments). JSON mode: yes (supported in agentic contexts per official docs and system card).
- **Pricing (as of 2026-11-02):** Paid — $1.75 / $14.00 per 1M input/output; cached input $0.175 per 1M (`pricingNote` in meta.json). Very expensive output rate ($14/M) reflects specialist coding/agentic pricing. No free tier (`no free lane` per meta.json). Cost efficiency score will be low-to-moderate given high output cost, but the coding capability justifies it for specialized use.
- **Architecture:** Not fully disclosed by OpenAI in the sources I retrieved (official docs focus on capabilities, pricing, and evaluation, not architecture details). The model is described as an upgraded version of GPT-5.2 optimized for agentic coding (`openai.com/index/introducing-gpt-5-2-codex/`); includes improvements in long-horizon work through context compaction, stronger performance on large code changes (refactors/migrations), improved Windows-environment performance, and significantly stronger cybersecurity capabilities. System card (`oai_5_2_Codex.pdf`) describes it as very capable in cybersecurity but not reaching "High capability" on cybersecurity; treated as High capability on biology; does not reach High on AI self-improvement. Proprietary closed-weights; not open-source. Note: independent aggregator (`verticaltabs.com`) reports the model as shut down (2026-07-23); official docs still list it — this discrepancy is noted in the score explanation but does not change benchmark-derived scores.
