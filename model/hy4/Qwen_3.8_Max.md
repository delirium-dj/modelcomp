## Model card

- **Name:** Hy4 preview (Tencent Hunyuan "Hy4" / Hi-4 Preview)
- **Short description:** **Tencent Hunyuan's August-2026 next-generation open-weight flagship *preview*** — a **text-only reasoning MoE, 770B total / 49B active**, **Apache 2.0**, with a **1M-token context** (up from Hy3's 295B/21B and 256K — a 2.6× jump on both). It is "the biggest open-weights release of the month," aimed at **long-running, repo-scale agentic coding on private infrastructure**. Vendor numbers are strong (**Terminal-Bench 2.1 85.4, SWE-bench Multilingual 82.9, SWE-bench Pro 65.7, DeepSWE 64.3, GPQA Diamond 92.3**), but the **independent Vals AI suite is the reality-check**: **Vals Index 55.40% (#21/58, #4 open-weight** behind DeepSeek V4.1 Flash, Kimi K3, GLM 5.3), and **Terminal-Bench 2.1 only 55.06% (#42/66) — ~30 points below the vendor 85.4**. Reasoning has **exactly two levels** (`high` default / `no_think`) and **over-reasons/over-verifies** (a latency tax). ⚠ **No AA Intelligence Index** (page 404s). **Preview** — weights/serving may change.
- **Provider / access:** **Open weights (Apache 2.0)** on Hugging Face `tencent/Hy4-preview`, ModelScope, GitCode, CNB — **self-host $0** (BF16 ~1.56TB; **FP8 is the primary deployment target**, still an **8-GPU class** node via vLLM/SGLang, tensor-parallel 8). Hosted on **OpenRouter by Tencent Cloud** at **~$0.834/$2.501** per 1M in/out (**$0.042 cache reads**), tool-calling + structured outputs supported. **NOT on OpenCode Zen** (`noFreeId: true`).
- **Release / knowledge:** Released **August 28, 2026** — **current (preview)**. Successor to **Hy3** (295B/21B, 256K, July 6 2026). No knowledge-cutoff published. Official: `hunyuan.tencent.com/research/hy4-preview`; attention papers arXiv `2512.02556` (Gated DeepSeek Sparse Attention) + `2603.12201` (IndexCache).
- **IDs:** `tencent/hy4-preview`; OpenRouter `tencent/hy4-preview`; Vals `tencent_hy4-preview`; **AA page 404s** (no Intelligence Index). HF/ModelScope `Tencent-Hunyuan/Hy4-preview`.
- **Context window:** **1,000,000 (1M) total; 64,000 (64K) max out** — enabled by **Gated DeepSeek Sparse Attention + IndexCache** (cross-layer sparse index reuse); "matches the context ceiling DeepSeek V4 and Qwen3.8 Max set for the category." No explicit MRCR/RULER long-context-effectiveness figure published.
- **Modalities:** **Text in → text out (TEXT-ONLY).** Confirmed by the model card, developersdigest, and the decision guide ("if screenshots or diagrams are part of the task, this model is out by construction"). **No vision** — the "first honest signal about what it is for" (long-context text/agentic coding).
- **Pricing (as of 2026-10-28):** Hosted **~$0.834 / $2.501** per 1M in/out (OpenRouter/Tencent Cloud; **$0.042** cache reads); **self-host $0** (Apache 2.0, but an 8-GPU node). **Not a budget model** — "~2.5× DeepSeek V4 Pro's off-peak output rate… GLM-5.2 list-price territory," though "a quarter to a twentieth of frontier closed-model prices." Vals measured **$1.28/test, below the board median on nearly every benchmark**.
- **Architecture:** **Open-weight Mixture-of-Experts, 770B total / 49B active, Apache 2.0, reasoning.** **78 layers** (first dense, remaining 77 MoE) with **256 routed experts + 1 shared**, **top-8** routed activation; **Gated DeepSeek Sparse Attention** + **IndexCache**; identity **Hyper-Connections** residual pathway; native **MTP layer (10B total, 0.7B active)** for speculative decoding. Ships BF16 + **FP8** (`Hy4-preview-FP8`). **Two reasoning levels only** (`high` / `no_think`; any other value raises).

### Raw benchmarks found

> Independent anchor: **Vals AI (Sep 17, 2026) — a full independent suite**, accessed via OpenRouter: **Vals Index 55.40% (#21/58 overall, #4 open-weight**, behind DeepSeek V4.1 Flash, Kimi K3, GLM 5.3), **$1.28/test**. Crucially, Vals' **Terminal-Bench 2.1 = 55.06% (#42/66)** — **~30 points below the vendor 85.4** (the meta tradeoff's "one independent agentic run lands 30 points below the vendor Terminal-Bench score" is confirmed, and has since grown into a full suite). **AA has NO Intelligence Index** (page 404s). So the honest independent composite is **Vals #21/58 / #4 open-weight**, not the vendor headliners. AA Index baskets are version-specific and not convertible — and there is no AA measurement here at all.
>
> **Scoring stance:** distinct shipped artifact (open weights + FP8 + arXiv-cited architecture + OpenRouter serving) and both vendor **and** independent (Vals) benchmarks → **scored, not excluded**, weighting the independent Vals data above the vendor headliners (especially Terminal-Bench).

Vendor / community (model card, via developersdigest + 36kr):

- **Terminal-Bench 2.1: 85.4** (vendor) — ⚠ but **Vals independently measures 55.06% (#42/66)**, a ~30-pt gap; treat the vendor figure as harness/sampling-generous.
- **SWE-bench Multilingual (resolved): 82.9**; **SWE-bench Pro: 65.7**; **DeepSWE: 64.3** (36kr: "up from 28.0" on Hy3, and SWE-bench Pro 65.7 "entered the competitive range of GLM-5.3, Kimi K3 and GPT-5.6 Sol").
- **SkillsBench V1.1: 62.9**; **Apex Agents: 37.1**.
- **GPQA Diamond: 92.3** (vendor) — frontier-class *if* confirmed, but no independent GPQA re-run located.
- **Blind expert side-by-side** (163 evaluators, 203 engineering tasks): **"slightly ahead" of GLM 5.3 (2.99 vs 2.92) and Kimi K3 (2.99 vs 2.94)** — verdict-scale deltas, "not a routing cliff."

### Normalized scores (1–100)

- **Tool use: 79/100.** Genuinely agentic: vendor **Terminal-Bench 2.1 85.4, DeepSWE 64.3, SkillsBench 62.9, Apex Agents 37.1**, tool-calling + structured outputs on OpenRouter, and coding agents (**Claude Code, Command Code**) are already top OpenRouter traffic. **But the independent reality-check bites:** Vals **Terminal-Bench 2.1 = 55.06% (#42/66, mid-pack)** — ~30 pts below vendor — and **SRE Bench #7/10**, with **no AA Index** (no AutomationBench/Briefcase anchor). The **over-reasoning/over-verification** habit is a latency tax on long agent loops. Strong-vendor but independently-mid agentic-terminal band.
- **Reasoning: 80/100.** A **reasoning model** (`high` deep-CoT default) with strong independent showing: **Vals ProofBench v1.1 75.00% (#8/32)**, IOI #10/28, Legal Research #10/61, Harvey's Legal #13/62, and vendor **GPQA Diamond 92.3%** (frontier-class *if* confirmed — no independent GPQA re-run located). Anchored honestly by the **Vals Index 55.40% (#21/58, #4 open-weight)** — respectable, **behind DeepSeek V4.1 Flash / Kimi K3 / GLM 5.3**, not elite. Strong-open-weight-reasoning band, tempered by the vendor-only GPQA and the #21/58 composite.
- **Context window: 85/100.** **1M tokens / 64K out**, purpose-built for length via **Gated DeepSeek Sparse Attention + IndexCache**, and "matches the context ceiling DeepSeek V4 and Qwen3.8 Max set for the category." A genuine 1M (Vals accessed it at 1M), and the differentiator vs every 256K-class open model. Held at the 1M band (not above) because **no explicit MRCR/RULER long-context-effectiveness figure** is published.
- **Multimodal: 50/100.** **TEXT-ONLY** — no vision by construction ("if screenshots or diagrams are part of the task, this model is out"). The text-only floor, which — as with GLM-5.3, DeepSeek V4 Flash, and MiMo-V2.5-Pro — is the single biggest drag on the mean.
- **Coding: 81/100.** The headline strength, and better-corroborated than its agentic-terminal numbers: vendor **SWE-bench Multilingual 82.9, SWE-bench Pro 65.7** (36kr: "competitive range of GLM-5.3, Kimi K3 and GPT-5.6 Sol"), **DeepSWE 64.3** (up from Hy3's 28.0), plus the **independent Vals Code Migration 47.43% (#7/61) — the best open-weight model Vals has tested there**. The blind expert eval edged GLM 5.3 / Kimi K3. Tempered below the 84–88 elite tier because it is **Vals #4 open-weight (behind DeepSeek V4.1 Flash / Kimi K3 / GLM 5.3)**, its **Terminal-Bench is independently mid-pack (55.06%, #42/66)**, and it is a **preview**. Strong repo-scale-coding band.
- **Cost efficiency: 85/100.** **Apache 2.0 open weights → self-host $0** (commercial use, zero attribution) and **Vals cost-per-test below the board median on nearly every benchmark ($1.28/test)** — but **hosted is premium for open-weight (~$0.834/$2.501**, "GLM-5.2 list-price territory," ~2.5× DeepSeek V4 Pro's off-peak output) and **self-hosting needs an 8-GPU node** (1.56TB BF16 / FP8). "A quarter to a twentieth of frontier closed-model prices." Open-weight-plus-below-median-cost-per-test band, trimmed for the premium hosted rate and heavy self-host bar. Not counted toward Overall.
- **Overall Score: 75/100.** Mean of Tool 79 + Reasoning 80 + Context 85 + Multimodal 50 + Coding 81 = 375 / 5 = 75.0 → 75. Best fit: **the top-of-tier open-weight text-only agentic coder** — Tencent Hunyuan's **Aug-2026 Apache-2.0 770B/49B MoE** with a **1M context**, **two-level reasoning**, strong repo-scale coding (**SWE-bench Pro 65.7, Code Migration best-open-weight #7/61**) and vendor headliners (**Terminal-Bench 85.4, GPQA 92.3**) — but **text-only (Multimodal 50)**, a **preview** that **over-reasons**, **no AA Index**, **premium hosted pricing + 8-GPU self-host**, and an **independent Vals Index of only 55.40% (#21/58, #4 open-weight) with Terminal-Bench 55.06% (#42/66), ~30 pts under the vendor claim**. Ideal for **private/self-hosted, long-context, text-only repo-scale refactors and multi-file synthesis where heavy reasoning is welcome and latency isn't binding**; **use DeepSeek V4.1 Flash / Kimi K3 / GLM 5.3 (the open-weight models Vals ranks above it) when independent standing matters, DeepSeek V4 Flash for cheap bounded inner loops, or any VLM when vision is needed**. **Divergence note:** curated queue 73 vs my 75 → **+2.0**. I credit the **1M well-architected context (85)**, the **strong, independently-corroborated repo-scale coding (81)** and **reasoning (80)**; the curated score leans harder on the **text-only floor (50)**, the **preview/over-reasoning** status, the **absent AA Index**, and the **vendor-vs-independent Terminal-Bench gap** — all of which I also reflect (Multimodal 50, Tool 79 not higher). Lands **one below the current DeepSeek V4 Flash (76) and two below GLM-5.2 (77) / GLM-5.3 (78)** — consistent with Vals ranking Hy4 the **#4 open-weight model behind DeepSeek V4.1 Flash, Kimi K3 and GLM 5.3**.
