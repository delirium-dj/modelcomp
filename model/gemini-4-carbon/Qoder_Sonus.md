## Model card

- **Name:** Gemini 4 Carbon.
- **Short description:** Google's next frontier reasoning model after Gemini 4 Argon, announced for sustained agentic engineering and cybersecurity defense. It is an exact named model with original external evaluations, not an inferred Argon alias. This report covers the existing general model record, not a newly created unrestricted or cybersecurity tier.
- **Provider / access:** The [October 28 announcement](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-carbon/) starts access with selected cyber defenders and subsequently trusted Fairwind partners. Broader developer, business, and consumer access is promised without a firm date. The current [Artificial Analysis profile](https://artificialanalysis.ai/models/gemini-4-carbon) still displays **no publicly available API**. Evaluation access does not establish public availability.
- **Release / knowledge:** Announced **2026-10-28**. No exact Carbon knowledge cutoff or general-availability date was verified. Argon's release date and knowledge specifications are not transferred to Carbon.
- **IDs / integration:** No public, model-specific API ID, free OpenCode Zen ID, or supported OpenAI-compatible route was verified. `gemini-4-carbon` is used here as the repository slug, not asserted to be a callable endpoint. Indexed Google evaluation methodology identifies Gemini API runs; AA independently evaluates Carbon in Antigravity CLI. These establish evaluated tool-driven workflows, not every API feature flag. Function-calling schemas, JSON mode, PDF limits, batch support, and Live API support remain unverified for this exact deployment.
- **Context window:** **1M tokens**, independently listed by both Artificial Analysis and Vals. No directly verified exact input/output split or maximum output length was obtained. A secondary review's 1,048,576-output claim is not adopted without matching official Carbon documentation. Google's indexed GraphWalks result covers the 256K–1M range but is not an API output-limit specification.
- **Modalities:** AA reports **text, image, video, and speech input; text output**. Reasoning is supported, with the main AA and Vals evaluations at high effort. No native image, audio, or video generation was verified. Producing code that renders media is not native non-text output. A separate AA visual evaluation explicitly uses **Medium**, retained as such below.
- **Pricing (2026-11-05):** Official introductory price **$2 input / $10 output per million tokens**, with cached input 95% cheaper, implying **$0.10/M** at that tier. AA and Vals list **$4 input / $20 output** standard pricing; AA confirms **$0.20/M** standard cached input. AA's comparisons use standard pricing, not the 50% launch discount. No confirmed Carbon discount end date, free API tier, batch discount, cache-write charge, or long-prompt surcharge was verified. The cost score below uses the standard paid tier.
- **Privacy / restrictions:** Carbon-specific data-use, retention, and contractual access terms were not established in the retrieved material. No no-training, zero-retention, or free-tier privacy promise is assumed. Reviews describe Fairwind organizational checks and usage restrictions, but also warn that the program page described Argon at the time; these are not silently promoted to a complete Carbon contract. Google says Carbon is participating in voluntary US pre-release testing.
- **Architecture:** Proprietary; no verified parameter count, active-parameter count, detailed architecture, or open-weight license. The retrieved Carbon evaluation document is a benchmark methodology PDF, not a successfully inspected model card or separate safety report.

### Raw benchmarks found

Evidence is separated into **original external evaluations**, **Google-reported measurements**, and **secondary transcriptions**. The research used web searches and direct retrieval only, with no browser. Google's evaluation PDF was retrieved as non-extractable PDF data; exact indexed primary excerpts corroborate some methodological details, but the full document was not read. The family page also did not yield its full table through direct retrieval.

Agent / tool use:

- **Artificial Analysis Coding Agent Index: 59**, Carbon **high** in **Antigravity CLI**, versus 62 for Claude Opus 5.5 max in Claude Code, in AA's [October 28 original evaluation](https://artificialanalysis.ai/articles/gemini-4-carbon-new-number-1). This measures model-plus-harness behavior, not a harness-independent model score.
- **Terminal-Bench 4.0: 64%**, rounded, in that AA coding-agent evaluation; **63.13%**, rank **4/57**, in [Vals' high-effort evaluation](https://www.vals.ai/models/google_gemini-4-carbon). Aleksei Aleinikov's transcription of Google's table lists a further **65.2%** attributed to AA. The 65.2 row's exact run configuration was not independently extracted; it is not substituted for AA's directly readable 64% or Vals' 63.13%. None is Terminal-Bench 2.1, and these results are not averaged.
- **AA-Briefcase: 1,609 Elo**, high effort, in AA's original article, versus Argon 1,483. Presentation quality **1,598 Elo** and analytical quality **1,671 Elo** represent different components. AA explicitly says Carbon still trails several models in agentic knowledge work. Elo is not a success percentage or GDPval-AA score.
- **Vals Index v2.2: 70.36%**, **2/29**, **$10.51 per test**, high effort, behind Sonnet 5.5 at 70.85% and ahead of Opus 5.5 at 70.18%, in the October 28 announcement. Its components include **Legal Research Bench 55.77% (1/87)**, **EMB v1.1 76.47% (2/35)**, **Tax Agent 48.86% (3/78)**, **Finance Agent v2.1 67.16% (5/33)**, and **HLAB-Vals-1.1 17.50% (tied 6/30)**. These are benchmark-specific outcomes, not interchangeable legal/finance reliability rates.
- **Google-table rows, secondary transcription:** **Agents' Last Exam v1.1 77.4%**, **OSWorld 2.1 offline 81.5%**, **AutomationBench private set 53.9%**, and **Vending-Bench 2 ending balance $16,484** appear in [Aleinikov's review](https://www.alekseialeinikov.com/en/blog/topics/ai/gemini-4-carbon-review-benchmarks-price-access). Indexed Google text separately confirms the OSWorld 81.5% row and use of the official Docker/evaluator, 1080p, and 500 maximum steps. The review describes an 82-task offline subset and reporting the best of three runs; those additional details remain secondary-source methodology, not a claim of full PDF inspection. Do not call that a full-suite, single-run OSWorld result.
- The same review describes ALE-Claw with a five-hour budget and safeguards enabled for Agents' Last Exam. AutomationBench's private-set score is **not AutomationBench-AA**, and vending balance is a simulation outcome, not real trading profit. These supplementary rows are lower-confidence than directly readable original AA/Vals results.
- No separately verified Carbon numeric result was obtained for Terminal-Bench 2.1, Tau3-Banking/Tau2, Claw-Eval/ClawProBench, Toolathon, MCP-Atlas, or SWE-Atlas Codebase QnA. Aggregator-only GDPval/AutomationBench-AA values were not promoted to primary measurements.

Reasoning / knowledge:

- **Artificial Analysis Intelligence Index v5: 59**, historical **#1** on October 28. AA reports first place in **four of nine** components: HLE-Diamond, Terminal-Bench-Science, AA-Omniscience, and AutomationBench-AA. The directly readable article does not provide every component's exact percentage.
- **Current AA profile: 60, #1/69**, retrieved November 5, on **Index v5.0.1**. That profile names nine components and now includes **FrontierCode 2.0**. The historical 59 and current 60 are dated/versioned snapshots, not proof of a checkpoint improvement or a one-point gain on an unchanged suite. Index points are not percent accuracy.
- **AA-Omniscience v1.1: net score 54; accuracy 58%; hallucination rate 11%**, rounded figures in AA's original article. Argon is 48% accurate with 4% hallucination. Carbon answers more questions correctly but also hallucinates more under this evaluation; the net score still improves. Accuracy and hallucination have different denominators and should not be added or treated as complements.
- **RiemannBench: 80.0%**, exact Carbon row in indexed text of Google's [Gemini family page](https://deepmind.google/models/gemini/), corroborated by the review's table. The review attributes the source to a public leaderboard; the owner’s run details were not retrieved, so it remains a Google-published scientific result rather than a claimed personally verified independent rerun.
- **Terminal-Bench-Science 0.1: 64.8%**, secondary transcription of Google's AA-attributed table. AA's original article confirms the leading position but not that exact percentage in readable text. Retain this evidence tier; scientific agent success with tools is not unaided academic-test accuracy.
- No verified exact-model GPQA Diamond, full HLE, ARC-AGI, CritPt, or MRCR numeric result was obtained. HLE-Diamond is a revised evaluation, not automatically comparable to older HLE scores. No peer report or repository average supplies missing numbers.

Coding:

- **FrontierSWE V2: 61.2% mean reward**, verified directly on [Proximal Labs' original leaderboard](https://www.frontierswe.com/): **34 tasks, five trials each, 170 graded trials, 20-hour budget per trial**, harness labeled **proximus**. Carbon's mean reward is **0.6120**, average cost **$61.93/trial**, and displayed average time **12.6 hours**. It appears third in the page's **per-provider Best** view behind Astra 65.5% and Opus 5.5 62.3%; that filtered rank is not an all-model ranking.
- The FrontierSWE page explicitly defines mean@5, with whiskers spanning worst@5–best@5. This is not pass@5, not a 61.2% strict whole-task completion rate, and not a confidence interval established by this report. Its per-trial cost uses its own configuration; no undocumented promotional-price assumption is made. Argon's comparison also has an explicit lower-cache-hit warning caused by a non-production setting.
- **FrontierCode v1.1: 51%**, rounded AA high-effort Antigravity CLI result, second behind Opus 5.5 at 56% in AA's launch article. The AA Coding Agent Index 59 and Terminal-Bench 4.0 results above provide additional original coding evidence.
- **Vibe Code Bench: 89.06%, 8/121**, high reasoning, original Vals announcement. **WebDev Arena: 1,768 Elo, #4, +89 Elo**, Google launch claim. These evaluate different aspects of generated web artifacts; neither is a broad repository-maintenance pass rate.
- **SWE-sweep: 9.6%** appears in the review's Google-table transcription, which identifies Google's mini-swe-agent run and externally published competitor results. This is supplementary and not SWE-bench Verified or SWE-Pro.
- A tracker lists **FrontierCode 2.0 40.0%**, but the directly retrieved [Cognition article](https://cognition.com/blog/frontier-code-2.0) did not expose a Carbon result row. That value is **not used as a verified scoring anchor**. Cognition does establish materially broader tasks and stricter mergeability criteria for 2.0; no 51-to-40 regression is inferred across versions and evaluators.
- No verified Carbon SWE-bench Verified/Pro, LiveCodeBench, SciCode, DeepSWE, or independent code-review precision/recall figure was obtained. Strong agentic results do not prove every generated change is mergeable or secure.

Long context and multimodal:

- **GraphWalks, 256K–1M, BFS F1: 96.2%**, exact Carbon row in indexed Google family-page text, independently corroborated as a transcription by multiple reviews. Indexed [Google methodology](https://deepmind.google/models/evals-methodology/gemini-4-carbon) explicitly says GraphWalks results for all models are **self-computed**. This is vendor-run graph reasoning/retrieval over a range, not independently replicated pointwise 1M recall, document comprehension, or an MRCR score.
- The 1M capacity and 96.2% range-level F1 support strong long-context capability, but neither establishes **at least 98% retrieval at 512K+**. The perfect-context-score condition is not met, and detailed length-distribution/aggregation settings were not recovered.
- **MMMU-Pro: 89%, Gemini 4 Carbon (Medium)**, rounded, verified directly on [AA's original evaluation page](https://artificialanalysis.ai/evaluations/mmmu-pro). It leads that page's summary over Opus 5.5 Max Default Fallback at 88% and Astra Max at 87%. This is exact-model visual evidence at **Medium**, not silently relabeled as the High configuration used by the main coding/index evaluations.
- **Chartography, no tools: 72.5%; Blueprint-Bench 2: 58.6%**, secondary transcriptions of Google's table in the review, not independently rerun tests by that reviewer. These are supplementary chart/blueprint evidence. No separately verified numeric Carbon video, audio, or PDF benchmark was recovered; modality support and measured quality remain distinct.

Cybersecurity and safety:

- Google reports **SEC-bench Pro 88.2%**, **ExploitGym 54.8%**, and **CWE-bench 71.0%**, explicitly describing the cyber evaluations as **without guardrails**. They do not estimate what a safeguarded deployment will permit or accomplish.
- **ExploitGym time-budget caveat:** indexed primary methodology confirms self-computed, single-attempt runs and an extended **ten-hour** timeout. NeuralTrust, Aleinikov, and other chart transcriptions distinguish **54.8% at ten hours** from **53.5% at six hours**; that pairing was not directly extracted from the full primary chart. Aleinikov describes Antigravity, no internet, mitigations off, and competitor results from other providers' reports. This is not a controlled same-harness comparison merely because the benchmark name matches.
- **CWE attribution/version caveat:** indexed Google methodology explicitly identifies **CWE-bench v1** results as sourced from the public leaderboard and evaluated across models by **Collinear AI**. Thus the blanket claim that every cyber number was self-run by Google is too broad. However, the [owner's currently retrieved page](https://cwe-bench.com/) is now **v2**, with 100 public plus 150 held-out tasks, and did not expose a Carbon row. The 71.0% remains a Google-published, externally attributed **v1** result; it is not a verified current v2 result. No v1/v2 percentage comparison is made.
- **Google internal safety claims:** Terminal-Bench 4.0 successful cheating **0.0%**, cheating attempts **0.4%**, high-severity misalignment alerts down **almost 80%**, unsupported claims roughly halved, overreach down **26%**, and under-service down **29%**. **Gray Swan indirect prompt-injection attack success: 0.0%**, versus Argon 0.7%. These are finite, vendor-reported evaluations, not universal safety guarantees, calibrated production failure probabilities, or proof against adaptive attacks.
- Google additionally claims **more than 2×** secure-code success over Argon and **more than 10×** better Chrome patching than another lab's unnamed model. Absolute rates, the unnamed comparator, and complete run details are absent. Wiz's positive assessment has no numeric result in the launch text. These claims are not converted into benchmark percentages or used to erase the independent coding limitations.

### Evidence comparison and deployment limitations

1. **Pricing is tier-dependent, not contradictory:** Google's $2/$10 is introductory; AA/Vals' $4/$20 is standard. AA measures **$7.76 per Intelligence Index task**, versus Opus 5.5 $10.04 and Astra $6.25, with **123K output tokens/task** versus Opus 173K. Carbon is cheaper than one strong peer on this workload, but not universally cheapest. Vals' $10.51 and FrontierSWE's $61.93 describe different tests and must not be pooled.
2. **Token speed is not task speed:** the current AA profile reports **69 output tokens/s**, **69.44 seconds to first answer token**, and **29.6 minutes per Index task**, with **205M total output tokens** and **7.62B input tokens** for its displayed index run. Historical reviews quote different speed/token snapshots. Long reasoning can produce substantial latency even with reasonable streaming throughput; these totals are not user request limits.
3. **Rankings depend on the selected competitors:** Google's transcribed table omits Sonnet 5.5, while the original Vals announcement ranks Carbon second behind it. “Wins 15 of 17 rows” in a selected vendor table is not “best model on every independent benchmark.” FrontierSWE's per-provider filter and AA's distinct knowledge-work/coding results create additional ranking boundaries.
4. **Live snapshots differ:** Vals' November 4 home listing showed **70.45** while the original October 28 announcement remains **70.36**. AA's historical 59 versus current 60 likewise needs its version/date labels. No unverified cause, score averaging, or silent replacement is introduced.
5. **Reliability claims measure different things:** Google's reduction in unsupported claims in internal workflows can coexist with AA-Omniscience hallucination rising from 4% to 11% versus Argon. They use different tasks, denominators, and harnesses. AA still reports improved net knowledge performance; neither claim cancels the other.
6. **Independent testing is narrower than broad public experience:** AA, Vals, and Proximal provide original external evaluations. [NeuralTrust](https://neuraltrust.ai/blog/gemini-4-carbon) and Aleinikov are useful source-comparison reviews, not demonstrated independent hands-on reruns of every table. Restricted access limits reproducibility, API integration certainty, and production feedback. Full Carbon output limits, cutoff, retention terms, and safeguard documentation remain open evidence gaps.

### Normalized scores (1–100)

These are evidence-weighted interpretations under the repository methodology, not benchmark percentages. Most evaluated agent configurations use high reasoning; the separately labeled Medium visual result supports model-level modality assessment without pretending it was the same run. Confidence in core measured capabilities is higher than confidence in deployment specifications.

- **Tool use: 94/100.** Original AA/Vals terminal and knowledge-work evaluations plus long-horizon FrontierSWE establish frontier agent capability; harness dependence, uneven business-task performance, and missing Tau/Claw/MCP coverage cap the score.
- **Reasoning: 96/100.** AA's leading v5/v5.0.1 index, strong scientific evidence, and improved Omniscience net score support the frontier band; 58% knowledge accuracy, nonzero hallucination, and missing directly inspected academic component scores prevent a perfect rating.
- **Context window: 97/100.** Two original evaluators list 1M capacity and Google's indexed GraphWalks reports 96.2% BFS F1 over 256K–1M; vendor-only range aggregation, unknown output limits, and no verified 98% retrieval at 512K+ cap the score below 100.
- **Multimodal: 95/100.** Independently documented text/image/video/speech input and AA's 89% MMMU-Pro at Medium support broad understanding; text-only output and absent measured audio/video/PDF results cap the score.
- **Coding: 94/100.** Original AA agent tests, FrontierSWE V2 mean reward 61.2%, and Vals Vibe Code 89.06% support frontier engineering capability; stronger competing coding results, strict mergeability gaps, and missing review/SWE coverage limit the rating.
- **Cost efficiency: 56/100.** Scored at standard $4/$20 with $0.20 cached input: $7.76 per AA task is competitive with some frontier peers but costly overall, with substantial verbosity; the temporary $2/$10 discount is disclosed without inflating the durable standard-tier score.
- **Overall Score: 95/100.** Half-up mean of the five quality dimensions: (94 + 96 + 97 + 95 + 94) / 5 = 95.2 → 95; cost is excluded. Best fit is authorized long-context engineering and multimodal analysis, with access, latency, and independently enforced safety controls assessed before deployment.
