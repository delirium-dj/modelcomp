## Model Overview

Gemini 4 Carbon is Google DeepMind's frontier model optimized for cybersecurity and long-horizon agentic coding. 1M token context and 1M output, accepting text, image, speech, and video input; text out. Introductory pricing $2/$10 per 1M (standard $4/$20), cached input $0.20/M. Gated launch: access routed to cyber defenders first via the Fairwind Program while awaiting broader public release. #1 on the Artificial Analysis Intelligence Index (score 60) at launch.

## Scores

- **Tool use: 93/100.** Terminal-Bench 4.0 65.2% confirms strong agentic terminal command execution. Agents' Last Exam v1.1 77.4% validates long-horizon multi-step agentic capability. SEC-bench Pro 88.2% shows top-tier agentic cybersecurity tool use. AA Coding Agent Index 59 is competitive.
- **Reasoning: 95/100.** HLE-Diamond 69.1% leads the leaderboard for hard reasoning. AA Intelligence Index 60 (#1/66 at launch). Agents' Last Exam 77.4% and CWE-bench 71.0% (root-cause remediation) further confirm elite multi-step scientific and security reasoning.
- **Context window: 92/100.** 1M input AND 1M output (both) maps to the 1M tier (92). Full 1M output is rare and distinctive — most models cap output far below their context.
- **Multimodal: 82/100.** Text, image, speech, and video input; text output — full four-modality input coverage. Maps to the full omni input tier (82–90). Scored 82 for breadth without non-text output.
- **Coding: 93/100.** SEC-bench Pro 88.2%, CWE-bench 71.0%, ExploitGym 54.8% validate specialized security coding depth. Terminal-Bench 4.0 65.2% confirms agentic coding environment capability. Roughly twice as likely to generate secure code vs. predecessor Argon.
- **Cost efficiency: 25/100.** $4/$20 per 1M (standard) is premium pricing. Introductory $2/$10 is better but still expensive. Gated access limits availability further. Cached input $0.20/M improves economics for repeated-context workflows.
- **Overall Score: 91/100.** Mean of Tool use (93) + Reasoning (95) + Context (92) + Multimodal (82) + Coding (93) = 455 / 5 = 91.0. The frontier cybersecurity and agentic coding flagship — recommended for vetted cyber defenders and enterprises needing the top HLE/SEC-bench class capability; expect gated access constraints.
