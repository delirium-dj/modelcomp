## Model card

- **Name:** Claude Sonnet 5
- **Short description:** Anthropic's June-2026 **mid-tier** model (family order: Fable 5 > Opus 4.8 > **Sonnet 5** > Haiku 4.5) and the first Sonnet that genuinely rivals the flagship on most intelligence benchmarks — **SWE-bench Verified 85.2%**, **GDPval-AA 1618 Elo (≈ ties Opus 4.8's 1615)**, **HLE-with-tools 57.4% (near Opus 4.8's ~57.9%)** and **Terminal-Bench 2.1 80.4% (level with the flagship)** — at ~40% lower per-token cost. The catch that defines it: **adaptive thinking is always on** (five effort levels) and a new tokenizer inflates output ~1.0–1.35×, so Artificial Analysis measured **cost-per-task ~$2.29, ~15% *more* than Opus 4.8** unless effort is actively managed. A stark harness sensitivity also shows up on the newest terminal-agent benchmark (**Terminal-Bench 4.0 = 10.3%**, later fixed to 70.6% in Sonnet 5.5).
- **Provider / access:** claude.ai (**default model for Free and Pro tiers**), Anthropic API (`claude-sonnet-5`), Claude Code, AWS Bedrock, Google Vertex AI, Microsoft Foundry, and aggregators. Broadest channel availability of any current Claude.
- **Release / knowledge:** Released **2026-06-30** (succeeds Claude Sonnet 4.6). **Knowledge cutoff January 2026.**
- **IDs:** `claude-sonnet-5` (predecessor `claude-sonnet-4-6`; successor Sonnet 5.5; flagship siblings Opus 4.8 / Fable 5).
- **Context window:** **1M tokens native** (matched only by Opus 4.8 in the lineup); **128K max output** standard, **up to 300K via the Batch API beta**. No MRCR-style long-context recall figure published in the sources reviewed.
- **Modalities:** **text + image in → text out** (no audio). **Adaptive thinking always on, cannot be disabled** — five effort levels (low / medium / **high [default]** / xhigh / max); full tool use, self-verifying agentic follow-through.
- **Pricing (as of 2026-10-23):** **Standard $3 / 1M input, $15 / 1M output** (in effect from 2026-09-01). *Intro pricing was $2 / $10 through 2026-08-31 — now expired.* Prompt-cache reads up to **90% off**; **Batch API 50% off**. Per-token ~40% cheaper than Opus 4.8 ($5/$25), **but AA-measured cost-per-task is ~$2.29 (~15% above Opus 4.8)** because always-on reasoning + the new tokenizer inflate output tokens.
- **Architecture:** Undisclosed proprietary. Shares the **new tokenizer** with Opus 4.7/4.8/Fable 5 (~1.0–1.35× more tokens than older Claude tokenizers) — the root of the effort-level cost trap.

### Normalized scores (1–100)

- **Tool use: 84/100.** **Trimmed 85 → 84.** Strong agentic tool orchestration — GDPval-AA 1618 Elo (≈ ties Opus 4.8 on the vendor card), HLE-with-tools 57.4%, Terminal-Bench 2.1 80.4% — plus reliable self-verifying follow-through. The terminal-harness weakness is now **independently corroborated**, not just vendor-acknowledged: **Terminal-Bench 3.0 14.6** (frontierbench) sits alongside the draft's TB 4.0 10.3, and **Vals Terminal-Bench 2.1 74.5** only partially replicates the vendor 80.4 (AA's own leaderboard 80.5). The broader independent agentic set is mid (AA Agentic Index 44.3, AA Tau3 Banking 37.3, ApprenticeBench 16), and always-on adaptive thinking still drives token-burning over-reading. Held below the flagship tier accordingly.
- **Reasoning: 84/100.** **Trimmed 86 → 84** because the draft's "overlaps-the-flagship" premium rested on the **AA Index 53 / #5 overall** anchor, which AA has now **deprecated to N/A (→ Sonnet 5.5)**; the fresh neutral read is **AA v5.0 Index 38.2** and **BenchLM #36/1004** — a strong mid-tier, one tier below the flagship. The substance is still good and now multi-source: **GPQA-D AA 91.1 / Vals 88.9** is flagship-adjacent, MMLU-Pro (Vals) 87.5 and Epoch FrontierMath v2 T1-3 65.6 are strong — but peak-reasoning cells cap the ceiling (**CritPt 16.9, AA-HLE 41.3, Omniscience accuracy 40.1 / hallucination 39.4**). Broad, reliable, top-decile; not flagship on the hardest reasoning.
- **Context window: 89/100.** **Lifted 88 → 89.** A **1M-token native window** (matched only by Opus 4.8 in the lineup; **AA spec independently confirms 1M, text+image, no audio**), 128K standard output and 300K via Batch beta. The draft discounted depth specifically for lack of a recall benchmark — **AA-LCR 82.0** now supplies it: solid long-context reasoning that removes the "unverified at depth" penalty (a provenance lift, not a capability change), though 82.0 is good rather than elite, so it stays below the 90–93 top-recall leaders.
- **Multimodal: 79/100.** **Holds 79, but the path is now measured rather than assumed.** The draft scored 79 "conservatively, rather than assume flagship parity" because **no vision benchmark existed**; **AA-MMMU-Pro 77.3** now lands exactly in that mid-70s band (+ CharXiv 88.3 vendor, ParseBench 61.16). Text + image only, **no audio (AA spec confirms)** — competent document/UI/agentic reading, neither a strength nor a liability, so 79 remains the honest value, now grounded in data instead of a discount.
- **Coding: 86/100.** **Holds 86** — the one dimension the independent pass actively **corroborates**. Vals **SWE-bench 79.6** and **LiveCodeBench 82.4** broadly validate the vendor's SWE-bench Verified 85.2 / Pro 63.2 for a mid-tier model, and AA Coding Index 71.5 is solid. It stays capped below the high-80s/90s by the same signals the draft flagged that independent data confirms — **Terminal-Bench 3.0 14.6 / 4.0 10.3** (long-horizon terminal collapse), **SWE Multimodal 28.1**, Cognition FrontierCode 1.1 42.7 and steep CursorBench generation-sensitivity (3.2 61.5 → 4.0 34.1) — while still trailing the true frontier (Opus 4.8 88.6, Fable 5 ~95%).
- **Cost efficiency: 68/100.** **Holds 68.** The defining tension stands: sticker is ~40% below Opus 4.8 with 90%-off caching and 50%-off Batch, and at low effort it's a genuine cheap workhorse — but always-on adaptive thinking + the new tokenizer inflate real spend (the draft's AA-measured ~$2.29/task, ~15% *above* Opus 4.8). Two caveats from the re-check: AA now **tracks the price at $2/$10, conflicting with the draft's "$3/$15 standard (intro expired)"** — pricing is contested — and because the model is **deprecated** AA's cost-per-task is now **N/A**, so the trap can no longer be independently re-measured. Scored but **not** counted in the Overall per methodology.
- **Overall Score: 84/100.** **Trimmed 85 → 84.** Mean of Tool 84 + Reasoning 84 + Context 89 + Multimodal 79 + Coding 86 = 422 / 5 = 84.4 → **84**. Best fit: **the default high-volume agentic workhorse** — end-to-end coding agents, terminal work, knowledge/research pipelines and 1M-context analysis where you want strong (not flagship) quality at lower per-token cost, *provided you manage effort level* and instrument token counts. Escalate to Opus 4.8/5.x for output-variance-critical or irreversible actions, and avoid it for the newest terminal-agent harness (TB 3.0/4.0) until Sonnet 5.5. Independent read: my 84 sits **below the queue's curated 88.5** because the neutral anchor the draft leaned on (AA Index 53 / #5) is now deprecated to N/A with a fresh read of **38.2 / BenchLM #36**, the terminal-harness collapse is independently confirmed (TB 3.0 14.6), and the unmeasured multimodal path plus contested pricing argue against flagship-parity tiering — a strong mid-tier that *nearly* matches the flagship on breadth, not on peak.
