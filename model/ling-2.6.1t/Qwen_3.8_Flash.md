## Model card

- **Name:** Ling-2.6-1T (Hugging Face `inclusionAI/Ling-2.6-1T`, ModelScope mirror, AA id `ling-2-6-1t`, OpenRouter `inclusionai/ling-2.6-1t` with a **`:free`** variant; curated id `opencode/ling-2.6.1t`)
- **Short description:** InclusionAI's "**trillion-parameter comprehensive flagship model for complex tasks**" — the **instruct / non-thinking** half of the 2.6-1T pair (the thinking half is `Ring-2.6-1T`, researched separately). Pitched at "coding and daily workflows", with three headline engineering upgrades: a **hybrid MLA + Linear-Attention** architecture for low-latency/low-VRAM long context, a **"Fast Thinking"** post-training reward (*Contextual Process Redundancy Suppression*) that cuts reliance on verbose chains-of-thought, and "reliable multi-step execution" for agents.
- **Provider / access:** **Open weights under the MIT License** (card front-matter `license: mit`; repo `inclusionAI/Ling-V2/LICENSE`) — fully permissive, commercial use unrestricted. Runs on **SGLang** (vendor recipe: `--tp-size 8`, `--context-length 262144`, `--tool-call-parser qwen25`, EAGLE/MTP speculative flags, patched `antgroup/sglang` branch `ling_2_6` because "the current official SGLang implementation of MTP contains a bug") and **vLLM** (`VLLM_USE_PRECOMPILED=1`, TP8, 0.85 GPU memory utilisation). Hosted access on OpenRouter (paid **and `:free`** variants) and ZenMux. Agent-framework integrations named by the vendor: **Claude Code, OpenClaw, OpenCode, CodeBuddy**.
- **Release / knowledge:** Artificial Analysis lists **Released April 2026** (marketplace listings date 2026-04-23/27). Technical report: **arXiv 2606.15079**, "Ling and Ring 2.6 Technical Report: Efficient and Instant Agentic Intelligence at Trillion-Parameter Scale", **submitted 2026-06-13** (paper under CC BY-NC-ND 4.0). **No knowledge-cutoff date is published**; training-content disclosure exists only as a summary PDF (`inclusionAI/AI-Transparency/Ling-2.6_TDS-Summary.pdf`). **Status flag:** AA carries a **deprecation banner** — "This model is deprecated … InclusionAI has launched a newer release, **Ling 3.0 Flash**. We suggest considering it instead" — and freezes all but the default 10 K-input workload.
- **IDs:** `inclusionAI/Ling-2.6-1T` (HF/ModelScope), `inclusionai/ling-2.6-1t` / `…:free` (OpenRouter), `ling-2-6-1t` (AA), `opencode/ling-2.6.1t` (curated). **Aggregator coverage flag:** **BenchLM has no page** (404 for `ling-2-6-1t`; it does cover `ling-2-6-flash`), and **llm-stats renders no content** — so unlike most folders, there is **no third-party per-benchmark table** for this ID, only AA's composite plus vendor claims.
- **Context window:** **262,144 tokens** — corroborated twice: AA's spec block says **262k**, and the vendor's own SGLang launch command pins `--context-length 262144`. Max output is **not published** (the methodology's sub-64 K caveat therefore cannot be checked). The curated `meta.json` says "128K total", which **under-states the window by half**.
- **Modalities:** **text in / text out** (AA: "supports text input, outputs text"; card is `pipeline_tag: text-generation`, no encoder or media evaluation). The curated "Text in/out" is correct.
- **Pricing (as of 2026-10-08):** AA measures **$0.30 / $2.50 per 1M input/output** — input at its class median ($0.29), output called "**somewhat expensive**" against a class median of $0.91; AA reports **no cost-per-task figure** for this ID ("N/A … Results for other workloads are historical"). The card's framing is that token *efficiency*, not sticker price, is the product: "Fast Thinking" compresses output tokens, and the vendor cites AA's Index run at **~16 M output tokens**. A **free OpenRouter endpoint** (`inclusionai/ling-2.6-1t:free`) exists for evaluation, and MIT weights make self-hosting licence-free.
- **Architecture:** **1.0 T total / 63 B active parameters** (AA spec block), sparse MoE, **hybrid MLA + Linear Attention** ("dramatically reduce latency and VRAM footprint for long contexts"), multi-token prediction via EAGLE speculative decoding, tool-call parsing reusing the `qwen25` parser. Post-training adds the redundancy-suppression reward to shorten CoT.
- **Identity flags:** (1) **Ling vs Ring split:** this is the non-reasoning instruct line; `Ring-2.6-1T` (`model/ring-2.6.1t/`) is the reasoning line with the `high`/`xhigh` effort knob — AA's page here explicitly says "This page shows the **non-reasoning** version of this model. A reasoning variant may also exist." Do not inherit scores between them. (2) **Vendor-vs-AA intelligence conflict:** the card states "On Artificial Analysis, **Ling-2.6-1T achieved an Intelligence Index of 34** with approximately 16M output tokens", while AA's live page for this ID shows **17 (marked *Estimated*)**. 34 is not reproducible from any current AA figure; the divergence is flagged and the **measured 17** is what this report scores. (3) **Scaffolded entry:** `meta.json` has `"scaffolded": true`, boilerplate `short`, placeholder `"Standard pricing"` and a wrong context figure. (4) **Slug check:** `ling-2.6.1t` follows the dotted-version convention and has no hyphen twin (rule-7 clean); it is *not* the same object as `model/ling-3.0-flash/`, `model/ling-3.1-flash/` or `model/ling-3.0-flash-vl/`.

### Normalized scores (1–100)

- **Tool use: 56/100.** The agentic intent and integration surface are unusually concrete for an open model — the card claims **open-source SOTA on TAU2-Bench and BFCL-V4**, top-tier on **Claw-Eval** and **PinchBench**, "more stable performance in multi-step tasks, tool collaboration", plus first-class wiring into **Claude Code / OpenCode / CodeBuddy / OpenClaw** and an existing `qwen25` tool-call parser. But **not one of those harnesses has a published number for this ID** (BenchLM 404, AA breaks nothing out, vendor numbers are chart images), and the one independent composite that exists (AA Index 17) is built substantially from agentic evaluations and does not corroborate a frontier claim. Scored in the mid band with the missing-value penalty explicit.
- **Reasoning: 50/100.** AA's **Index 17 (estimated)** is *above* its class median (12) but lands below the methodology's 20–35 mid-tier reference, and the class is the weakest one (open-weight non-reasoning). "Leads non-thinking models on AIME26" is a claim without a value. The decisive independent deduction is knowledge reliability: **AA-Omniscience −51 with a ~92 % hallucination rate** — the model asserts facts it does not have, roughly nine times in ten on that suite, which is worse than any other folder scored in this pass and caps this dimension regardless of composite rank.
- **Context window: 76/100.** **262,144 tokens**, double-verified (AA spec block + the vendor's own `--context-length 262144` launch recipe) → 200 K–500 K tier (65–84). It sits above the tier floor rather than mid because the vendor reports **MRCR results across 16 K–256 K**, i.e. retrieval at the full advertised window was actually run (values not readable in text, so not rewarded numerically). Held below 80 by **no published max-output limit** (sub-64 K caveat cannot be dismissed), no AA long-context row, and the curated sheet claiming only 128 K.
- **Multimodal: 15/100.** **Text-only** — AA (text in, text out), card (`pipeline_tag: text-generation`, no vision/audio encoder or media benchmark). Nothing lifts it out of the 10–20 band; vision in this family is a different model (`model/ling-3.0-flash-vl/`).
- **Coding: 55/100.** Coding is the model's own headline use case — "**open-source SOTA on SWE-bench Verified**", "end-to-end engineering from code generation to bug fixing", agent-framework support, and a sibling report of **Terminal-Bench**-class execution strength — but a SOTA *claim* with no retrievable number, no BenchLM row, no LiveCodeBench/DeepSWE/SciCode measurement and a **deprecated** status cannot be scored above the middle of the band. This is one of the cases where the positioning is strong and the evidence is thin: the next researcher with access to the technical-report tables should be able to move this dimension substantially.
- **Cost efficiency: 90/100.** **MIT open weights** plus a **free OpenRouter endpoint** (`:free`) makes evaluation $0, the hybrid MLA + linear-attention design and MTP/EAGLE speculative decoding target exactly the latency/VRAM costs that make trillion-parameter models expensive, and "Fast Thinking" explicitly suppresses CoT token bloat (~16 M output tokens cited for the AA Index run). Against that, AA calls the hosted output price "somewhat expensive" ($2.50 vs class median $0.91 — 2.7×, which matters for a chatty instruct model), **no cost-per-task figure exists**, and self-hosting still needs an 8-GPU TP8 node.
- **Overall Score: 50/100.** Mean of the five quality dimensions (56 + 50 + 76 + 15 + 55) / 5 = 252 / 5 = 50.4 → 50; Cost excluded per `RULES.md`. Best fit: **teams that must own and self-host a permissively-licensed trillion-parameter instruct model** for agentic coding and multi-step tool workflows on an SGLang/vLLM stack, where the 262 K window, token-efficiency design and MIT licence outweigh leaderboard position — and where the model can be re-benchmarked internally (the vendor's own harness charts are not machine-readable, so verification is on you). It is **not** the pick for factual Q&A (**~92 % hallucination on AA-Omniscience**), not the pick for multimodal work, and not a first choice for a *new* build: AA marks it **deprecated** and points to **Ling 3.0 Flash**, which this registry tracks separately.
