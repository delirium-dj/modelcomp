## Model card

- **Name:** Ling-2.6-1T
- **Short description:** InclusionAI's (Ant Group) **trillion-parameter instant/instruct model**, released **2026-04-23** — the *fast-thinking* half of the 2.6 family, whose sibling **Ring-2.6-1T** is the deep-reasoning half with controllable effort. Its thesis is **token efficiency**: a "fast thinking" approach plus a Contextual Process Redundancy Suppression reward that suppresses verbose chain-of-thought while holding capability, cutting token cost to **roughly a quarter of comparable models**. Rather than retraining a trillion-parameter model, it retrofits the Ling-2.0-1T base through architectural change, continued pre-training (~9.6T tokens) and large-scale post-training. Top use case: high-volume production agents and long-document work.
- **Provider / access:** Hugging Face `inclusionAI/Ling-2.6-1T` (**MIT**, confirmed by AA's technical-specifications table); OpenRouter `inclusionai/ling-2.6-1t` (status **Deprecated**) **and a `:free` variant** `inclusionai/ling-2.6-1t:free`; ZenMux; Novita AI; Ant's direct API (which requires a personal Alipay account before the first call). Self-host via vLLM or SGLang on 8 GPUs (`--tp-size 8 --context-length 262144 --tool-call-parser qwen25`). OpenAI-compatible `/v1/chat/completions`. No OpenCode Zen ID found.
- **Release / knowledge:** Released **2026-04-23** (OpenRouter, AA "Released April 2026"); HowAIWorks dates the card 2026-04-30. Technical report **arXiv:2606.15079**, June 2026 (shared with Ring-2.6-1T). Knowledge cutoff: not disclosed — Ant publishes neither a cutoff nor a training-token count.
- **IDs:** `inclusionAI/Ling-2.6-1T` (HF), `inclusionai/ling-2.6-1t` (OpenRouter, deprecated), `inclusionai/ling-2.6-1t:free` (free variant)
- **Context window:** **CORRECTED — the first pass credited 262,144 as the model's context window. That is the API-exposed window, not the model's.** InclusionAI's official docs page (published **2026-10-08**) now states: **"Ling-2.6-1T: Supports up to 1M context window natively; the official API currently exposes a 256K context window."** HowAIWorks corroborates this independently and adds the mechanism: **"`config.json` sets 262,144 positions"** — the shipped weights are configured for 256K and the 1M figure requires self-hosting with an extended rope configuration. So: **1M claimed native / 256K hosted / 262,144 positions in `config.json`.** Max output **32,768** (LLMTR, Requesty, Kilo; llmrates rounds to 32K).
- **Modalities:** **Text in → text out only.** The HF repo is a `Text Generation` / `AutoModelForCausalLM` checkpoint (`bailing_hybrid`); AA's spec table lists text in / text out. **Instant/instruct — not a reasoning model** in the extended-thinking sense: the family's own framing is "instant response and high token efficiency," vs Ring-2.6's controllable reasoning effort. HowAIWorks adds a useful caveat: the whole published comparison set is non-reasoning peers (GPT-5.4, GLM-5, DeepSeek-V3.2, Kimi-K2.5, all labelled "Non Reasoning"), so none of these scores say anything about reasoning-mode comparison. Tool calls / function calling: yes. Structured outputs: yes. Prompt caching: yes ($0.06/1M cache read).
- **Pricing (as of 2026-10-17):** **CORRECTED — the first pass's headline "$0.075 in / $0.625 out" is wrong by roughly 4×.** Four independent sources now agree on the OpenRouter list rate of **$0.30 in / $2.50 out / $0.06 cache read**: InclusionAI's own official third-party pricing table, Artificial Analysis ("$0.30 per 1M input tokens … and $2.50 per 1M output tokens"), Kilo Code, and the OpenRouter route. The $0.075/$0.625 figure survives on BenchmarkList and llmrates.ai and is a stale/derived artefact — **Ant's own page is authoritative and is preferred here.** Ant's **direct-API list is ¥4.50 / ¥18.00 / ¥0.90**, undiscounted: HowAIWorks records that the earlier **¥0.45 / ¥1.80 promotional rate (1/10 of list) expired 2026-07-31**. A **`:free` variant remains at $0** on OpenRouter. AA characterises the pricing as "somewhat expensive when comparing to other open weight non-reasoning models of similar size" ($2.50 output vs a $1.74 class median). Weights are MIT, so self-hosting has no token cost.
- **Architecture:** **~1.03T total / ~63B active** sparse MoE (AA: 1.0T total, 63B active). Hybrid linear attention combining **MLA with Lightning Linear components** at a 7:1 ratio, replacing the GQA stack that consumed >60% of FLOPs beyond 32K. Retrofit pipeline: hybrid initialization, QK-Norm absorption, Partial RoPE adaptation, MLA warmup. Base: Ling-2.6-1T-base, upgraded from Ling-2.0-1T-base. **Licence conflict, unresolved:** HF tags the repo `License: mit` and AA's spec table says MIT; llmreference records Apache 2.0. MIT is preferred (two sources incl. the vendor repo).

### Normalized scores (1–100)

- **Tool use: 68/100** *(was 78).* Lowered, but this dimension got *much* better-evidenced. The first pass scored 78 on a single independent number (τ²-Bench ~90%) with **no** published BFCL, PinchBench, GDPval or ClawEval value. Those values now exist: **ClawProBench 57.4 (#23/48)** with Tool Use 62.4 and Pass^3 only 36.6%, **GDPval-AA 1045 (#104/352)**, **Terminal-Bench Hard 31.1% (#70/326)**, **Kilo's Terminal-Bench 2.0 at 28.1% and $30.82 per attempt**, and **Gert Labs GScore 25.0% — #61 of 62**. On the positive side **τ²-Bench Telecom 89.8% is genuinely strong (#53/332, 84th percentile)** and the vendor's BFCL-v4 70.64 / τ² 78.36 / PinchBench 85.24 are respectable. That is an above-median-but-not-elite agentic profile, and the missing rows are still missing. **This model is markedly better at tool use than its 2.6-flash sibling** (ClawProBench 57.4 vs 27.04) — that contrast is the real finding.
- **Reasoning: 55/100** *(was 58).* **GPQA Diamond 75.2% (#173/468)** is solid and vendor reasoning rows (bbeh 52.37, ARCPrize 50.94, IMO-AnswerBench 65.81) are respectable. Held down by **HLE 8.7%**, **NYT Connections Extended 10.8% — dead last of 64**, **AA-Omniscience −51**, **CritPt 0.3%**, **ObviousBench 39th percentile**, and an AA Intelligence Index that has been **revised downward twice (34 → 26.05 → 17)** as AA reweighted the composite. The first pass called the 34-vs-17 gap an unexplained discrepancy; this pass traced it to index-version changes and now scores the **current 17**, which is why the score moved down even though no individual benchmark got worse.
- **Context window: 85/100** *(was 78).* Raised on the **vendor's own newly published long-context docs page (2026-10-08)**: "Supports up to 1M context window natively; the official API currently exposes a 256K context window" — corroborated independently by HowAIWorks showing `config.json` ships 262,144 positions. Adding **vendor MRCR (16K–256K) = 80.37**, the best in its comparison set, the *model* is now credibly a 1M-window model even though you cannot call more than 256K today. Not higher because (a) the 1M figure is entirely unfalsified — no provider serves it and no independent benchmark touches it, (b) the independent retrieval number that does exist, **AA-LCR, is 34.7–41.7%, near the bottom of the field**, and (c) AA still reports the context window as 262k.
- **Multimodal: 15/100.** Unchanged — **text-only**, confirmed by the HF `Text Generation` causal-LM checkpoint, AA's spec table (text in / text out) and CloudPrice's 1-of-5 modality listing. Floor score by methodology.
- **Coding: 62/100** *(was 70).* **BLXBench 75.3% at #8 of 25 is a real, strong, independently-run new result** and is the main reason this is not lower. Against it: **SciCode 37.0% (#141/296)**, **Terminal-Bench Hard 31.1%**, **Kilo's Terminal-Bench 2.0 28.1% at $30.82 per attempt**, **AA Coding Index 33.0 (#100/198)**, and the fact that the **only** respectable SWE-bench numbers (72.20 / 73.80) are vendor-reported and vendor-annotated as scaffold-dependent, with no AA corroboration. For a 1T model the coding evidence base is thinner than the parameter count suggests.
- **Cost efficiency: 72/100** *(was 98 — the single largest correction in this report).* The first pass scored 98 on "$0.075 in / $0.625 out with $0.015 cache reads, among the cheapest paid routes available for any trillion-parameter model." **That price was wrong by ~4×.** The real OpenRouter list is **$0.30 / $2.50 / $0.06**, and AA itself calls that "somewhat expensive when comparing to other open weight non-reasoning models of similar size" — $2.50 output against a $1.74 class median. Ant's own direct-API rate is **¥4.50 / ¥18.00**, and the earlier 1/10-of-list promotion **expired 2026-07-31**. What survives is the **`:free` variant at $0** and MIT weights for self-hosters. Deprecated at AA and on OpenRouter, so even the free route is not durable.
- **Overall Score: 57/100.** `(Tool 68 + Reasoning 55 + Context 85 + Multimodal 15 + Coding 62) / 5 = 285 / 5 = 57.0 → 57`. Best fit: **high-volume, long-document and long-horizon agent workloads on the free OpenRouter variant**, where 1M native context, MRCR 80.37, ClawProBench 57.4 and τ²-Telecom 89.8% are genuinely attractive and the free tier makes the arithmetic work. Do **not** adopt it new: **deprecated** by AA and OpenRouter, its AA Intelligence Index has been revised down twice to 17, HLE is 8.7%, AA-LCR is ~35–42%, Gert Labs is #61 of 62, and its real price is $0.30/$2.50, not the $0.075/$0.625 the first pass reported. `ling-3.0-flash` in this same repo is the live successor and is an order of magnitude cheaper per token.
