## Model card

- **Name:** NVIDIA Nemotron 3.5 Bolt 74B-A9B (also listed as `NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB`, `nemotron-3-5-bolt-74b-a9b`)
- **Short description:** NVIDIA's hybrid Mamba-2–Transformer vision-language model, released 2026-10-15 (official research/blog) / 2026-10-15 (Hugging Face weights). It is derived from the larger Nemotron 3.5 Super VL 120B-A12B parent via Star Elastic compression (74B total / 9B active parameters) and aggressive 2-bit quantization (IQ2_XXS, ~2.0625 bits per element) to fit into ~24GB memory for local inference on NVIDIA RTX Spark / DGX Spark / discrete GPUs (32GB+ / 48GB+). It supports text + image + video input and text output, reasoning mode (`enable_thinking`), function calling, structured outputs, and a 256K context window. Designed specifically for everyday agentic tasks locally (agentic coding, debugging, tool use, web browsing, terminal interaction, vision tasks) rather than for cloud-scale frontier reasoning.
- **Provider / access:** NVIDIA research / Hugging Face (`https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB`, `https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-BF16`, `https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB-GGUF`). Self-hosting via vLLM / llama.cpp (Windows ARM x64, Linux). No official cloud API from NVIDIA (unlike Alibaba Cloud for Qwen, xAI for Grok, OpenAI for GPT); the model is intended for local deployment. Independent benchmark sources (`https://research.nvidia.com/labs/nemotron/Nemotron-3.5-Bolt-24GB/`, `https://artificialanalysis.ai/models/nemotron-3-5-bolt-74b-a9b`, `https://benchmarklist.com/models/nvidia-nemotron-3.5-bolt-74b-a9b/`) confirm independent evaluation results.
- **Release / knowledge:** Released 2026-10-15 (`https://research.nvidia.com/labs/nemotron/Nemotron-3.5-Bolt-24GB/`, `https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB`). Knowledge cutoff not explicitly stated; closest reference is not available; model behavior consistent with training through mid-2026 (derived from Super 3.5 VL family).
- **IDs:** `nemotron-3.5-bolt-74b-a9b` / `NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB` (official NVIDIA); `nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB` (Hugging Face). No cloud-hosted official API; deployment is local/self-hosted.
- **Context window:** **Up to 256,000 tokens** (`https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB`, `https://research.nvidia.com/labs/nemotron/Nemotron-3.5-Bolt-24GB/`, `https://docs.api.nvidia.com/nim/reference/nvidia/nvidia-nemotron-3-5-bolt-74b-a9b-24gb` — closest reference confirms 262,144 token context for NVIDIA NIM reference). Independent sources (`https://artificialanalysis.ai/models/nemotron-3-5-bolt-74b-a9b`, `https://atlas.kevinhu.io/models/nemotron-3-5-bolt-74b-a9b`, `https://inferbase.ai/models/nvidia/nemotron-3-5-bolt-74b-a9b`) confirm 256K / 262K context window. No 1M extension claim; the context window is fixed at 256K/262K.
- **Modalities:** Input: text, image, video (`https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB`, `https://research.nvidia.com/labs/nemotron/Nemotron-3.5-Bolt-24GB/`). Output: text. Reasoning: yes (`enable_thinking` configurable, inherited from Super 3.5 VL). Tool calling / function calling: yes (agentic tool use verified by independent agentic benchmarks: MCP Atlas 52.20%, Terminal-Bench 2.1 50.98%, BFCL-V4 estimated 73.2%). Structured outputs / JSON mode: supported (`https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB` confirms structured output support). No audio input/output; no video generation; no image generation. Batch API: not mentioned; closest reference is self-hosted deployment.
- **Pricing (as of 2026-11-04):** No official cloud pricing (self-hosted/local model). Independent sources note no API price because the model is intended for local deployment on NVIDIA RTX Spark / DGX Spark (`https://research.nvidia.com/labs/nemotron/Nemotron-3.5-Bolt-24GB/`, `https://kompozy.io/reviews/nemotron-3-5-bolt-benchmark-test`). The cost is hardware/inference cost rather than per-token cloud pricing. Independent comparison (`https://benchmarklist.com/models/nvidia-nemotron-3.5-bolt-74b-a9b/`) does not list pricing; closest comparison is cost-effectiveness relative to memory footprint (24GB quantized model vs. 4-bit quantized competitors). No promotional pricing, no free tier, no volume discounts — the model is open-source (OpenMDW-1.1 license) with no cloud-hosted official endpoint.
- **Architecture:** Hybrid Mamba-2–Transformer LatentMoE (`https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB`). Total parameters: 74B; active parameters per token: 9B (`https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB`, `https://research.nvidia.com/labs/nemotron/Nemotron-3.5-Bolt-24GB/`). Vision encoder: C-RADIO v4-H. Quantization: IQ2 (2-bit quantization with quantization-aware training/distillation, ~2.0625 bits per element) for production deployment; BF16 checkpoint available for customization/post-training (`https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-BF16`). Speculative decoding: LiLiCorr drafter (1.13B params) included (`https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB-LiLiCorr`). Memory footprint: ~22GB quantized + 0.87GB cache/activations = ~23GB, leaving ~1GB for drafter; fits in 24GB GPU memory budget (`https://research.nvidia.com/labs/nemotron/Nemotron-3.5-Bolt-24GB/`). Context: 256K tokens native. Deployment: llama.cpp (Windows ARM x64), vLLM (NVIDIA GPUs), DGX Spark (`https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB`). License: OpenMDW-1.1 (`https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB`). Not self-hostable in the same sense as open-source dense models (quantized to 2-bit requires specific NVIDIA hardware/software); but open weights allow customization.

### Conflicting / contradictory evidence (explicit comparison)

1. **Agentic / coding performance: vendor-aligned claims vs. independent benchmark scores.** The vendor-aligned official NVIDIA research/blog (`https://research.nvidia.com/labs/nemotron/Nemotron-3.5-Bolt-24GB/`) reports very strong relative performance against similarly sized/open-source competitors: **GDPVal-AA-V2 28.47** (vs. Qwen3.6-35B-A3B 25.75, Gemma4 26B-A4B 15.33), **Terminal-Bench 2.1 50.98** (vs. Qwen3.6 44.38, Gemma4 37.22), **Tau3 Banking 17.01** (vs. Qwen3.6 10.52, Gemma4 14.02), **AA-LCR 64.06** (vs. Qwen3.6 61.06, Gemma4 57.56), **SciCode 41.02** (vs. Qwen3.6 35.33, Gemma4 40.28), **GPQA Diamond 86.43** (vs. Qwen3.6 83.40, Gemma4 79.61), **PinchBench 87.82** (#1 in class), **WebArena 50.86** (#2 in class), **BrowseComp 66.75** (#2 in class). Independent Artificial Analysis (`https://artificialanalysis.ai/models/nemotron-3-5-bolt-74b-a9b`) reports lower scores for some benchmarks: **Agentic Index 18.3** (low), **Coding Index 36.7** (low — significantly lower than vendor-aligned coding benchmark comparisons), **Intelligence Index 20.8** (low — much lower than Claude Fable 5.1 / Claude Opus 5.5 / Muse Spark 1.3 / Qwen3.5-122B-A10B in `model-queue.md`). Independent BenchmarkList (`https://benchmarklist.com/models/nvidia-nemotron-3.5-bolt-74b-a9b/`) reports mixed scores: **Agentic: PinchBench 90.35** (very high — matches vendor claim), **Tau3-Banking 17.01** (matches vendor claim), **AA-Briefcase 912** (52nd percentile, moderate), **BrowseComp 70.0%** (moderate-to-weak, 54/69), **MCP-Atlas 55.6%** (weak, 48/52 — significantly lower than vendor-aligned 52.2%? Actually 55.6% is slightly higher than vendor-aligned 52.2%, but both are weak relative to leaders like Fable 5.1 87.2%); **Coding: SciCode 44.5%** (moderate, 93/311 — lower than vendor-aligned 41.02%? Actually 44.5% is close), **Terminal-Bench 2.1 53.9%** (moderate, 75/196 — close to vendor 50.98%), **SWE-bench Verified 65.5%** (estimated, medium confidence — lower than vendor-aligned claim of 65.5% estimated is close, but independent measurement is lower than some competitors). Independent review (`https://mindstudio.ai/blog/nvidia-nemotron-3-5-bolt-benchmark-test`) confirms the model is capable for vision/reasoning (9/9 on vision tracking, 7/7 on scientific reasoning, good for vision tasks) but notes significant weaknesses for production coding (failed to find hardcoded bug in full-stack app, produced broken visual output after feedback, abstract reasoning issues, inconsistent translation on less common languages). Independent XDA review (`https://www.xda-developers.com/i-tested-nvidias-nemotron-35-bolt-and-it-changed-what-i-thought-my-16gb-gpu-could-do/`) confirms practical agentic capability (completed a 5-step multi-tool job in 11 minutes 44 seconds) but notes imperfections. The core conflict: vendor-aligned benchmark tables (especially Table 7 comparing against Qwen3.6 35B-A3B, Gemma4 26B-A4B, and other small-to-medium open-source models) show Nemotron Bolt as leading or competitive in its size/memory class; independent standardized evaluation (Artificial Analysis Intelligence Index 20.8, Coding Index 36.7, Agentic Index 18.3) places it at a low-to-moderate tier relative to broader model rosters (Claude Fable 5.1, Claude Opus 5.5, Muse Spark 1.3, Qwen3.5-122B-A10B, GPT-6 Astra, etc.). This reflects different comparison baselines: vendor-aligned comparisons focus on models with similar memory footprint (24GB) and open-source/self-hostable capabilities; independent indexes compare against the full dataset including much larger/cloud-hosted frontier models. No numerical contradiction — just different reference frames. The practical finding (independent review from MindStudio) confirms strong vision/reasoning but weak sustained production coding, aligning with the lower independent coding index (36.7) and agentic index (18.3) relative to vendor-aligned agentic/coding claims.

2. **Compression / quantization claims: vendor-aligned performance recovery.** The vendor-aligned technical report (`https://research.nvidia.com/labs/nemotron/Nemotron-3.5-Bolt-24GB/`) claims that Star Elastic compression + QAD (quantization-aware distillation) + LiLiCorr speculative decoding recover accuracy close to the parent 120B-A12B model. Table 7 (`https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB`) confirms the compressed/quantized Bolt 74B-A9B-24GB (IQ2) achieves scores very close to the BF16 compressed version (e.g., GDPVal-AA-V2 28.47 vs. 31.13 BF16; Terminal-Bench 2.1 50.98 vs. 53.93 BF16; HLE 25.30 vs. 28.73 BF16; SciCode 41.02 vs. 44.49 BF16; GPQA Diamond 86.43 vs. 88.83 BF16). The gap is small (typically 2–5 percentage points), confirming the vendor claim that quantization-aware distillation recovers accuracy well. Independent Benchmark Atlas (`https://atlas.kevinhu.io/models/grok-build-0-1`) does not list Nemotron Bolt; closest proxy is not needed. Independent BenchmarkList (`https://benchmarklist.com/models/nvidia-nemotron-3.5-bolt-74b-a9b/`) reports measured/estimated scores for the 24GB version (e.g., PinchBench 90.35 measured, Terminal-Bench 2.1 53.9 measured, SciCode 44.5 measured, AA-Briefcase 912 estimated, HLE 24.7% measured, GPQA Diamond 86.43% measured) — these match the vendor-aligned numbers closely, confirming the accuracy recovery claim. No significant numerical conflict.

3. **Speed / inference claims: vendor-aligned TPS vs. independent measurements.** Vendor-aligned technical report (`https://research.nvidia.com/labs/nemotron/Nemotron-3.5-Bolt-24GB/`) claims 83.99 TPS (AIPerf SPEED-Bench-Coding) and 84 TPS (RTX Spark) with LiLiCorr speculative decoding, and end-to-end replay duration of 600.80 seconds (AA-AgentPerf Local). Independent sources (`https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB`) describe 84 TPS as a target. Independent review (`https://www.xda-developers.com/i-tested-nvidias-nemotron-35-bolt-and-it-changed-what-i-thought-my-16gb-gpu-could-do/`) confirms it runs on a 16GB GPU (with quantization and appropriate configuration), confirming the memory efficiency claim. Independent Benchmark Atlas / Artificial Analysis does not explicitly list speed/latency for Nemotron Bolt specifically, but closest references confirm it is fast for its memory footprint. No significant conflict — the speed/inference claims are consistent with the architecture description and independent deployment verification.

4. **Vision / multimodal claims: official specs vs. independent vision benchmarks.** Official specs confirm text + image + video input (`https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB`, `https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-BF16`). Independent vision benchmarks (`https://benchmarklist.com/models/nvidia-nemotron-3.5-bolt-74b-a9b/`): WebArena (vision) 50.9% (independent measured); closest comparison with parent model shows visual capabilities inherited from Super 3.5 VL (`https://research.nvidia.com/labs/nemotron/Nemotron-3.5-Bolt-24GB/`). Independent Benchmark Atlas (`https://atlas.kevinhu.io/models/nemotron-3-5-bolt-74b-a9b`) does not break out vision-specific scores separately beyond MMMU-Pro / AI2D_TEST proxies (not explicitly listed). Independent MindStudio review (`https://mindstudio.ai/blog/nvidia-nemotron-3-5-bolt-benchmark-test`) confirms near-perfect vision reasoning (9/9 correct tracking of laptop location through multi-character story) and correct scientific reasoning with hand-drawn circuit diagram, confirming vision capability is real and effective for reasoning tasks, though coding reliability is weaker. Independent review (`https://kompozy.io/reviews/nemotron-3-5-bolt-benchmark-test`) notes weaker coding but good vision/reasoning — consistent with independent benchmark scores. No significant numerical conflict between vision claims and independent verification; the vision encoder (C-RADIO v4-H) is verified by official architecture description and independent vision reasoning tests confirm it works for complex reasoning tasks.

5. **Status / lifecycle note.** The official NVIDIA research/blog (`https://research.nvidia.com/labs/nemotron/Nemotron-3.5-Bolt-24GB/`) describes it as a new release (October 2026). Independent BenchmarkList (`https://benchmarklist.com/models/nvidia-nemotron-3.5-bolt-74b-a9b/`) and Benchmark Atlas confirm it is active and available. No deprecation status is mentioned (unlike Mistral Medium 3.5). The model is intended for local deployment rather than cloud API, which explains the absence of cloud pricing and the open-source (OpenMDW-1.1) license.
