## Model card

- **Name:** Nemotron 3.5 Bolt 74B-A9B (24GB)
- **Short description:** NVIDIA's **October-2026 open-weight hybrid Mamba-Transformer MoE (74B total / 9B active)** — a **vision-language local agent** "designed to run everyday agentic tasks locally on NVIDIA RTX/DGX Spark," **fitting in 24GB at ≥80 TPS**. It is **compressed from Nemotron 3.5 Super VL (120B/12B)** via NVIDIA's Star Elastic framework and **aggressively 2-bit quantized (IQ2_XXS, 2.0625 bpw)** with quantization-aware distillation, plus a **LiLiCorr** speculative drafter → **84 TPS**. NVIDIA reports it is **#1 on PinchBench, #2 on WebArena, #2 on BrowseComp** among similar-memory-footprint models, and beats **Qwen3.6 35B-A3B / Gemma 4 26B-A4B** on agentic/web/terminal tasks. ⚠ **AA has no Intelligence Index / Speed / Cost for it — "No publicly available API"** (it is a local/self-host model), so all benchmarks are **vendor or leaderboard placements**. Coding evidence is **thin**: **Terminal-Bench 2.1 50.98%**, but **no SWE-bench, LiveCodeBench, or DeepSWE** figure exists.
- **Provider / access:** **Open weights (OpenMDW-1.1)** — self-host $0; checkpoints on Hugging Face `nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB` (24GB IQ2, BF16, GGUF, + LiLiCorr drafter), also via **NVIDIA NIM**. **No public per-token API and no free hosted tier id** (`noFreeId: true`) — which is exactly why AA cannot index it.
- **Release / knowledge:** Released **October 15, 2026** (AA: October 2026) — **current**. Technical report: arXiv `2610.33039`. No knowledge-cutoff published.
- **IDs:** `nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB`; AA `nemotron-3-5-bolt-74b-a9b`; parent `Nemotron 3.5 Super VL` (120B/12B).
- **Context window:** **262,144 (256K)** — AA lists 262k (~393 A4 pages). Generous for a local 24GB model.
- **Modalities:** **Text + image in → text out** — a **vision-language model (VLM)**, confirmed by AA ("text and image"), NVIDIA ("regain lost vision functionality"), and multiple mirrors (modelscope/hostyourai/arXiv "A Hybrid Vision…"). ⚠ **Meta claims "text, image, video in," but neither AA nor the NVIDIA page confirms *video* for this SKU** — I score on the confirmed text+image and flag video as unverified (the parent Super VL may do video; this compressed Bolt is not documented as such).
- **Pricing (as of 2026-10-28):** **$0 self-host (OpenMDW-1.1 open weights)** — no per-token list price; the value proposition is running frontier-shaped agentic capability on a **single 24GB desktop GPU** (RTX/DGX Spark) at **~84 TPS**, with no API dependency.
- **Architecture:** Open-weight **Mixture-of-Experts hybrid Mamba-Transformer (Mamba-2), 74B total / 9B active per token**, **OpenMDW-1.1**, **reasoning**-capable. **Compressed** from the 120B/12B Nemotron 3.5 Super VL via **Star Elastic** (router-guided architecture search; expert top-K cut 22→9), then **2-bit IQ2_XXS quantization** (Mamba layers NVFP4; embeddings/attention/Latent-MoE Q8_0) recovered by **quantization-aware distillation (QAD)**; **LiLiCorr** drafter (1.13B) gives mean acceptance 4.68 (greedy). The **IQ2 24GB build trails the BF16 checkpoint on every quality row** (meta tradeoff).

### Normalized scores (1–100)

- **Tool use: 78/100.** This is the model's raison d'être — "run **everyday agentic tasks locally**," with NVIDIA-reported **#1 PinchBench, #2 WebArena, #2 BrowseComp** among similar-footprint models, a vision lane for GUI/web agents, and **Terminal-Bench 2.1 50.98%**. Genuinely strong *for a 24GB local agent*, and it beats Qwen3.6 35B-A3B / Gemma 4 26B-A4B on agentic/web/terminal. Held below the 80+ agentic specialists by: **all vendor/leaderboard-relative evidence** (a memory-footprint-restricted peer set, not open-field), **no AA Index** (no AutomationBench/Briefcase measurement), the **2-bit IQ2 quant**, and thin absolute corroboration. Strong-local-agent band.
- **Reasoning: 74/100.** **Reasoning-capable** and compressed from the 120B/12B Super VL parent, so the architecture is "frontier-shaped" — but there is **no AA Intelligence Index** (no public API), **no GPQA/HLE/math** figure published, and the **IQ2 24GB build trails BF16 on every quality row**. With only a **9B-active** budget at **2-bit** precision and no neutral intelligence measurement, reasoning evidence is thin and the ceiling modest. Conservative small-active/quantized band pending independent measurement.
- **Context window: 78/100.** **262,144 (256K)** — AA-confirmed, and generous for a model that fits in 24GB (the hybrid Mamba attention is memory-efficient at length). Solidly above the 200K tier, below 400K/1M. The 256K/262K band; no long-context effectiveness benchmark (MRCR/RULER) published.
- **Multimodal: 78/100.** A **vision-language model** with **text + image confirmed** (AA + NVIDIA + mirrors) — vision is core to its local web/GUI-agent niche. Scored at the **image-only-verified tier** because **video is NOT confirmed** for this SKU (meta claims it; AA says "text and image"; NVIDIA documents regaining "vision functionality" without specifying video). No audio. Were video confirmed it would reach the 82 native-video tier — flagged, not credited.
- **Coding: 73/100.** **Thin**: the only coding-accuracy figure is **Terminal-Bench 2.1 50.98%** (moderate — well below the 67–82% of the text-only coding leaders), and the meta tradeoff is explicit that "**no SWE-bench, LiveCodeBench or DeepSWE figure exists.**" The AIPerf SPEED-Bench-Coding 83.99 is a *throughput* metric, not accuracy. Respectable terminal coding for a local 24GB model, but the absence of any repo-scale/competitive-programming harness caps it in the thin-evidence band.
- **Cost efficiency: 93/100.** The defining strength: **open weights (OpenMDW-1.1), $0, running frontier-shaped agentic capability on a single 24GB desktop GPU (RTX/DGX Spark) at ~84 TPS** — no API, no per-token cost, no datacenter. Among the best local/self-host value in the dataset (a 74B-total MoE that a consumer can actually run). The 2-bit quant is precisely what buys this footprint. Not counted toward Overall.
- **Overall Score: 76/100.** Mean of Tool 78 + Reasoning 74 + Context 78 + Multimodal 78 + Coding 73 = 381 / 5 = 76.2 → 76. Best fit: **the 24GB local vision-language agent** — an open-weight **74B/9B-active hybrid Mamba-Transformer MoE**, 2-bit-quantized from Nemotron 3.5 Super VL, that **runs everyday agentic/web/terminal tasks on a single desktop GPU at ~84 TPS with 256K context and vision input**, and posts **#1 PinchBench / #2 WebArena / #2 BrowseComp** among similar-footprint peers — but with **no AA Index (no public API)**, **thin coding evidence (only Terminal-Bench 2.1 50.98%; no SWE-bench/LiveCodeBench)**, an **IQ2 build that trails BF16**, and **video unconfirmed** despite the meta's claim. Ideal for **private/local, cost-sensitive vision+web+terminal agent workloads on consumer hardware**; **use Nemotron 3.5 Super VL (the BF16 parent) or an API-indexed model when absolute quality or independent verification matters**. **Divergence note:** curated queue 73.1 vs my 76 → **+2.9**. I credit the **exceptional local cost efficiency (93, uncounted)**, the **strong size-relative agentic/web results (Tool 78)**, the **confirmed VLM + 256K (Multimodal 78, Context 78)**, and its **current, genuinely-distinct open-weight artifact**; the curated score leans harder on the **thin/independent-unverified evidence** (no AA Index, no SWE-bench/LiveCodeBench, IQ2-trails-BF16), which I reflect in Reasoning 74 and Coding 73 but which don't fully offset its local-agent value. Lands **level with the deprecated Gemini 2.0 Flash / Claude Haiku 4.5 neighborhood (76)** — a very different (current, local, open-weight VLM) route to the same score.
