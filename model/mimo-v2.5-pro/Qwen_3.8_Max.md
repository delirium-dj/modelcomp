## Model card

- **Name:** MiMo-V2.5-Pro (Reasoning)
- **Short description:** Xiaomi's **April-2026 MIT open-weight 1.02T-total / 42B-active hybrid-attention MoE (1M, text-only)**, pitched as a **long-horizon agent + coding** flagship: "our most capable model to date," able to "sustain complex, long-horizon tasks spanning more than a thousand tool calls" (SysY compiler in Rust: 672 calls / 4.3 h / 233-233; a video editor: 1,868 calls / 11.5 h / 8,192 LOC). Its headline is **token efficiency** — **ClawEval Pass³ 64% at ~70K tokens/trajectory, "40–60% fewer tokens than Claude Opus 4.6, Gemini 3.1 Pro, and GPT-5.4"** at comparable capability — plus **top instruction-following discipline** (IFBench 79.9%). AA gives a **full-4/4-unit Intelligence Index 26 (#29/122, above the open-weight Large-class median 19)**. ⚠ **Deprecated** — superseded by **MiMo-V2.6-Pro** (AA banner), which jumps to **AA Index 46.32**. **Text-only** — the omni-modal sibling is the separate **MiMo-V2.5** (and the retired free omni tier, report 81).
- **Provider / access:** **Xiaomi API Platform / AI Studio** (`mimo-v2.5-pro`) and **OpenRouter** (`xiaomi/mimo-v2.5-pro`); **self-host $0 (MIT)** — weights on Hugging Face `XiaomiMiMo/MiMo-V2.5-Pro`. **No free hosted tier id** (`noFreeId: true`). AA: "reasonably priced when comparing to other open weight models of similar size" ($0.15 per Index task). Natively integrated with Claude Code, OpenCode, Cline, OpenClaw.
- **Release / knowledge:** Released **April 2026** (announced **April 22–23**, open-sourced **April 27, 2026**). **Deprecated** — Xiaomi's successor **MiMo-V2.6-Pro** (Sep 2026) is the recommended model; AA only continues the default 10k-token workload. Predecessor: MiMo-V2-Pro (which appeared anonymously on OpenRouter as "Hunter Alpha").
- **IDs:** `xiaomi/mimo-v2.5-pro`; OpenRouter `xiaomi/mimo-v2.5-pro`; HF `XiaomiMiMo/MiMo-V2.5-Pro`; AA `mimo-v2-5-pro` (reasoning variant; a non-reasoning variant may exist).
- **Context window:** **1,000,000 (1M)** — AA lists 1M (~1500 A4 pages); the **MiMo-V2.5-Pro-Base** checkpoint is **256K**, the instruct model extends to 1M via the hybrid-attention design (meta: "1M (Base 256K)").
- **Modalities:** **Text in → text out** (AA-confirmed) — **strictly text-only**, matching meta. The image/audio/video lane is the separate **MiMo-V2.5** omnimodal model, not this Pro tier.
- **Pricing (as of 2026-10-27):** **~$0.41–0.435 / $0.87–1.02** per 1M in/out (AA: $0.413/$1.02, 97% cache, $0.0036 cached read, $0.15/task; meta FP8 route $0.435/$0.87) — "moderately priced" per AA; **Token Plan** uses a 2× credit multiplier; **$0 self-host (MIT)**, though a 1.02T checkpoint needs a large multi-GPU (H200/B200) cluster.
- **Architecture:** Open-weight **sparse MoE, 1.02T total / 42B active per token**, **MIT License**, **reasoning** variant. **Hybrid attention** inherited from MiMo-V2-Flash: **Local Sliding-Window Attention : Global Attention interleaved 6:1** (128-token window) cuts KV-cache ~7× at long context, plus a **Multi-Token-Prediction (MTP)** module that ~triples output throughput. Pre-trained on **27T tokens** (FP8, native 32K → extended 1M); post-trained via a 3-stage paradigm (SFT → domain-specialized RL teachers → **Multi-Teacher On-Policy Distillation**). 51.4 tok/s (#62/78, "notably slow"), **fairly concise** (110M output tokens per Index run vs median 140M).

### Normalized scores (1–100)

- **Tool use: 80/100.** This is the model's core pitch — **long-horizon agentic work spanning 1000+ tool calls** (SysY compiler 672 calls / 233-233; video editor 1,868 calls), vendor **τ²-Bench 94.2% / τ³-Bench 72.9%**, **ClawEval Pass³ 64%**, **IFBench 79.9%** (instruction-following inside agentic loops), and noted "harness awareness." Strong agentic posture, but **all vendor-reported** (no independent agentic harness), **AA Index 26 is only middling** for the class, **deprecated**, and **text-only** (no visual GUI/computer-use). Strong-but-vendor-only band; below the independently-verified GLM-5.2 (Tool 82).
- **Reasoning: 79/100.** **AA Index 26 (full 4/4 units, #29/122) is "well above average"** for the open-weight Large class (median 19), and **GPQA Diamond 86.6%** is a strong knowledge signal — but the absolute Index is **modest** (below the Index-34 siblings GLM-5.2 / DeepSeek V4 Flash, and far below its successor **MiMo-V2.6-Pro's 46.32**), and **HLE is discrepant** (33.8% vendor vs 48.0% meta — I credit the lower). Above-median, capped by deprecation and a below-frontier Index. Two points below the Index-34 band.
- **Context window: 85/100.** **1M tokens**, and unusually well-evidenced for real long-context effectiveness: the **hybrid SWA:GA (6:1) attention cuts KV-cache ~7× "while preserving performance,"** and Xiaomi demonstrates coherent **1000+ tool-call** trajectories (GraphWalks/BFS long-context tests) rather than just a nominal window. The 1M-proven tier, level with GLM-5.2 / DeepSeek V4 Flash. No published MRCR/RULER figure keeps it at 85 rather than higher.
- **Multimodal: 50/100.** **Strictly text-only** (AA + meta confirmed: text in → text out). The hard text-only floor and this SKU's defining limitation — the omni-modal capability lives in the **separate MiMo-V2.5** line, not here. Vision/audio require a different model.
- **Coding: 80/100.** Vendor grid is frontier-competitive: **SWE-bench Pro 57.2%** (≈ GPT-5.4's 57.7%, ahead of Opus 4.6's 53.4%), **SWE-bench Verified 78.9%** (meta), **MiMo Coding Bench 73.7%** ("closing the gap to Opus 4.6"), **TerminalBench Hard 43.2%**, **SciCode 50.2%**. Strong coding claims — but **entirely vendor-reported** (no independent Vals/swebench verification), and **deprecated**. Held below the independently-verified GLM-5.2 (Coding 85, Vals SWE-bench Verified 82.80% #1-open-weight); strong-vendor + partial Index corroboration band.
- **Cost efficiency: 88/100.** **MIT open-weight → $0 self-host** in principle, a **moderately-priced API** (~$0.41/$1.02, $0.15/task, 97% cache), and — the real multiplier — **exceptional token efficiency (40–60% fewer tokens than the frontier at comparable capability)**, which the AA concision (110M) independently corroborates. Strong value for high-volume agentic coding. Capped below the 92–95 bargains by the **impractical 1.02T self-host footprint** and mid-tier (not rock-bottom) API price. Not counted toward Overall.
- **Overall Score: 75/100.** Mean of Tool 80 + Reasoning 79 + Context 85 + Multimodal 50 + Coding 80 = 374 / 5 = 74.8 → 75. Best fit: **the token-efficient long-horizon agent MoE** — a 1.02T/42B-active MIT text-only model built for **1000+ tool-call autonomous coding at 40–60% lower token cost than the frontier** (ClawEval Pass³ 64%, SWE-bench Pro 57.2% ≈ GPT-5.4, τ²-Bench 94.2%, IFBench 79.9%), with a proven 1M context and a full-4/4-unit **AA Index 26 (#29/122)** — but **strictly text-only (Multimodal 50)**, **notably slow (51 tok/s)**, **all benchmarks vendor-reported**, and **deprecated → MiMo-V2.6-Pro (Index 46.32)**. Ideal historically for **cost-sensitive, high-volume, long-horizon text coding/agent pipelines with open-weight/MIT requirements**; **use MiMo-V2.6-Pro for the live, far-higher-scoring successor**, or the omni MiMo-V2.5 for vision/audio. **Divergence note:** curated queue 73.8 vs my 75 → **+1.2**. I credit the **proven 1M context (85)**, the **strong vendor agentic/coding grid (Tool 80, Coding 80)**, and the **above-median AA Index 26 (Reasoning 79)**; the **text-only Multimodal floor (50)**, slow speed, vendor-only verification, and deprecation hold the mean down — landing close to the curated value. Sits **two below its text-only sibling-in-spirit GLM-5.2 (77)** and **one below DeepSeek V4 Flash (76)**, whose higher AA Index (34) and (for GLM) independent Vals coding edge out MiMo's vendor-only numbers.
