## Model card

- **Name:** MiniMax M3
- **Short description:** **Shanghai-based MiniMax's open-weight frontier coding/agent model** (released **2026-06-01**), pitched as *"the first open-weight model to combine frontier-level coding, a 1M-token context window, and native multimodality (text, image, video) in one system."* It is a **428B-parameter sparse MoE (~22-23B active/token)** on a Grouped-Query-Attention backbone with **MiniMax Sparse Attention (MSA)** — block-level selection over *uncompressed* KVs that MiniMax reports cuts long-context per-token compute to **~1/20** of the prior generation (**~9.7× faster prefill, ~15.6× faster decode vs M2**), which is the real engineering story: it makes the huge window *economically usable* in an agent loop. Coding claims are strong — **SWE-bench Pro 59%** (framed as the **first open-weight model to clear 59%**, beating GPT-5.5 and Gemini on that board) and **SWE-bench Verified 80.5%** — at dramatically low cost. ⚠ **The decisive caveat: every benchmark is vendor-reported** (run on MiniMax infra, reportedly with Claude Code scaffolding) and **M3 had not yet appeared on neutral boards like DeepSWE**, so its standing vs the newest closed releases is *"genuinely unproven."* Weights are under the **non-standard MiniMax Community License** (not Apache/MIT). **[2026-11-02: the "not yet on neutral boards" caveat is resolved — MiniMax-M3 is now on AA (reasoning version, Intelligence Index 19, #15/23 below-average) and BenchLM (#108/1004, non-reasoning variant). The neutral read is mixed-to-adverse: strong GPQA 92.9 / AA-LCR 83.0, but a 91.4% Omniscience hallucination rate, CritPt 3.7, AA Agentic Index 30.8 and Vals SWE-bench 75.0 (below the vendor 80.5).]**
- **Provider / access:** **MiniMax** (Shanghai). **Open weights on Hugging Face** (`MiniMaxAI/MiniMax-M3`; technical report arXiv:2606.13392) + MiniMax platform API + OpenRouter (12 providers). **Paid only** (`noFreeId`). Self-hosting is **server-class** (~214GB+ at 4-bit → multiple high-memory GPUs; NVIDIA has published deployment guidance) — not a laptop model. First-party agent product **MiniMax Code** uses a **Producer + Verifier** self-correction loop.
- **Release / knowledge:** Released **2026-06-01**. Knowledge cutoff not stated in the sources reviewed.
- **IDs:** `minimax-m3` / `minimax-ai/minimax-m3` (line: M2.5 < M2.7 < **M3** < M3.1-flash-preview).
- **Context window:** **"Up to 1,048,576 (1M) tokens, with a minimum of 512K guaranteed"** (the official framing is a ceiling, not a flat 1M) and a **very large 512K max output** — the highest output cap in this dataset. MSA is what makes the window economically usable rather than a spec-sheet number. **[2026-11-02: AA confirms the 1M context window as native, and neutral AA-LCR 83.0 validates long-context reasoning quality at depth — the two discounts the draft applied (ceiling-not-guaranteed + unverified MSA) are resolved → Context 89 → 90.]**
- **Modalities:** **Text, image, video in → text out** (native multimodality; no audio, text-only output). No dedicated multimodal/vision benchmark was published in the sources reviewed. **[2026-11-02: AA's authoritative spec CONFIRMS text + image + video input; a neutral AA-MMMU-Pro 78.6 now exists and vendor VideoMMMU 84.6 / Video-MME 85.4 back the video path → Multimodal 80 → 82.]**
- **Pricing (as of 2026-10-23):** **meta.json lists a $0.30 / $1.20 per 1M promo**; MiniMax's **standard API rate is $0.60 / $2.40** (the launch-week half-price promo has likely expired — **verify the current rate card**). Either way it is a **fraction of Claude Opus / GPT-class pricing** (~5% of Opus cost per task per one review), and self-hosting removes per-token cost entirely (for compute). Promotional pricing + lighter enterprise support = fewer deployment guarantees.
- **Architecture:** **428B sparse Mixture-of-Experts, ~22-23B active/token**, Grouped-Query Attention + **MiniMax Sparse Attention (MSA)** — block-level pre-filtering on real, uncompressed key-values (a different bet from KV-compression approaches that trade long-context precision). Supports claimed **8+ hour autonomous coding sessions** and tool-calling/function invocation as core capabilities.

### Raw benchmarks found

Coding / agentic (MiniMax **vendor-reported**, run on MiniMax infra with Claude Code scaffolding; **not yet neutral-board-verified**):

- **SWE-bench Pro: 59.0%** — framed as the **first open-weight model to clear 59%**, ahead of GPT-5.5 and Gemini on that board (ofox.ai / mindstudio / datanorth coverage)
- **SWE-bench Verified: 80.5%** (meta.json; for context, Claude Sonnet 5 = 82.1%, MiMo-V2.6-Flash = 92.0%, Ember-1 = 92.2%, Claude Opus 5 = 97.0%)
- **MCP Atlas (tool use): 74.2%** — vendor-reported
- Also cited: **Terminal-Bench** and **BrowseComp** results (vendor-reported; absolute figures not consistently transcribed)
- **MSA efficiency (vendor-reported):** ~1/20 long-context per-token compute vs prior gen; ~9.7× faster prefill, ~15.6× faster decode vs M2

### Normalized scores (1–100)

- **Tool use: 82/100.** [2026-11-02: neutral read landed; trimmed for adverse agentic cells.] Purpose-built for the agent loop (MCP Atlas 74.2%, Producer+Verifier, 8+ hour sessions), and neutral **τ²-bench 88.9** + **Harvey LAB-AA 88.4** corroborate real tool competence. But the neutral agentic picture is otherwise weak — **AA Agentic Index 30.8, GDPval-AA 37.1, OSWorld 2.0 4.6, MazeBench 0**, and **Vals Terminal-Bench 53.6 vs the vendor's 66.0** — so the vendor table overstates it. Trimmed 84 → 82: competent on the harnesses it likes, unremarkable on the neutral composites.
- **Reasoning: 80/100.** [2026-11-02: neutral read landed; trimmed −3 on a severe adverse signal.] The draft inferred reasoning depth from vendor SWE-Pro because nothing neutral existed; now there is, and it is **split**. Genuinely strong: **AA-GPQA-Diamond 92.9 / Vals 92.7, MMLU-Pro 84.2, AA-LCR 83.0, AA-HLE 39.0**. Adverse: **AA Intelligence Index 19 (#15/23, below average)**, **CritPt 3.7**, and — decisively — **AA-Omniscience Net −5.5 with a 91.4% hallucination rate (Accuracy 44.9)**. A model that answers hard science well but fabricates at a very high rate is not an 83-reasoner. Trimmed 83 → 80.
- **Context window: 90/100.** [2026-11-02: verified; lifted +1.] A genuine standout — **1M tokens (512K guaranteed min) + 512K output**, and the **MSA** architecture that makes it economical. The draft discounted for "ceiling-not-guaranteed + no recall benchmark"; **AA now confirms the 1M window as native and AA-LCR 83.0 independently validates long-context reasoning quality at depth** — both discounts lift. Lifted 89 → 90; still off the very top because the MSA efficiency figures remain vendor-reported.
- **Multimodal: 82/100.** [2026-11-02: reversal — draft UNDER-reported for lack of a benchmark.] Native **text + image + video → text** — and the draft capped it at 80 specifically because *no vision benchmark was published*. **AA now confirms video input in its authoritative spec, and a neutral AA-MMMU-Pro 78.6 landed** (vendor VideoMMMU 84.6 / Video-MME 85.4 / OmniDocBench 91.6 back the video/doc path). Lifted 80 → 82. Still below the omni tier because there is **no audio and text-only output**.
- **Coding: 84/100.** [2026-11-02: neutral read landed; trimmed −2.] The headline strength on the vendor table (**SWE-Pro 59**, **SWE-V 80.5**, "first open-weight over 59%"). Neutral harnesses confirm *solid, not frontier*: **Vals SWE-bench 75.0** (below the vendor 80.5), **LiveCodeBench (Vals) 82.2** (good), but a modest **AA Coding Index 58.6** and AA-SciCode 47.1 — well below the peers this draft scored 86 on stronger neutral cells. Trimmed 86 → 84.
- **Cost efficiency: 95/100.** The other standout — **$0.30/$1.20 promo (or $0.60/$2.40 standard)** is a **fraction of closed-frontier pricing (~5% of Opus per task)**, MSA makes long-context calls ~1/20 the compute, and **open weights let you self-host to remove per-token cost entirely**. The best value proposition among frontier-claimed coding models. Minor caveats: promotional pricing may expire (verify the rate card), self-hosting needs server-class hardware (~214GB+ at 4-bit), and the non-standard license adds compliance friction. Scored but **not** counted in the Overall per methodology.
- **Overall Score: 84/100.** [2026-11-02: neutral-verified — holds.] Mean of Tool 82 + Reasoning 80 + Context 90 + Multimodal 82 + Coding 84 = 418/5 = 83.6 → 84. Best fit: **long-context, cost-sensitive, self-hostable coding-agent work** — large-repo migrations, multi-file reasoning and high-volume agent loops where the MSA-economical 1M window, open weights (data residency) and ~5%-of-Opus cost address needs the closed API models structurally can't. **Hold off** if you require neutral-board-verified performance before procurement, need a locally-runnable model, or want the most proven closed-frontier quality. Independent read: my **84 sits below the queue's curated 86.6** — the discount is driven by the **entirely vendor-reported, neutral-board-unverified** benchmark picture (verdent's central caution), the **non-standard license**, the **1M-is-a-ceiling** context nuance, and **SWE-V 80.5% below the 92% open-weight peers**, weighed against genuinely excellent context economics, multimodal input and best-in-class cost. Internally consistent: M3 (84) clusters with the other open-weight/efficiency value plays I've scored (ember-1 84, mimo-v2.6-free 84) and sits just below claude-sonnet-5.4 (85) and muse-wonder-1.0 (85), which have family-anchored or independent (AA) verification M3 lacks — an accurate portrait of a compelling but not-yet-independently-proven open-weight wildcard. **[2026-11-02: the neutral read HOLDS at 84 but for a different reason — the trims to Reasoning −3 (Index 19 below-average, 91.4% hallucination), Tool −2 (AA Agentic 30.8 / OSWorld 2.0 4.6 / MazeBench 0) and Coding −2 (Vals SWE-bench 75.0, AA Coding Index 58.6) are offset by Context +1 (AA-confirmed 1M + AA-LCR 83.0) and Multimodal +2 (video AA-confirmed + neutral MMMU-Pro 78.6). My 84 sits well below the queue's curated 87.3 (the draft's "86.6" was stale). M3 is now proven, and what it's proven to be is a cheap, huge-context, video-capable open coder with below-average independent intelligence and a serious hallucination problem.]**
