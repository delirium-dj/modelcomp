## Model card

- **Name:** Muse Spark 1.2. Proprietary, no open weights (Meta's open-weight local sibling is **Muse Glimmer**). Variant/alias flag: **the "Contributor" and "Free"/"Max" wordings are pricing and effort tiers of this one model, not separate models** — Meta serves a lower-priced **`muse-spark-1.2-contributor`** SKU whose data may be used to improve Meta products, alongside the standard SKU. Superseded by **Muse Spark 1.3** (2026-09-02), which Meta reports completes coding workflows with ~20% fewer tool calls and ~25% fewer tokens on identical tasks.
- **Short description:** Meta's coding-focused update to Muse Spark 1.1, released **2026-08-05** — Meta's third release in four months (1.0 in April, 1.1 in July, 1.2 in August) — and launched **alongside Muse Code (beta)**, a terminal coding agent that Meta **co-trained with the model specifically so the two perform best as a pair**. Meta states it significantly scaled up coding-task training compute and training-environment diversity relative to 1.1 while maintaining general agentic strength.
- **Provider / access:** **Meta Model API** (`muse-spark-1.2`, with expanded global access at launch), the discounted `muse-spark-1.2-contributor` SKU, **OpenRouter** (`meta/muse-spark-1.2`, 3 providers tracked), and **Muse Code (beta)** — installed via `curl -fsSL https://dev.meta.ai/install.sh | bash`. Muse Code is unusually well specified for a launch harness: a simple agent loop plus **persistent async background agents that stay active for the whole session rather than being spawned per task** (they carry out next steps and choose when to report back, reducing redundant information-gathering and steering overhead on long tasks), an **append-only local event log for every model call, tool run, approval and edit — making sessions replay-exact and restart-safe after a crash**, and bundled skills `/plan`, `/grill` and `/goal`.
- **Release / knowledge:** Released 2026-08-05. **Knowledge cutoff: no verified public figure found.**
- **IDs:** `muse-spark-1.2` (Meta Model API), `muse-spark-1.2-contributor` (discounted, data-use-conditioned), `meta/muse-spark-1.2` (OpenRouter). **No `$0` tier** — Contributor is a data trade, not a free tier.
- **Context window:** **1,048,576 tokens (1M)**, retained unchanged from Muse Spark 1.1 and corroborated by Artificial Analysis, OpenRouter, LLM Stats and CloudPrice. (One model-card aggregator lists context as "Undisclosed", which contradicts four independent sources and is treated as an error.) Max output: no verified public figure found. **Context compaction was an explicit training objective** rather than a serving trick — see Architecture.
- **Modalities:** Input: **multimodal — text, images, audio and video** per Meta's own developer catalogue and two independent trackers; **one specification aggregator lists "text and vision" only**, so audio and video ingestion is well-attested but not unanimously documented. Output: text only. Reasoning: yes, with an explicit reasoning mode and effort levels up to **`xhigh`** (Meta's own benchmark runs used xhigh). Tool calls: yes, and this is the model's standout capability. JSON mode: not separately documented in the sources checked.
- **Pricing (as of 2026-10-03):** **$1.25 / 1M input, $0.15 / 1M cached input, $4.25 / 1M output** — **unchanged from Muse Spark 1.1**, so the capability gain arrived free. The **Contributor tier runs at roughly $0.10 / $0.20** in exchange for Meta being permitted to use prompts and completions to improve its products. Artificial Analysis measured the practical figure: **$0.40 per Intelligence Index task**.
- **Architecture:** Proprietary; **parameter count and architecture are undisclosed**. What Meta does disclose is the training recipe, and it is specific: co-training with Muse Code used **rejection-sampled harness trajectories** plus recipe optimisations for **goal-setting, context compaction and subagent coordination**, with the full Muse Code toolset integrated for harness compatibility. The model was extensively trained on **long-horizon coding — whole-repository generation, large end-to-end projects and auto-research workflows** — using planning to sequence work, goal conditioning to hold direction, and context compaction to sustain progress across long sessions. A **self-improvement loop used Muse Spark 1.1 to generate challenging coding environments and instruction-following templates, then graded candidate solutions against those requirements**, producing additional training data that improved precise instruction-following. Case study evidence of the long-horizon claim: the model **iteratively optimised GPU kernels (KDA and MLA) on NVIDIA Hopper GPUs over 1,000+ tool calls and up to 24 hours**, achieving substantial speedups over baseline Triton implementations **without being allowed to import third-party kernel libraries**.

### Raw benchmarks found

> Three provenances, kept separate. **(AA)** = Artificial Analysis's independent launch-day evaluation at xhigh effort — Meta gave AA pre-release access for benchmarking, and AA's GDPval figures use its own **Stirrup** harness with shell access and web browsing in an agentic loop. **(Meta)** = Meta's release-blog figures, with Terminal-Bench 2.1 and DeepSWE 1.1 run **through Muse Code at xhigh effort in Meta's internal framework using isolated Daytona cloud sandboxes**, and MCP Atlas run in **Scale AI's own harness**. **(G)** = Muse Spark 1.2's column in Google DeepMind's August 2026 Gemini 3.7 Flash model card, verified earlier in this session. An important caveat carried from the source set: **Meta's evaluation setup may not be tuned for third-party proprietary models, so its competitor figures may understate their best achievable performance** — Meta's own numbers, run in its native harness, are the more reliable read on this model.

Agent / tool use:

- **MCP Atlas: 90.3% (Meta)** — **the highest score of any model in Meta's comparison set, including Claude Opus 5 run at xhigh (85.8%)**, ahead of Gemini 3.5 Flash (83.6%), Claude Fable 5 (83.3%), Kimi K3 (82.3%) and GPT-5.6 Sol (81.8%). Up from Muse Spark 1.1's 88.1%. MCP Atlas covers **36 real MCP servers and 220 tools**, and the result came from Scale AI's harness rather than Meta's.
- **Terminal-Bench v2.1: 80% (AA, independent)** / **82.9% (Meta, via Muse Code at xhigh)** — up from 1.1's 78% (AA) and 76.2% (Meta). **Trails Claude Opus 5 at max effort with Claude Code (86.7%)** but edges GPT-5.6 Terra (81.8%) and Grok 4.5 (81.6%). Google's table also records 82.9%.
- **τ³-Banking: 27% (AA)** — up 2 points from 1.1's 25%. This sits in the methodology's **mid band (Tau3 ~10–25%)** and far below the ~50%+ frontier reference; it is the clearest agentic weakness.
- **GDPval-AA v2: 1,631 Elo (AA / Meta / 1,628 in Google's table)** — **#5 among all models Artificial Analysis has benchmarked**, up **260 Elo** from Muse Spark 1.1's 1,371, and **ahead of Claude Opus 4.8 at max (1,588)**. Behind Claude Opus 5 (max, 1,852), GPT-5.6 Sol (max, 1,730) and Kimi K3 (max, 1,685). Just under the methodology's ~1750+ frontier reference.
- Claw-Eval / ClawProBench: no verified public score found
- Toolathon / SWE Atlas Codebase QnA: no verified public score found
- OSWorld / AutomationBench: no verified public score found

Reasoning / knowledge:

- GPQA Diamond: **no verified public score found**
- **HLE: 44% (AA)** — down 1 point from 1.1's 45%; above the methodology's 40%+ frontier reference.
- LCR / MLCR / MRCR: no verified public score found
- **CritPt: 18% (AA)** — up 3 points from 1.1's 15%. A rare published CritPt figure (research-level physics reasoning).
- **Artificial Analysis Intelligence Index: 54 at xhigh (AA)** — up 3 from Muse Spark 1.1 (51) and 11 from 1.0 (43, April). **Effectively tied with GPT-5.5 (xhigh, 55) and Grok 4.5 (high, 54)**, narrowly behind Kimi K3 (max, 57), GPT-5.6 Sol (max, 59), Claude Fable 5 (max with fallback, 60) and Claude Opus 5 (max, 61). AA framed this as putting **Meta tied for third place among US labs**. **Conflicting figure: Google's table lists 57** — a different index version/date, not interchangeable. Either way, below the 60+ frontier marker.
- **Omniscience Accuracy / Hallucination Rate (AA) — a genuine strength:** the **AA-Omniscience Index rose from 18 to 22** as the **hallucination rate fell 10 points, from 38% to 28%**. The mechanism is explicit and matters: the **attempt rate dropped from 82% to 67%** — heavy abstention — which also pulled **accuracy down from 41% to 38%**. For context, GPT-5.5 posted an 86% hallucination rate on the same benchmark. This model declines to answer when unsure, by design and for the second consecutive release.

Coding:

- **DeepSWE 1.1: 59.3% (Meta, via Muse Code at xhigh)** / **54.9% (G)** — up from 1.1's 53.0%, but **well below the methodology's 74%+ frontier reference** and trailing **Claude Opus 5 (65.0%)** and **GPT-5.6 Terra (64.8%)**; ahead of Grok 4.5 (56.6%).
- LiveCodeBench: no verified public score found
- **SciCode: 56% (AA)** — down 2 points from 1.1's 58%, but **above the methodology's 55%+ frontier reference**.
- Vibe Code Bench: no verified public score found
- **Code Arena, WebDev Elo: 1,535 (G)** — mid-table in Google's five-model comparison (Gemini 3.7 Flash 1,588, Claude Sonnet 5 1,541, GPT-5.6 Terra 1,523).
- **Meta Internal Coding Bench: 70.6% (Meta)** — an internal agentic harness over **440 tasks sourced from Meta's own codebase**. Recorded for completeness only: **no public dataset and no independently verifiable methodology**, so it carries no scoring weight.

Vision / documents:

- **GDP.pdf: 16.0% (G)** — **the lowest figure in Google's five-model table** (Gemini 3.7 Flash 34.0%, Claude Sonnet 5 28.0%, GPT-5.6 Terra 24.7%, Gemini 3.6 Flash 22.0%).
- No MMMU, CharXiv, LVBench, OmniDocBench or ASR result found.

Long context:

- **No MRCR, RULER or GraphWalks figure found** — the 1M window has no published retrieval rate.

Cost (independent, Artificial Analysis):

- **$0.40 per Intelligence Index task, near the Pareto frontier of intelligence versus cost.** Within its intelligence cluster **only Grok 4.5 (high, $0.37) and GPT-5.6 Sol (medium, $0.39) are cheaper**, while GPT-5.6 Terra (max, $0.51), Kimi K3 (max, $0.86) and GPT-5.5 (xhigh, $1.18) all cost more. The increase over Muse Spark 1.1 ($0.29) came from **input tokens up ~53% and output tokens up ~36%**, concentrated in GDPval-AA v2.

### Normalized scores (1–100)

- **Tool use: 88/100.** The standout dimension. **MCP Atlas at 90.3% is an outright win over every frontier model Meta tested — including Claude Opus 5 at xhigh — on a dedicated tool-use benchmark spanning 36 real MCP servers and 220 tools, measured in Scale AI's harness rather than Meta's own**, which removes the obvious objection. **GDPval-AA v2 at 1,631 Elo ranks #5 among every model Artificial Analysis has benchmarked**, a 260-Elo generational jump that puts it ahead of Claude Opus 4.8, and **Terminal-Bench 2.1 at 80% independently measured / 82.9% in Meta's harness** is near-frontier. The GPU-kernel case study — 1,000+ tool calls sustained over 24 hours without third-party libraries — is unusually concrete evidence of long-horizon tool use. Three deductions hold it to 88: **τ³-Banking at 27% sits in the methodology's mid band and roughly 23 points below the ~50%+ frontier reference**, GDPval is just under the ~1750+ marker, Terminal-Bench falls short of the ~88% anchor and loses to Claude Opus 5 by ~4–7 points, and **Claw-Eval, Toolathon and OSWorld/AutomationBench are all unreported** (explicit methodology penalty).
- **Reasoning: 84/100.** Two references are met — **HLE at 44% clears the 40%+ marker** and a published **CritPt figure of 18%** (up 3 points) is rare evidence on research-level physics — and the **hallucination discipline is the best in this dataset: 28%, down 10 points, against GPT-5.5's 86% and Gemini 3 Pro's 88% on the same benchmark family**. But the mechanism caps the score honestly: that 28% is bought with **heavy abstention — attempt rate down from 82% to 67% and accuracy down from 41% to 38%** — so the model is reliable because it answers less, not because it knows more. Add that the **Intelligence Index of 54 is six points below the 60+ frontier marker** and behind four frontier models, that Google's table and AA's own measurement disagree (57 vs 54) and cannot be reconciled, that **SciCode and HLE both regressed** versus 1.1, and that **GPQA Diamond and MRCR/LCR are entirely unreported**.
- **Context window: 95/100.** A verified **1,048,576-token window** places it in the ≥1M tier (95–100), and unusually the long-context engineering is documented rather than merely claimed — **context compaction was an explicit training objective** alongside planning and goal conditioning, and Muse Code pairs it with persistent session-long background agents and a replay-exact event log, which is a coherent design for sustaining very long sessions. It sits at the tier floor because the 100 condition (≥98% retrieval at 512K+) has **no supporting evidence at all** — no MRCR, RULER or GraphWalks figure exists — **max output tokens are undocumented**, and the AA cost analysis shows input token usage rising ~53% generation-on-generation, which means long sessions cost more than the headline rate implies.
- **Multimodal: 88/100.** Input is attested as **text, images, audio and video** by Meta's own developer catalogue and two independent trackers, which would place it in the methodology's top band (90–100) on audio ingestion — and the successor generation's documented modalities corroborate it. Two things pull it just below that band floor rather than to it. First, the specification is **not unanimous**: one model-card aggregator lists "text and vision" only, so audio and video ingestion is well-attested but not uncontested. Second and more decisively, **the only measured multimodal result anywhere is GDP.pdf at 16.0% — last of five models in Google's comparison, less than half Gemini 3.7 Flash's 34.0%** — with no MMMU, CharXiv, LVBench, OmniDocBench or ASR figure to offset it. Broad input with one measured result that is last in its field does not earn a top-band placement.
- **Coding: 82/100.** **SciCode at 56% clears the methodology's 55%+ frontier reference**, Terminal-Bench 2.1 at 82.9% is close to the 85%+ coding reference, and the generational gains are real across every row Meta reports (DeepSWE 53.0 → 59.3, Terminal-Bench 76.2 → 82.9). But the headline software-engineering number is the problem: **DeepSWE 1.1 at 59.3% in Meta's own harness — and only 54.9% in Google's table — is roughly 15 points below the 74%+ frontier reference**, and loses to **Claude Opus 5 (65.0%) and GPT-5.6 Terra (64.8%)**, both of which also beat it on effort-matched comparisons. Add that **SWE-bench Verified, SWE-bench Pro, LiveCodeBench and Vibe Code Bench are all absent**, that Code Arena WebDev Elo is mid-table, and that the strongest coding figure Meta offers (Meta Internal Coding Bench 70.6%) is **unverifiable by construction** — no public dataset, no published methodology.
- **Cost efficiency: 84/100.** Among the best value propositions in this dataset, and the evidence is independent rather than vendor-claimed. **$1.25 / $4.25 is far below the $3/$15 anchor**, cached input at **$0.15** is near-free for stable prefixes, and **pricing was held unchanged from Muse Spark 1.1 despite a 3-point Intelligence Index gain and a 260-Elo GDPval jump** — the capability arrived free. Artificial Analysis's measured figure confirms it: **$0.40 per Intelligence Index task, near the Pareto frontier, with only two models in its entire intelligence cluster cheaper** and Kimi K3 and GPT-5.5 costing 2.2x and 3x more. The **Contributor SKU at roughly $0.10 / $0.20** is cheaper still for anyone willing to trade data-use consent. Deductions: **cost per task rose 38% over 1.1** ($0.29 → $0.40) through ~53% more input and ~36% more output tokens, so the model got more expensive to run even at a frozen rate card; there is **no genuine $0 tier**; it is proprietary with no open-weight escape; and its own successor Muse Spark 1.3 uses ~25% fewer tokens at the same price.
- **Overall Score: 87.4/100.** Mean of the five non-cost dimensions (88 + 84 + 95 + 88 + 82) / 5 = 87.4 — the right pick for **MCP- and tool-heavy agent workloads**, where its 90.3% MCP Atlas score beat every frontier model Meta tested including Claude Opus 5 at xhigh, and for **long-horizon terminal work run through Muse Code**, where co-training, persistent background agents and a replay-exact event log make 24-hour, 1,000-tool-call sessions a documented reality rather than a claim. It is also the standout choice for **factually cautious deployments**: a 28% hallucination rate with deliberate abstention is the most reliable knowledge behaviour measured in this dataset, which matters more than raw recall in retrieval-backed systems. Do not choose it for **raw software engineering** — DeepSWE 59.3% is ~15 points off the frontier reference and loses to both Claude Opus 5 and GPT-5.6 Terra — nor for **document or PDF pipelines** (GDP.pdf 16.0%, last of five), nor for **general reasoning depth** (Intelligence Index 54, six below the frontier marker, with GPQA and MRCR unreported), nor where **unaided factual accuracy** matters, since the low hallucination rate is achieved by answering only 67% of the time. And note the succession: **Muse Spark 1.3 shipped four weeks later at the same price with ~20% fewer tool calls and ~25% fewer tokens**, so 1.2 is the right choice only for workloads already validated against it.
