> **Verdict:** Omen Alpha is an **anonymous stealth coding/agent model** that OpenCode dropped into its **Go subscription** on **4 September 2026** with almost no ceremony — no model card, no benchmark table, no named lab, just $100 of usage on the $10 plan. Third-party listings (Pi's model page) give the practical spec: **text + image input, reasoning support, a 500,000-token context window, 128,000 max output, $0.20/$0.66 per 1M** ($0.04 cached; TokenRa promo $0.08/$0.26; zero-day retention). The identity is an **open hypothesis, not a fact**: OpenCode's own public data URL files it under a **`zhipu`** path and community infrastructure-fingerprinting (tokenizer / error-code DNA / route metadata / logprob geometry) matched it closest to **GLM** (Kimi one place behind) — but no vendor has confirmed it, one widely-shared post claimed the opposite, and others guessed Grok. The **only quantitative public number** is a 2026-09-04 **OpenCode coding snapshot at 23.14/40 (~57.9%)**; everything else is qualitative. A detailed 36kr/Zhidx hands-on found it **very fast with strong vision and front-end/game/3D output but "problems in logical reasoning, prioritizing speed over intellectual performance."** It is a real, callable, distinct artifact (ranked 7th on OpenCode's call-volume leaderboard 5 days after launch) — but with an undisclosed vendor, undisclosed parameters, and near-zero hard benchmark data. Scored Overall 67 (div +1.0 vs curated 66) with low confidence.

Hands-on character: extremely fast execution, genuine image understanding, strong front-end/game/3D scaffolding, but weak deep logical reasoning ("flash-level," speed over intellect).

No downloadable weights, no confirmed license, no stable official model ID.
- **Release / knowledge:** Surfaced **4 September 2026** (OpenCode X post + a same-day Chinese-language community report by "LinearUncle"). Knowledge cutoff undisclosed. Still an alpha/stealth entry — could be experimental, internal, renamed, re-routed, or removed without notice.
- **IDs:** id `omen-alpha`; OpenCode data namespace points at `zhipu/`. **No Artificial Analysis page** (404). **Explicitly NOT confirmed to be the same system as `ox_alpha`** (the August stealth drop that Z.ai revealed as GLM-5.3-Flash) — kie.ai stresses the similar names do not establish identity, so the two are treated as distinct artifacts here.

Scored for the nominal capacity, heavily discounted for confidence.
- **Multimodal: 75/100.** **Text + image input → text output**, with image-in **verified working** by hands-on tests (recognized and structured a Republic-of-China-era newspaper image; built front-ends/plugins from screenshot references — "quite good visual capabilities"). Above documented-but-unbenchmarked, below benchmarked vision (no MMMU/quantitative vision score), and anonymous.
- **Coding: 65/100.** The core use case. The one quantitative number (OpenCode snapshot 23.14/40, ~57.9%) is mid-tier, and hands-on shows very fast, visually-strong front-end/game/3D output undercut by logic flaws and a "flash-level" (lightweight) positioning. Speed is the standout; depth is not.

(Scored but NOT counted toward Overall.)
