## Model card

- **Name:** Omen Alpha
- **Short description:** A **stealth model with a deliberately unnamed vendor**, added to **OpenCode Go** on 2026-09-04 and described in OpenCode's own announcement as a "new stealth model" — "which, in this industry, means a release whose maker is deliberately left unnamed" ([OrcaRouter](https://www.orcarouter.ai/blog/omen-alpha-stealth-model)). Its own product site positions it as a "**low-cost, privacy-first reasoning model for coding and agentic work**" at **$0.20 in / $0.66 out per MTok with 0-day data retention** ([omenalpha.io](https://omenalpha.io)). ⚠️ **The widely repeated claim that this is a Zhipu/GLM model is not established.** RankLLMs audited exactly this question on 2026-10-09 and concluded: "**GLM connection: Not established**… Is Omen Alpha confirmed to be a Zhipu GLM model? **No.**… There is no reliable public evidence in the cited model data that identifies Omen Alpha as a GLM-5.4 checkpoint or any other specific model" ([RankLLMs](https://rankllms.com/posts/omen-alpha-opencode-mystery-model-zhipu-glm/)). I therefore treat the vendor as unknown throughout and have corrected this repo's "likely GLM-family" note.
- **Provider / access:** **OpenCode Go** (the $10/month managed coding-model plan) and the **TokenRa** API route. **OpenAI-compatible Chat Completions**, model ID `omen-alpha`, endpoint `zen/go/v1/chat/completions`. Access requires a TokenRa account and API key. Privacy terms are unusually explicit and favourable: "**Prompts are not used for training, and the stated data retention is 0 days.**"
- **Release / knowledge:** **went live 2026-09-04.** Knowledge cutoff: **not disclosed.** Community reporting describes it as "the **2.0 successor to Ox Alpha**", a previous OpenCode stealth model — but the site itself is careful: "**The relationship has not been officially confirmed**" by either team.
- **IDs:** `omen-alpha` (OpenCode Go, TokenRa). **No free tier.**
- **Context window:** ⚠️ **Not publicly disclosed.** This is a correction to this repo's metadata, which recorded "~500K community-reported (128K max output)". Both the model's own site — "**Model parameters, including the context window, are not yet publicly disclosed**" — and RankLLMs' audit — "**Context, output, knowledge and release details: Unknown**" — contradict that figure. I found no source substantiating 500K or 128K, and I am not scoring a number that only exists in this repo.
- **Modalities:** **Text in → text out**, as far as can be verified. ⚠️ **The repo's "Text, image in" claim is unsubstantiated** — no source I found mentions image input, and the product site describes only coding and agentic text use. Reasoning: the site calls it a "low-cost **reasoning** model", which is a vendor-adjacent claim with no benchmark behind it. Tool calls: implied by inclusion in OpenCode Go's coding-agent lineup, but not independently documented.
- **Pricing (as of 2026-10-08):** **$0.20 / MTok input, $0.66 / MTok output, $0.04 / MTok cached read** — a 5× cache discount. A **TokenRa promotional rate of $0.08 / $0.26 (60% off)** is advertised. Bundled access comes with **OpenCode Go at $10/month**. Measured in its one benchmark run, average cost was **$0.03 per prompt**.
- **Architecture:** **Entirely undisclosed** — "Parameters: Not yet publicly disclosed. Community evaluation is ongoing." No parameter count, no architecture family, no training details, no vendor.

> RankLLMs is also explicit about why the usage page is not evidence of quality: "This is **platform telemetry, not a model card or an independent capability evaluation**. It shows that people used a model under this identifier; it does not establish who built it, how it performs, or what weights it runs." And on identity attribution generally: "Behavioral impressions, response style, speed, or **a model's own answer about its identity are not sufficient** to attribute it to a provider."

Coding — the only measured dimension:

- **OpenCode coding score: 23.14 / 40 (57.9%), leaderboard rank #15** — "Recorded on **September 4, 2026** across **four coding projects**", with **average cost $0.03 per prompt and average time 01:51** (omenalpha.io's benchmark snapshot). This is a dated result with stated methodology and a stated sample size, which is why I treat it as a usable figure rather than excluding the model — but **four projects is a very small sample** and the publisher is a product site promoting a discounted API route, not an independent evaluator.

Usage telemetry — recorded for completeness, explicitly **not** scored as capability:

- OpenCode's data page showed, on **2026-10-09**, a **usage rank of 35** and **0.2% of the observed two-month token volume**. Per RankLLMs, "these figures describe activity within OpenCode's dataset only; they are **not market share or evidence of model quality**."

**Absent entirely:** no SWE-bench (any variant), LiveCodeBench, Terminal-Bench, DeepSWE, SciCode, GPQA Diamond, MMLU-Pro, HLE, AIME, ARC-AGI, CritPt, Omniscience, BFCL, τ²-bench, GDPval, MCP-Atlas, AA-LCR, MRCR, or any multimodal benchmark. No tokens-per-second figure, no context-length figure, no parameter count, no vendor.

### Normalized scores (1–100)

- **Tool use: 42/100.** Scored almost entirely on circumstantial evidence. The model is **sold for "agentic work"** and was placed in OpenCode Go's lineup of "models used in coding agents", and its one benchmark was run across four coding *projects* in a harness that drives tool loops — so basic tool calling demonstrably functions. But **no tool-use benchmark of any kind exists**: no BFCL, Terminal-Bench, τ²-bench, GDPval, MCP-Atlas or Toolathlon figure. The usage-rank telemetry is deliberately excluded as evidence. Scored below the midpoint on absence of measurement, not on demonstrated weakness.
- **Reasoning: 35/100.** Its own site calls it a "low-cost **reasoning** model", and that is the entire basis for the claim — **there is no GPQA Diamond, MMLU-Pro, HLE, AIME, ARC-AGI, CritPt or Omniscience figure**, and nothing from any independent evaluator. A 57.9% composite on a four-project coding harness implies non-trivial reasoning is happening, which is why this is not scored lower. But an unverified vendor-adjacent adjective is not evidence, and I will not credit one.
- **Context window: 30/100.** **Explicitly undisclosed by the vendor** and confirmed unknown by RankLLMs' audit. This repo's "~500K / 128K max output" figure is **uncorroborated by any source I could find**, so I am not scoring it. What remains is the inference that a model marketed for multi-file coding projects must carry a workable window — that is worth something, but not much. No retrieval measurement at any depth, and no max-output figure.
- **Multimodal: 15/100.** No evidence of image, audio or video input from any source, and the repo's "Text, image in" claim is unsubstantiated. Template floor for what appears to be a text-only model, with the caveat that **the modality is unverified rather than confirmed absent**.
- **Coding: 52/100.** The only dimension with a real number: **OpenCode coding score 23.14/40 — 57.9% — at leaderboard rank #15**, dated 2026-09-04 across four coding projects, with the practical figures that matter for an interactive coding model also published (**$0.03 per prompt, 1 minute 51 seconds average**). Mid-field, and cheap per task. Capped at the low 50s for three reasons: **four projects is a thin sample**, the publisher is a commercial site routing traffic to a discounted API rather than an independent harness, and **there is no SWE-bench, LiveCodeBench, Terminal-Bench, DeepSWE or SciCode figure** to corroborate it or to place it against the rest of this dataset.
- **Cost efficiency: 84/100.** The strongest dimension, and the model's actual selling point. **$0.20 in / $0.66 out with $0.04 cached reads** is a genuinely low rate with a 5× cache discount, the **TokenRa promotional $0.08 / $0.26 is 60% below that**, bundled access via **OpenCode Go costs $10/month**, the **measured cost per prompt was $0.03**, and the OpenAI-compatible Chat Completions interface means zero integration cost. The privacy terms deserve explicit credit and are better than most priced models here: **0-day retention and no training on user data**. Three deductions: there is **no free tier**, the **completely undisclosed specifications** make rate limits, context behaviour and capacity unpredictable, and **anonymous provenance is itself a procurement risk** — RankLLMs' guidance is the right one: "Before relying on it for sensitive or production work, check the service's current provider, data handling, availability, and model details… If those details are unavailable, **avoid sending secrets**."
- **Overall Score: 34.8/100.** Mean of the five non-cost dims (42 + 35 + 30 + 15 + 52) / 5 = 34.8. **This score reflects an absence of evidence, not demonstrated incompetence, and that distinction matters.** One dated benchmark on four projects is all the public record contains; four of five quality dimensions have no measurement whatsoever, and even the context window and vendor are unknown. Best fit: **low-risk, cost-sensitive coding work where you can evaluate it yourself** — exactly as the independent coverage recommends, "use it on low-risk code and compare it against known models like GLM-5.3-Flash, DeepSeek V4 Flash or Kimi K3 on the same tasks". The 0-day retention and no-training terms make that experimentation safer than most stealth routes. Do not put it on a critical path, do not send it secrets, and do not assume a context window, a parameter count or a vendor — none of the three is public. If OpenCode or an upstream developer publishes an attributable model card, this folder should be re-researched from scratch.
