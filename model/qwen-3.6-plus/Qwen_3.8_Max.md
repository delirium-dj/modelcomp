## Model card

- **Name:** Qwen 3.6 Plus
- **Short description:** **Alibaba's Qwen3.6-generation hosted "Plus" tier** (released **~2026-04-01**, blog titled *"Towards Real World Agents"*) — a **397B-A17B MoE** (17B active) built for **long-context, multimodal, GUI/API agent work** at a **very low price**. Its headline specs are genuinely strong: a **native 1M-token context window by default**, **text + image + video in**, **native MCP + multi-agent (orchestrator/subagent) support**, hybrid thinking mode, and vendor coding numbers close to the frontier (**SWE-bench Verified 78.8 vs Claude Opus 4.5's 80.9**; **SWE-bench Pro 56.6**; **LiveCodeBench 87.1**). ⚠ But the honest picture is thinner than the marketing: **the only independent measurement is Vals AI's SWE-bench Verified leaderboard, where it scores 86% / 71% / 38% / 0% across difficulty bands** — strong on short tasks but it **collapses on long-horizon work (38% on 1–4 hr, 0% on >4 hr)**, which directly undercuts the "real-world agent" pitch (real agent tasks *are* long-horizon). There is **no Artificial Analysis Intelligence Index**, every other number is **vendor-reported**, and the model is **explicitly superseded** by the Qwen3.7/3.8 Plus tiers — so new agent work belongs on the newer generations. Listed here as `opencode/qwen-3.6-plus`.

Tiered pricing kicks in above 256K input.
- **Modalities:** **Text + image + video in → text out.** Multimodal vision reads screenshots/UI mockups (frontend dev), charts/diagrams (data analysis), scanned docs/PDFs and annotated images — real-world agent inputs beyond plain text. **Video input** puts it above image-only peers; **no audio, no generative image/video output.**
- **Pricing (as of 2026-10-24):** **$0.50 / $3.00 per 1M in/out (≤256K input)**; **$2.00 / $6.00 per 1M (256K–1M input)**; **~$0.325 / $1.95 via OpenRouter.** Extremely cheap for a 1M-context frontier-class MoE — commandcode.ai prices a representative agent task (180K in @ 75% cache hit, 12K out) at **~$0.07**. (Note: its successor Qwen3.7-Plus is cheaper still at $0.40/$1.60.)
- **Architecture:** **397B-total / 17B-active Mixture-of-Experts** (the Qwen3.5-397B-A17B MoE class), hybrid **thinking mode** (extended reasoning on/off), fine-tuned for **structured/JSON tool calls, multi-tool orchestration, parallel tool calling**, **native MCP (Model Context Protocol)**, and **multi-agent** roles (orchestrator + subagent), trained on **extended task trajectories** for long-horizon coherence.

### Normalized scores (1–100)

- **Tool use: 81/100.** Architecturally this is the model's *design focus* — **native MCP, structured/JSON tool calls, multi-tool orchestration, parallel tool calling, orchestrator/subagent multi-agent roles and long-horizon trajectory training**, aimed squarely at GUI/API "real-world agents" (the Qwen-UI-Agent lineage). But it is **independently unproven**: there is **no AA Index, no OSWorld/ScreenSpot/AndroidWorld result** in the sources reviewed, and the one independent harness (Vals, bash-only) shows the **long-horizon collapse (38% / 0%)** that most hurts sustained multi-step agent work. Held below Qwen3.7-Plus's 84 (which had *verified* ScreenSpot Pro 79.0 / AndroidWorld 81.0) because Qwen3.6-Plus's agent claims rest on architecture and vendor framing rather than independent measurement.
- **Reasoning: 81/100.** A large **397B-A17B MoE with hybrid thinking mode**; vendor LiveCodeBench 87.1 and SWE-bench Pro 56.6 imply solid reasoning, and the blog claims "major gains in overall reasoning" over the 3.5 series. Capped at 81 because there is **no independent reasoning benchmark** (no AA Index, no GPQA/ARC-AGI in the sources reviewed) [2026-11-02: AA per-eval cells now exist and **confirm the cap rather than lift it** — **AA-GPQA-D 88.2 (< vendor 90.4), AA-HLE 27.8, Omniscience Index +0.9 / halluc 34.6%, CritPt 2.9, Epoch FrontierMath v2 T1-3 38.2**; HOLD 81], the headline numbers are **vendor-only**, Alibaba itself notes the **Max tier "may outperform on the hardest reasoning tasks,"** and the model is **superseded**.
- **Context window: 86/100.** The genuine standout — a **native 1M-token window by default** (not a YaRN extension), fitting entire codebases, document sets and long agent trajectories without truncation, plus ~65K output. Scored at the top tier alongside Qwen3.7-Plus (86), MiniMax M3 and GPT-5.4 (1.05M) — 1M native is materially ahead of the 128K–400K pack. Not higher because the >256K range carries a steep pricing step ($2.00/$6.00) and no long-context *recall* benchmark (e.g. MRCR) was published to verify quality across the full 1M.
- **Multimodal: 81/100.** **Text + image + video in → text out**, with vision built for real-world agent inputs — screenshots/UI mockups (frontend), charts/diagrams, scanned docs/PDFs and annotated images. Scored **above image-only peers (gpt-5.2, grok-4.6, claude-sonnet-4.6 at 77–78)** because native **video** plus document/chart grounding is broader — but held just below Qwen3.7-Plus's 82 because the 3.7 generation is the explicitly "multimodal" sibling with more documented vision benchmarks, while Qwen3.6-Plus's vision is described qualitatively (no MMMU/CharXiv/OmniDocBench figures in the sources reviewed) [2026-11-02: AA now indexes **AA-MMMU-Pro 78.0** (≈ vendor 78.8, mid-tier — below successor qwen-3.7-plus's 80.5) and **confirms the text+image+video spec in its own table** — the missing quantitative confirmation arrives *neutral-to-positive*, so **81 holds**].
- **Coding: 83/100.** Vendor numbers are close to the frontier — **SWE-bench Verified 78.8 (vs Opus 4.5's 80.9)**, **SWE-bench Pro 56.6**, **LiveCodeBench 87.1** — and the independent Vals harness confirms **strong short-task coding (86% <15 min, 71% 15m–1h)**. But it is discounted below Qwen3.7-Plus's 84 and Qwen 3.8 27B's 85 because the **independent long-horizon bands collapse (38% on 1–4 hr, 0% on >4 hr)** — exactly the repository-scale, multi-hour real-world issues that matter most — and the SWE-Pro/LiveCodeBench figures are **vendor-only and unreproduced**.
- **Cost efficiency: 89/100.** Exceptional value — **$0.50/$3.00 per 1M (≤256K)**, **~$0.325/$1.95 on OpenRouter**, and roughly **$0.07 for a representative 180K-in/12K-out agent task**, delivering a **native 1M context + video multimodality + frontier-adjacent coding** at a fraction of closed-API prices. Held just below Qwen3.7-Plus's 90 only because the successor is cheaper still ($0.40/$1.60) and the >256K tier jumps 4× ($2.00/$6.00). Scored but **not** counted in the Overall per methodology.
- **Overall Score: 82/100.** Mean of Tool 81 + Reasoning 81 + Context 86 + Multimodal 81 + Coding 83 = 412/5 = 82.4 → 82. Best fit: **cost-sensitive, long-context, multimodal agent and coding workloads that stay within short-to-medium task horizons** — bulk document/codebase processing, frontend-from-mockup generation, MCP tool orchestration and high-volume inference where the ~$0.07/task economics and native 1M window win. **Not** the pick for **long-horizon autonomous agents** (the independent Vals 38%/0% collapse is disqualifying there), the hardest reasoning (Max tier / newer gens lead), audio, or anyone who should simply use the **superseding Qwen3.7/3.8 Plus tiers**.
