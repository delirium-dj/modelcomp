## Model card

- **Name:** Muse Glimmer 30B (official Meta SKU; dataset label `muse-glimmer-30b` matches the 30B dense open-weights model; also listed as `Muse Glimmer-30B High Reasoning` or `Muse Glimmer (high)` in independent benchmark cards). Instruction-tuned (`IT`) variant is the primary release on Hugging Face (`meta-models/Muse-Glimmer-30B`) and NVIDIA NIM.
- **Short description:** Meta's first open-weights model since Llama 4 (released 2026-08-09/10). A 29.6B-parameter dense causal transformer with a dedicated ~1.8B-parameter ViT-G/14 perception encoder, purpose-built for autonomous agentic tasks on consumer hardware. Released under Apache 2.0. Key design choices: multi-step reasoning, reliable tool use, multimodal perception (text + image), failure recovery, persistent memory, 131,072+ token context, quantized to ~18 GB (4-bit) for 24/32 GB consumer GPU deployment. Designed to run locally without cloud infrastructure or network access.
- **Provider / access:** Meta / Meta Superintelligence Lab (official); Hugging Face (`meta-models/Muse-Glimmer-30B`); NVIDIA NIM (`build.nvidia.com/meta/muse-glimmer-30b`); also available via third-party providers (Artificial Analysis lists +8 providers; vLLM / llama.cpp / transformers / Inference Endpoints confirmed by Meta blog and Hugging Face). Not served on Meta's proprietary API at launch (Meta blog 2026-08-10: "Meta is not serving the model on their API"); commercial hosting depends on NVIDIA NIM, Hugging Face Inference, or self-hosted vLLM/Ollama. Open-weights (Apache 2.0) — free to download, fine-tune, and deploy locally.
- **Release / knowledge:** Released 2026-08-09/10 (Meta blog `research.meta.ai/blog/introducing-muse-glimmer-open-agentic-model`, Hugging Face `huggingface.co/blog/muse-glimmer`, NVIDIA NIM, arXiv `2610.24628` 2026-10-23). Knowledge cutoff: January 4, 2026 (official model card, NVIDIA NIM, HF model card, Artificial Analysis comparison). Model card updated 2026-08; arXiv technical report published 2026-10-23.
- **IDs:** `meta-models/Muse-Glimmer-30B` (Hugging Face); `Muse Glimmer-30B` (official); `muse-glimmer-30b` (dataset slug). No separate `Free` tier — the open-weights license IS the free-access mechanism.
- **Context window:** 131,072 tokens (official model card, NVIDIA NIM, HF, arXiv — all agree; described as "131,072+" with extension capability). Hybrid attention: 3 local sliding-window layers + 1 global full-attention layer repeating (pattern `[Local, Local, Local, Global]`). Sliding window size 2048 tokens; RoPE (θ = 500,000) applied to local layers only. The "+" indicates extension beyond 128K; no independent 256K+ retrieval benchmark found specifically for this model — closest verified retrieval is AA-LCR 80.0% (official/AA) and Beam 128K 65.1% (official, meta-internal), confirming strong 128K retrieval but not verified beyond.
- **Modalities:** Input: text (UTF-8, 200,000 BPE tokens + 2,048 special tokens; vocabulary size 202,048) + image (interleaved text and image tokens; max 4,096 visual tokens per image; variable aspect ratios/resolutions; ViT-G/14 vision encoder, ~1.8B params, 50 layers, width 1536, patch size 14). Video: not explicitly listed as a direct input modality in official docs; closest reference is the vision encoder processing image sequences (not confirmed for video input). Output: text only (no audio/video/image generation). Reasoning: yes — controllable reasoning strength (`low`, `medium`, `high`, `xhigh`). Tool calls: yes — native agentic workflow support (function-calling, structured output, native system instructions, persistent state, multi-step reasoning with failure recovery). Multilingual: 100+ languages (training data covers over 100 languages; official docs mention 100+). Audio input/output: not supported (no audio encoder/decoder on Glimmer; audio is only in Muse Spark family, not Glimmer).
- **Pricing (as of 2026-10-29):** Open-weights (Apache 2.0) — zero licensing cost. Self-hosting cost: ~60 GB GPU memory (BF16, 29.6B total + vision encoder + overhead); quantized variants: ~32 GB (K-Quant-Dynamic, 0.2% degradation) or ~24 GB (K-Quant-17GB, 1.0% degradation) — fits on single H100 80GB (full BF16) or RTX 5090 / Apple M5 Max (quantized). Commercial hosting: Artificial Analysis reports $0.30 / $1.20 per 1M input/output (pricing for hosted inference via third-party providers, not a Meta commercial API). NVIDIA NIM pricing depends on instance configuration; no fixed per-token price published by Meta. Cost efficiency score reflects the open-weights/free-license model combined with efficient quantization (4-bit, ~18 GB) allowing single-consumer-GPU deployment.
- **Architecture:** Dense causal transformer (not MoE). 29.6B total parameters: ~25.16B language model (52 layers, hidden dim 6656, SwiGLU FFN intermediate 19,968, GQA 32 Q-heads / 2 KV-heads, head dim 128, untied embeddings/projection ~1.34B each) + ~1.8B ViT-G/14 perception encoder + ~1.34B token embedding + ~1.34B output projection = ~29.6B total. Attention pattern: local sliding-window (2048 tokens) with gated attention, repeating `[Local, Local, Local, Global]` (3 local + 1 global per cycle). Position encoding: RoPE (θ = 500,000) applied to local layers only. Vocabulary: 202,048 tokens (200,000 BPE + 2,048 special). Tokenizer: BPE. Context length: 131,072+ (official). No audio encoder; no video encoder (only image encoder). Speculative decoding: optional DFlash drafter (~4-bit quantized, provides 3.1x speedup on RTX 5090, 1.5x on Apple M4 Max per official hardware table). Training: distilled from Muse Spark (proprietary flagship); pre-training on multimodal public + third-party + Meta data, then supervised fine-tuning + RLHF for agentic behavior (detailed in arXiv `2610.24628`); reasoning mode enabled by default in IT variant.
