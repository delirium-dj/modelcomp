# Grok 4.3 — Independent Research Report

## Summary and evidence

Grok 4.3 is SpaceXAI's enterprise agent model with configurable none/low/medium/high reasoning and a **one-million-token context window**. SpaceXAI reports it ranked first on Artificial Analysis Omniscience for low hallucination, Tau2 Telecom for tool-calling, and Vals AI Case Law and Corporate Finance for complex document work.

Sources: [SpaceXAI Grok on Amazon Bedrock](https://x.ai/news/grok-amazon-bedrock), [SpaceXAI API pricing](https://docs.x.ai/developers/pricing)

## Cost and limitations

Short-context pricing is **$1.25 input, $0.20 cached input, and $2.50 output per million tokens**; requests at or above 200K cost $2.50/$0.40/$5. It is superseded by Grok 4.5–4.7, and public first-party coding detail is limited.

## Scores

- **Tool use: 92/100.** Leading telecom-agent results and enterprise integration show excellent tool use.
- **Reasoning: 88/100.** Low hallucination and professional-domain results support strong reasoning.
- **Context window: 96/100.** One million tokens is excellent.
- **Multimodal: 86/100.** Grok's text-and-image platform is capable, though this release emphasizes enterprise text work.
- **Coding: 86/100.** Agentic coding is capable but less documented than later Grok releases.
- **Cost efficiency: 94/100.** Low short-context prices provide strong value.
- **Overall Score: 90/100.** Half-up rounded mean: (92 + 88 + 96 + 86 + 86) / 5 = 89.6.

## Bottom line

Grok 4.3 is an economical million-context enterprise agent, but later Grok versions are better for new coding deployments.
