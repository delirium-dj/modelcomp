## Model card

- **Name:** Grok 4.3 (API id `grok-4.3`; reasoning-effort variants Low/Medium/High — AA tracks "Grok 4.3 (Medium)" and "(High)"). xAI is labelled "**SpaceXAI**" on Artificial Analysis.
- **Short description:** **xAI's cost-efficient, reasoning-first 1M-context model — now deprecated and superseded, but still the cheap long-context + native-video option.** Released to the public API **2026-04-30** (beta on grok.com/SuperGrok from Apr 17; GA the week of May 4), it succeeds **Grok 4.20** and folds **always-on chain-of-thought reasoning** into the base behavior (no separate toggle). Its launch pitch was **price-per-intelligence**: an aggressive cut (**input −37.5%, output −58.3% vs Grok 4.20**) to **$1.25/$2.50** put it "**comfortably on the Pareto frontier for intelligence versus cost**" at **$395 to run the AA Intelligence Index** (~20% cheaper than Grok 4.20). Independent (AA-measured) strengths: **GDPval-AA Elo 1500** (+321 over Grok 4.20 — surpassing Gemini 3.1 Pro Preview, Muse Spark, GPT-5.4-mini-xhigh and Kimi K2.5), **τ²-Bench Telecom 98%** (agentic customer support, in line with GLM-5.1), **IFBench 81% (leading instruction-following)**, and **#1 on legal/finance domain benches (CaseLaw v2 79.3%, CorpFin)**. It was also the **first xAI model with native video input**. ⚠ **Two important reality-checks:** (1) On the **current AA Intelligence Index v4.3.2 it scores just 24.88 (High) — *below* the 27 median and roughly *tied* with the Grok 4.20 it replaced (25.22)**; codersera's honest read is that "**Grok 4.3 was not a general-intelligence upgrade over the model it replaced**" (its real gains were agentic tool use, video, context and price). (2) **It never published a SWE-bench Verified / SWE-bench Pro / Terminal-Bench number** ("itself a tell"), and on agentic coding it **trails Claude Opus 4.7 by double-digit points**. It is now **deprecated** — xAI shipped **Grok 4.5 (Jul 8), 4.6 (Aug 12) and 4.7** (Grok 4.6-High = **44.31** on v4.3.2, ~18 points above 4.3), though those drop to 500K context, cost $2/$6, and lack native video — so 4.3 retains a niche.
- **Provider / access:** **xAI.** First-party **xAI API** (`console.x.ai`, OpenAI-compatible `https://api.x.ai/v1`, model name `grok-4.3`, $25 promo credits); consumer **grok.com / SuperGrok** apps (free with rate limits; **SuperGrok Heavy $300/mo** unlocks max reasoning + artifact generation); third-party gateways **OpenRouter** and **Requesty**. **Proprietary** (weights and parameter count undisclosed). **No free-id API tier** (`noFreeId: true`). xAI retired 8 legacy Grok slugs on May 15, 2026 (deprecated ids silently route to `grok-4.3`). Listed here as `opencode/grok-4.3`.
- **Release / knowledge:** **2026-04-30** (public API). ⚠ **Now DEPRECATED** — Artificial Analysis explicitly flags it ("**This model is deprecated … SpaceXAI has launched a newer release, Grok 4.6. We suggest considering it instead**"), which the scaffolded meta does **not** mention. Knowledge cutoff not stated in the sources reviewed.
- **IDs:** `grok-4.3` (xAI API) / `xai/grok-4.3` (Requesty) / `opencode/grok-4.3` (this dataset).
- **Context window:** **1,000,000 tokens (1M)** — confirmed by AA, codersera and contracollective (~1,500 A4 pages / a full codebase / hours of transcripts). *Verified against the meta's "1,000,000 total."* No documented hard output cap (latency scales with length). Notably, the **1M is a retained differentiator** — the newer Grok 4.5/4.6/4.7 all **cut context to 500K**. ⚠ Requests over **200,000 input tokens are billed at double the standard rate** (the long-context tier).
- **Modalities:** ⚠ **Meta correction — the scaffolded meta's "Text, image in; text out" is missing video.** Grok 4.3 is **text + image + native video in → text out**. **Native video input is an xAI first**: the vision encoder ingests video directly (**mp4/mov/webm, up to 5 minutes at up to 1080p**) and handles **speech transcription, speaker segmentation, object tracking and motion causality in a single pass** (no upstream frame extraction/transcription). codersera calls it "**currently the only API model in this tier with native video input**." It also adds **native artifact *output*** (directly produces PDFs, slide decks and spreadsheets). *Caveat:* AA's model page lists only "text and image" (AA does not benchmark video), so the video capability rests on two detailed independent launch guides (codersera, contracollective) rather than an AA measurement — but both describe it as a headline feature with consistent technical specifics. High-resolution image reasoning still trails Claude Opus 4.7 (98.5% visual acuity, 3.75MP).
- **Pricing (as of 2026-10-25):** **$1.25 input / $2.50 output per 1M** (standard tier, <200K prompt); **$2.50 / $5.00 above 200K** (long-context tier); **cached input $0.20 per 1M (84% discount)**; AA blended rate **$0.64** (7:2:1 cache/input/output). *Verified against the meta's tiered pricing.* **$395 to run the full AA Intelligence Index** (~20% cheaper than Grok 4.20). Roughly **4× cheaper on input / 10× on output than Claude Opus 4.7** ($5/$25). ⚠ The **price-per-intelligence crown has moved on**: on v4.3.2, **GPT-6 Luna scores 34.56 at ~$0.04/Index-task vs Grok 4.3's 24.88 at ~$0.21** — codersera says to "read the price-per-intelligence case as a **May 2026 verdict rather than a current one**." Still the cheapest 1M-context + native-video xAI option (its successors cost $2/$6).
- **Architecture:** **Reasoning-first proprietary LLM; parameter count undisclosed** (AA: "SpaceXAI has not disclosed the model size or parameter count"). **Chain-of-thought reasoning is on by default for every request** (unlike prior Groks where reasoning was a toggle) — this lifts multi-step results but makes **time-to-first-token slow (~15.75–19.7s)** while **output throughput is fast (~98.5–146 tok/s)**: "quick once it starts, slow to start." Uses **~44% more output tokens than Grok 4.20** but "remains less verbose than other leading models" (similar to MiniMax-M2.7). A dedicated **vision encoder** handles image + native video.

### Raw benchmarks found

The strongest evidence here is **independent (Artificial Analysis–measured)** — a notable contrast with the vendor-only profiles of pareto-26.10-preview and seed-2.0-pro. ⚠ **Rebasing caveat (critical):** AA has rebased its Intelligence Index since launch. **Grok 4.3 scored 53 on the launch-era v4.1.1 basket (April/May 2026)** but **24.88 (High) / ~25 (Medium, estimated) on the current v4.3.2 basket (October 2026)**. Per codersera, "**there is no conversion factor, so a v4.1.1 number and a v4.3.2 number are not comparable in either direction**" — the two are never averaged or equated below.

**Independent — Artificial Analysis (measured) + Vals/third-party:**

- **AA Intelligence Index: v4.3.2 = 24.88 (High) / ~25 (Medium, estimated), #123/215, *below* the price-class median of 27** — roughly **tied with Grok 4.20's 25.22**, i.e. "**not a general-intelligence upgrade**." *(Launch-era v4.1.1 = 53, just above Muse Spark and Claude Sonnet 4.6, +4 over Grok 4.20 — a May-2026 verdict, not current.)* Current-basket context: GPT-5.5-xhigh 38.36, GPT-6 Luna 34.56, Gemini 3.1 Pro Preview 29.72, **Grok 4.6-High 44.31**.
- **GDPval-AA (agentic real-world work, Elo): 1500** — **+321 over Grok 4.20's 1179**; surpasses Gemini 3.1 Pro Preview, Muse Spark, GPT-5.4-mini (xhigh), Kimi K2.5; still **trails GPT-5.5 (xhigh) by 276 Elo (~17% expected win rate)**.
- **τ²-Bench Telecom (agentic customer support): 98%** (+5 pts, in line with GLM-5.1).
- **IFBench (instruction following): 81%** (maintained from Grok 4.20; AA calls it a **leading** score). ⚠ **Meta discrepancy:** the scaffolded meta says "**IFBench 83.3% #1**" — AA's independent figure is **81%**; the 83.3% is not corroborated by AA (likely an xAI-blog or different-version number). Reported as **81% (AA)** here.
- **AA-Omniscience: Accuracy +8 pts vs Grok 4.20, but Non-Hallucination Rate −8 pts** — so **Grok 4.20 still leads xAI's lineup on non-hallucination**, with Grok 4.3 merely "**in line with MiMo-V2.5-Pro**." ⚠ **This directly contradicts the meta's standout** ("**unusually strong honesty profile**" / "honesty 83% non-hallucination"): on AA's independent suite, Grok 4.3's honesty **regressed** and it is **mid-pack, not a leader**. The absolute "83%" is unconfirmed by AA.
- **AA cost/speed:** **$395 to run the Intelligence Index**; output **~98.5–146 tok/s** (above the 82 median); **TTFT ~15.75–19.7s** (well above the 3.9s median — always-on CoT); cache discount 84%.
- **Coding — conspicuously absent:** **no published SWE-bench Verified, SWE-bench Pro or Terminal-Bench 2.0 number** (contracollective: "not directly reported"; codersera: "xAI has not published its own SWE-bench Verified number, which is itself a tell"), and **no Vals SWE-bench-Verified row exists for Grok 4.3** (Vals lists Grok 4.6-High at 95.60%, "a benchmark xAI never published a Grok 4.3 number for"). On **SWE-bench Pro it trails Claude Opus 4.7 by double-digit points**; for function-level generation/unit tests/simple fixes the third-party gap is <5 pts.

### Normalized scores (1–100)

- **Tool use: 82/100.** Genuinely strong **independent (AA-measured)** agentic results: **GDPval-AA Elo 1500** (+321 over Grok 4.20; ahead of Gemini 3.1 Pro Preview, Muse Spark, GPT-5.4-mini-xhigh, Kimi K2.5) and **τ²-Bench Telecom 98%** (in line with GLM-5.1), plus "stronger agentic tool calling" and native artifact generation. Held to **82** (below GPT-5.6 Luna's 84) because GDPval still **trails GPT-5.5-xhigh by 276 Elo**, there is **no AA Coding Agent Index / AA-Briefcase / AutomationBench** number, and the model is **deprecated**. Clearly above the vendor-only agentic profiles (seed-2.0-pro 81, mistral-large-4 80) on independent evidence.
- **Reasoning: 77/100.** The **current AA Intelligence Index v4.3.2 = 24.88 (High) / ~25 (Medium)** is ***below* the 27 median** and **tied with the Grok 4.20 it replaced** — codersera's verdict is that it "**was not a general-intelligence upgrade**." **GPQA-Diamond ~90%** is respectable and it **leads legal/finance (CaseLaw v2 79.3% #1, CorpFin #1)**, which lifts it off the floor. Scored **77** — below mistral-large-4's 80 (whose AA Index 38 was *above* its price-class median, vs Grok 4.3's *below*-median 24.88), and far below the independently-verified frontier-reasoning tier (GPT-5.6 Luna 84). The launch-era **53 (v4.1.1)** is documented but **not** credited at face value (no cross-version conversion).
- **Context window: 85/100.** **1M tokens**, confirmed by three independent sources and actually served (not a preview claim) — the **proven-1M tier**. It is also a **retained differentiator**: the newer Grok 4.5/4.6/4.7 all **cut context to 500K**. Scored level with GPT-5.6 Luna (85, 1.05M) and above pareto-26.10-preview (84, unvalidated preview 1M). Minor drag: the **>200K long-context tier is billed at double** and no independent AA-LCR long-context score surfaced, but the window itself is real and generous.
- **Multimodal: 82/100.** **Text + image + native video in → text out** (video **corrected into** the meta) — **native video is an xAI first** (mp4/mov/webm, ≤5 min, ≤1080p; in-model transcription/segmentation/tracking/motion-causality) and codersera calls it "**the only API model in this tier with native video input**," plus **native artifact output** (PDF/slides/sheets). Scored **82** (video tier) — above the image-only floor (77–78) but **below Seed 2.0 Pro (84)**, which pairs video with a **published SOTA VideoMME 89.5**; Grok 4.3 publishes **no video benchmark**, and its high-res **image** reasoning trails Opus 4.7.
- **Coding: 76/100.** The clear weak spot on evidence: **no published SWE-bench Verified / SWE-bench Pro / Terminal-Bench number** ("itself a tell"), **no Vals SWE-bench-Verified row**, and it **trails Claude Opus 4.7 by double-digit points on SWE-bench Pro**. It is "strong on math and analytical tasks" (GPQA ~90%) and within **<5 pts** of Opus 4.7 on function-level generation/unit tests/simple fixes, and its agentic strengths (GDPval, τ²-Bench) are non-coding. Scored **76** — below pareto (79) and mistral-large-4 (78), which at least publish DeepSWE/Surge numbers, and well below the elite-Vals coders (86).
- **Cost efficiency: 87/100.** **$1.25/$2.50** (cached **$0.20**, 84% discount; blended **$0.64**), **$395/index-run** (~20% under Grok 4.20), and **4×/10× cheaper than Opus 4.7** on input/output — at launch it "**sat comfortably on the Pareto frontier for intelligence versus cost**." Held to **87** (below GPT-5.6 Luna's 93) because that crown has moved: on v4.3.2 **GPT-6 Luna delivers a higher Index (34.56) at ~1/5th the per-task cost (~$0.04 vs ~$0.21)**, so the price-per-intelligence case is now "a May-2026 verdict." Still very cheap in absolute terms and the cheapest 1M-context + native-video xAI option (successors are $2/$6).
- **Overall Score: 80/100.** Mean of the five quality dimensions = (82 Tool + 77 Reasoning + 85 Context + 82 Multimodal + 76 Coding) / 5 = **402/5 = 80.4 → 80** (Cost efficiency 87 is scored but **not** counted, per the v4 formula). **Divergence note:** my independent read is **80 vs the queue's curated 84.3 → −4.3.** The gap is a **launch-era-vs-current** story plus meta corrections: the curated 84.3 reflects the **May-2026 verdict** (AA Index **v4.1.1 = 53**, Pareto-frontier price-per-intelligence, "just above Claude Sonnet 4.6"), whereas my score reflects the **current v4.3.2 reality** — **Index rebased to 24.88 (below the 27 median, tied with Grok 4.20, "not an intelligence upgrade"), the model deprecated in favor of Grok 4.6 (44.31), no published coding benchmarks, and GPT-6 Luna overtaking it on price-per-intelligence** — plus the **corrected honesty picture** (AA-Omniscience non-hallucination *regressed* 8 pts, contradicting the meta's "unusually strong honesty profile" standout). Its genuine, retained strengths — **1M context (85), native video (82), strong independent agentic/domain results (GDPval 1500, τ²-Bench 98%, CaseLaw/CorpFin #1), and cheap tokens (87)** — keep it at a solid 80 rather than lower. This −4.3 mirrors the other superseded/rebased profiles (gpt-5.2, gemini-2.5-pro) where curation captured a launch peak that independent rebasing has since deflated.
