## Model card

- **Name:** GPT-5.5 Pro
- **Short description:** OpenAI's maximum-compute reasoning tier, released 2026-04-23 alongside GPT-5.5 and made generally available in the API on 2026-04-24. OpenAI's description is unchanged from GPT-5.4 Pro's: "uses more compute to think harder and provide consistently better answers," with **"some requests may take several minutes to finish"** and an explicit instruction to use **background mode** to avoid timeouts. OpenAI's own framing of the Pro delta is qualitative and specific: testers found its responses "significantly more comprehensive, well-structured, accurate, relevant, and useful," with **"especially strong performance in business, legal, education, and data science,"** and — unusually — **"latency improvements that make it much more practical for demanding tasks"** versus GPT-5.4 Pro. It is also the **freshest model in this dataset**: a 2025-12-01 knowledge cutoff, three months newer than GPT-5.4 Pro's. Not a variant or alias of another entry in this dataset.
- **Provider / access:** **OpenAI Responses API only** (plus the Batch API), for multi-turn model interactions before responding. **Not available on Chat Completions and not offered in Codex** — Codex caps GPT-5.5, including Pro, at a 400K context window, so **sessions needing the full 1M window must go through the Responses API directly.** In ChatGPT it is restricted to **Pro, Business and Enterprise**; Free and Plus users cannot select it. Also on **Azure OpenAI** and **Amazon Bedrock** (general availability 2026-06-01 under the $50B AWS–OpenAI partnership, at matching first-party rates with no markup), plus OpenRouter and Vercel AI Gateway.
- **Release / knowledge:** released **2026-04-23**; API general availability **2026-04-24**. Knowledge cutoff **2025-12-01** — the most recent cutoff of any model in this dataset.
- **IDs:** `gpt-5.5-pro`; snapshot `gpt-5.5-pro-2026-04-23`. OpenRouter: `openai/gpt-5.5-pro`.
- **Context window:** **1,050,000 tokens, 128,000 max output** (OpenAI developer docs). DataLLM Lab lists a slightly different split (922K input / 128K output within the 1,050,000 total); the first-party 1,050,000 / 128,000 pair is used here. **Long-context surcharge:** once a session's input exceeds **272,000 tokens, the entire session is billed at 2× input and 1.5× output** — not merely the portion over the threshold, which is the detail that matters for retrieval-heavy workloads. Codex caps it at 400K.
- **Modalities:** **text, image and file in; text out** (DataLLM Lab's modality listing; OpenAI's Pro model page documents the Responses API surface but does not enumerate modalities on that page). Reasoning effort: **`medium`, `high` (default), `xhigh`** — no `none`, no `low`, consistent with a tier built exclusively to think harder. Tool calling and structured JSON output both supported.
- **Pricing (as of 2026-10-01):** **$30.00 / MTok input, $180.00 / MTok output** (OpenAI developer docs). **First-party statement, and this is the important line on the card: "GPT-5.5 Pro does not offer a cached input discount."** That is strictly worse than GPT-5.4 Pro, which merely *omitted* a cached rate — here OpenAI documents the absence as a policy. HokAI estimates ~$3/MTok cached by applying GPT-5.5's 90% discount ratio and notes OpenAI has not confirmed it; **no cached rate is used in scoring.** Blended price: **$67.50/MTok** (BenchLeader, HokAI), **#68 of 68 ranked models** on that metric in HokAI's peer set — i.e. the most expensive model in its comparison group. This is **6× standard GPT-5.5's $5/$30**. Regional processing endpoints carry a **10% uplift.** No free tier.
- **Architecture:** proprietary. HokAI claims GPT-5.5 Pro is **the same Mixture-of-Experts weights as standard GPT-5.5** with 128 expert routing groups and sparse per-token activation, differentiated by **parallel test-time compute** exploring multiple reasoning paths. **This is a third-party architectural claim; OpenAI has not published it**, and it is recorded here as unverified. OpenAI's own only architectural statement is the compute-allocation one.

### Raw benchmarks found

The **seven Pro-specific rows OpenAI actually published**, from its GPT-5.5 launch table (GPT-5.5 / GPT-5.4 / **GPT-5.5 Pro** / GPT-5.4 Pro / Claude Opus 4.7 / Gemini 3.1 Pro):

- **BrowseComp (agentic information gathering): 90.1%** — the highest figure in OpenAI's entire table for this benchmark, ahead of Claude Opus 4.7 (79.3%), Gemini 3.1 Pro (85.9%), GPT-5.5 (84.4%) and GPT-5.4 Pro (89.3%)
- **FrontierMath Tier 4: 39.6%** — GPT-5.5 35.4%, GPT-5.4 Pro 38.0%, Claude Opus 4.7 22.9%, Gemini 3.1 Pro 16.7%. Also the highest in the table.
- **FrontierMath Tier 1–3: 52.4%** — GPT-5.5 51.7%, GPT-5.4 Pro 50.0%, Claude Opus 4.7 43.8%, Gemini 3.1 Pro 36.9%. Highest in the table.
- **Humanity's Last Exam with tools: 57.2%** — GPT-5.4 Pro 58.7%, Claude Opus 4.7 54.7%, GPT-5.5 52.2%, Gemini 3.1 Pro 51.4%
- **Humanity's Last Exam without tools: 43.1%** — GPT-5.4 Pro 42.7%, Claude Opus 4.7 **46.9%** (the table's best), Gemini 3.1 Pro 44.4%, GPT-5.5 41.4%
- **FinanceAgent v1.1: 61.5%** — GPT-5.4 Pro 64.4% and Claude Opus 4.7 59.7% both higher; GPT-5.5 60.0%
- **GDPval (wins or ties): 82.3%** — GPT-5.5 84.9%, GPT-5.4 Pro 82.0%, Claude Opus 4.7 80.3%, Gemini 3.1 Pro 67.3%. **GPT-5.5 Pro scores *below* both its sibling and its predecessor on this row.** Its one clear win is margin: **0.3 points over GPT-5.4 Pro.**

Third-party Pro-specific figures, flagged as such:

- **GDPval-AA: Elo 1785** — versus GPT-5.5's 1769, a **+16 lead**, described by LLMReference as "the first visible non-tie lead" between the two.
- **GeneBench-Pro: 20.5** — GPT-5.5 12.0
- **SWE-bench Verified: 88.7%** (HokAI, labelled "vendor-reported", **#4 of 28**, peer median 78.3%) — **conflicts with LLMReference, which records SWE-bench Verified tied at 82.6 for GPT-5.5 and GPT-5.5 Pro.** OpenAI's own table carries a dash for Pro on this row, and HokAI elsewhere concedes "OpenAI has not independently published separate GPQA Diamond or AIME 2025 scores for the Pro inference setting." **The 88.7% is therefore not OpenAI-published and is not used as the primary figure.**
- MMLU 92.4%, CharXiv Reasoning 84.1%, MMMU-Pro 81.2% appear in HokAI's and AI Release Tracker's lists but correspond to **GPT-5.5's** figures in OpenAI's table (CharXiv 84.1% and MMMU-Pro 81.2% are GPT-5.5's published values). They are **not** Pro-specific and are not transferred.

Rows where OpenAI published a dash for GPT-5.5 Pro, and the shared GPT-5.5 values LLMReference carries for both — **recorded as an assumption, not a measurement**:

- SWE-bench Verified **82.6**, SWE-bench Pro **58.6%**, GPQA Diamond **93.6%**, Terminal-Bench 2.0 **82.7%**, Terminal-Bench 2.1 **78.2%**, OSWorld-Verified **78.7%**, MCP-Atlas **75.3%**

### Normalized scores (1–100)

- **Tool use: 86/100.** The strongest Pro-specific tool-use evidence in this dataset, and it comes with a caveat about how thin it is. Up: **BrowseComp 90.1%**, the highest figure in OpenAI's whole launch table for that benchmark and ~11 points clear of Claude Opus 4.7 and ~4 clear of Gemini 3.1 Pro; **GDPval-AA Elo 1785**, a +16 lead over GPT-5.5 and the only Pro-specific number that beats its sibling; **FinanceAgent 61.5%** on real financial workflows. Against: **no Pro-specific Toolathlon, Tau3-Banking or Tau2-Bench figure exists**, and LLMReference's shared rows imply Terminal-Bench 2.0 **82.7%** and MCP-Atlas **75.3%**, both excellent but both *assumed* from GPT-5.5 rather than published for Pro. Scored at 86 on BrowseComp and GDPval-AA, which are measured, and explicitly below the 90+ frontier band because the agentic harnesses this dimension is built on are unpublished for this checkpoint.
- **Reasoning: 92/100.** Near the top of the dataset, on the strongest mathematics in OpenAI's table. **FrontierMath Tier 1–3 at 52.4% and Tier 4 at 39.6%** — both the highest figures in OpenAI's launch table, Tier 4 by 4.2 points over GPT-5.4 Pro and 16.7 over Claude Opus 4.7. **HLE 57.2% with tools**, and **43.1% without**, which clears GPT-5.5's 41.4%. Held at 92 rather than 96+ for two specific gaps: **GPQA Diamond is a dash for Pro** in OpenAI's table, so the 93.6% belongs to GPT-5.5 and is not borrowed — meaning the standard frontier science-reasoning anchor is simply unmeasured here; and **HLE without tools at 43.1% is below Claude Opus 4.7's 46.9%**, the one row where OpenAI's most expensive reasoning tier is not the best in its own table.
- **Context window: 95/100.** **1,050,000 tokens with 128,000 max output** — the methodology's "≥1M = 95–100" band, scored at its floor. The 100 tier requires **≥98% retrieval at 512K+**, and **every long-context row in OpenAI's GPT-5.5 table is a dash for Pro**: no MRCR, no RULER, no GraphWalks, no AA-LCR for this checkpoint. GPT-5.5 base's own retrieval at that scale (GraphWalks BFS 45.4% at 1M, MRCR 74.0% at 512K–1M) shows the generation's 1M behaviour is real but nowhere near 98%, and those figures are not Pro's either. Two practical qualifications that do not change the score but change the bill: **Codex caps Pro at 400K**, so the full window requires the Responses API, and the **2× input / 1.5× output surcharge above 272K tokens applies to the entire session**.
- **Multimodal: 72/100.** **Text, image and file in; text out.** Scored above the "+image in = 60–70" band and into the "+video/PDF in = 75–90" band's floor because **file input is listed** by DataLLM Lab alongside image and text — but that listing is third-party and **OpenAI's GPT-5.5 Pro model page does not enumerate modalities**, so the PDF credit is provisional. No Pro-specific **MMMU, MMMUPro, DocVQA, OmniDocBench or CharXiv** figure was found; GPT-5.5's CharXiv 84.1% and MMMU-Pro 81.2% are not transferred. No audio or video input documented, so the top of the band is unreachable.
- **Coding: 86/100.** Strong, but **every coding number for this model is either a dash from OpenAI or a third-party figure**. Best available: LLMReference's shared reading of **SWE-bench Verified 82.6%**, **SWE-bench Pro 58.6%** (a state of the art per OpenAI, for GPT-5.5) and **Terminal-Bench 2.0 82.7%**; HokAI's contested **88.7%** SWE-bench Verified at #4 of 28. Scored at 86 on the shared reading — the same place GPT-5.3-Codex earned in this pass on a $180/MTok price rather than $14 — and explicitly not higher, because OpenAI published **no Pro-specific coding figure at all**, and a coding score for a maximum-compute reasoning tier inferred entirely from its sibling's numbers is the weakest link in this file.
- **Cost efficiency: 10/100.** **$30.00 / $180.00 per MTok**, and the disqualifying detail is first-party: **"GPT-5.5 Pro does not offer a cached input discount."** No model in this dataset is scored worse on cost. BenchLeader and HokAI both put the blended figure at **$67.50/MTok**, with HokAI ranking it **#68 of 68** — the most expensive model in its peer set — and the blended peer median at $1.70/MTok, roughly **40× cheaper**. This is **6× standard GPT-5.5's $5/$30**, itself 2× GPT-5.4's $2.50/$15, itself 2× GPT-5.2's $1.25/$10: four consecutive doublings. Compounding penalties: **no cache discount at all**, the **2×/1.5× surcharge above 272K input tokens applied to the whole session**, and a **10% regional-processing uplift**. One credit extended for OpenAI's documented token efficiency — GPT-5.5 uses significantly fewer tokens than GPT-5.4 on the same Codex tasks, and AA's output-token figures fall from 120M to 75M at `xhigh` and 45M at `high` — but that is a GPT-5.5-family figure with no Pro-specific equivalent, and it cannot offset a $180 output rate on a model whose cached input is not discounted. Ten points is the methodology's neighbourhood for "$10/$50 ≈ 30" scaled past its top anchor by roughly 3.6×, with the cache discount removed entirely.
- **Overall Score: 86/100.** (86 + 92 + 95 + 72 + 86) / 5 = 86.2 → **86** — the highest Overall in this pass. **Best fit, with the price stated first because the Overall hides it:** correctness-critical work where a wrong answer is more expensive than a right one — **high-stakes legal, financial, business and scientific analysis** across large document sets, where BrowseComp 90.1%, FrontierMath Tier 4 39.6%, HLE-with-tools 57.2% and a **2025-12-01 knowledge cutoff** (the freshest here) justify **$30/$180 with no cache discount**, and where a request taking several minutes in background mode is acceptable. OpenAI's own stated strength areas — business, legal, education, data science — match that list exactly. **Not** the choice for volume, latency or agentic loops: GPT-5.5 at $5/$30 beats it on GDPval (84.9% vs 82.3%), Terminal-Bench 2.0 (82.7% shared) and OSWorld-Verified, at one-sixth the price and with a 90% cache discount.
