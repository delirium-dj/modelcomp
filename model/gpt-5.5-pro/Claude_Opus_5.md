## Model card

- **Name:** GPT-5.5 Pro. No free tier of any kind — API-only at $30/$180, plus ChatGPT Pro/Business/Enterprise seats (the $200/month Pro plan). Variant/alias flag: **this is not an independently trained model.** OpenAI documents Pro as the *same* GPT-5.5 base running **parallel test-time compute** — multiple independent reasoning threads synthesised into one answer — so GPT-5.5 base results are the correct floor for it, not a different model's results.
- **Short description:** The highest-compute tier of OpenAI's GPT-5.5 family, built for problems where accuracy matters more than latency or cost. GPT-5.5 itself was OpenAI's first fully retrained base model since GPT-4.5 (not a post-training tweak like 5.1–5.4), released 2026-04-23, with Pro API availability confirmed 2026-04-24. OpenAI warns that difficult Pro requests **may take several minutes** and recommends background mode to avoid timeouts.
- **Provider / access:** OpenAI directly — **Responses API (`v1/responses`) and Batch API (`v1/batch`) only**. Explicitly *not supported*: Chat Completions, Realtime, Live, Assistants, fine-tuning, embeddings, image/video/speech generation endpoints, moderation, legacy completions. That Responses-only constraint is a real integration cost for stacks built on Chat Completions. Also resold through unified-API gateways (e.g. `openai/gpt-5.5-pro`). Supported features: `structured_outputs`, `function_calling`, `file_search`, `image_input`, `image_generation`, `mcp`, `web_search`. Supported Responses-API tools: function calling, web search, file search, image generation, code interpreter, **hosted shell**, MCP.
- **Release / knowledge:** Released **2026-04-23**; default snapshot `gpt-5.5-pro-2026-04-23`. **Knowledge cutoff 2025-12-01** — the oldest cutoff of any frontier model in this dataset's top tier, which matters given the model's documented reliance on grounding.
- **IDs:** `gpt-5.5-pro` (OpenAI), snapshot `gpt-5.5-pro-2026-04-23`. **No free-tier ID exists.** Standard sibling for routing: `gpt-5.5` ($5 / $0.50 cached / $30).
- **Context window:** **1,050,000 input tokens, 128,000 max output tokens** — taken directly from OpenAI's model documentation and independently restated by OpenRouter and multiple pricing trackers. Published long-context recall evidence exists and is mediocre: **MRCR v2 at 74%** for the GPT-5.5 base at the 1M window.
- **Modalities:** Input: **text and image only**. Output: **text only** (OpenAI's own "Output modalities: text"). Audio and video are not natively supported in either direction. Image *generation* is available only as a hosted Responses-API **tool**, not as a model output modality. Reasoning: yes — reasoning-token support with `reasoning.effort` limited to **medium, high (default) and xhigh** (no low/minimal setting, unlike base GPT-5.5). Tool calls: yes, including a hosted shell. JSON mode / structured outputs: yes.
- **Pricing (as of 2026-10-03):** **$30 / 1M input, $180 / 1M output** (~$37.10 / 1M blended at 20:1). **No cached-input discount is offered at all** — unique among the frontier models reviewed here and brutal for agent loops that re-read a large prefix. Regional processing (data-residency) endpoints carry a **10% uplift**. Batch and Flex run at roughly half the standard rate; Priority processing ~2.5x. For comparison inside its own family, Pro is **6x** standard GPT-5.5 on both input and output, and roughly **7x Claude Opus 4.7's output price**. Rate limits are tight at the bottom: Tier 1 is 50 RPM / 50K TPM, rising to Tier 5 at 2,000 RPM / 4M TPM.
- **Architecture:** Proprietary, closed weights. Parameter count, active parameters and topology: not disclosed. Serving infrastructure is disclosed: NVIDIA **GB200 NVL72** rack-scale systems, which NVIDIA claims deliver 35x lower cost per million tokens and 50x higher output per megawatt than prior systems. OpenAI also states that Codex running GPT-5.5 wrote load-balancing and partitioning heuristics for OpenAI's own serving stack, raising token generation speed by over 20%.

### Raw benchmarks found

> **Attribution discipline matters for this entry.** Only four published rows are measured on **GPT-5.5 Pro** itself; the remainder are **GPT-5.5 base** figures. Because OpenAI documents Pro as the same model with extra inference compute, base figures are recorded as a labelled floor — they are not Pro results and are not treated as such in the scoring.

Agent / tool use:

- Terminal-Bench 2.1: **no verified public score found** (no 2.1 or 4.0 figure for either variant). **Terminal-Bench 2.0 — GPT-5.5 base: 82.7%** (GPT-5.4 75.1%, Claude Opus 4.7 69.4%, Gemini 3.1 Pro 68.5%). **No Pro-specific terminal result published.**
- Tau3-Banking / Tau2-Bench: **Tau2-Bench Telecom — GPT-5.5 base: 98.0%** (GPT-5.4 92.8%). No Tau3-Banking figure; Telecom is the most tractable tau2 domain, so this is not a general agentic result.
- GDPval-AA: no Elo figure found. **GDPval (wins or ties) — GPT-5.5 base: 84.9%** (GPT-5.4 83.0%, Claude Opus 4.7 80.3%, Gemini 3.1 Pro 67.3%) — a win-rate, not comparable to the Elo scale used elsewhere in this dataset.
- Claw-Eval / ClawProBench: no verified public score found
- Toolathon / MCP-Atlas / SWE Atlas Codebase QnA: no verified public score found
- OSWorld-Verified (computer use) — **GPT-5.5 base: 78.7%** (Claude Opus 4.7 78.0% — effectively a tie)
- **BrowseComp — GPT-5.5 Pro: 90.1%** (GPT-5.5 base 84.4%, Claude Opus 4.7 79.3%, Gemini 3.1 Pro 85.9%). **This is the single best Pro-attributable agentic number: +5.7pp over base and the highest in its comparison set.**

Reasoning / knowledge:

- GPQA Diamond: **GPT-5.5 base 93.6%** (Claude Opus 4.7 94.2%, Gemini 3.1 Pro 94.3% — GPT-5.5 narrowly *loses* this row). No Pro-specific figure.
- HLE: **GPT-5.5 Pro — 43.1% without tools, 57.2% with tools** (base 41.4% / 52.2%; Claude Opus 4.7 46.9% / 54.7%). Pro's +5.0pp with-tools gain flips the row from a loss to a win against Opus 4.7.
- LCR / MLCR: no verified public score found. Closest long-context figure: **MRCR v2 74%** at 1M (GPT-5.5 base).
- CritPt: no verified public score found
- Artificial Analysis Intelligence Index / BenchLM overall: **59 for GPT-5.5 (high), ranked #2 of 141 evaluated models** at the time (median comparable score 33; full index run cost $2,159.38). Artificial Analysis maintains a separate **"GPT-5.5 Pro (Xhigh)"** profile, but no numeric index value for the Pro variant was retrievable in this pass. Third-party composites place Pro at **#12 of 211 (74.62/100, evidence status self-labelled "Estimated")** on one leaderboard and **#38** on another — both non-authoritative.
- Omniscience Accuracy / Hallucination Rate: **this is the defining weakness.** On AA-Omniscience, **GPT-5.5 (xhigh) scores the highest accuracy Artificial Analysis has ever measured at 57% — with an 86% hallucination rate**, the worst of any flagship (Claude Opus 4.7 max: 36%; Gemini 3.1 Pro Preview: 50%). AA's own summary: better at the right answer when it knows it, more willing to confabulate when it doesn't. On **SimpleQA the hallucination rate is 47% without web search, dropping to 9.6% with web search enabled** — the model is reliable only when grounded.
- **FrontierMath Tier 4 — GPT-5.5 Pro: 39.6%** (base 35.4%, GPT-5.4 27.1%, Claude Opus 4.7 22.9%, Gemini 3.1 Pro 16.7%) — roughly double the nearest competitor and Pro's most decisive published lead. **FrontierMath Tier 1–3 — base: 51.7%.**
- **ARC-AGI-2 — GPT-5.5 base: 85%.** **OfficeQA Pro — base: 54.1%** (Claude Opus 4.7 43.6%, Gemini 3.1 Pro 18.1%).
- OpenAI system card preparedness ratings: Biological/Chemical **High**; Cybersecurity **High, below Critical** (up from GPT-5.4); AI Self-Improvement **below High**.

Coding:

- SWE-bench Verified / SWE-Pro: SWE-bench Verified — no verified public score found. **SWE-Bench Pro (public) — GPT-5.5 base: 58.6%**, which **loses to Claude Opus 4.7 at 64.3%** (GPT-5.4 57.7%, Gemini 3.1 Pro 54.2%). **No Pro-specific figure.**
- LiveCodeBench: no verified public score found
- SciCode / AA-SciCode: no verified public score found
- Vibe Code Bench: no verified public score found
- DeepSWE / Coding Index / other: no DeepSWE figure found. **Expert-SWE (OpenAI internal) — base: 73.1%** (GPT-5.4 68.5%); no external comparison possible. OpenAI claims state-of-the-art on the Artificial Analysis **Coding Index at half the cost of competitive frontier coding models** — a vendor claim with no number attached. Documented qualitative weakness: a reproducible "card problem" — asked to generate UI from a plain-language prompt, GPT-5.5 reaches for the same rounded-card grid regardless of domain, with reviewers preferring Claude Opus 4.7 for layout hierarchy and typography.
- Anecdotal Pro evidence (not a benchmark): a researcher's 5,000-year procedural harbour-town simulation completed in 20 minutes on GPT-5.5 Pro versus 33 minutes on GPT-5.4 Pro, with cleaner code.

Long context:

- **MRCR v2: 74% at the 1M window** (GPT-5.5 base) — the only published long-context retrieval figure, and well short of a frontier recall rate. No RULER or GraphWalks result found.

### Normalized scores (1–100)

- **Tool use: 89/100.** **BrowseComp 90.1% is Pro-measured and the best in its comparison set**, Tau2-Bench Telecom at 98.0% clears the methodology's Tau-family frontier reference by a wide margin, GDPval wins-or-ties at 84.9% beats every rival in that sweep, OSWorld-Verified 78.7% matches Claude Opus 4.7, and the tool surface is unusually complete (hosted shell, code interpreter, MCP, web search, file search). Four things keep it out of the mid-90s: **there is no Pro-specific terminal or agentic-coding number at all**, the available Terminal-Bench figure is 2.0 (82.7%, base) rather than the 2.1/4.0 versions the frontier is now measured on, **Tau3-Banking and Claw-Eval are unreported** (explicit methodology penalty), and the operational envelope fights agent loops — multi-minute responses, Responses-API-only, and 50 RPM / 50K TPM at Tier 1.
- **Reasoning: 91/100.** Pro's own numbers are strong where it counts: **FrontierMath Tier 4 at 39.6% is roughly double the nearest competitor**, **HLE 43.1% no-tools / 57.2% with tools** clears the 40%+ frontier reference and overtakes Claude Opus 4.7 once tools are on, and the base model's ARC-AGI-2 85%, GPQA Diamond 93.6% and #2-of-141 Intelligence Index placement (59) establish a frontier floor. The deduction is large and evidence-based rather than stylistic: **an 86% hallucination rate on AA-Omniscience — the worst of any flagship measured — alongside 47% on SimpleQA without web search.** Record accuracy (57%, highest ever recorded) bought with record confabulation is a genuine reasoning-reliability defect, not a presentation quibble. It also *loses* GPQA Diamond to both Claude Opus 4.7 and Gemini 3.1 Pro, the Index of 59 sits below the 60+ marker, and MRCR v2 74% is far from the 95%+ long-context reference.
- **Context window: 95/100.** A verified **1,050,000-token input window with 128,000 output tokens** places it in the ≥1M tier (95–100). It stays at the tier floor on hard evidence rather than absent evidence: **MRCR v2 at 74%** means roughly a quarter of needles are missed at full length, nowhere near the ≥98%-retrieval condition for 100. The economics compound the limitation — with **no cached-input discount**, re-reading a 500K-token prefix costs $15 every single turn, so the window is affordable far below its nominal size.
- **Multimodal: 68/100.** Input is **text and images only** and native output is **text only**, which places it in the methodology's "+image in = 60–70" band. It does not reach the band ceiling because, unlike peers scored there, **not a single multimodal benchmark exists for this model** — no MMMU, no chart/document-understanding figure, no vision result for either variant was found — and independent comparison guidance explicitly routes multimodal work to Gemini 3.1 Pro instead. Image *generation* exists only as a hosted Responses-API tool, which is an orchestration capability rather than a model output modality, and audio and video are unsupported in both directions.
- **Coding: 84/100.** The honest position: **no coding benchmark has been published for GPT-5.5 Pro at all.** Scoring therefore rests on the documented base floor — Terminal-Bench 2.0 82.7% (clearly leading its cohort), Expert-SWE 73.1% internal, and OpenAI's unnumbered claim of SOTA on the AA Coding Index at half the cost of rivals — plus the structural argument that extra test-time compute should not reduce coding quality. Three real deductions: **SWE-Bench Pro at 58.6% loses to Claude Opus 4.7's 64.3%**, which is the row that matters most for fixing bugs in real repositories; **DeepSWE, LiveCodeBench, SciCode and SWE-bench Verified are all missing**, so none of the methodology's 90–100 coding references can be checked; and two documented failure modes bite developers directly — hallucinated library and API names (the 86% confabulation rate landing in code) and the reflexive card-grid UI pattern.
- **Cost efficiency: 14/100.** At **$30 / $180** this is the most expensive model in this dataset by a wide margin — 3x the input and 3.6x the output of the methodology's $10/$50 anchor that already maps to only ~30, 6x its own standard sibling, and roughly 7x Claude Opus 4.7's output rate. The aggravating factor is structural: **there is no cached-input discount whatsoever**, so the long-context agent patterns this model is sold for are precisely the ones that bill at full rate every turn, and data-residency endpoints add a further 10%. Partial mitigations are small — Batch/Flex at half rate ($15/$90) and the family's ~40%-fewer-output-tokens efficiency claim, which Pro structurally undercuts by spending *more* compute by design. Independent guidance in the same source set recommends routing most traffic to base GPT-5.5 and escalating selectively, which is the correct read of this price point.
- **Overall Score: 85.4/100.** Mean of the five non-cost dimensions (89 + 91 + 95 + 68 + 84) / 5 = 85.4 — a narrow specialist, not a default. Choose it for **graduate-level mathematics and hard scientific reasoning** (FrontierMath Tier 4 39.6%, roughly double the field) and **deep autonomous web research** (BrowseComp 90.1%), run selectively at low volume with background mode, and always with grounding enabled — the 86% AA-Omniscience hallucination rate collapses to 9.6% on SimpleQA once web search is on, so retrieval is not optional. Do not choose it for repository bug-fixing (SWE-Bench Pro loses to Claude), for any multimodal or audio/video work, for citation-sensitive or compliance writing, or for high-volume production traffic where $180/1M output with no cache discount makes the economics indefensible.
