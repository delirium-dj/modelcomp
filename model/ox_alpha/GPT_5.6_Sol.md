# Ox Alpha — Independent Research Report

## Summary and evidence

Ox Alpha was the anonymous pre-release identity used to test **GLM-5.3-Flash** on OpenCode and OpenRouter. Z.ai later confirmed the mapping. The released model is a native multimodal **320B-parameter MoE with 18B active parameters**, hybrid sparse/linear attention, one-million-token operation, open weights, and an MIT license.

Source: [Z.ai GLM-5.3-Flash announcement confirming Ox Alpha](https://autoclaw.z.ai/blog/model/glm-5.3-flash/)

## Cost and limitations

Ox Alpha itself was a temporary free preview and is no longer a stable product identity; production users should select GLM-5.3-Flash. The architecture is efficient but still large to self-host, and the anonymous preview offered no contractual stability.
