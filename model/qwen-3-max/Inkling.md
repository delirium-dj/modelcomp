> Model-status note: `qwen3-max` (official release 2025-09-23; preview `qwen3-max-preview` released 2025-09-05) is a proprietary (closed-weights) model from Alibaba Qwen. The Puter developer page (`developer.puter.com/ai/qwen/qwen3-max-2025-09-23/`) notes "This model is no longer available" for that specific dated snapshot; the DeepLearning.ai batch (2026-01-08) treats `qwen3-max` as available via API (Alibaba Cloud, OpenRouter, Qwen Chat); the dataset (`model-queue.md`) includes it at Overall 70.8. Availability may depend on region/provider and snapshot alias; findings below document the verified profile at time of dataset inclusion.

## Model card

- **Name:** Qwen3-Max / Qwen3 Max (official Alibaba SKU; dataset slug `qwen3-max` matches; preview variant `qwen3-max-preview` or `qwen3-max-instruct-preview` released earlier 2025-09-05; official release 2025-09-23/24). Instruction-tuned (`Instruct`) is the primary accessible version; reasoning variant (`Thinking`) in training as of 2025-10/2026-01 (not fully released at time of dataset inclusion).
- **Short description:** Alibaba Qwen's largest and most capable model (released 2025-09-23, preview 2025-09-05). A trillion-parameter-class Mixture-of-Experts (MoE) model trained on 36 trillion tokens, built on the Qwen3 architecture (hybrid thinking/non-thinking modes, MoE with global-batch load balancing loss). Designed for complex reasoning, coding, agentic tasks, structured data (JSON), multilingual understanding, and creative tasks. The preview version ranked 3rd on LMArena text leaderboard (ahead of GPT-5-Chat at time of preview); official release improves coding and agent capabilities. The reasoning-focused variant (`Qwen3-Max-Thinking`) achieves 100% on AIME 25 and HMMT (with code interpreter + parallel test-time compute) but was still in training at time of dataset inclusion (not fully available).
- **Provider / access:** Alibaba Cloud / Qwen Chat / Alibaba Cloud Model Studio (primary commercial routes); also available via OpenRouter, AnyCoder (open-source coding tool), and other third-party API providers. Not open-weights (unlike Qwen3-235B-A22B which is open-weights under Apache 2.0; `qwen3-max` is proprietary — confirmed by VentureBeat, DeepLearning.ai, The Decoder, Alibaba docs). No direct open-source download available; weights not released.
- **Release / knowledge:** Preview released 2025-09-05 (`venturebeat.com`, `qwenlm.github.io/blog/qwen3/`); official release 2025-09-23/24 (`the-decoder.com`, `alibabacloud.com/blog/qwen3-max-just-scale-it_602621`, `developer.puter.com/ai/qwen/qwen3-max-2025-09-23/`). Knowledge cutoff: April 2025 (Puter developer docs, BenchmarkList — confirmed); some sources mention Jan 2026 for later variants (e.g., `qwen3-max-2026-01-23` reasoning variant per Alibaba blog 2026-01-27) — the dataset model `qwen3-max` refers to the 2025-09 release with April 2025 cutoff.
- **IDs:** `qwen3-max` (dataset slug / OpenRouter alias); `qwen3-max-preview` / `qwen3-max-instruct` / `qwen3-max-instruct-preview` (release variants); `qwen3-max-2025-09-23` (Puter dated snapshot); `qwen3-max-2026-01-23` (later reasoning-variant snapshot mentioned in 2026-01 blog). Model family: `qwen3-max` (official); not to be confused with open-weights `qwen3-235b-a22b` (open-weights, 235B total / 22B active, released same Qwen3 family in 2025-04).
- **Context window:** 262,144 tokens (official Alibaba docs, VentureBeat, DeepLearning.ai, BenchmarkList, Puter — full agreement); maximum input 258,048 tokens; maximum output varies by source: official Alibaba docs and Puter list 32,768 tokens (Puter also notes 66K max output for a different version/config — this is a conflict); DeepLearning.ai notes input up to 262K, output up to 65,536 tokens. There is a discrepancy between official Alibaba docs (32,768 max output) and some provider/source listings (65,536 / 66K). **Conflict noted: max output 32,768 (official Alibaba docs) vs 65,536 (DeepLearning.ai, Puter for some config) — likely reflects different API tiers or version updates.** The dataset's `average.md` lists context window score 83.6/100 — consistent with very large context but not maximum verified retrieval quality at full 262K.
- **Modalities:** Input: text (primary — up to 262K context); image/video/audio not explicitly confirmed for `qwen3-max` in the sources read. The Qwen3 family (from 2025-04 blog) supports hybrid thinking/non-thinking modes but does not emphasize multimodal input for the Max variant (unlike Qwen3-VL or Qwen3-Omni which are separate releases). The dataset `average.md` shows Multimodal score 32.8/100 — very low — confirming minimal or no verified multimodal capability for this model. Output: text only (no image/audio/video generation). Reasoning: yes — hybrid thinking/non-thinking modes (official Qwen3 family feature); the `Thinking` variant (`Qwen3-Max-Thinking`) is reasoning-optimized but was in training at dataset time. Tool use: yes — agentic capabilities verified (Tau2-Bench 74.8 official / 72.0 BenchmarkList; agent tasks; structured JSON; multi-step reasoning with adaptive tool-use per 2026-01-27 blog for Thinking variant). Not video-output.
- **Pricing (as of 2026-10-29, historical at release):** Alibaba Cloud Singapore: $1.20 / 1M input, $6.00 / 1M output (official Alibaba docs, DeepLearning.ai, VentureBeat — full agreement). Alibaba Cloud Beijing: $0.861 / 1M input, $3.441 / 1M output (DeepLearning.ai — regional price difference confirmed). BenchmarkList: $0.78 / 1M input, $3.90 / 1M output (possibly a different provider/region or updated pricing). OpenRouter / third-party: pricing varies by provider; no fixed universal price. The pricing reflects a premium flagship model (high cost, especially output at $6/1M). Cost-efficiency score 74.3/100 (dataset average) reflects high price relative to capability — competitive at frontier level but not budget-efficient.
- **Architecture:** Proprietary (not open-weights). 1 trillion total parameters; Mixture-of-Experts (MoE) architecture (official Alibaba docs confirm MoE design following Qwen3 series; global-batch load balancing loss). Training: 36 trillion tokens pre-training; architecture details (layer count, expert count, activation ratio) not fully disclosed for `qwen3-max` specifically (unlike Qwen3-30B-A3B or 235B-A22B which publish layer/expert details). The model uses the Qwen3 series architecture scaled up. No independent architecture audit; weights not released.

### Normalized scores (1–100)

- **Tool use: 79/100.** Evidence: Tau2-Bench 74.8% (official) / 82.1% (Thinking variant, 2026-01-27) — very high agentic tool-use score, ahead of Claude Opus 4 and DeepSeek V3.1 (official claims); BenchmarkList Tau2 Telecom 74.3% — near-agreement; agent capabilities (structured JSON, adaptive tool-use, search, memory, code interpreter for Thinking variant — 2026-01-27) confirm very strong structured agentic-tool-use design. Capped slightly by lower autonomous agentic performance (Terminal-Bench Hard 20.5% independent BenchmarkList; Deep Planning 28.7% independent — lower than top-tier autonomous agents) and absence of verified independent agentic-autonomy benchmarks specifically for Max (only Tau2-Bench and BenchmarkList agent scores available). Confirmed excellent structured agentic/task performance; weaker open-ended autonomous planning.
- **Reasoning: 80/100.** Evidence: AIME 25 81.6% (official) — very high mathematical reasoning; Thinking variant achieves 100% (with code interpreter + parallel test-time compute — 2026-01-27) but applies to different variant; GPQA 87.4% (Thinking variant, very high scientific reasoning); MMLU-Pro 85.7% (Thinking variant); Arena-Hard v2 90.2% (Thinking variant — very high human-preference ranking); DeepLearning.ai independent comparison confirms competitive reasoning (ahead of Anthropic, DeepSeek, xAI; behind Gemini 2.5 Pro / GPT-5); official claims competitive reasoning and top-3 LMArena ranking (ahead of GPT-5-Chat at preview). Capped by Thinking variant being in training (not fully available at dataset time) and independent comparison showing Qwen3-Max behind Gemini 2.5 Pro / GPT-5 on aggregate; the base Instruct version's exact independent reasoning numbers are less extensively verified than Thinking variant's impressive scores. Confirmed very strong reasoning for Instruct (AIME 81.6%, competitive ranking); Thinking variant shows frontier-level reasoning potential (100% AIME 25, 87.4% GPQA) but is not the dataset's tracked `qwen3-max` slug.
- **Context window: 84/100.** Evidence: 262,144 tokens (official, full agreement across Alibaba docs, VentureBeat, DeepLearning.ai, BenchmarkList, Puter); 1M-token context training capability (ChunkFlow, 3x throughput — official 2025-10-28 blog); max input 258,048 confirmed; max output conflict noted (32,768 official / 65,536 DeepLearning.ai / 66K Puter). Confirmed among the largest context windows; very strong long-context training infrastructure. Capped by absence of independent verified retrieval benchmark specifically for `qwen3-max` at full 262K (family-level 1M training confirmed, specific retrieval verification not independently published), and by the output-token limit discrepancy (potential API/config variation).
- **Multimodal: 33/100.** Evidence: dataset `average.md` score 32.8/100 — very low; official `qwen3-max` docs focus exclusively on text (no vision/audio/video input/output specs confirmed for Max); separate Qwen3 family members handle multimodal (Qwen3-VL, Qwen3-Omni) — confirming Max is text-focused. Confirmed minimal multimodal capability for this specific model.
- **Coding: 78/100.** Evidence: SWE-Bench Verified 69.6% (official — very high agentic-coding verification); LiveCodeBench v6 74.8% (official); BenchmarkList LiveCodeBench 78.2%, IDE-Bench 65.0%, SciCode 38.3%, VibeCodingBench 88.6%, Cangjie-bench 73.5% — competitive coding performance across dimensions; Tau2-Bench 74.8% (official) confirms agentic-coding/tool-use strength; DeepLearning.ai confirms competitive coding/agent performance. Confirmed very strong structured agentic-coding (SWE-bench Verified 69.6%, Tau2-Bench 74.8%) but weaker open-ended autonomous agentic-coding (Terminal-Bench Hard 20.5%).
- **Cost efficiency: 74/100.** Evidence: pricing varies by region/provider — Singapore $1.20/$6.00 per 1M (official Alibaba); Beijing $0.861/$3.441 (DeepLearning.ai); BenchmarkList $0.78/$3.90; Puter confirms similar pricing. The model is proprietary (not open-weights) with premium pricing (high output cost $6/1M at Singapore rate — among the highest in dataset); dataset `average.md` Cost efficiency 74.3/100 reflects high cost relative to capability. Confirmed premium pricing; competitive capability (top-3 LMArena, very high agentic/task scores) but at high token cost, particularly for output. Capped by proprietary/non-free access, high output price ($6/1M Singapore rate — 8x input rate), and regional price variation (Beijing significantly cheaper but still premium relative to open-weights/free-tier alternatives like Muse Glimmer or Nemotron Ultra Free). The model's value is frontier-level agentic/coding capability, not budget efficiency.
- **Overall Score: 71/100.** Mean of quality dims: (79 + 80 + 84 + 33 + 78) / 5 = 70.8 → rounded to 71 (matches dataset `average.md` Overall 70.8). Best-fit: a very capable proprietary frontier model (1T MoE, 36T training tokens, 262K context) with verified strengths in agentic/tool-use (Tau2-Bench 74.8), agentic-coding verification (SWE-bench Verified 69.6), competitive coding (LiveCodeBench 78.2%), very large context (262K spec + 1M training capability), and competitive reasoning (AIME 81.6% Instruct; Thinking variant achieves 100% AIME 25, 87.4% GPQA, 90.2% Arena-Hard v2). Key weaknesses/limitations: (a) proprietary (not open-weights) — unlike Qwen3-235B-A22B in the same family; (b) high cost ($1.20/$6 Singapore, premium relative to open-weights); (c) multimodal capability minimal for this specific model (dataset 32.8/100 — text-focused; separate family members handle vision/audio); (d) open-ended autonomous agentic-coding weaker (Terminal-Bench Hard 20.5% independent; Deep Planning 28.7%); (e) max output token discrepancy (32,768 official vs 65,536/66K in some sources); (f) model/family availability ambiguity (Puter notes dated snapshot no longer available; Thinking variant in training/released separately). Recommended for structured agentic/task workflows, large-context applications, agentic-coding verification, and reasoning tasks (Instruct version; Thinking variant for frontier reasoning); not recommended for budget-sensitive applications (high token cost, proprietary), multimodal tasks (use Qwen3-VL/Omni), or open-ended autonomous agentic tasks requiring highest autonomous-planning scores.
