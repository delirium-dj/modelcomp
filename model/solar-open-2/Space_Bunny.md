## Model card

- **Name:** Solar Open 2 (Solar-Open2-250B, 250B-A15B)
- **Short description:** Upstage's **Korean sovereign foundation model**, released **July 2026** (weights on Hugging Face announced 2026-07-23) — a 250B-total / 15B-active hybrid-attention MoE purpose-built for **long-horizon agentic tasks** and scaled up from Solar Open 1 (Solar Open 100B). Its distinguishing claim is a genuinely usable **1M-token window** that can hold entire agent trajectories in one context, delivered via a hybrid attention stack at roughly one quarter the memory and compute of an all-softmax design. Top use cases: Korean-language enterprise and officework agents (Ko-GDPval 86.8), document-intensive work, and coding. It is **Upstage's only openly licensed model** and the only one of the three Solar lines for which Upstage publishes weights.
- **Provider / access:** Hugging Face `upstage/Solar-Open2-250B`; ModelScope `upstage/Solar-Open2-250B`. **Still no pay-per-token hosted API price** — Artificial Analysis lists "No publicly available API" and cost as not publicly available. Self-hosting: **minimum 4× H200 in BF16, or 2× H200 with quantization** (Upstage's own official figure, confirmed by MSIT); the model card's headline table still says "Minimum H200 × 4 / Recommended H200 × 8". No OpenCode Zen ID found.
- **Release / knowledge:** Weights released **2026-07-23** (Upstage Media Day); technical report **arXiv:2607.20062v1, submitted 2026-07-22, v2 2026-07-24**. AA dates the page 2026-08-12. **Knowledge cutoff: February 2026.**
- **IDs:** `upstage/Solar-Open2-250B` (HF/ModelScope); self-host served model name `solar-open2-250b` or `solar-open2`; API aliases `solar-open2-250b`, `upstage-solar-open2-250b`
- **Context window:** **1,048,576 tokens (1M)**, max output **up to 256K at `reasoning_effort="high"` and up to 128K at `reasoning_effort="none"`** — the output budget is new this pass and is a real differentiator. Verified in the technical report, on the model card's Best Practices table, on Artificial Analysis and on CloudPrice. This is a **native** window: the architecture interleaves one softmax layer among every three linear-attention layers with **no positional encoding** and a gated delta rule extended to negative eigenvalues, which the report says means the context is "in principle… unbounded regardless of the length distribution of its training data."
- **Modalities:** **Text in → text out only.** Artificial Analysis is explicit: "Solar Open2 250B does not support image input. It can only process text" / "is not multimodal." CloudPrice independently lists text as the sole input and output modality. Reasoning: yes, `reasoning_effort` exposed and steerable, with the trace preserved by default (`think_render_option=preserved`). Languages: **English, Korean, Japanese**.
- **Pricing (as of 2026-10-17):** **No hosted per-token price published — this is unchanged and is the single biggest practical constraint.** Open weights are downloadable at no license fee under the Upstage Solar License. For self-hosters the real cost is hardware and engineering, and the floor is lower than the first pass recorded:
  - **Official:** 4× H200 BF16, or **2× H200 quantized**; recommended serving configuration is 8 GPUs of ≥141 GB.
  - **Community:** AutoRound **INT4** (`nota-ai/Solar-Open2-250B-Nota-INT4`) fits **TP4**; **NVFP4 with global expert pruning** (`nota-ai/…-Nota-NVFP4-GlobalPruned`) runs on **1× B200** at 131K context; **W4A8** (`vessl/…-W4A8`) is **132 GiB** total, TP4 on 4× H200, with published production figures (TTFT p50 0.433 s, TPOT p50 15.1 ms, 0.87 cache hit rate); **NVFP4 on 2× DGX Spark** reportedly reaches the **full 1M window** at a 28 GiB KV pool (1.08× headroom).
  - **Caveat that matters:** **no released vLLM implements this architecture.** It requires Upstage's own fork (`UpstageAI/vllm` at `v0.22.0-solar-open2`) plus a `--reasoning-parser solar_open2 --tool-call-parser solar_open2` and a custom logits processor; `trust_remote_code` alone does not work. Transformers needs Upstage's `v5.14.1-solar-open2` branch and `fla-core` for the KDA kernels, without which it falls back to a much slower path. Upstage's own hosted line is priced far lower (Solar Pro 4 at $0.30/$1.20 list), which is a useful reference for what the same vendor charges for API access.
- **Architecture:** **250B total (250,287,794,944) / 15B active**, 48 layers, hidden size 4,096, head dimension 128, vocabulary 196,608, ~12T pre-training tokens. Hybrid attention pattern **[Softmax, Linear × 3] × 12**. 321 experts (320 routed + 1 shared), top-8 routed + 1 shared. No positional encoding; gated delta rule extended to negative eigenvalues. Initialized from Solar Open 1 by transferring the **5.69B-parameter shared skeleton**, everything else by full pre-training; a **20T-token pool refined to a 10T-token mixture**. Agent skills built by training **twelve domain specialists** and consolidating via **Multi-teacher On-Policy Distillation (MOPD)**. Trained on NVIDIA B200 GPUs for **2M GPU-hours**. **License: Upstage Solar License** (Model Beat calls the weights "unrestricted"; AA lists the Upstage Solar License — the license terms themselves were not read line-by-line here).
- **Government-programme status (new this pass):** Upstage **advanced to the third-stage evaluation** of Korea's sovereign-AI foundation-model programme alongside SK Telecom and LG AI Research; Motif Technologies was eliminated. Three teams remain and **two finalists are expected to be selected in February**, with roughly 1,200억원 of GPU support across the three teams for round three.

### Normalized scores (1–100)

- **Tool use: 70/100** (was 68). APEX-Agents 16.6% leads its size class, MCP-Atlas 58.2% matches DeepSeek-V4-Flash, and Ko-GDPval 86.8 shows real agentic competence. **Raised two points on two new independent results:** the **NIA benchmark evaluation places Upstage 2nd of four at 13.3/15 across instruction following, reliability and safety**, and the **MSIT-commissioned AAII run confirms the ~37 index figure as an AA measurement rather than press paraphrase**. Held well below the 70s+ band by Terminal-Bench Hard at only 28.3%, τ³ banking 19.6%, GDPval-AA 1128 Elo, the loss of the unverified Terminal-Bench 2.1 44.19% datapoint, and the fact that Upstage's flagship Ko-GDPval claim still rests on a single **in-house** benchmark where DeepSeek-V4-Pro ties it. No Claw-Eval, Toolathon or SWE-Atlas figure exists. The **3rd-of-4 general-citizen usability score (7.3/10)** is also credited against this dimension.
- **Reasoning: 77/100** (was 76). MMLU-Pro 86.2%, GPQA Diamond 86.3%, AIME 2026 95.7% and HMMT2602 93.9% are strong mid-frontier results, now backed by the **independent NIA evaluation's knowledge, maths and long-text components (13.3/15, 2nd of 4)** and the officially commissioned **AAII run at ≈37**. Raised one point. Still capped by HLE at 28.8%, an AA-side Intelligence Index that AA itself marks *estimated*, AA-LCR 62.3%, no CritPt or reliable Omniscience data, and the fact that the model placed **3rd of 4 on general-citizen usability** while only tying DeepSeek-V4-Pro on the single in-house benchmark behind its headline.
- **Context window: 94/100** (unchanged). **1,048,576 tokens, natively, with up to 256K output at high reasoning effort** — the top tier, achieved architecturally rather than by extrapolation, and the entire point of the model (holding full agent trajectories in one context). Independent support is stronger than in the first pass: the NIA long-text comprehension domain placed Upstage 2nd of 4, and a community NVFP4 build is reported reaching the **full 1M window on 2× DGX Spark**. Still not 100 because model-reported retrieval quality at 1M is AA-LCR 62.3% only, with no MRCR/RULER measurement at long lengths by anyone.
- **Multimodal: 15/100** (unchanged). **Text-only, confirmed by two independent sources.** AA states outright that it does not support image input and is not multimodal; CloudPrice lists text as the sole input and output modality. Floor score by methodology.
- **Coding: 78/100** (unchanged). LiveCodeBench v6 92.4%, SWE-bench Verified 70.4% and the huge generational jump over Solar Open 1 keep it high. **Deliberately not raised despite new material:** no *independent* coding number appeared this pass, and this pass established that BenchLM's Solar Open 2 page and the HF eval-results block are both **relabels of Upstage's own model card**, so every coding row is vendor-internal-harness. Held down by Terminal-Bench Hard 28.3%, ArtifactsBench 55.9%, SWE-bench Verified trailing DeepSeek-V4-Flash and MiMo-V2.5, and **no SWE-bench Pro, SciCode, DeepSWE or Vibe Code Bench data at all**.
- **Cost efficiency: 94/100** (was 93). **No hosted per-token price exists and the weights are downloadable at no license fee**, which makes marginal token cost zero for anyone who already runs GPUs — and this pass **lowered the effective hardware floor materially**: Upstage now officially documents **2× H200 with quantization** (4× H200 BF16), MSIT's own release cites the two-H200 figure, AutoRound INT4 runs at TP4, a globally expert-pruned NVFP4 build runs on **1× B200**, a W4A8 build is 132 GiB, and a 2× DGX Spark NVFP4 build reportedly reaches the full 1M context. Raised one point. Held off 100 because there is still **no cheap hosted API to fall back on**, because **no released vLLM supports the architecture** — every deployment needs Upstage's fork plus custom reasoning/tool-call parsers, which is real engineering cost and a supply-chain dependency — and because the Upstage Solar License is not a standard OSI-style open license despite Model Beat calling it unrestricted.
- **Overall Score: 67/100** (was 66). Arithmetic: **(Tool 70 + Reasoning 77 + Context 94 + Multimodal 15 + Coding 78) / 5 = 334 / 5 = 66.8 → 67** (half-up, cost efficiency excluded per `RULES.md`). Best fit: **Korean-language enterprise and officework agents on self-hosted sovereign infrastructure**, where a native 1M context with 256K output that fits whole agent trajectories, an independently 2nd-placed Korean/safety/long-text evaluation, and 15B active parameters per token deliver genuine value — and where the text-only limitation does not matter. Not the pick for multimodal work, frontier reasoning, hard agentic coding, or for anyone who does not want to maintain a vLLM fork. Weight the February 2027 stage-three finalist decision: Upstage's next iteration depends on a funding path the Korean government is openly reconsidering.
