## Model card

- **Name:** Claude Haiku 5.5 (this dataset maps to Artificial Analysis's **"Claude Haiku 5.5 (Max)"** — the reasoning version at maximum effort). Anthropic's **fastest, most cost-efficient small model** and "the most capable Haiku yet," sitting below **Claude Sonnet 5.5** and **Claude Opus 5.5**. Not to be confused with the older **Haiku 4.5** it replaces.
- **Short description:** **Anthropic's subagent engine — released 2026-10-07, "built for high-volume work like summarization, subagents, and browser use," and designed to run "many parallel sub-agents."** Its headline independent result is exceptional for a small/cheap model: **AA Intelligence Index v4.3.2 = 43, #4/173** ("amongst the leading models in intelligence," well above the class **median of 13**) — which **beats GPT-6 Luna (38, #11/173) at the identical $0.10/$0.50 price**. Anthropic's own launch table (corroborated to the decimal by independent benchlm.ai/BenchAlign v5.8) shows it **sweeping GPT-6 Luna on every shared benchmark** — **OSWorld 2.1 72.4% vs 48.9%, Terminal-Bench 4.0 39.2% vs 16.4%, GDPval-AA 1,620 vs 1,437, AA-Briefcase 1,578 vs 1,336, FrontierCode 46.4% vs 42.4%, Chartography 46.4% vs 29.1%** — while **trailing Sonnet 5.5** on the hardest coding/professional work (Terminal-Bench 39.2% vs 70.6%). The scaffolded meta is **largely ACCURATE** (verified, not corrected); its "small-model reasoning ceiling" tradeoff is well-supported, though it omits the two real cost caveats: **most-verbose-in-class (#69/69, 440M Index tokens)** and a **322s time-to-first-token at max effort**.
- **Provider / access:** **Anthropic** — first-party Claude API (model ID `claude-haiku-5-5`), **Claude.ai and Claude Code**, plus **Amazon Bedrock, Google Cloud (Vertex) and Microsoft Foundry** (AA lists **6 API providers**). **Proprietary** (weights/parameters undisclosed). `noFreeId` not set in meta but no free tier is advertised. Listed here as `opencode/claude-haiku-5.5`.
- **Release / knowledge:** **2026-10-07.** **Current — not deprecated.** (Knowledge cutoff not published in the sources reviewed.)
- **IDs:** `claude-haiku-5-5` (Anthropic API) / `claude-haiku-5-5` (Artificial Analysis slug) / `opencode/claude-haiku-5.5` (this dataset).
- **Context window:** **1,000,000 total (128,000 max output).** *Verified against the meta's "1,000,000 total (128K max output)," AA ("1M tokens"), and emergent.sh ("1 million-token context window and up to 128,000 output tokens").* ~1500 A4 pages — **the largest window in the budget tier and the cheapest 1M-context model here at $0.10/$0.50**. Long-context reasoning is an **Index component (AA-LCR v1.1)**; the meta cites **AA-LCR 82.7%** (not independently re-read here — the AA chart value). ⚠ Prompts **over 100K tokens jump to $0.50/$2.50** (a 5× input surcharge), so full-window use is not flat-rate.
- **Modalities:** **Text + image + PDF in → text out.** *Verified against the meta's "Text, image, PDF in; text out."* AA categorizes input as "text and image," but **native PDF/document ingestion is a real Anthropic capability**. Reasoning: **yes** ("adaptive thinking with an adjustable effort setting"). **No native video or audio.** Visual reasoning is corroborated: **Chartography 46.4% (beats GPT-6 Luna's 29.1%), ParseBench 56.1%** (benchlm).
- **Pricing (as of 2026-10-25):** **Prompts ≤100K: $0.10 input / $0.50 output per 1M** (cache reads **$0.01**, 5-min cache writes **$0.125**); **prompts >100K: $0.50 / $2.50** (cache reads $0.05, writes $0.625). *Verified exactly against the meta's pricingNote + emergent.sh's table.* AA blended (7:2:1) = **$0.08 per 1M**; both input and output are "very competitive" (medians $0.24 / $0.80). **90% cheaper per token than Haiku 4.5** ($1/$5). ⚠ But **$0.21 per Intelligence Index task** (3× GPT-6 Luna's $0.07) because of extreme verbosity.
- **Architecture:** **Proprietary; parameter count undisclosed** ("Anthropic has not disclosed the model size"). A **reasoning** model with **adaptive/adjustable thinking effort** (the "(Max)" variant runs extended thinking). ⚠ **Most verbose model in its class (#69/69): 440M output tokens across the Index vs a 100M median**, and **TTFT 322.16s at max effort** (vs 1.70s class median) — the extended-thinking cost of the max setting; lower effort settings are far snappier (234.2 tok/s decode).

### Normalized scores (1–100)

- **Tool use: 84/100.** A genuine agentic strength for its class: **OSWorld 2.1 72.4%** (near-frontier computer use — beats GPT-6 Luna's 48.9%, approaches Sonnet 5.5's 83.9%), **GDPval-AA v2.1 1,620** and **AA-Briefcase v1.1 1,578** (both beat GPT-6 Luna, trail only Sonnet 5.5), **Terminal-Bench 4.0 39.2%** (independently corroborated), and a **benchlm Agentic lane of 61.4 (#25/132)** — all in a model explicitly "built for browser use" and "parallel sub-agents." Capped below 88 (verified-agentic-leader) because **Terminal-Bench 39.2% is mid in absolute terms** (Sonnet 5.5 70.6%) and it is a small model that delegates the hardest planning. Scored **84** (top of the strong-independent-agentic band), above GPT-6 Luna (80) and grok-4.3 (82).
- **Reasoning: 82/100.** **AA Intelligence Index v4.3.2 = 43, #4/173, well above the median of 13** — the highest Index of any model at this price point (GPT-6 Luna 38), reinforced by strong independent **ARC-AGI-2 61.3% / ARC-AGI-1 89.0%**, **FrontierMath v2 T1–3 75.1%**, and **HLE 45.9% (no tools) / 57.4% (with tools)**. Capped at **82** (not the 84 frontier band) by the **small-model reasoning ceiling**: it trails Sonnet 5.5 (Index/HLE 56.9%) and the frontier (Opus 5.5 Index 58, Astra 53, Sol 48), and AA-LCR long-context is strong but not top. Sits above GPT-6 Luna (81) on the higher Index and richer reasoning evidence.
- **Context window: 86/100.** **1,000,000 total (128K max output)** — verified across three sources, **the cheapest 1M-context model in the dataset at $0.10/$0.50**, with long-context reasoning validated as an **Index component (AA-LCR v1.1; meta reports 82.7%)**. Scored **86** — above the "1M proven" band (85, e.g. GPT-6 Luna) for the added AA-LCR long-context-reasoning evidence and dominant price, but held just under the top "validated-1M" 87 because the specific AA-LCR value is meta-asserted (not independently re-read here) and **>100K prompts incur a 5× input surcharge** ($0.10→$0.50).
- **Multimodal: 78/100.** **Text + image + PDF in → text out**, with corroborated visual reasoning — **Chartography 46.4% (beats GPT-6 Luna's 29.1%, Haiku 4.5's 6.4%)** and **ParseBench 56.1%**. **No native video or audio**, and Chartography 46.4% is mid (Sonnet 5.5 61.6%). Scored **78** — the standard image+file tier (level with GPT-5/GPT-6 Luna); the native PDF ingestion and verified Chartography are noted but don't reach the native-video band (grok-4.3 82, Seed 2.0 Pro 84).
- **Coding: 78/100.** Multiple **corroborated independent** anchors — **Terminal-Bench 4.0 39.2%** (3× GPT-6 Luna's 13–16.4%), **FrontierCode 1.1 Main 46.4%**, **FrontierSWE v2 43.8%**, **Bug Hunt Bench 21.5 fixes** — position it for "focused edits, simple bug fixes, test generation, and delegated tasks." Capped at **78** (mid) because it has **no SWE-bench Verified row**, **clearly trails Sonnet 5.5** (Terminal-Bench 70.6%, FrontierCode 52.1%) and the elite independent coders (Opus 5 ~97% SWE-bench), and Anthropic itself frames it as the delegate-not-architect tier. One notch above GPT-6 Luna (77) for the stronger, corroborated Terminal-Bench/FrontierCode.
- **Cost efficiency: 90/100.** **Rock-bottom token price** — **$0.10/$0.50** (≤100K), cache reads **$0.01**, blended **$0.08/M**, **90% cheaper than Haiku 4.5**, and the **cheapest 1M-context + Index-43 model** here; AA calls both input and output "very competitive." Held to **90** (below GPT-6 Luna's 94) because it is the **most verbose model in its class (#69/69, 440M Index tokens vs a 100M median)**, which drives **$0.21 per Intelligence Index task — 3× GPT-6 Luna's $0.07** — plus a **322s max-effort TTFT**; per-token it is the cheapest, but per-completed-task GPT-6 Luna's lower verbosity wins. (Not counted in Overall.)
- **Overall Score: 82/100.** Mean of the five quality dimensions = (84 Tool + 82 Reasoning + 86 Context + 78 Multimodal + 78 Coding) / 5 = **408/5 = 81.6 → 82** (Cost efficiency 90 is scored but **not** counted, per the v4 formula). **Divergence note:** my independent read is **82 vs the queue's curated 83.5 → −1.5**, one of the **narrowest** gaps in this batch — appropriately so, because Claude Haiku 5.5 is a **current, exceptionally well-corroborated model** (unlike the deprecated GPT-5/5.1, whose −5 to −6 gaps reflect rebasing). The curated **83.5** and my **82** agree it is the **class-leading budget model**: it **beats GPT-6 Luna on every shared benchmark at the same price** (Index 43 vs 38, OSWorld 72.4 vs 48.9, Terminal-Bench 39.2 vs 16.4) and posts a top-quintile agentic lane. My score sits a touch below the curated value only for the two real ceilings the evidence shows — the **small-model reasoning cap** (trails Sonnet 5.5 on every hard axis) and the **extreme verbosity** (#69/69, 3× GPT-6 Luna's cost/task). Best fit: exactly Anthropic's target — **fleets of parallel sub-agents, high-volume summarization/classification/extraction, browser/computer automation, and delegated focused coding**, where its 84-tool / 86-context / 90-cost carry the load and a stronger model (Sonnet/Opus) handles architecture and long-horizon engineering.
