## Model card

- **Name:** Ling-3.0-flash
- **Short description:** InclusionAI's **hybrid reasoning MoE model** — **124B-total / 5.1B-active**, activating ~1/64 of its parameters per token, released **2026-07-23** on OpenRouter (Vercel dates its listing 2026-08-06; the first pass cited 2026-08-02 from ApX — **three release dates in circulation, unresolved**). Its thesis is **efficiency and production deployment**: among the fastest models measured anywhere and among the cheapest, trained on **10,000+ interactive environments** for closed-loop execution across coding, general and deep-research agent tasks. Top use case: high-throughput production agents in Claude Code, Kilo Code, Qwen Code, Hermes Agent and OpenClaw.
- **Provider / access:** Hugging Face `inclusionAI/Ling-3.0-flash` (**MIT**, 46 quantizations, FP8 and GGUF variants, Inference Providers incl. Novita); ModelScope; **OpenRouter** `inclusionai/ling-3.0-flash` (**NovitaAI 65% off and DeepInfra**, 100% / 99.49% uptime); InclusionAI's direct API (requires a personal Alipay account); Vercel AI Gateway. Self-host via SGLang (`lmsysorg/sglang:dev-Ling-3.0-flash`) or vLLM, with MTP speculative decoding. The official ling-cookbook now ships **six** deployment recipes for this model alone — DGX Spark SGLang MXFP4 / MXFP4 / INT4, vLLM FP4 / INT4, and **llama.cpp GGUF Q6_K / Q4_K** — which is new local-runtime coverage the first pass did not record. No OpenCode Zen ID for this base model.
- **Release / knowledge:** Released **2026-07-23** (OpenRouter catalogue; LiteLLM added it 2026-08-27); AA says "Released August 2026"; Vercel lists 08/06/2026. Knowledge cutoff: not disclosed.
- **IDs:** `inclusionAI/Ling-3.0-flash` (HF), `inclusionai/ling-3.0-flash` (OpenRouter)
- **Context window:** **262,144 tokens native** (256K), trained on a progressive **8K → 32K → 256K** schedule, confirmed by the SGLang/vLLM recipes (`--context-length 262144`). **NEW this pass:** InclusionAI's official long-context docs page (published **2026-10-08**) adds **"Ling-3.0-flash: Native 256K context window, extendable up to 1M"** — beyond 256K via YaRN (`SGLANG_ALLOW_OVERWRITE_LONGER_CONTEXT_LEN`). **NEW caveat:** the hosted routes do **not** all serve 262K — **DeepInfra's bf16 route is listed at 128–131K** while Novita's is 256–262K (LiteLLM and ModelCap agree on this). Max output **32,768**.
- **Modalities:** **Text in → text out only.** The HF repo is a `Text Generation` `bailing_hybrid` causal LM; AA lists text for both input and output. Reasoning: **thinking mode enabled by default** (disable with `chat_template_kwargs: {"enable_thinking": false}`); defaults temperature 0.6, top_p 0.95, top_k 20. Tool calls / function calling: yes (`--tool-call-parser ling3`, `--enable-auto-tool-choice`). Prompt caching: yes ($0.0042/1M cached on OpenRouter, one fifth of the discounted input rate).
- **Pricing (as of 2026-10-17):** **CORRECTED — the first pass's "$0.075 in / $0.22 out" is stale.** OpenRouter's live price is **$0.021 in / $0.063 out / $0.0042 cache read**, badged **"65% off"** a **$0.06 / $0.18 / $0.012 list**. InclusionAI's own official pricing page gives the CNY list as **¥0.50 → ¥0.14 in, ¥1.50 → ¥0.42 out, ¥0.10 → ¥0.028 cache** (a **72%** discount) and states the USD OpenRouter rate as **$0.06 → $0.0168 / $0.18 → $0.0504 / $0.012 → $0.0034**. **Conflict recorded:** OpenRouter's badge says 65% off and its effective price is $0.021/$0.063, while Ant's own table implies 72% off at $0.0168/$0.0504. Both are current; the effective price you pay depends on the reseller. **CRITICAL: the discount is explicitly limited-time and NO end date is published.** Ant's page says "Original prices will gradually resume after the promotional period ends"; the vendor described the window as running "through September 2026" and the homepage still advertised it as limited-time when re-read on 2026-10-01. **The $0.075/$0.22 rate the first pass recorded is what AA's own model page still displays — i.e. AA's price row is stale, not the OpenRouter row.** MIT weights make self-hosting free of token cost. No free API tier for this base model (the `:free` variant was removed from OpenRouter on 2026-10-13).
- **Architecture:** Hybrid-linear MoE, **124B total / 5.1B activated**. **35 KDA + 7 Gated MLA transformer layers in a 5:1 alternating stack** — Kimi Delta Attention with fine-grained diagonal gating, combined with MLA — plus **1/64 sparse MoE** with 512 routed experts (8 activated) and 1 shared expert. 2 dense layers; 32 attention heads; hidden size 2,560; expert intermediate 768; dense intermediate 6,144; vocabulary 157,184; 1 multi-token-prediction head. Native hybrid-linear attention **from the start of pretraining** — not a retrofit. Natively integrates **SGLang HiCache + Mooncake hierarchical caching**, cutting TTFT 60–80%+ on long inputs.

### Normalized scores (1–100)

- **Tool use: 66/100** *(was 62).* Raised because the missing numbers turned out **net positive for tool calling specifically.** The first pass could only say "InclusionAI names Tau3-banking-AA, MCP-Atlas, SkillsBench, GDPval v2-AA, BrowseComp, WideSearch and Draco as strengths but publishes no numbers for any of them," and scored on Terminal-Bench 2.1 50.2%, AA-Briefcase 796 Elo, AutomationBench 3% and Terminal-Bench 4.0 0%. Now measured: **BFCL-V4 73.0 — which ties Claude Sonnet 4.6 at max effort in the vendor's own chart**, **MCP-Atlas 65.5**, **BrowseComp 72.2 / 82.0**, **WideSearch 73.6**, **Draco 70.4**, **Hermes Bench 53.8**, **SkillsBench 44.8**, **SysBench 93.6**. Capped at 66 — not higher — because **the single benchmark InclusionAI leads with, Tau3-banking-AA, measures 27.2% independently (#26 of 90, level with GPT-5.4-mini)**, **AutomationBench-AA has been revised to 0.0%**, **Terminal-Bench 4.0 is a verified 0.0%**, **AA-Briefcase is 796 Elo**, **GDPval-AA is 22.4%**, and **AA Agentic Index is only 19.3–21.0**. The profile is now clear and it is split: **excellent at calling tools in the short, structured, benchmark-shaped sense; weak at long-horizon professional work.** That is a dispatch-and-execute model, not an autonomous agent.
- **Reasoning: 73/100** *(was 74 — a small downgrade).* GPQA Diamond is up to **85.5%** and HLE to **23.7%** on independent AA runs, with AIME26 93.2%, HMMT 87.0%, IMOAnswerBench 83.7% and IFBench 74.5%. Downgraded one point because this pass made the **knowledge-reliability** weakness concrete: **AA-Omniscience Accuracy 18.2% with a 44.1% hallucination rate and an Omniscience score of −17.9**, plus **CritPt 1.7–2.0%** and an Intelligence Index of only 20.1. The strong exam rows and the poor self-knowledge rows are both real and both belong in this score.
- **Context window: 93/100** *(was 90).* The strongest improvement in this report's context dimension, on three pieces of evidence: **native 262,144 on a documented 8K→32K→256K training schedule**; **vendor MRCR 90.8% at 128K and 81.1% at 256K**, which is at or near the top of every peer in the vendor's own chart including Claude Sonnet 4.6 (92.5 / 92.7) and Ring-2.6-1T (90.1 / 76.5); and **independent AA-LCR at 73.0%**, where the vendor's own card claims a *lower* 65.1. InclusionAI's official docs page now also states the window is **extendable to 1M**. Held at 93 rather than higher because **DeepInfra's hosted bf16 route serves only 128–131K**, so "262K" is route-dependent, and because no independent RULER/GraphWalks/LongBench-v2 measurement exists.
- **Multimodal: 15/100.** Unchanged — **text-only**, confirmed by the HF repo being a `Text Generation` causal LM and by AA listing text for both input and output. Floor score by methodology. The vision-capable sibling in this family is **Ling-3.0-flash-VL**, a different model, and it was **retired 2026-09-22** by at least one gateway (LLMTR).
- **Coding: 72/100.** Unchanged, and the new evidence brackets it tightly. Up: **Terminal-Bench 2.1 revised up to 55.4% independent / 57.0% vendor** (from the 50.2% Vals figure the first pass used), **ArtifactsBench 77.0**, **SWE-bench Multilingual 72.4%**, **LiveCodeBench 82.8–84.0%**, **AntSWEBench 52.2**. Down: **Terminal-Bench 4.0 = 0.0% (verified)**, **SciCode 41.2–42.0%**, **MiniAppBench 25.3%**, **AA Coding Index 50.6**. For a 124B/5.1B-active model the ceiling is real but so is the floor.
- **Cost efficiency: 97/100** *(was 98).* **The price is now materially cheaper than the first pass recorded — $0.021/$0.063 rather than $0.075/$0.22, a further ~3.5× cut on the already-discounted rate, and #3 cheapest of AA's five InclusionAI models at a $0.05 blended price.** The point lost is durability, not price: Ant's own page states the **72% discount is limited-time with no published end date**, the vendor described the window as running "through September 2026" (already elapsed) while still advertising it as limited-time on 2026-10-01, and AA flags the model as **#13 of 13 on verbosity (260M tokens vs a 100M median)** — which erodes much of the per-task advantage of a very low tariff. It is also **deprecated by AA** and the `:free` variant was removed on 2026-10-13. MIT weights keep the self-host floor at zero.
- **Overall Score: 64/100.** `(Tool 66 + Reasoning 73 + Context 93 + Multimodal 15 + Coding 72) / 5 = 319 / 5 = 63.8 → 64`. Best fit: **high-throughput, low-cost production agents and subagents** — Claude Code / Kilo Code / Qwen Code / OpenClaw loops, deep-research and BrowseComp-shaped agents, and high-volume routing — where 271 t/s, a natively trained 262K window with MRCR 90.8/81.1, BFCL-V4 73.0 and MIT weights are a combination nothing else in this repo matches. Not the pick for long-horizon professional knowledge work (AA-Briefcase 796 Elo, AutomationBench 0.0%), document work (GDP.pdf 5–6%), or hard SWE-agentic loops (Terminal-Bench 4.0 = 0%). If you are starting something new, note that **InclusionAI now points at `ling-3.1-flash` (Index 41 vs 20) and that this model carries a limited-time discount with no end date** — cost your pipeline at the $0.06/$0.18 list and treat the discount as upside.
