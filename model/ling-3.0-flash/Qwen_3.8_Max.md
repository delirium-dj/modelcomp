> **Verdict:** Ling 3.0 Flash is **InclusionAI (Ant Group's AGI programme)'s open-weight "intelligence-density" reasoning model** — a **124B-total / 5.1B-active (≈12.4%) MIT hybrid-linear Mixture-of-Experts** (the **BailingMoeV3** family: **35 Kimi Delta-Attention layers interleaved 5:1 with 7 Gated-MLA layers, 512 routed experts + 1 shared, 8 experts active/token**, trained on an 8K→32K→256K context schedule and served at **262,144**) announced **late July 2026** (26 Jul; free API 23 Jul–3 Aug, HF weights 2 Aug, AA dates it 4 Aug), **native hybrid reasoning (thinking on by default), TEXT-ONLY**. Its thesis is *doing more useful work per token*: it matches far larger models on **structured reasoning and tool-calling primitives** — independent **GPQA Diamond 85.5% (82nd pct)**, **AIME 2026 93.2%**, **BFCL-V4 73.0% (97th pct, #4/102 function calling)**, **Multi-IF 87.7% (#1)**, **AA-LCR 73.0%**, and MRCR long-context retrieval of **74.3% in reasoning mode (88th pct)** — at rock-bottom cost (**$0.075/$0.22 first-party, AA-blended $0.05; OpenRouter/Vercel routes $0.021/$0.063; free MIT self-host**) with **exceptional speed (AA 266.0 tok/s, #2/26, 4-of-4)**. **But the agentic ceiling and reliability are the honest weakness:** on the hard modern agent benchmarks it collapses — **AA v5.0 Terminal-Bench 4.0 ≈ 0% and AutomationBench-AA ≈ 3%**, **Vibe Code Bench 2.9%**, **SWE-bench Pro 56.6% (32nd pct)**, **BrowseComp 72.2% (24th pct)**, **MCP Atlas 65.5% (31st pct)**, **DuelLab GameBench dead-last (23.7, 0th pct, 48.4% code-failure)** — with **frontier reasoning soft (HLE 23.7%)**, **factual reliability poor (meta-cited 44.1% hallucination; ObviousBench 70.1% at 37th pct = frequent "obvious" mistakes)**, and the vendor's "matches 2–3× its size" claim published only as **chart images, not a numeric table**. It is **DEPRECATED** — the successor **Ling 3.1 Flash (560B/25B, a genuinely different/larger base, so meta's "same base" note is inaccurate)** carries a much stronger profile; AA's current **v5.0 Intelligence Index is N/A** and the aggregator-cited **"38" is a pre-v5.0 (v4.x) reading, non-convertible**. Scored Overall **66** (div **+1.5** vs curated 64.5) — a fast, dirt-cheap, strong-*per-token* open-weight reasoner whose elite function-calling / math-science / long-context efficiency lift it slightly above the curated value, capped by a weak modern-agentic ceiling, poor reliability, text-only modality, and end-of-life status.

## Model card

- **Name:** Ling 3.0 Flash
- **Short description:** InclusionAI (Ant Group)'s **open-weight MIT hybrid-reasoning MoE** — 124B total / 5.1B active on a native hybrid-linear (KDA 5:1 Gated-MLA) BailingMoeV3 stack, 262K context, built for **agent workloads and "intelligence density per token."** Strong structured reasoning (GPQA 85.5, AIME 93.2), best-in-class function calling (BFCL 73), and rock-bottom cost/speed, but a weak modern-agentic ceiling (TB4.0≈0%, Vibe 2.9%), poor factual reliability (halluc ~44%), text-only, and now **deprecated by Ling 3.1 Flash**.
- **Provider / access:** **Open weights** on **Hugging Face + ModelScope (MIT, free commercial self-host)**; served via **InclusionAI first-party API, OpenRouter (`inclusionai/ling-3.0-flash`), Vercel AI Gateway, Kilo** — AA counts **2 API providers**. Launched as a **free API through 3 Aug 2026** then paid. Recommended serving: SGLang with **HiCache + Mooncake** hierarchical caching on **4× 141GB (H20-3e) at TP=4** or **8× 80GB (H100/H800) at TP=8**, NEXTN speculative decoding. `noFreeId: true`. **DEPRECATED** — AA banner points to **Ling 3.1 Flash** instead.
- **Release / knowledge:** **Announced 26 July 2026** by Ant Group (free-API window ~23 Jul–3 Aug; **HF weights published 2 Aug 2026**; AA records "released August 4, 2026"; meta/orcarouter say Jul-24/Aug-2026). Successor to the Ling-2.6 line; **superseded by Ling 3.1 Flash (30 Sep 2026)**. Knowledge cutoff not separately published.
- **IDs:** id `inclusionai/ling-3.0-flash`; API `ling-3.0-flash`; AA `ling-3-0-flash`; HF/ModelScope `inclusionAI/Ling-3.0-flash`; family **BailingMoeV3**. **AA page EXISTS but deprecated** — only the default 10k-input workload is still benchmarked; Intelligence Index / Cost-per-task / Verbosity all **N/A**. **Distinct variants (do NOT conflate):** `Ling-3.0-flash-VL` (vision-language, 124B/**5.5B** active, multimodal), `Ling-3.0-flash-Fin` (finance), `Ling-3.0-tiny`, `Ling-3.0-flash-int4` (quant), and the successor `Ling-3.1-flash` (**560B/25B** — different/larger base).
- **Context window:** **256K trained (8K→32K→256K schedule) / 262,144 served** (inclusionAI's SGLang recipe; AA spec table 262k, FAQ "260k"). **Native hybrid-linear attention (KDA + Gated-MLA) is purpose-built for long-context efficiency.** MRCR retrieval is strong *within* the window (reasoning-mode 74.3% avg, AUC@128K 66.9%; AA-LCR 73.0%) but collapses far beyond it (AUC@1M 7.5–10.8%).
- **Modalities:** **Text input → text output only.** AA is explicit: *"not multimodal. It only supports text input."* **Reasoning:** **native hybrid** — thinking enabled by default with a non-thinking mode; reasoning mode visibly lifts long-context retrieval (MRCR 50.2→74.3) and latency/TTFT trade cost.
- **Pricing:** **First-party $0.075/$0.22 per 1M** (AA: blended 7:2:1 **$0.05**, 80% cache); **OpenRouter / Vercel routes $0.021/$0.063** (rock-bottom); **MIT self-host $0**. AA rates both input and output "very/competitively priced" (vs medians $0.30 / $0.80). Among the cheapest capable open-weight models.
- **Architecture:** **124B-total / 5.1B-active sparse MoE (BailingMoeV3), 1/64 routing over 512 routed + 1 shared experts, 8 active/token.** **Native hybrid-linear attention from the start of pretraining: 35 Kimi Delta-Attention (KDA) layers interleaved 5:1 with 7 Gated-MLA layers**, KDA fine-grained diagonal gating; hidden 2,560, 32 heads, 157,184-token vocab. Trained across **10,000+ interactive environments** (coding / general / deep-research agents); exercised against **Claude Code, Kilo Code, Qwen Code, Hermes Agent, OpenClaw** harnesses. activates ≈**12.4% of its own params** and ≈**8.1% of the Ring-2.6-1T flagship's active params**.

- **Agent / tool use:** A **split picture**. The **function-calling primitive is elite** — **BFCL-V4 73.0% (97th pct, #4/102)**, **Tau3-Banking 28.0% (77th pct)** — and it is explicitly trained for agents (**10,000+ environments**, Claude Code/OpenClaw harnesses). **But multi-step autonomy is weak**: **MCP Atlas 65.5% (31st pct)**, **BrowseComp 72.2% (24th pct)**, and the hardest modern suites collapse — **AA v5.0 AutomationBench-AA ≈ 3%, Terminal-Bench 4.0 ≈ 0%**, **Vibe Code Bench 2.9%**, **AA-Briefcase 798 Elo (46th pct, rubric 17.4%)**. A superb single-shot tool-caller, a mediocre long-horizon agent.
- **Reasoning / knowledge:** **Strong on structured exam-style reasoning** — **GPQA Diamond 85.5% (82nd pct, independent)**, **AIME 2026 93.2%**, MMLU-class breadth, and **native hybrid reasoning** that measurably improves downstream tasks (MRCR 50.2→74.3). **Weak at the frontier and on reliability** — **HLE 23.7%**, **AIIQ composite 104 (39th pct)**, and **factual reliability is a real liability (hallucination ~44.1%; ObviousBench 70.1% answer-pass at 37th pct = frequent simple, high-visibility mistakes)**.
