## Model card

- **Name:** GPT-6 Luna (this dataset maps to Artificial Analysis's **"GPT-6 Luna (Max)"** — the reasoning version at maximum effort). The **low/budget tier** of OpenAI's GPT-6 family, sitting below **GPT-6 Sol** (mid) and **GPT-6 Astra** (flagship). Not to be confused with the older **GPT-5.6 Luna** it replaces.
- **Short description:** **OpenAI's cost-efficiency workhorse — released 2026-09-22 (about 90 minutes after Anthropic's Claude Opus 5.5), aimed at "high-volume tasks with a clear goal, like summarizing documents, extracting information, or answering quick questions."** Its defining result is the **cost-per-intelligence Pareto frontier**: at **$0.10/$0.50 per 1M** it scores **AA Intelligence Index v4.3.2 = 38 (#11/173, "amongst the leading models in intelligence," well above the class median of 13)** for just **$0.07 per Index task** — a 50% price cut from GPT-5.6 Luna ($0.20/$1.20) with **flat intelligence but ~60% lower cost/task and a hallucination rate that drops from 93% → 77%**. ⚠ Tosea's verdict is the honest one: "**a pricing and reliability release more than an intelligence release**" — and its **independent agentic/coding signals actually regressed** vs GPT-5.6 Luna (**Coding Agent Index 43 → 41, SWE-Atlas-QnA 49% → 44%, Terminal-Bench 4.0 12% → 13%** still weak). The **scaffolded meta's "not built for hard reasoning" tradeoff is UNDERSTATED/partially contradicted** by that #11/173 Index — it *is* a class-leading reasoner for its price, just below Sol/Astra/Opus 5.5.
- **Provider / access:** **OpenAI** — first-party API (`gpt-6-luna`) via **Chat Completions, Responses and Batch APIs**, with the **full hosted tool set** (web search, file search, code interpreter, hosted shell, apply patch, skills, computer use, MCP, tool search, image generation). In ChatGPT it reaches **Work and Codex** tiers plus **Free and Go** users in the desktop app. **Proprietary** (weights undisclosed). `noFreeId: true`. Listed here as `openai/gpt-6-luna`.
- **Release / knowledge:** **2026-09-22.** **Current — not deprecated** (unlike GPT-5/5.1/5.2 in this dataset). **Knowledge cutoff: May 18, 2026** (later than Sol's Apr 20, 2026).
- **IDs:** `gpt-6-luna` (OpenAI API) / `gpt-6-luna` (Artificial Analysis slug) / `openai/gpt-6-luna` (this dataset).
- **Context window:** **1.05M total (≈922,000 max input + 128,000 max output).** *Enriches the meta's vague "1M tokens" and matches AA ("1M tokens") + the tosea spec table.* ~1500 A4 pages. The largest window in the budget tier and economically viable at $0.10/$0.50 — the meta's standout ("1M context at pocket change"). ⚠ Prompts **over 272K tokens are billed at 2× input/cache + 1.5× output**, so the full window is not flat-rate. No independent long-context retrieval score (MRCR/RULER) surfaced, so effective-use at 1M is asserted, not validated.
- **Modalities:** **Text + image in → text out** (image-only). *Verified against the meta's "Text, image in; text out" and AA's "supports text and image input, outputs text."* Reasoning: **yes** (effort `none`→`max`, default `medium`). **No native video or audio.**
- **Pricing (as of 2026-10-25):** **$0.10 input / $0.50 output per 1M** (cached input **$0.01**, cache writes **$0.125**; 90% cache-read discount). *Enriches the meta's vague "Paid-tier pricing."* A **flat 50% cut** from GPT-5.6 Luna's $0.20/$1.20. **$0.07 per Intelligence Index task** (#26/66). Fine print: Batch/Flex half price; Fast mode 2×; >272K prompts 2×/1.5×; caching improved (higher hit rates, explicit breakpoints, change effort/toggle tools mid-conversation without invalidating cache).
- **Architecture:** **Proprietary; parameter count undisclosed.** Trained "**with similar methods as GPT-6 Astra**" (OpenAI), distilled into a budget tier. Inherits Astra's communication style ("more clarity, less jargon... slightly shorter answers"). Adaptive reasoning via `reasoning_effort`. ⚠ **Verbose**: 140M tokens across the Index / **~51K output tokens per task (~25% more than GPT-5.6 Luna's 41K)** — this eats into the per-token discount (though the $0.07/task figure already reflects it).

### Raw benchmarks found

GPT-6 Luna is a **current** model, so it has a **full independent Artificial Analysis evaluation** (Index v4.3.2, Coding Agent Index v1.5, Terminal-Bench 4.0, SWE-Atlas-QnA, AutomationBench-AA, AA-Omniscience) alongside OpenAI's vendor cost-vs-score charts — letting me separate the measured story from the marketed one.

**Independent — Artificial Analysis (launch day, 2026-09-22):**

- **AA Intelligence Index v4.3.2 = 38, #11/173** — "**amongst the leading models in intelligence**," well above the class **median of 13**. (The tosea AA table reads **37**; the AA model page reads **38** — quoted as **~37–38**, AA page authoritative. Flat vs GPT-5.6 Luna's 37.)
- **AA cost per Intelligence Index task = $0.07** (#26/66) — the **cost-per-intelligence frontier**; GPT-5.6 Luna was $0.18, Sol is $1.06, Opus 5.5 ~$6.
- **Coding Agent Index v1.5 = 41** — **DOWN 2 from GPT-5.6 Luna's 43** (regressed). Fell on **SWE-Atlas-QnA 44% (from 49%)** and **DeepSWE v1.1 64% (from 66%)**.
- **Terminal-Bench 4.0 = 13%** — **WEAK** (GPT-5.6 Luna 12%; Sol 43%; Astra higher).
- **AutomationBench-AA = 53%** — improved from GPT-5.6 Luna's 50% (Sol 62%).
- **AA-Omniscience hallucination rate = 77%** — improved sharply from GPT-5.6 Luna's **93%** (Sol 60%, Astra 51%, Opus 5.5 59%), but still **answers incorrectly on >3/4 of questions it should decline** → needs source grounding for factual work.
- **Speed 140.1 tok/s** (#54/151 — faster than the 116 average). **Verbosity #43/69** (140M Index tokens vs 100M median).

**Vendor — OpenAI (launch post, max effort; presented as score-vs-cost charts):**

- **DeepSWE v1.1 (long-horizon SWE): 66.6% at $0.22/task** (= the meta's headline figure; below Astra xhigh 74.1%, Opus 5 73.7%, GPT-5.6 Sol 72.7%, Sol 68.8%).
- **AutomationBench 1.0.6 (business workflows, 47 tools): 20.7% at $0.037/task** (Astra 41.4%, Sol 33.2%, Opus 5.5 40.0%).
- **Agents' Last Exam V1 (long-horizon professional, 55 sub-industries): 50.9% at ~$0.15/task** (Sol 56.4%, Astra 59.3%, Opus 5 55.9%).
- **FrontierCode 1.1 Main (mergeability-graded): 42.4% at ~$0.11/task** (Sol 49.3%).
- **OSWorld 2.0 (offline, partial reward): 52.7%** — OpenAI notes this "**exceeds GPT-5.6 Sol at medium effort at one-tenth the cost**" (Sol max 64.4%, Astra 73.5%).
- **Factuality (internal, de-identified flagged ChatGPT conversations):** Luna at higher effort "**matches GPT-5.6 Sol at about a hundredth of its cost**" — corroborated directionally by AA-Omniscience's 93%→77% drop.
- **Alignment:** coding-deception rate **2.8%** (Sol 1.3%), **down from GPT-5.6 Sol's 10.4%** (Decrypt, system-card coverage).

> Provenance: A **current budget-tier model** whose story is **cost and reliability, not raw intelligence**. The **independent AA Index v4.3.2 = ~37–38 (#11/173, well above the median 13)** is a genuinely strong *for-price* result that **partially contradicts the scaffolded meta's "not built for hard reasoning" tradeoff** — but AA also shows the intelligence is **flat vs GPT-5.6 Luna** and that its **agentic/coding metrics regressed** (Coding Agent Index 43→41, SWE-Atlas 49→44, Terminal-Bench still 13%), with hallucination (77%) still high in absolute terms. **The scaffolded meta.json is largely ACCURATE but under-specified and one field is misleading** — `openai/gpt-6-luna`, "$0.10/$0.50 low-cost Luna tier," "1.05M context," "**DeepSWE 66.6%**," "Text, image in; text out," and the standout ("**extraction workhorse: 1M context at pocket change**") all verify against OpenAI + AA + tosea. **Enriched here:** the vague `contextWindow` ("1M tokens" → **1.05M / 922K-in / 128K-out**) and `pricingNote` ("Paid-tier pricing" → **$0.10/$0.50, cached $0.01/$0.125, $0.07/Index-task**). **Flagged/corrected:** the `tradeoff` "**Not built for hard reasoning**" is **understated** — it is class-leading on AA Index for its price (#11/173) though below Sol/Astra/Opus 5.5, and the sharper caveat is **weak terminal/agentic coding (Terminal-Bench 13%, Coding Agent Index regressed to 41) + high hallucination (77%) + verbosity**, not a blanket inability to reason. AA Index is quoted **per basket version (v4.3.2)** and never cross-converted to the launch-era v4.1 numbers. **No benchmark was invented; the AA-page 38 vs tosea-table 37 discrepancy is stated.**

### Normalized scores (1–100)

- **Tool use: 80/100.** The **full hosted tool set** (web/file search, code interpreter, hosted shell, apply patch, skills, computer use, MCP, tool search, image gen) plus genuine **computer-use value — OSWorld 2.0 52.7% "exceeds GPT-5.6 Sol at medium at 1/10 cost"** and **AutomationBench-AA 53% (up from 50%)**. But the agentic picture is **split and net-regressed**: **Coding Agent Index 41 (down 2)** and **Terminal-Bench 4.0 13% (weak)** with **SWE-Atlas-QnA 44% (down from 49%)**. Scored **80** — the strong computer-use/automation-for-cost offsets the terminal/coding-agent regressions, keeping it level with GPT-5 (79) / just under grok-4.3 (82, which has measured GDPval-AA/τ²-Bench).
- **Reasoning: 81/100.** **AA Intelligence Index v4.3.2 = ~37–38, #11/173, "amongst the leading models in intelligence," well above the median of 13** — a strong, *current*, independently-measured result, reinforced by **Agents' Last Exam V1 50.9%** (vendor). Capped at **81** because it is the **budget tier** — below Sol (48), Astra (53) and Opus 5.5 (58) — AA finds the intelligence **flat vs GPT-5.6 Luna** ("not an intelligence release"), and **hallucination is still 77%**. Sits above the below-median deprecated models (GPT-5.1 78, GPT-5 78) that this current model has effectively replaced.
- **Context window: 85/100.** **1.05M total (922K in + 128K out)** — proven, the largest in the budget tier, and uniquely **economically viable at $0.10/$0.50** (the meta's standout). Scored **85** (the "1M proven" tier, level with other verified-1M models); held below the 87 "validated-1M" band because **no independent long-context retrieval score (MRCR/RULER) surfaced** and **>272K prompts incur a 2×/1.5× surcharge**, so full-window flat-rate use is asserted rather than measured.
- **Multimodal: 78/100.** **Text + image in → text out** (image-only), with the full hosted vision pipeline of the GPT-6 family. **No native video or audio**, and **no verified MMMU/multimodal benchmark surfaced** for Luna specifically. Scored **78** — the standard image-only tier (level with GPT-5/GPT-5.1), below the native-video models (grok-4.3 82, Seed 2.0 Pro 84).
- **Coding: 77/100.** Vendor **DeepSWE v1.1 66.6% at $0.22/task** and **FrontierCode 42.4% at ~$0.11** are strong *for the cost*, but the **independent** signals are weak and regressed: **Coding Agent Index 41 (down from 43)**, **Terminal-Bench 4.0 13%**, **SWE-Atlas-QnA 44% (down from 49%)**, and **no Vals SWE-bench row**. Scored **77** — mid-tier, below GPT-5.1 (79, higher + corroborated SWE) and far below the elite independent coders (Opus 5 ~97%, DeepSeek V4 Pro 96.4%); the DeepSWE value keeps it from scoring lower.
- **Cost efficiency: 94/100.** **THE standout dimension.** **$0.10/$0.50** (a 50% cut from GPT-5.6 Luna), cached **$0.01/$0.125**, and above all **$0.07 per Intelligence Index task** — the **cost-per-intelligence Pareto frontier** (#11/173 intelligence at ~1/15 of Sol's $1.06/task and ~1/85 of Opus 5.5's ~$6). Scored **94** (Pareto-frontier/cheapest-paid band); the only thing off the absolute top is **verbosity (~51K output tokens/task, ~25% more than GPT-5.6 Luna)**, which the per-task figure already absorbs. (Not counted in Overall.)
- **Overall Score: 80/100.** Mean of the five quality dimensions = (80 Tool + 81 Reasoning + 85 Context + 78 Multimodal + 77 Coding) / 5 = **401/5 = 80.2 → 80** (Cost efficiency 94 is scored but **not** counted, per the v4 formula). **Divergence note:** my independent read is **80 vs the queue's curated 83.8 → −3.8**, a moderate gap. The curated **83.8** credits the headline story — **cost-per-intelligence frontier ($0.07/task), AA Index #11/173, 1.05M context at pocket change, current (not deprecated)** — and that story is real. My **80** is held below it because GPT-6 Luna is explicitly the **budget tier** ("a pricing and reliability release more than an intelligence release"): intelligence is **flat vs GPT-5.6 Luna** and below Sol/Astra/Opus 5.5; its **independent agentic/coding metrics regressed** (Coding Agent Index 43→41, SWE-Atlas 49→44, Terminal-Bench still 13%); it is **image-only, verbose, and still hallucinates on 77%** of decline-worthy questions. Best fit: **high-volume extraction/summarization/classification with source grounding, and first-pass drafts a stronger model reviews** — exactly OpenAI's stated target — where its 94-cost and 85-context carry the load and its 77-coding / 80-tool ceilings don't bite.
