## Model card

- **Name:** GPT-6 Luna (official OpenAI SKU; dataset label `gpt-6-luna` matches the released API model)
- **Short description:** OpenAI's most efficient, focused-task model in the GPT-6 family (released 2026-09-22). Designed for high-volume, cost-sensitive workloads (extraction, classification, structured summaries). Supports six controllable reasoning-effort levels (`none` through `max`). Part of the same training family as GPT-6 Astra but optimized for speed and price rather than maximum intelligence.
- **Provider / access:** OpenAI (`gpt-6-luna`) — Chat Completions and Responses APIs; ChatGPT Work / Codex (Plus/Pro/Business/Enterprise/Edu); free/go users in desktop app; Amazon Bedrock (`prod-fiwlckcpwkwli`); Cloudflare AI; OpenRouter (`openai/gpt-6-luna`). Not available in standard Chat (as of 2026-10) — only Work/Codex/desktop/free tiers.
- **Release / knowledge:** Released 2026-09-22 (OpenAI blog / API docs); knowledge cutoff May 18, 2026 (official docs, Amazon Bedrock card, Cloudflare docs). System-card update: 2026-10 (October release distinguishes ChatGPT version from Codex/Work versions; see `cdn.openai.com/pdf/gpt-6-october.pdf`).
- **IDs:** `openai/gpt-6-luna` (OpenAI API); `gpt-6-luna` (snapshots list — only one live snapshot). No separate `Free` tier on Zen; the model itself is the low-cost tier.
- **Context window:** 1,050,000 tokens total; max input 922,000; max output 128,000 tokens (official OpenAI docs, Amazon Bedrock card, Cloudflare AI docs). Long-context (>272K input) triggers 2x input/cache rates and 1.5x output rate. Verified across three independent documentation sources (OpenAI, AWS, Cloudflare) — full agreement.
- **Modalities:** Input: text (UTF-8) + image (pixel-based, standard vision pipeline — no explicit pixel-range stated). Output: text only (no audio/video/image generation). Reasoning: yes — six discrete `reasoning.effort` levels (`none`, `low`, `medium` [default], `high`, `xhigh`, `max`). Tool calls: yes — Responses API supports `web_search`, `file_search`, `code_interpreter`, `computer_use`, `mcp`, `skills`, `hosted_shell`, `apply_patch`, `image_generation` (as tool, not output modality), `prompt_caching`. Chat Completions supports function calling only with `reasoning_effort` set to `none`. JSON mode / structured outputs: yes (`structured_outputs` supported). Not video-output.
- **Pricing (as of 2026-10-29):** Standard rates (per 1M tokens): Input $0.10; Cached input $0.01; Cache writes $0.125; Output $0.50. Batch / Flex = 50% of Standard. Fast mode = 2x applicable rate. Long-context (>272K input) = 2x input/cache + 1.5x output for the full request. Regional premium (+10%) where EU data residency is selected. Verified by official OpenAI pricing docs, Amazon Bedrock pricing table (US Geo / Global), Cloudflare AI docs — all consistent within rounding. Cost per task on Artificial Analysis Intelligence Index: $0.07 (max) / $0.0045 (low) — ~60% lower than GPT-5.6 Luna max ($0.18). This is the cheapest model in the dataset with a verified public benchmark profile.
- **Architecture:** Proprietary (OpenAI does not disclose parameter count, MoE structure, or weights). Not open-weights. Training family: same methods as GPT-6 Astra (system card 2026-10). No independent architecture audit published.

### Raw benchmarks found

Sources compared and conflicts noted (3+ independent web searches performed):

1. **Official OpenAI docs + release blog** (`developers.openai.com/api/docs/models/gpt-6-luna`, `openai.com/index/introducing-gpt-6-sol-and-luna/`, `openai.com/index/practical-guide-building-gpt-6/`, `cdn.openai.com/pdf/gpt-6-october.pdf`) — primary vendor specs, pricing, availability, reasoning-effort levels, context limits. System card (Oct 2026) notes DeepSWE 1.1 max 66.6% (vendor self-reported, max effort) and compares cost-efficiency vs Claude Opus 5 (93% less per task) and Fable 5 (96% less).
2. **Artificial Analysis (independent evaluation)** (`artificialanalysis.ai/articles/gpt-6-sol-and-luna-push-the-cost-efficiency-frontier`, `artificialanalysis.ai/models/releases/gpt-6-luna`, `artificialanalysis.ai/models/comparisons/gpt-6-luna-vs-gpt-6-astra`) — Intelligence Index 28 (max) / 23 (xhigh) / 21 (high) / 18 (medium) / 9 (low) / 9 (non-reasoning). Coding Agent Index 41 (max) — DOWN 2 points from GPT-5.6 Luna max (43). DeepSWE v1.1: vendor-stated 66.6% (max) vs AA-reported regression from 66% (5.6 Luna) to 64% (6 Luna max) — **conflict: vendor reports 66.6% absolute; AA reports 64% (relative regression of ~2 pp)**. GDPval-AA v2.1: ~1,367 Elo (down ~75 Elo from 5.6 Luna max ~1,442). AA-Briefcase v1.1: 1336 Elo (down ~45 from predecessor). AA-Omniscience: hallucination rate drops 93% → 77% (max); accuracy broadly unchanged (~44%). AutomationBench-AA 53% (+3 vs 5.6 Luna). Terminal-Bench 4.0: 13% (+1). AA-LCR 83.3%. CritPt 19.4%. SciCode 54.6%. HLE-Diamond 22%. Intelligence Index ties exactly with 5.6 Luna max (28). Price per task: $0.07 (max) — ~60% lower than $0.18 (5.6 Luna max).
3. **Benchgap / independent benchmark aggregator** (`benchgap.net/model/gpt-6-luna`) — 33 measured + 96 estimated scores (as of 2026-10-29). Key measured: AA-GPQA Diamond 94.6% (±2.1, medium conf); AA-HLE 38.5% (measured); AA-SciCode 54.6%; AIME26 97.9% (±1.4); CritPt 19.4%; GDPval-AA 46.6% (measured — note: this appears to be a mis-parsed percentage representation of an Elo score; the raw Elo from AA is 1,367, which aligns better); GPQA Diamond 94.9% (est); HLE 46.0% (est, ±5.4, low conf) — **conflict with AA measured 38.5%**; SWE-bench Verified 88.4% (est, ±4.6, high conf); SWE-bench Pro 66.5% (est); Terminal-Bench 2.1 85.2% (est, ±5.2, low conf); AA Coding Index 76.7% (est); MMLU-Pro 86.2% (est); AA-Omniscience Accuracy 39.6% / Non-Hallucination 20.7% (measured) — **conflicts with AA's 44% accuracy / 23% non-hallucination**; LiveCodeBench v6 95.1% (est, ±4.9, medium conf); DeepSWE 1.1: not directly listed in Benchgap — vendor 66.6% and AA 64% are the only verified numbers.
4. **Benchmark Registry** (`benchmarkregistry.org/models/10013`) — independent record aggregation for 40+ benchmark results reported Oct 7, 2026. Confirms DeepSWE 1.1 (max) 66.6% (OpenAI self-reported), DeepSWE 1.1 (high) 59.3%, (medium) 44.5%, (low) 2.4%, (xhigh) 61.3%. AutomationBench 1.0.6 (max) 20.7% (vendor); (high) 14.5%; (medium) 9.4%; (low) 1.2%. Financial/agentic scores lower at max effort (Finance Agent 49.9%, HLAB 2.9%, Immigration 62.5%) — indicates the model excels at focused, structured tasks but struggles with open-ended, multi-week deliverable work (consistent with AA's Briefcase/GDPval regressions).
5. **Emergent analysis / comparison reviews** (`go.tabbit.ai/model/gpt-6-luna/reviews/...`, `emergent.sh/learn/gpt-6-luna-benchmarks`) — confirms the same conflict narrative: Luna holds roughly level with 5.6 Luna on aggregate Intelligence Index but regresses on coding agent and long-form deliverable quality; cost fall (~60%) is the real upgrade. Notes that the vendor's DeepSWE 66.6% is the only absolute number stated in launch text, and that most other vendor claims are relative (e.g. "exceeds 5.6 Sol at medium effort, ~1/10th cost").

Conflict comparison (explicit):
- **DeepSWE 1.1 (max):** Vendor (system card + Benchmark Registry) = 66.6%. Artificial Analysis reports regression from 66% (5.6 Luna) to 64% (6 Luna max) — absolute value close (~2 pp difference, within measurement noise), but the direction is opposite if comparing to the same predecessor benchmark (vendor implies 66.6% is the 6 Luna max score; AA implies 64% is lower than 5.6 Luna's 66%). **Verdict: near-agreement within ~2.6 pp; vendor reports absolute 66.6%, AA reports 64% (slight regression from predecessor). Both cited; difference noted.**
- **HLE:** AA measured 38.5% (max); Benchgap estimated 46.0% (±5.4, low confidence). **Conflict: ~7.5 pp gap. AA is direct measurement; Benchgap is estimated with low confidence. We weight the direct measurement (38.5%) more heavily but cite both.**
- **AA-Omniscience Accuracy:** AA reports ~44% (max); Benchgap reports 39.6% (measured). **Conflict: ~4.4 pp. Both from independent sources; AA is the source of the benchmark design, so we cite AA's 44% as primary and note Benchgap's 39.6%.**
- **GDPval-AA:** AA reports ~1,367 Elo (v2.1, max); Benchgap reports 46.6% (likely mis-parsed Elo). **Conflict: representation error. AA Elo is authoritative; Benchgap percentage discarded in favor of AA Elo.**
- **Coding Agent Index:** AA reports 41 (max) — down 2 from 43 (5.6 Luna). No conflicting independent score found; vendor does not publish a single aggregate coding index. This is a genuine regression, not a measurement error.

Agent / tool use:
- Terminal-Bench 4.0 (AA harness): 12.626% (max) / 8.1% (xhigh) / 4.5% (high) / 2.5% (medium) — very low at lower effort; only max reaches double digits. Vendor reports Terminal-Bench 4.0 13% (max) — near-agreement.
- DeepSWE 1.1: 66.6% (vendor, max) / 64% (AA, max) / 61.3% (xhigh) / 59.3% (high) / 44.5% (medium) — strong at max, falls sharply with lower effort.
- SWE-bench Verified: 88.4% (Benchgap est, ±4.6, high conf) — very strong independent estimate; no vendor absolute number published separately.
- SWE-bench Pro: 66.5% (Benchgap est, ±6.6, medium conf).
- AutomationBench 1.0.6: 20.7% (vendor max) / 14.5% (high) / 9.4% (medium) — low absolute, consistent with focused-work design rather than full agentic autonomy.
- APEX-Agents (Original, max): 44.3% (Mercor independent); AutomationBench (max): 20.7% (vendor). **No verified independent score found for Claw-Eval / ClawProBench, Toolathon Verified, MCP Atlas, SWE Atlas Codebase QnA specifically for this model ID** — closest proxy is the aggregate Coding Agent Index (41) and Terminal-Bench 4.0 (13%).

Reasoning / knowledge:
- Artificial Analysis Intelligence Index: 28 (max) / 23 (xhigh) / 21 (high) / 18 (medium) / 9 (low/non-reasoning) — moderate; tied exactly with 5.6 Luna max; well below Claude Opus 5.5 (58) and GPT-6 Astra (57).
- GPQA Diamond: 94.6% (AA measured, ±2.1) / 94.9% (Benchgap est, ±1.0) / 89.9% (Mercor single-shot, max) — very high; agreement within ~5 pp across sources. Best evidence: 94.6% (AA direct measurement).
- AA-HLE: 38.5% (AA measured, max) / 46.0% (Benchgap est, ±5.4, low conf) / 38.7% (Mercor single-shot text-only, max) — AA and Mercor agree (~38.5-38.7%); Benchgap's 46.0% is the outlier with low confidence. **Verdict: 38.5% (AA) is the authoritative measured value.**
- HLE w/ tools: 55.4% (Benchgap est, ±3.9, high conf) — no direct vendor number; independent only.
- AIME26: 97.9% (Benchgap est, ±1.4, medium conf) — extremely high; no vendor absolute published separately.
- AA-LCR: 83.3% (measured, max) — very high.
- MMLU-Pro: 86.2% (Benchgap est, ±4.1, low conf) / MMLU: 93.5% (Benchgap est, ±1.0, low conf) — both estimated; no direct measurement.
- AA-Briefcase v1.1: 1336 Elo (max) — down ~45 Elo from 5.6 Luna max (~1,381) per AA review. Confirms deliverable-quality regression.
- GDPval-AA v2.1: ~1,367 Elo (max) — down ~75 Elo from 5.6 Luna max (~1,442); lower presentation quality and rubric-compliance noted by AA manual review.
- AA-Omniscience: 44% accuracy / 23% non-hallucination (max) — improvement over 5.6 Luna (43% / 7%) due to lower hallucination rate (93% → 77%) rather than higher accuracy; accuracy nearly flat.
- CritPt (hard subset): 19.4% (measured, max) — low absolute; indicates weaker physics/reasoning depth vs frontier.

Coding:
- DeepSWE 1.1: 66.6% (vendor max) / 64% (AA max) — strong at max, regresses from 5.6 Luna (66%).
- SWE-bench Verified: 88.4% (Benchgap est, high conf) — very strong; best verified coding evidence.
- SWE-bench Pro: 66.5% (Benchgap est, medium conf) — solid but not frontier.
- Coding Agent Index: 41 (max) — 2-point regression from 43 (5.6 Luna max); coding is weaker than aggregate reasoning.
- Terminal-Bench 2.1: 85.2% (Benchgap est, ±5.2, low conf) — high but low-confidence estimate; vendor reports Terminal-Bench 4.0 13% (max) — these are different benchmark versions (2.1 vs 4.0), not directly comparable.
- SciCode / AA-SciCode: 54.6% (AA measured, max) / 54.3% (Benchgap est, ±3.1, high conf) — agreement within 0.3 pp; very consistent.
- LiveCodeBench v6: 95.1% (Benchgap est, ±4.9, medium conf) — no vendor absolute; only independent estimate.
- FrontierCode 2.0: 25% (AA comparison vs Astra) — very low; confirms focused-task rather than frontier-coding design.

Long context:
- Context window: 1.05M verified by three documentation sources (OpenAI, AWS, Cloudflare) — full agreement, no conflict.
- Long-context retrieval (MRCR / RULER / GraphWalks at 512K+): **no verified independent retrieval benchmark number found** for `gpt-6-luna`. Vendor architecture documentation does not describe a special long-context retrieval mechanism beyond standard attention; the 1.05M window is a spec claim, not a measured retrieval result. The closest proxy is AA-Briefcase (multi-week, thousands of input files) which shows regression (1,336 Elo vs 1,381 for 5.6 Luna), suggesting long-form deliverable quality does not scale linearly with window size.

Multimodal:
- Input: text + image verified (official docs, Amazon Bedrock input-modality table: Image, Text; no Audio, Video, Speech). No video-output capability.
- Independent vision benchmark (MMMU-Pro, CharXiv, etc.) for `gpt-6-luna`: **no verified independent score found specifically for this model ID**. Artificial Analysis comparison table shows MMMU-Pro for Astra (not Luna). The closest proxy is the general vision support claim (official docs) plus the image input modality confirmation (Amazon, Cloudflare). No multimodal benchmark number is cited for Luna specifically; score capped by absence of verified vision evidence.

### Normalized scores (1–100)

- **Tool use: 76/100.** Evidence: DeepSWE 1.1 64-66.6% (strong), SWE-bench Verified 88.4% (high estimate), Coding Agent Index 41 (moderate, regressed from 43), Terminal-Bench 4.0 13% (max) / 85.2% (Benchgap 2.1 est, low conf). Capped by lower agentic-autonomy scores (AutomationBench 20.7%, APEX-Agents 44.3%) and the 2-point coding-index regression. Source agreement: vendor/AA conflict within ~2.6 pp on DeepSWE; Benchgap estimates have wider confidence intervals (±4.6–5.2). No conflicting independent benchmark for SWE-bench Verified exists.
- **Reasoning: 74/100.** Evidence: Intelligence Index 28 (max) — moderate; GPQA Diamond 94.6% (very high); AA-HLE 38.5% (low-moderate); AIME26 97.9% (extremely high); AA-LCR 83.3% (high); GDPval-AA ~1,367 Elo (down ~75 from predecessor); AA-Briefcase 1,336 Elo (down ~45); CritPt 19.4% (low). Capped by HLE weakness (38.5% vs 46% estimated outlier), Intelligence Index well below frontier (28 vs 58 for Opus 5.5 / Astra 57), and deliverable-quality regressions on GDPval/Briefcase. Conflicts: HLE 38.5% (AA measured) vs 46.0% (Benchgap est, low conf); we weight AA direct measurement.
- **Context window: 95/100.** Evidence: 1.05M verified by official OpenAI docs, Amazon Bedrock card, Cloudflare AI docs — three independent documentation sources in full agreement. Architecture claims standard attention; no published independent 512K+ retrieval benchmark (MRCR/RULER) for this ID. Capped slightly for absence of verified long-context retrieval measurement; the 1.05M spec is authoritative but unverified for actual retrieval quality beyond the window claim.
- **Multimodal: 70/100.** Evidence: text + image input confirmed (official docs, Amazon, Cloudflare). No independent vision benchmark (MMMU-Pro, CharXiv, etc.) published specifically for `gpt-6-luna`. No audio/video output; no video-output. Score capped by absence of verified independent multimodal benchmark numbers; the image modality is confirmed but unmeasured in independent evaluation.
- **Coding: 75/100.** Evidence: SWE-bench Verified 88.4% (high est); DeepSWE 1.1 66.6% (vendor max) / 64% (AA max) — near-agreement; SWE-bench Pro 66.5% (est); Coding Agent Index 41 (regressed); SciCode 54.6% (consistent); FrontierCode 2.0 25% (low). Capped by agentic-coding regression (Coding Agent Index down 2 pp, AutomationBench 20.7%, APEX-Agents 44.3%) and the fact that Luna is optimized for focused, structured tasks rather than open-ended coding autonomy.
- **Cost efficiency: 98/100.** Evidence: $0.10 / $0.50 per 1M (input/output) — 50% cheaper than 5.6 Luna ($0.20 / $1.20); Batch/Flex at 50% of Standard. Cost per Intelligence Index task: $0.07 (max) — ~60% lower than $0.18 (5.6 Luna max) and orders of magnitude lower than Claude Opus 5.5 ($6.24) / Astra ($6.24) per AA comparison. No verified $0 Free tier exists (unlike Muse Spark Free or Nemotron Ultra Free). Score near-maximum because of the extreme price-to-capability ratio; only capped by absence of a verified zero-cost route.
- **Overall Score: 78/100.** Mean of quality dims: (76 + 74 + 95 + 70 + 75) / 5 = 78.0. Best-fit: a highly cost-efficient, focused-work model with verified 1.05M context, solid coding benchmarks, and moderate intelligence (tied with 5.6 Luna). The real upgrade over 5.6 Luna is price (~60% lower task cost), not capability — coding agent and deliverable-quality benchmarks show slight regression. Recommended for high-volume extraction, classification, structured-output, and budget-sensitive agentic work rather than frontier reasoning or complex multi-week projects.
