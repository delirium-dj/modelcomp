## Model card

- **Name:** Gemini 3 Pro. Status **Preview** — the API ID retains the `-preview` suffix and Google expected general availability in Q1 2026. **No free API tier** exists for `gemini-3-pro-preview` (a break from earlier Gemini models); Google AI Studio offers free *interactive* sessions at 10–50 requests/minute. Variant/alias flag: two siblings must not be conflated with this entry — **`gemini-3-pro-image-preview`** (native 4K image generation, also marketed as "Nano Banana Pro") and **Gemini 3 Deep Think** (released 2025-12-04, **Google AI Ultra subscribers only**, no public API ID).
- **Short description:** Google's first undisputed claim to the frontier, released **2025-11-18**. It was the first model to break 1500 Elo on LMArena (1501, #1) and posted genuine breakthroughs in abstract reasoning and mathematics. Variant/alias flag continued: **this is a legacy entry as of this report's date.** It was superseded by Gemini 3.1 Pro in February 2026 — which more than doubled its ARC-AGI-2 score, 77.1% against 31.1% — and by October 2026 the Flash line has iterated through 3.6/3.7/3.8 and Gemini 4 Argon has launched, so every figure below is an unrefreshed late-2025 result.
- **Provider / access:** Gemini API via Google AI Studio and Vertex AI, **no waitlist**. Also in the Gemini app across tiers: Free (limited, via the "Thinking" dropdown), **Google AI Pro $19.99/month** (expanded access, Deep Research, Nano Banana Pro, Workspace integration) and **Google AI Ultra $99.99/month** (highest limits plus **the only tier with Deep Think**, Project Mariner, 30 TB storage). AI Pro is available in 150+ countries, AI Ultra in 140+. Rate limits scale with tier (10 RPM free, 50+ RPM paid); Vertex AI provisioned throughput runs **$1,200/week to $2,000/month on an annual commitment**.
- **Release / knowledge:** Released 2025-11-18. **Knowledge cutoff January 2025 (2025-01-31)** — by far the oldest cutoff in this dataset's upper tier, which is why Google Search grounding matters for this model (billing for grounding began 2026-01-05).
- **IDs:** `gemini-3-pro-preview` (Google AI Studio, Vertex AI). Siblings: `gemini-3-pro-image-preview`. **No free-tier API ID.**
- **Context window:** **1,000,000 input tokens / 64,000 output tokens.** Two important qualifications: the window is **economically tiered, not flat** — crossing 200K doubles the input rate and raises output 50% — and there is **documented negative evidence on usable length**: independent and community testing reports **context degradation at 300K+ tokens despite the 1M theoretical limit**, with some users reporting problems on codebases under 10,000 lines and the model "flaking out" on complex existing codebases.
- **Modalities:** Input: **text, images, video, audio, code and PDFs as first-class inputs** — the broadest input surface of its generation. Output: text only (the separate Image variant handles generation). Media token consumption is documented: **images cost 280–1,120 tokens depending on detail; video frames roughly 70 tokens each at standard resolution.** Reasoning: dynamic thinking via a **`thinking_level` parameter — `low`, `medium` (documented as currently unsupported) and `high` (default)**, applied adaptively by query complexity rather than as a binary thinking/instant split. **Thought signatures** are a genuine innovation: encrypted reasoning context preserved across API calls, letting multi-turn agentic chains keep reasoning state without reprocessing the whole context. Tool calls: yes, with **streaming function calling** (partial argument streaming) and **multimodal function responses** (functions can return images and PDFs directly).
- **Pricing (as of 2026-10-03):** USD per MTok, tiered by prompt length:
  - **Standard (≤200K): $2.00 input / $12.00 output; cached input $0.20 (a 90% discount)**
  - **Long context (>200K): $4.00 input / $18.00 output; cached input $0.40**
  - **Cache storage: $4.50 per hour** — expensive relative to the Flash line's $0.50
  - Batch API: $1.00 / $6.00 (≤200K), $2.00 / $9.00 (>200K)
  - Represents a 20–60% premium over Gemini 2.5 Pro. A typical conversation costs $0.02–0.05; processing a 500K-token document costs roughly $2.00.
- **Architecture:** Proprietary, closed weights. **Google will not disclose parameter count**, architecture or training compute.

### Raw benchmarks found

> Figures are Google-reported launch results unless marked otherwise, compiled by an independent tracker with competitor columns for GPT-5.1 and Claude Opus 4.5. Treat vendor numbers as a ceiling — and note a specific integrity caveat recorded below: this model was **trained on benchmark data including BIG-bench canary strings**, and has been publicly criticised as "benchmarkmaxxed".

Agent / tool use:

- Terminal-Bench 2.1: no verified public score found. **Terminal-Bench 2.0: 54.2%** (GPT-5.1 47.6%, **Claude Opus 4.5 59.3% leads**) — squarely in the methodology's mid band.
- Tau3-Banking / Tau2-Bench: no verified public score found
- GDPval-AA: no verified public score found
- Claw-Eval / ClawProBench: no verified public score found
- Toolathon / MCP-Atlas / SWE Atlas Codebase QnA: no verified public score found
- OSWorld / AutomationBench: no verified public score found
- **ScreenSpot-Pro: 72.7%** (GPT-5.1 **3.5%**) — a ~20x gap in screen and interface understanding, and the strongest computer-use-adjacent signal published for any model of that generation.
- Partner-reported agentic evidence (vendor-selected, not independent): **Warp reported Gemini 3 improved its Terminal Bench state-of-the-art score by 20%**; **JetBrains reported "more than a 50% improvement over Gemini 2.5 Pro in the number of solved benchmark tasks"**.

Reasoning / knowledge:

- **GPQA Diamond: 91.9%** (GPT-5.1 87.0%, Claude Opus 4.5 87.0%) — **above the methodology's 90%+ frontier reference**, and above the cited human-expert baseline of 89.8%.
- **HLE: 37.5%** (GPT-5.1 26.5%, Claude Opus 4.5 ~14%) — leads its cohort decisively but sits **just below the 40%+ frontier reference**.
- LCR / MLCR / MRCR: no verified public score found
- CritPt: no verified public score found
- Artificial Analysis Intelligence Index: **no verified index value found.** The closest independent composites are **LMArena Elo 1,501 (#1, the first model to break 1500**; GPT-5.1 ~1,480, Claude Opus 4.5 ~1,485) and a third-party aggregate ranking it **#48 of 212 at 61.57/100** as of October 2026 — a fair reflection of how far the field has moved since.
- **Omniscience Accuracy / Hallucination Rate: this is the model's defining weakness.** On AA-Omniscience it achieves **the highest accuracy measured at the time (53%) alongside an 88% hallucination rate when incorrect** — unchanged from Gemini 2.5 despite the accuracy gain. The model prefers fabrication to "I don't know". A widely-quoted summary: "Gemini 3 is the most likely model to give you the right answer, but it'll be damned before it answers 'I don't know' and would rather make something up."
- **ARC-AGI-2: 31.1% base, 45.1% with Deep Think** (GPT-5.1 17.6%, **Claude Opus 4.5 37.6%** — so the base score *loses* to Claude and only Deep Think, an Ultra-subscription-only mode, overtakes it). A 535% improvement over Gemini 2.5 Pro's 4.9%.
- **MathArena Apex: 23.4%** (GPT-5.1 1.0%, Claude Opus 4.5 1.6%, Gemini 2.5 Pro 0.5%) — a >20x margin over every competitor and a 4,580% generational gain. The single most dramatic result in the launch set.
- **MMLU 91.8%** (saturated); **AIME 2025 95%** (100% with code, as do all competitors); **SimpleQA Verified 72.1%** (GPT-5.1 34.9%, Claude 29.3%)

Coding:

- **SWE-bench Verified: 76.2%** — essentially ties GPT-5.1's 76.3% and **trails Claude Opus 4.5's 80.9% by 4.7 points**. SWE-bench Pro: no verified public score found.
- **LiveCodeBench Elo: 2,439** (GPT-5.1 2,243, Claude ~2,100) — leads clearly.
- SciCode / AA-SciCode: no verified public score found
- Vibe Code Bench: no verified public score found
- DeepSWE: no verified public score found
- **WebDev Arena Elo: 1,487 (#1)** — frontend and UI development is a genuine strength, corroborated by developer reports of reaching for Gemini specifically for UI work.
- Documented coding weaknesses: "flakes out" with complex existing codebases; multiple developers report Claude maintains better coherence in 30+ minute coding sessions.

Multimodal:

- **MMMU-Pro: 81%** (GPT-5.1 76%, Claude 68%)
- **Video-MMMU: 87.6%** (GPT-5.1 80.4%, Claude 77.8%) — **no competitor within 7 percentage points**
- **ScreenSpot-Pro: 72.7% vs GPT-5.1's 3.5%** — a 20x advantage in understanding and interacting with desktop and mobile interfaces

Long context:

- **No MRCR, RULER or GraphWalks figure found.** What exists instead is **negative evidence**: documented context degradation at 300K+ tokens against a 1M nominal limit.

### Normalized scores (1–100)

- **Tool use: 72/100.** **Terminal-Bench 2.0 at 54.2% sits in the methodology's mid band (45–60% → 50–70)** and loses to Claude Opus 4.5's 59.3%, which is the only direct agentic-execution measurement available. What lifts it above that band is **ScreenSpot-Pro at 72.7% against GPT-5.1's 3.5%** — a 20x gap that makes this the obvious choice of its generation for screen automation — plus genuinely useful agentic infrastructure (thought signatures preserving encrypted reasoning across calls, streaming function calling, multimodal function responses returning images and PDFs) and partner-reported gains from Warp and JetBrains. It cannot go higher because **GDPval-AA, Tau3-Banking, Claw-Eval, OSWorld/AutomationBench, MCP-Atlas and Terminal-Bench 2.1+ are every one of them unreported** — five of the methodology's six tool-use references are simply absent — and because API reliability complaints (CLI crashes reported "at least half the time" by some users) undercut agentic dependability.
- **Reasoning: 88/100.** The raw numbers are frontier-grade for their moment: **GPQA Diamond 91.9% clears the 90%+ reference** and beats the human-expert baseline, **MathArena Apex 23.4% is a >20x margin over every competitor** and a genuine mathematical-reasoning breakthrough, LMArena 1,501 was the first score above 1500, and SimpleQA Verified 72.1% more than doubles GPT-5.1. Four substantial deductions: **HLE at 37.5% falls just short of the 40%+ reference**; **the base ARC-AGI-2 score of 31.1% loses to Claude Opus 4.5's 37.6%** and only the Ultra-subscription-only Deep Think mode overtakes it, so the headline 45.1% is not available through the API at all; **MRCR/LCR and CritPt are unreported** and no Intelligence Index value exists; and most seriously, **an 88% hallucination rate when incorrect** combined with **confirmed training on benchmark data including BIG-bench canary strings** and a documented inability to identify its own version means both the reliability and the provenance of these numbers carry real doubt.
- **Context window: 92/100.** The nominal **1,000,000-token input window** reaches the ≥1M tier, and the broad first-class input surface makes that window unusually useful in practice (a 500K-token document for ~$2.00). But this is one of the few models in the dataset where long-context evidence is **actively negative rather than merely absent**: **reported degradation from 300K+ tokens** against a 1M limit, with some users hitting problems on codebases under 10,000 lines, and no MRCR/RULER/GraphWalks figure to contradict it. Two further structural limits: the **64,000-token output ceiling sits at the methodology's <64K caveat boundary** and is half the frontier norm, and the window is **not flat-rated** — crossing 200K doubles input cost and raises output 50%, so the economically and behaviourally sane window is roughly 200–300K, not 1M.
- **Multimodal: 95/100.** The strongest measured multimodal profile in this dataset. Input covers **text, images, video, audio, code and PDFs as first-class modalities** — audio places it in the methodology's top band (90–100) — and unlike almost every model scored there, the breadth is backed by dominant, independently-notable results: **ScreenSpot-Pro 72.7% against GPT-5.1's 3.5% (a 20x gap)**, **Video-MMMU 87.6% with no competitor within 7 points**, and **MMMU-Pro 81%** leading both rivals. Documented per-modality token costs (280–1,120 per image, ~70 per video frame) and multimodal function responses that return images and PDFs make it genuinely engineerable rather than nominally multimodal. Five points are withheld because output is text-only — 4K image generation lives in a separate model ID — and no audio-specific benchmark (ASR or audio understanding) was published.
- **Coding: 82/100.** **WebDev Arena Elo of 1,487 (#1)** and **LiveCodeBench Elo of 2,439** against GPT-5.1's 2,243 are real leads, and **SWE-bench Verified at 76.2%** is frontier-adjacent. But the methodology's coding references are largely unmet or unmeasured: **Terminal-Bench 2.0 at 54.2% is far below the 85%+ reference**, **DeepSWE, SciCode, Vibe Code Bench and SWE-bench Pro are all absent**, and SWE-bench Verified **trails Claude Opus 4.5 by 4.7 points** — the gap that matters for real repository work. The qualitative evidence points the same way: documented failures on complex existing codebases and consistent developer reports that Claude holds coherence better across long autonomous sessions. The honest read is a model that is excellent at greenfield frontend generation and competitive programming, and materially weaker at maintaining existing code.
- **Cost efficiency: 60/100.** At $2.00 / $12.00 it is marginally better than the $3/$15 anchor that maps to ~60, with a genuine **90% cached-input discount ($0.20)**, Batch at $1/$6, and the best price-per-1M-context of its generation — a 500K-token document for ~$2.00 was impossible on Claude's 200K window and degraded on GPT-5.1 beyond 120K. Four deductions hold it at the anchor. The **>200K tier at $4.00/$18.00 penalises exactly the long-context work the window is sold for**; **cache storage at $4.50 per hour is nine times the Flash line's rate**; **there is no free API tier** at all; and most decisively, time has gutted the value case — by October 2026 **Gemini 3.8 Flash delivers materially better agentic and coding results at $0.75/$3.75**, roughly a third of this model's standard rate, so Gemini 3 Pro is no longer the cheap option even within Google's own catalogue.
- **Overall Score: 85.8/100.** Mean of the five non-cost dimensions (72 + 88 + 92 + 95 + 82) / 5 = 85.8 — a multimodal and abstract-reasoning specialist whose other dimensions have aged badly. Its remaining best fits are the ones nothing in this dataset has clearly displaced: **screen and interface understanding** (ScreenSpot-Pro 72.7%, a 20x margin), **video understanding** (Video-MMMU 87.6%), **mathematical reasoning** (MathArena Apex 23.4%, >20x competitors), and **frontend/UI generation** (WebDev Arena #1). Do not choose it for maintaining existing codebases (SWE-bench Verified trails Claude Opus 4.5; documented failures on complex repositories), for agentic terminal work (Terminal-Bench 2.0 54.2%, with five of six tool-use references unmeasured), for anything beyond ~300K tokens despite the 1M headline, or for factual work without a verification layer — an **88% hallucination rate when incorrect** is the single most important number on this page. Treat it as a legacy preview: the ID still carries `-preview`, the knowledge cutoff is January 2025, the successor line has shipped five times since, and the benchmark set was never refreshed.
