# GPT-5.4 — Independent Research Report

## Summary and evidence

GPT-5.4 is OpenAI's March 2026 mainline reasoning model combining GPT-5.3-Codex coding capability with stronger professional work, tool search, and computer use. OpenAI reports **87.3%** on an internal spreadsheet-modeling benchmark versus 68.4% for GPT-5.2. Standard API context is 272K, while Codex offered experimental **one-million-token context**.

Source: [OpenAI GPT-5.4 launch](https://openai.com/index/introducing-gpt-5-4/)

## Cost and limitations

Pricing is **$2.50 input, $0.25 cached input, and $15 output per million tokens**; Batch and Flex halve the price. It accepts text/images but not native audio/video, and newer GPT-5.6 and GPT-6 generations supersede it.

## Scores

- **Tool use: 90/100.** Tool search and computer-use improvements support capable professional agents.
- **Reasoning: 89/100.** Strong knowledge-work reasoning remains useful but is no longer frontier.
- **Context window: 87/100.** 272K standard is good; experimental Codex operation reaches 1M.
- **Multimodal: 85/100.** Vision is supported without broader native media input.
- **Coding: 91/100.** It incorporates GPT-5.3-Codex capabilities into the mainline model.
- **Cost efficiency: 79/100.** $15 output is costly relative to newer efficient options.
- **Overall Score: 88/100.** Half-up rounded mean: (90 + 89 + 87 + 85 + 91) / 5 = 88.4.

## Bottom line

GPT-5.4 remains a solid legacy reasoning and coding model, but newer OpenAI tiers offer better context and economics.
