## Model card

- **Name:** Muse Spark 1.1
- **Short description:** Meta's July-2026 mid-frontier reasoning model and the first substantial jump of the Muse Spark line — **+8 Artificial Analysis Intelligence Index points over Muse Spark 1.0 (43 → 51) in three months**, with the gains concentrated in scientific reasoning, coding and knowledge. Its standout independent results are **SciCode 58% (#3 across every model Artificial Analysis has ever benchmarked**, behind only Claude Fable 5 and Gemini 3.1 Pro Preview), **Humanity's Last Exam 45%** (within a point of Claude Opus 4.8 and ahead of GPT-5.5 and Grok 4.5) and a **Coding Agent Index of 69** in the Opencode harness (above Claude Opus 4.8's 67, just below GPT-5.5's 71). It pairs that with a **1M-token context window** (up from 262K) and best-in-class cost-per-task (~$0.26) for its intelligence tier. Its clearest limits: **text + image only** (no video/audio, no published vision benchmark) and agentic knowledge work (GDPval-AA v2) that still lags the frontier. **[2026-11-02: the "text + image only" limitation is now FALSIFIED — AA's spec lists text, image, speech AND video input (omni-modal); the remaining multimodal gap is a missing independent vision score, not missing modalities. The GDPval-AA lag is confirmed by AA Agentic Index 27.5.]**
- **Provider / access:** **Meta Model API** (public preview from 2026-07-09), "Thinking" mode in the Meta AI app, meta.ai, and an OpenCode listing. Regional availability limited; $20 free credit at launch. Effort levels up to **xhigh**.
- **Release / knowledge:** Released **2026-07-09** (one day after Grok 4.5). Knowledge cutoff not disclosed in the sources reviewed.
- **IDs:** `muse-spark-1.1` (predecessor Muse Spark 1.0 [Index 43]; successors 1.2 / 1.3; sibling line Muse Glimmer-30B).
- **Context window:** **1M tokens native** (up from 262K for 1.0); Meta emphasizes the model **"actively manages" its context** — compacting earlier work while retaining steps needed later — aimed at long-running agentic sessions. No MRCR-style long-context recall figure published in the sources reviewed.
- **Modalities:** **text + image in → text out** (no video, no audio). Reasoning ("Thinking") model with extended-thinking effort levels; function calling / tool use for agentic workflows. **[2026-11-02: AA's authoritative spec table lists input modality as text + image + speech + video — the draft's "no video, no audio" was wrong; the model is omni-input. No independent vision benchmark (MMMU-Pro) surfaced; only vendor CharXiv 88.4 / BabyVision 76.3.]**
- **Pricing (as of 2026-10-23):** **$1.25 / 1M input, $4.25 / 1M output**; **cache hits $0.15 / 1M (88% discount)**; $20 free credit. **~$0.26 per AA Intelligence-Index task** (2nd-cheapest among models at/above its intelligence, behind only GPT-5.6 Luna's $0.21; below GLM-5.2's $0.37 and ~3× below GPT-5.4's $0.89). Output speed **~114–121 tok/s** median on Meta's first-party API, ~21s time-to-first-token.
- **Architecture:** Undisclosed proprietary (Meta). Notably **token-efficient for its tier** — used **94M output tokens** to run the Intelligence Index (fewer than GPT-5.4 xhigh's 109M, GPT-5.6 Luna's 125M and GLM-5.2's 141M, though above the ~60M average and more than Claude Fable 5 / Grok 4.5). Full Index evaluation cost $548.07.

### Normalized scores (1–100)

- **Tool use: 81/100.** **Trimmed 83 → 81.** Solid vendor agentic breadth (Meta eval: MCP Atlas 88.1, OSWorld-Verified 80.8, Toolathlon 75.6, Cybench 92.9, Coding Agent Index 69 above Opus 4.8's 67) — but the **neutral harnesses lag**: **AA Agentic Index 27.5** and **GDPval-AA normalized 35.6** confirm the draft's own note that agentic knowledge work "continues to lag the frontier," and **Terminal-Bench 2.1 (Vals) 69.3** only partially replicates the vendor 80.0. The hard-collapse cells (**ExploitGym 0.8, OSWorld 2.0 14.2**) cap the ceiling. Held mid-80s for the strong vendor coding-agent orchestration, discounted for the weak independent agentic index.
- **Reasoning: 84/100.** **Trimmed 85 → 84.** The draft's premium leaned on the **AA pre-release Index 51** ("ties GPT-5.4/Luna"); AA has since **deprecated 1.1 (composite N/A)** and the only fresh neutral read is **BenchLM's republished v5.0 Index 33.7 / #32/1004** — a rebase, not a regression, but the flagship-adjacent tiering can no longer be anchored on the 51. Substance is still strong: **GPQA-D AA 89.8 / Vals 91.2**, **AA-HLE 46.2** (matches the draft's 45%), **MMLU-Pro (Vals) 88.7**. Capped by **CritPt 15.1** (weak peak) and the confirmed **AA-Omniscience 50% hallucination (accuracy 52.1)** — the draft's "abstention-driven, not a knowledge gain" caveat is now measured.
- **Context window: 86/100.** **Trimmed 88 → 86.** A **1M-token native window** (AA-confirmed) with active context compaction is genuine. But the draft discounted 88→below-89 purely for "no published recall benchmark"; the independent read is now **AA-LCR 77.7** — **mid**, not elite — and the vendor **MRCR 1M is only 54.1**. The measured mid recall grounds the discount and pulls the score toward reality rather than the assumed 88.
- **Multimodal: 80/100.** **Lifted 76 → 80 — the draft's headline limitation is falsified.** The 76 was scored explicitly because the draft assumed **"text + image only (no video, no audio)"**; **AA's authoritative spec now lists input modality as text + image + speech + video**, so the model is genuinely **omni-input** — a breadth *strength*, not a limit. Held to 80 (not higher) because no independent vision score (MMMU-Pro) surfaced; the only measured cells are vendor **CharXiv 88.4** (strong chart-reading) and **BabyVision 76.3** (mid). Breadth confirmed + quality mid ⇒ 80.
- **Coding: 88/100.** **Holds 88 — the one dimension the independent pass actively corroborates.** **AA-SciCode 58.8 confirms the "#3 across all AA-benchmarked models" claim**, **AA Coding Index 71.3** matches, and neutral **Vals SWE-bench 82.0 / LiveCodeBench 85.9** independently validate an elite coding read for the tier. Stays capped below the high-80s/90s only by the documented **game-code/physics weakness** (n=3 third-party) and Terminal-Bench 2.1 69.3 (Vals) short-horizon terminal softness.
- **Cost efficiency: 88/100.** **Holds 88.** Pricing (**$1.25/$4.25, 88%-off cache $0.15**) is AA-confirmed and cheap for the intelligence tier, and AA now measures speed at **308 tok/s (#2/195 — far faster than the draft's ~114–121)**, improving real-world value. The one regression: because 1.1 is **deprecated**, AA's **cost-per-task (~$0.26) and verbosity (94M) are now N/A** and can no longer be re-measured, so the draft's "2nd-cheapest at Index 51" ranking rests on a historical figure. Scored but **not** counted in the Overall per methodology.
- **Overall Score: 84/100.** **Holds 84.** Mean of Tool 81 + Reasoning 84 + Context 86 + Multimodal 80 + Coding 88 = 419 / 5 = 83.8 → **84**. The two adverse neutral reads (deprecated Index-51 anchor → v5.0 33.7; AA Agentic Index 27.5 lag) and the mid AA-LCR trims are offset by the **multimodal breadth reversal (76 → 80)** and the actively-corroborated elite coding (SciCode 58.8 / Vals SWE 82 / LCB 85.9). Best fit: **high-volume agentic reasoning and coding at low frontier-tier cost with omni-modal input** — long-horizon 1M-context agent sessions, scientific/coding work; avoid graphics/physics/game-code first-shot and offensive-security/OS-agent hard cells. Independent read: my 84 sits **below the queue's curated 88.4** because the neutral anchor (Index 51) is deprecated to N/A (fresh v5.0 read 33.7 / BenchLM #32), the AA agentic index lags the frontier (27.5), and long-context recall measures mid (AA-LCR 77.7) — even though coding is genuinely elite and the modality breadth is now confirmed stronger than the draft assumed.
