## Model card

- **Name:** DeepSeek V4.1 Flash
- **Short description:** An **open-weight (MIT) 552B MoE** from DeepSeek that became the lab's served flagship on 2026-09-10 — a *cheaper* model that DeepSeek says "comprehensively surpassed" its ~4x-more-expensive V4 Pro, which it retired on 2026-09-14. It is a genuine fresh pretrain (not a patch) built on a new **Causal Encoder-Decoder (CED)** backbone with aggressive **FP4 KV-cache compression**, aimed squarely at **short-horizon, high-volume agent loops** where cost-per-task dominates. On DeepSeek's own model card it beats/matches GPT-5.6 Sol and Claude Opus 5.0 on several agentic-coding benchmarks, but trails them decisively on long-horizon, repo-scale and offensive-security work.
- **Provider / access:** DeepSeek API as `deepseek-flash` (bases `api.deepseek.com` and `api.deepseek.com/anthropic`; compatible with **both OpenAI and Anthropic request formats**). MIT weights on Hugging Face (`deepseek-ai/DeepSeek-V4.1-Flash`) — self-host/fine-tune/serve commercially royalty-free. Responses API native; partners WorkBuddy/CodeBuddy and OpenCode day one; DeepSeek Harness (own agent scaffold) shipped in developer preview at launch. The retired `deepseek-v4-flash`, `deepseek-v4-flash-vision-exp` and (from 04:00 UTC 2026-09-14) `deepseek-v4-pro` aliases all now route to V4.1 Flash at Flash prices until V4.1 Pro ships.
- **Release / knowledge:** Released **2026-09-10** (Beijing time; pricing effective 04:00 UTC same day). V4.1 Pro is confirmed coming but has **no published card, scale, price or date**. Knowledge cutoff not disclosed in the sources reviewed.
- **IDs:** `deepseek-v4.1-flash` / `deepseek-flash`; weights `deepseek-ai/DeepSeek-V4.1-Flash` (**AA now marks this slug deprecated, superseded by the newer `DeepSeek-V4.1-Flash-1017` checkpoint**).
- **Context window:** **1,000,000 tokens** with up to **384,000 output** (a larger output ceiling than GPT-5.6/GPT-5.5's 128K). FP4 KV cache = ~890 bytes/token (~1/4 of V4 Flash, ~1/437 of DeepSeek V1) → a full 1M window is ~0.9 GB global KV; SWA Bounded Replay cuts persistent cache to ~1/8 of V4 Flash. Concurrency 2,500 (vs V4 Pro's 500).
- **Modalities:** text + **image** in (native DeepSeek-ViT — no separate Vision-Exp model) → text out; **no audio/video** (**AA spec independently confirms text+image only, 2026-11-02**). Reasoning on by default with a **continuous `reasoning_effort` dial 1–100** (published scores use 100); JSON + function calling supported.
- **Pricing (as of 2026-10-23):** per 1M tokens — **peak $0.30 input (cache miss) / $1.20 output**, **off-peak $0.15 / $0.60**; cache **hits $0.006 peak / $0.003 off-peak**. Peak windows 01:00–04:00 and 06:00–10:00 UTC weekdays (the Chinese business day). ~4.1x cheaper than the V4 Pro it replaced; a 2M-in/200K-out agent run ≈ **$0.42 off-peak**.
- **Architecture:** 552B-backbone MoE, **8B active (prefill) / 16B active (decode)** per token; 40-layer CED (20 causal encoder + 20 decoder, decoder global KV projected from encoder final states); Compressed Sparse Attention 2 (CSA2, Full/Reindex/Reuse modes); 1 shared + 384 routed experts, 6 routed active/token; 196B sparse **Engram** conditional memory; FP4 (E2M1) KV cache; Single-Pass mHC + DSpark decoding. Trained from scratch on **45T tokens** (context extended to 1M at the 34T mark); post-training SFT + RL + on-policy distillation, with agentic gains credited to large-scale synthetic agent-task/environment generation.

### Normalized scores (1–100)

- **Tool use: 84/100.** Frontier-competitive on the vendor's short-horizon agentic set (DeepSWE v1.1 74.2 matches Opus 5.0, AutomationBench 54.8 beats Opus/Sol, HLE-with-tools 63.9 edges Opus 5.0), plus native function calling, Responses API and OpenAI/Anthropic-compatible endpoints. **Trimmed 85 → 84** after the independent pass: the vendor Terminal-Bench 2.1 **90.6 does not replicate** (Vals AI measures **74.5**), and the security/agentic picture softens independently (**AA Cyber Index 40.8, CyberGym-E2E-AA 22.9** vs the vendor CyberGym 88.1, **AA ITBench 46.9**); long-horizon deficits confirmed (Terminal-Bench 3.0 30.0 vs Opus 43.3; 4.0 31.2 vs 51.8; ProgramBench 20.3 vs 37.0).
- **Reasoning: 81/100.** **Holds** on independent confirmation — solid-but-mid-pack expert reasoning: GPQA Diamond 90.9, Codeforces 3471, Apex 65.6, MMLU-Pro 74.1, but a marked tool-free weakness (HLE no-tools 36.8/39.1 vs Opus 5.0's 56.3). Independently anchored by **AA Index 39.5, AA-HLE 39.2, CritPt 14.3, Epoch FrontierMath v2 T1-3 67.4** — squarely the "≈40, well below frontier" read, no lift. Caveat: **AA-Omniscience 96.5% hallucination** (net index −5.3) flags fabrication risk that argues against any upward move.
- **Context window: 90/100.** A real **1M-token window with a 384K output ceiling** made economically usable by FP4 KV compression (~890 bytes/token) and SWA Bounded Replay — excellent for repeated large-repo/agent re-reads and cache hits at $0.003–0.006. **Lifted 89 → 90:** the draft discounted long-context *specifically because* "no MRCR-style far-edge recall benchmark is published" — the independent **AA-LCR 84.0** now publishes exactly that recall score, closing the gap (a provenance lift, not a capability change). Still below the 92–93 of verified top recall leaders.
- **Multimodal: 77/100.** **Holds at 77 but the rationale is corrected.** The draft reached 77 off a weak vendor **MMMU-Pro 56.5**; the independent **AA-MMMU-Pro 77.0** (+ ExtractBench 87.11, ParseBench 64.56) is materially stronger and lands right in the mid-70s the score already assumed — right number, wrong reason. Native DeepSeek-ViT, text + image only (**AA spec independently confirms; no audio/video**), so complex multimodal reasoning and non-visual modalities remain capped.
- **Coding: 85/100.** **Trimmed 86 → 85.** Strong for its class and price (DeepSWE v1.1 74.2 matches Opus 5.0, HumanEval 79.4, Codeforces 3471), but the vendor headline Terminal-Bench 2.1 90.6 does not replicate independently (Vals 74.5), and independent coding probes are mid/low (**AA-SciCode 51.9**, **Cognition FrontierCode 2.0 19.3**); long-horizon/repo/security categories remain documented deficits (NL2Repo 64.0 vs Opus 75.3, ProgramBench 20.3, ExploitGym 15.3 vs Sol 33.7).
- **Cost efficiency: 96/100.** **Holds.** Near-unbeatable: $0.15/$0.60 off-peak (cache hits $0.003), MIT open weights for royalty-free self-hosting (FP4 KV makes the 552B cheap to serve), 4.1x cheaper than the V4 Pro it replaced, concurrency 2,500, and OpenAI/Anthropic-compatible endpoints for one-line migration. Best-in-class price-to-capability for high-volume agent work; scored but **not** counted in the Overall per methodology.
- **Overall Score: 83/100.** Mean of Tool 84 + Reasoning 81 + Context 90 + Multimodal 77 + Coding 85 = 417 / 5 = 83.4 → **83**. Best fit: **bulk, short-horizon, high-volume agent and coding loops** where cost-per-task dominates — route the many cheap passes here and keep a frontier model (Opus 5.0 / Sol) for the hard ~5% (marathon autonomous sessions, repo-scale refactors, offensive security, tool-free expert reasoning). Independent read: my 83 sits **below the queue's curated 88.6** because the vendor-only frontier-agentic posture does not replicate independently (Terminal-Bench Vals 74.5, CyberGym-E2E 22.9), the neutral AA Index is only 39.5, and the 96.5% Omniscience hallucination plus long-horizon/security/multimodal-reasoning deficits are confirmed — an exceptional-value specialist, not a universal frontier-killer.
