## Model card

- **Name:** GLM 5.3 (GLM-5.3) — Z.ai's flagship open-weights agentic/coding model, and **the same base model as GLM-5.2 with post-training alone as the delta**
- **Short description:** A 753B-total / 40B-active **open-weights MoE** with a **1M-token context** and 128K max output, aimed squarely at long-horizon coding agents. It posts the best **GDPval-AA v2 (1769 Elo)** and **AutomationBench (48.2%)** of any model Z.ai compared, **88.2% on Terminal-Bench 2.1** and **78.1% on FrontierSWE**, and an unusual emergent capability: it is the strongest model measured on **CyberGym (84.5)** for vulnerability discovery, more than doubling GLM-5.2 on exploitation. It is also the **most expensive** model in this comparison at $1.40/$4.40, and it is **text-only** — the multimodal sibling is GLM-5.3-Flash.
- **Provider / access:** **OpenCode Zen `opencode/glm-5.3`** (Chat Completions). Z.ai first-party `https://api.z.ai` ID **`glm-5.3`**, plus the subscription **GLM Coding Plan** and the **ZCode** client; Z.ai explicitly names Claude Code, OpenCode, Hermes Agent and OpenClaw as supported agent clients. OpenRouter `z-ai/glm-5.3`, NVIDIA NIM (`build.nvidia.com/z-ai/glm-5-3`), and **23 API providers** per Artificial Analysis. Ollama library `glm-5.3:cloud` (36.7–56.1K downloads). Local: vLLM (official recipe), SGLang (official cookbook), Transformers, KTransformers, Unsloth, TokenSpeed, and vLLM-Ascend / xLLM on Ascend NPUs.
- **Release / knowledge:** announced **2026-08-14** (z.ai blog); AA records the API release as **2026-08-18**; **weights published on Hugging Face 2026-08-27**, two weeks later as Z.ai promised, after a safety evaluation prompted by how fast its vulnerability-discovery ability emerged. **Knowledge cutoff not published** on the card, the blog, or AA.
- **IDs:** `opencode/glm-5.3` (Zen, $1.40/$4.40, cached read $0.26), `z-ai/glm-5.3` (OpenRouter, Kilo), `glm-5.3` (Z.ai API), `zai-org/GLM-5.3` (Hugging Face weights, `glm_moe_dsa` architecture tag), `z-ai/glm-5-3` (NVIDIA NIM). **No Free ID exists on Zen** — confirmed by models.dev and this folder's `meta.json` (`noFreeId: true`).
- **Context window:** **1,048,576 tokens (1M) with 131,072 (128K) max output** — verified on Kilo/OpenRouter (both figures), Opper (1M / 131K), AA ("1M tokens context window"), and Z.ai's own harness notes, which report **Agents' Last Exam run at 1M context and 64K max output** and **PostTrainBench / SWE-Marathon at a 1M-token context window** with 128K max output. Z.ai's own evals therefore exercise the full window, not a truncated version of it.
- **Modalities:** **text in, text out.** Reasoning: **always on** — `reasoning_effort` accepts `low` / `high` / `max` and **defaults to `max`**; Z.ai states explicitly that **`thinking.type: "disabled"` is no longer supported and the request will fail**, so a non-thinking mode requires a migration. In the chat template `clear_thinking` defaults to `false`, so chat clients should pass `clear_thinking=true` explicitly. Tool calls and structured/JSON output supported. **No image, audio, or video input** — AA's FAQ is explicit that GLM-5.3 is not multimodal. (The separate **GLM-5.3-Flash** is the first natively multimodal model in the GLM-5 series: 321B/18B, **MIT**-licensed.)
- **Pricing (as of 2026-09-25):** **$1.40 in / $4.40 out per 1M** on OpenCode Zen, OpenRouter/Kilo and Z.ai's own API, with **cached read $0.26** (an 81% cache discount) and a **blended 7:2:1 rate of $0.90/M**. Third-party routes via Opper range **$1.16–$1.75 in / $4.00–$4.65 out** — DeepInfra cheapest at **$1.20/$4.00**, Melious $1.16/$4.65, TensorX dearest at $1.75/$4.50 — with EU residency and zero-data-retention options on several. AA measured **$2.01 per Intelligence Index task** (#31 of 115) and a **$1,238.50 total cost** to run the full Index, making it the most expensive model measured in this comparison. Access is also available by subscription through the GLM Coding Plan rather than purely per-token.
- **Architecture:** **753B total / 40B active parameters**, Mixture-of-Experts (`glm_moe_dsa` — GLM-5 integrates **DeepSeek Sparse Attention**), BF16 with FP8 expert tensors, 753B safetensors on HF. **Same base as GLM-5.2**: "Scaling post-training is all we did for GLM-5.3." The scaled stack is **IndexShare** (arXiv 2603.12201, efficient long-context processing), **SAO** (arXiv 2607.07508, RL on long-horizon tasks), and **slime** (Z.ai's open-source asynchronous RL framework), with more environments, more task variety and longer runs — including simulated professional-work environments Z.ai says take a human engineer several days. GLM-5's improved **MTP layer** for speculative decoding raises acceptance length by up to 20%. Citation: arXiv 2602.15763, *GLM-5: from Vibe Coding to Agentic Engineering*. **License: `glm-5.3`** — commercial use permitted **with restrictions**, materially less open than DeepSeek V4 Flash's MIT or GLM-5.3-Flash's MIT. 1,158,317 HF downloads last month.

### Raw benchmarks found

> Official numbers are the **GLM-5.3** column of the `zai-org/GLM-5.3` model card, measured against GLM-5.2, Kimi K3, DeepSeek-V4 Pro-0813, Qwen3.8-Max, Opus 4.8, Fable 5 (w/ fallback) and GPT-5.6 Sol. Decoding params vary by row and are footnoted per benchmark on the card; **all rows assume `max` reasoning effort**, and Z.ai instructs reproducing benchmark runs at the default `max`. Independent measurements are labelled separately.

Agent / tool use:

- Terminal-Bench 2.1: **88.2%** (official; Claude Code 2.1.207, temp 1.0, top_p 1, 65,536 max new tokens, 6h timeout) — vs Kimi K3 88.3, GPT-5.6 Sol 88.8, DS-V4-Pro-0813 87.9, Qwen3.8-Max 86.6, Fable 5 88.0, Opus 4.8 85.0, GLM-5.2 81.0. Reproduced as an HF eval result at **88.2**; GLM-5.3's own TB2.0 predecessor scored 52.4
- Terminal-Bench 3.0: **28.3%** (official; Claude Code 2.1.207, effort max, 400K context, 128K max output, **avg@3 over three rollouts**, 600 agent turns, 10h timeout) — vs GLM-5.2 **4.6**, Kimi K3 17.4, Opus 4.8 21.1, Fable 5 33.7, GPT-5.6 Sol 34.6. **#1 on llm-stats' TB3.0 board** (0.283 of 3 tracked models). This 4.6 → 28.3 jump on an unchanged base is the single largest post-training delta Z.ai claims
- Toolathlon Verified: **73.0%** (official, pass@1 averaged over 3 runs via the official evaluation service) — vs Kimi K3 76.5, DS-V4-Pro-0813 74.1, Opus 4.8 76.2, GPT-5.6 Sol 74.9, GLM-5.2 59.9. Reproduced at **73** in the HF eval results

Z.ai calls this an open-weights SOTA. Reproduced at **62.5** in the HF eval results

Long context:

- Z.ai's own harness runs at the full window: **Agents' Last Exam at 1M context**, **PostTrainBench and SWE-Marathon at a 1M-token context window with 128K max output**, **HLE w/ tools at 300K max context with a context-management strategy**, **DeepSWE at 400K**, **Terminal-Bench 3.0 at 400K**. The model is therefore benchmarked *at* 1M, not merely advertised at it
- AA-LCR v1.1 long-context reasoning: **80%** (provisional — Opper's AA mirror)

Z.ai's efficiency claim is architectural — **IndexShare** (arXiv 2603.12201) for long-context processing, plus DeepSeek Sparse Attention in the GLM-5 backbone — not a published retrieval number

### Normalized scores (1–100)

- **Tool use: 92/100.** The strongest tool profile measured. **Terminal-Bench 2.1 88.2%** meets the methodology's ≥88% frontier anchor, and it is backed by the two best-of-table numbers in the whole comparison: **GDPval-AA v2 1769 Elo** and **AutomationBench 48.2%**, both ahead of Fable 5, Kimi K3, DeepSeek-V4 Pro-0813 and GPT-5.6 Sol. **Toolathlon Verified 73.0%** and **HLE with tools 62.5%** are firmly frontier. Capped at 92 — not 95 — because the evidence is one-sided: **no Tau3/Tau2, no MCP-Atlas, no ClawProBench, no Toolathon** score exists at all, so the tool dimension is being judged off Z.ai's own table plus Vals' harness, and Z.ai chose Claude Code 2.1.207 as the single agent harness across nearly every row. Agents' Last Exam 28.5 also sits just under GPT-5.6 Sol's 28.6, so the agentic lead is not universal.
- **Reasoning: 90/100.** Frontier-band knowledge work: **HLE with tools 62.5%** (level with Fable 5's 63.9 and behind only GPT-5.6 Sol's 64.5), **GPQA Diamond 92%**, and an AA Intelligence Index of **45 that ranks #2 of 115** among Large open-weights models. Held to 90 by two gaps. First, there is **no AIME, HMMT, IMO, SimpleQA, CritPt or Omniscience figure** published, so the maths-and-hallucination side of the dimension is unmeasured — and the one AA fact that *is* visible cuts the wrong way: 210M output tokens on the Index (#29 of 115) makes it one of the most verbose models measured. Second, the strongest reasoning number is explicitly **tool-assisted** (HLE w/ tools, GPT-5.6-luna as judge), which flatters a model whose tool use is its strongest suit.
- **Context window: 95/100.** **1,048,576 tokens with 131,072 max output** — verified on Kilo/OpenRouter, Opper, AA, and Z.ai's own evals, which run **Agents' Last Exam at 1M context and PostTrainBench / SWE-Marathon at a 1M-token window**. The top of the methodology's ≥1M band. Held at 95 rather than 100 because **no retrieval benchmark at window length is published** — no RULER, no MRCR, no needle test — so the 1M claim rests on served limits plus Z.ai's IndexShare/DSA architecture work, and the only visible long-context *score* is a provisional AA-LCR 80%, well short of the ≥98% the 100 tier demands.
- **Multimodal: 15/100.** **Text in, text out, no image input** — the methodology's flat text-only value, confirmed by AA's FAQ. Worth flagging for anyone shopping the GLM-5 line: **GLM-5.3-Flash is the natively multimodal member** (321B/18B, first multimodal in the series, hybrid sparse+linear attention, mHC, 30T-token multimodal pre-training, **MIT**-licensed, TB2.1 84.3 / DeepSWE 63.4 / HLE 55.3). GLM-5.3 proper is the larger, text-only, more capable and much more expensive of the two.
- **Coding: 90/100.** Frontier-adjacent and consistent: **Terminal-Bench 2.1 88.2%**, **FrontierSWE 78.1%**, **DeepSWE v1.1 66.9%** (independently reproduced on HF), **NL2Repo 58.0%**, and an independent **Vals AI** bash-only-harness SWE-bench Verified run placing it **6th of 88 models** with 97/95/90/100 across the difficulty bands — ahead of Kimi K3 and Claude Opus 4.8. Capped at 90 because it is consistently **2nd or 3rd, not 1st**: FrontierSWE 78.1 vs Fable 5's 88.2, ProgramBench 19.0 vs Fable 5's 33.0, SWE-Marathon 42.5 vs Opus 4.8's 48.8, ExploitBench 54.4 vs Fable 5's 78.0, and Terminal-Bench 3.0 28.3 vs GPT-5.6 Sol's 34.6. There is also **no LiveCodeBench, no SWE-bench Pro and no Vibe Code Bench** score, and the headline coding claim rests partly on **Z.ai Code Bench, an in-house private benchmark**.
- **Cost efficiency: 72/100.** The weakest dimension by a wide margin, and the honest reason to hesitate. At **$1.40 in / $4.40 out** the output rate is **exactly 2× the methodology's ~$0.60/$2.20 ≈ 92 anchor**, and AA measured **$2.01 per Intelligence Index task plus a $1,238.50 total Index run** — the most expensive model in this comparison, at 69.0 tok/s and a 3.23s TTFT. Mitigations that keep it out of the 50s: an **81% cache discount** (cached read **$0.26**) and a **$0.90/M blended 7:2:1 rate**, third-party routes down to **$1.20/$4.00** (DeepInfra) or **$1.16/$4.65** (Melious), and subscription access via the GLM Coding Plan. Also note the 210M-token verbosity multiplies the bill on long agentic runs, and there is **no free Zen tier** to fall back on.
- **Overall Score: 76/100.** (92 + 90 + 95 + 15 + 90) / 5 = 76.4 → 76. Best fit: **the strongest open-weights pick for long-horizon coding agents and professional-knowledge deliverables that can absorb the price** — 88.2% Terminal-Bench 2.1, the best GDPval-AA v2 (1769) and AutomationBench (48.2) of anything Z.ai measured, and a real 1M window that its own benchmarks exercise. Two things to design around: it is **text-only** (use GLM-5.3-Flash for images, and it is MIT-licensed and roughly a tenth of the price), and **thinking cannot be disabled** — `thinking.type: "disabled"` fails outright, so a `low` effort setting plus `clear_thinking=true` is the only token-cost lever. If cost per task is the binding constraint, DeepSeek V4 Flash 0731 delivers 82.7% Terminal-Bench 2.1 and 54.4% DeepSWE at $0.14/$0.28.
