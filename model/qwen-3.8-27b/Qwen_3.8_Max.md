## Model card

- **Name:** Qwen 3.8 27B
- **Short description:** **Alibaba's dense 27-billion-parameter open-weight (Apache 2.0) multimodal model**, released **2026-08-14** (FP8-quantized on Hugging Face), and the standout **self-host value pick** of the Qwen 3.8 family — a 27B that runs on a **single 24 GB GPU at 4-bit** yet posts frontier-adjacent agentic numbers. Its **one strong independent anchor** is **Vals AI's SWE-bench Verified leaderboard** (bash-tool-only, mini-swe-agent harness), where it lands at **90% / 86% / 69% / 67%** across difficulty bands — roughly **15th of 88 models and the top open-weight dense model**, ahead of Claude Opus 4.6, Sonnet 4.6, GPT-5.2 and Gemini 3 Pro on that harness (corroborating the meta card's "SWE-bench 86.0% (Vals)"). Everything else on the official card is **vendor-reported by Alibaba with no independent reproduction at launch** — and those numbers claim it **beats Claude Opus 4.6 Max on 16 of 24 benchmarks**, led by **OSWorld-Verified 84.3 (vs Opus 72.7)**, **SWE-bench Pro 61.7 (vs 53.4)** and **IFBench 79.5 (vs 62.5)**, while **losing on knowledge-heavy reasoning** (HLE 30.8 vs 40.0; GPQA Diamond 89.2 vs 91.3; Terminal-Bench 2.1 73.0 vs 78.2). ⚠ **Artificial Analysis had *not* indexed it** as of Aug 2026, so read the vendor table as a **ceiling, not a floor** (documented caveats: imported competitor scores, asymmetric prompting on MathVision/BabyVision, and in-house QwenSWEBench/CoWorkBench).
- **Provider / access:** **Alibaba Qwen team.** **Open weights (Apache 2.0)** on Hugging Face (`Qwen/Qwen3.8-27B`, FP8 + NVFP4/4-bit quants) — self-host free (GPU compute only) via **SGLang / vLLM / Ollama** with an OpenAI-compatible API; managed inference via **Qwen Cloud (official API)**, **Alibaba Cloud Model Studio (DashScope/Bailian)** and third parties (OpenRouter, Northflank, Regolo, kie.ai). **No free hosted tier** (`noFreeId`). Listed here as `Qwen/Qwen3.8-27B`.
- **Release / knowledge:** Released **2026-08-14** (twelve days after the hosted **Qwen3.8-Max** flagship on 2026-08-02); the open dense successor to **Qwen3.6-27B** (2026-04-21). Training-data cutoff not published in the sources reviewed.
- **IDs:** `Qwen/Qwen3.8-27B` (HF) / `qwen3.8-27b` (API slug); Qwen open-dense line: Qwen3.6-27B → **Qwen3.8-27B**; hosted siblings Qwen3.8-Max / Qwen3.8-Flash.
- **Context window:** **262,144 (262K) native, extensible to 1M with YaRN.** ⚠ Qwen itself warns that **static YaRN can hurt shorter prompts**, so the 1M tier is an extension trick with a documented quality caveat, not a native 1M. Max output not separately published in the sources reviewed.
- **Modalities:** **Text + image + video in → text out.** Natively multimodal vision-language model (dedicated vision encoder ≈ 1B params, 28B total). Broad vendor vision coverage — GUI/desktop (OSWorld 84.3, AndroidWorld 81.9), documents/charts (OmniDocBench 1.5 91.1, CharXiv RQ 90.2 w/ code interpreter), real-world photos (RealWorldQA 85.9), embodied reasoning (ERQA 65.5), multimodal SWE (SWE-MM 38.6). **Video input** puts it above image-only peers; **no audio, no generative image/video output.**
- **Pricing (as of 2026-10-24):** **Open weights (Apache 2.0) → self-hosting is free** (pay only GPU compute). 4-bit quant weights ≈ **14–17 GB → single 24 GB GPU**; 32–48 GB for production headroom; full **BF16 ≈ 55.6 GB**; 80 GB+ for long context/high concurrency. Hosted API pricing varies by provider (Qwen Cloud / Model Studio / OpenRouter / Regolo); Regolo advertises ~93% below Alibaba Model Studio rates. Multi-token-prediction supported for faster serving.
- **Architecture:** Dense **27B** (28B incl. vision encoder) hybrid-attention Transformer — **48 Gated DeltaNet linear-attention layers + 16 full-attention layers** (linear-attention hybrid for efficient long context). Flexible "thinking" control (reasoning on/off), native multimodal encoder, multi-token prediction. Runs contamination-resistant fresh-problem evals (LiveCodeBench v6).

### Raw benchmarks found

Independent (**Vals AI** SWE-bench Verified, bash-tool-only mini-swe-agent harness — weighted highest):

- **SWE-bench Verified by difficulty band: 90% (<15 min) / 86% (15m–1h) / 69% (1–4 hr) / 67% (>4 hr)** — ≈ **15th of 88 models**, the **top open-weight dense model**, ahead of Claude Opus 4.6 (Thinking), Sonnet 4.6, GPT-5.2, Gemini 3 Pro and its own hosted sibling Qwen 3.8 Max (93/84/64/67) on the hard long-horizon bands; behind Grok 4.6 (96/96/93/100) and the frontier (Opus 5, GPT-5.6 Sol)
- ⚠ **No Artificial Analysis Intelligence Index** — AA had **not indexed** Qwen3.8-27B as of Aug 2026 (no independent general-intelligence/agentic score exists)

Vendor-reported (**Alibaba** official model card, 2026-08-14 — **no independent reproduction at launch**; treat as ceiling):

- Agentic coding: **SWE-bench Pro 61.7** (vs Opus 4.6 Max 53.4 — *imported* competitor score, different harness), **QwenSWEBench 79.0** (*in-house*, vs 63.8), **LiveCodeBench v6 90.3** (vs 88.8), **DeepSWE 1.1 42.2** (Opus not reported), **CoWorkBench 70.7** (*in-house*, vs 68.2), **IFBench 79.5** (vs 62.5 — widest text-side gap)
- Computer use / GUI: **OSWorld-Verified 84.3** (vs Opus 4.6 Max 72.7 — the card's strongest result, +11.6), **AndroidWorld 81.9** (vs 62.0)
- Terminal: **Terminal-Bench 2.1 73.0** — a *loss* (vs Opus 4.6 Max 78.2, −5.2); **NL2Repo-Bench 42.3** (vs 47.6, −5.3)
- Knowledge reasoning: **GPQA Diamond 89.2** (vs 91.3, −2.1), **Humanity's Last Exam 30.8** (vs 40.0, −9.2)
- Vision/multimodal: **OmniDocBench 1.5 91.1**, **CharXiv RQ 90.2** (w/ code interpreter; 83.7 no-CI), **RealWorldQA 85.9**, **ERQA 65.5**, **SWE-MM 38.6**, **ClawEval-MM 57.4/56.9**; ⚠ **MathVision 94.6** and **BabyVision 85.6** carry an *asymmetric-prompting* caveat (Qwen used one fixed prompt; competitors got best-of-two)
- vs open-weight peer **Muse Glimmer-30B**: wins every overlapping row (TB 2.1 73.0 vs 51.7; SWE-Pro 61.7 vs 51.2; GPQA 89.2 vs 83.5; OSWorld 84.3 vs 65.9)

> Provenance: The **Vals AI SWE-bench Verified bands (90/86/69/67)** are the **only independent** measurement and are weighted highest — they verify **elite agentic coding for a 27B dense open model** (top open-weight dense, ~15th/88, beating Opus 4.6/Sonnet 4.6/GPT-5.2 on a neutral bash-only harness). **Every other figure is vendor-reported by Alibaba** and, per regolo.ai and kingy.ai, had **no independent reproduction at launch** — with three documented caveats: **(1) imported competitor scores** (SWE-Pro uses Opus's own published number, not a same-harness re-run), **(2) asymmetric prompting** (MathVision/BabyVision), **(3) in-house benchmarks** (QwenSWEBench, CoWorkBench — directional only). **Artificial Analysis had not indexed the model**, so there is **no independent general-intelligence/agentic index** and the vendor table must be read as a **ceiling, not a floor**. The scaffolded meta.json was verified against coverage rather than inherited: its **"SWE-bench 86.0% (Vals)"** is corroborated by the Vals leaderboard, but its **"GPQA 90.5%"** is corrected to the vendor card's **GPQA Diamond 89.2**, and its 262K-native / 1M-YaRN, text/image/video-in and Apache-2.0 specs are all confirmed. **No benchmark was invented.**

### Normalized scores (1–100)

- **Tool use: 84/100.** Grounded in the **independent Vals bash-tool-only harness**, where Qwen 3.8 27B is **exceptionally strong on the long-horizon bands** (69% on 1–4 hr, 67% on >4 hr — well above Inkling Small's 43%/33% and Sonnet 4.6's 50%/33%), verifying sustained command-line agent fluency. Vendor card adds OSWorld-Verified 84.3 (would be #1 if real), AndroidWorld 81.9, IFBench 79.5, CoWorkBench 70.7 and DeepSWE 42.2 — but these are **unverified** (no AA Index, no reproduction), so they are credited only as upside. Held below GPT-5.4's 88-tier (which owns an **independently-measured** OSWorld #1 at 75.0 plus a broad verified agent stack) because Qwen's headline computer-use numbers rest entirely on the vendor card.
- **Reasoning: 80/100.** Strong-for-size but **vendor-only and behind frontier on the hardest knowledge tasks**: GPQA Diamond 89.2 and LiveCodeBench v6 90.3 are impressive for a 27B, yet it **loses to Opus 4.6 Max on HLE by 9.2 pts (30.8 vs 40.0)**, GPQA by 2.1 and NL2Repo by 5.3, and there is **no independent reasoning index** (AA never scored it). Capped at 80 because the encyclopedic/ambiguous-reasoning gap to the frontier is consistent across sources and none of the reasoning numbers are independently reproduced.
- **Context window: 82/100.** **262K native** is solid for a self-hostable dense model, and the **1M YaRN extension** is a real option — but Qwen itself warns **static YaRN can hurt shorter prompts**, so the 1M tier is a gated extension trick rather than native long-context. Discounted below the 1M-native frontier (Qwen3.7-Plus, MiniMax M3, GPT-5.4 at 1.05M) and held at 82 because max-output isn't separately published and the top of the range carries a documented quality caveat.
- **Multimodal: 82/100.** **Text + image + video in → text out** with a dedicated ~1B vision encoder and **genuinely broad coverage** — GUI/desktop (OSWorld, AndroidWorld), documents/charts (OmniDocBench 91.1, CharXiv RQ 90.2), real-world photos (RealWorldQA 85.9), embodied reasoning (ERQA 65.5) and multimodal SWE (SWE-MM 38.6). Scored **above image-only peers (grok-4.6, claude-sonnet-4.6 at 77)** because native **video** input plus document/chart understanding is materially broader — but held to 82 (not higher) because the flashiest vision numbers (MathVision 94.6, BabyVision 85.6) carry an **asymmetric-prompting** caveat and none are independently reproduced.
- **Coding: 85/100.** The honest headline — **independently verified elite agentic coding for its class**: Vals SWE-bench Verified ~86% overall (90/86/69/67) makes it the **top open-weight dense model** on a neutral bash-only harness, beating Claude Opus 4.6, Sonnet 4.6 and GPT-5.2, and its 69%/67% on the long-horizon bands exceed its own hosted sibling Qwen 3.8 Max. Vendor adds SWE-Pro 61.7, LiveCodeBench v6 90.3 and QwenSWEBench 79.0. Discounted a notch below the frontier because **Terminal-Bench 2.1 (73.0) loses to Opus 4.6 Max (78.2)** and the SWE-Pro win relies on an **imported competitor score** in a different harness — i.e. genuinely top-tier among open models, a step below the closed frontier on the hardest terminal work.
- **Cost efficiency: 93/100.** The defining strength — **Apache 2.0 open weights, self-hosting free**, with a **4-bit quant (14–17 GB) that fits a single consumer 24 GB GPU** and full BF16 at ~55.6 GB. No per-token cost when self-hosted; multi-token-prediction and SGLang/vLLM serving keep throughput high; even managed API rates are far below frontier closed models. Scored at the top of my open-weight range (above inkling-small's 90, since a 27B dense on one 24 GB GPU is dramatically cheaper to run than a 276B MoE). Scored but **not** counted in the Overall per methodology.
- **Overall Score: 83/100.** Mean of Tool 84 + Reasoning 80 + Context 82 + Multimodal 82 + Coding 85 = 413/5 = 82.6 → 83. Best fit: **self-hosted agentic coding, computer-use/GUI automation, document/multimodal extraction and high-volume private inference** on hardware most teams already own — where an independently-verified top-open-dense coder (Vals SWE-V ~86%) at zero license cost wins. **Not** the pick for the hardest knowledge reasoning (HLE/GPQA trail frontier), maximum native context (262K, 1M only via YaRN with caveats), audio, or teams unwilling to manage GPUs. Independent read: my **83 sits ~3.1 below the queue's curated 86.1** — a *deliberately large* gap because **the entire official benchmark table is vendor-reported with no independent reproduction and no AA Index**, with three documented inflation caveats (imported competitor scores, asymmetric prompting, in-house benchmarks); I credit the **one strong independent anchor** (Vals SWE-V ~86%) fully but treat the flashy OSWorld-#1 / beats-Opus claims as a ceiling. Internally consistent: Qwen 3.8 27B (83) lands **just below the strong 84-tier generalists** (inkling-small, grok-4.6, qwen-3.7-plus, ember-1, mimo-v2.6-free, minimax-m3 — all of which had at least one independent general-intelligence index) and **just above step-5-preview (82)** — an accurate portrait of a superb self-host value model whose 5-dimension mean is held to 83 chiefly by *unverified* reasoning/tool headlines and a capped 262K-native context, not by any weakness in its independently-proven coding.
