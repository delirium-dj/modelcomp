## Model card

- **Name:** Qwen3.5-397B-A17B
- **Short description:** Alibaba's largest and most capable **Qwen3.5** open-weights model, released **February 2026** — the first Qwen open-weights checkpoint with **native vision and video input**, unifying the previously separate Qwen3 (text) and Qwen3-VL lines through early fusion on multimodal tokens. A 397B-total / 17B-active sparse MoE on a Gated DeltaNet + gated-attention hybrid stack, supporting **201 languages and dialects**. Top use case: self-hosted or cheap-API multimodal agents that need frontier-adjacent vision, video and GUI capability under Apache 2.0. **Already superseded within the Qwen line:** Qwen3.6 (Apr 2026) and **Qwen3.8 2.4T-A95B (2026-08-12)** have shipped with their own weights, and the hosted production counterpart **Qwen3.5-Plus** remains the product Qwen actually points you at.
- **Provider / access:** Hugging Face `Qwen/Qwen3.5-397B-A17B` (Apache 2.0; compatible with Transformers, vLLM, SGLang, KTransformers). Served by **~20 tracked providers** (up from the 9 recorded in the first pass): Alibaba Cloud Model Studio (Beijing / Singapore / Frankfurt / Virginia), OpenRouter, DeepInfra, Novita, Together, Nebius, Scaleway, GMICloud, SiliconFlow, Parasail, Phala, DigitalOcean, AtlasCloud, StreamLake, Hugging Face, Cloudflare AI Gateway, AIHubMix, NVIDIA NIM, Mistral, Venice and others. Alibaba Cloud Model Studio (DashScope, OpenAI-compatible Chat Completions). No OpenCode Zen ID found.
- **Release / knowledge:** Released **2026-02-16** (HF page dated 2026-03-09; OpenRouter release date Feb 16, 2026; QwenLM GitHub news confirms "2026-02-16: We release Qwen3.5"). Knowledge cutoff: not disclosed on the model card; trackers list "Unknown".
- **IDs:** `Qwen/Qwen3.5-397B-A17B` (HF), `qwen/qwen3.5-397b-a17b` (OpenRouter), `qwen3.5-397b-a17b` (Alibaba/QwenCloud)
- **Context window:** **262,144 natively, extensible to 1,010,000 via YaRN** (model card). **The hosted route does not serve the extension.** Alibaba Cloud Model Studio's own Context Limits table (page last updated **2026-10-11**) gives **Context Window 262,144 / Max Input 260,096 / Max Output 65,536**, and **258,048 max input in Thinking Mode with an 81,920 max chain-of-thought cap**. So 1,010,000 is a self-hosting-only figure; the official API stops at 262K. **Caveat carried forward:** the project's `meta.json` `128K total` and `Text in/out` placeholders come from `scripts/lib/naming.mjs` defaults, not provider evidence. Qwen also warns that static YaRN can degrade shorter inputs and advises keeping ≥128K to preserve thinking.
- **Modalities:** **Text, image, and video in → text out** (confirmed identically across all four Model Studio regions). Reasoning: **on by default**, disabled via `enable_thinking: False`. Tool calls / function calling: **Supported**. Structured outputs: **Supported**. Web search: **Supported** in Beijing, Singapore and Virginia — **not supported in Frankfurt**. Prefix completion: supported. **Correction to the first pass: Context Caching is listed as "Unsupported" on Model Studio in every region**, so the first pass's "Prompt/context caching: yes" is wrong for the official API (it holds on third-party hosts such as StreamLake $0.12, Phala $0.225, DeepInfra $0.22). **Batch Inference: Unsupported. Fine-tuning: Unsupported** on Model Studio.
- **Pricing (as of 2026-10-17, USD per 1M tokens):** **Alibaba has moved to tiered pricing and this is the biggest change since the first pass.** Model Studio Global regions (Beijing, Frankfurt, Virginia): **$0.172 in / $1.032 out for input ≤128K, and $0.43 in / $2.58 out for 128K < input ≤256K** (all tokens in a request bill at the tier rate). Singapore (International deployment): flat **$0.60 in / $3.60 out**. Beijing CNY rates are ¥1.2/¥7.2 and ¥3/¥18 for the same two tiers. Alibaba's page states these are list prices excluding limited-time promotions. **Free quota: 1 million tokens, Singapore only, valid for 90 days** from activation/release/approval — no free quota in other regions. Third-party routes undercut even the cheap tier: **AIHubMix $0.1644/$0.9864**, OrcaRouter/Merge/EmpirioLabs $0.172/$1.03, CrofAI $0.35/$1.75, SiliconFlow/Kilo $0.39/$2.34, DeepInfra $0.45/$3.00 (cache read $0.22), OpenRouter $0.50/$3.60, the rest $0.55–0.75 in / $3.30–4.50 out. Apache 2.0 weights make self-hosting free of token cost.
- **Architecture:** Causal LM with vision encoder. **397B total / 17B activated MoE**, 60 layers laid out as 15 × (3 × (Gated DeltaNet → MoE) → 1 × (Gated Attention → MoE)), hidden dimension 4096, token embedding 248,320 (padded), **512 experts (10 routed + 1 shared)** with expert intermediate dimension 1024. Gated DeltaNet: 64 linear-attention heads for V, 16 for QK, head dim 128. Gated attention: 32 Q heads / 2 KV heads, head dim 256, RoPE dimension 64. Trained with multi-step MTP. **Apache 2.0.**

### Normalized scores (1–100)

- **Tool use: 78/100** (was 80). **Slightly lowered.** The genuinely new agentic evidence is mixed and mostly *upward* on the first pass's worst point — **APEX-Agents rose from 13.6% to 24.9%** (Mercor, 2026-10-07), **τ³-bench Telecom 97.8% / Airline 81.5% / Retail 84.4%** are strong, and **AA's own τ² reasoning run of 95.61% beats the card's 86.7%**. Independent tool rows now exist for the first time: **Toolathlon Verified 40.7%**, **Claw-Eval 57.8% (#23 of 27)**. Against that, **AA AutomationBench 1.2%** and **AA Agentic Index 19.1** are near-floor on the new index suite, **τ³-bench Banking 9.8%** shows a catastrophic domain-specific failure the vendor table conceals, and **AA-IFBench independent 51.6% vs the card's 76.5%** is a 25-point silent gap. Net: real agentic breadth, poor floor. 78.
- **Reasoning: 70/100** (was 78). **The clearest evidence-driven drop in this report.** The independent record is now substantial and it is consistently below the card: **AA Intelligence Index 21.4 on the current v4.3.2, versus the "45 / #3 among open-weights" headline this report's first pass led with** — AA's own index upgrade moved Qwen3.5 397B from 3rd to roughly 104th of 224 tracked models, and pricepertoken independently reads 18.4. **AA-HLE 19.8% vs the card's 28.7%**, **CritPt 0.9%**, **AA-LCR 64.3% vs 68.7%**, **AA-Omniscience −32 to −37.9 with an 88% hallucination rate**, **GDP.pdf 12.3%**, **FrontierMath v2 Tier 4 8.7%**, **FrontierSWE v2 0.0%**, and **LMArena text 1,450 — mid-pack, not the frontier**. The knowledge and math rows (MMLU-Pro 87.8/88.0, GPQA 86.1–86.4 independent, AIME26 91.3) hold up well; the composite and reliability rows do not. 70.
- **Context window: 84/100** (was 88). **Lowered on a specification correction, not on a capability finding.** 262,144 native is unchanged and still lands in the 200K–500K band, but this pass established that **the hosted route serves 262K only** — Model Studio's own table gives max input 260,096 (258,048 in thinking mode) — so the 1,010,000 YaRN figure is a self-hosting-only claim and should not be credited to the API. Measured retrieval is **mid-pack and independently lower than advertised** (**AA-LCR 64.3% vs 68.7%**; LongBench v2 63.2% trails GPT-5.2's 54.5% only in vendor framing and sits below Claude 4.5 Opus's 64.4%), and there is still no MRCR/RULER/GraphWalks. 84 reflects a solid, well-documented 262K with no evidence of exceptional long-horizon behaviour.
- **Multimodal: 84/100** (was 86). **Marginally lowered.** The native image **and video** input path is confirmed identically on all four Alibaba regions and the model-card evaluation is deep and largely corroborated where it can be (OSWorld-Verified 62.2% **[I]**, CharXiv 91.6% **[I]**, MLVU 86.7% **[I]**). But the one hard independent probe of vision reasoning, **AA-MMMU-Pro 52.7% against the card's 79.0%**, plus **OSWorld 2.0 at 0.0%**, shows the vendor's visual numbers are optimistic by a wide margin. Capped by text-only output and no audio input.
- **Coding: 70/100** (was 76). **Lowered on materially new independent data.** The evidence gaps the first pass complained about have been filled: **SWE-bench Pro 50.9%**, **DeepSWE 27.6%**, **AA-SciCode 41–45%**, **AA Coding Index 45.8**, **Terminal-Bench Hard 40.91%**, **Terminal-Bench 2.1 51.31%** (Mercor 53.9%, Vals 45.9%), **Vals SWE-bench 65.9%**, **Vibe Code Bench 7.7%**, **FrontierCode 13.6%**, **CursorBench 4.0 28.5%**, and Mercor's independent SWE-bench Verified **72.1%** against the card's 76.4%. The model is a competent-but-not-strong coding agent: respectable on Verified, distinctly mid-pack on Pro, weak on app generation and on hard agentic coding. The **Terminal-Bench 4.0 hard-zero** is recorded as an unresolved outlier rather than folded into the score.
- **Cost efficiency: 94/100** (was 91). **Raised on a real first-party price cut.** Alibaba's Model Studio moved this model to **tiered pricing: $0.172 in / $1.032 out below 128K input, $0.43/$2.58 from 128K to 256K** on the Global regions — roughly a **3.5× cut** on both sides versus the flat $0.60/$3.60 the first pass recorded (the flat rate survives only on Singapore, which is also the only region with a 1M-token free quota for 90 days). Third-party relays undercut even that (AIHubMix $0.1644/$0.9864). **Apache 2.0 weights** still make self-hosting token-free, which for a 397B model with only 17B active is the strongest cost argument in the tier. Held at 94 rather than higher because **context caching is not supported on Model Studio**, so long-prompt workloads on the official route pay full input price, and because the Singapore free quota is explicitly 90-day-limited and region-locked.
- **Overall Score: 77/100.** `(78 + 70 + 84 + 84 + 70) / 5 = 386 / 5 = 77.2 → 77`. Best fit: **self-hosted or cheap-API multimodal agents that need genuine video, document and GUI understanding alongside real tool calling** — the Apache 2.0 licence plus the new tiered pricing and 17B-active architecture make this the most cost-effective way to run a large open-weights vision-video model, and the τ³-bench Telecom/Airline/Retail results show real agentic execution. Explicitly **not** the pick for hard SWE-agentic coding (SWE-bench Pro 50.9%, DeepSWE 27.6%, Vibe Code Bench 7.7%, and an unexplained 0.0% on both Terminal-Bench 4.0 and OSWorld 2.0), and not for research-grade or frontier-knowledge work (FrontierMath Tier 4 8.7%, GDP.pdf 12.3%, AutomationBench 1.2%). Also note it has been overtaken inside its own family: **Qwen3.8 2.4T-A95B (2026-08-12)** and the hosted **Qwen3.5-Plus** (1M context by default, built-in tools, adaptive tool use) are where new deployments should look.
