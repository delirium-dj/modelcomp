## Model card

- **Name:** Qwen 3.5 397B — canonical ID **Qwen3.5-397B-A17B**, the **open-weights** release of Alibaba's Qwen3.5 flagship. This entry is the **self-hostable Apache-2.0 sibling** of the hosted **`qwen-3.5-plus`** API (same base model, different distribution).
- **Short description:** **Alibaba Cloud's largest and most capable open multimodal foundation model (released 2026-02-15/16), built "Towards Native Multimodal Agents" — a natively-multimodal MoE (early text-vision fusion) spanning chatbot, image and video understanding, document processing, reasoning, coding and agent work, and said to outperform Qwen3-VL at similar scales.** On **Alibaba's own agent scaffold (vendor-run)** it posts **SWE-bench Verified 76.4%** ("essentially level with Gemini 3 Pro's 76.2"), **LiveCodeBench v6 83.6%**, **AIME 2026 91.3%**, **GPQA Diamond 88.4%**, plus **MathVision 88.6 / BrowseComp 78.6 / OSWorld 62.2** (the shared base's vendor set). ⚠ **Independent verification is thin**: there is **no Artificial Analysis Intelligence Index page** (the AA model URL 404s), and the only independent harness that tracks the base — **Vals AI SWE-bench Verified (as the hosted "Qwen 3.5 Plus," same weights)** — shows a **severe long-horizon collapse: 85% (<15 min) / 68% (15m–1h) / 36% (1–4h) / 0% (>4h)**, with **JobBench 18.5%**. So the strong vendor numbers hold for short, scaffolded tasks but not for sustained real-world engineering. **Superseded by the 3.6/3.7/3.8 open lines.**
- **Provider / access:** **Alibaba / Qwen.** **Open weights on Hugging Face (`Qwen/Qwen3.5-397B-A17B`) and ModelScope under Apache 2.0** — free to self-host (ModelScope documents a **262,144-token endpoint via tensor-parallel on 8 GPUs**). Also served as a hosted API (the `qwen-3.5-plus` sibling; DeepInfra and others host `qwen3-5-397b-a17b`). `noFreeId: true` (no free hosted ID, but the weights themselves are free). Listed here as `opencode/qwen-3.5-397b`.
- **Release / knowledge:** **2026-02-15** (Qwen blog) / **2026-02-16** (release trackers). ⚠ **Superseded** by Qwen 3.6 / 3.7 / 3.8 open lines, "which improved every axis at similar footprints" (meta tradeoff — verified against my coverage of those successors). (Knowledge cutoff not published in the sources reviewed.)
- **IDs:** `Qwen3.5-397B-A17B` (HF/ModelScope weights) / `qwen3-5-397b-a17b` (hosted API ID) / `opencode/qwen-3.5-397b` (this dataset).
- **Context window:** **262,144 native, extensible to ~1,010,000 (~1M); the hosted tier serves 1M.** *Verified against the meta, ModelScope ("natively supports context lengths of up to 262,144 tokens"), and Qwen3-VL lineage docs ("native 256K, expandable to 1M").* ⚠ The **native out-of-the-box limit is 262K**; long-context beyond it needs explicit rope-scaling/YaRN config, and **no independent long-context retrieval score (RULER/MRCR) at ~1M surfaced**, so the extension is documented, not validated.
- **Modalities:** **Text + image + video in → text out.** *Verified against the meta and the Qwen blog ("native vision-language model"; "image and video understanding, image generation, document processing").* A **native VLM via early text-vision fusion** (not a bolted-on vision encoder) — the strongest dimension of this model. Reasoning: **yes** (a thinking-capable MoE). No native audio *input*.
- **Pricing (as of 2026-10-25):** **Open weights — free to self-host under Apache 2.0** (the primary value; cost = your GPU footprint, ~8 GPUs for a 262K endpoint). Hosted API (meta-reported, AA): **$0.60 input / $3.60 output per 1M** — ⚠ **not independently re-verified here** (the AA model page 404s). No free hosted ID.
- **Architecture:** **MoE, 397B total / ~17B active parameters, hybrid attention, Apache 2.0 open weights.** *Enriches the meta with the hybrid-attention + early-fusion native-VLM detail from the Qwen/AlibabaCloud blog.* The 17B-active footprint is the "serious-but-feasible self-hosting" the standout cites — large total capacity, modest active cost per token. Positioned as a **native multimodal agent** foundation, outperforming Qwen3-VL at similar scale.

### Raw benchmarks found

The critical split for this model: a **strong vendor benchmark set (all run on Alibaba's own agent scaffold)** versus a **near-total absence of independent replication** for the open weights — no AA Intelligence Index, and the one independent harness (Vals) that tracks the base model reveals a long-horizon collapse the vendor headline hides.

**Vendor — Alibaba/Qwen (own agent scaffold, Feb 2026):**

- **SWE-bench Verified: 76.4%** — "essentially level with Gemini 3 Pro (76.2)" (techie007); a strong *headline* coding number, but **scaffold-specific and vendor-run**.
- **LiveCodeBench v6: 83.6%** · **AIME 2026: 91.3%** · **GPQA Diamond: 88.4%** (morphllm/qwen blog) — strong reasoning/math/competition numbers, all vendor-reported.
- **MathVision 88.6 · BrowseComp 78.6 · OSWorld 62.2** — the shared base's vendor multimodal/agent set (MathVision is the standout visual-math result; OSWorld 62.2% is decent computer use).
- Framing: "demonstrates outstanding results across a full range of benchmark evaluations, including reasoning, coding, agent capabilities" (qwen.ai blog).

**Independent — Vals AI + Artificial Analysis:**

- **Vals AI SWE-bench Verified (mini-swe-agent, bash-tool-only; the base model tracked as the hosted "Qwen 3.5 Plus"): 85 / 68 / 36 / 0** across the <15min / 15m–1h / 1–4h / >4h difficulty bands — a **textbook long-horizon collapse** (solves short tasks at 85%, **fails 100% of the >4h tasks**). This is the single most informative independent number: the vendor 76.4% is a blended figure that masks zero sustained-agentic capability.
- **Vals JobBench: 18.5%** (weak real-world job-task performance).
- **Artificial Analysis Intelligence Index: none** — the AA model page (`qwen-3-5-397b-a17b`) **404s**, so there is **no independent AA Index, Coding Agent Index, GDPval-AA, Terminal-Bench or AA-Omniscience score** for this release. This is a significant verification gap for an open-weight flagship.
- **Official SWE-bench leaderboard:** does not list Qwen3.5-397B-A17B among the top rows (Qwen3-Coder 480B appears at 55.40 via mini-SWE-agent) — no independent SWE-bench confirmation of the 76.4%.

### Normalized scores (1–100)

- **Tool use: 79/100.** Vendor agent capability is real — **OSWorld 62.2%** (computer use) and **BrowseComp 78.6%** (web/agent), and the whole release is framed "Towards Native Multimodal Agents." But the **independent** agentic evidence is weak: **Vals JobBench 18.5%** and the **SWE-bench long-horizon collapse to 0% (>4h)** show it cannot sustain multi-step real-world work, and there is **no AA GDPval-AA/Briefcase/Terminal-Bench/AutomationBench** (no Index page). Scored **79** — vendor-strong but independent-weak agentic, capped by the long-horizon failure and the total absence of a neutral agentic harness.
- **Reasoning: 79/100.** Vendor **AIME 2026 91.3%** and **GPQA Diamond 88.4%** are near-frontier on paper, and MathVision 88.6 shows strong visual-math reasoning. Held to **79** because **every reasoning number is vendor-run on Alibaba's scaffold with zero independent replication** (no AA Index — which would place it on the neutral curve — and no Vals reasoning row for the base), and the model is **superseded**. Sits below the independently-verified open-weight reasoners (e.g. AA-Indexed Kimi/Inkling) and below the current budget tier (Claude Haiku 5.5 82, GPT-6 Luna 81) whose Index scores are measured.
- **Context window: 80/100.** **262,144 native, extensible to ~1M; 1M hosted.** Scored **80** — a point above the pure-256K band (78) for the **officially documented ~1M extensibility** (rope-scaling/YaRN) and the 1M hosted tier, but well below the validated-1M band (85) because the **native default is 262K**, the extension requires special config, and **no independent long-context retrieval score (RULER/MRCR) at ~1M surfaced**. (The hosted `qwen-3.5-plus` sibling, serving 1M out of the box, scores higher on this axis.)
- **Multimodal: 82/100.** **The standout dimension.** A **native vision-language model** (early text-vision fusion, not a bolted-on encoder) supporting **text + image + video in**, "**Alibaba's largest and most capable multimodal foundation model**," said to **outperform Qwen3-VL at similar scales**, with a strong vendor **MathVision 88.6** and document processing. Scored **82** — the native-video tier (level with grok-4.3 82, above qwen-3.6-plus 81); capped below 84 because the multimodal evidence is **vendor-only** (no independent Video-MME/MMMU replication for the 397B surfaced).
- **Coding: 77/100.** Vendor **SWE-bench Verified 76.4%** ("level with Gemini 3 Pro 76.2") and **LiveCodeBench v6 83.6%** look strong, but the **independent Vals SWE-bench row for the same base (85/68/36/0)** exposes a **severe long-horizon collapse — 0% on >4h tasks** — and there is **no AA Coding Agent Index** and **no official SWE-bench leaderboard confirmation** of 76.4%. Scored **77** (mid): the vendor short-task coding is respectable, but the measured inability to sustain real engineering tasks and the scaffold-specific headline keep it below the independently-verified coders.
- **Cost efficiency: 90/100.** **Apache 2.0 open weights — free to self-host** (the defining value; the most permissive license, no usage fee), with a modest **~17B active** per-token compute despite the 397B total. Held to **90** (just under the 92 open-weight-MIT band) because the **397B total footprint needs ~8 GPUs** for a 262K endpoint ("serious-but-feasible," not cheap), the **hosted tier is $0.60/$3.60** (meta-reported, mid-priced), and it is **superseded** by better open lines at similar footprint — which erodes its value proposition. (Not counted in Overall.)
- **Overall Score: 79/100.** Mean of the five quality dimensions = (79 Tool + 79 Reasoning + 80 Context + 82 Multimodal + 77 Coding) / 5 = **397/5 = 79.4 → 79** (Cost efficiency 90 is scored but **not** counted, per the v4 formula). **Divergence note:** my independent read is **79 vs the queue's curated 83 → −4**, a moderately wide gap consistent with the hosted sibling `qwen-3.5-plus` (report 62: 81 vs 85.1 → −4.1), since both share this base. The curated **83** credits the **headline vendor story** — Apache-2.0 open weights, native multimodality, SWE-bench 76.4% / AIME 91.3% / GPQA 88.4%, 397B/17B MoE — and those are real strengths (its **82 multimodal** and **90 cost** are genuine). My **79** is held below by the **evidence gap**: **no independent AA Index**, a **Vals long-horizon collapse to 0% (>4h) + JobBench 18.5%** on the same weights, **all reasoning/coding numbers vendor-run on Alibaba's own scaffold**, a **262K native** (not 1M) default context, and **superseded** status. Best fit: **cost-sensitive self-hosters who need a permissively-licensed native-multimodal generalist for short-to-medium reasoning/vision/summarization tasks** — not long-horizon autonomous engineering, where the independent data says it fails, and not buyers who should look to the 3.6/3.7/3.8 successors.
