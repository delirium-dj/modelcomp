## Model card

- **Name:** Grok 4.1 Fast (`grok-4.1-fast`; `grok-4-1-fast-reasoning` / `grok-4-1-fast-non-reasoning` API IDs; dataset uses `grok-4.1-fast`)
- **Short description:** xAI's speed-optimized 4.1 tier with 2M context window. Released 2025-11-19 (per xAI news post and model card PDF dated Nov 17 2025). Designed for high-volume tool-calling and agentic search; features 2M context, $0.20/$0.50 pricing, and a reasoning build (`grok-4-1-fast-reasoning`) that scores 93.3% on τ²-bench Telecom (independent AA verification noted) vs 63.7% for the plain/non-reasoning build. Meta note: deprecated in favor of Grok 4.3; this is a historical/preview-tier model in the dataset.
- **Provider / access:** xAI API (`grok-4-1-fast-reasoning`, `grok-4-1-fast-non-reasoning`); OpenRouter may list it but meta notes `noFreeId` (no verified Zen Free route); not on OpenCode Zen (`noFreeId: true` in meta.json).
- **Release / knowledge:** 2025-11-19 (xAI news/blog); model card PDF 2025-11-17. Knowledge cutoff not explicitly stated in sources consulted (xAI card focuses on evaluation, not training data cutoff).
- **IDs:** `x-ai/grok-4.1-fast-reasoning` (reasoning variant); `x-ai/grok-4.1-fast` (alias per meta); `grok-4-1-fast-non-reasoning` (plain build, deprecated faster — meta notes "deprecated in favour of Grok 4.3").
- **Context window:** 2,000,000 total; ~30,000 max output — verified by meta.json in this folder, xAI docs, and independent spec sources (Artificial Analysis review confirms 2M).
- **Modalities:** Text + image input; text output (per meta.json and xAI docs). Reasoning: yes — reasoning build (`reasoning`) vs plain (`non-reasoning`) with significant performance gap (`tau2` 93.3% reasoning vs 63.7% plain — meta.json). Tool calls: yes (explicitly designed for agentic/search; Agent Tools API launched same day). No verified audio/video output.
- **Pricing (as of 2026-11-02):** $0.20 / $0.50 per 1M input/output; cached input $0.05 (per meta.json `pricingNote` and independent Artificial Analysis review). No verified $0 Free route (`noFreeId: true`). Note: pricing is very low for 2M context, making cost efficiency a standout.
- **Architecture:** Not fully disclosed by xAI; model card focuses on evaluation/safety rather than architecture details. Independent Artificial Analysis review (2025-11-19) describes it as a reasoning-optimized variant with 2M context, faster inference, and lower cost. No open-weights release; proprietary xAI model. The dataset meta notes it is deprecated in favor of Grok 4.3.

### Raw benchmarks found (3 independent searches, compared)

Sources consulted (independent):
1. **Official xAI announcement + model card** (`x.ai/news/grok-4-1-fast`, `data.x.ai/2025-11-17-grok-4-1-model-card.pdf`) — official vendor benchmarks and specs; 2M context confirmed; pricing and tool-calling focus confirmed; reasoning vs plain variants noted; deprecated status confirmed by meta.json (`tradeoff` line: "deprecated in favour of Grok 4.3").
2. **Independent benchmark aggregator / evaluation sources** (`benchgap.net/model/grok-4-1-fast-reasoning`, `benchmarklist.com/models/x-ai-grok-4-1-fast/`, `theaggregate.ai/model?slug=grok-4-1-fast-non-reasoning`) — measured and estimated scores across 12+ benchmarks; confirms reasoning build vs plain build divergence (e.g., AA-GPQA Diamond 85.3% measured for reasoning; AA-HLE 19.3% measured; AA Agentic Index 24.1% estimated — low). Independent Artificial Analysis review (`artificialanalysis.ai/models/grok-4-1-fast-reasoning`, 2025-11-19) explicitly notes: "This model is deprecated. We only continue performance benchmarking for the default 10k input token workload. Results for other workloads are historical and no longer updated." This is a critical independent verification of deprecated status.
3. **Independent comparison / analysis / review sources** (`aireleasetracker.com/compare/openai/gpt-5.6-sol/x-ai/grok-4.1-fast`, `benchmarklist.com/models/x-ai-grok-4-1-fast/` coding section) — independent benchmark comparison with competitors; confirms coding scores vary widely by harness (e.g., Terminal-Bench 2.1 88.8% vs Terminal-Bench 4.0 37.27% — massive harness/version sensitivity); independent `benchmarklist.com` coding evaluation shows DeepSWE 1.1 73% (but note this may be for reasoning variant or family, not precisely `grok-4.1-fast` alone).

Conflicting / comparative results (explicitly compared):

- **GPQA Diamond (science reasoning):** Independent Benchgap (reasoning variant): AA-GPQA Diamond measured 85.3%; GPQA Diamond estimated 88.8% ± 2.3 pp (medium confidence). Independent `benchmarklist.com`: GPQA diamond 83.0% estimated (low confidence, Vals AI). No official vendor GPQA score published in the sources I retrieved (xAI news/card focuses on τ²-bench Telecom 93.3% and agentic/tool-calling benchmarks, not GPQA). **Conflict by absence:** vendor does not claim GPQA for this model; independent estimates vary (83.0% → 85.3% → 88.8%). Score anchored conservatively toward measured value (85.3%), with lower bound noted.
- **Agentic / tool-use benchmarks (τ²-bench Telecom):** Official vendor: τ²-bench Telecom 93.3% (independent AA verification noted by vendor); Berkeley Function Calling v4 72% overall accuracy. Independent Benchgap: τ²-bench results 93.3% (measured) — same figure, independently cited. Independent `benchmarklist.com` agentic section: Tau2-Bench Telecom 98.5% (98th pct), Tau2-Bench Retail 78.2% (100th pct), GDPval-AA 1748 Elo (99th pct), Toolathlon 78.4% (93rd pct) — **note:** these may mix reasoning and plain variants or family-level data; exact `grok-4.1-fast` attribution is unclear from independent source labeling. **Conflict noted:** independent benchmark aggregator (`benchmarklist.com`) reports very high agentic scores (Tau2 Telecom 98.5%, GDPval 1748) but the independent Artificial Analysis review (2025-11-19) states the model is deprecated and only benchmarks the default 10k workload, with historical results for other workloads. The high agentic scores likely reflect the reasoning build (`grok-4-1-fast-reasoning`), while the dataset's `grok-4.1-fast` may represent the family or a mixed entry. My score uses the vendor-confirmed reasoning variant scores but notes the variant ambiguity.
- **Coding benchmarks (DeepSWE, Terminal-Bench, LiveCodeBench):** Independent `benchmarklist.com`: DeepSWE 1.1 73% (official leaderboard, 69th pct); Terminal-Bench 2.1 88.8% (88th pct, best reported harness); LiveCodeBench 80.6% (54th pct); Terminal-Bench 4.0 37.27% (46th pct); SWE-bench Verified 60.4% (verified). Independent comparison (`aireleasetracker.com`) shows Terminal-Bench 2.1 88.8% for Grok 4.1 Fast vs 84.3% for GLM 5.3 Flash; SWE-Bench Pro 55.6% (but this may be for GPT-5.2 Thinking comparison, not Grok directly — comparison table format is ambiguous). Independent Benchgap: AA Coding Index 39.3% estimated ± 6.8 pp (low confidence); SWE-bench Verified estimated 71.9% ± 4.4 pp (high confidence) — **conflict with benchmarklist.com verified 60.4%**: 71.9% estimated vs 60.4% verified. Score uses the more conservative verified figure (60.4%) with the estimated range noted.
- **Reasoning (HLE, AA Agentic Index, MMLU):** Independent Benchgap (reasoning variant): AA-HLE measured 19.3% (low); AA Agentic Index 24.1% estimated ± 12.3 pp (low confidence); MMLU-Pro 86.0% estimated ± 4.1 pp; MMMLU 87.6% estimated; ARC-AGI-1 66.8% estimated ± 7.6 pp (low confidence). **Notable conflict:** HLE is very low (19.3%) compared to MMLU-Pro (86.0%) — this suggests reasoning is weak on expert-level open-ended questions (HLE) but strong on multiple-choice knowledge (MMLU), consistent with a tool-calling/speed-optimized model rather than deep-reasoning flagship. The dataset meta confirms this tradeoff: "plain build has no deliberation — it executes plans, it does not make them."
- **Deprecated status (independent verification):** Independent Artificial Analysis review (2025-11-19) explicitly confirms: "This model is deprecated. We only continue performance benchmarking for the default 10k input token workload." The dataset meta also states: "deprecated in favour of Grok 4.3". No conflict — both independent and dataset agree.
