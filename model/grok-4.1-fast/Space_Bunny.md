## Model card

- **Name:** Grok 4.1 Fast (ships in a **Reasoning** and a **Non-reasoning** variant under one name; both are covered here because the catalog slug `grok-4.1-fast` maps to either depending on provider)
- **Short description:** xAI's November 2025 value tier — a very cheap, very long-context Grok offered in thinking and non-thinking flavors, launched 2025-11-19 alongside the Agent Tools API (real-time X search, Reddit search, web browsing, remote code execution) and positioned as "our best tool-calling model with a 2M context window", trained with long-horizon RL across "dozens of domains" covering customer support and finance. Its defining feature is a **2M-token context window at a $0.20/$0.50 price point**, which no other model at that price matched. **Status: RETIRED, and the retirement has had a second-order effect on pricing that the first pass missed entirely.**
- **Provider / access — dead, with a trap.** Per xAI's own migration guide (`docs.x.ai/developers/migration/may-15-retirement`): `grok-4-1-fast-reasoning` and `grok-4-1-fast-non-reasoning` were **retired from the xAI API on 2026-05-15 at 12:00 PM PT**, and *"requests to the retired model slugs above will automatically redirect to `grok-4.3`. The slugs themselves continue to resolve, so you do not need to change your code to avoid breakage."* **Anyone still calling this model ID is calling Grok 4.3 and being charged Grok 4.3 prices.** Historical mirrors existed on OpenRouter, Vercel AI Gateway, Kilo Gateway, Azure AI Foundry, Helicone, Qiniu and Google Agent Platform; **Oracle OCI** carried it with its own retirement notice and **retired it 2026-08-15**. It is absent from the xAI API, from OpenRouter's live list, and from Artificial Analysis as a purchasable model (AA shows no price and no measured speed).
- **Retirement timeline — three dates, all recorded:**

  | Milestone | Date | Source |
  | --- | --- | --- |
  | xAI API retirement; slugs begin redirecting to `grok-4.3` | **2026-05-15** | docs.x.ai migration guide |
  | Oracle OCI deprecation → retirement | deprecated **2026-05-15**, retired **2026-08-15** | Oracle OCI Generative AI model page |
  | BazaarLink's own record of the endpoint's end | **2026-05-18** (BazaarLink's figure, not xAI's) | bazaarlink.ai |

  In service: **177 days** from 2025-11-19 to 2026-05-15 (LLMLearner's tally). Superseded by Grok 4.3, then 4.5, 4.6, 4.7 and 4.20.
- **Release / knowledge:** **2025-11-19** (xAI launch post; Artificial Analysis, LLM Directory and LLMLearner all agree). Knowledge cutoff **not published by xAI**; Oracle states "Knowledge Cutoff: Not available".
- **IDs:** `x-ai/grok-4.1-fast`, `x-ai/grok-4.1-fast-reasoning`, `x-ai/grok-4-1-fast-non-reasoning`, `xai.grok-4-1-fast-reasoning` (OCI). No Zen Free ID. **Note:** this folder's `meta.json` stub carries `contextWindow: "128K total"`, which contradicts the 2M below; correcting `meta.json` is the orchestrator's job per `tasks/sync-data.md`.
- **Context window:** **2,000,000 tokens.** Oracle OCI's model page states it first-party: *"Context Length: 2 million tokens (maximum prompt + response length is 2 million tokens for keeping the context). In the playground, the response length is capped at 16,000 tokens for each run, but the context remains 2 million."* Corroborated by Artificial Analysis (both variants) and by provider listings. **Max output: contested, and the first pass got this wrong.** The first pass recorded **104,857** on the strength of a single aggregator (anyrouter) and stated that it "clears the <64K caveat comfortably". Against that: **Oracle's documented playground cap is 16,000 tokens** and AnotherWrapper lists **30K**. The anyrouter 104,857 figure is not corroborated by any platform documentation and is now treated as unreliable. Either documented value sits *below* the methodology's 64K caveat threshold, so the first pass's "comfortably clears" was wrong on the evidence then available too.
- **Modalities:** text and **image** in; text out (both variants per Artificial Analysis and Oracle). Reasoning: **yes** on the Reasoning variant, **no** on the Non-reasoning variant. Tool calling: supported on both (Oracle: function calling and structured outputs both yes; cached input tokens yes). Oracle notes deep domain knowledge in finance, healthcare, law and science.
- **Pricing — the single most important change in this report:**

  | | Input /1M | Output /1M |
  | --- | --- | --- |
  | **Historical (2025-11-19 → 2026-05-14)** | **$0.20** | **$0.50** |
  | **What the slug bills today** (Grok 4.3 rates, per docs.x.ai) | **$1.25** | **$2.50** |

  xAI's migration page is explicit: *"If you continue sending requests to a deprecated slug after May 15, please be aware that you will be billed at `grok-4.3` pricing of $1.25 per 1M input tokens and $2.50 per 1M output tokens rather than the rates of the original model."* That is **6.25× the input price and 5× the output price** of the rate card this entry is named after. The first pass scored Cost efficiency 99 on the $0.20/$0.50 figure and described the model as "cheaper than the methodology's ~$0.10/$0.20 band" — that is true of a price nobody can pay any more.
- **Architecture:** Proprietary; xAI has not disclosed parameter count, architecture or training details beyond the long-horizon RL description.

### Raw benchmarks found

> The first pass stated flatly that "no verified public coding benchmark exists for this model." **That was wrong, and correcting it is the main work of this pass.** A substantial independent suite now exists. Numbers are labelled by source; several aggregator records are demonstrably garbled and are rejected explicitly below.

Agent / tool use:

- **τ²-Bench (Telecom): xAI's launch page claims 100% at a total benchmark cost of $105, footnoted "Independent evaluation verified by Artificial Analysis." The leaderboard value is 93.3% (BenchmarkList, #35 of 332, recorded 2026-06-10).** On the corrected **τ²-Bench-Verified** leaderboard, Grok 4.1 Fast **Reasoning is #1 of 17 models** with **82.71% average — Airline 72.00%, Retail 81.40%, Telecom 94.74%** — ahead of Claude Opus 4.5 (81.99%) and GPT-5.2 (80.30%), with `gpt-5.1` as the user simulator. **So the honest reading is: xAI's headline 100% is ~6 points above the independently listed value, but on a corrected, harder version of the benchmark this model is genuinely the strongest in the field.** Both facts are recorded.
- **BFCL v4: xAI's launch page claims 72% at a total cost of $400. The independent leaderboard value is 69.6%, #5 of 85 (BenchmarkList), with sub-scores Non-Live AST 88.3%, Live 78.5%, Multi-Turn 58.9%, Web Search 82.5%, Memory 54.0%.** The score gap is **2.4 points, not the 5–7 the pre-pass lead suggested**. The *cost* gap is the more alarming one: **BenchmarkList records the total run at $17.26 against xAI's stated $400 — a 23× discrepancy**, which says the xAI figure came from a materially more expensive configuration than the leaderboard run. xAI's own launch table also concedes that "Gemini 3 Pro's score is an estimate provided by an independent evaluator, pending official results" — an acknowledged non-official number inside xAI's own comparison chart.
- **Claw Bench: 88.6%, #12 of 29** *(Thinking, with tools)*. **PinchBench: 82.4%, #42 of 75**. **Public Benefits Bench v1.1: 44.8%, #26 of 26 (last place)**. **SAGE: 31.3%, #50 of 55.**
- **APEX-Agents: 24.8%, #31 of 44.** **DeepPlanning: 17.2%, #22 of 30.** **Agent Island: 0.25, #43 of 49.** **RecoAtlas: 25.2%, #3 of 12.**
- **τ³-Banking: 13.1%, #71 of 107** *(Thinking-high, with tools)* — a poor banking-agent result, and it directly contradicts the launch framing of the model as tuned for "finance".
- **GDPval-AA: 1044 Elo, #109 of 356** *(Artificial Analysis, recorded 2026-05-28)*.
- Agent Island / agency work: **AgencyBench 44.3%, #7 of 11**; **LLM-WikiRace 44.7% medium success, #12 of 31** (Easy 90.0%, Hard 5.0%).
- Notable and worth recording: **Hack-Verifiable TextArena 28.5% average hack rate — #1 of 12, the field leader** — with Hidden-Solution HR 56.3%, Logical-Bug HR 32.0%, Read-Prompt HR 25.7%. This is the only benchmark in this report where Grok 4.1 Fast leads its field, and it is a *reward-hacking susceptibility* measurement. The source flags it as self-reported.
- xAI's own launch-comparison numbers (vendor-reported, comparing against GPT-5, Claude Sonnet 4.5, Gemini 3 Pro): **Reka Research-Eval 63.9%** (vs 45.5 / 41.2 / 55.9), **FRAMES 87.6%** (vs 86 / 85 / 90.9), **X Browse 56.3%** (vs 24.2 / 14.6 / 26.5). xAI also reports **FActScore hallucination error of 2.97%, "about half the rate of Grok 4 Fast"** — i.e. a vendor claim that this is a *low*-hallucination model.
- Tool calling: **supported on both variants** (Oracle capability flags; BenchmarkList's BFCL row confirms the function-calling path was exercised).

Reasoning / knowledge:

- **Artificial Analysis Intelligence Index — three conflicting published values, all recorded and none adopted as sole truth: 20.4 (reasoning) / 11.3 (non-reasoning)** per Sophon and benchgap (benchgap marks 20.4 "measured"); **30.6, #130 of 566** per Easy-Benchmarks; **39 (reasoning) / 24 (non-reasoning)** per AI Wiki. A 20-point spread on one index reading is unusually large and is almost certainly index-version or effort-setting drift rather than measurement error. The first pass recorded 20 / 11; the direction of travel is upward on every aggregator.
- **GPQA Diamond: 85.3% (AA) / 85.0% (#66 of 187)** — consistent across sources and *above* the methodology's 60–80% mid band.
- **MMLU-Pro: 85.4% (AA) / 85.0% (#25 of 147)** — strong.
- **AIME 2025: 89.0%, #36 of 85** *(Thinking, no tools)*.
- **Humanity's Last Exam: 17.6% (#99 of 137) / 19.3% (AA)** — well below the methodology's "<10% → 55–65" floor being cleared and far below the 40%+ frontier anchor.
- **CritPt: 2.9%, #72 of 125** — near-floor.
- **AA-Omniscience Accuracy: 25.1%.** **AA-IFBench: 52.7%.** **LiveBench: 60.0% (#83 of 103) / 70.0% depending on aggregator.** **IMO-ProofBench Advanced 18.6% (#12 of 23)**. **SimpleBench 56.0% (#44 of 92)**. **MedCode 28.4% (#55 of 55 — last place)**. **MedScribe 78.7% (#39 of 57)**.
- **The pattern is consistent and specific:** this model is strong on classical, well-graded academic benchmarks (GPQA, MMLU-Pro, AIME) and weak on frontier knowledge, hard multi-step reasoning and hallucination control (HLE ~18%, CritPt 2.9%, Omniscience 25.1%, ProofBench 4 on Sophon). xAI's own FActScore claim of 2.97% error is *not* corroborated by AA's Omniscience Accuracy of 25.1%.

Coding:

- **SWE-bench Verified: 41.4%** — **Vals AI's own leaderboard, Mini-SWE-agent harness, #85 of 88, at a recorded $0.03 per test.** This is the strongest-provenance number in the whole file: a first-party benchmark operator's own board, same scaffold for every model. For scale on that board: Grok 4 Fast (Reasoning) 45.4%, Mistral Large 3 41.4%, Ling 3.0 Flash 65.2%, MiniMax-M3 75.0%, Claude Opus 4.8 88.6%, Claude Opus 5 97.0%. **Vals states it has stopped running SWE-bench Verified on new releases because the benchmark has saturated** — the board is frozen at 2026-09-01, so no fresher value will ever appear.
- **LiveCodeBench: 82.0% (#33 of 114) / 82.2% (#22)** — **genuinely strong**, and the one coding row where this model is near the top of its field. (The pre-pass lead's 80.6% is stale; the live value is 82.0–82.2%.)
- **SciCode: 44.2% (#84)** *(AA)* — below the methodology's 55% frontier reference and below where a Coding Index in the high 50s would sit.
- **Terminal-Bench Hard: 24.2%, #92 of 326** *(Artificial Analysis, recorded 2026-06-10)*. Terminal-Bench 1.0: 23.0% (#22 of 26). Terminal-Bench 2.0: 18.0%.
- **Vibe Code Bench v1.1: 1.2%** *(measured, #60 of 63)* — effectively a zero. **Code Migration 19.9%. FrontierCode 14.7%. ProofBench 4.** **LiveBench Coding: 69.6%.**
- **Terminal-Bench 4.0 / Tau3-Banking / AutomationBench / Claw-Eval: still no value published** for this model.
- **Net read:** strong at *algorithmic and competitive* programming (LiveCodeBench 82%), near the floor at *real-repository software engineering* (SWE-bench Verified 41.4%, bottom four of 88) and *agentic terminal coding* (TB-Hard 24.2%, bottom third). The lead's characterisation of "mediocre and bottom-decile" is accurate for the latter two and wrong for LiveCodeBench.

Long context:

- **2M-token context window**, first-party on Oracle OCI and corroborated by Artificial Analysis for both variants.
- **AA-LCR v1.1: 74.0%** *(measured — benchgap, listing Artificial Analysis as the source)*. **This closes the first pass's "zero retrieval measurement" gap**, and it is the first long-context measurement this model ever received.
- **Conflict worth stating plainly:** xAI's own launch page claims *"consistent performance across its full 2-million-token context window"* and, separately, reports a **long-context retrieval figure of 67%, "far above Grok 4 (22%)"**. So **the vendor's own number is ~67% at 2M, and the independent long-context measurement is 74%.** Neither supports "no degradation" — the marketing line and the vendor's own measurement contradict each other. For scale on AA-LCR: Kimi K3 (max) leads at 88.67%.
- **No MRCR / RULER / GraphWalks retrieval result exists.** A 2M *capacity* claim with a 67–74% retrieval figure attached is a materially different claim from one with no measurement, and this report scores it that way.

Throughput:

- **Not measured.** Artificial Analysis shows "Speed N/A, Output tokens per second Unknown" for both variants, and no provider currently serves the model to measure. One aggregator lists ~90 tok/s and another 0 t/s; neither is a measurement and neither is used.

### Normalized scores (1–100)

> Derived from the raw numbers above using `model-comparison.md` (v4). Overall = half-up
> mean of the five quality dims; Cost efficiency is scored but never counted.
>
> Scores below describe the **Reasoning variant** as the default, with the non-reasoning variant's divergence noted where it changes a dimension.

- **Tool use: 65/100.** Up from 55, and this is the biggest upward correction in the report. The first pass scored 55 on the explicit basis that "no quantified agentic score exists at all" and that the methodology says to penalise the gap rather than assume a band. **Data now exists and it is good: τ²-Bench-Verified #1 of 17 at 82.71% average (the strongest model on the corrected benchmark), Claw Bench 88.6% #12 of 29, PinchBench 82.4%, τ²-Bench Telecom 93.3% #35 of 332, BFCL v4 69.6% #5 of 85, AgencyBench 44.3% #7 of 11, GDPval-AA 1044 Elo.** xAI's central claim — that this is its best tool-calling model — is now supported by independent evidence, not just vendor copy. **What caps it at 65 rather than higher:** xAI's headline numbers are **not** reproduced — τ²-Bench Telecom is 93.3% against a claimed 100%, and BFCL v4 is 69.6% against a claimed 72% — and the agentic evidence is sharply bimodal. **τ³-Banking 13.1% (#71 of 107)** and **Public Benefits Bench 44.8% (#26 of 26, last)** directly contradict the "tuned for finance and customer support" framing, while **APEX-Agents 24.8%, DeepPlanning 17.2% and Agent Island 0.25** are weak general-purpose agentic results. The model is an excellent *tool-call formatter* and a mediocre *long-horizon planner*, which is not the same thing.
- **Reasoning: 62/100.** Up from 58. Two independent pushes in opposite directions, resolved by weight. **Up:** GPQA Diamond **85.3%** and MMLU-Pro **85.4%** — both above the methodology's 60–80% mid band — plus **AIME 2025 89.0%**, **LiveBench 60–70%** and **SimpleBench 56.0%**. These are real measurements the first pass recorded as absent. **Down:** **HLE 17.6–19.3%**, **CritPt 2.9%**, **AA-Omniscience Accuracy 25.1%** and **MedCode 28.4% (last of 55)** are all weak, and the AA Intelligence Index — the composite that actually weights agentic and long-horizon work — reads **20.4 / 11.3**, **30.6** or **39** depending on the aggregator, i.e. between clearly-below-median and mid-tier. **The ~9-point reasoning-vs-non-reasoning gap on the AA index is the cleanest available measurement of what this model's thinking mode is worth** and is unchanged from the first pass. Scored above 58 because the classic academic rows are genuinely strong, and well below the methodology's 70+ band because the frontier knowledge and hard-reasoning rows are genuinely poor.
- **Context window: 90/100.** Down from 95. **2,000,000 tokens** is now first-party on Oracle OCI, so the ≥1M tier placement is solid. **What changed, in both directions.** *Up:* there is now a real measurement — **AA-LCR v1.1 at 74.0%** — where the first pass had none, and a measured mediocre long-context score is better evidence than an absence. *Down:* 74% is not close to the **≥98% at 512K+** the methodology requires for the top of this tier, and **xAI's own advertised long-context retrieval figure is 67%** — which means the vendor's claim of "consistent performance across its full 2-million-token context window" is contradicted by the vendor's own measurement two paragraphs later. **And the max-output caveat now bites in the wrong direction:** the first pass recorded 104,857 and said it "clears the <64K caveat comfortably", but the only *documented* figures are **Oracle's 16,000-token playground cap** and AnotherWrapper's 30K — both **below** the 64K threshold, which is a deduction the first pass did not apply. 90 reflects a genuinely enormous window with genuinely mediocre measured recall and a contested output ceiling.
- **Multimodal: 65/100.** Unchanged. Text + image input with text-only output matches the +image-in = 60–70 band, confirmed identically by Artificial Analysis on both variant pages and by Oracle. **Now measured, and the measurement sits in the lower half of the band: MMMU-Pro 63.3%, #81 of 118** — so this is a middling visual-reasoning model, which is what the score already implied. (AnotherWrapper prints MMMU-Pro 78.1% and MMMU 63.7% for this model with no harness stated; the AA-sourced 63.3% is the one used.) No video, PDF or audio path and no non-text output, so the 75+ bands do not apply. Two Qiniu listings advertise audio/video input; that is not corroborated by AA, Oracle or xAI and is not counted.
- **Coding: 52/100.** Up from 45. **The first pass's reasoning for 45 was "no verified public coding benchmark exists for this model" — that premise is now false, and it is corrected here rather than carried forward.** What the full suite actually shows is a model that is **strong at algorithmic coding and near the floor at real software engineering**: LiveCodeBench **82.0–82.2%** (#22–33 of 114) is a genuine top-of-field result, and LiveBench Coding 69.6% supports it. Against that, **SWE-bench Verified 41.4% on Vals' own board is #85 of 88 — bottom four** (Grok 4 Fast Reasoning 45.4%, MiniMax-M3 75.0%, Claude Opus 4.8 88.6%, Claude Opus 5 97.0%), **Terminal-Bench Hard 24.2% is #92 of 326**, **Code Migration 19.9%**, **FrontierCode 14.7%**, **SciCode 44.2% (#84)** and **Vibe Code Bench v1.1 1.2%** — the last of which is effectively a zero on a suite where the field leader scores 89.59%. A model that writes competitive-programming solutions well and resolves 41% of real GitHub issues is not the coding model its price invited anyone to expect, and that gap is the finding. 52 is mid-low band: above the evidence floor the first pass was forced into, well below the methodology's frontier anchors.
- **Cost efficiency: 72/100.** Down sharply from 99, and this is the most consequential correction in the report. **The $0.20 / $0.50 rate card is no longer purchasable.** xAI's own migration guide states that requests to this slug after 2026-05-15 are *"billed at `grok-4.3` pricing of $1.25 per 1M input tokens and $2.50 per 1M output tokens rather than the rates of the original model"* — **6.25× input and 5× output**. Anyone whose code still points at `grok-4-1-fast-reasoning` is running Grok 4.3 at `low` effort and paying Grok 4.3 prices, which places them below the methodology's ~$0.60/$2.20 ≈ 92 anchor on both axes. **72 is scored on what the entry actually costs today**, with the historical rate recorded alongside it: at $0.20/$0.50 this would have been the cheapest long-context model available and would have scored in the high 90s, which is what the first pass did. A score that cannot be bought is not a score. The 177-day life of the model and its own list price are the same story.
- **Overall Score: 67/100.** Half-up mean of the five quality dims (65 + 62 + 90 + 65 + 52) / 5 = 66.8 → **67**. Up from 63.6 — and the composition matters more than the total. **Four of the five quality dimensions rose** (Tool use +10, Reasoning +4, Coding +7, with Multimodal held) purely because real measurements replaced absence, and the methodology's stated rule is to penalise a *gap*, not to punish a mediocre result harder than a missing one. **Cost efficiency collapsed −27**, but Cost is excluded from the mean by design, so it does not appear here. **What this entry actually is now:** a 177-day historical artifact whose one genuinely great property — the best tool-call formatting and the best corrected-τ²-Bench agentic score in the field, at a 2M context — was real and is now unobtainable, and whose reputation for cheapness actively misleads, because the slug resolves and bills at 5–6× the advertised rate. For any live xAI work the correct destination is `grok-4.3` (1M context, four effort levels, $1.25/$2.50) or a current-generation model, chosen deliberately rather than by inherited slug.
