# Grok 4.1 Fast — Independent Research Report

## Summary and evidence

Grok 4.1 Fast is SpaceXAI's November 2025 fast agent model with separate reasoning and non-reasoning variants and a **two-million-token context window**. Its Agent Tools API integrates web and X search. SpaceXAI reports **63.9 Research-Eval**, **87.6 FRAMES**, and **56.3 X Browse**, with substantially lower task costs than compared models.

Source: [Grok 4.1 Fast and Agent Tools API](https://x.ai/news/grok-4-1-fast)

## Cost and limitations

Pricing is **$0.20 input, $0.05 cached input, and $0.50 output per million tokens**; server tools start at $5 per thousand successful calls. It prioritizes speed, search, and cost over frontier coding depth, and image/multimodal evidence is less extensive than newer Grok models.

## Scores

- **Tool use: 93/100.** Native web/X search and strong research-agent results are central strengths.
- **Reasoning: 82/100.** Reasoning mode is capable but optimized below flagship depth.
- **Context window: 99/100.** Two million tokens is exceptional.
- **Multimodal: 78/100.** Its public evidence focuses primarily on text and search workflows.
- **Coding: 82/100.** Useful for agentic coding, but not positioned as a top coding specialist.
- **Cost efficiency: 99/100.** Extremely low token rates deliver outstanding value.
- **Overall Score: 87/100.** Half-up rounded mean: (93 + 82 + 99 + 78 + 82) / 5 = 86.8.

## Bottom line

Grok 4.1 Fast is an exceptional low-cost choice for long-context search agents, less so for the hardest coding or multimodal tasks.
