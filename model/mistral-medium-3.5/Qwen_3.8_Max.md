> **Verdict:** Mistral Medium 3.5 is **Mistral AI's dense 128B open-weight flagship** (released **2026-04-29**), a **reasoning** model with a **256K context**, **text + image → text** I/O, published under the **Modified MIT** license (weights on Hugging Face, self-hostable on ~4 GPUs). Its positioning is **"Medium is the new large"**: a merged dense checkpoint that **supersedes all of Mistral's previous coding models (namely Devstral)**. Mistral published **only two launch numbers** — **SWE-bench Verified 77.6 %** and **τ³-Telecom agentic tool use 91.4 %** — and third parties add **GitBench (GitKraken) 97.6 % (high) / 95.1 % (medium)** across 204 fixtures. **Independent measurement is thin:** **Artificial Analysis has NOT scored it on the current v5.0 Intelligence Index (N/A — only 29 of 718 models are on v5.0, and the page reads "No publicly available API" on every eval chart)**, and the one independent coding figure — **Vals SWE-bench Verified 66.4 %** — sits **11 points below the vendor's 77.6 %**, so the curated meta itself calls its coding "clearly mid-pack." What AA *does* confirm is **efficiency**: **156.4 tok/s (#9/26 open-weight Medium class, above the 111.6 median)**, TTFT 2.26 s. Catches: the hosted API is **expensive ($1.50/$7.50, ~5×/9× the $0.30/$0.80 medians)** with no free tier, the context figure is **inconsistently reported (256K table vs 260K FAQ vs 262K meta)**, the **merge lineage** makes behavior harder to reason about than a trained-clean checkpoint, and there is **no published reasoning benchmark at all** (no AIME/GPQA/MMLU, no current AA Index). Net: **Overall 77 (divergence +2.1 vs the curated 74.9)** — a fast, open, image-capable European dense workhorse whose vendor coding headline is strong but whose independent verification is mid-pack and whose reasoning is unmeasured; I land slightly above the curator because the open-weight freedom + #9/26 speed + τ³-Telecom 91.4 % agentic strength outweigh the expensive API.

## Model card

- **Name:** Mistral Medium 3.5 — vendor **Mistral AI**; the **Medium** (dense 128B) tier, successor to **Mistral Medium 3** (May 2025) and the model that **supersedes Devstral** (Mistral's prior coding line). Distinct from **Mistral Large 4**, **Mistral Small**, and the **Magistral** reasoning family.
- **Short description:** "The European dense workhorse" — a merged dense 128B open-weight model for instruction-following, coding agents and **telecom agents** (τ³-Telecom 91.4 %), pitched as frontier-adjacent capability at an order-of-magnitude lower deployment cost.
- **Provider / access:** **Mistral La Plateforme API** (+ 1 other provider per AA — "available through 2 API providers"). **$1.50 / $7.50** per 1M in/out (**$0.15** cached input, **90 % cache discount**); **Batch $0.75 / $3.75**; **self-host free** under **Modified MIT** (Hugging Face weights). **Not on OpenCode Zen** (`noFreeId`).
- **Release / knowledge:** **2026-04-29** (AA FAQ "released on April 29, 2026"; AA header "Released April 2026"; model-card version `26-04`). **Current.**
- **IDs:** `mistralai/mistral-medium-3-5`; AA `mistral-medium-3-5`; official `huggingface.co/mistralai/Mistral-Medium-3.5-128B`; model card `docs.mistral.ai/models/model-cards/mistral-medium-3-5-26-04`.
- **Context window:** **256K** (AA technical-specs table + comparison summary "256k"). **⚠ Inconsistently reported:** AA's own FAQ says **260k**, the curated meta's `contextWindow` field says **256,000 (256K)** but its `short`/`standout` say **262K**. I resolve to **256K** (the authoritative AA spec table) and flag the 256/260/262 spread.
- **Modalities:** **text + image in → text out** (AA-confirmed: "supports text and image input, outputs text"; "is multimodal"). **Image-only — no video, no audio, text-only output.**
- **Pricing:** **$1.50 / $7.50** per 1M in/out — **AA flags both as "expensive"** (input median $0.30, output median $0.80); blended (7:2:1) **$1.16**/1M. 90 % cache discount, Batch half-price. Open-weight self-hosting is free.
- **Architecture:** **Dense 128B** (AA: total = active, "dense models use all parameters"), **open-weight**, **Modified MIT** (commercial use allowed with restrictions), a **merged** checkpoint (meta tradeoff: "the merge lineage makes behavior harder to reason about than a trained-clean checkpoint"). **Reasoning** (AA: "uses extended thinking … a non-reasoning variant may also exist"). **Speed 156.4 tok/s** (#9/26, 3/4 units, above the 111.6 open-weight-Medium median); **TTFT 2.26 s**.

### Normalized scores (1–100)

- **Tool use: 77/100.** Strong **vendor** agentic signal — **τ³-Telecom 91.4 %** (telecom tool-use / function-calling) — plus a strong **third-party** GitBench 97.6 % (high) / 95.1 % (medium) agentic-PR result, and it "supersedes Devstral." Held below the independently-verified agentic leaders because **AA has no agentic Index for it on v5.0** (N/A) and the one independent coding harness (Vals 66.4 %) is mid-pack — so the tool-use strength is vendor/third-party-leaning, not AA-confirmed.
- **Reasoning: 74/100.** It **is** a reasoning model (AA: extended thinking; a non-reasoning variant may exist), but there is **no published reasoning benchmark of any kind** — **no AIME, no GPQA, no MMLU**, and the **AA Intelligence Index is N/A on the current v5.0 basket** (the model is not among the 29 of 718 scored). Reasoning-capable but **unmeasured**; I cannot credit a frontier reasoning score without a single verified number, and I refuse to reattribute the unverifiable pre-v5.0 Index.
- **Context window: 78/100.** **256K** native (AA spec table), a solid mid-large window — but well short of the 1M frontier norm (DeepSeek V4-Flash, which it ties on coding, has 1M), and **no independent RULER/MRCR @256K long-context retrieval figure** is published, so it sits at the standard 256K tier with no long-context bonus.
- **Multimodal: 78/100.** **Text + image input → text output** (AA-confirmed multimodal, can "analyze, describe, and answer questions about images") — the verified **image-only** tier. **No video, no audio, text-only output**, so no bump above image-capable.
- **Coding: 76/100.** The **vendor SWE-bench Verified 77.6 %** is strong (ties DeepSeek V4-Flash's 78.4 %, "same conversation as larger closed flagships") and **GitBench 97.6 %** is a strong third-party result — **but the independent Vals SWE-bench Verified is only 66.4 %** (11 points lower), and the curated meta itself calls coding "clearly mid-pack." The wide vendor-vs-independent gap and the merge-lineage caveat keep this at strong-published-but-independently-mid rather than elite.
- **Cost efficiency: 80/100.** *(Not counted in Overall.)* Mixed-to-good: **open-weight (free self-host under Modified MIT, ~4 GPUs)**, **fast (156.4 tok/s, #9/26)**, **90 % cache discount** and **half-price Batch** are real advantages — but the **hosted API is expensive ($1.50/$7.50, ~5×/9× the $0.30/$0.80 medians)** with **no free tier** (`noFreeId`, not on Zen). The open-weight freedom + speed offset the pricey API, landing mid-to-good rather than elite.
- **Overall Score: 77/100.** Half-up mean of the five quality dims: (77 + 74 + 78 + 78 + 76) / 5 = 383 / 5 = **76.6 → 77**. **Divergence +2.1** vs the curated 74.9. Mistral Medium 3.5 is a **fast, open-weight, image-capable European dense 128B workhorse** — vendor SWE-bench Verified 77.6 % + τ³-Telecom 91.4 %, third-party GitBench 97.6 %, #9/26 speed, Modified MIT — whose weaknesses are an **unmeasured reasoning profile (AA Index N/A on v5.0, no AIME/GPQA)**, an **independently mid-pack coding result (Vals 66.4 %)**, an **expensive hosted API**, a **256K** (not 1M) context and an **internally inconsistent context figure**. My **+2.1** above the curator reflects that the open-weight freedom, #9/26 efficiency and strong vendor/third-party agentic-coding signals are worth slightly more than the curated 74.9 credits, even after discounting the thin independent verification.
