## Model card

- **Name:** Mistral Medium 3.5 (also `mistral-medium-3-5`, `Mistral-Medium-3.5-128B`)
- **Short description:** Mistral AI's first flagship "merged" dense model (128B total, dense, 256K context), released 2026-04-28 (official card) / 2026-04-30 (listing). It unifies previous specialist families (Medium 3.1 for chat, Magistral for reasoning, Devstral 2 for coding) into a single dense 128B weight set. Supports text + image input, configurable reasoning effort (`none` / `high`), native function calling, JSON output, vision encoder trained from scratch for variable image sizes/aspect ratios. Released under Modified MIT license (open weights, commercial/non-commercial with revenue exceptions). Note: official docs (`https://docs.mistral.ai/models/model-cards/mistral-medium-3-5-26-04`) list the model as **deprecated** (deprecation date 2026-10-31; replacement: Mistral Large 4) — a critical status conflict.
- **Provider / access:** Mistral AI API (`mistral/mistral-medium-3-5`); hosted via OpenRouter (`mistralai/mistral-medium-3-5`), Azure AI Foundry (`azure_ai/mistral-medium-3-5`), NVIDIA NIM (`mistralai/mistral-medium-3-5-128b`); self-hostable on 4 GPUs (`https://docs.mistral.ai/models/model-cards/mistral-medium-3-5-26-04`). Chat Completions / OpenAI-compatible endpoint supported.
- **Release / knowledge:** Released 2026-04-28 (official blog/card) / 2026-04-30 (OpenRouter). No explicit knowledge cutoff stated; closest behavior suggests training through early 2026.
- **IDs:** `mistral-medium-3-5` (official API); `mistralai/Mistral-Medium-3.5-128B` (Hugging Face weights); `mistralai/mistral-medium-3-5` (OpenRouter); `mistral-medium-3-5-128b` (NVIDIA NIM). No dedicated free tier.
- **Context window:** **256K native** (official card); independent endpoint listings confirm **262,144 tokens** (`https://openrouter.ai/mistralai/mistral-medium-3-5`, `https://docs.api.nvidia.com/nim/reference/mistralai-mistral-medium-3-5-128b`, `https://artificialanalysis.ai/models/mistral-medium-3-5`). Azure AI Foundry endpoint lists **128K** (`https://ai.azure.com/catalog/models/mistral-medium-3-5`) — an endpoint-specific cap, not a model limitation. No 1M extension claim (unlike Qwen3.5-Flash or Gemini 3.5 Flash-Lite); the 256K cap is fixed.
- **Modalities:** Input: text, image. Output: text. Reasoning: yes (configurable `reasoning_effort`: `none` / `high`). Tool calls: yes (native function calling). Structured outputs / JSON: yes (`https://docs.mistral.ai/models/model-cards/mistral-medium-3-5-26-04`). System prompt: strong adherence (vendor claim). Multilingual: 40+ languages (official docs list English, French, Spanish, German, Italian, Portuguese, Dutch, Chinese, Japanese, Korean, Arabic, plus many others). Audio / video input: not supported per official specs (`https://docs.mistral.ai/models/model-cards/mistral-medium-3-5-26-04` lists only text + image input; `https://openrouter.ai/mistralai/mistral-medium-3-5` confirms same). Image generation / video / speech: not supported.
- **Pricing (as of 2026-11-04):** $1.50/M input, $7.50/M output (`https://docs.mistral.ai/inference/pricing`, `https://openrouter.ai/mistralai/mistral-medium-3-5`, `https://models.litellm.ai/models/mistral-medium-3-5`). Cache read: $0.15/M (`https://docs.mistral.ai/inference/pricing`, `https://openrouter.ai/mistralai/mistral-medium-3-5`). No tiered pricing by input length; flat rate regardless of context length (no >128K tier unlike Qwen3.5-Flash). No promotional pricing; no volume discounts listed. Independent directory (`https://dvarahq.com/models/mistral/mistral-medium-2604`) confirms same rates as of Oct 26, 2026.
- **Architecture:** Dense transformer (not MoE). 128B total parameters (dense). Vision encoder: custom ViT (trained from scratch, supports variable image sizes and aspect ratios, RoPE-2D rotary position encoding). Context: 256K tokens native (`https://docs.mistral.ai/models/model-cards/mistral-medium-3-5-26-04`). License: Modified MIT (`https://huggingface.co/mistralai/Mistral-Medium-3.5-128B`). No open-source parameter count breakdown beyond 128B dense; no hidden dimension / layer count / vocabulary details published by vendor.

### Conflicting / contradictory evidence (explicit comparison)

1. **Agentic performance: vendor claims vs. independent harness scores.** Vendor blog (`https://mistral.ai/news/vibe-remote-agents-mistral-medium-3-5/`) and card (`https://docs.mistral.ai/models/model-cards/mistral-medium-3-5-26-04`) claim very strong agentic results: **τ³-Telecom 91.4**, **SWE-bench Verified 77.6%**, best-in-class agentic capabilities with native function calling and JSON output. Independent Artificial Analysis (`https://artificialanalysis.ai/models/mistral-medium-3-5`) reports very different profile: **Agentic Index 7.0** (low), **Terminal-Bench 4.0 0.0%** (`https://benchmarklist.com/models/mistralai-mistral-medium-3-5/`), **AutomationBench-AA 6.3%** (`https://benchmarklist.com/models/mistralai-mistral-medium-3-5/`), **GDPval-AA 13.4%** (independent). Independent BenchmarkList (`https://benchmarklist.com/models/mistralai-mistral-medium-3-5/`) confirms weak standardized agentic scores: **AA-Briefcase Elo 523** (35th percentile, rank 104/160 — below median), **Terminal-Bench 2.0 30.3%** (31st percentile), **Agentic category scores generally low** (Tau3-Banking 15.1%, GDPval-AA 936 Elo — 64th percentile, moderate). Independent review (`https://awesomeagents.ai/reviews/review-mistral-medium-3-5/`) supports vendor-aligned agentic claim (`https://awesomeagents.ai/reviews/review-mistral-medium-3-5/`): notes Intelligence Index 30 (vendor-aligned evaluation), strong agentic coding (4.2/5), and strong agentic tool use (τ³-Telecom 91.4). The discrepancy is significant and likely reflects harness/protocol differences: vendor agentic benchmarks (τ³-Telecom, SWE-bench Verified) use specific agent scaffolds (Vibe CLI, Claude Code-style harnesses) optimized for the model, while Artificial Analysis uses a standardized agentic evaluation suite (AA-Briefcase, AutomationBench-AA, Terminal-Bench 4.0) that tests different agentic capabilities (knowledge work, SaaS automation, terminal workflows). No contradiction in raw capability — the model performs well on vendor-aligned harnesses but poorly on independent standardized agentic benchmarks. This is a critical conflict for dataset users who rely on standardized agentic evaluation.

2. **Coding benchmarks: vendor claim vs. independent estimates.** Vendor reports **SWE-bench Verified 77.6%** (`https://mistral.ai/news/vibe-remote-agents-mistral-medium-3-5/`), which is the most-cited agentic-coding benchmark. Independent BenchmarkList (`https://benchmarklist.com/models/mistralai-mistral-medium-3-5/`) reports lower measured estimates: **SWE-bench Verified 66.4%** (independent measured, lower than vendor 77.6%), **LiveCodeBench 79.6%** (independent estimated, close to vendor-aligned expectations for a model of this class), **Terminal-Bench 2.0 30.3%** (independent measured — weak), **SciCode 40.2%** (independent measured — moderate), **Vibe Code Bench v1.1 2.9%** (independent measured — extremely weak). Independent CrucibleMark (`https://www.cruciblemark.com/reports/mistral-medium-3-5/`) reports different profile: **Code Quality 74.76** (high — close to best 88.9), **CLI Benchmark 90.67** (good — close to best 97.7), **Logical Reasoning 69.57** (moderate), but lower scores on other dimensions. Independent review (`https://pub.towardsai.net/i-tested-mistral-medium-3-5-on-18-tasks-the-128b-just-killed-magistral-and-devstral-647da623f41b`) confirms vendor-aligned coding results: the model scores very well on algorithmic/system design tasks (Bucket A 11/12, Bucket B 10/12, Bucket C 11/12 — 32/36 total) and outperforms previous Mistral specialist models (Magistral 24/36, Devstral 2 26/36) by 6–8 points. It also notes SWE-bench Verified 77.6% is 5.4 points above Devstral 2 (72.2%). The conflict reflects different evaluation harnesses: SWE-bench Verified / vendor-aligned harnesses show strong results, while independent BenchmarkList / Vals AI / independent agentic harnesses show weaker results (SWE-bench 66.4% measured, Vibe Code Bench 2.9%, Terminal-Bench 2.0 30.3%, SciCode 40.2%). The CrucibleMark profile (high Code Quality / CLI Benchmark) aligns more closely with vendor-aligned results than with BenchmarkList's weaker agentic/coding estimates. The safest interpretation: coding performance is strong on vendor-aligned harnesses and for structured algorithmic/system tasks, but weaker on independent standardized agentic/coding benchmarks that emphasize full-stack web development (Vibe Code Bench 2.9%), multi-step terminal workflows (Terminal-Bench 2.0 30.3%), and scientific programming (SciCode 40.2%).

3. **Multimodal / vision performance.** Vendor claims native vision (text + image input, custom vision encoder trained from scratch, variable image sizes, aspect ratios). Official specs confirm input modalities: text, image (`https://docs.mistral.ai/models/model-cards/mistral-medium-3-5-26-04`, `https://huggingface.co/mistralai/Mistral-Medium-3.5-128B`). Independent Artificial Analysis (`https://artificialanalysis.ai/models/mistral-medium-3-5`) reports **MMMU-Pro 66.3%** (independent measured) / 76.6% (independent estimated, high confidence) — moderate-to-good; **MMMU 76.6%** (independent estimated) — good; **AI2D_TEST 88.0%** (independent estimated) — very good; **RealWorldQA 76.0%** (independent estimated) — good. Independent review (`https://awesomeagents.ai/reviews/review-mistral-medium-3-5/`) does not explicitly evaluate vision benchmarks but notes the model supports vision input (as per specs). Independent NVIDIA NIM reference (`https://docs.api.nvidia.com/nim/reference/mistralai-mistral-medium-3-5-128b`) confirms vision input capabilities. No significant numerical conflict — vision benchmarks are consistent with vendor-aligned claims for a dense 128B vision-language model, though MMMU-Pro 66.3% is not at the frontier (below Claude Opus 5.5 87.7%, Qwen3.5-122B-A10B 76.9%).

4. **Context length: official claim vs. endpoint-specific limits.** Official specs state **256K** (`https://docs.mistral.ai/models/model-cards/mistral-medium-3-5-26-04`). Independent endpoint listings show **262,144 tokens** (`https://openrouter.ai/mistralai/mistral-medium-3-5`, `https://docs.api.nvidia.com/nim/reference/mistralai-mistral-medium-3-5-128b`). Some sources (Azure AI Foundry `https://ai.azure.com/catalog/models/mistral-medium-3-5`) list **128K**. The discrepancy is endpoint-specific, not a model capability conflict. Independent AA-LCR (`https://benchmarklist.com/models/mistralai-mistral-medium-3-5/`) reports 69.3% (independent measured) / 69.7% (independent estimated) — moderate-to-good for long-context reasoning. No independent verification of full 256K retrieval (RULER / MRCR / GraphWalks) specifically for this SKU in the sources read; closest reference is AA-LCR 69.3% (moderate). The 256K context is verified by official specs and multiple endpoint listings, but long-context retrieval performance at the very upper limit is not independently confirmed by dedicated retrieval benchmarks.

5. **Status / deprecation: official docs vs. independent listings.** Official Mistral docs (`https://docs.mistral.ai/models/model-cards/mistral-medium-3-5-26-04`) list the model status as **Deprecated** (deprecation date: 2026-10-31; replacement: Mistral Large 4). Independent listings (OpenRouter, NVIDIA NIM, BenchmarkList, Benchmark Atlas, Hugging Face) continue to show the model as available/released without deprecation warnings. Independent review (`https://awesomeagents.ai/reviews/review-mistral-medium-3-5/`) discusses it as a current/recent model (published 2026-06-17, before deprecation date). This is a significant identity/status conflict: the model was released in April 2026 and deprecated just ~6 months later (Oct 2026). Dataset users should note that this model is deprecated per official Mistral documentation, even though it remains accessible via API and open weights. The replacement (`mistral-large-4`) is listed in `model-aliases.generated.md`? No — but it exists in `model/` (`mistral-large-4/` has `Inkling.md` from previous runs). This deprecation note is critical for any dataset or comparison report that relies on current model availability.
