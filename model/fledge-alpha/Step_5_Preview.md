## Model card

- **Name:** Fledge Alpha — a **deliberately undocumented free stealth preview** that appeared on OpenCode Zen on **2026-10-01** and has **already been deprecated/delisted**. **A negative finding governs this report: BenchLM carries no `fledge-alpha` page in any spelling** (it 404s), so the 2026-11-06 re-research had no catalog to check against.
- **Short description:** **No lab has claimed it.** The models.dev entry (`opencode/fledge-alpha-free`) was added by the opencode-agent bot, the catalog describes only *"a free-tier preview reasoning model with text and image input and tool use"*, and the community's leading hypothesis (stealthmodels.com) is that it is a **router** rather than a single model — based on **inconsistent input-token counts for identical prompts (7,536 / 7,536 / 6,499)** and uneven output quality. Early community guesses (a DeepSeek V4.x build, Thinking Machines' Inkling) are **unconfirmed rumours**. Despite the thin documentation it briefly ran hot: **#7 by tokens on OpenCode's weekly ranking (2.2T tokens, 32K unique users, 974K completed sessions, 92.6% cache-hit ratio, $0 total spend)**.
- **Provider / access:** **Was OpenCode Zen free tier only ($0/$0)**; never listed on OpenRouter; closed weights. **Deprecated within days** — re-confirmed on the prior pass: the models.dev entry still exists with `status: deprecated`, and the route is absent from the live Zen models endpoint.
- **Release / knowledge:** **2026-10-01; deprecated within days.** **Knowledge cutoff not disclosed** — and structurally undisclosable if the router hypothesis is correct.
- **IDs:** `opencode/fledge-alpha-free` (models.dev catalog ID); `fledge-alpha` / `fledge-alpha-free` (Zen route, both dead).
- **Context window:** **1,048,576 tokens (1M); max output 131,072 tokens** — input, output and reasoning tokens share the context budget.
- **Modalities:** **text and image in; text out**; reasoning with `reasoning_effort` low/high/max; tool calling.
- **Pricing (as of 2026-11-06):** **was free ($0/$0); deprecated.** The route is dead, so the rate card describes a host that no longer serves the model.
- **Architecture:** **unverified.** The tokenizer/route inconsistency suggests a router over multiple backends; no architecture document exists.
