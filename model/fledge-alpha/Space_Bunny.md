## Model card

- **Name:** Fledge Alpha (listed as *Fledge Alpha Free* on OpenCode Zen)
- **Short description:** **A retired preview.** An anonymous, free OpenCode Zen model added to the catalogue on 2026-10-01 and withdrawn roughly a week later; OpenCode's own changelog now calls it "the retired Fledge Alpha Free listing". It was widely treated as a **multi-model routing gateway** rather than a single set of weights. Its entire published life on Zen was **7 days on Zen (2026-10-01 → 2026-10-08)** — or 12 days by the catalogue-to-telemetry reckoning — and **no working public endpoint has been verified since**. Retained here as a historical tracking record and as a data point on OpenCode's free-preview rotation.
- **Provider / access:** **None.** Was `opencode/fledge-alpha-free` on OpenCode Zen (Chat Completions) and `stealth/fledge-alpha` on anyrouter. **Access timeline, all primary or first-hand:** 2026-10-01 added to the Zen catalogue (models.dev PR #8566, merged); 2026-10-08 the Zen docs removal PR is opened and merged the same day (`anomalyco/opencode` PR #53984, `dc85`, removing the endpoint row, pricing row, free-model note and privacy note); 2026-10-08 OpenCode Go's free-model tracker logs "Fledge Alpha Free was available for 5 days (since 2026-10-03)" and adds Step 5 Preview Free as its replacement; 2026-10-09 OpenCode's daily telemetry drops to zero tokens and zero sessions, and a third-party proxy probe at 16:27 UTC that day gets `ModelError: "Model fledge-alpha-free is …"` back; 2026-10-13 a first-hand check of `opencode.ai/zen/v1/models` finds the ID gone; 2026-10-16 **OpenCode changelog v2.0.32: "removed the retired Fledge Alpha Free listing."** Stealthmodels recorded the same conclusion on 2026-10-11 and states no replacement endpoint was verified.
- **Release / knowledge:** Catalogue addition 2026-10-01 (models.dev commit / PR #8566); **withdrawn 2026-10-08**. Identity and knowledge cutoff never disclosed. **Expiry conflict recorded:** a forensic probe report from 2026-10-03 captured a banner reading `"Going away October 5, 2026"`, while OpenCode Go's own tracker dates the availability window as "since 2026-10-03 … available for 5 days" and the docs removal merged on 2026-10-08. Three plausible end dates, one day apart in each direction; the **2026-10-08** official removal is preferred because it has a merged PR and a vendor changelog behind it.
- **IDs:** `opencode/fledge-alpha-free` (Zen, $0 preview — **retired**); `stealth/fledge-alpha` (anyrouter, $0 — never verified as independently reachable). A Free ID did exist, so no paid Zen ID was ever required; there is now no ID at all.
- **Context window:** **1,048,576 tokens total with 131,072 max output**, as originally catalogued. *Provenance is better than the first pass credited and the status is worse.* The models.dev PR that added it states the figures came from the **operator-provided served `/models` response** — i.e. a real API response from the operator, not a guess. **However, the catalogue row that carried these numbers has now been withdrawn**, OpenCode's own usage page lists the model's context and output as *Unknown*, and no vendor ever certified them. Treat 1M as **operator-asserted at the time and no longer verifiable**. No MRCR / RULER / GraphWalks measurement existed at any length.
- **Modalities:** text and image in; text out; tool calling (function calling); reasoning with selectable effort (low / high / max). **Correction this pass:** the first pass reported the three effort tiers as established. The models.dev PR shows they were **not**. Its own author raised an open question before merge — "the served `/models` response lists reasoning as supported, but does not list `reasoning_effort` among its supported sampling parameters" — and an automated review flagged the effort set as supported "only by 'operator-provided serving spec' via Slack, with no provider pricing/docs/API reference", noting the `reasoning_effort` wire comment was removed in the second patch and that Zen does not document reasoning-field passthrough. **The low/high/max tiers were never wire-confirmed.** Reasoning *supported* is still catalogued; the effort presets are unverified.
- **Pricing (as of 2026-10-17):** **None — the free preview has ended.** It was $0 input / $0 output on the Zen preview route and on anyrouter while it existed, and the Zen docs described it as available "for a limited time". That limit has now expired with a documented end date. **There is no list price, no successor price and no reachable route**, which is a materially different thing from the "$0.00 means unpriced" trap the MiniMax entry guards against: there a price exists but is unpublished, here there was a real $0 and it is gone.
- **Architecture:** Proprietary service, weights never released. The routing hypothesis is now **much better evidenced than in the first pass.** Stealthmodels' repeated tokenizer probes returned 7,536 / 7,536 / 6,499 input tokens for the same prompt. A separate ~130-probe forensic report (instax-dutta, 2026-10-03, `opencode run --pure --format json`) captured two verbatim identity leaks in the model's own output — **"I'm Kimi, developed by Moonshot AI; in this deployment I'm running as opencode/fledge-alpha-free"** and the Chinese equivalent **"我是 Kimi，由月之暗面（Moonshot AI）开发和训练"** — plus a token-count cluster analysis anchoring a Kimi-class backend and a "cutoff ~Jan 2026" behaviour, alongside a claimed DeepSeek V4.1-Flash anchor. Treat all of it as **strong circumstantial evidence, still unconfirmed**, and note it is now doubly unverifiable because the endpoint is dead. Fledge also sits inside a documented family of Chinese-lab "Alpha" stealth entries on OpenCode (Hunter Alpha → Xiaomi MiMo-V2.5; Ox Alpha → GLM-5.3-Flash, a ~6-day free window; Union Alpha → Unbiased Pareto; Space Bunny Alpha → still unclaimed).

Throughput / adoption (measured, not quality):

- **Adoption telemetry — three sources, three different numbers, unresolved.** The first pass cited OpenCode's data page at rank #15 with 451B tokens, 7.7K unique users and 240,992 completed sessions. All three are recorded; **none is used in scoring**, and the likely explanation — different snapshot windows and different definitions of "tokens" (total vs non-cached vs attributed) — cannot be verified now that the model is delisted.
- Adoption velocity: 1 → 1,818 users in two days (@MikelEcheve, promptblueprints.tech)
- **End of life:** OpenCode's daily telemetry fell to **zero tokens and zero sessions on 2026-10-09**, and the route has been unavailable ever since.

### Normalized scores (1–100)

> Derived from the raw numbers above using `model-comparison.md` (v4). Overall = half-up
> mean of the five quality dims; Cost efficiency is scored but never counted.
>
> **All five quality dimensions are held unchanged from the first pass.** The model was
> withdrawn on 2026-10-08 without ever being benchmarked by a standard harness, so this
> pass adds evidence about its *lifecycle*, not about its *capability*. The quality
> scores below are retained as the best available reading of a model that **no longer
> exists**, and the Overall is now a historical artifact rather than a live
> recommendation. Only Cost efficiency moves, because only Cost efficiency has been
> falsified.

- **Tool use: 45/100.** *(unchanged — no new capability evidence, and none obtainable.)* Tool calling was declared in the catalogue and the only agentic evidence is one user-run probe passing 61/61 executable-code checks (best of a three-way comparison). Capped far below the mid band (TB2.1 45–60%) because Terminal-Bench, Tau3 and GDPval are all absent, and the routing fingerprint (same prompt → 7,536/6,499 tokens) implies non-reproducible behaviour between calls. **What this pass adds is not a score change but a permanent one:** with the endpoint withdrawn, this dimension can never be re-anchored to a harness row. It will stay at 45 forever unless an independent archive of the route resurfaces.
- **Reasoning: 45/100.** *(unchanged — and one caveat hardened.)* Best available evidence is 6/6 math and 4/4 logic spot checks from a single un-pinned-effort probe; no GPQA, HLE, MRCR, LCR, CritPt or Intelligence Index figure exists. Scored below the methodology's mid band (GPQA 60–80% / Index 20–35 → 55–65) because nothing comparable to those was measured, and observers report the route "often rushes to a simple answer". **What this pass adds:** the effort-tiers claim that the probe could not be pinned to is now known to have been **never wire-confirmed at all** — models.dev PR #8566 records that the served `/models` response did not list `reasoning_effort` among supported sampling parameters, and a follow-up fix commit was needed. So the probe's un-pinned effort is not a testing lapse; the route may never have exposed a working effort control at all. The score stays at 45 and the reasoning behind it gets worse, not better.
- **Context window: 95/100.** *(unchanged — the documented figure is now dead but was genuinely operator-asserted.)* 1,048,576 total (models.dev, sourced from the operator's served `/models` response) placed it in the ≥1M = 95–100 tier on the first pass. **What this pass changes is the status of the evidence, not its direction.** The catalogue row has been withdrawn, OpenCode's own usage page lists context and output as *Unknown*, and the 131,072 output limit was asserted by the operator and never independently confirmed. The methodology's Context tier scores the **documented window**, not reachability, so a figure the operator itself served is not retroactively invalidated by the operator's later delisting — but it can no longer be verified by anyone, and the *Unverified* label is now permanent rather than provisional. Not 100 for the same reason as before: no ≥98% retrieval at 512K+ was ever published, and the single retrieval probe (12/12) topped out around ~250K tokens of real text.
- **Multimodal: 65/100.** *(unchanged.)* Text + image input with text output matches the +image-in = 60–70 band. No video, PDF or audio input and no non-text output, so the 75+ bands do not apply; vision was catalog-declared and never independently benchmarked.
- **Coding: 48/100.** *(unchanged.)* 61/61 on a small executable-code set and a showcase SVG scene show real competence, but there is no SWE-bench, LiveCodeBench, SciCode, DeepSWE or Coding Index number, and the six SVG runs swung "from basic sketches to quite good" with higher effort not consistently helping — which now reads as unsurprising, given the effort presets may never have been functional. Provisional, evidence-thin, and permanently so.
- **Cost efficiency: 25/100.** *(lowered 72 from 97 — the largest single change in this batch.)* The first pass scored 97, three points under a flat $0 = 100, because $0 in / $0 out was confirmed on both the Zen preview route and anyrouter with $0.00 recorded OpenCode spend and a 93% cache ratio, discounted only for the explicitly limited-time nature of the preview and the training-data caveat. **That discount is now the whole story, and it has resolved against the model.** The free preview ended with a documented, verifiable date: withdrawn from the Zen docs on 2026-10-08 (merged PR), logged as "available for 5 days" by OpenCode Go's tracker, unreachable from 2026-10-09, absent from the model list by 2026-10-13, and described by OpenCode itself as "the retired Fledge Alpha Free listing" in the v2.0.32 changelog. **Scoring a dead free offer at 97 would be the single most misleading number in this report** — it would tell a reader that a $0 route exists when nothing does. With **no list price, no successor price and no reachable endpoint**, the methodology's inverse-pricing ladder cannot be applied at all. Placed below the $10/$50 ≈ 30 rung, because unlike an expensive model there is not even an expensive tier to buy: the honest reading is that cost efficiency is now unmeasurable, and 25 is a placeholder for "no current pricing exists" rather than a verdict that the model was expensive.
- **Overall Score: 59.6/100.** Mean of (45 + 45 + 95 + 65 + 48) / 5 = 298/5 = 59.6 → **59.6** *(unchanged)*. The 72-point Cost-efficiency drop does **not** touch this figure, because Cost efficiency is scored but excluded from Overall under the v4 methodology — which is exactly why that exclusion exists. **Best fit: none, as of 2026-10-08.** This Overall is now a historical artifact describing a 7-day free preview that no one can call. Its original use — a zero-cost exploratory route for smoke-testing an agent loop, drafting throwaway scripts, or pulling a key out of a long document — has no live equivalent on this route; OpenCode's replacement in the same slot was Step 5 Preview Free (added 2026-10-08). **The durable lesson from this entry is lifecycle, not capability:** an operator can list a 1M-context multimodal reasoning model, accept traffic for under a week, and withdraw it, and every quality score in this file becomes permanently un-updatable. Do not cite this model as evidence that anonymous free previews are good value; cite it as evidence that they are ephemeral.
