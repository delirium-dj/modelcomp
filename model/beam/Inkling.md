## Model card (updated with verified data)

- **Name:** Beam (Reflection / Reflection AI; open-weight model)
- **Short description:** Reflection's first open-weight 501B-total / 23B-active sparse MoE (Apache 2.0, weights released Oct 16 2026). Built for coding, reasoning, agentic workloads, and long-horizon agentic tasks. 1M context window. Instruction-tuned in BF16, FP8, NVFP4. Released weights with model card (Oct 5 announcement updated Oct 16 with final benchmarks), technical report, open coding harness (Mirror), and developer docs. Independent reviews (Oct 16–19 2026) confirm it is a real US-built open-weight model — second-best US open-weight on AA Intelligence Index (30) — but note significant gaps to leading open models (Kimi K3, DeepSeek V4.1 Flash, GLM 5.3) on coding and agentic benchmarks.
- **Provider / access:** Reflection (`reflection/beam`); weights on Hugging Face (`reflection/Beam-1.0-501B-A23B`); API beta (`platform.reflection.ai` — free to start per official blog); partner endpoints (vLLM, Ollama, AWS, Google Cloud); open-source harness (`Mirror`); dataset identity: `opencode/beam` (meta.json); `beam-free` listed in dataset/pricing docs (`opencode.asia` and `models.dev` show `beam-free` as a free tier — `pricingNote`: free tier available; `noFreeId`: false per meta.json presence and dataset pricing references).
- **Release / knowledge:** Announced 2026-10-05 (`reflection.ai/blog/introducing-beam`); weights and final model card released 2026-10-16 (`reflection.ai/beam-model-card`, updated from Oct 5 table); blog update `reflection.ai/blog/beam-is-available` (2026-10-16) confirms weights out, final benchmarks published, free beta access. Knowledge cutoff: June 30, 2026 (official model card property table).
- **IDs:** `reflection/beam` (vendor/model identity); `opencode/beam` (dataset/meta identity); `reflection/Beam-1.0-501B-A23B` (HF weights ID); `beam` (folder slug in dataset).
- **Context window:** 1,000,000 (1M) tokens total — verified by official model card (`Property | 501B A23B MoE` table: `Context Length | 1M`), meta.json (`model-aliases.generated.md` does not override this; `model-queue.md` confirms `beam` at Overall 73.1 — active model), independent review sources (`buildfastwithai.com`, `shattered.io`, `iraluca.com` all confirm 1M context).
