> **Verdict:** Beam 1.0 is **Reflection AI's first open-weight model** (the reveal of the stealth label **"Cat Jam"**) — a **501.3B-total / 23.4B-active sparse MoE (Apache 2.0, 1M context, TEXT-ONLY)** announced 2026-10-05 with weights published **2026-10-16 (current)**. Reflection pitches it as an **efficiency** play, not a raw-capability leader: its own blog concedes "*frontier open models like Kimi K3 remain ahead on raw capability; Beam's advantage is efficiency at inference time*," and that it is "*competitive with… GLM 5.2 and approaching Qwen 3.8-Max*" while using "*3–4× less inference compute*." **Artificial Analysis independently corroborates exactly that framing:** Intelligence Index **18 (below the open-weight-Large median of 23)**, but **Speed 344.9 tok/s (#3/78)**, **Verbosity 54M tokens/task (#1/16 — the most concise model AA tracks, median 99M)**, and **$0.28/Index-task** — AA's one-line verdict: "*below average in intelligence, but reasonably priced… notably fast and highly concise.*" Its headline coding numbers (**SWE-bench Verified 81.6%, ~#8/107 on the public leaderboard; Terminal-Bench 2.1 80.1%; LiveCodeBench 88.3%**) are strong but **vendor-self-reported** (Vals has no entry yet; the weights are ~12 days old). Net: a fast, cheap, concisely-reasoning open-weight coder whose **independent broad-intelligence signal sits below median**, so I land it at **Overall 74 (divergence +1.4 vs the curated 72.6)** — the text-only Multimodal floor (50) and the below-median AA Index hold it under its glossy vendor coding table.

## Model card

- **Name:** Beam 1.0 (vendor: **Reflection AI**; former stealth codename **"Cat Jam"** — meta aliases include `cat-jam`, `stealth/cat-jam`). Reflection's **first open-weight** release.
- **Short description:** Open-weight **sparse-MoE coding/reasoning/agentic** model. Reflection's blog: "*501 billion total parameters, 23 billion active, built for coding, reasoning, and agentic workloads*," pretrained on **23.8T tokens** then a **>100M-rollout high-compute RL** campaign (10.5K NVIDIA GB300 GPUs, 4 weeks, ~1.3B sandboxes, ~1M curated environments). A controllable **reasoning-effort** parameter (trained with a length penalty) trades token budget against capability.
- **Provider / access:** Open weights on **Hugging Face `reflection/Beam-1.0-501B-A23B`** (Apache 2.0; BF16/FP8/NVFP4 checkpoints + a speculative-decoding drafter); **free OpenCode Zen slot** `beam-free` (30-day-retention host, **not** zero-retention); **free Reflection API public beta** (daily caps, reset 12:00 AM PT); hosted via OpenRouter/`reflection/beam-1.0-501b-a23b` and 40+ partners (vLLM, SGLang, Unsloth, Axolotl, NVIDIA Dynamo); Reflection's **Mirror CLI** coding agent.
- **Release / knowledge:** Announced **2026-10-05**, weights **2026-10-16** (current, actively served). **Knowledge cutoff 2026-06-30.**
- **IDs:** `opencode/beam-free` (Zen) · `reflection/Beam-1.0-501B-A23B` (HF) · `reflection/beam-1.0-501b-a23b` (OpenRouter) · AA slug `reflection-beam`.
- **Context window:** **1,048,576 (1M) total / 131,072 (128K) max output.** Verified: the widely-quoted **256K** figure is Reflection's **RL-rollout** max context, *not* the inference window (datastudios: "*the 256K maximum RL rollout context and 1M supported inference context… are not contradictory*"). Meta flags this correctly.
- **Modalities:** **Text in / text out only.** Explicitly **not** multimodal — datastudios: "*Beam is text-only: its million-token context should not be confused with native image, audio or video understanding*"; the blog adds it "*can work with information from other modalities when represented as text*." AA technical specs confirm "Supports: text" for both input and output.
- **Pricing:** **Free** on Zen + Reflection beta; **self-host $0** (Apache 2.0); hosted **$0.25–$1.30 / $1.00–$4.30 per 1M in/out** across providers (**AA uses $0.40 in / $1.20 out, 90% cache discount → $0.28 per Intelligence-Index task**).
- **Architecture:** Sparse MoE — **501.3B total / 23.4B active (4.67%, 21.4:1)**, **52 layers (3 dense + 49 MoE), 256 routed experts**, vocab ~152K, **gated GQA + sliding-window attention**, interleaved local/global attention, SandwichNorm, aux-loss-free load balancing, FP32 residual accumulation. Weight storage ≈ **1003 GB BF16 / 501 GB FP8 / 251 GB NVFP4** (not a local model).

### Normalized scores (1–100)

- **Tool use: 78/100.** Solid mid-pack agentic — MCP Atlas 80.8%, BrowseComp 76.8%, DeepSearchQA 80.5%, AutomationBench 39.3% (above GLM 5.2's 26.2, below GLM 5.3/Kimi K3/DeepSeek), tau3-banking a weak 36.1%. AA's agentic-weighted Index (18, below median) caps this: capable with tools, not a leader.
- **Reasoning: 77/100.** Strong vendor math/science (AIME 97.7%, GPQA 90.6%, LiveCodeBench 88.3%), but the **independent AA Intelligence Index is 18 — below the median 23** — and Reflection's own table puts Beam under GLM 5.2/GLM 5.3/Kimi K3 on HLE, GPQA and AIME. Explicitly efficiency-focused ("*Kimi K3 remain ahead on raw capability*"), so broad reasoning is middling despite elite math.
- **Context window: 85/100.** A well-architected **1M** window (sliding-window + gated GQA, long-context midtraining) with a competitive **LongBench v2 66.9** (tops Reflection's table) and AA-LCR 79.3; no independent MRCR/RULER yet, so held just under the proven-1M tier.
- **Multimodal: 50/100.** **Text-only** (explicit; AA confirms text in/out). No native image/audio/video — the floor for a non-multimodal model.
- **Coding: 82/100.** The standout: **SWE-bench Verified 81.6% (~#8/107 leaderboard)**, LiveCodeBench 88.3%, Terminal-Bench 2.1 80.1%, SWE-bench Multilingual 78.3%, Pro v2-Hard 76.5% — a broad, strong, leaderboard-listed profile. Held below 84 by **vendor-only** provenance (no Vals/AA per-eval), Reflection's own table placing it below the frontier on Terminal-Bench, and the below-median AA Index.
- **Cost efficiency: 92/100.** *(Not counted in Overall.)* **Apache 2.0 open weights (self-host $0)** + **free Zen slot** + **free Reflection beta**, hosted from ~$0.40/$1.20 with 90% cache, and best-in-class efficiency (**344.9 tok/s #3/78**, **most concise #1/16**, 3–4× less inference compute) — an exceptional value profile for a 501B model.
- **Overall Score: 74/100.** Half-up mean of the five quality dims: (78 + 77 + 85 + 50 + 82) / 5 = 372 / 5 = **74.4 → 74**. **Divergence +1.4** vs the curated 72.6. Beam is a fast, cheap, concise, strong-coding open-weight MoE, but the **text-only floor (50)** and the **below-median independent AA Intelligence Index (18 vs 23)** keep it from matching its vendor coding gloss; my +1.4 reflects weighting its genuine 1M long-context, #8/107 SWE-bench Verified and elite efficiency slightly above the curated mean.
