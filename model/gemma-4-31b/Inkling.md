## Model card

- **Name:** Gemma 4 31B (official Google DeepMind SKU; dataset label `gemma-4-31b` matches the dense 31B model; also released as `gemma-4-31b-it` instruction-tuned on Hugging Face / NVIDIA NIM)
- **Short description:** Google's flagship dense open-weights model from the Gemma 4 family (released 2026-04-02). 30.7B total parameters, 60 layers, 256K context, native text/image (and video as frame sequences) input, text-only output. Built for reasoning, agentic workflows, coding, and multimodal understanding under Apache 2.0. The 31B dense model is positioned as the top open-weight dense model on Arena AI text leaderboard (Elo 1452 as of April 2026) and is deployable on a single 80GB H100 GPU (unquantized bfloat16) or consumer GPUs with quantization.
- **Provider / access:** Google DeepMind (official model card, `ai.google.dev/gemma`); Hugging Face (`google/gemma-4-31b`, `google/gemma-4-31b-it`); NVIDIA NIM (`build.nvidia.com/google/gemma-4-31b-it`); also available via third-party providers (Artificial Analysis lists +8 providers; OpenRouter / Cloudflare / vLLM / Ollama deployments confirmed). Not a proprietary API-first model — open weights allow self-hosting at zero token cost (but high infrastructure cost).
- **Release / knowledge:** Released 2026-04-02 (Google blog, Hugging Face, NVIDIA NIM, arXiv technical report `2607.02770v2`). Knowledge cutoff not explicitly stated in official docs; training data covers public internet, synthetic sources, multilingual content (140+ languages). Model card (2026-07-30) confirms release date and architecture specs.
- **IDs:** `gemma-4-31b` (base); `gemma-4-31b-it` (instruction-tuned, primary use); `google/gemma-4-31b` (Hugging Face model ID). No separate `Free` tier ID — the entire model is open-weights (Apache 2.0) and free to download/run.
- **Context window:** 256,000 tokens (official model card, NVIDIA NIM, Hugging Face, arXiv report — all agree exactly). Sliding window 1024 tokens per layer; hybrid attention (local sliding-window + global full attention) with unified Keys and Values in global layers and Proportional RoPE (p-RoPE) for long-context extrapolation. Long-context benchmark MRCR v2 (8-needle, 128K): 66.4% (official) — very strong independent retrieval evidence.
- **Modalities:** Input: text (UTF-8), image (variable aspect ratios/resolutions, configurable visual token budgets: 70/140/280/560/1120 tokens), video (input as sequences of frames up to 60 seconds at 1 fps; MP4/WebM). Output: text only (no audio/video/image generation). Reasoning: yes — native thinking/reasoning mode (enabled by default in IT; can be controlled). Tool calls / agentic: yes — function-calling, structured JSON output, native system instructions (official docs confirm agentic workflow support). Multilingual: 140+ languages. No audio-output capability; audio input is supported on E2B/E4B/12B models only, not on 31B dense (official model card confirms 31B: Text + Image only; no Audio input for 31B).
- **Pricing (as of 2026-10-29):** Open-weights (Apache 2.0) — zero per-token licensing cost. Self-hosting cost: ~69.9 GB GPU memory (BF16, 30.7B params + overhead) — single 80GB NVIDIA H100 fits; quantized versions (SFP8 ~34.9 GB, Q4_0 ~17.5 GB) fit on consumer GPUs. Commercial hosting via NVIDIA NIM, Hugging Face Inference, vLLM, Ollama — pricing varies by provider; Artificial Analysis reports $0.00 / $0.00 per 1M tokens (reflecting open-weights/free access via HF rather than commercial API pricing). No verified direct API endpoint (like `openai/gemma-4-31b`) with published per-token rates; closest commercial route is NVIDIA NIM or cloud-hosted vLLM instances. Cost efficiency score reflects the free-license + self-hosting option rather than a cheap commercial token price.
- **Architecture:** Dense transformer (not MoE). 30.7B total parameters / 60 layers / vocabulary size 262,144. Vision encoder: ~550M parameters (4-layer hMLP-style patch encoder, not encoder-free; the 12B Unified model is encoder-free, but 31B uses a dedicated vision encoder). No audio encoder on 31B (E2B/E4B use ~300M audio encoder; 31B does not). Hybrid attention: interleaved local sliding-window (1024 tokens) + full global attention; Proportional RoPE (p-RoPE) for relative positional embeddings supporting 256K extrapolation. Training recipe: pre-training + supervised fine-tuning + RLHF (detailed in arXiv `2607.02770v2`). Thinking/reasoning mode: yes (controllable; default in IT). Not an MoE — full dense activation (unlike 26B-A4B which activates only 3.8B of 26B total).

### Raw benchmarks found

Sources compared and conflicts noted (3+ independent web searches performed):

1. **Official Google / DeepMind sources** (`deepmind.google/models/gemma/gemma-4/`, `blog.google/innovation-and-ai/technology/developers-tools/gemma-4/`, `ai.google.dev/gemma/docs/core/model_card_4`, `huggingface.co/google/gemma-4-31b`, `huggingface.co/blog/gemma4`, arXiv `2607.02770v2`) — primary vendor benchmark tables, architecture details, release notes. Vendor reports benchmarks for instruction-tuned (`IT`) variants in thinking/reasoning mode unless stated otherwise.
2. **Artificial Analysis (independent evaluation)** (`artificialanalysis.ai/articles/gemma-4-everything-you-need-to-know`, `artificialanalysis.ai/models/gemma-4-31b`, `artificialanalysis.ai/es/models/releases/gemma-4-31b`, `go.tabbit.ai/model/gpt-6-luna/reviews/...` [indirect comparison]) — Intelligence Index 39 (reasoning mode) / 14.7 (non-reasoning); Coding Index 43.4; Agentic Index ~40.9 (per Infinum comparison table); Terminal-Bench 4.0: 0.0% (AA harness, mini-swe-agent, reasoning mode) — this is a critical conflict; AA-Briefcase 1,336 Elo (not directly for 31B but family-level comparison); AA-LCR 69.7%; GPQA Diamond 85.7%; HLE 23.6%; MMMU-Pro 73.4%; SciCode 45.5%; AA-Omniscience Index −47.9 (accuracy − hallucination). Note: AA's Terminal-Bench 4.0 0% is for the reasoning-mode variant with the mini-swe-agent harness — this is not the same harness as Google's official Terminal Bench Hard 36.0%.
3. **Benchmark aggregators / independent reviews** (`benchgap.net` [not listed separately for 31B but family-level references], `benchmarkregistry.org` [indirect], `graysoft.dev/benchmarks/google-gemma-4-31b.html`, `the-aischool.com/leaderboard/gemma-4-31b`, `shawnhack.com/models/gemma-4-31b`, `verdictpal.com/models/gemma-4-31b`, `dataconomy.com/ai-models/gemma-4-31b/`, `infinum.com/blog/gemma-4-newest-benchmarks/`) — confirm Intelligence Index ~39.2 (Dataconomy) / 39 (Artificial Analysis reasoning) / 14.7 (non-reasoning); Coding Index 38.7 (Infinum / AI School); Terminal-Bench 2.1 43.45% (VerdictPal / Graysoft) / 36.4% (Shawn Hack Terminal Bench Hard); SciCode 45.5% (Graysoft / AA); GPQA 85.7% (Graysoft / AA); HLE 23.6% (Graysoft / AA); LiveCodeBench v6 80.0% (official) — no independent LiveCodeBench published separately for 31B; closest proxy is official table.

Conflict comparison (explicit):
- **Intelligence Index:** Official vendor (blog/comparison) reports Arena AI Elo 1452 (text, reasoning mode, as of 2026-04-02); Artificial Analysis reports Intelligence Index 39 (reasoning) / 14.7 (non-reasoning). These measure different things (Elo = human preference ranking; Intelligence Index = blended 9-evaluation composite). **No direct numerical conflict — different metrics.** We note both: Arena 1452 = top dense open model; AA Intelligence 39 = moderate-to-high among open weights (trails Qwen3.5 27B at 42, GLM-4.7 at 42, DeepSeek V3.2 at 42).
- **Terminal-Bench 4.0 / Hard:** Official vendor reports Terminal Bench Hard 36.0% (thinking mode, official harness, 2026-07 model card / arXiv). Artificial Analysis reports Terminal-Bench 4.0 0.0% (AA harness, mini-swe-agent, reasoning mode, 2026-09-28). VerdictPal / Graysoft report Terminal-Bench v2.1 43.45% (AA harness, different harness version). **Conflict: the same benchmark family yields 36.0% (official harness) vs 0.0% (AA mini-swe-agent harness) vs 43.4% (v2.1). These are different harness versions (Hard / 4.0 / v2.1) and evaluation configurations. The 0.0% is specific to AA's mini-swe-agent harness on the reasoning-mode variant — a severe harness mismatch, not necessarily model failure. We weight the official 36.0% (vendor harness) and the 43.45% (independent v2.1) as more representative, and explicitly note the 0.0% as a harness-specific outlier.**
- **Coding Index / Agentic:** Official vendor reports LiveCodeBench v6 80.0%, Codeforces Elo 2150, SciCode 43.0%, Tau2 retail 86.4%, Terminal Bench Hard 36.0%. Artificial Analysis reports Coding Agent Index 43.4 (reasoning) — lower than Qwen3.5 27B (41.3) and Nemotron 3 Super (39.5) in Infinum comparison; actually the comparison table shows Gemma 4 31B Coding Index 38.7 (Infinum / AI School) vs 43.4 (AA direct). **Conflict: Coding Index varies by evaluation harness (AA index vs official LiveCodeBench/Codeforces). The official 80.0% LiveCodeBench v6 and 2150 Codeforces Elo are very high; the AA Coding Agent Index (~39-43) reflects agentic-coding autonomy (multi-file repository editing) which is weaker. We cite both: coding benchmark scores (LiveCodeBench/Codeforces) are very strong; agentic-coding autonomy (AA Coding Agent Index, Terminal Bench 4.0) is weaker — consistent with official docs that the model excels at structured, focused coding but not open-ended multi-file agentic autonomy.**
- **HLE:** Official 19.5% (no tools) / 26.5% (with search). Artificial Analysis reports 23.6% (reasoning mode). These are within ~4 pp — near-agreement; the official no-tools 19.5% is lower because AA includes search/tool-augmented evaluation in some configurations. **No significant conflict — cited together.**
- **GPQA Diamond:** Official 84.3%. Independent AA / Graysoft / VerdictPal / Dataconomy all report 85.7% (AA run) / 86% (Infinum comparison table). **Near-agreement within ~1.4 pp — very consistent.**
- **SciCode:** Official 43.0%. AA reports 45.5% (independent). **Near-agreement within 2.5 pp.**
- **AA-Omniscience:** AA reports Index −47.9 (very poor); official docs do not publish an Omniscience score. This is a verified independent weakness (high hallucination / low accuracy combination) — no vendor conflict, just a negative independent finding.
- **MMMU-Pro / Vision:** Official 76.9%. AA comparison table reports MMMU-Pro 73.4% (Graysoft / VerdictPal). **Near-agreement within ~3.5 pp.**
- **Long-context retrieval (MRCR v2, 128K):** Official 66.4% (8-needle average). No independent verification for this exact number found in external sources — closest proxy is AA-LCR 69.7% (independent, different harness). **Near-agreement; official MRCR is authoritative but unverified externally.**
- **Agentic (Tau2 retail):** Official 86.4% (retail, thinking mode). Independent AA comparison does not list Tau2 specifically for 31B — closest family-level comparison shows Tau2 average 76.9% (official table for all sizes; 31B is the highest). **No conflict; official 86.4% is the authoritative number.**

Agent / tool use:
- Terminal Bench Hard (official harness): 36.0% (thinking mode) — moderate; confirms the model can handle agentic terminal tasks but is not frontier (Claude Opus 5.5 / GPT-6 Astra are significantly higher).
- Terminal-Bench v2.1 (independent AA harness): 43.45% — slightly higher than official Hard harness; indicates harness-dependent variation.
- LiveCodeBench v6: 80.0% (official) — very high competitive-coding score; best verified coding evidence.
- Codeforces Elo: 2150 (official) — very high for a 30.7B open-weight model; confirms strong algorithmic coding.
- SciCode: 43.0% (official) / 45.5% (AA) — solid; consistent.
- Tau2 (agentic tool use): Retail 86.4%, Airline 75.0%, Telecom 69.3% (official, thinking mode) — very high agentic tool-use scores for structured retail/airline tasks; telecom lower.
- AA Coding Agent Index: ~39-43 (independent, reasoning mode) — lower than frontier (Claude/GPT families). Confirms that while raw coding benchmarks (LiveCodeBench/Codeforces) are very high, multi-file agentic autonomy (repo-level editing, open-ended coding) is weaker.
- AutomationBench / APEX-Agents / Toolathon / MCP Atlas / Claw-Eval: **no verified independent score found specifically for `gemma-4-31b`.** The closest proxy is the official Tau2 retail 86.4% (agentic tool use) and the AA Agentic Index (~40.9 per Infinum comparison) — these reflect different evaluation dimensions.

Reasoning / knowledge:
- Artificial Analysis Intelligence Index: 39 (reasoning mode) / 14.7 (non-reasoning) — the reasoning-mode 39 is the relevant score (model is released in reasoning/IT mode by default); 14.7 reflects non-reasoning mode which is not the primary deployment mode.
- Arena AI (text): 1452 Elo (as of 2026-04-02) — top dense open-weight model; ahead of Qwen3.5 26B-A4B (1441) and well ahead of Gemma 3 27B (1365). Verified by official blog and arXiv report (Table 4).
- GPQA Diamond: 84.3% (official) / 85.7% (independent AA/Graysoft) — very high scientific-reasoning score; agreement within 1.4 pp.
- AIME 2026 (no tools): 89.2% (official) — very high mathematics/reasoning benchmark.
- MMLU Pro: 85.2% (official) — high general knowledge.
- HLE (no tools): 19.5% (official) / 23.6% (AA independent) / 23% (AI School / comparison) — moderate-to-low; well below frontier (Claude/GPT families score 30-46%). Confirms reasoning depth is good for open-weights but not at the absolute frontier.
- HLE with search: 26.5% (official) — improvement with tool/search augmentation; confirms the model benefits from external retrieval.
- BigBench Extra Hard: 74.4% (official) — very high complex-reasoning task score.
- AA-Omniscience Index: −47.9 (AA independent) — very poor; indicates high confident-wrong-answer rate combined with low accuracy. This is a verified weakness, not a measurement error; official docs do not dispute it (they don't publish an Omniscience score).
- CritPt: 1.4% (Shawn Hack / independent) — very low physics/reasoning depth; consistent with HLE weakness.
- IFBench: 76.0% (official) / 75.6% (AA independent) — near-agreement.
- IFEval: 98.9% (official) — very high instruction-following accuracy.

Coding:
- LiveCodeBench v6: 80.0% (official, IT) — best verified coding evidence; very high.
- Codeforces Elo: 2150 (official) — very high competitive programming score for 30.7B dense model; outperforms much larger open models.
- SciCode: 43.0% (official) / 45.5% (AA) — solid software-engineering benchmark; near-agreement.
- Terminal Bench Hard: 36.0% (official, thinking mode) — moderate agentic terminal performance; well below frontier (Claude Opus 5.5 / GPT-6 Astra are significantly higher) but competitive for open-weights.
- Tau2 (agentic): Retail 86.4% / Airline 75.0% / Telecom 69.3% — very high structured agentic-work scores; confirms strength in focused, structured coding/tool-use tasks.
- AA Coding Agent Index: 43.4 (reasoning) / 38.7 (Infinum comparison, reasoning) — moderate-to-high; lower than Qwen3.5 27B (42) and well below frontier closed models. Confirms the coding-agency gap: raw coding benchmarks (LiveCodeBench/Codeforces) are excellent; multi-file autonomous agentic coding (AA index) is weaker.
- FrontierCode 2.0: 25% (AA comparison for 31B reasoning, per Artificial Analysis comparison table) — low open-source repository-level agentic coding score; confirms the autonomy gap.

Long context:
- Context window: 256K verified by official docs (model card 2026-07-30, arXiv, NVIDIA NIM, Hugging Face) — full agreement across 4+ independent sources.
- MRCR v2 (8-needle, 128K): 66.4% (official, thinking mode) — very strong verified long-context retrieval benchmark; significantly ahead of Gemma 3 27B (13.5%) and 26B-A4B (44.1%). Best verified long-context evidence for the 31B dense model.
- AA-LCR (long-context reasoning, independent): 69.7% (AA independent, 2026-09-28) — very close to official 66.4% (different harness); near-agreement confirms long-context capability.
- No independent RULER / GraphWalks at 256K+ published specifically for `gemma-4-31b` — closest proxy is the official MRCR 66.4% and independent AA-LCR 69.7%.

Multimodal:
- Input modalities: text + image verified (official model card, NVIDIA NIM input table: Text + Image; no Audio input for 31B). Video input supported (frame sequences, up to 60 sec @ 1 fps) — verified by official docs and NVIDIA NIM input table (Video: MP4/WebM).
- Vision benchmarks: MMMU-Pro 76.9% (official) / 73.4% (AA independent) / 73.4% (Graysoft) — near-agreement within ~3.5 pp. MATH-Vision 85.6% (official). OmniDocBench 1.5 (edit distance, lower better): 0.131 (official) — very low edit distance (high document-editing accuracy). MedXPertQA MM 61.3% (official) — moderate medical-vision score.
- Multimodal capability: strong vision performance for an open-weight dense model; weaker than frontier multimodal closed models (e.g., Claude/GPT vision scores are higher) but competitive within open-weights. No audio-output capability.
- Independent review (Artificial Analysis comparison): notes Gemma 4 31B is notably token-efficient (39M output tokens for Intelligence Index vs 98M for Qwen3.5 27B reasoning) — a verified efficiency advantage.

### Normalized scores (1–100)

- **Tool use: 79/100.** Evidence: Tau2 retail 86.4% (official, very high structured agentic work); Terminal Bench Hard 36.0% (official, moderate); LiveCodeBench v6 80.0% (official, very high); Coding Agent Index 43.4 (AA, moderate-high); AA Agentic Index ~40.9 (Infinum, moderate); Terminal-Bench 4.0 0.0% (AA harness — harness outlier, discounted). Capped by weaker open-ended agentic autonomy (FrontierCode 25%, AA Agentic Index lower than frontier) and the harness-dependent variation (36.0% official vs 0.0% AA vs 43.45% v2.1). Conflicts noted and weighted: official vendor numbers (hard harness) and v2.1 independent scores are weighted more heavily than the 0.0% outlier.
- **Reasoning: 82/100.** Evidence: Intelligence Index 39 (AA reasoning, moderate-high open-weight); Arena AI Elo 1452 (official, top dense open model); GPQA Diamond 84.3-85.7% (very high); AIME 2026 89.2% (very high); MMLU Pro 85.2% (high); BigBench Extra Hard 74.4% (high); HLE 19.5-23.6% (moderate-low, well below frontier); AA-Omniscience Index −47.9 (verified weakness — high confident errors). Capped by HLE weakness (below Claude/GPT families by ~10-20 pp) and poor Omniscience (high confident-wrong rate). Conflicts resolved: different metrics (Elo vs Index) cited together; no numerical contradiction.
- **Context window: 92/100.** Evidence: 256K verified by 4+ independent sources (official docs, arXiv, NVIDIA NIM, HF, model card 2026-07-30) — full agreement. MRCR v2 66.4% (official, very strong 128K retrieval); AA-LCR 69.7% (independent, near-agreement). No independent RULER at full 256K found. Capped slightly by absence of independent 256K retrieval measurement (only 128K verified); architecture (hybrid local/global attention) supports 256K extrapolation but 128K is the highest verified retrieval benchmark.
- **Multimodal: 85/100.** Evidence: native text + image + video input verified (official model card, NVIDIA NIM, HF); MMMU-Pro 76.9% (official) / 73.4% (independent) — near-agreement; MATH-Vision 85.6% (official); OmniDocBench 0.131 (official, very strong document editing); vision encoder ~550M (verified architecture spec). No audio input on 31B (official model card explicitly excludes audio for 31B dense — audio only on E2B/E4B/12B). No video-output capability. Score capped by weaker multimodal scores vs frontier (MMMU-Pro 73-77% is good but not at Claude/GPT vision levels; no independent video-output or audio-input benchmark for 31B specifically).
- **Coding: 83/100.** Evidence: LiveCodeBench v6 80.0% (official, best evidence); Codeforces Elo 2150 (official, very high); SciCode 43.0-45.5% (agreement); Tau2 retail 86.4% (official, very high structured agentic coding); Terminal Bench Hard 36.0% (moderate agentic terminal); AA Coding Agent Index 38.7-43.4 (moderate-high agentic autonomy). Capped by weaker multi-file autonomous agentic coding (FrontierCode 25%, AA Agentic Index lower than frontier) and the harness-dependent variation. Conflicts resolved: LiveCodeBench/Codeforces (official, very high) and agentic-coding indices (independent, moderate) reflect different dimensions — both cited.
- **Cost efficiency: 100/100.** Evidence: Apache 2.0 open-weights — zero licensing cost; self-hosting possible on single 80GB H100 (unquantized) or consumer GPU (quantized Q4_0 ~17.5 GB). Artificial Analysis reports $0.00 / $0.00 per 1M (reflecting open-weights/free access, not a commercial API price). NVIDIA NIM provides commercial hosting; no per-token price published for direct Google API (model is open-weights first). The extreme cost-efficiency (free weights + local inference option) justifies the maximum score; capped only by the absence of a verified commercial $0 free-tier endpoint (the model itself IS the free tier for self-hosters).
- **Overall Score: 84/100.** Mean of quality dims: (79 + 82 + 92 + 85 + 83) / 5 = 84.2 → rounded to 84. Best-fit: the leading dense open-weights model (Arena AI 1452, top open dense) with verified 256K context, very strong coding (LiveCodeBench 80%, Codeforces 2150), very high agentic structured-work scores (Tau2 retail 86.4%), strong vision (MMMU-Pro 76.9%), and verified long-context retrieval (MRCR 66.4%). Main weaknesses: open-ended agentic autonomy (AA Coding Agent Index ~39-43, FrontierCode 25%), deliverable-quality/completeness on multi-file tasks (Terminal Bench 4.0 harness variation 0-43%), HLE reasoning depth (19.5-23.6%, below frontier), and poor Omniscience (high confident errors, Index −47.9). Recommended for open-weight deployment, structured agentic coding/workflows, vision+multimodal tasks, and long-context applications (up to 128K verified retrieval, 256K spec-supported); not the best choice for frontier-level open-ended autonomous agentic coding or complex multi-week deliverable projects requiring high presentation/completeness quality.
