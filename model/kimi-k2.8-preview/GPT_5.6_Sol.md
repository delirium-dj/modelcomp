# Kimi K2.8 Preview — Independent Research Report

## Summary and evidence

Kimi K2.8 Preview is a September 2026 experimental upgrade available in Kimi Code and Kimi Work under the existing `kimi-for-coding` route. Moonshot has not published a model card, architecture, open weights, controlled benchmark table, or independent API identifier. Product materials indicate a **one-million-token coding context**, but its relationship to K2.6, K2.7, and K3 is not technically documented.

Source: [Kimi K2.8 preview evidence summary](https://kimi-k2.org/blog/58-kimi-k2-8-preview)

## Cost and limitations

There is no separately published per-token price. Preview routing, undocumented architecture, and missing reproducible evaluations create substantial deployment uncertainty; scores therefore remain conservative.

## Scores

- **Tool use: 86/100.** Kimi Code and Work provide agent scaffolding, but controlled results are absent.
- **Reasoning: 84/100.** It appears improved over K2.x predecessors, without enough evidence for a frontier score.
- **Context window: 95/100.** Reported one-million-token coding context is excellent.
- **Multimodal: 76/100.** Public preview evidence centers on coding rather than verified multimodality.
- **Coding: 88/100.** The preview is specifically deployed for coding workflows.
- **Cost efficiency: 75/100.** No separate, stable API pricing is disclosed.
- **Overall Score: 86/100.** Half-up rounded mean: (86 + 84 + 95 + 76 + 88) / 5 = 85.8.

## Bottom line

Kimi K2.8 Preview is promising for Kimi Code users, but insufficiently documented for high-confidence production selection.
