## Model card

- **Name:** Claude Fable 5.1 (Adaptive Reasoning, Max Effort, Default Fallback)
- **Short description:** Anthropic's most capable generally available model for ambitious long-running coding, research, and knowledge work; it shares its underlying model with restricted Mythos 5.1 but has production safeguards and fallback behavior.
- **Provider / access:** Anthropic Claude Platform, Amazon Bedrock, Google Cloud and Microsoft Foundry. API ID `claude-fable-5-1`. **Status: Active, not deprecated.** Enterprise Frontier Safeguards (EFS) began phased rollout "later this fall" 2026 and is available for internal use on Bedrock / Claude Platform on AWS through **2026-12-31**; until EFS is available, EFS-eligible customers get zero data retention, which is what the first pass recorded.
- **Release / knowledge:** Anthropic announced Fable 5.1 on **2026-09-01** (Artificial Analysis gives the same date; Vals agrees). The reviewed model overview lists a **June 2026** reliable knowledge cutoff for the Fable 5.1 family — unchanged this pass. Claude Opus 5.5 (released 2026-09-22) is described by Anthropic as performing "at the level of Claude Fable 5.1 on most work" at roughly 40% lower cost; Fable 5.1 itself is **not** flagged as deprecated.
- **IDs:** `claude-fable-5-1`.
- **Context window:** **1M input tokens, 128K maximum output tokens** (Anthropic model overview; independently confirmed by Vals AI's capability panel, which lists Context Window 1M / Max Output Tokens 128k). Artificial Analysis rounds the window to 1M.
- **Modalities:** Text and image input; text output; **file input supported** per Vals. Video input **not** supported. Multilingual, vision, and tool use supported. Fable documentation specifically describes document/PDF understanding and vision-assisted coding.
- **Pricing (as of 2026-10-17, unchanged):** **$10 per 1M input tokens and $50 per 1M output tokens**; **cache reads $0.25 per 1M** (98% cache discount; blended 7:2:1 $7.17). Vals' leaderboard rows use $10 / $50 throughout, and Vals reports a Vals Index cost of **$28.71 per test**. Cache reads were cut 75% relative to Fable 5. US-only inference is 1.1x input/output pricing.
- **Architecture:** Proprietary; Anthropic has not disclosed parameter count.

**OSWorld 2.0 and the safeguards — a lead stated too broadly, corrected.**
Anthropic states, in both the launch page and the Fable page: *"Fable 5.1 was evaluated with its production safeguards enabled. **On tasks where these safeguards intervened**, Fable 5.1 and Fable 5 scored a zero on OSWorld 2.0, and Fable 5 scored a zero on AutomationBench."* So the correct claim is **not** that safeguards scored Fable zero on OSWorld 2.0 as a whole — Anthropic still reports 77.9% partial / 41.7% strict. It is that **individual intervened tasks were scored zero** and rerouted (cyber → Opus 4.8, biology → Opus 5), which Anthropic concedes "likely reduces the performance of Fable 5.1 and Fable 5 on these benchmarks." Two independent analyses (paddo.dev, llm-stats) put the TB4.0 cost of that mechanism at roughly 5 points, with the cyber classifier firing on GPU kernels and proof assistants that have nothing to do with cyber. Recorded at the strength Anthropic actually claims.

**Vals' own source conflict — resolved, and it is not an inconsistency.**
A lead flagged three apparently contradictory Vals figures. They are **three dated snapshots of one re-weighted index**, not a contradiction:
- **67.87%** — Vals' model-page news post and the `vals.ai/benchmarks/vals_index` landing text, from the **2026-09-01** evaluation, where Fable 5.1 was **#1**
- **68.83%** — Vals' Gemini 4 Argon / Sonnet 5.5 news posts, a later snapshot ahead of the Sonnet 5.5 launch
- **65.83%, #4 of 49** — the **leaderboard updated 2026-10-16**, corroborated independently by the BenchLM mirror (2026-10-13, 48 models) and BenchLeader (2026-10-18), both showing Gemini 4 Argon at **68.90%** #1 and Fable 5.1 at 65.8 #4
The mechanism is visible in the methodology: Terminal-Bench 4.0 replaced Terminal-Bench 2.1, Code Migration and ProofBench were added, and private benchmarks entered the GDP-weighted mix. Fable 5.1 did not fall because it got worse — it fell from #1 to #4 because **the benchmark set got harder**. Both the 68.83% and the 68.90% figures are correct for their dates; **65.83% (#4/49) is the current value** and the one used here.

**A lead that could not be verified.** The BenchLM **agentic lane 80.9 (#2/128)** figure was searched for on BenchLM's own Fable 5.1 page and **not found**. That page exposes 57 benchmark rows in an agentic table but prints no composite agentic score and no field size. The BenchLM Vals Index mirror it does carry lists Fable 5.1 at **#4 of 48** on the current snapshot. **No 80.9 / #2-of-128 figure is recorded as fact**, and nothing in this report's Tool use score depends on it.
