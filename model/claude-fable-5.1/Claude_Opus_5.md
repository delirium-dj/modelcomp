## Model card

- **Name:** Claude Fable 5.1 — status **Active (latest)**, positioned by Anthropic's own docs "for demanding reasoning and long-horizon agentic work". No free tier. **Variant/alias flag — important:** **Claude Mythos 5.1 offers the same capabilities by invitation only** as part of Project Glasswing and **shares Fable 5.1's specifications and pricing exactly**; the two are the same capability tier behind different access gates and must not be scored as if Mythos were a stronger model.
- **Short description:** Released **2026-09-01** (jointly announced with Mythos 5.1), extending Claude Fable 5 at **identical input and output prices with cache reads at a quarter of the cost**, and adding stronger long-running agentic coding, multistep research, and document/spreadsheet/slide work. The notable thing about this model is Anthropic's own positioning: the docs say **"For most workloads, start with Claude Opus 5… Use Claude Fable 5.1 for demanding reasoning and long-horizon agentic work, or when your evals on Claude Opus 5 at higher effort still fall short."** The vendor explicitly frames its most expensive model as an escalation path, not a default — and Anthropic has separately stated that "the gap between Opus 5.5 and Fable 5.1 is narrower than the scores suggest".
- **Provider / access:** Claude API (`claude-fable-5-1`, Messages API), Amazon Bedrock (`anthropic.claude-fable-5-1`), Google Cloud, Microsoft Foundry and Claude Platform on AWS (all `claude-fable-5-1`). Breaking changes for anyone migrating from Fable 5 (three): **forced tool use returns an error**, **earlier models cannot read its thinking blocks**, and **editing earlier turns invalidates thinking blocks**. Additive changes (five): **per-message effort** (beta — change effort mid-conversation without invalidating the prompt cache), **turn-scoped system messages** (beta), **readable progress updates between tool calls** (`display: "updates"`, beta), the lower cache-read price, and **content provenance**.
- **Release / knowledge:** Released 2026-09-01. **Knowledge cutoff June 2026** (both reliable and training-data cutoff). Retirement not sooner than 2027-09-01.
- **IDs:** `claude-fable-5-1` (Claude API / Google Cloud / Microsoft Foundry / Claude Platform on AWS); `anthropic.claude-fable-5-1` (Amazon Bedrock). **No free-tier ID.**
- **Context window:** **1M tokens input, 128K tokens max output** on the synchronous Messages API. Two caveats from Anthropic's own documentation: **Fable 5.1 is *not* in the list of models eligible for the 300K-output Batch API beta** — Opus 5.5, Opus 5, Sonnet 5.5, Sonnet 5, Opus 4.8/4.7/4.6 and Sonnet 4.6 all are, so the most expensive model has the *smaller* maximum generation ceiling; and **1M tokens is roughly 555k words / 2.5M Unicode characters on the current tokenizer** (introduced with Opus 4.7), against ~750k words for pre-4.7 models.
- **Modalities:** Input: **text and images only** → output: text. No audio, video or PDF path documented; no non-text output. Reasoning: **Adaptive thinking, always on — the only available mode**, steered by `effort` with a **`high` default**. **Comparative latency: "Slower" — the slowest in Anthropic's current lineup.** Tool calls: yes, but **forced tool use is unsupported**.
- **Pricing (as of 2026-10-03):** **$10 / MTok input, $50 / MTok output.** 5-minute cache write $12.50, 1-hour cache write $20, and the headline improvement: **cache read $0.25 / MTok — a 2.5% multiplier, the lowest in the entire Claude lineup** (the standard is 10%; Opus 5.5 is 5%), and a 4x cut from Fable 5. Batch API 50% off input and output. Lineup context from Anthropic's own comparison table: Opus 5.5 $4/$20, Sonnet 5.5 $2/$10, Haiku 4.5 $1/$5 — all with the same 1M context and 128K output except Haiku.
- **Architecture:** Proprietary, closed weights. Parameter count, active parameters and topology: not disclosed.

### Raw benchmarks found

> Anthropic publishes no standalone Fable 5.1 benchmark table on the model overview page. Every figure below is therefore **third-party-table-reported** and labelled by whose table it came from — all verified directly in this research session: **(A)** Anthropic's own Claude Opus 5.5 system-card comparison (Table 8.1.A and §8), where Fable 5.1 appears as the comparison model, and **(G)** Google DeepMind's Gemini 4 Argon launch comparison. Where the two disagree on the same benchmark, both values are recorded.

- **GDPval-AA v2.1 (Elo): 1,735 (A)** — just under the methodology's ~1750+ frontier reference; behind Opus 5.5's 1,846 and Sonnet 5.5's 1,844, ahead of Claude Opus 5's 1,708 and GPT-6 Astra's 1,542.
- **AA-Briefcase v1.1 (Elo): 1,678 (A)** — 144 Elo behind Opus 5.5's 1,822.

Vision / documents:

Long context:

- **No MRCR, RULER or dedicated retrieval figure found.** The available long-context evidence is **negative relative to its cohort**: **GraphWalks breadth-first-search F1 of 91.4% up to 128K and 65.0% across 256K–1M (G) — the worst of the four models in Google's table** (Argon 99.7% / 84.2%, Astra 98.7% / 71.8%, Opus 5.5 90.6% / 66.8%), and **ProgramBench 87.6% (A)** against Opus 5.5's 91.2%.

### Normalized scores (1–100)

- **Tool use: 86/100.** **GDPval-AA v2.1 at 1,735 Elo sits essentially at the ~1750+ frontier reference**, OSWorld 2.0 partial credit of 80.7% is within 1.1 points of Claude Opus 5.5, and the **Gray Swan prompt-injection ASR of 1.0% is among the best measured anywhere** — genuine evidence of a hardened agent loop. But the agentic record is weak in exactly the places that matter for autonomous work: **AutomationBench at 31.4% is last in both tables it appears in, and that figure was achieved with Opus 5 fallback on ~40% of tasks**; Harvey's Legal Agent reaches only 6.7%; **Terminal-Bench 4.0 (55.8–57.9%) trails Opus 5.5 by 9–11 points** and Terminal-Bench-Science (52.6%) trails it too; OSWorld's strict completion rate is only 42.8%; CWE-bench v1 is last of four; and **Tau3-Banking, Claw-Eval, Toolathon, MCP-Atlas and Terminal-Bench 2.1 are all unreported** (explicit methodology penalty).
- **Reasoning: 90/100.** This is the dimension the model is sold on and the evidence does support a frontier placement: **HLE 60.9% without tools and 65.6% with tools is far above the 40%+ reference** and survives independent re-testing at 59.1%, ArXivMath reaches 82.9%/92.1%, and it **beats Claude Opus 5.5 on OfficeQA (80.2% vs 78.9%) and OfficeQA Pro (69.0% vs 67.7%)** — real wins on document comprehension. Capped at 90 by a consistent pattern of losing to cheaper siblings and rivals: the **independent Intelligence Index of 53 is below the 60+ marker, 5 behind Opus 5.5 and 3 behind the five-times-cheaper Sonnet 5.5**; **LABBench 2 (68.6%), RiemannBench (65.6%) and PostTrainBench (40.2%) are all last of four** in Google's comparison; HLE loses both rows to Opus 5.5; and **GPQA Diamond, MRCR/LCR, CritPt and any hallucination measurement are entirely absent**.
- **Context window: 93/100.** The nominal **1M-token window** reaches the ≥1M tier, but this is the one model in the dataset where the long-context evidence is actively unfavourable rather than merely missing. **GraphWalks F1 of 65.0% across 256K–1M inputs is the worst of the four models in Google's table** — 19.2 points behind Gemini 4 Argon and 1.8 behind Claude Opus 5.5 — and **ProgramBench at 87.6% also trails Opus 5.5's 91.2%**, so reasoning quality over long inputs is measurably weaker than cheaper alternatives. Three further structural caveats: no MRCR/RULER figure exists; **Fable 5.1 is excluded from the 300K Batch-output beta that even two-generation-old Opus and Sonnet models support**, so the most expensive model has the smaller generation ceiling; and the current tokenizer means 1M tokens holds roughly 555k words, about 30% less text than the number suggests.
- **Multimodal: 66/100.** Input is **text and images only** with text-only output, placing it in the methodology's "+image in = 60–70" band — and unlike its siblings it does **not** earn the top of that band, because its unaided visual performance is the weakest in every comparison it appears in. **Chartography without tools is 44.8% (Anthropic's own table) or 46.2% (Google's) — 19.6 points behind Claude Opus 5.5 and 20–25 points behind Gemini 4 Argon and GPT-6 Astra.** With tools it recovers to 88.4%, but that measures the harness as much as the model. SWE-bench Multimodal at 54.7% is 6.7 points behind Opus 5.5, LVBench is last of four, and there is no audio, video or PDF input path and no non-text output.
- **Coding: 89/100.** Solid frontier-adjacent results across a wide suite: **SWE-bench Pro 81.2%**, **SWE-bench Multilingual 89.1%**, **ProgramBench 87.6%**, **Vibe Code Bench 90.3%**, and **SciCode 63.1% independently measured, above the methodology's 55%+ reference**. Four deductions keep it below Opus 5.5 and Sonnet 5.5: **DeepSWE v1.1 at 67.4% is 6.6 points below the 74%+ frontier reference and last of four**; every SWE-bench variant loses to Opus 5.5; **SWE-bench Verified and LiveCodeBench are absent**; and the efficiency evidence is poor — **CursorBench 4.0 at 51.8% for ~$17.28 per task against Opus 5.5's 52.5% at ~$3** means it is outscored *and* outpriced by a cheaper model from the same vendor on the benchmark built from real coding sessions.
- **Cost efficiency: 26/100.** $10 / $50 sits on the methodology's ~30 anchor, and one genuine improvement argues up: **cache reads at $0.25 / MTok are a 2.5% multiplier — the lowest in the entire Claude lineup, 4x cheaper than Fable 5's** — plus Batch at 50% off and the fact that Fable 5.1 arrived at Fable 5's price with better scores. Everything else argues down, and hard. The measured per-task figure is **~$17.28 on CursorBench for a lower score than Claude Opus 5.5 achieved at ~$3**, a 4–6x premium for a worse result. Latency is rated **"Slower" — the worst in the lineup**. **Thinking is always on with a `high` default**, so every call spends $50/MTok reasoning tokens with no way to switch them off. And most decisively, **Anthropic's own documentation tells you not to default to it** — "start with Claude Opus 5… use Fable 5.1 when your evals on Opus 5 at higher effort still fall short" — while Opus 5.5 at $4/$20 beats it on nearly every published row. A model priced at 2.5x a sibling that outperforms it is poor value by construction, which is why this lands below the raw anchor.
- **Overall Score: 84.8/100.** Mean of the five non-cost dimensions (86 + 90 + 93 + 66 + 89) / 5 = 84.8 — a narrow specialist that its own vendor positions as an escalation tier. The defensible reasons to pay for it are **office-document QA**, where it is the only model that beats Claude Opus 5.5 (OfficeQA 80.2%, OfficeQA Pro 69.0%); **demanding open-ended reasoning where Opus 5 at high effort has already failed your evals**, which is Anthropic's own stated criterion; **cache-heavy pipelines** that can exploit the 2.5% cache-read multiplier; and **agents ingesting untrusted content**, where a 1.0% prompt-injection success rate is near best-in-class. Everything else points elsewhere: Claude Opus 5.5 at 40% of the price leads SWE-bench Pro, Terminal-Bench 4.0, HLE, Chartography, GraphWalks, ProgramBench and the Intelligence Index; Claude Sonnet 5.5 at 20% of the price scores higher on the Intelligence Index and Vibe Code Bench; Gemini 4 Argon and GPT-6 Astra lead the agentic-science, automation and long-context rows. Do not choose it for autonomous business automation (AutomationBench 31.4% with fallbacks), unaided chart or document vision (Chartography 44.8% without tools), latency-sensitive work (rated Slowest), or long single-shot generation (no 300K Batch-output eligibility). Finally, note the alias: **Claude Mythos 5.1 is this same capability tier at this same price, gated to Project Glasswing invitees** — there is no capability argument for seeking it out over Fable 5.1.
