## Model card

- **Name:** Claude Haiku 3.5 (Claude 3.5 Haiku)
- **Short description:** Anthropic's fast, cheap small model from October 2024 — positioned as "state-of-the-art meets affordability and speed", matching or beating the much larger Claude 3 Opus on many intelligence benchmarks at Haiku-class latency, with standout coding ability for its tier. **Status: RETIRED.** This is not a "superseded and still purchasable" entry — Anthropic's own lifecycle table marks `claude-3-5-haiku-20241022` as **Retired**, and **API requests to it now fail**. The entry is retained here as a historical tracking record and as a calibration point for what the methodology scores on a cheap, fast, non-reasoning, long-context-weak small model.
- **Provider / access:** Originally the Anthropic API (`claude-3-5-haiku-20241022` / `claude-3-5-haiku-latest`), Amazon Bedrock and Google Vertex AI. Historical OpenCode route `opencode/claude-3-5-haiku`; models.dev records it as `status = "deprecated"`, described as "Legacy model retained for compatibility with older integrations". **No live first-party endpoint as of 2026-10-17.**

AA: "not a reasoning model", reasoning variants do not exist for this checkpoint.

Artificial Analysis shows no price at all, because it tracks only providers still serving the model and none do.

### Raw benchmarks found

> Everything in the vendor block below is **vendor-reported**, from Anthropic's own Model Card Addendum (2024-10-22) and launch post, except where marked otherwise. The independent block is Artificial Analysis. **The two blocks barely overlap, and that is the point of this entry.**

Agent / tool use (vendor-reported — Anthropic Model Card Addendum):

- **TAU-bench (τ-bench) pass^1 — Retail: 51.0%, Airline: 22.8%.** These rows existed in the addendum all along but were not recoverable from text versions of the launch post; they are now verified against the addendum PDF itself. Anthropic's own reading: Claude 3.5 Haiku **outperforms Claude 3 Opus in the retail domain** (Opus 45.1%) **and outperforms Claude 3 Haiku in the airline domain** (3 Haiku 16.0%). For calibration on the same run: upgraded 3.5 Sonnet 69.2% / 46.0%, original 3.5 Sonnet 62.6% / 36.0%, Claude 3 Opus 45.1% / 34.5%, Claude 3 Haiku 18.2% / 16.0%. Anthropic also reports that on the pass^1→pass^k reliability curve Haiku "not only maintains its lead over Claude 3 Opus but degrades in consistency at a slower pace" — i.e. it is the *most* consistent of the small models across repeated trials, not the highest-peaking.
- **Anthropic's internal agentic coding evaluation: Claude 3.5 Haiku solved 74% of problems**, against 78% for the upgraded 3.5 Sonnet, 64% for the original 3.5 Sonnet and 38% for Claude 3 Opus. This is an Anthropic-internal, unpublished-metric number with no task list, and it should be read as a within-family ordering rather than an absolute score.
- Tool use: explicitly cited by Anthropic as more accurate than the previous Haiku generation ("more accurate tool use, … well suited for user-facing applications").
- **Computer use (OSWorld line): not available.** Anthropic debuted computer use with Claude 3.5 **Sonnet**, not Haiku 3.5; Haiku 3.5 has no GUI/computer-use capability. It scores 0% by construction on the OSWorld line its sibling leads.
- Terminal-Bench 2.1 / Tau2-Bench / Tau3-Banking / GDPval-AA / Claw-Eval / Toolathon / MCP-Atlas: **no verified public score found.** (AA lists Terminal-Bench 4.0 as an evaluation for this model but publishes no value.)

Reasoning / knowledge:

- **Vendor-reported, Anthropic's own launch chart (0-shot CoT where stated):**
  - **Graduate-level reasoning (GPQA Diamond): 41.6%** — vs upgraded 3.5 Sonnet 65.0%, original 3.5 Sonnet 59.4%, GPT-4o 53.6%.
  - **Undergraduate-level knowledge (MMLU): 65.0%** — vs 78.0% / 75.1% for the Sonnets.
  - **Math problem-solving (MATH): 69.2%** — vs 78.3% / 71.1%.
  - **High-school math competition (AIME): 5.3%** — vs 16.0% / 9.6%.
  - **Code (HumanEval): 88.1%** — vs 93.7% / 92.0%.
  - **Visual Q/A (MMMU): no Haiku figure published** — the cell is blank in Anthropic's chart even though the Sonnets and GPT-4o have one. Anthropic never evaluated this model's vision path.
  - **Provenance note on GPQA 41.6%:** this is a single first-party source. Deepranking.ai and Langbase both reproduce 41.6% and both attribute it to Anthropic's addendum, i.e. they are **relabelling a vendor number as a benchmark score**, not reporting an independent run. One aggregator (AnotherWrapper) instead prints **GPQA Diamond 38.1%, #146 of 157** with no stated harness; that is not reconcilable with 41.6% and is recorded as an unexplained third value, not adopted.
- **Independent (Artificial Analysis):**
  - **Intelligence Index 9 (estimated), #105 / 296 among non-reasoning models**, above the class median of 7. Estimated because the model is deprecated; AA continues benchmarking only the default 10k-input-token workload.
  - **AA-LCR v1.1: 27%** *(see Long context — this is the headline new independent number)*.
  - **Humanity's Last Exam: 4%.** **CritPt: 0%.**
  - **AA-Omniscience: −23** (composite; correct answers minus confident wrong answers, scored −100 to +100) — a *negative* hallucination profile. For scale on the same page: GPT-5 (high) −9, GLM-5 (reasoning) 0, Grok 3 −33, Mistral Large 3 −40.
  - **GDPval-AA v2.1: 211.** Caution: several AA comparison pages print exactly 211 for this model *and* for o3, while others print 210 — an aggregator-consistency artefact. Treat the value as "very low, approximately 210–211", not as a precise measurement.
  - MMMU-Pro, MLCR-AA, Terminal-Bench 4.0, SciCode (listed "under review"), Terminal-Bench-Science 0.1, FrontierCode 1.1, Harvey LAB-AA, EnterpriseOps-Gym-AA, ITBench-AA: **listed as evaluations for this model on AA's page with no published value.**
- Anthropic's qualitative claim, not a number: Claude 3.5 Haiku "matches the performance of Claude 3 Opus … on many evaluations" and "surpasses even Claude 3 Opus … on many intelligence benchmarks". On the only agentic domain benchmark where both were run, this holds for retail (51.0 vs 45.1) and fails for airline (22.8 vs 34.5) — the claim is true but domain-dependent.
- Non-reasoning by design: no extended thinking and zero reasoning tokens, so the reasoning-heavy benchmarks above understate what a reasoning model of this size could do and are the right measure of what this one is.

Coding:

- **SWE-bench Verified 40.6%** — Anthropic's own table, with the full comparison row: upgraded 3.5 Sonnet **49.0%**, Claude 3.5 Haiku **40.6%**, original 3.5 Sonnet **33.4%**, Claude 3 Opus **22.2%**, Claude 3 Haiku **7.2%**. The figure carries a footnote: *"Compared to the current state-of-the-art score of 45.2% as reported on SWE-bench's leaderboard as of October 22nd, 2024"* — i.e. **45.2% was the leaderboard SOTA at launch (Claude 3.7 Sonnet), not Haiku's score**, and the 40.6% is 4.6 points below it.
- **HumanEval 88.1%** *(Anthropic's launch chart — see the relabelling note above)*.
- **Anthropic internal agentic coding eval 74%** *(see above)*.
- SciCode / LiveCodeBench / Vibe Code Bench / DeepSWE / Coding Index / AA Terminal-Bench 4.0: **no verified public score found.**
- Anthropic's framing: "Claude 3.5 Haiku is particularly strong on coding tasks" for its tier.

Long context:

- **AA-LCR v1.1: 27%** *(Artificial Analysis — confirmed, and it appears identically on every AA comparison page for this model: against Grok 3, o3, GPT-5 medium, GPT-5 high, Claude 4 Opus, Claude 3.7 Sonnet, Claude 4.1 Opus, Mistral Large 3 and GLM-5. For scale on the same rows: o3 75%, GPT-5 high 78%, Grok 3 58%, Mistral Large 3 36%.)* This is **the only long-context measurement this model ever received**, and it is poor — at 27% the model fails roughly three quarters of the long-context reasoning tasks, in a 200K window it nominally supports. It is a low number for a model whose whole selling point was a 200K context, and it is the single most load-bearing new fact in this report.
- No MRCR / RULER / GraphWalks retrieval result exists at any window length. The 200K window, the $0.08 cache-read rate and the 8,192 output cap are capacity and price facts, not retrieval-quality measurements.

### Normalized scores (1–100)

> Derived from the raw numbers above using `model-comparison.md` (v4). Overall = half-up
> mean of the five quality dims; Cost efficiency is scored but never counted.

- **Tool use: 60/100.** Up from 52. The first pass had to score this on vendor copy plus SWE-bench, and said so. **The TAU-bench rows close that gap: Retail 51.0% and Airline 22.8% are genuine agentic tool-use measurements**, they come from Anthropic's own addendum with a stated metric (pass^1, all-k-correct, not pass@k), and the Retail figure is above the methodology's mid band while beating Claude 3 Opus by ~6 points on the same run. **What caps it below the upper bands:** Airline 22.8% is a poor domain result — Haiku beats only Claude 3 Haiku there and loses to *every other model on the table including Claude 3 Opus*; the numbers are two years old and vendor-run with no independent τ-bench reproduction; Terminal-Bench 2.1/4.0, Tau2/Tau3 and GDPval-AA proper are all absent; AA's AutomationBench-AA and EnterpriseOps-Gym-AA rows exist on the page with no published value; and the **8,192-token output cap structurally throttles long tool loops**, which is exactly the regime τ-bench and Terminal-Bench measure. 60 is mid-band on one good vendor row and one bad one.
- **Reasoning: 30/100.** Down from 35, and this is the largest single downward move in the report. Recovering Anthropic's launch chart changed the picture in both directions. **Up:** MMLU 65.0% and MATH 69.2% are real first-party knowledge and maths figures that the first pass recorded as "no verified public score found", and GPQA Diamond **41.6%** is confirmed (the lead's number was right) — a figure the first pass was missing entirely. **Down, and it dominates:** GPQA 41.6% is far below the methodology's mid band (GPQA 60–80% → 55–65) and below its floor for a reasoning model; **AIME is 5.3%**; and on the independent side **HLE is 4%, CritPt is 0%, and AA-Omniscience is −23 (negative)**. **AA's Intelligence Index of 9 (estimated)** remains only modestly above the 7 median for non-reasoning models, and it is an *estimate* on a deprecated model. The model has **no reasoning mode at all** (zero reasoning tokens; Vertex states extended thinking is unsupported), so the ceiling on this dimension is structural, not incidental. Treated as a floor-plus signal, not a measurement.
- **Context window: 58/100.** Down from 68. Verified 200,000 total maps to the 200K–500K = 65–84 band, whose stated anchor is 200K = 70. The first pass placed it just below the anchor because the 8,192 max output is far under the methodology's 64K caveat threshold and no retrieval result existed. **That retrieval result now exists and it is bad: AA-LCR v1.1 at 27%.** The methodology's caveat language treats a *missing* retrieval measurement as a deduction; a *measured* 27% at the model's own nominal window is a stronger deduction than an absence, and it puts this model below models with no long-context data at all. Compounding it: the **8,192-token output cap** (Vertex- and Bedrock-confirmed) makes this a long-*input*, short-output model, and the July 2024 knowledge cutoff means the 200K window is largely filled with pre-2024 text the model cannot reason freshly about. Context capacity and context usefulness are not the same quantity, and only the second one is scored here.
- **Multimodal: 78/100.** Down from 82. Text, image and PDF input with text output still places this in the 75–90 band rather than the 60–70 plain-image band. **What caps it, newly established:** Anthropic's own launch chart leaves the **Visual Q/A (MMMU) cell blank for Haiku 3.5** while populating it for both Sonnets, GPT-4o and the Flash models — the vendor never evaluated this checkpoint's vision path, and no independent MMMU-Pro or MathVista figure has since appeared either. So the modality capability is entirely a **specification claim with no measurement of any kind behind it**, which is weaker evidence than the first pass assumed. Output is text-only, there is no video or audio path, and there is no published vision or PDF evaluation in any retrievable form.
- **Coding: 57/100.** Up from 55. **SWE-bench Verified 40.6%** is a real, dated, first-party number and was genuinely strong for a small fast model in October 2024 — above GPT-4o and the original Claude 3.5 Sonnet at the time, and 18.4 points above Claude 3 Opus. It now also carries a fully recovered comparison row and the **45.2% leaderboard-SOTA footnote**, which contextualises it properly: 4.6 points below the best result anyone had published at that moment. **What was added:** HumanEval **88.1%** and the Anthropic internal agentic coding figure of **74%** of problems solved — the latter notably close to the upgraded 3.5 Sonnet's 78%, which is the strongest evidence anyone published that Haiku 3.5 was a competent agentic coder for its tier. **What caps it:** both new numbers are vendor-reported on internal or undisclosed metrics; SWE-bench Verified is a single-epoch 2024 measurement that has never been independently reproduced (Vals has stopped running it on new releases entirely); SciCode, LiveCodeBench, Vibe Code Bench, DeepSWE and the AA Coding Index are all missing; and everything is far below the methodology's frontier anchors (TB 2.1 85%+, DeepSWE 74%+).
- **Cost efficiency: 92/100.** Unchanged. $0.80 in / $4.00 out per 1M with a $0.08 cache-read rate sits right at the methodology's ~$0.60/$2.20 ≈ 92 anchor. Two honest complications, neither of which moves the number because the score is on the *rate card*, not on buyability: (1) the rate card is **historical and unbuyable** — Anthropic still prints the row but marks the model retired, so no first-party provider sells it; (2) **the true successor is now cheaper still.** Claude Haiku 5.5 (2026-10-07) is **$0.10 / $0.50 for prompts ≤100K and $0.50 / $2.50 above 100K** — 90% below Haiku 4.5 on short prompts, 50% below on long ones, and Anthropic's own blended estimate is **~75% cheaper than Haiku 4.5**. Against this model that is a **8× reduction on input and 8× on output for prompts under 100K**. So the 92 describes a rate card that is both retired *and* obsolete.
- **Overall Score: 57/100.** Half-up mean of the five quality dims (60 + 30 + 58 + 78 + 57) / 5 = 56.6 → **57**. Down from 58.4, and the composition of that move matters more than the total: Tool use **+8** and Coding **+2** from newly recovered first-party rows, more than offset by Reasoning **−5** and Context window **−10** from the AA-LCR 27% and the now-visible weakness of the vendor's own GPQA/MATH/HLE/AIME figures. **Best understood strictly as a historical artifact, not a live recommendation.** Two things a buyer should carry away. First, **the successor chain is broken**: Anthropic named `claude-haiku-4-5-20251001` as the replacement, and that model's own retirement floor — "not sooner than October 15, 2026" — **passed two days before this report's date**. The real successor is Claude Haiku 5.5, which is cheaper, has a 1M window, supports extended thinking and effort settings, scores **43 on the AA Intelligence Index against this model's 9**, and is committed to availability until at least 2027-10-07. Second, **the AA-LCR 27% is the finding to remember**: a 200K context window on a cheap fast model is a capacity spec, and this is the cleanest available demonstration that it was not a quality claim.
