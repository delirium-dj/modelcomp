## Model card

- **Name:** LongCat 2.5 Preview (available as the `$0` Zen/Go tier `longcat-2.5-preview-free`)
- **Short description:** Meituan's follow-up to its open-source LongCat-2.0 flagship: a closed-weight, multimodal (image-input) reasoning model for coding and agent workflows with a native 1M context. It is not an open-weights release — unlike LongCat-2.0 it shipped with no technical write-up, no MIT weights and no vendor benchmark table, so nearly all public evidence is third-party.
- **Provider / access:** Meituan first-party LongCat API platform (`https://longcat.ai/platform/`), model ID `LongCat-2.5-Preview`, offering both an **OpenAI-compatible Chat Completions** endpoint and an **Anthropic-compatible Messages** endpoint with a `thinking` toggle; canonical third-party ID `meituan/longcat-2.5-preview` (Blackbox AI, NanoGPT, Vercel AI Gateway per CloudPrice); OpenCode Zen and OpenCode Go both expose the free ID `meituan/longcat-2.5-preview-free` at `https://opencode.ai/inference/v1/chat/completions`. Documented integrations include Claude Code, Codex, OpenCode, Cline, Kilo Code, OpenClaw and Hermes Agent.
- **Release / knowledge:** Released 2026-09-25 (LongCat API platform changelog version 2026-09-25; models.dev); CloudPrice and Blackbox date it 2026-09-26 and TechNode covered it 2026-09-30. No knowledge-cutoff date published.
- **Context window:** **1,048,576 tokens** (not the rounded 1,000,000 first reported); maximum output **131,072** tokens (128K). Re-verified 2026-10-13 from Vercel AI Gateway's model page, which states both figures exactly, alongside models.dev, CloudPrice, Blackbox AI, NanoGPT and the LongCat quick start — all agree.
- **Modalities:** **Text and image input, text output.** Re-verified 2026-10-13 against Vercel AI Gateway ("support for text and image inputs"), models.dev ("image understanding"), CloudPrice (Input Modalities: Image) and Blackbox AI (`text, image` in, `text` out). Reasoning: yes — optional extended thinking with interleaved reasoning traces; native tool calling and structured outputs supported; temperature controllable. No audio input, no non-text output.
  > **Conflict recorded and adjudicated:** creativeainews.com (2026-09-25) describes the launch as offering "image **and video** input". Four independent provider catalogues (Vercel AI Gateway, models.dev, CloudPrice, Blackbox AI) list **text and image only**, and none mentions video. One secondary blog against four provider records — **image-only is the finding**, and video is not credited anywhere in the scoring below. Documentation caveat from the first pass still stands: the published chat-completions reference still types `content` as a plain string and shows no image payload, so the image path is documented in the changelog but not yet in the API reference — a docs gap, not evidence the capability is absent.
- **Pricing (as of 2026-10-13):** Free tier on OpenCode Zen and OpenCode Go at `$0.00` input / `$0.00` output per 1M (models.dev, both providers). **New this pass — the free tier's data terms are now documented, and they are favourable:** OpenCode's Zen privacy section states that *LongCat 2.5 Preview Free's provider follows a zero-retention policy and does not use your data for model training*, and the model is **absent from the privacy exception list** (Big Pickle, Cat Jam Free, Exo Free, the MiMo/Ling/Nemotron free routes and Muse Spark 1.3 Contributor Free are all named as exceptions — LongCat is not). The 2026-09-30 report flagged this as "not documented in any source found"; that gap is now closed. Meituan first-party per 1M: standard `$0.75` uncached input / `$0.015` cached / `$2.95` output, with a limited-time promotional rate of `$0.30` / `$0.006` / `$1.20` (that promo figure is identical to MiniMax M3's list price, not uniquely cheap). Meituan also granted 5M free tokens to existing users at launch. NanoGPT's auto-routed rate is `$0.75` / `$2.95` / `$0.015`.
- **Architecture:** Proprietary for 2.5 — **1.6T total / ~48B active MoE**, independently confirmed 2026-10-13 by BenchmarkList, which describes it as a "natively multimodal mixture-of-experts with 1.6 trillion total and about 48B active parameters". These are the same scale figures published for LongCat-2.0, so 2.5 is not a parameter-count or context-length jump. No 2.5 weights are published on Hugging Face; LongCat-2.0's MIT open-weight status must not be assumed for 2.5. BenchmarkList adds that 2.5 is **API-only for now**.

### Raw benchmarks found

> **Status unchanged and re-confirmed on 2026-10-13: Meituan has still published no benchmark for this model.** Orcarouter's second look (published 2026-10-12) states it plainly — "no eval table in the documentation, no comparison chart in the changelog, no score on the pricing page, and no release blog post to carry one" — and adds a warning this report follows: **Artificial Analysis, which does measure the LongCat line (it carries LongCat 2.0 and LongCat Flash Lite), had no LongCat 2.5 entry as of 2026-10-13.** OpenVibeEval's leaderboard (updated 2026-10-03) independently shows LongCat 2.5 Preview's Artificial Analysis Coding, Intelligence and Agentic columns as "—" (a dash meaning "not yet listed on Artificial Analysis"), and BenchmarkList carries a pricing row and nothing else. **All measured numbers below are therefore third-party, and all three harnesses that produced them are coding harnesses rather than benchmark suites.**

Coding / agentic — **run #1**, AI Coding Daily LLM Coding Leaderboard, evaluated 2026-09-28 with the **OpenCode** harness:

- **44.25 / 60** total points (73.75% of available), average time per prompt **16:50**, average cost `N/A` (tested on a subscription, not per-token API billing), rank **#34** on that leaderboard. This scores a model-and-harness configuration, not the bare model.
- Per-project breakdown: Laravel Code Quality **16.98 / 20** (84.9%); React-TS Code Quality **16.67 / 20** (83.4%); Bank Feed (Dart/Flutter) **4 / 5**; CSV Import (PHP) **3 / 5**; Offline Sync (PHP) **2.7 / 5**; Shipping Quotes (Go) **0.9 / 5** (18%).
- Same-leaderboard context for scale: Opus 5.5 (High) 57.83/60, GPT-6.1-Sol (Medium) 57.3/60, Qwen 3.8 27B (Xhigh) 45.05/60, Muse Spark 1.3 (Xhigh) 45.22/60, GLM-5.3-Flash (Max) 42.82/60.

Coding / agentic — **run #2 (new this pass)**, OpenVibeEval, an independent community benchmark of single-file frontend builds scored by an **axe-core accessibility formula** with sandboxed live previews; **8 of 8 runs scored**, all on 2026-09-27 through the OpenCode harness:

- **Average accessibility 65 / 100 raw; 70 / 100 after the site's sample-size adjustment; rank #29 of 42 models.** Site last updated 2026-10-03.
- Individual runs: Digital Garden **100/100**; Web Audio Synthesizer & Step Sequencer **100/100**; Retro Arcade Game & Physics Engine **93/100**; Mini Vector Drawing Canvas Tool **70/100**; Interactive Analytics Dashboard **49/100**; High-Density Crypto Trading Terminal **48/100**; CodeSense Landing Page **35/100**; Scroll-Driven Storytelling Page **28/100**. Spread 28–100, **±25** standard deviation.
- Site-reported category means: strength **Dashboard 48.5/100 (n=2)**; weakness **Marketing 31.5/100 (n=2)**.
- **Independent field context (new):** frontier models sit at **85–86** (GPT-6 Astra 85 adjusted / 96 raw ±4; DeepSeek V4.1 Flash 85 / 94 ±8; Qwen 3.8 27B 84 / 94 ±7); the middle band is 72–78 (Kimi K3 75, Grok 4.6 73, GLM-5.2 73, Gemini 3.8 Flash 74, Ling 3.1 Flash 74); the bottom is 61–67 (MiMo V2.6 Pro 62, MiMo V2.5 Pro 61, Muse Spark 1.2 65, Step 3.7 Flash 66, Grok 4.5 67). **LongCat 2.5 Preview's 70 sits immediately below the middle band and above the entire MiMo/Muse/Grok-cheap tier.**
- **Direct predecessor comparison, same harness, same run count (new):** **LongCat 2.0 = 71/100 adjusted (68 raw ±21, n=8), rank #28 — versus LongCat 2.5 Preview's 70 (65 raw ±25, n=8).** On this independent frontend harness the 2.5 Preview is **statistically indistinguishable from, and nominally one point below, its own predecessor.** That is a direct check on Meituan's "superior" positioning claim, and it does not support it on this axis.

> **Conflicting result found, evaluated and REJECTED.** APIVALE (a token reseller, not Meituan and not an independent lab) published **"SWE-bench Lite 88.6%"** for "LongCat 2.5 API", tabulated against Claude Sonnet 5 at 92.4%, GLM-5.3 Flash 88.2%, Qwen 3.7 Max 87.2% and DeepSeek V4 Flash 85.4%, at a "$0.20/1M APIVALE flat" price. **This figure is not used anywhere in the scoring below**, for five independent reasons: (1) it is **SWE-bench Lite**, a weaker subset, not the SWE-bench Verified or SWE-bench Pro used as reference points elsewhere in this dataset; (2) APIVALE's own quoted price of **$0.20/1M contradicts Meituan's published promotional rate of $0.30/1M**, which is positive evidence the gateway was routing to a different or cheaper backend and not measuring Meituan's 2.5 Preview; (3) no harness, date, methodology or run logs are given; (4) it is contradicted by every primary-adjacent check — Meituan published nothing, Artificial Analysis has no entry as of 2026-10-13, OpenVibeEval's external-benchmark columns are all dashes, and BenchmarkList lists pricing only; (5) it is **internally implausible**: an 88.6% SWE-bench Lite would place this model near Claude Sonnet 5, yet on the one independent capability harness it has actually been measured on it scores 70 while **GLM-5.3 Flash scores 76**. A reseller's marketing table is not a benchmark result, and this one is the exact failure mode Orcarouter warned about — a number in the wild that does not trace back to a Meituan source.

Tool use:

- Tool calling and structured outputs are verified as supported capabilities (models.dev, Blackbox AI, NanoGPT, Vercel AI Gateway), and the two runs above required multi-step file-editing and shell tool use across **fourteen separate agentic sessions** in total (six projects plus eight frontend builds).
- **Still no dedicated tool-use benchmark** (Terminal-Bench, τ-bench, GDPval-AA, Toolathlon, Claw-Eval): **no verified public score found**. Note that the OpenVibeEval spread of 28–100 with ±25 deviation is itself a reliability signal: the same model and harness produced two perfect builds and one 28/100 on the same day.

Reasoning / knowledge:

- Configurable reasoning effort with interleaved reasoning traces is verified (TensorFeed.ai, models.dev, Blackbox `reasoning` / `include_reasoning`, Vercel AI Gateway "optional thinking").
- GPQA Diamond, HLE, CritPt, AA-LCR, Artificial Analysis Intelligence Index: **no verified public score found** for this exact model. **Re-confirmed against a live source on 2026-10-13:** Artificial Analysis's LongCat coverage carries LongCat 2.0 and LongCat Flash Lite and **no 2.5 entry**, and OpenVibeEval's Intelligence column for this model is a dash. Orcarouter's caution is adopted wholesale: any LongCat 2.5 number circulating publicly should first be checked for whether it is actually a LongCat 2.0 result relabelled — and LongCat 2.0's own Artificial Analysis figures are Intelligence Index 19, Coding Index 45, Agentic Index 14, GPQA 78%, SciCode 36%, HLE 34%, LCR 65%, τ³-Banking 13%, Terminal-Bench 50%, Terminal-Bench 4.0 0%. **None of those is carried into this report.**

Long context:

- 1,048,576-token window verified from provider metadata (Vercel AI Gateway states the exact figure). Long-context retrieval measurement: **still no verified public score found**, now on a 17-day-old finding. Orcarouter's 2026-09-26 comparison made this the central gap and its 2026-10-12 re-check did not close it ("LongCat-2.5-Preview has no equivalent number, from anyone", against GLM-5.2's Artificial Analysis Long-Context Recall of 78.33). Note the irony worth stating plainly: a 1M window with no recall measurement at any depth is a window size, not a context capability.

Multimodal:

- Native image input verified (four provider catalogues). No image-specific benchmark (MMMU, CharXiv, MathVista): **no verified public score found**. BenchmarkList's summary of Meituan's own positioning names "new image understanding" as a claim with no number attached.
- **Caveat that belongs with this score:** OpenVibeEval's eight runs are all HTML/CSS/JS frontend artifacts scored by axe-core — an accessibility audit of generated markup, not a visual-understanding test. It is evidence the model produces usable front-end output; it is **not** evidence it can *read* an image.

Predecessor (LongCat-2.0, **a different model** — do not attribute these to 2.5 Preview): Meituan self-reported SWE-bench Pro 59.5, SWE-bench Multilingual 77.3, Terminal-Bench 2.1 70.8, RWSearch 78.8, FORTE 73.2, BrowseComp 79.9, GPQA Diamond 88.9; plus Artificial Analysis Intelligence Index 19, Coding Index 45, Agentic Index 14, SciCode 36%, HLE 34%, LCR 65%, τ³-Banking 13%, Terminal-Bench 50%, Terminal-Bench 4.0 0%.

### Normalized scores (1–100)

- **Tool use: 68/100.** Unchanged. Tool calling, structured outputs and interleaved reasoning are verified, and fourteen independent agentic sessions across two harnesses now demonstrate multi-step file-editing and shell use in production configurations. It is still capped by the complete absence of a dedicated tool benchmark — no Terminal-Bench, τ-bench, GDPval-AA, Toolathlon or Claw-Eval figure exists to place it in the methodology's frontier (TB2.1 ≈ 88%+) or mid (TB2.1 45–60%) bands. The ±25 OpenVibeEval deviation across eight same-day runs is the reason this did not move upward despite more evidence than before.
- **Reasoning: 60/100.** Unchanged, and deliberately so. Configurable reasoning effort and interleaved traces are verified, but **zero reasoning benchmarks exist for this exact model** — no GPQA, HLE, CritPt, LCR or Intelligence Index — and this was re-confirmed against two live sources on 2026-10-13 rather than merely repeated from September. Scored at the methodology's mid band on capability evidence alone. The predecessor's GPQA-D 88.9 and its Intelligence Index 19 both belong to LongCat-2.0; the first is wildly higher and the second wildly lower than anything here, which is exactly why the lineage cannot be inferred from the family name.
- **Context window: 95/100.** Unchanged. 1,048,576 verified tokens — now stated exactly rather than rounded — sits in the ≥1M band (95–100). It is not 100 because the methodology reserves that for ≥98% measured retrieval at 512K+, and as of 2026-10-13 **no recall test at any depth has been published for this model** by Meituan, by Artificial Analysis, or by any of the four third-party harnesses.
- **Multimodal: 65/100.** Unchanged. Verified native image input with text-only output places it in the +image band (60–70). No audio input, no non-text output, and — following the adjudication above — **no video input credited**, since four provider catalogues say image-only and one secondary blog says otherwise. The evidence gap is unchanged and total: no MMMU, CharXiv or MathVista figure, and the frontend-artifact scores above measure generated markup, not visual comprehension.
- **Coding: 71/100.** *Revised up from 70.* The second independent harness is the reason. 44.25/60 (73.75%) on a six-project real-code rubric, plus **65/100 raw and 70/100 adjusted on OpenVibeEval's eight-prompt axe-core suite, rank #29 of 42** — a genuine second measurement rather than a restatement of the first. Its PHP/TypeScript results are strong (Laravel 84.9%, React-TS 83.4%) and its Go project is weak (18%); on the frontend suite it shows real peaks (two 100/100, one 93/100) and real collapses (28/100, 35/100). It still cannot be tested against the frontier reference (DeepSWE 74%+, SciCode 55%+) because no SWE-bench, Terminal-Bench, LiveCodeBench or SciCode figure exists for it, and the one credible relative signal available — **rank #29, one point below its own predecessor** — argues against scoring it into the frontier band on the strength of Meituan's positioning language.
- **Cost efficiency: 100/100.** Unchanged. The evaluated tier is the OpenCode Zen / OpenCode Go free route `meituan/longcat-2.5-preview-free` at `$0.00` input / `$0.00` output per 1M — `$0 = 100` under the methodology. **The privacy caveat that sat on this line in the previous version is withdrawn on evidence:** OpenCode's Zen documentation now states that this route's provider follows a zero-retention policy and does not use your data for model training, and names the model nowhere in its list of training-data exceptions. Paid fallback is Meituan's promotional `$0.30`/`$1.20`, which would land near 92, with the standard rate at `$0.75`/`$2.95` landing near 88; APIVALE's claimed `$0.20` flat is a reseller figure not used here.
- **Overall Score: 72/100.** (68 + 60 + 95 + 65 + 71) / 5 = 71.8 → **72**. *Up one point, and the more useful change is the evidence base: the quality picture now rests on two independent harnesses instead of one, and the free tier's data terms are documented rather than unknown.* Best fit unchanged in substance — a free, zero-retention 1M-context image-capable workhorse for multi-file coding and agent workflows — with one qualification sharpened: it is **not** measurably better than its own LongCat-2.0 predecessor on independent coding evidence, so treat "2.5" as a refresh (1M context plus an image path at $0) rather than a capability jump, and treat every quality score except context as provisional until Meituan or a proper lab publishes a table.
