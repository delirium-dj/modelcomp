> **Version note (critical, now fact rather than forecast):** this report covers the **GA `qwen3-max`** released 2025-09-23. **The model has now been shut down.** The first pass reported a *future* retirement date of 2026-10-10; as of this pass that date has passed and the shutdown is confirmed executed on every tracked host. Distinct, separately-listed versions are not folded in here: **Qwen3-Max-Preview** and **qwen3-max-2025-09-23**, **Qwen3 Max Thinking** (itself deprecated, AA now points to Qwen3.6 Max Preview), and the **Qwen3.6 / 3.7 / 3.8 Max** generations, which have their own folders.

## Model card

- **Name:** Qwen3 Max
- **Short description:** Alibaba's former **flagship Qwen3 closed-weights model** — over **1 trillion parameters**, GA'd **2025-09-23** after a 2025-09-05 preview, and positioned by Alibaba as rivalling the best OpenAI and Google offerings, with specialized upgrades in **agent programming and tool invocation**. Top use case was enterprise agents, tool invocation, structured/JSON output, RAG and multilingual (100+ languages) general work. **Retired: inference discontinued, API calls now fail. Successor on Alibaba Cloud is `qwen3.7-max`; on Novita the replacement is `qwen/qwen3.8-max`; OpenRouter recommends `qwen3.8-max (0902)`.**
- **Provider / access:** **No provider currently serves this model.** Alibaba Cloud Model Studio retired `qwen3-max`, `qwen3-max-2025-09-23` and `qwen3-max-2026-01-23` on **2026-10-10 00:00 (UTC+8)**; NovitaAI retired `qwen/qwen3-max` on **2026-10-09**; OpenRouter marked `qwen/qwen3-max` deprecated on **2026-10-09**; Undominated.ai delisted it on **2026-10-12**. ModelClock (updated 2026-10-14) records zero upcoming shutdown dates and the three completed Alibaba shutdowns; ModelCap (2026-10-17 21:29 UTC) reports **"Providers: 0 endpoints — No provider is currently serving this model."** Historically it ran on Alibaba Cloud / DashScope, OpenRouter, DeepInfra, Vercel AI Gateway, Novita, Eden AI, and ~15 gateways, on OpenAI-compatible Chat Completions **and** Responses APIs. **Closed weights — not open source.** No OpenCode Zen ID found.
- **Release / knowledge:** Preview 2025-09-05; **GA 2025-09-23**. **Knowledge cutoff: still unresolved — and the two sources have swapped.** OpenRouter's model card states **"Knowledge Cutoff: Jun 2025"**; llm.ing, llmpricing.dev and 17NAS all state **2025-04**. The first pass recorded CloudPrice 2025-06-30 vs ModelBench 2025-04. Three readings now exist and none is corroborated; no scoring dimension in this report depends on the cutoff, so it is recorded and left open.
- **IDs:** `qwen3-max`, `qwen3-max-2025-09-23`, `qwen3-max-2026-01-23` (all retired); `qwen/qwen3-max` (OpenRouter, deprecated)
- **Context window:** **262,144 tokens** on Alibaba Cloud (ModelBench, llm.ing, llmpricing.dev, ModelCap, OpenRouter's provider matrix). **Conflict:** OpenRouter's model header says **256K**, and ModelCap/OpenRouter now report **0 live providers**, so no window is actually servable. Max output **65,536** (raised from 32,768 in a 2026-07-28 catalog revision; the Coding Plan channel still showed 32,768). *Discrepancy flagged and still unresolved:* benchlm.ai's model header listed the context as "1M" in the first pass — no provider or first-party source has ever supported that.
- **Modalities:** **Text in → text out only**, triple-confirmed (CloudPrice 1 of 5 modalities, ModelBench "Vision input: No / Attachments: No", QwenCloud). Reasoning: the base `qwen3-max` was the **non-thinking** variant; reasoning lived in the separately-versioned **Qwen3 Max Thinking**. Tool calls / function calling: yes. Structured outputs: yes. Built-in tools: `search_strategy:agent` / `agent_max`, web search, web extractor, code interpreter, prefix completion, context caching, batch. Rate limits were 1M TPM / 600 RPM. LMArena evaluated the snapshot `qwen3-max-2025-09-23`.
- **Pricing (as of 2026-10-17, last-known rates — no route is purchasable):** **Alibaba International $0.780 in / $3.90 out**, cache read $0.156, with **tiered escalation past 32K ($1.56/$7.80) and past 128K ($1.95/$9.75)** recorded by Undominated.ai on 2026-10-06; batch $0.60/$3.00. **Conflict on the official rate:** llmpricing.dev, 17NAS and swen.live all record Alibaba's official list price as **$1.20 / $6.00**; llmbase.ai-era trackers and llm.ing record **$0.78 / $3.90** as the OpenRouter route. Both are recorded; the **$0.78/$3.90 tiered** figure is preferred because it is the only one that distinguishes prompt-length tiers, matching the platform's published tiered-pricing rule. Third-party gateways undercut hard: **Ofox and OrcaRouter $0.36/$1.43**, Merge Gateway $0.36/$1.43, AIHubMix $0.45/$2.70 (tiered), LLM Gateway $0.85/$3.38. Alibaba (China) Official $0.36 tiered (>32K: $0.57; >128K: $1.00) against $1.43 output. novita was the dearest at ~$2.11/$8.45. **All of these are now historical.**
- **Architecture:** proprietary closed weights. **>1 trillion total parameters**, MoE. **Active-parameter count never disclosed by Alibaba** — no total/active split is claimed here.

### Normalized scores (1–100)

- **Tool use: 72/100.** **Unchanged — deliberately.** The evidence that could move this dimension has stopped existing: the model is unservable, AA has deprecated it, and **no new agentic benchmark can now be run against it**. What survives is the frozen record — **τ²-bench 74.3%** and **TAU2 ~70%** are genuine mid-to-upper agentic-tool numbers, Alibaba shipped first-class agent tooling (`search_strategy:agent_max`, function calling, structured outputs) that n8n's workflow suite rates **Tool Use 64 (#2)**, and LMArena coding 1,473 (#120/411) is a real independent human-preference row. Held down by **Terminal-Bench Hard ~20%** (itself a rounded CloudPrice figure), **AA-IFBench 44.1%**, and the permanent absence of GDPval-AA, Tau3, Claw-Eval and MCP-Atlas. The LMArena 1,473 coding Elo is *new evidence that arrived this pass* and it supports the existing score rather than moving it — 1,473 is mid-pack, and 1,423 overall is mid-pack.
- **Reasoning: 64/100.** **Unchanged — deliberately, with one new independent row.** **LMArena text 1,423.4 (#126 of 416)** is the first genuinely independent, crowd-sourced evaluation of this model and it lands squarely in the mid-pack that the other rows already implied. **Epoch Capabilities Index 142.4 (#101 of 270)** points the same way. Those two new rows *confirm* the first pass's read rather than overturning it, and no row capable of moving the score exists any more. Still capped by **HLE 11.9%**, **CritPt 0.0%**, an **AA Intelligence Index of ~16 (estimated, down from three-way disagreement to a single deprecated estimate)**, **AA-LCR 50.0%**, and above all by the **AA-Omniscience Hallucination Rate of 89.9%** with 24.4% accuracy — a 1T-parameter model that states falsehoods roughly 9 times in 10 on the abstention probe should not be trusted for factual or long-horizon autonomous work without verification at every step.
- **Context window: 76/100.** **Unchanged, with the caveat sharpened.** The **262,144** figure is still the correct historical spec, and it still sits in the 200K–500K band above the 200K baseline. But this pass establishes that **no provider is serving the model at all**, so the window is a specification rather than a capability anyone can currently exercise; OpenRouter's header says 256K and benchlm's unsupported "1M" claim still stands unresolved. Held at 76 — not raised, not lowered — because the reasoning (a real 262K class window with one mediocre retrieval measurement) is unchanged and the shutdown affects availability, which is scored in Cost efficiency, not here.
- **Multimodal: 15/100.** **Text-only**, triple-confirmed. Floor score by methodology. Qwen's vision line is a separate model family (`qwen3-vl-*`, `qwen2.5-vl-*`) with its own folders.
- **Coding: 62/100.** **Unchanged — deliberately.** The coding evidence set is frozen exactly where the first pass left it: **LiveCodeBench ~80% (#38)** is the one good row and **Design Arena Website 1,123** is credible and has now been refreshed across eight Design Arena boards to 2026-10-08 (all between 1,010 and 1,134 — mid-to-low pack on every one). But **Vibe Code Bench 3.51%** is near-total failure on app generation, **SciCode ~40% (#113)** is weak, the Coding Index is irreconcilable at **26.4 vs 65.1**, LiveCodeBench itself disagrees between aggregators (**~80% vs 69.0%** on different versions), and there is **no SWE-bench, no SWE-bench Pro and no DeepSWE number — and none can ever now be published.** For a model marketed for coding agents, being shut down without ever publishing a SWE-bench score is a serious and now permanent evidence gap. 62 stands.
- **Cost efficiency: 45/100** (was 90). **Lowered on availability, which is a cost fact, not a capability one.** The arithmetic the methodology asks for — inverse pricing on the evaluated tier — is no longer performable because **there is no tier**: ModelCap reports **0 serving endpoints** as of 2026-10-17, ModelClock shows the three Alibaba routes shut down with no successor dates pending, OpenRouter deprecated the route on 2026-10-09, and Undominated.ai delisted it on 2026-10-12. Last-known pricing was genuinely good (**$0.36–$0.78 in / $1.43–$3.90 out** on gateways, batch at $0.60/$3.00), and it is recorded above — but a price for a model that cannot be called is not a cost. 45 credits the historically cheap tariff and MIT-free closed weights' successor licensing environment while marking the tier as unobtainable. **Cost is excluded from Overall, so this change does not move the score.**
- **Overall Score: 58/100.** `(72 + 64 + 76 + 15 + 62) / 5 = 289 / 5 = 57.8 → 58`. **Unchanged, and that is the honest result.** Two genuinely new independent measurements arrived this pass — **LMArena text 1,423.4 (#126/416)** and **Epoch Capabilities Index 142.4 (#101/270)** — and both confirm the first pass's mid-pack read rather than contradicting it, so no quality dimension was warranted a change. Best fit: **nothing, going forward.** This was an enterprise agent and tool-invocation model for Alibaba Cloud with batch and caching enabled; that decision is now closed. Migration target is **`qwen3.7-max`** (AA Intelligence Index 29.5, ~2× this model's 16, 1M context, ~206 tok/s) or, per OpenRouter, **`qwen3.8-max (0902)`** (AA 45, 984k context). Any residual use should carry two hard warnings carried over unchanged: the **89.9% hallucination rate**, and the fact that it was **retired precisely because Alibaba's own newer generations dominate it**.
