## Model card

- **Name:** Qwen3 Max (API id `qwen3-max`; curated id `opencode/qwen3-max`)
- **Short description:** Alibaba's **Qwen3-generation proprietary flagship** (the generation *before* the current 3.5/3.6/3.7/3.8 Max line), sold as a scaled-up general model for coding agents, complex reasoning and tool use. Two behavioural variants shipped at launch: **Qwen3-Max-Instruct** (direct answers, no thinking) and **Qwen3-Max-Thinking** (extended chain-of-thought). The curated registry entry describes it as having "thinking mode", but Artificial Analysis tracks the `qwen3-max` ID as the **non-reasoning** variant and lists `Qwen3 Max Thinking` as a separate, newer model.
- **Provider / access:** **Proprietary** — weights are not published and Alibaba has not disclosed the parameter count or model size. Available through Alibaba's own API (Model Studio) and, per Artificial Analysis, through **2 measured providers**. `noFreeId: true` in the curated registry: there is no free hosted tier for this ID.
- **Release / knowledge:** launched **2025-09-23** (Artificial Analysis: "released September 2025", FAQ gives 23 September 2025). **Status flag:** Artificial Analysis carries an explicit **deprecation banner** on this page — "This model is deprecated … Alibaba has launched a newer release, Qwen3 Max Thinking. We suggest considering it instead" — and AA now only continues benchmarking the default 10 K-input workload; every other workload figure is historical and no longer updated. The registry therefore contains a superseded flagship: Qwen3.5-Max → 3.6-Max-Preview → 3.7-Max → 3.8-Max all post-date it.
- **IDs:** `qwen3-max` (Alibaba Model Studio / OpenRouter), `opencode/qwen3-max` (curated). BenchLM carries the ID at `benchlm.ai/models/qwen3-max`. Artificial Analysis carries it at `artificialanalysis.ai/models/qwen3-max` (deprecated page; reasoning sibling listed separately).
- **Context window:** **262,144 tokens total** — the curated `meta.json` states "262,144 total (65,536 out)" and Artificial Analysis independently prints **262k** (FAQ: "260k"), so 256 K-class is the verified figure. **Conflict flag:** BenchLM's row for this ID lists the **context window as 1M**. Two of three sources (vendor-curated + AA) say 262 K, so the 1 M claim is recorded as **unverified** and scored against 262 K; if 1 M were confirmed for this ID the dimension would move up roughly 20 points. Max output 65,536 (> 64 K, so no output-length caveat).
- **Modalities:** **text in / text out only.** Artificial Analysis states it plainly: supports text input, supports text output, "**does not support image input**", "is not multimodal". This matches the curated `meta.json` ("Text in/out") exactly. Vision for the Qwen3 line lives in separate `-VL` / omni checkpoints, not in this ID.
- **Pricing (as of 2026-10-07):** **$1.20 / $6.00 per 1M input/output tokens**, verified — the curated `pricingNote` and Artificial Analysis agree to the cent. AA's blended rate (7:2:1 cache-hit/input/output) is **$1.68 per 1M tokens**; within its class the input price beats the median ($1.75) and the output price beats the median ($9.00), so AA labels it "moderately priced" but still "**somewhat expensive**" for a model of its intelligence tier. Alibaba's own sheet tiers the price above 32 K/128 K prompt lengths (per the curated note); no cache-hit price, no cost-per-task figure and no verbosity figure are published for this ID ("Not publicly available" / "Unknown out of 4 units").
- **Architecture:** undisclosed dense/MoE details — proprietary, no parameter count published. AA's technical-spec block: **Reasoning: No** (non-reasoning page), input text, output text, 262k context. Measured serving performance on Alibaba's API: **59.4 output tokens/s** (class median 73.3 — "slower than average") and **TTFT 2.16 s** (class median 1.13 s — "higher end"), i.e. a slow, mid-priced flagship.
- **Identity flags:** (1) the folder slug **`qwen3-max` breaks the registry's dotted-version convention** (`qwen-3.5-max`, `qwen-3.7-max`, `qwen-3.8-max`); disk audit confirms **no** `model/qwen-3-max/` twin exists, so this is the sole folder for the ID and not a rule-7 duplicate — but the naming inconsistency is worth normalising at the orchestrator level. (2) It is a **different model generation** from `model/qwen-3.5-plus/`, `model/qwen-3.7-max/`, `model/qwen-3.8-max/`, etc.; scores must never be inherited across that boundary. (3) The **Instruct vs Thinking** split means single published rows may describe either variant; rows below are attributed to whichever variant the source names.

### Normalized scores (1–100)

- **Tool use: 60/100.** τ²-bench **74.3 %** is the strongest agentic row for this ID and sits comfortably in the methodology's mid-to-upper band, with Gert Labs **43.74 %** corroborating real enterprise tool competence; that pairing is what keeps this dimension off the floor. But it is nearly the *whole* evidence base — no Terminal-Bench, τ³, Toolathlon, Claw-Eval, AutomationBench or GDPval row exists for `qwen3-max`, and Artificial Analysis has stopped updating this ID's workloads (deprecation banner), so the number is effectively frozen at 2025-era serving conditions. Missing-harness penalty applied, no fabricated score.
- **Reasoning: 55/100.** GPQA Diamond **76.4 %** is solidly mid-tier and AA-LCR **50.0 %** is respectable for a 262 K window; HLE **11.9 %** is low, and the AA Intelligence Index of **16** lands *below* the methodology's 20–35 mid band. Two further deductions: the Index is **estimated** ("independent evaluation forthcoming"), so it is not a completed measurement; and knowledge reliability is the worst signal in the set — AA-Omniscience index **−43.5** with **24.4 %** accuracy and **89.9 %** hallucination means the model is wrong far more often than right when it asserts a fact, and more negative than the comparable text-only mid-tier peers scored elsewhere in this registry. Instruction following at **44.1 %** (AA-IFBench) reinforces the mid-tier placement.
- **Context window: 72/100.** **262,144 tokens**, verified by two of three sources (curated + AA) against the 200 K–500 K tier (65–84), where 200 K anchors ≈ 70; 65,536 max output clears the 64 K threshold, so no output caveat. It is not pushed higher because there is **no MRCR / AI-Needle retrieval measurement** for this ID (the tier's upper scores require demonstrated retrieval at long input), and because the **1 M claim on BenchLM remains unverified** — that conflict is flagged above rather than rewarded.
- **Multimodal: 15/100.** **Text-only, confirmed by the vendor-independent source**: AA states the model accepts text and emits text, does not take images, and is not multimodal — matching the curated "Text in/out". That is the methodology's 10–20 band with nothing to lift it: no image, no PDF, no audio, no video, no generated output. Vision-capable Qwen3 checkpoints exist but are different IDs.
- **Coding: 52/100.** The headline is **SWE-bench Verified 69.6** (Alibaba, Qwen3-Max-Instruct) — credible for its generation but *below* the current peer median for coding agents (~77 on the same harness, e.g. MAI-Code-1.1-Flash 72.6 and the Qwen3.6-Plus 73.4/78.8 family figures recorded elsewhere), and it is a **vendor number with no independent confirmation** for this ID. Against that, the one genuinely agentic coding measurement that does exist is poor: **Vibe Code Bench 3.51 %** (Vals AI), which is the "Vibe < 10 %" signature of a model that cannot drive a real editing loop, and Design Arena Website **1125** is mid-pack. No LiveCodeBench, DeepSWE, SciCode or Coding-Index row is published for the ID despite the launch claim of rivalling top models on LiveCodeBench. Judged at the bottom of the mid band, with the evidence gap stated.
- **Cost efficiency: 83/100.** **$1.20 / $6.00** per 1M in/out, verified against the curated sheet, is cheaper than its class medians ($1.75 / $9.00) but lands just under the methodology's $1.25/$4.25 ≈ 88 anchor because output is pricier, and the blended figure AA computes is **$1.68 per 1M**. Withheld further: **no** cache-hit price, cost-per-Intelligence-Index-task or verbosity figure is published ("Unknown out of 4 units"), so the real-workload price is unmeasured; serving is slow (**59.4 tok/s**, TTFT **2.16 s**), which raises wall-clock cost per task; Alibaba tiers the price upward above 32 K/128 K prompts; and `noFreeId` means no zero-cost evaluation path.
- **Overall Score: 51/100.** Mean of the five quality dimensions (60 + 55 + 72 + 15 + 52) / 5 = 254 / 5 = 50.8 → 51; Cost excluded per `RULES.md`. Best fit: legacy **general-purpose text completions and light tool loops** where an existing `qwen3-max` integration must keep running, and single-pass Q&A over ~200 K-token text — with the explicit caveats that it is **deprecated and superseded** (AA recommends Qwen3 Max Thinking; four later Max generations exist in this registry), **slow**, **text-only**, **hallucination-prone on factual recall (89.9 %)**, and **not a coding-agent choice** at 3.51 % on Vibe Code Bench. For anything new, a current Max or a dedicated coding model is the correct pick.
