## Model card

- **Name:** Claude Fable 5 (Claude API id `claude-fable-5`; `anthropic.claude-fable-5` on Amazon Bedrock; `claude-fable-5` on Google Cloud, Microsoft Foundry and Claude Platform on AWS)
- **Short description:** Anthropic's **first broadly available "Mythos-class" model** — the tier *above* Opus, positioned for long-horizon agentic work, demanding reasoning and software engineering. **Lifecycle flag:** the vendor docs page opens with **"Legacy. Released June 9, 2026 … you should consider migrating to Claude Fable 5.1"**; status is *Active (legacy)* with retirement **not sooner than 2027-06-09**. Artificial Analysis carries the matching **deprecation banner** ("This model is deprecated … Anthropic has launched a newer release, Claude Fable 5.1"). So this registry entry is a superseded flagship, still live but no longer the frontier of its own line.
- **Provider / access:** **Proprietary**, served on all five Anthropic partner platforms. No weights, no parameter count disclosed. Available in Claude Code / agent harnesses; no free tier for the API (the curated `meta.json` has no `noFreeId` key at all — see the scaffold flag below, so absence must not be read as "free").
- **Release / knowledge:** released **2026-06-09** (vendor docs + AA "Released June 2026"). **Reliable knowledge cutoff: Jan 2026; training-data cutoff: Jan 2026** — both printed in the vendor spec table, ~5 months of staleness against the current date and ~9 months behind Fable 5.1 (Jun 2026 cutoff).
- **IDs:** `claude-fable-5` (Anthropic), `opencode/claude-fable-5` (curated), BenchLM canonical `benchlm.ai/models/claude-fable`, Artificial Analysis `artificialanalysis.ai/models/claude-fable-5` (page title records the measured configuration as **"Claude Fable 5 (Max, Opus 4.8 Fallback)"**), Vals AI `vals.ai/models/anthropic_claude-fable-5`, OpenRouter `anthropic/claude-fable-5`.
- **Context window:** **1M tokens total, 128K max output** (vendor spec table; AA and BenchLM both list 1M / "1M+"). The 1M figure is ~555 k words on the current tokenizer (the one introduced with Claude Opus 4.7). The 128K synchronous output ceiling is the Messages-API limit; **Fable 5 is not in the batch list that unlocks 300K output** with the `output-300k-2026-03-24` beta header. **Curated conflict:** `meta.json` says "128K total" — that is the *output* cap, not the context window; it under-reports the window by ~8×.
- **Modalities:** **text and images in, text out** (vendor capability table: "Input → output: Text and images → text"; AA: "supports text and image input, outputs text"). No video input, no audio input, no image/audio generation. **Curated conflict:** `meta.json` says "Text in/out", which is wrong on the input side.
- **Pricing (as of 2026-10-07):** **$10 / $50 per 1M input/output tokens** — the most expensive rate in the current Claude lineup (Opus 5.5 $4/$20, Sonnet 5.5 $2/$10, Haiku 5.5 from $0.10/$0.50). Cache reads **$1 / MTok (90 % discount)**, 5-minute cache write **$12.50**, 1-hour cache write **$20**, Batch API **50 % off** input and output. AA: input "expensive, median $2.00", output "expensive, median $10.00", and **$8.75 per Intelligence-Index task** (#110 of 225) — "particularly expensive … when comparing to other models of similar price". **Curated conflict:** `meta.json`'s `pricingNote` is the placeholder string "Standard pricing" — it names no numbers at all.
- **Architecture / inference mode:** undisclosed. **Thinking: Adaptive, always on**, with the API's default **effort = `high`** (the model decides how much to think, steered by the effort parameter rather than a manual `budget_tokens`). Anthropic ships a dedicated **"Refusals and fallback"** mechanism for this model — a safety classifier can refuse and the request can be retried on another Claude model via the `fallbacks` parameter; AA's headline figures are measured on exactly such a configuration ("Max, Opus 4.8 Fallback"), so third-party scores for this ID describe **Fable 5 with an Opus 4.8 safety fallback**, not a bare single-model call.
- **Sibling / identity flags:** (1) **Claude Mythos 5** is the same-spec, same-price model restricted to verified organisations for defensive cybersecurity work (`model/claude-mythos-5.1/` exists in the registry for the newer generation) — shared specs mean benchmark rows are frequently reported for the pair jointly (the system card is titled "Claude Fable 5 and Claude Mythos 5"). (2) `model/claude-fable-5.1/` is the **current** generation with its own entries; nothing may be inherited between them — Fable 5.1 raises the cutoff to Jun 2026 and deepens the cache discount to 97.5 %. (3) **Queue flag:** this folder has an `average.md` but is **absent from `model-queue.md`** (the queue still lists only `90.8 claude-fable-5.1`), i.e. the queue file has not been regenerated since the folder appeared; per `tasks/research-assign.md` rule 3 it was processed as a newly discovered slug, appended last, A-Z. (4) **Scaffold flag:** `meta.json` carries `"scaffolded": true` and a boilerplate `short` ("Claude Fable 5 model evaluation entry.") — all three substantive curated fields (context, modalities, pricing) are contradicted by the vendor page, so this entry needs curation, not just syncing.

### Normalized scores (1–100)

- **Tool use: 88/100.** This is a frontier agentic profile: **τ²-bench 98.5 %** (AA) is near the ceiling of that harness, **GDPval-AA 1747** vendor / **55.6 %** AA-normalized sits at the methodology's ~1750 frontier anchor, **Terminal-Bench 2.1 84.3 %** vendor with **80.5 %** independently reproduced, **OSWorld-Verified 85 %** for computer use, and a broad AA agentic spread (Agentic Index 51.0, Harvey LAB 93.6, EnterpriseOps-Gym 51.1, AnalystAgent 48.8, TB-Hard 62.9). Held back from the top of the band by the harder new-generation signals — **Terminal-Bench 3.0 34.0 %** and **ApprenticeBench 34 %** show long-horizon novelty still bites — plus **no τ³, Toolathlon or Claw-Eval row for this ID** (missing-harness penalty applied, per the contract) and the fact that AA measured it with an Opus 4.8 refusal fallback.
- **Reasoning: 84/100.** GPQA Diamond **92.6 %** (AA) and **93.2 %** (Vals), HLE **55.5 %**, MMLU-Pro **91.5 %**, AA-LCR **82.3 %**, CritPt **28.6 %** and the ARC Prize verified pair **ARC-AGI-1 98.50 % / ARC-AGI-2 89.2 %** place it clearly in the frontier band (the contract's 90–100 gate is GPQA 90+/HLE 40+/Index 60+ — two of three are met). The Intelligence Index of **50** is top-20 of 225 but *below* the 60 frontier anchor, and knowledge reliability is the real deduction: **AA-Omniscience index 43.3 with 65.4 % accuracy but 63.6 % hallucination rate** means roughly two-thirds of its assertions on hard factual questions are wrong — a worse faithfulness signature than its rank implies. IFBench **63.5 %** is competent, not leading.
- **Context window: 96/100.** **1M tokens** confirmed by the vendor spec table, AA and BenchLM — the methodology's ≥1M tier (95–100). It is not a perfect 100 because **no MRCR / AI-Needle retrieval measurement exists for this ID**, and the tier's top score is reserved for demonstrated ≥98 % retrieval at 512K+. Max output **128K** clears the 64K threshold, so no output caveat; note that Fable 5 is excluded from the 300K-output batch beta that some sibling models support, which matters for single-call very-long generations.
- **Multimodal: 70/100.** **Text + image in, text out** — the methodology's +image band (60–70), entered at its top because the document/grounding evidence is real rather than nominal: **OSWorld-Verified 85 %** and **ApprenticeBench 34 %** are screen-grounded agent tasks, and the vendor's **Blueprint-Bench 2 38.6 %** / **OfficeQA Pro 57.9 %** rows are document-and-chart reasoning evaluations. It cannot reach the 75–90 video/PDF band: there is **no video input, no audio input and no generated (image/audio) output** for this ID, and the curated "Text in/out" claim would have scored it 15 — corrected here against the vendor capability table.
- **Coding: 92/100.** The strongest dimension. Against the contract's frontier gates (DeepSWE 74+/TB2.1 85+/SciCode 55+/Coding Index 70+) it clears **SciCode 61.0**, **AA Coding Index 76.5**, and effectively **Terminal-Bench 2.1** (84.3 vendor, 4/10 of a point shy of the 85 anchor), on top of **SWE-bench Verified 95 %** with **independent Vals confirmation at 95.0 %**, **SWE-bench Pro 80 %**, **LiveCodeBench (Vals) 89.8 %**, **CursorBench 70.6/70.5** and **VulcanBench v3 89.5 %**. Deductions: the harder second-wave harnesses are not conquered — **FrontierSWE v2 47.0 %** and **Cognition's FrontierCode 1.1 Main 53.5 %** — and no DeepSWE row exists for the ID, so it sits at the bottom of the frontier band rather than near 100.
- **Cost efficiency: 28/100.** **$10 / $50 per 1M tokens** is more than three times the methodology's $3/$15 ≈ 60 anchor and the highest rate in the Claude lineup; AA ranks it **#110 of 225 on cost** at **$8.75 per Intelligence-Index task**, calling it "particularly expensive … compared to other models of similar price", and its **130M-token** Index run (median 81M) inflates effective spend by roughly 1.6× versus a typical peer, at below-average speed (64.6 tok/s) so wall-clock cost rises too. Mitigations that keep it off the floor: **90 % cache-read discount** ($1/MTok) which is significant precisely for the long-horizon agent loops this model is built for, **50 % Batch API**, and effort control (lowering `effort` from the `high` default cuts reasoning tokens). No free tier is documented.
- **Overall Score: 86/100.** Mean of the five quality dimensions (88 + 84 + 96 + 70 + 92) / 5 = 430 / 5 = 86.0 → 86; Cost excluded per `RULES.md`. Best fit: **high-stakes software engineering and long-horizon agentic work where the per-token premium is irrelevant next to success rate** — repo-level SWE/PR automation (95 % Verified, independently confirmed), terminal+GUI computer use (TB2.1 84.3, OSWorld 85), professional-document and legal/office deliverables (τ² 98.5, Harvey LAB 93.6, GDPval 1747), and 1M-token single-pass analysis of huge codebases or document sets. Explicitly *not* the pick for cost-sensitive volume work (28/100 cost, 63.6 % hallucination on factual recall, no video/audio input), and not the pick for new builds at all: it is **legacy**, its cutoff is **Jan 2026**, and Anthropic and AA both direct users to **Claude Fable 5.1**.
