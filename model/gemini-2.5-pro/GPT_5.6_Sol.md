# Gemini 2.5 Pro — Independent Research Report

## Summary and evidence

Gemini 2.5 Pro is Google's June 2025 stable thinking model for complex code, math, STEM, large datasets, documents, and codebases. It accepts text, images, video, audio, and PDFs; supports Search/Maps grounding, code execution, file search, functions, structured output, and URL context; and provides **1,048,576 input tokens** with **65,536 output tokens**.

Source: [Gemini 2.5 Pro documentation](https://ai.google.dev/gemini-api/docs/models/gemini-2.5-pro)

## Cost and limitations

Pricing through 200K is **$1.25 input and $10 output per million tokens**, rising to $2.50/$15 beyond 200K; Batch halves it. Google limits new-user access and recommends Gemini 3.8 Flash for new projects. It lacks native media generation and Live API support.

Source: [Gemini API pricing](https://ai.google.dev/gemini-api/docs/pricing)

## Scores

- **Tool use: 88/100.** Google's search, code, files, functions, and grounding suite is broad.
- **Reasoning: 87/100.** It remains a strong thinking model but is several generations old.
- **Context window: 96/100.** One-million-token input is excellent.
- **Multimodal: 94/100.** Native text, image, video, audio, and PDF understanding is comprehensive.
- **Coding: 88/100.** Long-codebase reasoning and code execution remain capable.
- **Cost efficiency: 80/100.** Long prompts and output are relatively expensive today.
- **Overall Score: 91/100.** Half-up rounded mean: (88 + 87 + 96 + 94 + 88) / 5 = 90.6.

## Bottom line

Gemini 2.5 Pro remains a capable legacy multimodal model, but constrained access and newer Gemini options weaken its case for new systems.
