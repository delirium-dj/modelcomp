## Model card

- **Name:** Qwen 3.8 Flash Next (**Qwen3.8-Flash-Next**)
- **Short description:** **Alibaba Qwen's open-weight research preview of the architecture it will carry into Qwen4** — released **2026-08-26**, and explicitly **a checkpoint, not a product** (the managed, production version is the hosted **Qwen3.8-Flash** on Qwen Cloud, which ships 1M context by default and built-in tools). The bet is efficiency-through-new-architecture: **180B total parameters but only 6B activated per token**, via three novel pieces — **Qwen Sparse Attention (QSA)** paired with **Gated DeltaNet** (3:1, micro-block-level selection to cut long-context latency), **Gated Residual connections** (four data-dependently-gated branches), and a **51B-parameter n-gram embedding table** (20M bigrams/trigrams at layer 2, offloadable to host RAM). On Alibaba's **own** numbers it is a genuine efficient-coding/agentic standout: it **leads open-weights on SWE-bench Pro (62.5%)**, posts **LiveCodeBench v6 91.9%** (above Claude Opus 4.6-Max's 88.8%), **GPQA Diamond 91.7%**, **DeepSWE 1.1 58.7%**, **Toolathlon 73.5%**, and tops **8 of 10 published multimodal benchmarks** (incl. GUI-agent **AndroidWorld 84.5** and **OSWorld 2.0 52.3**) — all while activating fewer parameters than nearly every model it beats. ⚠ **Three honest counterweights: (1) every benchmark is first-party** — akash.network states "independent, third-party reproductions were not available," and Morph's SWE-bench Pro leaderboard flags the 62.5% as "neither a Scale standardized entry"; there is **no Artificial Analysis Intelligence Index and no Vals AI row for Flash-Next itself**; **(2) it is experimental** — a preview lane with expected churn before Qwen4 ships; **(3) the license is restrictive** — **qwen-community-1.0**, *not* Apache 2.0 (unlike sibling Qwen3.8-27B): >100M MAU / >$20M-monthly-revenue products must display the model name, and any **Model-as-a-Service or "AI Work Assistant" business needs a separate Qwen license**. Self-hosting also needs a **multi-GPU node** (FP8 checkpoint 172.78 GiB) or a quality-lossy GGUF CPU-offload — the 6B-active figure speeds inference but does **not** shrink the memory footprint. - **Provider / access:** **Alibaba Qwen team.** Open weights on **Hugging Face** (`Qwen/Qwen3.8-Flash-Next`, qwen-community-1.0), served via **Vercel AI Gateway ($0.12/$0.40 per 1M)** and other hosts; **vLLM recipe**, **SGLang**, **TokenSpeed** support; **Unsloth** quantized GGUF builds for CPU/unified-memory. Production sibling **Qwen3.8-Flash** via **Qwen Cloud** (1M context, built-in tools). Listed here as `opencode/qwen-3.8-flash-next`. **No free-id tier** in this dataset (`noFreeId: true`).
- **Release / knowledge:** **2026-08-26.** An experimental open-weight preview of the Qwen4 architecture; knowledge cutoff not stated in the sources reviewed.
- **IDs:** `qwen-3.8-flash-next` / `Qwen/Qwen3.8-Flash-Next` (Hugging Face) / `opencode/qwen-3.8-flash-next` (this dataset).
- **Context window:** **262,144 (262K) native, extensible to 1,000,000 (1M) via YaRN** — confirmed. But YaRN is a **static** scaling factor that "can measurably hurt performance on shorter texts," so the *effective* served window is 262K unless you tune/enable YaRN. (The hosted **production Qwen3.8-Flash** ships 1M by default; the **open checkpoint** does not.) Qwen's agentic guidance at 1M: budget up to 262,144 reasoning tokens + 131,072 final-response tokens.
- **Modalities:** **Text, image, video in → text out; tool use.** A causal LM with a **vision encoder** (HF `image-text-to-text` task); accepts text, image URLs and video URLs in one OpenAI-compatible chat message. Strong vendor multimodal sweep (8/10 top) including computer-use (OSWorld 2.0) and mobile-agent (AndroidWorld) tasks.
- **Pricing (as of 2026-10-24):** **Vercel AI Gateway $0.12 input / $0.40 output per 1M** — among the cheapest hosted prices in the dataset; **open-weight self-host** otherwise. The **6B-active** footprint makes inference very cheap/fast (~2.5× faster prefill per community reports), but self-hosting the full checkpoint is a **six-figure capital decision** (multi-GPU H200/Blackwell node) unless using a quality-lossy GGUF build on 96GB+ RAM. **License caveat:** qwen-community-1.0 restricts large-scale commercial and MaaS/AI-worker use (see Short description) — a real cost for agent businesses, unlike MIT/Apache rivals.
- **Architecture:** **Hybrid MoE + n-gram-embedding causal LM with a vision encoder. 180B total = 125B language model + 51B n-gram embedding + 4B multi-token-prediction (MTP); only 6B active per token.** **48 layers, hidden dim 2,560, vocab 248,320, 512 total MoE experts (10 routed + 1 shared active).** Three architectural novelties: **QSA** (1 of every 4 blocks; micro-block-level attention selection) + **Gated DeltaNet** (the other 3), **Gated Residual connections** (4 gated branches), and **n-gram embedding** (20M bigrams/trigrams → 51B lookup at layer 2, cheap to offload to host RAM). **Hybrid thinking** with adjustable effort (`xhigh`/`medium`/`low`) that **preserves reasoning traces across turns**. Checkpoint: **FP8 172.78 GiB / BF16 335.28 GiB**; min validated deploy TP2 on GB300, recommended TEP8 on 8×H200. License **qwen-community-1.0**.
