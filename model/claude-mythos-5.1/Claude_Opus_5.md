## Model card

- **Name:** Claude Mythos 5.1 — status **Active (invite only)**. No free tier, and no paid self-serve tier either: access requires an invitation.
- **Short description:** **Variant/alias flag — this is the central fact about this entry.** Anthropic's own documentation describes Claude Mythos 5.1 as **"the same model as Claude Fable 5.1, offered by invitation only through Project Glasswing"**, and states that **"It shares Claude Fable 5.1's specifications and pricing."** The two were released on the same day (**2026-09-01**) under a **joint announcement and a single joint system card**, and Anthropic routes Mythos users to Fable 5.1's own "What's new" page for release notes. In other words this is not a separate capability tier, a larger model, or a more capable sibling — it is the same model behind an access gate, priced identically. Everything capability-related in this report is therefore Fable 5.1's evidence, correctly attributed.
- **Provider / access:** **Invitation only, as part of Project Glasswing.** Access is obtained by contacting an Anthropic, AWS or Google Cloud account team. Available on the Claude API (`claude-mythos-5-1`), Amazon Bedrock (`anthropic.claude-mythos-5-1`), Google Cloud and Microsoft Foundry. **One documented difference from Fable 5.1: Claude Platform on AWS is not listed as a Mythos platform** — Mythos spans four surfaces where Fable 5.1 spans five. A migration path exists from a predecessor, **Claude Mythos 5**, with its own section in Fable 5.1's migration guide. The breaking and additive API changes are Fable 5.1's: forced tool use returns an error, earlier models cannot read its thinking blocks, editing earlier turns invalidates thinking blocks; per-message effort (beta), turn-scoped system messages (beta), progress updates between tool calls (`display: "updates"`, beta), the reduced cache-read price, and content provenance.
- **Release / knowledge:** Released 2026-09-01. **Knowledge cutoff June 2026** (both reliable and training-data cutoff). Retirement not sooner than 2027-09-01.
- **IDs:** `claude-mythos-5-1` (Claude API / Google Cloud / Microsoft Foundry); `anthropic.claude-mythos-5-1` (Amazon Bedrock). **No free-tier ID, and no self-serve ID of any kind.**
- **Context window:** **1M tokens input, 128K tokens max output** on the synchronous Messages API. Two caveats carried from the shared specification: **Mythos 5.1 is absent from Anthropic's list of models eligible for the 300K-output Batch API beta** (Opus 5.5, Opus 5, Sonnet 5.5, Sonnet 5, Opus 4.8/4.7/4.6 and Sonnet 4.6 all qualify), so a $10/$50 model has a smaller generation ceiling than two-generation-old siblings; and **1M tokens is roughly 555k words / 2.5M Unicode characters on the current tokenizer** (introduced with Opus 4.7), against ~750k words for pre-4.7 models.
- **Modalities:** Input: **text and images only** → output: text. No audio, video or PDF input path; no non-text output. Reasoning: **Adaptive thinking, always on — the only mode**, steered by `effort` with a **`high` default**. **Comparative latency: "Slower"** — the slowest rating in Anthropic's published lineup, tied with Fable 5.1. Tool calls: yes, with **forced tool use unsupported**.
- **Pricing (as of 2026-10-03):** **$10 / MTok input, $50 / MTok output** — identical to Fable 5.1. 5-minute cache write $12.50, 1-hour cache write $20, **cache read $0.25 / MTok (a 2.5% multiplier — the joint-lowest in the Claude lineup with Fable 5.1, against a 10% standard and 5% on Opus 5.5)**, Batch API 50% off input and output. Lineup context: Opus 5.5 $4/$20, Sonnet 5.5 $2/$10, Haiku 4.5 $1/$5.
- **Architecture:** Proprietary, closed weights. Parameter count, active parameters and topology: not disclosed. One Mythos-specific signal exists in Anthropic's later documentation: in the Claude Opus 5.5 system card, Anthropic describes Opus 5.5 as its strongest released model for cyber capability, **"at or above Claude Mythos 5.1 on internal evals"** — which establishes Mythos 5.1 as the prior high-water mark for cyber capability in Anthropic's lineup and is consistent with a gated-access deployment. Whether Glasswing participants receive different safeguard or classifier behaviour than Fable 5.1 users is **not documented publicly** and is not assumed here.

### Normalized scores (1–100)

> **Scoring note, stated plainly:** Anthropic documents Mythos 5.1 as the same model as Fable 5.1 with the same specifications and pricing. The five quality dimensions therefore carry **identical** scores to Claude Fable 5.1 in this dataset. Inventing a differential would be fabricating a capability distinction that the vendor explicitly denies. The only genuine differences are access (invite-only) and platform coverage (four surfaces instead of five), neither of which is a quality dimension.

- **Tool use: 86/100.** **GDPval-AA v2.1 at 1,735 Elo sits essentially at the ~1750+ frontier reference**, OSWorld 2.0 partial credit of 80.7% is within 1.1 points of Claude Opus 5.5, and the **Gray Swan prompt-injection ASR of 1.0%** is among the best measured anywhere — real evidence of a hardened agent loop, which is particularly relevant for a model deployed to a vetted cohort. Held to 86 by the autonomous-work record: **AutomationBench at 31.4% is last in both tables and was achieved with Claude Opus 5 fallback on ~40% of tasks**, Harvey's Legal Agent reaches only 6.7%, **Terminal-Bench 4.0 trails Opus 5.5 by 9–11 points** and Terminal-Bench-Science trails it too, OSWorld strict completion is only 42.8%, CWE-bench v1 is last of four, and **Tau3-Banking, Claw-Eval, Toolathon, MCP-Atlas and Terminal-Bench 2.1 are all unreported** (explicit methodology penalty).
- **Reasoning: 90/100.** **HLE at 60.9% without tools and 65.6% with tools is far above the 40%+ reference** and survives independent re-testing at 59.1%; ArXivMath reaches 82.9%/92.1%; and it **beats Claude Opus 5.5 on OfficeQA (80.2%) and OfficeQA Pro (69.0%)**, which is the one genuine capability argument for this tier. Capped at 90 because it consistently loses to cheaper siblings: the **independent Intelligence Index of 53 is below the 60+ marker, 5 behind Opus 5.5 and 3 behind Sonnet 5.5 at a fifth of the price**; **LABBench 2, RiemannBench and PostTrainBench are all last of four**; HLE loses both rows to Opus 5.5; and **GPQA Diamond, MRCR/LCR, CritPt and any hallucination measurement are entirely absent**.
- **Context window: 93/100.** The nominal **1M-token window** reaches the ≥1M tier, but the long-context evidence here is actively unfavourable rather than merely missing: **GraphWalks F1 of 65.0% across 256K–1M inputs is the worst of four models**, 19.2 points behind Gemini 4 Argon, and **ProgramBench 87.6% also trails Opus 5.5's 91.2%**. Three structural caveats compound it: no MRCR/RULER figure exists; **this tier is excluded from the 300K Batch-output beta that even two-generation-old Opus and Sonnet models support**; and the current tokenizer means 1M tokens holds roughly 555k words, about 30% less text than the headline implies.
- **Multimodal: 66/100.** Input is **text and images only** with text-only output, placing it in the methodology's "+image in = 60–70" band — and it does not earn the top of that band, because unaided visual performance is the weakest in every comparison it appears in: **Chartography without tools is 44.8% (Anthropic's figure) or 46.2% (Google's), 19.6 points behind Claude Opus 5.5 and 20–25 behind Gemini 4 Argon and GPT-6 Astra.** The 88.4% with-tools figure measures the harness as much as the model. SWE-bench Multimodal is 6.7 points behind Opus 5.5, LVBench is last of four, and there is no audio, video or PDF input and no non-text output.
- **Coding: 89/100.** Solid across a wide suite — **SWE-bench Pro 81.2%, SWE-bench Multilingual 89.1%, ProgramBench 87.6%, Vibe Code Bench 90.3%**, and **SciCode 63.1% independently measured, above the 55%+ reference**. Four deductions: **DeepSWE v1.1 at 67.4% is 6.6 points below the 74%+ frontier reference and last of four**; every SWE-bench variant loses to Opus 5.5; **SWE-bench Verified and LiveCodeBench are absent**; and the efficiency evidence is poor — **CursorBench 4.0 at 51.8% for ~$17.28 per task against Opus 5.5's 52.5% at ~$3** means it is outscored *and* outpriced by a cheaper sibling on the benchmark built from real coding sessions.
- **Cost efficiency: 24/100.** The rate card is identical to Fable 5.1's — **$10 / $50 on the methodology's ~30 anchor**, with the one genuine improvement being **cache reads at $0.25 / MTok (a 2.5% multiplier, joint-lowest in the Claude lineup)** plus Batch at 50% off. Everything else argues down, and this scores two points *below* Fable 5.1 for one concrete, non-capability reason: **the same price buys strictly less access** — invitation-only availability on four platforms instead of five, with no self-serve path at all, so the price cannot be paid by most teams regardless of willingness. Added to that: a measured **~$17.28 per CursorBench task for a lower score than a $4/$20 sibling achieves at ~$3**; **"Slower" latency, the worst rating in the lineup**; **always-on thinking with a `high` default**, so every call bills reasoning tokens at $50/MTok with no off switch; and Anthropic's own guidance for this capability tier is to **start with Claude Opus 5 instead** and escalate only when Opus 5 at higher effort has already failed your evals.
- **Overall Score: 84.8/100.** Mean of the five non-cost dimensions (86 + 90 + 93 + 66 + 89) / 5 = 84.8 — **identical to Claude Fable 5.1, because Anthropic documents them as the same model.** The practical guidance follows from that: **there is no capability reason to seek Mythos 5.1 over Fable 5.1** — if you are not a Project Glasswing participant, use Fable 5.1 and lose nothing; if you are, you are choosing a deployment channel, not a better model. Within that capability tier, the defensible use cases are **office-document QA** (the only rows where it beats Claude Opus 5.5), **demanding open-ended reasoning where Opus 5 at high effort has already failed your evals** — Anthropic's own stated criterion — **cache-heavy pipelines** exploiting the 2.5% cache-read multiplier, and **agents ingesting untrusted content**, where a 1.0% prompt-injection success rate is near best-in-class. Avoid it for autonomous business automation (AutomationBench 31.4% with fallbacks), unaided chart or document vision (Chartography 44.8% without tools), latency-sensitive work (rated Slowest), long single-shot generation (no 300K Batch-output eligibility), and anything where Claude Opus 5.5 at 40% of the price already wins — which is most published rows.
