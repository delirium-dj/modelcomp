## Model card

- **Name:** Claude Opus 4.8. Status **Active (legacy)** — Anthropic's own documentation states plainly: *"Although Claude Opus 4.8 is still available, you should consider migrating to Claude Opus 5.5 for improved performance."* No free API tier. Variant/alias flag: distinct from Claude Opus 4.7 (its predecessor) and Claude Opus 5 / 5.5 (its successors). It retains one live infrastructure role in the current lineup: **requests that trip Claude Opus 5.5's cybersecurity classifiers fall back to Opus 4.8**, so it is still serving production traffic as a safety backstop even where nobody selected it.
- **Short description:** Released **2026-05-28** as Anthropic's Opus-tier flagship, superseded by Claude Opus 5 (2026-07-24) and then Claude Opus 5.5 (2026-09-22). Its standout credential has aged extremely well: **ARC Prize's official leaderboard records it at 72.1% on ARC-AGI-2 — the highest verified figure on that benchmark found anywhere in this research pass**, ahead of Gemini 3.6 Flash's verified 60.4%, GPT-5.2 Pro's 54.2% and Gemini 3 Pro's Deep Think mode at 45.1%. It also posts **SWE-bench Verified 88.6%, independently reproduced at exactly 88.6% by Vals AI.**
- **Provider / access:** Claude API (`claude-opus-4-8`, Messages API), Amazon Bedrock (`anthropic.claude-opus-4-8`), Google Cloud, Microsoft Foundry and Claude Platform on AWS (all `claude-opus-4-8`) — the full five-platform surface, one more than Claude Mythos 5.1 gets. Anthropic publishes model-specific prompting guidance and a dedicated migration guide to Opus 5.5.
- **Release / knowledge:** Released 2026-05-28. **Knowledge cutoff January 2026** (both reliable and training-data cutoff) — five months behind the current Claude lineup's June 2026. Retirement not sooner than **2027-05-28**.
- **IDs:** `claude-opus-4-8` (Claude API / Google Cloud / Microsoft Foundry / Claude Platform on AWS); `anthropic.claude-opus-4-8` (Amazon Bedrock). **No free-tier ID.**
- **Context window:** **1M tokens input, 128K tokens max output** on the synchronous Messages API, and **300K output on the Message Batches API** with the `output-300k-2026-03-24` beta header. Worth noting against the current lineup: **Opus 4.8 *is* eligible for the 300K batch-output beta, while the far more expensive Claude Fable 5.1 and Mythos 5.1 are not** — a two-generation-old model has the larger generation ceiling. Tokenizer caveat: **1M tokens is roughly 555k words** on the current tokenizer (introduced with Opus 4.7), against ~750k words for pre-4.7 models.
- **Modalities:** Input: **text and images only** → output: text. No audio, video or PDF path; no non-text output. Reasoning: **Adaptive thinking** with a **`high` default effort**. Tool calls: yes.
- **Pricing (as of 2026-10-03):** **$5 / MTok input, $25 / MTok output.** 5-minute cache write $6.25, 1-hour cache write $10, **cache read $0.50 / MTok (the standard 10% multiplier)**, Batch API 50% off both meters. The decisive comparison comes from Anthropic's own lineup table: **Claude Opus 5.5 costs $4 / $20 — 20% less on both meters — with a newer knowledge cutoff, a cheaper 5% cache-read multiplier, and a substantially higher composite benchmark score.**
- **Architecture:** Proprietary, closed weights. Parameter count, active parameters and topology: not disclosed.

### Normalized scores (1–100)

- **Tool use: 87/100.** The independent evidence is the strongest of any model in this pass on two axes: **τ²-bench at 94.4%, measured by Artificial Analysis, is far above the ~50%+ Tau-family frontier reference and the highest τ² result I found anywhere**, and the **AA Agentic Index of 42.6% is likewise the highest recorded here**. Anthropic's own figures are broad and credible — MCP Atlas 82.2%, OSWorld-Verified 83.4%, BrowseComp 84.3%, DeepSearchQA 93.1%, Toolathlon 59.9% — and the GDPval-AA figure of ~1,593 Elo is corroborated within ~12 Elo by two other sources. Four deductions keep it below 90: **GDPval-AA remains ~160 Elo short of the ~1750+ reference**; **Terminal-Bench 2.1 at 74.6% vendor / 71.9% independent is well below the ~88% anchor** and collapses to **21.1% on Terminal-Bench 3.0**; the **~63-point gap between OSWorld-Verified (83.4%) and the independent OSWorld 2.0 (20.6%)** makes the computer-use headline unreliable as a general claim; and **Tau3-Banking and Claw-Eval are unreported**, with the related ResearchClawBench at only 21.1%.
- **Reasoning: 93/100.** The best-verified reasoning profile in this research pass. **ARC Prize's official leaderboard records 72.1% on ARC-AGI-2 — the highest verified figure I found for any model**, on a benchmark explicitly designed to resist memorisation, and achieved without a subscription-gated special mode. **GPQA Diamond clears the 90%+ reference and is corroborated by two independent labs** (92.0% AA, 92.4% Vals against Anthropic's 93.6%). **HLE clears the 40%+ reference decisively** at 57.9% with tools and 49.8% without, with the independent figure landing within 1.1 points. **USAMO 2026 at 96.7%** and **Epoch AI's independently measured FrontierMath v2 Tier 4 at 31.3%** confirm genuine mathematical depth. The hallucination profile (39.3%) is far better than GPT-5.5's 86% or Gemini 3 Pro's 88%. Three deductions: the **Artificial Analysis Intelligence Index of 41.8% is well below the 60+ frontier marker**; **ARC-AGI-3 at 1.5% is a floor result**, so the ARC-AGI-2 generalisation does not extend; and **MRCR/RULER are unreported** with CritPt only mid-range at 20.9%.
- **Context window: 95/100.** A verified **1M-token input window with 128K synchronous output** places it in the ≥1M tier (95–100), and it carries a commercial advantage over Anthropic's own current flagship tier: **Opus 4.8 is eligible for the 300K Batch-output beta while Claude Fable 5.1 and Mythos 5.1 — at twice the price — are not.** Cache reads at the standard 10% multiplier ($0.50) and Batch at 50% keep long contexts affordable. It sits at the tier floor because the 100 condition (≥98% retrieval at 512K+) has **no direct supporting evidence** — there is no MRCR, RULER or GraphWalks figure, only an indirect AA-LCR of 77.7% — and because the post-4.7 tokenizer means 1M tokens holds roughly 555k words, about 30% less text than the number implies.
- **Multimodal: 70/100.** Input is **text and images only** with text-only output and no audio, video or PDF path, which fixes it in the methodology's "+image in = 60–70" band. It earns the **top of that band** on genuinely strong measured evidence: **ScreenSpot Pro at 87.9%** is excellent screen and interface understanding — better than Qwen3.7-Plus (79.0%) and Gemini 3 Pro (72.7%) — and **CharXiv at 80.5% without tools** is a striking result, nearly double Claude Fable 5.1's 44.8% on the same unaided condition, meaning a legacy model reads charts better than Anthropic's priciest current offering. OfficeQA Pro reaches 66.2%. Frontier-grade vision cannot lift it into the 75–90 band when the input surface simply excludes video, audio and PDF, and **SWE Multimodal at 38.4% shows the visual capability does not transfer cleanly to multimodal software engineering**.
- **Coding: 92/100.** **SWE-bench Verified at 88.6% from Anthropic's system card, reproduced at exactly 88.6% by Vals AI independently**, is the cleanest vendor-independent agreement on a flagship coding benchmark anywhere in this dataset — and the figure itself leads most of the field. **SWE-bench Pro at 69.2% beats GPT-5.6 Sol (64.6%), GPT-5.5 (58.6%) and Gemini 3.1 Pro (54.2%)**, SWE Multilingual reaches 84.4%, LiveCodeBench 87.8% is independently measured, and **the AA Coding Index at 74.3% clears the methodology's 70%+ frontier reference** — the highest such figure recorded here. Four deductions: **SWE Multimodal at 38.4% is weak**; **Terminal-Bench 2.1 at 74.6% is far below the 85%+ coding reference**; **AA-SciCode at 54.4% falls fractionally short of the 55%+ reference** and PostTrainBench v1.1 at 32.9% and FrontierCode 1.1 at 46.5% are mid-field; and **DeepSWE and Vibe Code Bench are absent**.
- **Cost efficiency: 42/100.** At **$5 / $25** it sits meaningfully worse than the $3/$15 anchor that maps to ~60, with only standard mitigations: a 10% cache-read multiplier ($0.50), Batch at 50% off, and 300K batch-output eligibility that its pricier stablemates lack. What drives the score well below the raw anchor is that it is **strictly dominated by a cheaper successor from the same vendor**: **Claude Opus 5.5 costs $4 / $20 — 20% less on both meters — with a newer knowledge cutoff (June 2026 versus January 2026), a cheaper 5% cache-read multiplier, and a composite benchmark score of 87.78 against this model's 70.82**. Anthropic's own documentation tells you to migrate. There is no workload where paying more for the older, weaker model is the right call, with one narrow exception that is not a purchasing decision at all: it remains the **automatic fallback target when Opus 5.5's cyber classifiers fire**, so it earns its keep as infrastructure rather than as a选择.
- **Overall Score: 87.4/100.** Mean of the five non-cost dimensions (87 + 93 + 95 + 70 + 92) / 5 = 87.4 — a genuinely excellent model that is commercially obsolete. Its capability case is real and in two places still unmatched: **ARC Prize's verified 72.1% on ARC-AGI-2 is the highest such figure in this entire dataset**, and **τ²-bench at 94.4% plus an AA Agentic Index of 42.6% are both the best independently measured tool-use results recorded here**. Add **SWE-bench Verified at 88.6% confirmed independently to the decimal**, SWE-bench Pro 69.2%, an AA Coding Index of 74.3% that clears the frontier reference, GPQA corroborated by two labs, USAMO 96.7%, and **CharXiv unaided at 80.5% — nearly double Claude Fable 5.1's**. If this model were current, it would rank near the top of this dataset. It is not current. **Anthropic explicitly recommends migrating to Claude Opus 5.5, which costs 20% less, knows five months more, caches more cheaply and scores substantially higher.** Choose Opus 4.8 only where an acceptance suite is already validated against this exact model and the migration cost exceeds the 20% saving, or where you specifically need its ARC-AGI-2 or unaided-CharXiv behaviour. For everything else — and certainly for any new build — route to Opus 5.5. Note also the operational reality that you may be using it without choosing it: **it is the designated fallback when Claude Opus 5.5's cybersecurity classifiers block a request**, so its behaviour matters to anyone running security-adjacent workloads on the current flagship.
