## Model card

- **Name:** MiMo-V2.6-Pro. **Open weight under the MIT licence** — commercial use, modification and redistribution with **no revenue thresholds and no Model-as-a-Service carve-outs**, the cleanest licence among the current open-weight flagships. No `$0` API tier. Variant/alias flag: three siblings must not be conflated with this entry — **MiMo-V2.6-Flash** (309B/15B, same omnimodal stack, $0.14/$0.28), **MiMo-V2.6-Pro-UltraSpeed** (API-only, "up to 20x faster" output at 10x the price), and **MiMo-V2.6-Distill-Qwen-9B** (an SFT checkpoint of Qwen3.5-9B on MiMo-generated data, released as a research starting point — explicitly *not* a small Pro).
- **Short description:** Xiaomi's omnimodal open-weight flagship, released **2026-09-22** (China time; Hugging Face repositories went live late 2026-09-21 UTC, which is why some trackers list the 21st). Xiaomi frames the series around "scaling reinforcement learning toward self-improvement": where earlier releases used separate RL runs per domain, V2.6 used **one mixed RL run across coding, general agents, visual tasks and cybersecurity**. The resulting gains over V2.5-Pro are the largest generational jump in this dataset — DeepSWE v1.1 from 19.0 to 71.9 and Terminal Bench 4.0 from 1.5 to 34.9 — on the same base, which supports the claim that the recipe rather than the architecture changed.
- **Provider / access:** Xiaomi's MiMo API platform (`mimo-v2.6-pro`), **OpenRouter** (`xiaomi/mimo-v2.6-pro`, OpenAI-compatible Chat Completions, 4 providers), plus Xiaomi MiMo Studio, MiMo Code and the MiMo Desktop app. Weights on Hugging Face as `XiaomiMiMo/MiMo-V2.6-Pro-RL`. Xiaomi also open-sourced the surrounding tooling: a **verl RL-framework fork**, a long-horizon agent framework called **Uni-Agent**, and a minimal coding agent called **mimoagent**. Xiaomi recommends `temperature=1.0` and `top_p=0.95`. Self-hosting requires the `mimo` reasoning and tool-call parsers or tool calling will not parse.
- **Release / knowledge:** Released 2026-09-22, five months after MiMo-V2.5. **Knowledge cutoff: no verified public figure found.**
- **IDs:** `mimo-v2.6-pro` (Xiaomi platform), `xiaomi/mimo-v2.6-pro` (OpenRouter), `XiaomiMiMo/MiMo-V2.6-Pro-RL` (Hugging Face). Siblings: `mimo-v2.6-flash`, `mimo-v2.6-pro-ultraspeed`.
- **Context window:** **1,048,576 tokens** (1M), confirmed on the model card and OpenRouter's catalogue. Max output: no verified public figure found. The window is made practical by a specific architectural choice rather than brute force — see Architecture.
- **Modalities:** **Omnimodal input — text, image, video and audio**; output text only. Purpose-built encoders rather than adapters: a **681M-parameter MiMo ViT** for vision and a **308M AudioTokenizer plus a 127M patch encoder** for audio. Reasoning: yes (a `mimo` reasoning parser is required when self-hosting). Tool calls: yes. JSON mode: not separately documented in the sources checked.
- **Pricing (as of 2026-10-03):** **$0.435 / 1M input, $0.0036 / 1M cached input, $0.87 / 1M output** — Xiaomi states pricing is unchanged from the V2.5 series, so the capability gain came free. Siblings: Flash **$0.14 / $0.0028 / $0.28**; Pro-UltraSpeed **$4.35 / $0.036 / $8.70**. For scale: Pro costs roughly **one-seventh of Kimi K3 on input and one-seventeenth on output**. Cached input at $0.0036/1M makes a stable system prompt plus repository context effectively free on the input side.
- **Architecture:** **Sparse MoE with no shared experts — 1.02T total parameters, 42B active per token, 384 routed experts of which 8 are active.** 70 layers: **60 use a 128-token sliding window and only 10 attend globally**, which is what keeps the KV cache small enough for a 1M context to be servable. Hidden size 6144. **Speculative decoding via a 5-layer multi-token-prediction drafter that predicts 7 tokens per forward pass** — part of why Artificial Analysis measures a usable **76 tokens/second** despite the model's size. Checkpoint is **~573 GB on disk** rather than the ~2 TB a BF16 release would need, because most tensors ship in a packed 8-bit container with FP8 and BF16 for the rest; **Xiaomi does not name the exact quantisation scheme.** Self-hosting Pro needs datacentre hardware: vLLM reference is one 8-GPU node at TP 8 (~72 GB/GPU for weights alone, so 8x H200 141 GB or 8x B200-class; 8x H100 80 GB leaves almost no KV-cache room), while Xiaomi's tuned SGLang production recipe uses **two nodes (TP 16, DP 2, expert parallelism 16, DeepEP all-to-all, EAGLE multi-layer speculative decoding)**. **Pre-training data is not public** — "open weight" here is not "open source".

### Raw benchmarks found

> Two sets, and the independent one carries more weight. **Independent** = Artificial Analysis on index **v4.3.x**; AA rescaled the index when it swapped in harder evaluations such as Terminal-Bench 4.0 and AutomationBench, so **v4.1.1 scores published in August are not comparable** with these. **Vendor-reported** = Xiaomi's own evaluation table from the Pro model card, measured in Xiaomi's harnesses; rows labelled "MiMo" are internal benchmarks nobody outside Xiaomi can reproduce. Xiaomi's release-notes page also gives different DeepSWE figures from its model card (72.6 Pro / 65.7 Flash vs 71.9 / 67.9), implying different run settings — the model-card values are quoted as primary and both are recorded.

Agent / tool use:

### Normalized scores (1–100)

- **Tool use: 89/100.** **Terminal Bench 2.1 at 89.9 is the highest figure in Xiaomi's entire comparison — ahead of Claude Opus 5 and GPT-5.6 Sol — and clears the methodology's ~88% frontier anchor**, while **AutomationBench v1.0.6 at 53.1 also beats both closed flagships** on end-to-end business execution. Toolathlon-Verified 76.9, OSWorld-Verified 82.0 and GDPval-AA 2.1 at 1,673 Elo put it within a few points of the closed frontier across four more agentic suites. Four deductions keep it below 90: **Terminal Bench 4.0 at 34.9 trails Opus 5 by 14.1 points**, so the 2.1 result does not hold up on the harder version; **ExploitBench at 47.9 against 70.0–78.5 is a 22–30 point deficit**; **Tau3-Banking and Claw-Eval are unreported** (explicit methodology penalty); and every agentic figure here comes from **Xiaomi's own harnesses** with no independent agentic replication.
- **Reasoning: 80/100.** The one independent datapoint is genuinely meaningful — **Artificial Analysis Intelligence Index 46, ranked #1 of 114 open-weight models** — and it sits above the methodology's mid band (Index 20–35). But it is **well below the 60+ frontier marker and 12 points behind Claude Opus 5.5's 58**, and the lead over GLM-5.3 (45) and Kimi K3 (44) is inside noise. More decisively, **not one of the methodology's named reasoning references has a published value**: no GPQA Diamond, no HLE, no MRCR/LCR, no CritPt, no hallucination measurement. ProgramBench at 26.5 against Claude Opus 5's 37.0 is the only other reasoning-adjacent row and it is a clear loss. Strong agentic RL outcomes are not evidence of general reasoning depth.
- **Context window: 95/100.** A verified **1,048,576-token window** places it in the ≥1M tier (95–100), and unlike most 1M claims this one comes with a disclosed engineering mechanism that makes it servable — **60 of 70 layers on a 128-token sliding window with 10 global layers**, keeping the KV cache small, plus a 5-layer MTP drafter that sustains 76 tokens/second at 1.02T parameters. It stays at the tier floor because the 100 condition (≥98% retrieval at 512K+) has **no supporting evidence whatsoever** — no MRCR/RULER/GraphWalks figure exists — and because the same sliding-window design that makes 1M affordable concentrates all long-range attention in ten layers, which is a plausible retrieval limitation that remains untested. Max output tokens are undocumented.
- **Multimodal: 90/100.** Genuinely **omnimodal input — text, image, video and audio** — with dedicated purpose-built encoders rather than bolted-on adapters (681M MiMo ViT; 308M AudioTokenizer plus a 127M patch encoder), which places it at the floor of the methodology's top band (90–100) on audio ingestion. It gets the floor and no more because the **only published visual result is MiMo VisualCoding at 72.3 — an internal benchmark nobody outside Xiaomi can reproduce** — with **no MMMU, CharXiv, LVBench, OmniDocBench or ASR figure at all**, and output is text-only with no generation path. Breadth is architecturally documented and almost entirely unquantified.
- **Coding: 86/100.** **Terminal Bench 2.1 at 89.9 clears the 85%+ coding reference and tops the comparison**, the V2.5→V2.6 DeepSWE jump from 19.0 to 71.9 is the largest generational coding gain in this dataset, and a third-party composite rates Coding as its strongest category. Three deductions: **DeepSWE v1.1 at 71.9–72.6 falls short of the 74%+ frontier reference** and loses to both Claude Opus 5 (74.0) and GPT-5.6 Sol (73.0); **ProgramBench at 26.5 against Opus 5's 37.0 is a 10.5-point deficit** on program-level work; and **SWE-bench Verified, SWE-bench Pro, LiveCodeBench, SciCode and Vibe Code Bench are all absent for Pro**, so three of the band's four references cannot be checked and the only visual-coding evidence is unreproducible.
- **Cost efficiency: 93/100.** The best cost profile in this dataset. **$0.435 input / $0.87 output is roughly an order of magnitude below the $3/$15 anchor that maps to ~60**, **cached input at $0.0036/1M is effectively free** for stable prompts and repository context, and the capability gain over V2.5 arrived at **unchanged prices**. The independent verdict is the strongest part: **Artificial Analysis measures $0.13 per Intelligence Index task, placing it on the intelligence-versus-cost Pareto frontier**, roughly one-seventh of Kimi K3's input cost and one-seventeenth of its output cost at a higher index score. The **MIT licence with no revenue thresholds** adds a cost-structure escape no proprietary peer offers. Deductions: it is **verbose (140M output tokens across AA's suite)** so long reasoning traces must be budgeted; **UltraSpeed costs 10x** for latency; self-hosting Pro is a datacentre project (~573 GB, 8x H200-class minimum); and there is no $0 API tier.
- **Overall Score: 88/100.** Mean of the five non-cost dimensions (89 + 80 + 95 + 90 + 86) / 5 = 88 — the clear pick when you want **frontier-adjacent agentic capability at open-weight prices**: terminal agents (Terminal Bench 2.1 89.9, beating both closed flagships in Xiaomi's table), business-process automation (AutomationBench 53.1, also ahead of them), omnimodal pipelines that need audio and video input, and any workload where $0.13 per task and near-free cached input let agent loops run without watching the meter. Choose **Flash instead** for high-volume work — it is within a few points on most agentic rows at about a third of the price and is realistic to self-host at ~178 GB. Do not choose Pro for the hardest security or terminal-agent work, where the closed frontier leads by 14–30 points (Terminal Bench 4.0, ExploitBench), nor for deep general reasoning, where **not a single standard reasoning benchmark has been published** and the independent index sits 12 points behind Claude Opus 5.5. Note for procurement completeness: Anthropic's September 2026 threat-intelligence report named Xiaomi among seven China-based labs over alleged distillation of Claude outputs (campaign GTG-16008, ~20 days in March–April 2026, >400,000 exchanges — the smallest of the published counts); these are allegations rather than findings, China's Commerce Ministry rejected them as having "no factual or legal basis", the reported dates precede even the V2.5 release, and the coverage ties them to no specific MiMo model. The MIT licence is Xiaomi's to grant and is unaffected.
