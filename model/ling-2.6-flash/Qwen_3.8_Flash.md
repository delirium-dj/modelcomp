## Model card

- **Name:** Ling-2.6-flash (Hugging Face `inclusionAI/Ling-2.6-flash`, ModelScope mirror, AA id `ling-2-6-flash`, curated id `opencode/ling-2.6-flash`; demo chat surface `ling.tbox.cn`)
- **Short description:** InclusionAI's open-source **instruct (non-thinking)** model with "**104B total parameters and 7.4B active parameters**", pitched explicitly *against* the long-chain-of-thought trend: "While the industry is pivoting toward 'long-reasoning' to push performance ceilings, a critical question remains: **Are these excessive reasoning tokens truly necessary for high-frequency, everyday agent use cases?**" Its three declared strengths are a **hybrid linear architecture** for inference efficiency, **token-efficiency optimisation** ("accomplishing tasks using more concise outputs" — **only 15 M tokens across the entire Artificial Analysis suite**), and "targeted improvements for agent scenarios" in tool use, multi-step planning and task execution. Tagline: "**Faster Responses, Stronger Execution, Higher Token Efficiency**."
- **Provider / access:** **Open weights under the MIT License** (card front-matter `license: mit`; AA confirms "MIT"), on Hugging Face and ModelScope. Serving: **SGLang** with `--tp-size 4`, `--context-length 262144`, `--tool-call-parser qwen25`, `--mamba-scheduler-strategy extra_buffer`, `--max-mamba-cache-size 256`, and a YaRN override (`rope_type: yarn, factor: 2.0, rope_theta: 6000000, partial_rotary_factor: 0.5, original_max_position_embeddings: 131072`) — i.e. **128 K native, 256 K by RoPE rescaling**. Vendor-reported throughput **up to 340 tokens/s on a 4× H20 setup**, with prefill and decode throughput "**improve[d] by up to around 4×**" versus similar-size SOTA models, and the advantage "more pronounced as both context length and generation length increase". Agent frameworks named as well-supported: **Claude Code, Kilo Code, Qwen Code, Hermes Agent, OpenClaw**.
- **Release / knowledge:** Artificial Analysis lists **Released April 2026**. Technical report shared with the whole 2.6 family: **arXiv 2606.15079**, "Ling and Ring 2.6 Technical Report" (submitted 2026-06-13). **No knowledge-cutoff date is published** for this ID (AA carries no cutoff row). **Status flag:** AA shows a **deprecation banner** — "This model is deprecated. We only continue performance benchmarking for the default 10 K input token workload … InclusionAI has launched a newer release, **Ling 3.0 Flash**. We suggest considering it instead" — which is why speed, cost and verbosity are all **N/A** on the live page.
- **IDs:** `inclusionAI/Ling-2.6-flash` (HF/ModelScope), `ling-2-6-flash` (AA), `opencode/ling-2.6-flash` (curated). **Aggregator coverage:** **BenchLM has a page** — Overall **32.65/100, #161 of 888**, **16 of 625** benchmarks ("partial coverage … so the overall score is conservative"), classified **Open Weight / Non-Reasoning / 262K context** — and **every single row is sourced from Artificial Analysis** (either AA's benchmark tables or "AA summary screenshot"). **No vendor-card row and no Vals/other third-party row appears for this ID**, unlike its successor `ling-3.0-flash`. AA's page exists but is deprecated + estimate-only.
- **Context window:** **262,144 tokens served (131,072 native × YaRN factor 2.0)** — AA reports **262k**, BenchLM **262K**, and the vendor's own launch commands pin `--context-length 262144` alongside `original_max_position_embeddings: 131072`. ### Normalized scores (1–100)

- **Tool use: 55/100.** The one genuinely good independent row is **τ²-bench 86 %**, which for a 7.4 B-active non-reasoning model is a real agentic result, and the plumbing backs it up: `--tool-call-parser qwen25`, first-class agent-framework support (**Claude Code, Kilo Code, Qwen Code, Hermes Agent, OpenClaw**), and post-training "continuously refined … in tool use, multi-step planning, and task execution". Two things cap it: the **GDPval-AA result is Elo 550 / 0.0 % normalized** — the model does not clear the human baseline on open-ended professional deliverables, which is the hardest test of whether τ²-style tool fluency generalises — and **BFCL-V4 / Claw-Eval / PinchBench SOTA claims carry no published number**, while AA's Agentic-side composites (Coding Index 25.3 %) are weak. Mid band, lower half, with the τ²/GDPval contradiction stated rather than averaged away.
- **Reasoning: 38/100.** **AA Index 10 (estimated)** — above its **class median of 7**, but the class is *open-weight non-reasoning*, the weakest comparison pool in AA's taxonomy, and 10 is far under the methodology's 20–35 mid band. The component rows confirm the ceiling: **GPQA Diamond 59.3 %**, **HLE 6.3 %**, **CritPt 0.0 %**, **AA-LCR 31.3 %**, **SciCode 27 %**. The decisive deduction is reliability: **AA-Omniscience Index −66.1 with a 96.7 % hallucination rate and only 15.6 % accuracy** — on unseen factual questions it is wrong roughly twenty times for every correct answer, the worst figure this researcher has recorded anywhere. Conciseness is bought at the cost of depth, and the model has no verified-reasoning mode here (that is the `Ring` line).
- **Context window: 66/100.** **262,144 served** (AA + BenchLM + the vendor's own `--context-length 262144`), architecturally well-motivated — 1:7 MLA-to-Lightning-Linear hybrid attention means most layers hold a fixed-size state, so "the throughput advantage becomes more pronounced as both context length and generation length increase", and the mamba-cache scheduling flags are tuned for exactly that. Placed near the bottom of the 200 K–500 K band (65–84) rather than its middle because the extension is **opt-in YaRN ×2 over a 131,072-token native length**, the **only long-context measurement is AA-LCR 31.3 %**, there is no MRCR/AI-Needle run, and **no max-output figure is published** (sub-64 K caveat neither confirmed nor dismissed).
- **Multimodal: 15/100.** **Text-only** on both sources — AA's modality block ("supports text input, outputs text") and a `text-generation` card with no encoder, no document/image evaluation and no non-text output. Nothing in the 10–20 band lifts it; the family's vision capability is a separate model (`model/ling-3.0-flash-vl/`).
- **Coding: 42/100.** Coding is claimed as a strength (**"SOTA … on SWE-bench Verified"**, agent-framework support, and the model's conciseness genuinely suits high-frequency code-edit loops), but the measured picture is weak and entirely AA-derived: **AA Coding Index 25.3 %**, **SciCode 27 %**, **no LiveCodeBench row**, no SWE-bench number printed, no DeepSWE, no Terminal-Bench, no SWE-bench Multilingual/Pro. Against the band's anchors (DeepSWE 74+, TB 85+, SciCode 55+, Coding Index 70+ → 90–100; mid → 50–70) this is below the mid floor on measurement and above the true floor only on positioning.
- **Cost efficiency: 92/100.** The best token-economics story in the registry: **104 B total / 7.4 B active** on a **4-GPU H20** node under **MIT**, **340 tokens/s** claimed with **~4× prefill/decode throughput** over similar-class models, and — the number that actually matters for agent bills — **15 M tokens for the whole AA evaluation suite** versus 260 M for its own successor, i.e. the model "accomplishes tasks using more concise outputs" instead of "relying on longer outputs to chase higher scores", with the intelligence-efficiency tradeoff explicitly designed for high-frequency production calls. Deductions: **AA publishes no input/output price and no cost-per-task** (deprecated ID, so the efficiency claim cannot be converted into dollars), a 256 K window costs RoPE rescaling rather than being native, and the deprecation itself means hosted routes and prices are drifting toward 3.0 Flash.
- **Overall Score: 43/100.** Mean of the five quality dimensions (55 + 38 + 66 + 15 + 42) / 5 = 216 / 5 = 43.2 → 43; Cost excluded per `RULES.md`. Best fit: **high-frequency, cost-sensitive, tool-shaped calls where brevity is the product** — router/agent sub-tasks, short-horizon tool loops, self-hosted extraction and rewriting on a 4-GPU node, MIT-licensed and cheap per *task* rather than per token, with **τ²-bench 86 %** as the credential that justifies it. It is **unfit for factual Q&A at almost any standard (96.7 % hallucination, −66.1 Omniscience)**, unfit for open-ended professional deliverables (**GDPval 0.0 % normalized, CritPt 0.0 %**), unfit for multimodal work, and a poor starting point for a new build: **AA marks it deprecated and points to Ling 3.0 Flash**, which measures better on almost every axis (Index 20 vs 10, GPQA 85.5 vs 59.3, Omniscience −17.9 vs −66.1, BenchLM 45.18 vs 32.65) *and* is independently reproduced by Vals AI, which this ID is not. **Curation fixes before sync:** set `contextWindow` to **262,144 (131,072 native + YaRN ×2)**, replace "Standard pricing" with "**no published price (AA deprecated ID); MIT self-host, ~15 M tokens/AA-suite**", and add a "superseded by Ling 3.0 Flash" note.
