## Model card

- **Name:** Ling-2.6-flash
- **Short description:** InclusionAI's (Ant Group) **open-weight "Instant" instruct model** — **104B total / 7.4B active** MoE, released via API **2026-04-21** and **open-sourced 2026-04-28/29** under MIT. Its stated thesis is an explicit rejection of the industry's "long-reasoning" trend: rather than chasing benchmark ceilings with longer outputs, it is optimized for **inference efficiency, token efficiency and agent performance**, using only **~15M output tokens to complete the full Artificial Analysis Intelligence Index suite** — roughly one-seventh of Nemotron-3-Super's ~110M+. InclusionAI markets it as class-leading on **BFCL-V4, TAU2-bench, SWE-bench Verified, Claw-Eval and PinchBench**. **This second pass found that the independent measurements of those same agentic claims are, with one exception, near the bottom of their fields** — see Raw benchmarks and the Tool use score.
- **Provider / access:** Hugging Face `inclusionAI/Ling-2.6-flash` (**MIT**, plus official `-fp8` and `-int4` variants and a `-base` checkpoint; 215 GB BF16); ModelScope; OpenRouter `inclusionai/ling-2.6-flash` (**NovitaAI is the only provider**, 181 t/s / 0.76 s latency observed by OpenRouter); Novita AI; demo at `ling.tbox.cn`. Self-host via SGLang (recommended) or vLLM — a **single 4-GPU node**. Requires `--trust-remote-code` (custom `BailingMoeV2_5ForCausalLM`). **No official GGUF exists in the upstream repo** (LocalClaw verified on 2026-10-14: "no public GGUF file verified"); the only GGUFs are an explicitly experimental community set (`ssweens/Ling-2.6-flash-GGUF-YMMV`) that **requires a custom llama.cpp fork** (`ssweens/llama.cpp-ling-2.6`) because vanilla llama.cpp does not support `BailingMoeV2.5`. No OpenCode Zen ID found.
- **Release / knowledge:** API release **2026-04-21**; **weights open-sourced 2026-04-28/29**; technical report **arXiv:2606.15079** (shared Ling/Ring 2.6 report, June 2026). Knowledge cutoff: not disclosed.
- **IDs:** `inclusionAI/Ling-2.6-flash` (HF), `inclusionai/ling-2.6-flash` (OpenRouter)
- **Context window:** **262,144 tokens (256K).** The first pass recorded this as "128K native, extendable to 256K via YaRN" — **this pass corrects that.** The official SGLang recipe does launch with `--context-length 262144` plus a YaRN override (`factor 2.0`, `original_max_position_embeddings 131072`), but the technical report's mid-training description states plainly that the third mid-training phase (525B tokens) **"extends the context window to 256K"** — i.e. **256K was trained**, not merely extrapolated. **262,144 is now credited as the real usable window.** Max output **32,768**.
- **Modalities:** **Text in → text out only.** The HF repo is a `Text Generation` `bailing_hybrid` checkpoint; Artificial Analysis states it "does not support image input" and "is not multimodal." Reasoning: **No** — AA is explicit it "is not a reasoning model. It provides direct responses without extended chain-of-thought reasoning." That is the core design decision, not a limitation. Tool calls: yes (`--tool-call-parser qwen25`). Structured output: yes.
- **Pricing (as of 2026-10-17):** **CORRECTED — the first pass's "$0.01 in / $0.03 out" was a promotional price presented as a list price.** InclusionAI's own published price page (https://developer.ant-ling.com/en/docs/models/price/) gives the **list rate for Ling-2.6-flash as ¥0.60 in / ¥1.80 out / ¥0.12 cache read (CNY)** and, for third-party platforms, **OpenRouter $0.10 / $0.30 / $0.02**. OpenRouter's live page shows **"$0.01 / $0.03 … 90% off"** against that $0.10/$0.30 list — i.e. the effective price is a **90%-off NovitaAI promotion of a $0.10/$0.30 list**. Ant's pricing page announces named limited-time discounts only for Ling-3.1-flash (75%) and Ling-3.0-flash/-VL (72%), and states the general rule "Original prices will gradually resume after the promotional period ends" — **it publishes no end date for the 2.6-flash promotion.** The first pass's "Novita AI $0.10/$0.30" was therefore not a separate provider price but the OpenRouter **list** rate. MIT weights make self-hosting free of token cost.
- **Architecture:** **104B total / 7.4B active** sparse MoE (HF safetensors report 107.49B). Hybrid linear attention: **1:7 MLA + Lightning Linear**, upgraded from Ling 2.0's GQA via a "smooth architectural retrofit" (hybrid initialization, QK-Norm absorption, Partial RoPE adaptation, MLA warmup). Continued pre-training from the Ling-2.0 base for ~9.6T tokens; mid-training ~1.2T tokens across three phases (4K→32K at 250B, 32K at 425B, →256K at 525B). Requires custom modeling code.

### Raw benchmarks found

> **Provenance rule for this model, restated because it now matters more than before.** InclusionAI's card footnotes say PinchBench comparisons come from the official leaderboard (2026-04-20) and Claw-Eval comparisons from the official leaderboard (2026-03-25), while "all other model performance data are based on internal evaluation results," with **GPT-5.2 as the User Agent**. The technical report (arXiv:2606.15079, Table 4) gives the full vendor table. **Every Ling-2.6-flash number below is either vendor-reported or aggregator-relabelled — nothing in the "independent" bucket is a first-party Artificial Analysis full-suite run** (AA lists the model as "No publicly available API / Estimate (independent evaluation forthcoming)"). The independent rows below come from BenchmarkList's ingestion of AA's per-evaluation results.

Agent / tool use — **vendor-reported** unless marked:

- **BFCL-V4: 66.81** (arXiv Table 4) — *vs 67.04 on the HF card; a 0.23-point discrepancy between the card and the report, unexplained.* Vendor claim: leads its set vs Nemotron-3-Super-120B-A12B 35.12, GPT-OSS-120B 43.30, GPT-5.4-mini NR 49.72, GLM-4.5-Air 61.73.
- **τ²-bench: 76.36** (arXiv Table 4, Mean@4, user model GPT-5.2, Average/Retail/Airline/Telecom) — **new numeric value; the first pass recorded this as "named, no published number."** Telemetry from a secondary write-up puts the **Telecom subdomain at 94.96**; if that is right, Retail and Airline must be far lower to average to 76.36.
- **ClawEval: 64.56** (arXiv Table 4, Pass@3) — **new numeric value; previously "named, no published number."**
- **PinchBench: 81.30** (arXiv Table 4, Mean@5) — *vs 81.10 on the HF card.* vs Qwen3.5-122B-A10B 78.20, Nemotron-3-Super 73.10, GLM-4.5-Air 73.30.
- **Multi-IF (turn-3): 74.80** (arXiv Table 4) — *vs 74.85 on the HF card.* Multichallenge 39.71. IFBench 57.40 (*vs 58.10 on the HF card*), LIFEBench 57.20.
- Decode throughput at 65K context: 4.38× vs Nemotron-3-Super 3.37×, Qwen3.5-122B-A10B 1.90×, GLM-4.5-Air 1.00× (baseline); 2.2× the prefill throughput of Nemotron-3-Super. At 64K output on 4× H20 (TP=4, BS=32): decode is 1.3× Nemotron-3-Super, 2.4× Qwen3.5-122B-A10B, 4.3× GLM-4.5-Air.
- **ClawProBench: 27.04 — #48 of 48, dead last (0th percentile)** (BenchmarkList ingestion of the OpenClaw suite, 2026-05-06). Pass^3 **2.4%**, Pass@3 28.9%, Avg Score 35.8, Capability 36.0, Efficiency 99.0, **Tool Use 29.2**, Planning 37.4, Safety 43.0, Constraints 31.0, Error Recovery 44.7, Synthesis 30.9. 54.98 s avg runtime, 26.4M tokens, **$1.97**.
- **Tau3-Banking Pass@1: 2.9% — #164 of 176 (7th percentile)** (BenchmarkList / AA, verified 2026-07-21). Field leader GLM-5.3 50.3%.
- **GDPval-AA: 547 Elo — #225 of 352 (36th percentile)** (verified 2026-09-02); field leader 1861. Normalized 2.2%.
- **Tau2-Bench Telecom: 86.0% — #72 of 332 (79th percentile)** (2026-06-10). **This is the one genuinely strong independent agentic row**, and it is the subdomain the vendor's own average hides.
- Terminal-Bench 2.1: **24.3% — #125 of 194**. Terminal-Bench Hard: **21.2% — #104 of 326**. Both 2026-07-21 / 2026-06-10.
- **Conflict to state plainly:** the vendor reports τ²-bench 76.36 and ClawEval 64.56 as class-leading; the independent rows measure the *same capability families* at **Tau3-Banking 2.9%, ClawProBench 27.04 (last of 48) and Terminal-Bench 2.1 24.3%**. These are not the same benchmark and the harnesses differ (τ² uses GPT-5.2 as user agent; ClawProBench is a repeated-trial OpenClaw suite), so this is **not** a clean refutation — but the direction is unambiguous and the vendor numbers are an upper bound.

That is an easy, leakage-prone metric and is not comparable to any of the rows above; recorded only because it is the only local quality measurement that exists.
- SWE-bench Pro / SWE-bench Multilingual / DeepSWE / Vibe Code Bench: no verified public score found.

Long context:

- **262,144 tokens, natively trained** (see the context-window correction in the Model card).
- **MRCR (16K–256K): 75.93** (vendor, arXiv Table 4, Mean@16K–256K) — **the first actual long-context retrieval benchmark ever published for this model**, and it is the strongest number in the report: **more than double the nearest competitor** (Nemotron-3-Super 39.04, GPT-OSS-120B 22.56, GPT-5.4-mini NR 34.76, GLM-4.5-Air 30.02). The first pass had to write "no long-context retrieval benchmark has been published."
- **Conflict:** the independent **AA-LCR v1.1 at 25.0%** is one of the weakest long-context results in the AA set. MRCR and LCR measure different things (needle-style multi-hop retrieval vs. dispersed multi-step synthesis over 10k–100k documents), so both can be true: this model retrieves planted facts well and synthesizes across them poorly. Prefer neither alone.
- No RULER / LongBench v2 / GraphWalks numbers.

Speed / cost efficiency inputs:

- **Up to 340 tokens/s** on a 4× H20-3e node (TP=4, batch 32) — InclusionAI's own hardware measurement.
- **~15M output tokens** to complete the full AA Intelligence Index suite vs ~110M+ for Nemotron-3-Super — roughly one-seventh.
- **Conflict on whether AA ever measured speed.** AA's model page still lists Speed / Cost / Verbosity as **"N/A."** But easy-benchmarks now publishes **Output Speed 172.8 tok/s, First Token 0.64 s, Max Output 32,768**, and OpenRouter's live provider table reports **181 tps / 0.76 s / 10.8% cache-hit rate / 100% uptime** for the single NovitaAI route. I treat the ~173–181 t/s hosted figures as measured and the 340 t/s figure as vendor hardware.
- Effective OpenRouter price today is $0.009/$0.029 (30-day weighted average) — i.e. the 90%-off promo is real and is being used.

### Normalized scores (1–100)

- **Tool use: 55/100** *(was 82 — the largest change in this report).* The first pass scored 82 off vendor claims: BFCL-V4 67.04, PinchBench 81.10, Multi-IF 74.85, with TAU2-bench and Claw-Eval "named, no number." This pass got the numbers, and they split the story in two. **For:** BFCL-V4 66.81 (vendor) genuinely leads its comparison set; τ²-bench Telecom 86.0% is **#72 of 332, 79th percentile**, and that is an independent measurement; ClawEval 64.56, PinchBench 81.30, τ² 76.36 are all vendor figures at or above their sets. **Against:** every *independent* agentic row that is not Telecom is near the floor — **Tau3-Banking Pass@1 2.9% (#164/176)**, **ClawProBench 27.04, dead last of 48, with a Tool Use subscore of 29.2 and Pass^3 of 2.4%**, **Terminal-Bench 2.1 24.3%**, **GDPval-AA 547 Elo (#225/352)**, **AA Agentic-grade work generally**. A model that is genuinely good at calling functions (BFCL, τ²-Telecom) and near-useless at sustained multi-step agent execution is a *routing/dispatch* model, not an agent backbone. 55 reflects a split profile; the previous 82 credited vendor claims that independent measurement does not support.
- **Reasoning: 52/100** *(was 62).* **AIME 2026 at 73.85%** remains independently leaderboard-confirmed and is respectable for an instruct model, and the vendor's C-SimpleQA 60.23 leads its set. But this pass filled every hole the first pass had to leave open, and they are bad: **GPQA Diamond 59.3% (#337)**, **HLE 6.2% (#291)**, **CritPt 0.0%**, **AA-Omniscience −65.68 with a 4.2% non-hallucination rate**, **AA-LCR 25.0%**, **AA Intelligence Index 14.05 (48th percentile of 427)**. Under `model-comparison.md`'s own bands (GPQA 60–80%, HLE <10%, LCR <40%, Index 20–35 → 55–65) this model sits *below* every band, because it was deliberately designed to. That is a legitimate design choice and it is still the reason not to pick it for analysis.
- **Context window: 85/100** *(was 80).* Raised on two pieces of genuinely new evidence: **256K was mid-trained, not extrapolated** (the report's phase-3 description says so explicitly), and **MRCR (16K–256K) = 75.93** is now published — the first retrieval measurement for this model, and it more than doubles every peer in its comparison set. Not higher because **independent AA-LCR is 25.0%**, which is close to worst-in-class and directly contradicts the synthesis half of the long-context story, and because the model is not in the ≥1M tier.
- **Multimodal: 15/100.** Unchanged — **text-only**, confirmed by the HF `Text Generation` checkpoint, AA's "does not support image input / is not multimodal," and every distribution channel. Floor score by methodology. InclusionAI's vision-capable members are `Ling-3.0-flash-VL` and `Ling-3.0-flash-Sante`, both separate models, and both already retired by at least one gateway (LLMTR, 2026-09-22).
- **Coding: 52/100** *(was 68).* The first pass credited **SWE-bench Verified 61.2%** (vendor) and explicitly noted "zero terminal-agentic measurements" as a gap. That gap is now filled and the result is poor: **Terminal-Bench 2.1 24.3% (#125/194)**, **Terminal-Bench Hard 21.2% (#104/326)**, **SciCode 27.1%**, **AA Coding Index 25.26 (#147/222)**. Only the vendor's SWE-bench Verified 61.20 and LiveCodeBench-v6 62.28 are respectable, and neither is independently corroborated. A model marketed as agentic that solves a quarter of Terminal-Bench is not a coding model.
- **Cost efficiency: 95/100** *(was 99).* **Corrected on the facts, not on taste.** The $0.01/$0.03 rate is real and is the cheapest route in this repo, MIT weights remove token cost for self-hosters, and the model fits a single 4-GPU node. But it is now documented as a **90%-off promotion of a $0.10/$0.30 list**, with **no published end date** from the vendor — and the first pass recorded it as a flat price. Ant's own direct-API list is ¥0.60/¥1.80/¥0.12, roughly 7× the effective OpenRouter rate. Against that, AA has marked the model deprecated and one gateway has delisted it, so neither the price nor the route is durable.
- **Overall Score: 52/100.** `(Tool 55 + Reasoning 52 + Context 85 + Multimodal 15 + Coding 52) / 5 = 259 / 5 = 51.8 → 52`. Best fit: **short, single-shot tool dispatch and function-calling at extreme price sensitivity** — classification, routing, structured extraction, format-constrained generation, and τ²-Telecom-shaped conversational support — where BFCL-V4 66.81, τ²-Telecom 86.0%, a 256K trained window and a $0.01/$0.03 route are hard to beat, and where the model's no-CoT design and 15M-token efficiency are exactly right. Do **not** pick it for multi-step agent execution (Tau3-Banking 2.9%, ClawProBench last of 48), coding (TB2.1 24.3%), deep reasoning (HLE 6.2%, CritPt 0%), or anything multimodal. If you want the cheap-and-fast Ling tier in production today, `ling-3.0-flash` in this repo is the live successor.
