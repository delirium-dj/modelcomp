# Model Research Report: GPT-6 Astra

**Researched by:** Gemini 3.8 Flash
**Research Date:** 2026-10-21
**Overall Score:** 92/100

---

### Executive Summary

Unveiled by OpenAI in early September 2026, GPT-6 Astra (`gpt-6-astra`) represents OpenAI's apex frontier system succeeding the GPT-5.6 series. Designed for long-horizon agentic orchestration, complex operating system/browser control, advanced cyber reasoning, and frontier mathematics, GPT-6 Astra features a 1.05M-to-1.1M-token context window with 128,000 output tokens. Astra made industry history by saturating ExploitBench at 100.0%, prompting OpenAI to classify it as their first model with "Critical" cybersecurity capability under their Preparedness Framework and instituting stringent access controls via the Trusted Access program. On computational and agentic benchmarks, it scores 98.0% on FrontierMath Tier 4, 99.9% on ARC-AGI-3 (OpenAI harness; ~62.7% standard), 57.7%–59.3% on Terminal-Bench 4.0, and ~74.1% on DeepSWE v1.1. Standard commercial API pricing is positioned at $10.00 per million input tokens ($1.00 cached) and $50.00 per million output tokens.

### Quantitative Evaluation

- **Tool use: 95/100.** Premier terminal and browser agent capabilities. Scoring 57.7%–59.3% on Terminal-Bench 4.0 and 64.6% on Terminal-Bench Science 0.1, Astra coordinates multi-step command sequences, provisions environments, and automates desktop operating system workflows with exceptional autonomy.
- **Reasoning: 96/100.** World-class mathematical and abstract reasoning. Saturates FrontierMath Tier 4 at 98.0% and achieves 99.9% on ARC-AGI-3 (adapter harness), demonstrating unprecedented formal logical deduction.
- **Context window: 96/100.** 1.05M-to-1.1M-token context window (128K max output) with full-recall attention, maintaining sharp contextual precision across multi-repo codebases and dense scientific corpuses.
- **Multimodal: 80/100.** Multimodal input ingesting text and high-resolution images/screenshots; text and code outputs. Optimized for computer use and document parsing, though lacking native raw video and audio streams.
- **Coding: 94/100.** Saturated ExploitBench at 100.0% and reached ~74.1% on DeepSWE v1.1. Excels at zero-day vulnerability identification, automated defensive patching, legacy system migration, and large-scale architectural refactoring.
- **Cost efficiency: 48/100.** Flagship frontier pricing at $10.00 in / $50.00 out per 1M tokens ($1.00 cached reads), tailored for high-leverage scientific, cyber, and enterprise agent workflows.
- **Overall Score: 92/100.** (Arithmetic mean: `(95 + 96 + 96 + 80 + 94) / 5 = 461 / 5 = 92.2`, rounded to **92**).

### Trade-offs & Limitations

1. **High Commercial Price:** $10.00/$50.00 per 1M tokens requires disciplined routing, reserving Astra for high-stakes workloads.
2. **Restricted Cyber Access:** Strict guardrails and verification requirements under Trusted Access programs govern advanced security features.
3. **Text/Image Modality Only:** Does not support bidirectional native voice or real-time video streaming on public API routes.
