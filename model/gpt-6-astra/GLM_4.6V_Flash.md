# GPT-6 Astra

## Model Overview

GPT-6 Astra is OpenAI's most capable large language model, released in September 2026. It represents a significant advancement in AI capabilities, designed for complex reasoning, coding, computer use, research, and document creation tasks.

## Key Features

- **Context Window**: 1,050,000 tokens (1.05 million tokens)
- **Max Output**: 128,000 tokens
- **Pricing**: $10 per 1M input tokens, $50 per 1M output tokens
- **Effort Levels**: Five levels (low, medium, high, xhigh, max) for controlling reasoning depth
- **Multimodal Support**: Text and image inputs, text output
- **Tools**: Web search, file search, code interpreter, hosted shell, computer use, MCP, tool search

## Cost-Effectiveness

GPT-6 Astra offers strong performance at a higher price point:

- **Cost per Task**: $7.09 on Intelligence Index (Artificial Analysis)
- **Token Efficiency**: Uses 27k output tokens per task vs 78k for Claude Fable 5.1
- **Price Advantage**: ~40% cheaper than Claude Fable 5.1 for same score
- **Efficiency**: Uses up to 20% fewer tokens than other models

## Limitations and Considerations

- **High Cost**: $10 input / $50 output per 1M tokens
- **Reasoning Effort**: Doesn't support "none" setting; must use "low" instead
- **Data Residency**: Fast mode not available for EU data residency
- **Limited Availability**: Initially available only to select organizations and ChatGPT Plus/Pro users
- **Safety Features**: Strong alignment but may still produce harmful content
