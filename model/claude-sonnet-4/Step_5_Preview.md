## Model card

- **Name:** Claude Sonnet 4. Anthropic's **May-2025 mid-tier model** (released **2025-05-22** alongside Opus 4) — the generation whose headline was **72.7% on SWE-bench Verified, matching flagship Opus 4 (72.5%) at 5x lower cost**, which made it the default backbone for GitHub Copilot's coding agent and countless early agentic pipelines. **A negative finding governs this report: BenchLM carries no `claude-sonnet-4` page in any spelling** (it 404s; BenchLM tracks only `claude-sonnet-4-5` at 47.33 and `claude-sonnet-4-6` at 55.66), so the 2026-11-06 re-research had no catalog to check against.
- **Short description:** Historically the most consequential Sonnet for cost-per-capability, and now **retired**: snapshot `claude-sonnet-4-20250514` was deprecated 2026-04-14 and **retired from the Claude API on 2026-06-15**, re-confirmed on Anthropic's official deprecations record, which lists `claude-sonnet-5-5` as the replacement. It survives on Amazon Bedrock and Google Cloud Vertex.
- **Provider / access:** Was Claude API `claude-sonnet-4-0` (**retired**); **Amazon Bedrock, Google Cloud Vertex**. No OpenCode Zen route. **`noFreeId`.**
- **Release / knowledge:** **released 2025-05-22; knowledge cutoff March 2025** (AA lists Mar 1, 2025) — a genuine, dated, specific fact, and an unusually old one: **20 months behind its own retirement date.**
- **IDs:** `claude-sonnet-4-0` (alias); `claude-sonnet-4-20250514` (snapshot, retired).
- **Context window:** **200,000 tokens** per Anthropic — though the repo's meta.json flags that **AA and some trackers quote the old 1M beta figure**, so the window is a source-conflicted spec. The 200K figure is used here.
- **Modalities:** **text and image in; text out.**
- **Pricing (as of 2026-11-06):** **$3 input / $15 output per 1M, $0.30 cached read, $3.75 cached write** (repo meta.json, Anthropic's pricing page). Methodology anchors put $3/$15 at ≈60.
- **Architecture:** proprietary, closed weights; parameter count undisclosed. Hybrid reasoning (instant + extended thinking up to 64K).

### Normalized scores (1–100)

> **Methodology note.** With no tracker page and one carried-forward capability figure, every quality dimension below is a placeholder-for-unknown anchored on the verified structural facts (200K window, hybrid reasoning up to 64K, $3/$15) and the model's historical positioning. The two dimensions where this SKU is genuinely distinctive — **context window** (200K) and **cost efficiency** ($3/$15) — are the best-grounded scores in this report.

- **Tool use: 58/100.** Anchored at the mid band as a placeholder, with a strong directional signal: the model **was the default backbone for GitHub Copilot's coding agent** and anchored early agentic pipelines, which implies a real and battle-tested agentic substrate. Scored at the mid band's lower edge and **capped by the absence of every agentic benchmark** — no Terminal-Bench, τ²-bench, τ³-bench, MCP-Atlas, OSWorld, Toolathlon, MazeBench, ALE, Claw-Eval, JobBench, GDPval-AA or AA Agentic Index. The **64K thinking budget** is a genuine asset for long-horizon agentic work.
- **Reasoning: 68/100.** Mid-band, anchored on the inference that a model matching flagship Opus 4 on SWE-bench Verified and shipping **hybrid reasoning with extended thinking up to 64K** implies mid-to-upper-mid reasoning. Capped at 68 rather than higher because **GPQA, HLE, CritPt, AA-LCR, MRCR, the composite index, ARC-AGI and every reliability figure are absent**, and because the **March 2025 knowledge cutoff** makes the substrate 20 months old. The strong-coding indication is a real signal but coding is not reasoning, and the repo's rule against importing sibling figures applies.
- **Context window: 70/100.** **200,000 tokens** per Anthropic, which the repo's meta.json records as the correct figure against **AA and some trackers' older 1M beta reading** — the conservative reading is used and the conflict is surfaced rather than resolved. Scored at 70, on the methodology's 200K tier boundary. Held at the floor rather than mid-tier because **no AA-LCR or MRCR figure exists**, so the window's usable depth is unverified, and the **64K max output** is a real constraint for repository-scale work.
- **Multimodal: 55/100.** **Text and image in; text out** per the repo's meta.json, scored at the bottom of the methodology's 60–70 band and marginally below it, because the image-input claim is a **spec-sheet claim with zero measured support** — no MMMU-Pro, CharXiv, ExtractBench, BabyVision, ZeroBench, OmniDocBench or Design Arena figure exists.
- **Coding: 74/100.** Mid-band and the best-grounded quality dimension, anchored on the one real figure: **SWE-bench Verified 72.7%** (80.2% at high compute) — a solid mid-frontier repair result, and the figure that made this model consequential. Capped by it sitting 12.3 points under the 85%+ terminal reference, and by the **total absence of SWE-bench Pro, LiveCodeBench, DeepSWE, AA-SciCode, the AA Coding Index, Vibe Code Bench, Terminal-Bench and FrontierCode** — so the 74%, 70% and 55% references cannot be checked. No successor-IV figures are imported.
- **Cost efficiency: 60/100.** **$3/$15 per 1M with $0.30 cached read and $3.75 cached write** (repo meta.json) — a real, verified rate card, sitting directly on the methodology's ≈60 anchor. Held at exactly 60 because the model is **retired from the Claude API** (still on Bedrock and Vertex), so the rate card describes a route that no longer exists on the primary API; and because it is strictly dominated on price-per-capability by **Sonnet 4.5 (47.33 BenchLM), Sonnet 5 (64.45) and Sonnet 5.5 (81.89 at $2/$10)** — the direct successor costs a third less for 34 more BenchLM points.
- **Overall Score: 65/100.** (58 + 68 + 70 + 55 + 74 + 60) / 5 = 65.0 → **65**. Recommendation: **a historically important model with a decisive operational problem: it was retired from the Claude API on 2026-06-15.** Its two genuine assets were **SWE-bench Verified 72.7% at $3/$15 — flagship-class coding at 5x lower cost** — which made it the backbone of GitHub Copilot's coding agent, and a **64K extended-thinking budget** that was generous for its tier. Both are now available better and cheaper elsewhere. **Do not build on it.** If you have an existing integration, pin to Bedrock or Vertex; otherwise migrate to **Sonnet 5.5 (81.89 at $2/$10)** or **Claude Haiku 5.5 (66.56, refreshed in an earlier batch)**, both of which dominate it on every axis. The 20-month-old knowledge cutoff is an additional reason not to use it for anything current.
