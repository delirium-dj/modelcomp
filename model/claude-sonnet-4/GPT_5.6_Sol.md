# Claude Sonnet 4 — Independent Research Report

## Summary and evidence

Claude Sonnet 4 is Anthropic's May 2025 hybrid reasoning model for coding and agents. It supports near-instant and extended-thinking modes, text and image input, tool use, and **200K context**. Anthropic reported leading SWE-bench Verified performance at release and 42.2% on OSWorld, establishing it as a strong early computer-use model.

Sources: [Anthropic Claude 4 launch](https://www.anthropic.com/news/claude-4), [Claude 4 system card](https://www-cdn.anthropic.com/4263b940cabb546aa0e3283f35b686f4f3b2ff47.pdf)

## Cost and limitations

Pricing is **$3 input and $15 output per million tokens**. It is now legacy behind several Sonnet generations, lacks audio/video input, and its 200K context and computer-use performance are modest by current standards.

## Scores

- **Tool use: 84/100.** Tool and early computer use are solid but dated.
- **Reasoning: 84/100.** Hybrid thinking remains capable, below newer Claude models.
- **Context window: 84/100.** 200K is practical but no longer leading.
- **Multimodal: 82/100.** Image input is supported without broader media.
- **Coding: 87/100.** Software engineering was a principal launch strength.
- **Cost efficiency: 74/100.** Legacy capability at $15 output is expensive today.
- **Overall Score: 84/100.** Half-up rounded mean: (84 + 84 + 84 + 82 + 87) / 5 = 84.2.

## Bottom line

Claude Sonnet 4 should generally be migrated to a newer Sonnet release for better agents, context, and value.
