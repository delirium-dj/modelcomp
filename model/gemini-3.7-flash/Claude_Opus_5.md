## Model card

- **Name:** Gemini 3.7 Flash — **generally available with a stable model ID**, not a preview. No `-free` API SKU; consumer access runs through the Gemini app and Google AI Studio. Variant/alias flag: **superseded three weeks later** by Gemini 3.8 Flash (2026-09-02) at the *same* introductory price, so this is a legacy entry whose main remaining argument is token economy rather than capability.
- **Short description:** Google's Flash-tier workhorse for coding, agents, multimodal reasoning and reliable multi-step execution, released **2026-08-13 — only three weeks after Gemini 3.6 Flash**. Google's own model card states it is **based on Gemini 3.6 Flash with algorithmic improvements** in the reasoning foundation plus production-developer feedback; it is explicitly not a new context or modality class. The gains are concentrated in first-pass code accuracy, design adherence when turning screenshots and design systems into web interfaces, multi-step planning and roadblock recovery, document reasoning in finance/law/biosciences, long-context retrieval and agentic computer use.
- **Provider / access:** Gemini API via the **Interactions API** (`generativelanguage.googleapis.com/v1beta/interactions`), Google AI Studio, and OpenAI-compatible Chat Completions through resellers. Supported capabilities: context caching, code execution, **Computer Use in preview**, file search, function calling, Google Maps grounding, Google Search grounding, structured outputs, thinking, URL context. Four consumption modes: Standard, Batch, Flex, Priority. **Not supported: audio generation, image generation, Live API.** Migration notes from Google's own guide are non-trivial: `temperature`, `top_p` and `top_k` must be removed, `thinking_budget` is replaced by the string enum `thinking_level`, unsupported `candidate_count` must be removed, and multi-turn flows use server-side `previous_interaction_id`.
- **Release / knowledge:** Released 2026-08-13; latest documented update August 2026. **Knowledge cutoff March 2026**, with Google noting some domains may effectively be limited to January 2025.
- **IDs:** `gemini-3.7-flash` (stable, GA). **No free-tier API ID verified.** Google's migration guidance advises pinning the exact ID and rejecting silent alias substitution.
- **Context window:** **1,048,576 maximum input tokens, 65,536 maximum output tokens** — the same class as 3.6 Flash. Unusually for this dataset, there is **hard published retrieval evidence**: GDM-MRCR v2 at a 97.0% 128K average (see benchmarks). Pricing is flat across the window — no long-context tier.
- **Modalities:** Input: **text, image, video, audio and PDF**. Output: text only. Reasoning: yes — three thinking levels (`low`, `medium` default, `high`); **`minimal` returns an error**, and thinking tokens bill as output. Tool calls: yes (surface above). JSON mode / structured outputs: yes.
- **Pricing (as of 2026-10-03):** USD per 1M tokens, with **introductory rates through 2026-12-31 that double on 2027-01-01**:
  - **Standard: $0.75 in / $3.75 out (thinking tokens included) / $0.075 cached in** → **$1.50 / $7.50 / $0.15**
  - Cache storage: **$0.50 per 1M tokens per hour** → $1.00
  - Batch and Flex: $0.375 / $1.875 / $0.0375 → $0.75 / $3.75 / $0.075
  - Priority: $1.35 / $6.75 / $0.135 → $2.70 / $13.50 / $0.27
  - Google Search grounding: 5,000 free requests per month **shared across Gemini 3.x models**, then **$14 per 1,000 requests**; Maps grounding uses a shared 5,000-prompt allowance then the same rate.
  - Worked examples at the introductory Standard rate: 100K input + 10K output ≈ **$0.1125**; 1M cached input + 100K output ≈ **$0.45** (excluding cache storage). Both double after the introductory period.
- **Architecture:** Proprietary, closed weights. **Total parameter count, active parameters, expert count, architecture details, training corpus size and compute budget are all explicitly undisclosed** — Google's model card states only that it is based on 3.6 Flash with algorithmic improvements.

### Raw benchmarks found

> The main table is **Google's August 2026 model card** comparison against Gemini 3.6 Flash, Claude Sonnet 5, GPT-5.6 Terra and Muse Spark 1.2. Google's stated conditions: Gemini scores are **generally pass@1 with default sampling**; non-Gemini numbers are **provider-reported unless the methodology says otherwise**, with maximum available reasoning settings preferred; several evaluations were self-computed; and **harnesses, tool access, run aggregation and even video frame limits vary by model**. A second set of figures comes from **Google's later Gemini 3.8 Flash launch chart**, which restated some 3.7 results differently — those disagreements are recorded rather than reconciled.

Agent / tool use:

- **Terminal-bench 2.1: 85.8%** (3.6 Flash 78.0%, Claude Sonnet 5 80.4%, **GPT-5.6 Terra 87.4% leads**, Muse Spark 1.2 82.9%) — just under the methodology's ~88% frontier anchor. **Conflicting Google surface:** the Gemini Enterprise developer guide cited in the 3.8 Flash launch materials reports 3.7 Flash at **81.6%** on this same benchmark.
- **Terminal-bench 3.0: 14.9%** (3.6 Flash 5.4%, Sonnet 5 14.6%, **Terra 20.8% leads**). Google's later 3.8 chart reports 3.7 Flash at **11.2% on Terminal-Bench 4.0** — a different version, both near the floor.
- Tau3-Banking / Tau2-Bench: no verified public score found
- **GDPVal-AA v2 (Elo): 1,525** on 3.7's own model card (3.6 Flash 1,422, Terra 1,578, Sonnet 5 1,598, **Muse Spark 1.2 1,628 leads** — 3.7 Flash is **last among its non-Gemini peers**). Google's later 3.8 chart restates this as **1,482**. Either figure is far below the ~1750+ frontier reference.
- Claw-Eval / ClawProBench: no verified public score found
- Toolathon / MCP-Atlas / SWE Atlas Codebase QnA: no verified public score found
- **AutomationBench (private set): 30.4%** — **leads the published table** (3.6 Flash 17.0%, Terra 23.6%, Sonnet 5 10.7%)
- **Harvey LAB-AA: 90.7%** — **leads the table** (Sonnet 5 90.1%, 3.6 Flash 85.1%, Terra 85.2%). Note: Google's later 3.8 chart uses a *different* Harvey metric (Legal Agent Benchmark all-pass rate), on which 3.7 Flash scores only **8.8%** — the two are not comparable.
- **OSWorld 2.0: 47.9%** on 3.7's own card (3.6 Flash 33.8%, **Terra 50.2% leads**); Google's later 3.8 chart restates 3.7 Flash as **50.6%**
- **Agent's Last Exam: 26.3%** (3.6 Flash 24.2%, Terra 28.0%, **Sonnet 5 33.3% leads** — 3.7 Flash is last)
- **Vals Finance Agent v2: 59.0%** (from Google's 3.8 chart)
- **Gray Swan indirect prompt injection (ASR, lower is better): 9.2%** (from the 3.8 comparison; 3.8 Flash improved to 5.5%)

### Normalized scores (1–100)

- **Tool use: 80/100.** Three outright leads on real agentic work — **AutomationBench private set 30.4%**, **Harvey LAB-AA 90.7%** and the generational OSWorld jump from 33.8% to ~48–51% — plus **Terminal-bench 2.1 at 85.8%**, close to the ~88% frontier anchor. Five deductions keep it at 80: **GDPVal-AA v2 at 1,525 Elo (restated 1,482) is far below the ~1750+ reference and last among its non-Gemini peers**; **Terminal-bench 3.0 at 14.9% and 4.0 at 11.2% are floor results** against Terra's 20.8%, so the 2.1 score does not survive harder harnesses; **Agent's Last Exam 26.3% is last in the table**; **Tau3-Banking, Claw-Eval and MCP-Atlas are all unreported** (explicit methodology penalty); and **Computer Use is still preview**, with Google's own two surfaces disagreeing on both Terminal-bench 2.1 (85.8% vs 81.6%) and OSWorld (47.9% vs 50.6%).
- **Reasoning: 87/100.** **HLE-Verified at 53.6% leads the published table and sits well above the 40%+ frontier reference**, **LABBench2 82.1% leads**, and **GDM-MRCR v2 at a 97.0% 128K average clears the methodology's MRCR 95%+ marker** — three of the five reasoning references are therefore met or exceeded. Capped at 87 because **GPQA Diamond and CritPt are entirely unreported**, the **Artificial Analysis Intelligence Index of 56 is below the 60+ marker and loses to both GPT-5.6 Terra and Muse Spark 1.2 at 57**, the MRCR figure is a 128K average rather than a measurement at the full million, BioMysteryBench's human-difficult split (43.5%) loses to Terra by 5.9 points, and no hallucination measurement exists.
- **Context window: 97/100.** A verified **1,048,576-token input window** places it in the ≥1M tier (95–100), and it earns the top of that tier on evidence no other model in this pass can match: **GDM-MRCR v2 at a 97.0% 128K average, leading all four comparison models** — actual measured retrieval rather than a capacity claim — reinforced by flat pricing across the window with no long-context cliff and $0.075 cached input. Two points are withheld because the tier's 100 condition requires **≥98% retrieval at 512K+** and the published figure is a 97.0% average at **128K**, so recall at half a million tokens and beyond remains unmeasured; the **65,536-token output ceiling is also half the frontier norm**, and Google's own documentation is explicit that a 1M window is capacity, not a target.
- **Multimodal: 91/100.** Input spans **text, image, video, audio and PDF** under one GA model ID, which places it in the methodology's top band (90–100) on audio ingestion, and the breadth is backed by measured leads: **LVBench 85.4%** on long video and **GDP.pdf 34.0%** on documents both top their comparison table. It stays near the band floor for three concrete reasons: output is **text only** with no audio generation, image generation or Live API; **GDP.pdf's 34.0% lead is a weak absolute result** — two-thirds of document tasks fail; and uniquely in this release, **CharXiv Reasoning regressed against 3.6 Flash on both conditions** (84.5% vs 85.2% without tools, 88.7% vs 89.4% with), so chart understanding got slightly worse, not better.
- **Coding: 85/100.** Three table-topping results — **Code Arena WebDev Elo 1,588**, **FrontierCode 1.1 Main 43.6%** and a 16.7-point DeepSWE jump over 3.6 Flash — plus **Terminal-bench 2.1 at 85.8%, which meets the methodology's 85%+ coding reference**, and a genuinely strong web-development profile that matches Google's design-adherence claim. The deductions are specific: **DeepSWE v1.1 at 65.3% is 8.7 points below the 74%+ frontier reference and loses to GPT-5.6 Terra's 69.6%** — and that figure is independently confirmed at 65% ±2%, so it is not a harness artefact; **SWE-bench Pro at 60.4% is mid-tier**; **SWE-bench Verified, LiveCodeBench, SciCode and Vibe Code Bench are all absent**, with a circulating third-party SWE-bench Verified claim that traces to no Google source; and Terra also beats it on both Terminal-bench versions.
- **Cost efficiency: 85/100.** $0.75 in / $3.75 out with **$0.075 cached input** is far below the $3/$15 anchor that maps to ~60, Batch and Flex halve it again to $0.375/$1.875, and the independently measured **$2.18 average cost per DeepSWE task** is concrete evidence of cheap agentic work — notably **lower than Gemini 3.8 Flash's $2.36**, because 3.7 spends ~107K output tokens per task against 3.8's ~143K. Four deductions: **every rate doubles on 2027-01-01**; **thinking tokens bill as output**; **cache storage costs $0.50 per 1M tokens per hour** on top of token charges and Search/Maps grounding costs **$14 per 1,000 requests** past a 5,000-request allowance shared across all Gemini 3.x usage; and the value case is structurally undercut by its own successor — **Gemini 3.8 Flash costs exactly the same and scores higher on nearly every row**, so paying 3.7 prices for 3.7 capability is only rational where token economy or an already-validated acceptance suite outweighs capability.
- **Overall Score: 88/100.** Mean of the five non-cost dimensions (80 + 87 + 97 + 91 + 85) / 5 = 88 — the strongest long-context retrieval profile in this dataset (GDM-MRCR v2 97.0% at 128K) paired with full multimodal input and the best web-development preference score in its comparison (Code Arena 1,588), at Flash-tier prices. Best fit: **long-document and multimodal analysis where retrieval fidelity matters**, **front-end and web-dev generation**, **business-process automation** (AutomationBench 30.4%, Harvey LAB-AA 90.7%), and **high-volume pipelines that are latency- or token-budget-constrained**, where its ~25% lower output-token spend than 3.8 Flash is a real advantage. Do not choose it for long-horizon software engineering or terminal agents — GPT-5.6 Terra beats it on DeepSWE, both Terminal-bench versions and OSWorld — nor for high-Elo professional knowledge work (GDPVal-AA last among peers). And be clear-eyed that **Gemini 3.8 Flash supersedes it at an identical price**: 3.7 Flash is the right pick only for workloads already validated against it, or where its lower token consumption beats 3.8's higher accuracy.
