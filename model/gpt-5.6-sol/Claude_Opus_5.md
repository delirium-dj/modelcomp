## Model card

- **Name:** GPT-5.6 Sol. No free tier. Variant/alias flag: **`gpt-5.6` is an alias that routes to Sol**, and the tier name "Sol" is durable — OpenAI advances Sol/Terra/Luna on their own cadence, so Sol roughly corresponds to the unsuffixed model tier in earlier GPT-5 families. Siblings in the same family: **Terra** (balanced, $2.50/$15) and **Luna** (fastest/cheapest, $1/$6). Do not confuse with GPT-6 Sol or GPT-6.1 Sol, which are later generations in this dataset.
- **Short description:** The flagship of OpenAI's GPT-5.6 family, released **2026-07-09** alongside Terra and Luna, positioned as OpenAI's most capable model for coding, knowledge work, cybersecurity and science with an explicit emphasis on **efficiency** — state-of-the-art results using fewer output tokens than both GPT-5.5 and competing frontier models. Three platform features shipped with the family: **Programmatic Tool Calling** (the model writes and runs small in-memory programs that coordinate tools without round-tripping every result), a **multi-agent beta in the Responses API**, and an **"ultra" setting that coordinates four parallel agents by default** for the hardest tasks.
- **Provider / access:** OpenAI, on **both Chat Completions and Responses**, plus the Batch API — a broader endpoint surface than GPT-5.5 Pro (Responses-only) and the same as GPT-6 Astra. Not supported: Realtime, Live, Assistants, fine-tuning, embeddings, image/video/speech generation, moderation, legacy completions. Supported features: streaming, structured outputs, function calling, file search, image input, web search, **prompt caching**. Responses-API tools: web search, file search, image generation, code interpreter, **hosted shell, apply patch, skills, computer use, MCP and tool search** — the same full agentic surface as Astra. Rate limits are generous and a real operational advantage over the Pro tier: **Tier 1 starts at 500 RPM / 500K TPM** and Tier 5 reaches 15,000 RPM / 40M TPM.
- **Release / knowledge:** Released 2026-07-09. **Knowledge cutoff 2026-02-16** (OpenAI model documentation).
- **IDs:** `gpt-5.6-sol`, with `gpt-5.6` as a routing alias. **No dated snapshot exists** — the only listed snapshot is `gpt-5.6-sol` itself, so there is nothing to pin for reproducibility. No free-tier ID.
- **Context window:** **1,050,000 tokens total context, maximum input 922,000 tokens, 128,000 max output** — all three from OpenAI's model reference page. The 922K input cap means the headline million cannot actually be filled with input, and the 272K pricing threshold (below) sets the economically sane ceiling far lower.
- **Modalities:** Input: **text and image only**. Output: text only. Audio and video are unsupported in both directions; image generation exists only as a hosted Responses-API tool. Reasoning: yes, with reasoning-token support and **six effort levels — `none`, `low`, `medium` (default), `high`, `xhigh`, `max`**. The presence of **`none` is a genuine advantage over GPT-6 Astra**, which removed it: thinking can be switched off entirely here to control cost and latency. Tool calls: yes (surface above). JSON mode / structured outputs: yes.
- **Pricing (as of 2026-10-03):** **$4.00 / 1M input, $0.40 / 1M cached input, $20.00 / 1M output**, taken from OpenAI's own documentation. OpenAI describes this as a **20% input and 33% output reduction**, and states the **promotional pricing is available at least through 2026-11-21** — so this rate has an expiry date. Launch pricing in July 2026 was $5.00 / $0.50 / $30.00, which is why independent trackers still disagree ($5/$30, $4/$20 and even $2/$10 all appear in third-party listings as of this date; **OpenAI's documentation is authoritative and says $4/$20**). Structural terms: **prompts over 272K input tokens reprice the entire request at 2x input and 1.5x output**, and **cache writes bill at 1.25x the uncached input rate**. Batch halves the standard rate. For routing comparison inside the family: GPT-5.5 was $5/$0.5/$30 and GPT-5.4 $2.5/$0.25/$15.
- **Architecture:** Proprietary, closed weights. Parameter count, active parameters and topology: not disclosed — no verified public figure found.

### Raw benchmarks found

> Provenance is separated. **OpenAI-reported** = figures published by OpenAI at launch (via a source that links every number to the official page, verified 2026-07-18). **Competitor-reported** = figures for Sol that appear in *rivals'* published comparison tables — Moonshot's Kimi K3 launch evaluation, Anthropic's Claude Opus 5.5 system-card table, and Google DeepMind's Gemini 3.8 Flash launch chart — all verified directly in this research session. Competitor tables generally source Sol's numbers from OpenAI's own publications rather than re-running them, and where two tables disagree on the same benchmark both values are recorded.

Agent / tool use:

- **Terminal-Bench 2.1: 88.8%** (OpenAI-reported; GPT-5.6 Terra 87.4%, GPT-5.5 85.6%, GPT-5.6 Luna 84.7%; corroborated at 88.8% in Moonshot's independent-of-OpenAI table, where it was the highest displayed score). **Clears the methodology's ~88% frontier anchor.**
- **Terminal-Bench 4.0: 37.3%** (competitor-reported, both Anthropic and Google tables) — a collapse against Claude Opus 5.5's 66.4% and GPT-6 Astra's 57.9% on the harder benchmark version.
- **Terminal-Bench-Science 0.1: 22.4%** (competitor-reported) — the lowest figure in Anthropic's comparison table, against Astra's 64.6%.
- Tau3-Banking / Tau2-Bench: no verified public score found
- **GDPval-AA (Elo): 1,748 on v2** per Moonshot's table and **1,710 on v2** per Google's chart — essentially at the methodology's ~1750+ frontier reference. Separately **1,588 on GDPval-AA v2.1** per Anthropic's table (a different version, not comparable).
- Claw-Eval / ClawProBench: no verified public score found
- **MCP Atlas: 83.6** (competitor-reported, Moonshot) — within 1.1 points of the best displayed score. Toolathon and SWE Atlas Codebase QnA: no verified public score found.
- **BrowseComp: 90.4** (competitor-reported, Moonshot; behind Kimi K3's 91.2, ahead of Claude Fable 5's 88.0)
- **SpreadsheetBench 2: 32.4** (competitor-reported, Moonshot) and **AutomationBench: 28.8%** (competitor-reported, Anthropic) — both near the bottom of their respective tables
- **OSWorld 2.0 (computer use): 62.6%** (competitor-reported, Google chart; Claude Opus 5 75.4%, Gemini 3.8 Flash 59.0%). OpenAI separately reported **65.7% at ~75 minutes per task** on the offline subset when comparing Sol against GPT-6 Astra.
- **Harvey Legal Agent (all-pass): 2.5%** (competitor-reported, Google chart) — effectively a floor result
- **Gray Swan indirect prompt injection (attack success rate, lower is better): 27.0%** (competitor-reported, Google chart) — **nearly 5x Gemini 3.8 Flash's 5.5% and 5.6x Claude Opus 5's 4.8%.** The worst agent-hardening figure in that comparison and a material risk for agents that ingest untrusted content.

Reasoning / knowledge:

- LCR / MLCR: no verified public score found

A separate third-party composite ranks it **#8 of 212 at 78.95/100** (source-verified position #5 of 74). Note that GPT-6 Astra's launch coverage reported Astra tying Sol at 61 on a *different* index version; these values are not interchangeable.
- Omniscience Accuracy / Hallucination Rate: no verified public score found

### Normalized scores (1–100)

- **Tool use: 88/100.** **Terminal-Bench 2.1 at 88.8% clears the methodology's ~88% frontier anchor** and was the best displayed figure in a rival's own comparison table; **GDPval-AA v2 at 1,710–1,748 Elo sits essentially at the ~1750+ reference**; MCP Atlas 83.6 and BrowseComp 90.4 are frontier-adjacent; and the platform layer is genuinely differentiated — Programmatic Tool Calling, a multi-agent Responses beta, an "ultra" four-parallel-agent setting, the full hosted-shell/apply-patch/skills/computer-use/MCP tool surface, and 500 RPM from Tier 1. Four hard deductions keep it below 90: **Terminal-Bench 4.0 at 37.3% collapses against Opus 5.5 (66.4%) and Astra (57.9%)**, so the 2.1 result does not survive a harder harness; **Terminal-Bench-Science 22.4%, AutomationBench 28.8% and Harvey Legal 2.5% are bottom-of-table**; **Gray Swan prompt-injection ASR of 27.0% is roughly 5x both Gemini 3.8 Flash and Claude Opus 5**, a real hardening defect for untrusted-input agents; and **Tau3-Banking and Claw-Eval are unreported** (explicit methodology penalty).
- **Reasoning: 88/100.** **GPQA Diamond 94.6%** clears the 90%+ reference (and led its published comparison), **HLE Full 44.5%** clears the 40%+ reference, and GPQA is corroborated at 94.1% on an independent harness. Capped at 88 because the composite evidence is weak where it matters most: the **Artificial Analysis Intelligence Index of 47 on v4.3.2 is far below the 60+ marker and last in Anthropic's five-model comparison**; HLE loses to Claude Fable 5 by 8.8 points and Opus 4.8 by 5.3; **MRCR/LCR, CritPt and any hallucination measurement are entirely absent**; and Terminal-Bench-Science at 22.4% suggests the reasoning does not transfer to autonomous scientific work.
- **Context window: 94/100.** The nominal 1,050,000-token context reaches the ≥1M tier, but the same three constraints that apply to GPT-6 Astra apply here and pull it to the tier boundary. **Maximum input is 922,000 tokens, not 1,050,000** — the headline million cannot be filled. **No retrieval evidence exists at all** (no MRCR/RULER/GraphWalks), so recall across the window is unverified. And the **272K threshold reprices the entire request at 2x input and 1.5x output**, making the economically sane window roughly a quarter of the advertised one. Partial offsets: cached input at $0.40 is a true 10% rate, cache writes are only 1.25x, and prompt caching is a first-class supported feature.
- **Multimodal: 70/100.** Input is **text and image only** with text-only output and no audio or video path, placing it firmly in the methodology's "+image in = 60–70" band. It takes the top of that band on measured evidence rather than claims: **MMMU-Pro 83.0 was the single highest score in Moonshot's cross-vendor comparison**, GDP.PDF 40% beat Gemini 3.8 Flash's 35%, and OSWorld computer use at 62.6–65.7% is entirely screenshot-grounded. Two counterweights prevent more: **OmniDocBench at 85.8 was the lowest figure in that same table** (5.3 points behind Kimi K3), and one third-party chart's 82.1% LVBench row for a documented image-only model is unreconcilable and was not credited.
- **Coding: 88/100.** **Terminal-Bench 2.1 at 88.8% clears the 85%+ coding reference**, Program Bench 77.6 is second only to Kimi K3 across a five-model field, and DeepSWE at 72.7–73.0 is within ~1.3 points of the 74%+ frontier reference. The deductions are specific and consequential: **SWE-bench Pro at 64.6% is last in OpenAI's own published comparison** — 15.4 points behind Claude Fable 5 and 4.6 behind Claude Opus 4.8 — which is exactly the benchmark that predicts fixing real bugs in real repositories; **FrontierCode v1.1 (47.5%) and CursorBench 4.0 (41.7%) are both bottom-of-table** in Anthropic's set; and **SWE-bench Verified, LiveCodeBench, SciCode and Vibe Code Bench are all missing**, so three of the band's four references cannot be checked.
- **Cost efficiency: 56/100.** At the documented **$4 / $20** it sits slightly worse than the $3/$15 anchor that maps to ~60, and four factors argue up from there: **cached input at $0.40 is a genuine 10% rate** with cache writes at only 1.25x, **Batch halves everything to $2/$10**, the **`none` reasoning effort means thinking can be switched off entirely** — a lever GPT-6 Astra removed — and the family offers principled downward routing to Terra ($2.50/$15) and Luna ($1/$6). Three factors argue down: **the $4/$20 rate is explicitly promotional and guaranteed only through 2026-11-21**, after which the $5/$30 launch pricing is the obvious reversion; the **272K full-request repricing cliff** punishes the long-context work the window advertises; and OpenAI's own token-efficiency pitch was later undercut by independent measurement showing GPT-6 Astra using roughly a third of Sol's tokens at max effort. No free tier.
- **Overall Score: 85.6/100.** Mean of the five non-cost dimensions (88 + 88 + 94 + 70 + 88) / 5 = 85.6 — a strong, broadly available workhorse flagship rather than a category leader. Choose it for **terminal-centric agentic coding at scale** (Terminal-Bench 2.1 88.8% with 500 RPM from Tier 1 and both Chat Completions and Responses supported), **graduate-level science Q&A** (GPQA 94.6%), **chart- and image-heavy analysis** (MMMU-Pro 83.0), and any workload that benefits from Programmatic Tool Calling or the `none` effort setting to cut cost. Do not choose it for repository bug-fixing (last on SWE-bench Pro in OpenAI's own table), for the hardest ambiguous terminal work (Terminal-Bench 4.0 37.3%), for autonomous scientific or SaaS-workflow agents (Terminal-Bench-Science 22.4%, AutomationBench 28.8%, Harvey Legal 2.5%), or for agents that ingest untrusted content without sandboxing — a 27% prompt-injection success rate is roughly five times its closest competitors. Re-baseline the cost case before 2026-11-21, when the promotional rate lapses.
