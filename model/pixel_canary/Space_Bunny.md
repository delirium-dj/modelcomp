### Normalized scores (1–100)

Bands per `model-comparison.md`. The single load-bearing input is Vercel's Next.js Agent Evals; everything else is absent, so several scores are deliberately held down by missing evidence rather than by measured weakness.

- **Tool use: 82/100.** The Next.js Agent Evals are a genuine multi-file agentic coding run — 31 tasks, real tool use, OpenCode harness — and Pixel Canary lands at 30/31 with `AGENTS.md`, tying Claude Opus 5.5 (high) and matching GPT 6 Astra and Gemini 3.8 Flash on the same tasks. That is frontier-adjacent *on this one suite*. It cannot go higher because there is no Terminal-Bench 2.1, Tau3, GDPval-AA, Toolathon or MCP-Atlas row to corroborate multi-domain tool reliability, and pass@4 over four attempts flatters a single-task outcome.
- **Reasoning: 66/100.** No GPQA, HLE, LCR, CritPt or Intelligence Index number exists, so this is inferred, not measured. The inference: the reasoning-habits fingerprint places Pixel Canary in the Qwen3.8 Flash / GLM 5.3 / Kimi K3 reasoning neighborhood (63.8 / 59.3 / 59.0 similarity to those), a capable-but-not-frontier tier, and its own fingerprint categories are only middling (Explanations 53.3, Creative 58.9, Politics 59.0, Math 60.3 — nothing near frontier). The 96.8% Next.js result lifts it into the methodology's mid band's upper half (mid = 55-65); the missing frontier anchors (GPQA 90%+, HLE 40%+) cap it well below 90.
- **Context window: 71/100.** Catalog-verified 262,144 tokens total places it squarely in the methodology's 200K-500K tier (200K = 70; band top 84), so the tier mapping alone yields a low-70s score. It does not climb toward the band ceiling because there is zero measured retrieval evidence at any length — no AA-LCR, RULER or MRCR row — and the methodology awards the top of the range for verified high-fidelity retrieval at 512K+.
- **Multimodal: 65/100.** Vercel's catalog lists text **and image** input with text output, which is the methodology's "+image in = 60-70" band; reaching the 75-90 band would require video or PDF input, which this route does not offer. Its SVG-code output quality is a genuine craft signal but stays inside the text-output cap. No MMMU / OCRBench / VideoMME style numbers were published, so the band midpoint is the honest placement.
- **Coding: 80/100.** 96.8% (30/31) on a real agentic Next.js suite, level with Claude Opus 5.5 (high) and one task ahead of Grok 4.7's 29/31, is well above the methodology's mid band (65-75) and into the frontier band. It stops short of 90 because it is a *single* 31-task suite with pass@4 and early exit — no SWE-bench Verified, SWE-Pro, SciCode, LiveCodeBench or Terminal-Bench corroboration exists — and because the 16.9-minute average duration is the slowest in its comparison group, which is a real cost-of-iteration signal even if it is not a correctness one.
- **Cost efficiency: 100/100.** $0 input / $0 output / $0 cached, verified in Vercel's catalog on 2026-10-01 — the methodology's "$0 = 100" rule, with no adjustment. Flagged as a temporary preview that was scheduled for deprecation roughly an hour after the price check, on a preview data policy that permits prompt/output retention for training. The 100 is arithmetically correct and practically fragile: cost efficiency was scored on the evaluated tier, and that tier has a published end date.
- **Overall Score: 73/100.** Half-up mean of the five quality dims — (82 + 66 + 71 + 65 + 80) / 5 = **72.8 → 73**. Best fit: a short-lived, zero-cost way to sample an unusually strong free coding agent — on Vercel's own harness it is a genuine Opus-5.5-tier performer for Next.js work. Do not build on it: the route is deprecated, the vendor is undisclosed, the data policy is training-permissive, and there is exactly one real benchmark behind the score.
