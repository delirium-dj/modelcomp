## Model card

- **Name:** GPT-5.3 Codex (**GPT-5.3-Codex**)
- **Short description:** **OpenAI's most capable agentic coding model at its Feb-5-2026 launch** — the "**codex merger**" that fused **GPT-5.2-Codex's coding performance with GPT-5.2's reasoning, 25% faster**, shipped the *same day* (an hour apart) as Anthropic's Opus 4.6 in a head-to-head benchmark war. Its headline is **Terminal-Bench 2.0 77.3% vs Opus 4.6's 65.4%** — "GPT reclaims the lead" on the one directly-comparable benchmark — plus a broad software-lifecycle skill set: **computer use (OSWorld-Verified 64.7% at launch, up from 38.2%; 74.0% with a later image-resolution-preserving API parameter)**, **GDPval 70.9%** (financial analysis, docs, slide decks), **SWE-Lancer IC Diamond 81.4%**, **Cybersecurity CTF 77.6%** (the **first model OpenAI classifies "High capability" for security**, backed by $10M in cyber-defense API credits), and **interactive collaboration** (steer mid-task without losing context). It is also the **"first model instrumental in creating itself"** — the Codex team used early versions to debug its own training pipeline and manage deployment. ⚠ **Three counterweights: (1) it is now explicitly DEPRECATED** — OpenAI's docs state "the gpt-5.2 and gpt-5.3-codex models are already deprecated in Codex"; its role lives on in the newer Codex and Sol generations; **(2) every headline number is OpenAI-self-reported at "xhigh" reasoning effort** (paddo.dev: "independent testing will tell the real story"), and OpenAI reports **SWE-bench Pro (56.8%)** while Anthropic reports **SWE-bench Verified** — different, non-comparable benchmarks; **(3) output pricing is frontier-expensive ($14/M)**. Its one solid **independent** anchor is the neutral **Vals AI SWE-bench Verified** row (**90/73/55/33**) — a strong top band that declines on long-horizon work.
- **Provider / access:** **OpenAI.** Available to **all paid ChatGPT plans** across the **Codex app** (500K downloads in three days), **CLI, IDE extension, and web**; via the **OpenAI API** (`gpt-5.3-codex`, Responses API), **Azure AI** (`gpt-5.3-codex`), **Venice** (private/zero-retention, from $2.19/1M), and other hosts. **Closed / proprietary. Now deprecated in Codex** — OpenAI instructs users to "update scripts, configuration files, and `codex exec --model`." **No free-id tier** (`noFreeId: true`). Listed here as `opencode/gpt-5.3-codex`.
- **Release / knowledge:** **2026-02-05** (same day as Opus 4.6). Knowledge cutoff not stated in the sources reviewed. **Deprecated**, superseded by the newer Codex line and GPT-5.6 "Sol" generation.
- **IDs:** `gpt-5.3-codex` (OpenAI/Azure API) / `opencode/gpt-5.3-codex` (this dataset).
- **Context window:** **400,000 (400K) total; 128,000 (128K) output** — confirmed (Venice: "400K context"). Solid but below the 500K (Grok 4.5) and 1M (Opus 4.6, Gemini) tiers; the 128K output window is generous for large code generation.
- **Modalities:** ⚠ **Meta correction — text + IMAGE in → text out (vision), NOT the scaffolded meta's "Text in/out."** Confirmed by the **Azure AI catalog** ("Multimodal reasoning: **accepts both text and image inputs** — ideal for reasoning across code, UI states, architecture diagrams, and design comps"), **Venice** ("agentic coding model **with vision**"), OpenAI's developer docs ("all latest OpenAI models support **text and image input**"), and OpenAI's own **OSWorld 74.0%** figure "with a newly introduced API parameter that **preserves the original image resolution**." Vision is **coding/computer-use-focused** (UI states, diagrams, screenshots) — **no video, no audio**.
- **Pricing (as of 2026-10-24):** **$1.75 input / $14.00 output per 1M; $0.175 cached.** The **$14/M output is frontier-expensive** (vs Grok 4.5's $6 with 4.2× token efficiency), and the model is **25% faster** than its predecessor (cheaper per task on latency), but for an output-heavy coding agent the sticker is high — and it is **deprecated**, so there is little reason to pay for it over the newer Codex/Sol generations.
- **Architecture:** **Closed / proprietary — parameter count and internals not disclosed.** A **reasoning model** (configurable effort; headline numbers at "xhigh") that **merges the GPT-5.2-Codex coding line with GPT-5.2-class reasoning**, trained with a notable **self-referential/bootstrapping** element (early versions helped debug its own training pipeline and manage deployment).

### Raw benchmarks found

The launch table is **OpenAI-self-reported at "xhigh" reasoning effort**; paddo.dev's independent read is that Terminal-Bench 2.0 is "the only direct comparison" and "independent testing will tell the real story." The one neutral anchor is **Vals AI**.

**Independent — Vals AI SWE-bench Verified (bash-tool-only neutral harness):**

- **GPT 5.3 Codex: 90 / 73 / 55 / 33** by difficulty band (<15 min / 15 m–1 h / 1–4 hr / >4 hr) — a **strong top band (90%)** that **declines on long-horizon work (33% at >4 hr)**. For scale: Grok 4.5 = 94/84/74/67, GPT 5.2 = 89/72/38/33, Claude Opus 5 = 98/97/90/100. So 5.3-Codex's independent long-horizon is mid-pack — well below Grok 4.5's 74/67.

**Vendor — OpenAI launch table (self-reported, "xhigh" effort; paddo.dev + OpenAI):**

- **Terminal-Bench 2.0: 77.3%** — vs Opus 4.6 **65.4%** (the only direct same-benchmark comparison; "GPT reclaims the lead"; Terminal-Bench "jumped from 64% to 77.3% in under two months")
- **SWE-bench Pro: 56.8%** — OpenAI's chosen coding metric; **middling** (Fable 5-max 80.4%, Opus 4.8-max 69.2% on the same benchmark). *Not* comparable to Anthropic's SWE-bench Verified (Opus 4.6 80.8%).
- **OSWorld-Verified: 64.7%** at launch (up from 38.2%); **74.0%** with a later image-resolution-preserving API parameter (per OpenAI's GPT-5.4 page) — strong computer use
- **GDPval: 70.9%** — strong professional/knowledge work (Opus 4.6 reported 1,606 Elo on a different scale)
- **Cybersecurity CTF: 77.6%** — new category; first OpenAI "High capability" security model
- **SWE-Lancer IC Diamond: 81.4%** — freelance-style engineering tasks
- **Meta's vendor reasoning claims: GPQA 91.52%, HLE 42.49%** — high (HLE 42.49% is elite) but **self-reported and not independently confirmed** in the sources reviewed.

### Normalized scores (1–100)

- **Tool use: 84/100.** A genuinely broad agentic surface — **interactive collaboration** (steer mid-task), **computer use (OSWorld-Verified 64.7→74.0%)**, **GDPval 70.9%** (professional work), **Cybersecurity CTF 77.6%** (first OpenAI "High capability" security model), built for "all of the work in the software lifecycle — debugging, deploying, monitoring, writing PRDs." Held **below Grok 4.7 (88)** and the independently-verified agentic leaders because **every tool number is OpenAI-self-reported at "xhigh"** (no AA Index), and the model is **deprecated**. Strong, but vendor-attested.
- **Reasoning: 84/100.** The "codex merger" explicitly folds in **GPT-5.2-class reasoning**, and the vendor marks are elite — **GPQA 91.52%, HLE 42.49%** (HLE in particular is among the highest I've recorded). But these are **self-reported at xhigh with no independent AA Index or replication**, and the model is deprecated. Scored **level with the strong-vendor tier and just below Kimi K2.6 (85, independent AA Index 54)** — the reasoning is clearly strong, but unverified independently.
- **Context window: 80/100.** **400K total / 128K output** — solid, with a generous output window for large code generation, but **below the 500K (Grok 4.5, 83) and 1M (Opus 4.6, Gemini, 85) tiers**. Scored above the 256K models (Kimi K2.6 78) and level with a strong-400K coding agent.
- **Multimodal: 78/100.** **Text + image (vision)** — corrected from the meta's "text-only" — with **strong computer-use/UI vision (OSWorld-Verified 64.7% at launch, 74.0% with resolution preservation)**, well above GPT-5.2's weak OSWorld 37.9%. But vision is **coding-focused** (UI states, architecture diagrams, design comps, screenshots) and there is **no video, no audio**. Scored **just above the image-only-with-weak-vision floor (Grok 4.7 77)** on the strength of its OSWorld computer use, **below the video/audio models (79–82)** on breadth.
- **Coding: 85/100.** Its raison d'être and the strongest dimension: **Terminal-Bench 2.0 77.3% (reclaims the lead over Opus 4.6's 65.4%)**, **SWE-Lancer IC Diamond 81.4%**, an **independent Vals top band of 90%**, and the "most capable agentic coding model" framing. Scored **level with GPT-5.2 / Kimi K2.6 / Grok 4.5 (85)** — but held **below Grok 4.5's elite long-horizon** because the **independent Vals row declines to 55%/33% at 1–4 hr / >4 hr**, the vendor **SWE-bench Pro (56.8%) is middling** (Fable 5 80.4%, Opus 4.8 69.2%), the numbers are **self-reported at xhigh**, and the model is **deprecated**.
- **Cost efficiency: 73/100.** **$1.75/$14.00 per 1M ($0.175 cached)** — the **$14/M output is frontier-expensive** for an output-heavy coding agent, with no token-efficiency claim beyond "25% faster" (contrast Grok 4.5's $6 output + 4.2× fewer tokens, scored 86). Compounded by **deprecated status** — paying a premium for a superseded model is poor value when the newer Codex/Sol generations exist. Scored **well below the open-weight and token-efficient leaders**; scored but **not** counted in the Overall per methodology.
- **Overall Score: 82/100.** Mean of Tool 84 + Reasoning 84 + Context 80 + Multimodal 78 + Coding 85 = 411/5 = 82.2 → 82. Best fit *at launch*: **frontier agentic software engineering** — long coding sessions, computer-use/desktop automation, cybersecurity tasks, and professional knowledge work (GDPval) inside the Codex app/CLI/IDE, where the Terminal-Bench lead and merged reasoning earned their keep. **Today it is deprecated** — the practical guidance is to **migrate to the newer Codex/Sol generations**; it is *not* the pick for cost-sensitive work ($14/M output), for long-horizon autonomous runs (Vals 33% at >4 hr), for video/audio multimodal, or for anyone needing independent (non-self-reported) benchmark assurance. **Divergence note:** my 82 is **3.0 below the queue's curated 85**, driven by the **self-reported-at-xhigh vendor table** (no AA Index; the SWE-bench Pro-vs-Verified mismatch), **mid-pack independent long-horizon coding** (Vals 55/33 at the top bands vs Grok 4.5's 74/67), **expensive output + deprecated status**, and **image-only (coding-focused) vision** — against genuinely strong launch results (Terminal-Bench 77.3% reclaiming the lead, elite vendor GPQA/HLE, first "High capability" cybersecurity model) and a strong independent Vals top band (90%).
