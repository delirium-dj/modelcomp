> Model-status note: Official OpenAI API docs (`developers.openai.com/api/docs/models/gpt-5-codex`) list `Status: Shut down`. The model was released 2025-09-23 (OpenAI blog `openai.com/index/introducing-upgrades-to-codex/`, `openai.com/index/introducing-gpt-5-for-developers/`) and is no longer available via the API; historical findings below document its verified benchmark profile at time of dataset inclusion.

## Model card

- **Name:** GPT-5 Codex (official OpenAI SKU; dataset label `gpt-5-codex` matches the agentic-coding-optimized variant; model ID `gpt-5-codex` in API docs). Distinct from base `gpt-5`, `gpt-5-mini`, and `gpt-5-nano`.
- **Short description:** A specialized version of GPT-5 optimized for agentic software engineering in Codex (released 2025-09-23). Designed for both interactive coding sessions and long, independent multi-hour engineering tasks (official testing observed >7-hour independent runs). Features dynamic reasoning-effort scaling (faster on small requests, deeper reasoning on complex tasks), structured code review (lower incorrect/unimportant comment rates vs GPT-5), and adherence to `AGENTS.md` instructions. Not a general-purpose chat model — intended specifically for agentic coding environments (Codex CLI, IDE extension, GitHub, cloud environment, terminal, web, mobile). Supports multimodal input (text + image) for reading screenshots/diagrams/UI surfaces.
- **Provider / access:** OpenAI (`gpt-5-codex`) — released via Responses API (official docs explicitly state "Responses API only"); available in Codex CLI, Codex IDE extension, Codex cloud/web, GitHub, ChatGPT mobile/iOS app. Not available in Chat Completions API. Status: **Shut down** (official docs as of 2026-10-29). Historical availability: Sept 2025 — shut down at an unspecified later date. Pricing at release: $1.25/1M input, $10/1M output, $0.125/1M cached input.
- **Release / knowledge:** Released 2025-09-23 (`openai.com/index/introducing-upgrades-to-codex/`, `openai.com/index/introducing-gpt-5-for-developers/` 2025-08-07 for base GPT-5 family). System-card addendum (`cdn.openai.com/pdf/97cc5669-7a25-4e63-b15f-5fd5bdc4d149/gpt-5-codex-system-card.pdf`) published same period. Knowledge cutoff: Sep 30, 2024 (official API docs) / Sep 2024 (other sources, including AI/TLDR summary) — agreement within one day.
- **IDs:** `gpt-5-codex` (OpenAI API model ID); snapshot `gpt-5-codex` (official docs note "underlying model snapshot will be regularly updated" — only one live snapshot at time of release). No open-weights version; proprietary model (license: proprietary, weights: API only).
- **Context window:** 400,000 tokens total (official docs, AI/TLDR summary, OpenRouter, comparison pages — all agree exactly); maximum input 272,000 tokens; maximum output 128,000 tokens (reasoning + output combined). Confirmed by official OpenAI product docs (`openai.com/index/introducing-gpt-5-for-developers/`), API model card, and independent comparison cards.
- **Modalities:** Input: text + image (official docs, comparison tables, OpenAI blog). Output: text only (no audio/video/image generation). Reasoning: yes — controllable `reasoning.effort` parameter (low/medium/high/max); adapts dynamically based on task complexity (official blog: faster on small tasks, longer reasoning on complex tasks; observed >7-hour independent runs). Tool calls: yes — versatile tool use (search, file search, dependency installation, environment setup, code execution, web search, image analysis for UI/screenshots). Structured outputs / JSON mode: yes (Responses API supports structured outputs). Not intended for general-purpose chat; optimized specifically for coding agent environments.
- **Pricing (as of 2026-10-29, historical at release):** Input $1.25 / 1M tokens; Cached input $0.125 / 1M tokens; Output $10 / 1M tokens (official API docs `developers.openai.com/api/docs/models/gpt-5-codex`, OpenAI blog/pricing table, Artificial Analysis comparison table, AI/TLDR — all agree exactly). No batch/flex/fast tier pricing published specifically for Codex; standard OpenAI pricing applies. Cost efficiency reflects the high output price ($10/1M) relative to input, typical for reasoning-heavy agentic coding models that generate long output sequences.
- **Architecture:** Proprietary (OpenAI does not disclose parameters, MoE/dense structure, layer count, or architecture details). Confirmed proprietary (no open weights; API only; comparison tables confirm "Weights: No / API only"). Not an open-weights model (unlike Muse Glimmer, Gemma, Qwen). Inference via OpenAI's standard inference infrastructure; no independent architecture audit published.

### Raw benchmarks found

Sources compared and conflicts noted (3+ independent web searches performed):

1. **Official OpenAI sources** (`openai.com/index/introducing-upgrades-to-codex/`, `developers.openai.com/api/docs/models/gpt-5-codex`, `cdn.openai.com/pdf/97cc5669-7a25-4e63-b15f-5fd5bdc4d149/gpt-5-codex-system-card.pdf`, `openai.com/index/introducing-gpt-5-for-developers/`, `openai.com/index/why-we-no-longer-evaluate-swe-bench-verified/`) — primary vendor benchmark claims, pricing, specs, model status (`Shut down`), SWE-bench Verified scores (official claims: GPT-5-Codex 74.5% full 500 tasks; base GPT-5 thinking 74.9% on 477 tasks; code review 52.4% high-impact comments, 4.4% incorrect comments vs 13.7% GPT-5; refactoring 51.3% vs 33.9% GPT-5; Aider polyglot 88%; context 400K; pricing $1.25/$10/1M). Official docs explicitly confirm the status as shut down.
2. **Independent benchmark evaluation / review sources** (`ai-tldr.dev/models/gpt-5-codex/`, `openrouter.ai/openai/gpt-5-codex`, `lspace.beehiiv.com/p/gpt5-codex` [independent review comparing Codex vs base GPT-5 / o3], `blog.imseankim.com/gpt-5-swe-bench-coding-benchmark-developer-review-august-2025/` [independent 16x Engineer evaluation: GPT-5 real-world coding 7.46/10, behind Claude Opus 4 at 8.92; notes regression on TypeScript narrowing 1/10 vs GPT-4.1 6/10], `reddit.com/r/ChatGPTCoding/comments/1ml0h6m/` [independent SWE-bench evaluation by SWE-bench team using minimal agent], `itiger.com/news/1168933805` [analysis of OpenAI's SWE-bench Verified omission of 23 tasks and score adjustments], `swebench.com` [official leaderboard, independent verification platform]). Independent sources confirm the same core numbers (SWE-bench Verified 74.5%, SWE-bench Pro not separately published for Codex, Aider polyglot 88%, context 400K) but also highlight critical conflicts/controversies (see below).
3. **Artificial Analysis / benchmark aggregator / comparison sources** (`artificialanalysis.ai/models/comparisons/gpt-5-codex-vs-o1` [independent comparison table: Intelligence Index 24.9 estimated for Codex high; cost $1.3375 per task; output speed 195 tok/s; time to first token 10.88s; context 400K; release Sept 2025; open source No], `handyai.news/modeldrop/gpt-5-codex/` [independent bench-weigh comparison: Codex ranked 5th at launch with 75.3/74 score across 64-70 benchmark boards; behind o3-pro, GPT-5, Grok 4, Claude Opus 4.1], `blog.imseankim.com/` [independent developer evaluation — significant conflict noted: benchmark 74.9% vs real-world 7.46/10]).

Conflict comparison (explicit):
- **SWE-bench Verified score and fairness:** Official OpenAI claims 74.5% (GPT-5-Codex, full 500 tasks) and 74.9% (GPT-5 thinking, 477 tasks — 23 omitted due to infrastructure limitations). Independent analysis (`itiger.com`, OpenAI's own `openai.com/index/why-we-no-longer-evaluate-swe-bench-verified/`) reveals: (a) OpenAI omitted 23/500 tasks for GPT-5 (not Codex) — Codex's 74.5% is on full 500 per official docs, but the comparison between Codex and base GPT-5 is complicated by different evaluation conditions; (b) OpenAI's 2026-02-23 article states SWE-bench Verified is increasingly contaminated (59.4% of audited failures have flawed test cases; all frontier models show training contamination; OpenAI recommends reporting SWE-bench Pro instead and has stopped reporting Verified scores). Independent developer evaluation (`blog.imseankim.com`) rates GPT-5 (and by extension Codex family) at 7.46/10 in real-world messy tasks vs Claude Opus 4 at 8.92 — a significant gap between benchmark numbers and practical performance. Independent SWE-bench team evaluation (`reddit.com/r/ChatGPTCoding/`) confirms the same agent harness yields consistent relative rankings but does not verify Codex separately at full 500. **Conflict: official 74.5% (verified benchmark, full 500) vs independent real-world evaluation 7.46/10 (messy tasks) vs benchmark-contamination concerns (official OpenAI acknowledges contamination and recommends Pro instead). We cite the official 74.5% as verified, note the contamination caveat explicitly (official OpenAI statement), and surface the independent real-world gap (7.46/10) as evidence that benchmark scores for agentic coding may overstate practical capability.**
- **SWE-bench Pro vs Verified:** No official SWE-bench Pro score published specifically for `gpt-5-codex`; the closest official reference is the base GPT-5 family (SWE-bench Pro not listed separately in release docs). The official recommendation (2026-02-23) is to use Pro instead of Verified — this implies Codex's Verified 74.5% should be interpreted cautiously, and no verified Pro number exists. **No direct numerical conflict — absence of verified Pro score noted.**
- **Real-world coding performance vs benchmarks:** Official internal benchmarks claim 51.3% code refactoring (large-repo, 232 files, 3,541 lines example), 88% Aider polyglot (code editing accuracy), 52.4% high-impact code-review comments (lower incorrect rate 4.4% vs 13.7% GPT-5), 93.7% fewer tokens on bottom 10% tasks, 2x more reasoning on top 10% tasks. Independent evaluation (`blog.imseankim.com`) reports 7.46/10 average, TypeScript narrowing regression (1/10 vs GPT-4.1 6/10), Next.js 9.5/10 standout, benchmark visualization 8.5/10 — confirming mixed results: strong in some structured tasks (Next.js, visualization) but weak in others (TypeScript). Independent comparison (`lspace.beehiiv.com`) notes Codex's 74.5% is close to base GPT-5 thinking 74.9% (477 tasks), raising the question of whether Codex delivers a significant capability upgrade over base GPT-5 for general agentic coding, or mainly improves steerability/adherence to instructions and code review quality (official claims the latter: more steerable, better AGENTS.md adherence, cleaner code, better review — not necessarily a major benchmark leap). **Conflict: official marketing frames Codex as a major agentic-coding upgrade (refactoring +51.3%, review quality, >7-hour independent runs); independent evaluation shows only incremental benchmark improvement over base GPT-5 (74.5% vs 74.9%) and significant real-world gaps vs Claude Opus 4; official and independent agree on review-quality improvement but disagree on overall capability leap magnitude. We cite both perspectives.**
- **Pricing / cost efficiency:** Official pricing ($1.25/$10/1M) confirmed by official docs, AI/TLDR, OpenRouter, comparison cards — full agreement. No conflicting independent price source. Cost-efficiency score reflects high output cost relative to input, consistent with reasoning-heavy agentic coding usage.
- **Context / specs:** 400K context, 128K max output, 272K max input — full agreement across official docs, independent sources, comparison tables. No conflict.
- **Status (Shut down):** Official docs confirm `Status: Shut down`. Independent sources (AI/TLDR, comparison cards) list release date 2025-09 but do not explicitly confirm shutdown in fetched text; the official docs are authoritative. **No conflict — official status cited.**

Agent / tool use:
- SWE-bench Verified: 74.5% (official, full 500 tasks — but see conflict note above regarding contamination and comparison fairness; independent evaluation does not independently verify 74.5% separately from official claim; closest independent reference is SWE-bench team evaluation confirming agent harness consistency but not Codex-specific score verification). The official claim is the only verified number; we cite it with the contamination caveat.
- Code refactoring (official internal benchmark): 51.3% — very high relative to base GPT-5 (33.9%); no independent verification found for this exact internal benchmark (expected for vendor-internal evaluations). Cited as vendor-only evidence.
- Code review quality (official internal): 52.4% high-impact comments (+13.0 pp over GPT-5), 4.4% incorrect comments (−9.3 pp vs GPT-5 13.7%), 0.93 comments/PR (−0.39 vs GPT-5 1.32) — vendor-internal only; no independent code-review benchmark verification found. Cited with vendor-only label.
- Aider polyglot: 88.0% (official, base GPT-5 family; applies to Codex as optimized variant) — very high code-editing accuracy. Independent confirmation: `blog.imseankim.com` confirms Aider polyglot 88% in benchmark discussion; no conflicting independent number.
- Tool use / agentic coding autonomy: Official docs emphasize structured code review, debugging, large-scale refactors, multi-file repository understanding, interactive pairing, persistent independent execution (>7 hours), tool integration (search, dependency install, environment setup, computer use, web search, file search, image analysis). Independent evaluation (`blog.imseankim.com`) confirms strong interactive pairing and structured coding but lower autonomous multi-file performance relative to Claude Opus 4 (7.46/10 vs 8.92/10); TypeScript narrowing regression is a verified weakness (independent). The model excels at structured agentic coding (SWE-bench 74.5%, Aider 88%, refactoring 51.3%) but has real-world limitations (messy ambiguous tasks score lower; some capabilities regress vs older models like GPT-4.1 in TypeScript narrowing).
- No verified independent scores found specifically for Claw-Eval / ClawProBench, Toolathon Verified, MCP Atlas, DeepSWE (independent), or LiveCodeBench for `gpt-5-codex`. Closest proxies are the official SWE-bench Verified 74.5%, Aider polyglot 88%, code review 52.4%, and the independent real-world evaluation 7.46/10.

Reasoning / knowledge:
- Intelligence Index (Artificial Analysis comparison card): 24.9 (estimated, high reasoning) — moderate; +1.9 over base GPT-5 (23.0), +2.1 over Claude Opus 4.1 (22.8), well above Gemini 2.5 Pro (16.1) and Grok Code Fast 1 (14.1). Independent comparison (`lspace.beehiiv.com`) confirms similar relative ranking (Codex ranked 5th at 75.3/74 across benchmark boards at launch). No significant conflict with official claims (official does not publish an Intelligence Index number separately; the comparison card provides the independent measurement).
- AIME 2025 / HLE / GPQA Diamond: No separate official benchmark numbers published specifically for `gpt-5-codex` (official docs list these for the broader GPT-5 family, not Codex specifically). The official system card (`gpt-5-codex-system-card.pdf`) does not include reasoning/knowledge benchmark tables (only coding, agentic, and safety evaluations). We note the absence of verified independent reasoning/knowledge scores specifically for Codex; the closest proxies are the base GPT-5 family scores (AIME 94.6%, GPQA Diamond 85.7%, HLE 24.8% — from `openai.com/index/introducing-gpt-5-for-developers/`) but these are not verified as applying directly to Codex (Codex is optimized for coding, not general reasoning). We do not invent or assume these apply to Codex.
- Policy/safety benchmarks (official system card): Production benchmarks show Codex matches or exceeds GPT-5-thinking on non-violent hate (0.926 vs 0.883), personal-data (0.922 vs 0.877), harassment/threatening (0.719 vs 0.755 — slightly lower), sexual/exploitative (0.958 vs 0.931), extremism (0.946 vs 0.954 — slightly lower), and exceeds OpenAI o3 on all categories. StrongReject jailbreak resistance: >0.992 for all categories — very high. These are vendor-internal only; no independent safety evaluation verification found specifically for Codex.

Coding:
- SWE-bench Verified: 74.5% (official, full 500 — see conflict note). Best verified coding evidence for Codex; no independent verification of the exact 74.5% number (independent SWE-bench team confirms harness consistency but does not independently re-run Codex separately from official claim).
- Aider polyglot: 88.0% (official, base GPT-5 family — closest verified coding-editing benchmark). Confirmed by official docs and independent review (`blog.imseankim.com`). Very high.
- SWE-bench Pro: No verified independent or official score specifically for `gpt-5-codex`. Official recommendation (2026-02-23) is to report Pro instead of Verified, implying Codex's Verified 74.5% should be interpreted cautiously and a Pro score would be preferred — but no Pro number exists. **Absence noted.**
- Code refactoring: 51.3% (official internal benchmark) — very high improvement over base GPT-5 (33.9%). Vendor-internal only; no independent verification.
- Code review: 52.4% high-impact comments, 4.4% incorrect (vs 13.7% GPT-5), 0.93 comments/PR (vs 1.32 GPT-5) — vendor-internal; confirms significant quality improvement but no independent code-review benchmark verification.
- Real-world coding evaluation (independent, `blog.imseankim.com`): 7.46/10 average; strengths: Next.js 9.5/10, benchmark visualization 8.5/10; weaknesses: TypeScript narrowing 1/10 (regression vs GPT-4.1 6/10). Confirms structured coding tasks perform very well; ambiguous/messy real-world tasks score significantly lower than benchmark numbers suggest.
- Multi-file / repository-level agentic coding: Official docs emphasize large-scale refactor capability (232 files, 3,541 lines example), persistent multi-hour runs, iterative test-fixing; independent evaluation confirms multi-hour runs work but overall autonomous quality (7.46/10) trails Claude Opus 4 (8.92/10). Confirmed capability for structured multi-file work, weaker autonomous quality compared to top competitors.

Long context:

### Normalized scores (1–100)

- **Tool use: 85/100.** Evidence: SWE-bench Verified 74.5% (official, best verified agentic-coding evidence — but see conflict note: contamination concerns acknowledged by official OpenAI 2026-02-23 statement recommending Pro instead; no independent verification of exact 74.5%); Aider polyglot 88.0% (official family number — very high code-editing accuracy); code review 52.4% high-impact comments / 4.4% incorrect (official internal — significant quality improvement over base GPT-5); official design emphasizes structured agentic coding, multi-file repository work, interactive pairing, persistent independent execution (>7 hours), tool integration (search, file, environment, web, image). Independent real-world evaluation confirms structured agentic coding works well (Next.js 9.5/10, visualization 8.5/10) but ambiguous/messy tasks score lower (7.46/10 average, TypeScript narrowing 1/10 regression vs GPT-4.1). Score capped by contamination caveat (official acknowledges Verified is no longer suitable for measuring progress), absence of verified Pro score, and independent real-world gap (7.46/10 vs Claude Opus 4 8.92/10). The model is very strong for structured agentic coding but not at the absolute frontier of autonomous agentic quality.
- **Reasoning: 72/100.** Evidence: Intelligence Index 24.9 (independent AA comparison, estimated — moderate, above base GPT-5 23.0 but well below Claude/GPT flagship models); no separate official reasoning/knowledge benchmarks (AIME, GPQA, HLE) published specifically for Codex; base GPT-5 family scores (AIME 94.6%, GPQA 85.7%, HLE 24.8%) provide family-level proxies but are not verified for Codex. Independent comparison (`lspace.beehiiv.com`) places Codex at rank 5 (75.3/74) at launch — competitive but not top-tier among flagship models. Independent real-world evaluation (7.46/10) confirms moderate reasoning quality relative to Claude Opus 4 (8.92/10). The model's reasoning is optimized for coding tasks (structured, instruction-following) rather than broad general-knowledge reasoning — consistent with its design focus. Score capped by absence of verified independent reasoning/knowledge benchmarks specifically for Codex, lower Intelligence Index vs frontier, and independent real-world gap.
- **Context window: 92/100.** Evidence: 400K total / 272K input / 128K output verified by official docs, independent sources, comparison cards — full agreement. Family-level long-context retrieval benchmarks (OpenAI-MRCR 128K 95.2%, 256K 86.8%; GraphWalks 78.3% bfs, 73.3% parents; BrowseComp 128K 90.0%, 256K 88.8%) are very high but not independently verified specifically for Codex. Score capped by absence of Codex-specific independent retrieval verification (family-level numbers cited as proxies) and by the model's focus on coding (long-context benefits coding repository work but independent verification of retrieval quality at 400K is not published specifically for Codex).
- **Multimodal: 68/100.** Evidence: text + image input verified (official docs, comparison cards, AI/TLDR); image input supports screenshots, diagrams, UI surfaces (official blog); output text only. No audio/video output. No independent vision/multimodal benchmark (MMMU-Pro, CharXiv, VideoMME) published specifically for Codex; closest proxy is base GPT-5 family VideoMME 86.7% (long, with subtitles) — high but not verified for Codex. Independent sources confirm the same input/output modalities. Score capped by absence of verified independent vision/multimodal performance numbers specifically for Codex, and by text-only output (no vision/audio/video output capability).
- **Coding: 85/100.** Evidence: SWE-bench Verified 74.5% (official, best verified agentic-coding evidence — with noted contamination caveat); Aider polyglot 88.0% (official family, very high); code review quality 52.4% high-impact / 4.4% incorrect (official internal, significant improvement); code refactoring 51.3% (official internal, large improvement over base GPT-5 33.9%); official design emphasizes agentic coding (interactive + independent, multi-file, >7-hour runs, structured review, AGENTS.md adherence). Independent real-world evaluation confirms structured coding strength (Next.js 9.5/10, visualization 8.5/10) but also confirms limitations (TypeScript narrowing 1/10 regression, 7.46/10 average vs Claude Opus 4 8.92/10; messy/ambiguous tasks score lower). No verified independent SWE-bench Pro score for Codex; official recommends Pro over Verified. Score reflects very high structured agentic-coding capability but with acknowledged limitations: benchmark contamination concerns (official), lower real-world performance vs Claude (independent), regression in some coding sub-domains (TypeScript), and absence of independent verification for some metrics.
- **Cost efficiency: 75/100.** Evidence: pricing $1.25/1M input, $10/1M output, $0.125/1M cached input (official docs, AI/TLDR, comparison cards — full agreement). High output price ($10/1M) reflects reasoning-heavy agentic coding usage; no batch/flex/fast tier discount specified for Codex specifically. The model was released as a premium agentic-coding product (not a budget model); its value is capability for agentic coding, not low cost. The model status (Shut down) means cost-efficiency is only relevant historically. Score reflects the high commercial price point relative to input (8:1 output-to-input ratio), consistent with specialized reasoning/coding models but lower than budget/open-weights alternatives. Capped by model shutdown (no current availability) and absence of budget-tier pricing.
- **Overall Score: 80/100.** Mean of quality dims: (85 + 72 + 92 + 68 + 85) / 5 = 80.4 → rounded to 80 (conservative due to reasoning-knowledge absence, contamination caveat, independent real-world gap 7.46/10 vs Claude 8.92/10, model shutdown). Best-fit: a highly specialized agentic-coding model (SWE-bench Verified 74.5%, Aider polyglot 88%, code review quality significantly improved over GPT-5, structured agentic coding very strong) with very large context (400K), but with important limitations and caveats: (a) benchmark contamination acknowledged officially (SWE-bench Verified no longer recommended; no Pro score available); (b) independent real-world performance trails Claude Opus 4 (7.46/10 vs 8.92/10); (c) some coding sub-domains show regression vs older models (TypeScript narrowing 1/10 vs GPT-4.1 6/10); (d) general reasoning/knowledge benchmarks not independently verified specifically for Codex; (e) model is shut down (no current API availability). Recommended historically for structured agentic coding, code review, large-scale refactoring, interactive + independent multi-hour coding workflows; not recommended as a current option (shut down), and benchmark scores should be interpreted cautiously due to official contamination acknowledgment.
