> **Verdict:** GPT-5-Codex is **OpenAI's original coding-specialist GPT-5** (released **2025-09-23**) — the model that, per the curated meta, **"made Codex the default coding surface."** It is a **reasoning** (High-effort) variant of GPT-5 **"further optimized for agentic software engineering in Codex"**, with a **400K context**, **text + image → text** I/O, priced at **$1.25/$10 per 1M** (input *very competitive* vs the $2.00 median; output at the $10.00 median; 90 % cache discount; OpenCode Zen $1.07/$8.50). Its launch story was **efficiency + agentic coding**: **SWE-bench Verified 74.5 %**, an internal **code-refactor 51.3 %**, **~72 % faster than GPT-5 on SWE-bench tasks with ~70 % fewer output tokens**, and **93.7 % fewer tokens than GPT-5-Patch** on simple tasks — achieved by **dynamically scaling its "thinking" time to task complexity**. Independently, **Artificial Analysis confirms only its efficiency: Speed 186.9 tok/s (#16/196, 4/4 units, "notably fast")** — but the **Intelligence Index is N/A (delisted)** because the model is **deprecated** ("OpenAI has launched a newer release, GPT-5.1 Codex. We suggest considering it instead"), and it was **removed from Codex in 2026-04**. Catches: there is **no public Terminal-Bench or LiveCodeBench figure of its own**, the **74.5 % SWE-bench Verified is vendor-reported** (and SWE-bench Verified is now widely flagged as contaminated), it is **Responses-API-only**, and it is **superseded** by the whole 5.1/5.2/5.3-Codex line. Net: **Overall 77 (divergence +4.3 vs the curated 73.1)** — a genuinely landmark agentic coder for its moment (400K, image-capable, very fast and token-efficient) whose score I hold above the curator because I credit the real 400K context + #16/196 speed + the era-defining Codex role, but capped by deprecation, a delisted Index and vendor-only coding evidence.

### Normalized scores (1–100)

- **Tool use: 76/100.** A **dedicated agentic coder** — the model that made **Codex** the default agentic-coding surface, doing repo-scale refactors, code review, bug-fixing and test-running with **dynamically-scaled thinking** and **~70 % fewer output tokens** (well-suited to long agent loops). Held below the independently-verified agentic leaders because it is **deprecated/Responses-API-only**, the **AA Index is delisted (N/A)**, and there is **no independent agentic harness** (Terminal-Bench/AutomationBench) result of its own — the agentic evidence is vendor-only.
- **Reasoning: 74/100.** It **is** a reasoning model (High-effort; its signature trick is **dynamically adjusting thinking time to task complexity**), but there is **no published pure-reasoning benchmark** (no AIME/GPQA/HLE) and the **AA Intelligence Index is N/A (delisted on v5.0)**. Reasoning-capable and clearly competent at code reasoning, but **unmeasured** on any current independent scale — so I cannot credit a frontier reasoning score.
- **Context window: 82/100.** **400K** native (AA-confirmed, ~600 A4 pages) with **128K max output** — a large, repo-scale-friendly window (the whole point of an agentic coder), though short of the 1M frontier norm and with no independent RULER/MRCR @400K long-context figure published.
- **Multimodal: 78/100.** **Text + image input → text output** (AA-confirmed: can analyze/describe/answer questions about images — useful for screenshot-driven UI/code work). The verified **image-only** tier: **no video, no audio, text-only output.**
- **Coding: 77/100.** Its reason for existing — **vendor SWE-bench Verified 74.5 %** (near-top at its Sep-2025 release; a third-party review saw ~77 %), **code-refactor 51.3 %**, **93.7 % fewer tokens than GPT-5-Patch**, and the "default coding surface" pedigree. Capped at strong-published rather than elite because it is **deprecated/removed (2026-04)**, the SWE-bench figure is **vendor-only** (no independent Terminal-Bench/LiveCodeBench of its own), SWE-bench Verified is now widely flagged as **contaminated**, and it is **superseded** by the higher-scoring 5.1/5.2/5.3-Codex line.
- **Cost efficiency: 73/100.** *(Not counted in Overall.)* Good on paper — **$1.25/$10** (input *very competitive* vs the $2.00 median), **90 % cache discount**, **exceptionally token-efficient (93.7 % fewer tokens / "a sixth of the tokens")** and **fast (186.9 tok/s, #16/196)** — but it is **deprecated and removed from Codex**, **Responses-API-only**, and has **no free tier** (`noFreeId`), so the practical value is largely historical.
- **Overall Score: 77/100.** Half-up mean of the five quality dims: (76 + 74 + 82 + 78 + 77) / 5 = 387 / 5 = **77.4 → 77**. **Divergence +4.3** vs the curated 73.1. GPT-5-Codex is the **landmark original agentic-coding GPT-5** — 400K context, image-capable, **186.9 tok/s (#16/196)**, dramatically token-efficient, vendor SWE-bench Verified 74.5 % — whose weaknesses are that it is **deprecated/removed (2026-04)**, **delisted (AA Index N/A)**, **Responses-API-only**, and backed by **vendor-only coding evidence with no independent Terminal-Bench of its own**. My **+4.3** above the curator reflects that I credit the genuine **400K context (82)**, **image multimodality (78)**, **#16/196 speed** and **era-defining Codex role** more than the curated 73.1 does, while still holding it **below the newer Codex siblings** (GPT-5.1-Codex 79, GPT-5.2-Codex 80, GPT-5.1-Codex-Max 80) because it is the oldest, has the least independent verification, and is superseded.
