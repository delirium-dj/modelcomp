## Model card

- **Name:** GPT-5.4 nano (xhigh)
- **Short description:** OpenAI's **March-2026 smallest, cheapest GPT-5.4 tier** — "for tasks where speed and cost matter most," built for **classification, data extraction, ranking, and sub-agent execution**: "cheap OpenAI reasoning for fleets of subagents." It is a **reasoning** model (AA measures the **xhigh** effort variant) with an **AA Intelligence Index 21 (3/4 units, #52/172) — *above* the class median 14**, **164.8 tok/s**, **$0.20/$1.25** per 1M, **text + image in**, **400K context**. Vendor coding is strong-for-nano (**SWE-bench 69.8%, LiveCodeBench 84.0%, Terminal-Bench 2.0 46.3%**). The defining limits: "**the smallest reasoning ceiling — strictly a specialist subagent, never the orchestrator**," and it is **very verbose (190M tokens/run vs median 99M)**. ⚠ **Deprecated** — superseded by **GPT-5.6 Luna** (AA banner).
- **Provider / access:** **OpenAI API only** (`gpt-5.4-nano`) at **$0.20/$1.25** per 1M in/out (**$0.02 cached input**, 90% cache discount); also on **opencode Zen** (`opencode/gpt-5.4-nano`) and OpenRouter. **No free hosted tier id** (`noFreeId: true`). AA: $0.18 per Intelligence Index task.
- **Release / knowledge:** Released **March 17, 2026** (alongside GPT-5.4 mini, report 93). **Knowledge cutoff August 31, 2025.** **Deprecated** — OpenAI's **GPT-5.6 Luna** is the recommended successor; AA only continues the default 10k-token workload.
- **IDs:** `opencode/gpt-5.4-nano`; OpenAI `gpt-5.4-nano`; AA `gpt-5-4-nano` → page titled **"GPT-5.4 nano (xhigh)"** (reasoning variant at xhigh effort; a non-reasoning/lower-effort variant may exist).
- **Context window:** **400,000 (400K)** — ~600 A4 pages; **128,000 (128K) max output**. Same 400K window as the GPT-5.4 mini sibling; double the deprecated Haiku 4.5's 200K.
- **Modalities:** **Text + image in → text out** (AA + llm-stats confirmed multimodal). Vision input supported; **no audio or video**. Matches meta exactly.
- **Pricing (as of 2026-10-28):** **$0.20 / $1.25** per 1M in/out ($0.02 cached; AA: input "moderately priced" vs $0.24 median, output "**somewhat expensive**" vs $0.82 median for the class). The cheapest OpenAI tier by input price; the verbose reasoning output erodes the effective cost advantage.
- **Architecture:** **Proprietary** (parameters undisclosed), **reasoning** model — AA indexes the **xhigh** effort variant. **164.8 tok/s (#45/149, "faster than average," median 114; 3/4 units)** — genuinely fast. **Verbosity 190M tokens (#54/68, "very verbose," 4/4 units)** vs median 99M — the reasoning-token burn is a real trait, notable for a nano priced for high-volume use.

### Normalized scores (1–100)

- **Tool use: 75/100.** Built for **sub-agent execution, classification, extraction, ranking** with **vendor Terminal-Bench 2.0 46.3%** (moderate, a touch above Haiku 4.5) and an above-median AA Index 21 whose basket includes AutomationBench/AA-Briefcase/Terminal-Bench. But the tradeoff is explicit — "**strictly a specialist subagent, never the orchestrator**" (smallest reasoning ceiling), it is **very verbose (190M)** which hurts agentic loop efficiency, and it is **deprecated**. Competent-worker band; a good leaf node, not a planner.
- **Reasoning: 76/100.** A genuine **reasoning** model (xhigh effort) with an **AA Intelligence Index 21 (3/4 units) that is *above* the class median 14** — "above average in intelligence." That is a real step above the non-reasoning, below-median Haiku 4.5 (Reasoning 72). But the absolute ceiling is **the smallest in the GPT-5.4 family** (mini 24, flagship higher), it is **very verbose**, and it is **deprecated**. Above-median small-tier band; below the mini sibling.
- **Context window: 82/100.** **400K tokens** (128K max out) — double the deprecated Haiku 4.5's 200K and equal to the GPT-5.4 mini. Generous for a nano, sized for extraction/classification over long documents and multi-turn subagent histories. The 400K tier; no long-context effectiveness benchmark (MRCR/RULER) published, and a small model has limited deep-retrieval headroom, so it stays at the nominal-400K grade.
- **Multimodal: 78/100.** **Text + image in → text out** (AA + llm-stats confirmed multimodal). Vision input supports document/chart/screenshot extraction and classification — directly relevant to its subagent niche. **No audio or video.** The image-only-verified tier; a clear advantage over the text-only models scored nearby (which floor at 50).
- **Coding: 76/100.** Strong *for a nano*: **vendor SWE-bench 69.8%**, **LiveCodeBench 84.0%** (notably good competitive programming), **Terminal-Bench 2.0 46.3%**. Real coding capability at the smallest/cheapest tier — but **all vendor-reported** (OpenAI launch post, no independent re-verification), the SWE-bench is a hair below Haiku 4.5's 73.3%, and the model is **deprecated** with the "smallest reasoning ceiling." Strong-for-tier vendor band; below the independently-verified larger tiers.
- **Cost efficiency: 86/100.** **$0.20/$1.25** per 1M (cheapest OpenAI input price), **90% cache**, **$0.02 cached input**, and **164.8 tok/s** — excellent sticker value for fleets of subagents. Tempered by **very verbose 190M-token reasoning runs** (nearly 2× median) that multiply the effective output cost, and AA flags output as "**somewhat expensive**" for the class. Strong-but-not-peak value; the verbosity is the hidden tax. Not counted toward Overall.
- **Overall Score: 77/100.** Mean of Tool 75 + Reasoning 76 + Context 82 + Multimodal 78 + Coding 76 = 387 / 5 = 77.4 → 77. Best fit: **the cheap reasoning nano for subagent fleets** — OpenAI's smallest GPT-5.4 tier delivering **above-median reasoning (AA Index 21 > 14), 400K context, text+image input, 164.8 tok/s, $0.20/$1.25, and strong-for-tier coding (LiveCodeBench 84.0%, SWE-bench 69.8%)** for classification/extraction/ranking/sub-agent work — but with **the smallest reasoning ceiling ("never the orchestrator")**, **very verbose 190M-token runs**, and **deprecation → GPT-5.6 Luna**. Ideal historically for **high-volume, cost-sensitive vision+text specialist subagents under a larger orchestrator**; **use GPT-5.6 Luna for the live successor**, **GPT-5.4 mini (79)** for a bigger delegation tier, or a flagship for orchestration. **Divergence note:** curated queue 73.7 vs my 77 → **+3.3**. I credit the **400K context (82)**, **above-median reasoning (76)**, **image multimodality (78)**, and **strong-for-tier coding (76, LiveCodeBench 84.0%)** — the curated score leans harder on the nano's small ceiling, verbosity, and deprecation, which I reflect in Tool 75 and Cost 86 but which don't outweigh the tier's genuine reasoning/context/multimodal strengths. Lands **one above the non-reasoning 200K Claude Haiku 4.5 (76)** — the nano's reasoning + 400K + above-median Index edge out Haiku's slightly-better SWE-bench — and **two below the larger GPT-5.4 mini (79)**.
