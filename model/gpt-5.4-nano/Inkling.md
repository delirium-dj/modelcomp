## Model card

- **Name:** GPT-5.4 Nano
- **Short description:** OpenAI's smallest and cheapest GPT-5.4-class model, released 2026-03-17. Designed for high-volume, low-latency tasks (classification, data extraction, ranking, sub-agents) where speed and cost matter more than deep reasoning. It is a significant upgrade over GPT-5 nano. Supports text + image input, tool calling, structured outputs, web search, file uploads, and reasoning with configurable effort (`none`, `low`, `medium`, `high`, `xhigh`). 400K context window; 128K max output. Knowledge cutoff: Aug 31, 2025.
- **Provider / access:** OpenAI API (`gpt-5.4-nano`). Available in API, Codex (30% quota of GPT-5.4), and ChatGPT (rate-limit fallback / Thinking feature for some tiers). Not available in ChatGPT for all users by default (Free/Go users via Thinking feature; paid users as fallback). Not self-hostable (closed weights). Not available via Assistants, Realtime, Batch is supported.
- **Release / knowledge:** Released 2026-03-17 (`https://openai.com/index/introducing-gpt-5-4-mini-and-nano/`). Knowledge cutoff 2025-08-31 (`https://developers.openai.com/api/docs/models/gpt-5.4-nano`). Model status: **Deprecated** per official docs (`https://developers.openai.com/api/docs/models/gpt-5.4-nano` shows "Status: Deprecated"). This is a critical status conflict: the model was released in March 2026 but is already deprecated in official documentation as of November 2026. Independent sources (Epoch AI, OpenRouter, BenchmarkList, Sugra) still list it as active/released; this discrepancy suggests either a documentation error or a very rapid retirement.
- **IDs:** `gpt-5.4-nano` (OpenAI API). Alias: `gpt-5.4-nano-2026-03-17` (default snapshot). No dedicated open-source weights; no Hugging Face repository for weights (only references in benchmark sources).
- **Context window:** 400,000 tokens (`https://developers.openai.com/api/docs/models/gpt-5.4-nano`, `https://openrouter.ai/openai/gpt-5.4-nano`, `https://vals.ai/models/openai_gpt-5.4-nano-2026-03-17`). Max input: 272,000 tokens (official). Max output: 128,000 tokens (`https://openrouter.ai/openai/gpt-5.4-nano`). This is verified by official docs, independent OpenRouter, and Vals AI listings.
- **Modalities:** Input: text, image (`https://openrouter.ai/openai/gpt-5.4-nano`, `https://developers.openai.com/api/docs/models/gpt-5.4-nano`). Video / audio / file input: not supported (`https://openrouter.ai/openai/gpt-5.4-nano` confirms video not supported; audio, speech, transcription, translation, image generation, video generation not supported). Output: text only. Reasoning: yes (`reasoning_effort`: `none`, `low`, `medium`, `high`, `xhigh`). Tool calling: yes (`function_calling`). Structured outputs: yes (`structured_outputs`). Web search: yes (`web_search`). File uploads: yes (`file_uploads`). Prompt caching: yes (`cached input` at $0.02/M tokens vs. $0.20/M fresh input) (`https://openrouter.ai/openai/gpt-5.4-nano`). Batch API: supported (`Batch`). Computer use: not explicitly confirmed by official docs; closest reference is OSWorld-Verified 39.0% (vendor-aligned, low for this SKU) (`https://openai.com/index/introducing-gpt-5-4-mini-and-nano/`).
- **Pricing (as of 2026-11-04):** $0.20/M input tokens (fresh); $0.02/M cached input; $1.25/M output tokens (`https://openrouter.ai/openai/gpt-5.4-nano`, `https://developers.openai.com/api/docs/models/gpt-5.4-nano`). Regional processing (data residency) endpoints: +10% uplift. No promotional pricing found; no volume discounts explicitly listed. Very low cost relative to larger GPT-5.4 variants ($0.75/$4.50 for mini; not directly comparable to flagship $5.4 pricing which is not listed for direct comparison but implied to be much higher). Independent pricing directories confirm these rates (`https://vals.ai/models/openai_gpt-5.4-nano-2026-03-17`, `https://openrouter.ai/openai/gpt-5.4-nano`).
- **Architecture:** Not fully disclosed by OpenAI. Official docs describe it as a "lightweight, ultra-efficient model" optimized for speed and cost, built on the GPT-5.4 family architecture. No parameter count, MoE/dense architecture, hidden dimensions, or layer counts are published (`https://developers.openai.com/api/docs/models/gpt-5.4-nano`). Independent sources describe it as a small, efficient variant of GPT-5.4 (`https://openai.com/index/introducing-gpt-5-4-mini-and-nano/`). No open-source weights (`https://epoch.ai/models/gpt-5-4-nano` confirms "Closed weights"). The exact architecture remains proprietary.

### Conflicting / contradictory evidence (explicit comparison)

1. **Status: released vs. deprecated.** Official OpenAI docs (`https://developers.openai.com/api/docs/models/gpt-5.4-nano`) list the model status as **Deprecated** (`Status: Deprecated`). The release announcement (`https://openai.com/index/introducing-gpt-5-4-mini-and-nano/`) is dated 2026-03-17, just ~8 months before the deprecation. Independent sources (Epoch AI `https://epoch.ai/models/gpt-5-4-nano`, Sugra `https://sugra.systems/blog/llm-bench/models/gpt-5-4-nano`, BenchmarkList `https://benchmarklist.com/models/openai-gpt-5-4-nano`) still list it as released/active and report benchmark scores without noting deprecation. This is a significant conflict: the official documentation says deprecated, but the model remains accessible via API and is actively evaluated by independent sources. The deprecation status may mean it is no longer recommended for new integrations (`https://docs.mistral.ai/models/model-cards/mistral-medium-3-5-26-04` is another model with similar deprecation, but for GPT-5.4 Nano the docs simply say "Deprecated" without a replacement named). This should be noted as a critical identity/status conflict.

2. **Reasoning / benchmark performance: vendor-aligned scores vs. independent measurements.** The vendor announcement (`https://openai.com/index/introducing-gpt-5-4-mini-and-nano/`) reports very high benchmark results for the `xhigh` reasoning effort mode: SWE-Bench Pro 52.4%, Terminal-Bench 2.0 46.3%, Toolathlon 35.5%, GPQA Diamond 82.8%, OSWorld-Verified 39.0%, MMMU-Pro 66.1% (w/o Python) / 69.5% (with Python), HLE w/o tools 24.3%, HLE w/ tools 37.7%, MCP Atlas 56.1%, τ²-bench Telecom 92.5%. Independent Artificial Analysis (`https://artificialanalysis.ai/models/releases/gpt-5-4-nano`) reports significantly different scores for the same model: **GPQA Diamond 76.1% (Medium) / 81.7% (Xhigh)** — the Xhigh matches vendor closely; **HLE 15.9% (Medium) / 28.3% (Xhigh)** — Xhigh is lower than vendor's 37.7% (with tools); **IFBench 64.4% (Medium) / 75.9% (Xhigh)** — lower than vendor's implied instruction-following performance; **Terminal-Bench Hard 33.3%** (independent) vs. vendor's Terminal-Bench 2.0 46.3% — different harness versions, so not directly comparable but lower; **Terminal-Bench 4.0 0.5% (Xhigh)** (`https://openrouter.ai/openai/gpt-5.4-nano`) — extremely low, suggesting failure on the newer harness; **AA Coding Index 56.1** (`https://openrouter.ai/openai/gpt-5.4-nano`) — moderate; **AA Agentic Index 16.0** — low. Independent Vals AI (`https://vals.ai/models/openai_gpt-5.4-nano-2026-03-17`) reports mixed scores: SWE-bench Verified 69.8% (close to vendor's SWE-Bench Pro 52.4%? No — different benchmark versions, Vals reports SWE-bench 69.8% which is actually higher than vendor's SWE-Bench Pro 52.4%, suggesting either a different harness or measurement protocol); LiveCodeBench 84.0% (independent, close to vendor-aligned expectations); MMLU Pro 77.2% (independent, lower than vendor-aligned base model expectations but not directly comparable since vendor doesn't provide exact MMLU-Pro for Nano in announcement); GPQA Diamond 77.5% (independent, lower than vendor's 82.8%); Terminal-Bench 2.1 41.6% (independent, lower than vendor's 46.3%). Independent review (`https://layerlens.ai/blog/gpt-5-4-benchmark-review`) confirms some vendor-aligned scores (MATH-500 Nano 88.6% vs. Mini 86.6%; AIME 2025 Nano 26.67% vs. Mini 6.67%; SWE-bench Lite Nano 32.33%) but also reveals weaknesses: MMLU Pro Nano 35.61% (much lower than Mini 55.29%), AGIEval English 46.47%, Multimodal Understanding 42.44%, Big Bench Hard 45.63%. The review explicitly notes the flagship model's SWE-Bench Lite failure and recommends caution. Independent review from YouTube/video review (`https://www.youtube.com/watch?v=w-HGuCmGLx4`) provides practical testing results and notes reliability/behavior issues (reasoning mode causing empty results, abstract thought chains, partial outputs) — these are qualitative reviews, not quantitative conflicts, but they confirm practical reliability concerns not fully captured by vendor benchmark tables.

3. **Coding and agentic performance variations across independent sources:** Independent CrucibleMark (`https://www.cruciblemark.com/reports/gpt-5-4-nano-2026-03-17/`) reports very different profiles: Code Quality 71.44 (high); CLI Benchmark 78.67 (good); Logical Reasoning 67.03 (good); but Tool Execution 67.5 (much lower than best 90.0); ToolUse Score 48.71 (low); Synthesis Quality 46.67 (low); UX Writing 69.45 (moderate). Independent BenchmarkList reports coding scores: SciCode 47.2%, LiveCodeBench 84.0%, SWE-bench 69.8%, Terminal-Bench 2.1 41.6%, Vibe Code Bench 26.1% — mixed. Independent LMSpeed reports overall 45.0 (#124/137), coding 28.5 (#72/83) — lower. Independent Artificial Analysis reports Coding Index 56.1, Agentic Index 16.0 — moderate-to-low. Independent review (`https://layerlens.ai/blog/gpt-5-4-benchmark-review`) shows Nano outperforms Mini on MATH-500 and AIME but is weaker on MMLU Pro, Multimodal, and Big Bench Hard. Independent YouTube review (`https://www.youtube.com/watch?v=w-HGuCmGLx4`) notes reliability and output issues. The core finding: performance varies significantly by benchmark version, harness, and reasoning effort; the model is best for simple/high-volume tasks (as vendor states) but not consistently at frontier level for complex reasoning, agentic tasks, or coding across all independent evaluations.

4. **Multimodal / vision performance.** Vendor announcement reports MMMU-Pro 66.1% (w/o Python) / 69.5% (with Python), OSWorld-Verified 39.0%, OmniDocBench 1.5 edit distance 0.2419 (lower is better). Independent Artificial Analysis reports MMMU-Pro 73.6% (independent, medium) / 65.38% (independent, estimated from BenchmarkList / other sources) — actually close to vendor's 66.1%. Independent Vals AI reports MMMU Pro 73.58% — close. Independent Artificial Analysis (via Benchmark Atlas / open sources) reports MMMU-Pro 65.38% (`https://benchlm.ai/models/gpt-5-4-nano`). The variation (66.1% vendor vs. 65.38% independent vs. 73.58% Vals AI vs. 73.6% Artificial Analysis medium) reflects measurement differences; the values are in a similar moderate-to-good range for this SKU.

5. **Context and pricing claims.** Vendor claims 400K context (`https://developers.openai.com/api/docs/models/gpt-5.4-nano`). Independent OpenRouter and Vals AI confirm 400K (`https://openrouter.ai/openai/gpt-5.4-nano`, `https://vals.ai/models/openai_gpt-5.4-nano-2026-03-17`). Independent Epoch AI (`https://epoch.ai/models/gpt-5-4-nano`) confirms 400K context window. No significant conflict. Pricing ($0.20/$1.25) is consistent across official docs, OpenRouter, Vals AI, and independent sources. No major pricing conflict.

- **Tool use: 65/100.** Evidence: τ²-bench Telecom 92.5% (vendor-aligned, very high), MCP Atlas 56.1% (vendor-aligned, moderate), Toolathlon 35.5% (vendor-aligned, weak), BFCL-V4 / agentic harness not explicitly broken out but Agentic Index 16.0 (independent, Xhigh — low), Terminal-Bench Hard 42.4% (independent, Xhigh — moderate), Terminal-Bench 4.0 0.5% (independent — very weak). - **Reasoning: 60/100.** Evidence: GPQA Diamond 82.8% (vendor-aligned, xhigh) / 81.7% (independent, Xhigh) — close agreement, good; MMLU-Pro 77.2% (independent) — moderate; HLE 24.3% (w/o tools) / 28.3% (independent Xhigh) / 37.7% (w/ tools, vendor-aligned) — weak; MATH-500 88.6% (independent review) — very good; IFBench 75.9% (independent Xhigh) / 64.4% (independent Medium) — moderate-to-good; CritPt 9.3% (independent Xhigh) / 0.0% (independent Non-reasoning) — very weak; Intelligence Index 20.7 (independent Xhigh) — low.
