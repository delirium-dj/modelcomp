## Model card

- **Name:** North Mini Code
- **Short description:** Cohere's first developer-focused model and the debut of its North family — a 30B-total / 3B-active sparse MoE built specifically for agentic software engineering and terminal tasks, trained across multiple scaffolds (OpenCode, SWE-Agent, mini-SWE-Agent) rather than optimized for one. Open weights under Apache 2.0, sized so it runs with low latency on local hardware as well as through hosted APIs.
- **Provider / access:** Open weights on Hugging Face (`CohereLabs/North-Mini-Code-1.0`, plus FP8 and W4A16 quantized variants); hosted on the Cohere API (`north-mini-code-1-0`), in OpenCode, and via a Cohere Hugging Face Space; Model Vault for managed dedicated deployment. Also routed as `cohere/north-mini-code:free` on OpenRouter and as `cohere/north-mini-code` on anyrouter.
- **Release / knowledge:** Announced and released **2026-06-09** (Hugging Face blog by the Cohere Code Agents Team; cohere.com blog same day). OpenRouter listing created 2026-06-17; anyrouter records 2026-06-18. Knowledge cutoff **not published**.
- **IDs:** `CohereLabs/North-Mini-Code-1.0` (HF), `north-mini-code-1-0` (Cohere API, per docs.cohere.com), `cohere/north-mini-code` (anyrouter), `cohere/north-mini-code:free` (OpenRouter). A Zen Free ID is **not** present on OpenCode Zen's live catalog, so cost is scored on the Cohere first-party route below.
- **Context window:** **256,000 tokens total with 64,000 max output** — identical on the model card, Cohere's API reference page, the anyrouter record and OpenRouter. Cohere's recommended vLLM launch uses `--max-model-len 320000`; the OpenCode config example sets context 256000 / output 64000. Artificial Analysis reports 256k (its FAQ text rounds to "260k").
- **Modalities:** text in; text out; **interleaved reasoning** (thinking blocks must be passed back into subsequent agentic steps for best results); tool calling via the `cohere_command4` parser with `--enable-auto-tool-choice`; structured output via JSON schema; sampling recommended at temperature 1.0 / top_p 0.95. Confirmed text-only by Artificial Analysis's own capability check ("does not support image input").
- **Pricing (as of 2026-10-17):** **$0 in / $0 out, first-party, on both trial and production keys** until the per-key rate limit is reached. This is stated by Cohere itself on `docs.cohere.com/docs/north-mini-code-1.0` ("For both trial keys and production keys, North Mini Code is free until rate limits are reached") and on the new Coding models tab of `cohere.com/pricing` (both the API key line and the model download line read `$0 / Free`). Rate limits: **20 req/min on trial keys, 500 req/min on production keys**; trial keys are additionally capped at 1,000 API calls per month. Artificial Analysis lists $0.00 / $0.00 and ranks it **#1 of 24** on cost. OpenRouter also carries a `cohere/north-mini-code:free` route at $0. This is a correction to the first pass, which had only a third-party free route and no verified Cohere price.
- **Architecture:** Decoder-only sparse Mixture-of-Experts. 128 experts with 8 activated per token, SwiGLU FFN blocks, sigmoid-gated router, one dense layer before the sparse stack. Attention interleaves sliding-window RoPE attention with global NoPE attention at a 3:1 ratio. 30B total / **3B active** parameters. Post-training: two-stage cascaded SFT (stage 1: 70% code tokens, 43% agentic tool-use data, 27% single-turn competitive/scientific programming; stage 2: a 4.5B-token mixture of agentic and reasoning-driven verified samples, 61% code) followed by asynchronous multi-environment RLVR.

### Raw benchmarks found

> Provenance is labelled per row. **Vendor** = Cohere's own harness. **Independent** = Artificial Analysis, measured by AA itself. Cohere's cross-model comparison table is *not* one uniform evaluation run: Cohere states it uses public reports or AA figures where available, runs missing rows internally, and takes Gemma 4's agentic scores from the Qwen team.

**Checkpoint identity — the single most important correction in this pass.** The first pass anchored Tool use and Coding on **80.2% pass@10 / 61.0% pass@1 SWE-bench Verified** and **55.1% pass@10 Terminal-Bench v2**. Cohere's blog text makes it explicit that those are the **SFT checkpoint** numbers ("The final SFT model achieves 80.2% pass@10 on SWE-Bench Verified and 55.1% pass@10 on Terminal-Bench v2"). The released, post-RLVR checkpoint's own registered scores are in `CohereLabs/North-Mini-Code-1.0/.eval_results/*.yaml` (commit 7cbbd56, dated 2026-06-09):

Reasoning / knowledge:

- Artificial Analysis Intelligence Index: **10**, rank **#41 / 141**, on the current **v4.3.2** scale (Artificial Analysis model page, read 2026-10-17). AA's own framing: "above average among comparable models (median: 8)". This confirms — and explains — the first pass's 9.9.
- **Correction to the first pass's central reasoning.** The first pass recorded AA Intelligence Index 9.9 from an OpenRouter feed while AA's 2026-06-09 launch article had measured **27.6**, and treated the collapse as evidence of a bad scrape because the sibling **Coding Index rose 33.4 → 36.5** over the same window. That inference does not survive checking. AA's own 2026-06-09 article reported **27.6 and 33.4 on the same date and the same scale**, and the current AA page reads **10 and ~36 on the current scale**. The two indexes are built differently and re-based differently: the Coding Index is a plain weighted average of two raw benchmark percentages (Terminal-Bench Hard and SciCode) whose components do not move when the composite is rebuilt, whereas the Intelligence Index v4.3.2 is a 10-way composite that now includes **AA-Briefcase v1.1, GDPval-AA v2.1, AutomationBench-AA, Terminal-Bench 4.0, GDP.pdf and AA-Omniscience**, several of which this model scores near zero on. Opposite movement in the two indexes over the same window is the expected signature of a composite re-basing, not a scrape failure. **27.6 → 10 is an index-version change; 10 is the live figure.**
- Launch-scale component scores (Artificial Analysis, 2026-06-09, Dataconomy aggregation of the AA dataset): GPQA **757 Elo**, HLE **99 Elo**, IFBench **57.6%**, SciCode **38.8%**, **AA-LCR 37.3%**, Terminal-Bench Hard **31.1%**, τ²-Bench **37.4%**.
- Cohere itself reports only the **Coding** Index (33.4 at launch) as a headline, never the Intelligence Index. Its own "AA Index" framing is therefore narrower than the composite now measured by AA.
- LiveCodeBench v6 and SciCode were run by Cohere per its stated methodology (Claude Code and mini-SWE-agent harnesses, temp 1.0, top_p 0.95, 256K context, 3 seeds averaged) but the release page publishes them only inside a benchmark chart image; the extractable numbers are the cross-model table values reproduced above.

### Normalized scores (1–100)

> Derived from the raw numbers above using `model-comparison.md` (v4). Overall = half-up
> mean of the five quality dims; Cost efficiency is scored but never counted.

- **Tool use: 54/100** (was 62). The revision is driven by using the **released RLVR checkpoint** instead of the SFT checkpoint. Terminal-Bench v2 falls from 55.1% pass@10 to **36.0% pass@1** — below the methodology's mid band (TB2.1 45–60% → 50–70) — and SWE-bench Verified falls from 80.2% pass@10 to **67.6% pass@1**. The newly-found **SWE-bench Pro 40.2%** is a further hard number in the same direction, and the independent GDPval-AA 14% / τ²-Bench Telecom 37% components behind the AA Agentic Index of 21.7 remain near-floor. Held at 54 rather than dropped further because SWE-bench Verified 67.6% pass@1 under SWE-agent is a genuinely respectable agentic result, and because the 36.0 figure carries a plausible pass@1 handicap against a field that reports pass@k.
- **Reasoning: 30/100** (unchanged, but for a corrected reason). The first pass anchored this to an AA Intelligence Index of 9.9 and treated it as a broken reading. It is not broken — AA's current v4.3.2 page reads **10** and calls that above the size-class median of 8. That is genuinely near-floor as an absolute, and it is now the *only* overall-capability signal that exists: no GPQA, HLE, CritPt or LCR figure is available as an extractable percentage on a current index. HLE at 99 Elo and IFBench at 57.6% are consistent with the same low read. Kept as a low-evidence placeholder, not as a reasoner score — this model was never marketed as one.
- **Context window: 74/100** (was 80). The window itself is unchanged and verified at 256,000 total / 64,000 output on four sources. The cut is for **new evidence, not spec**: **AA-LCR v1.1 at 37.3%** is the first measured retrieval result for this model and it is poor. The 200K–500K band still anchors the base value at 70; the 256K window plus a 64K output cap justifies the upper half of the band, and the weak LCR reading is what removes the remaining headroom.
- **Multimodal: 15/100** (unchanged). Text in / text out, now with independent confirmation from Artificial Analysis's capability check rather than three vendors agreeing on the same "text->text" label. No image, video, PDF or audio path. This is the methodology's plain text-only value.
- **Coding: 68/100** (was 75). Restating the same evidence against the released checkpoint: SWE-bench Verified **67.6% pass@1**, SWE-bench Pro **40.2%**, Terminal-Bench v2 **36.0%**, Terminal-Bench Hard **31.1%**, SciCode **38.2–38.8%**, LiveCodeBench v6 **70.3%**. That is solidly mid-field on repo-level work and below the methodology's "elite" band, which wants LiveCodeBench ~80% *plus* SciCode and Vibe/DeepSWE corroboration. It is comfortably above the first pass's 75 because the 75 was scored on a pass@10 figure from an earlier checkpoint. Not higher: no SWE-bench Verified number above 67.6% exists for this checkpoint, and the AA Coding Index of 33.4 is modest.
- **Cost efficiency: 98/100** (was 92). Raised on first-party evidence: Cohere's own API documentation and its `cohere.com/pricing` Coding models tab both put North Mini Code at **$0 on trial *and* production keys until rate limits are reached**, and Artificial Analysis ranks it **#1 of 24** on cost at $0.00 / $0.00. This is no longer a third-party free tier with unknown data handling — it is a vendor rate card. Held 2 under 100 because the free access is explicitly conditional on rate limits (500 req/min on production, 1,000 calls/month on trial), because Model Vault dedicated deployment is priced separately, and because Cohere is explicit that trial keys are for evaluation rather than production or commercial use.
- **Overall Score: 48.2/100.** Mean of (54 + 30 + 74 + 15 + 68) / 5 = 48.2. Best fit as a genuinely free, fast local or first-party coding agent for repo-level edits and terminal chores where a 3B-active model keeps latency low — not a general-purpose assistant. The near-floor independent agentic components (GDPval-AA 14%, τ²-Bench Telecom 37%, AA-LCR 37.3%, AA Intelligence Index 10) argue strongly against putting it in charge of unattended agentic loops, however good its SWE-bench Verified pass@1 is.
