## Model card

- **Name:** Claude Sonnet 4.6
- **Short description:** **Anthropic's cost-conscious agentic-coding Sonnet**, released **2026-02-17**, and — on independent measurement — **the strongest model Artificial Analysis had tested for agentic use cases** at launch. It scores **AA Intelligence Index 51** (an 8-point jump over Sonnet 4.5's 43; essentially tied with GPT-5.2 and **second overall, behind only Claude Opus 4.6's 53** — the first time Anthropic held the top two slots), and it **leads *all* models on GDPval-AA (1633 Elo) and TerminalBench**, edging even Opus 4.6. It pairs that with **near-flagship coding (SWE-bench Verified 79.6% vs Opus 4.6's 80.8%)** and **top-tier computer use (OSWorld 72.5%)** at **40% lower per-token price than Opus**. ⚠ The catch is **token hunger**: in max-effort adaptive thinking it burned **74M output tokens (~3× Sonnet 4.5)**, so real-world cost-per-task is far higher than the $3/$15 sticker implies, and Opus still leads on novel reasoning (ARC-AGI-2 ~10 pts), deep agentic search (BrowseComp ~9 pts) and Terminal-Bench 2.0 (65.4% vs 59.1%). Superseded by Sonnet 5 ($2/$10) on 2026-06-30. **[2026-11-02: AA now marks this model DEPRECATED and its active page is the NON-REASONING variant (composite Index N/A; BenchLM non-reasoning 55.29 #73/1004; speed 44.8 tok/s notably slow). The "Index 51 / #2 overall / leads ALL on GDPval-AA & TerminalBench" claims are Feb-2026 launch-vintage reasoning-variant figures and have aged out — newer Anthropic/OpenAI models now rank above it. Recalibrated: Reasoning/Tool/Coding down, Overall 85 → 83.]**
- **Provider / access:** **Anthropic**. API (`claude-sonnet-4-6`), plus **Google Vertex, Amazon Bedrock, Microsoft Azure**; surfaced in **Claude Chat, Claude Cowork and Claude Code**. **No free tier** (`noFreeId`). Listed here as `anthropic/claude-sonnet-4.6`.
- **Release / knowledge:** Released **2026-02-17** (two weeks after Opus 4.6 on 2026-02-05). **Training data cutoff: January 2026.**
- **IDs:** `claude-sonnet-4-6` (API) / `anthropic.claude-sonnet-4-6` (Bedrock) / `claude-sonnet-4-6` (Vertex) (Anthropic line: Sonnet 4.5 → **Sonnet 4.6** → Sonnet 5 → [Sonnet 5.4/5.5]).
- **Context window:** **200K standard / 1M beta** (beta header `context-1m-2025-08-07`, going GA). The 1M tier requires **usage tier 4+**, is charged at **2× input / 1.5× output above 200K**, and has dedicated (lower) rate limits; **context compaction (beta)** auto-summarizes history near the limit (trigger min 50K / default 150K) for effectively-infinite agent sessions. ⚠ Recall degrades past ~200K (MRCR-style failures reported). **Max output: 128K per Artificial Analysis** (a third-party spec table lists 64K — discrepancy noted; either way ≥ Sonnet 4.5's 64K).
- **Modalities:** **Text + image in → text out.** Image understanding underpins strong **computer-use / GUI** work (OSWorld 72.5%; reads screens, self-corrects through failures). No audio, no video, no generative multimodal output; no dedicated vision benchmark (MMMU/CharXiv) was published in the sources reviewed. **[2026-11-02: a neutral AA-MMMU-Pro 70.6 and vendor CharXiv 77.4 now exist, replacing the draft's "no vision benchmark" note — but 70.6 (non-reasoning variant) is modest, so Multimodal holds 77.]**
- **Pricing (as of 2026-10-24):** **$3 / $15 per 1M in/out** (unchanged from Sonnet 4.5; **40% below Opus 4.6's $5/$25**); >200K context at 2×/1.5×. ⚠ **Effective cost is much higher than sticker** — max-effort adaptive thinking used **74M output tokens** to run the AA Intelligence Index (**$2,088**, ~3× Sonnet 4.5's ~$733), so AA notes "the set of use cases that Sonnet makes sense for over Opus is narrower than ever."
- **Architecture:** Undisclosed-parameter dense hybrid-reasoning Transformer. Introduces **adaptive thinking** (replaces fixed-budget extended thinking; `type: "adaptive"` with `effort` = low/medium/high/max — **max is Opus-only**, Sonnet defaults to high), which **auto-enables interleaved thinking** (reasoning *between* tool calls in agent loops). Adds **context compaction (beta)** and the **1M-token beta window**. Improved **prompt-injection resistance** for computer use.
