## Model card

- **Name:** Claude Sonnet 4.6
- **Short description:** **Anthropic's cost-conscious agentic-coding Sonnet**, released **2026-02-17**, and — on independent measurement — **the strongest model Artificial Analysis had tested for agentic use cases** at launch. It scores **AA Intelligence Index 51** (an 8-point jump over Sonnet 4.5's 43; essentially tied with GPT-5.2 and **second overall, behind only Claude Opus 4.6's 53** — the first time Anthropic held the top two slots), and it **leads *all* models on GDPval-AA (1633 Elo) and TerminalBench**, edging even Opus 4.6. It pairs that with **near-flagship coding (SWE-bench Verified 79.6% vs Opus 4.6's 80.8%)** and **top-tier computer use (OSWorld 72.5%)** at **40% lower per-token price than Opus**. ⚠ The catch is **token hunger**: in max-effort adaptive thinking it burned **74M output tokens (~3× Sonnet 4.5)**, so real-world cost-per-task is far higher than the $3/$15 sticker implies, and Opus still leads on novel reasoning (ARC-AGI-2 ~10 pts), deep agentic search (BrowseComp ~9 pts) and Terminal-Bench 2.0 (65.4% vs 59.1%). Superseded by Sonnet 5 ($2/$10) on 2026-06-30.
- **Provider / access:** **Anthropic**. API (`claude-sonnet-4-6`), plus **Google Vertex, Amazon Bedrock, Microsoft Azure**; surfaced in **Claude Chat, Claude Cowork and Claude Code**. **No free tier** (`noFreeId`). Listed here as `anthropic/claude-sonnet-4.6`.
- **Release / knowledge:** Released **2026-02-17** (two weeks after Opus 4.6 on 2026-02-05). **Training data cutoff: January 2026.**
- **IDs:** `claude-sonnet-4-6` (API) / `anthropic.claude-sonnet-4-6` (Bedrock) / `claude-sonnet-4-6` (Vertex) (Anthropic line: Sonnet 4.5 → **Sonnet 4.6** → Sonnet 5 → [Sonnet 5.4/5.5]).
- **Context window:** **200K standard / 1M beta** (beta header `context-1m-2025-08-07`, going GA). The 1M tier requires **usage tier 4+**, is charged at **2× input / 1.5× output above 200K**, and has dedicated (lower) rate limits; **context compaction (beta)** auto-summarizes history near the limit (trigger min 50K / default 150K) for effectively-infinite agent sessions. ⚠ Recall degrades past ~200K (MRCR-style failures reported). **Max output: 128K per Artificial Analysis** (a third-party spec table lists 64K — discrepancy noted; either way ≥ Sonnet 4.5's 64K).
- **Modalities:** **Text + image in → text out.** Image understanding underpins strong **computer-use / GUI** work (OSWorld 72.5%; reads screens, self-corrects through failures). No audio, no video, no generative multimodal output; no dedicated vision benchmark (MMMU/CharXiv) was published in the sources reviewed.
- **Pricing (as of 2026-10-24):** **$3 / $15 per 1M in/out** (unchanged from Sonnet 4.5; **40% below Opus 4.6's $5/$25**); >200K context at 2×/1.5×. ⚠ **Effective cost is much higher than sticker** — max-effort adaptive thinking used **74M output tokens** to run the AA Intelligence Index (**$2,088**, ~3× Sonnet 4.5's ~$733), so AA notes "the set of use cases that Sonnet makes sense for over Opus is narrower than ever."
- **Architecture:** Undisclosed-parameter dense hybrid-reasoning Transformer. Introduces **adaptive thinking** (replaces fixed-budget extended thinking; `type: "adaptive"` with `effort` = low/medium/high/max — **max is Opus-only**, Sonnet defaults to high), which **auto-enables interleaved thinking** (reasoning *between* tool calls in agent loops). Adds **context compaction (beta)** and the **1M-token beta window**. Improved **prompt-injection resistance** for computer use.

### Raw benchmarks found

Intelligence / agentic (**independent** Artificial Analysis — weighted highest):

- **AA Intelligence Index: 51** — **#2 overall** (behind Opus 4.6's 53; tied GPT-5.2 xhigh 51); **+8 over Sonnet 4.5 (43)**; the Sonnet↔Opus gap narrowed from 7 pts to 2
- **GDPval-AA (agentic real-world work): 1633 Elo — leads ALL models** (> Opus 4.6 1606, > GPT-5.2 1462)
- **TerminalBench (agentic coding & terminal use): leads all models** (AA reports 53%, a slight lead over Opus 4.6) — "the overall strongest model we have tested for agentic use cases"
- Token efficiency: **74M output tokens** in max effort (~3× Sonnet 4.5's 25M; ~28% more than Opus 4.6's 58M), HLE alone 47M (64% of total)

Coding / computer use (Anthropic-reported + third-party technical breakdown):

- **SWE-bench Verified: 79.6%** (vs Opus 4.6 80.8%, GPT-5.2 80.0%) — a 1.2-pt gap at ~1.7× lower cost (Anthropic's model doc also lists 74.6% 10-trial-avg / 80.2% with prompt modification)
- **OSWorld (computer use): 72.5%** (≈ Opus 4.6 72.7%; > GPT-5.3 Codex 64.7%, GPT-5.2 37.9%) — the Sonnet line went 14.9% → 72.5% in 16 months; Pace reported 94% on its insurance computer-use benchmark
- **Agentic Financial Analysis: 63.3%** (> Opus 4.6 60.1%, > GPT-5.2 59.0%)
- **Terminal-Bench 2.0: 59.1%** — a relative weakness (< Opus 4.6 65.4%, < GPT-5.3 Codex 77.3%, < GPT-5.2 62.2%); note this differs from AA's TerminalBench harness where Sonnet 4.6 leads
- Opus 4.6 retains edges on **novel reasoning (ARC-AGI-2, ~10 pts)** and **deep agentic search (BrowseComp, ~9 pts)**
- Developer preference: **70%** over Sonnet 4.5 in Claude Code; **59%** over Opus 4.5

### Normalized scores (1–100)

- **Tool use: 88/100.** The independent standout — **AA ranks Sonnet 4.6 the strongest model tested for agentic use cases**, **leading *all* models on GDPval-AA (1633 Elo) and TerminalBench**, with **top-tier computer use (OSWorld 72.5%**, ≈ Opus 4.6, far above GPT-5.2's 37.9%), **interleaved adaptive thinking** between tool calls, **context compaction** for effectively-infinite agent sessions and improved **prompt-injection resistance**. Held just below GPT-5.4's 88-tier peak only because GPT-5.4 owns the outright **#1 OSWorld-Verified (75.0%)** and a broader measured GUI/computer-use stack; Sonnet 4.6's Terminal-Bench 2.0 (59.1%) also trails Opus/Codex on that specific harness.
- **Reasoning: 86/100.** **AA Intelligence Index 51 — #2 overall** (behind only Opus 4.6; tied GPT-5.2; +8 over Sonnet 4.5) and **Agentic Financial Analysis 63.3% (> Opus 4.6)**. Capped below the 87–88 frontier peak because **Opus retains ~10 pts on ARC-AGI-2 (novel/abstract reasoning) and ~9 pts on BrowseComp (deep agentic search)** — Sonnet 4.6 is a near-frontier reasoner that yields to Opus on the hardest novel problems.
- **Context window: 87/100.** **200K standard / 1M beta (going GA)** with **128K max output** (per AA) and the genuinely useful **context-compaction (beta)** that keeps long agent sessions alive instead of crashing at the limit. Discounted below the 88–89 leaders because the **1M window is beta-gated** (tier 4+, 2×/1.5× surcharge above 200K, lower rate limits), **recall degrades past ~200K** (MRCR-style), and a third-party spec table lists only 64K output (conflict flagged).
- **Multimodal: 77/100.** **Text + image in → text out**, with image understanding that powers **strong computer-use/GUI vision (OSWorld 72.5%**, self-correcting through on-screen failures). Held to 77 (just above claude-sonnet-5.4's interpolated 76, below GPT-5.4's 80) because there is **no audio or video, no generative multimodal output, and no published dedicated vision benchmark** (MMMU/CharXiv) to verify general visual reasoning beyond screen grounding.
- **Coding: 87/100.** Near-flagship agentic coding — **SWE-bench Verified 79.6%** (within 1.2 pts of Opus 4.6 at ~1.7× lower cost), the **AA TerminalBench lead**, and strong practitioner endorsements (GitHub, CodeRabbit; 70% preferred over Sonnet 4.5 in Claude Code). Discounted a notch because **Terminal-Bench 2.0 (59.1%) trails Opus 4.6 (65.4%) and GPT-5.3 Codex (77.3%)**, and Claude Code's own creator still prefers Opus for the hardest coding — i.e. elite for the majority of real PRs, a step below Opus on the hardest 5%.
- **Cost efficiency: 74/100.** Nominally attractive — **$3/$15**, **40% below Opus 4.6** — but **badly undermined by token hunger**: max-effort adaptive thinking used **74M output tokens (~3× Sonnet 4.5)** to run the AA Index (**$2,088**, ~3× Sonnet 4.5's ~$733), so AA concludes real-world cost is "substantially higher than Sonnet 4.5" and the Sonnet-over-Opus value case is "narrower than ever." The 1M-context surcharge (2×/1.5×) and no free tier compound this. Scored but **not** counted in the Overall per methodology.
- **Overall Score: 85/100.** Mean of Tool 88 + Reasoning 86 + Context 87 + Multimodal 77 + Coding 87 = 425/5 = 85.0 → 85. Best fit: **high-volume production agentic work** — parallel coding-agent sessions, computer-use/GUI automation of legacy systems, office/knowledge work (GDPval-AA #1) and long sessions needing compaction — where independently-verified near-frontier agentic capability at 40%-below-Opus per-token pricing wins. **Not** the pick for the hardest novel reasoning/deep search (Opus leads), pure terminal work (Opus/Codex lead Terminal-Bench 2.0), token-frugal budgets (it's verbose), audio/video, or self-hosting. Independent read: my **85 sits ~1.2 below the queue's curated 86.2** — a *small* gap because Sonnet 4.6's headline claims are **independently verified** (AA Index #2, GDPval-AA/TerminalBench #1), with the discount driven by **image-only multimodality (77)**, the **token-hunger that erodes its cost story**, and its **superseded** status. Internally consistent: Claude Sonnet 4.6 (85) lands alongside **GPT-5.4 (85)** and **claude-sonnet-5.4 (85)** in the near-frontier tier and just above the strong open-weight/value generalists (inkling-small, grok-4.6, qwen-3.7-plus, ember-1, mimo-v2.6-free, minimax-m3 at 84) — an accurate portrait of an independently-verified agentic leader whose 5-dimension mean is held to 85 chiefly by image-only multimodality rather than by any weakness in tool use or coding.
