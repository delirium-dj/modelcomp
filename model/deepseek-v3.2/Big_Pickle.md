## Model card

- **Name:** DeepSeek V3.2
- **Short description:** DeepSeek's December 2025 open-weight MoE flagship, MIT licensed, and the model that turned sparse attention into a shipping product. It warm-starts from V3.1 and adds **DeepSeek Sparse Attention (DSA)** — a lightning indexer that selects which attention blocks matter, specifically to make long-context inference cheaper — plus a new chat template that lets **reasoning interleave with tool use** in a single turn, which is what actually moved its agentic numbers rather than its knowledge scores. One checkpoint serves both modes: DeepSeek reports thinking and non-thinking columns side by side for every agentic benchmark, and thinking is worth real points (Terminal-Bench 2.0 **37.1% → 46.4%**, MCP-Mark **26.5% → 38.0%**) at the cost of tokens. The paper positions it directly against Claude 4.5 Sonnet, GPT-5 Pro, Gemini 3.0 and Kimi K2, and it genuinely beats all of them on several axes — most notably **SWE Multilingual 70.2%** versus Sonnet's 68.0% and GPT-5's 55.3% — while sitting below all of them on knowledge. Best described as the strongest open-weights tool-and-code agent per dollar, with a text-only interface.
- **Provider / access:** Open weights on Hugging Face (`deepseek-ai/DeepSeek-V3.2`, **MIT**), with GGUF/AWQ/FP8 community quantizations. Served by **50+ third-party hosts** — OpenRouter, SiliconFlow, Novita, DeepInfra, Azure AI Foundry (incl. a `deepseek-v3.2-speciale` variant), Google Vertex AI (`deepseek-ai/deepseek-v3.2-maas`), Amazon Bedrock, Together, Fireworks, Groq, Chutes, Vercel, zenmux, 302.ai, Venice, Novita and others. **DeepSeek's own first-party API no longer offers it**: `api-docs.deepseek.com` now lists only `deepseek-flash` (DeepSeek-V4.1-Flash) and `deepseek-v4-pro` (DeepSeek-V4-Pro-0813). **Not on OpenCode Zen** — the live catalog carries `deepseek-v4.1-flash`, `deepseek-v4-pro`, `deepseek-v4-flash`, `deepseek-v4-flash-vision-exp` and `deepseek-v4-flash-free`, and nothing matching `v3.2`.
- **Release / knowledge:** Released **2025-12-01** (models.dev, 20+ hosts). Succeeded **V3.2-Exp** of 2025-09-29. Pre-training cutoff not published on the model card.
- **IDs:** `deepseek-ai/DeepSeek-V3.2` (Hugging Face canonical), `deepseek/deepseek-v3.2` (OpenRouter, nano-gpt, Kilo, Novita, Zenmux), `deepseek-v3.2` (SiliconFlow, DeepInfra, Venice, many), `deepseek.v3.2` (Amazon Bedrock), `deepseek-ai/deepseek-v3.2-maas` (Google Vertex AI), `deepseek-ai/deepseek-v3.2-exp` / `-exp-thinking` (the September experimental ancestor — **a different checkpoint**, not this model). A separate `deepseek-v3.2-speciale` on Azure is a **math/olympiad-specialized variant**, also not this model.
- **Context window:** **128K native** (DeepSeek's own spec, and what BenchLM records). Most hosts publish a slightly larger **163,840 / 164,000** (OpenRouter, SiliconFlow, HuggingFace, Kilo, Bedrock, Vertex, meganova, tensorx, digitalocean); others publish 128,000 (Azure, Vercel, Qiniu, Novita-via-llmgateway, merge-gateway, ofox, vivgrid) and one outlier (crof) publishes 163,840 context *and* 163,840 max output, which no other source supports. **Max output is provider-dependent and inconsistent**: 64,000 (DeepInfra, zenmux, nano-gpt, 302.ai-thinking, ofox), 65,536 (OpenRouter, HuggingFace, Novita, Bedrock, Vertex, Kilo), 8,192 (Abacus), 128,000–164,000 (Azure, siliconflow, 302.ai, tensorx, crof), and **8,000 on Vercel**. This folder's `meta.json` records "164,000 total; 8K-128K max output (provider-dependent)" — the honest reading, though 164K is the hosted figure rather than DeepSeek's native 128K.
- **Modalities:** **Text in/out.** Hybrid thinking and non-thinking modes, tool calls, structured JSON output. **No vision and no audio.** This is the model's sharpest limitation: DeepSeek's *current* `deepseek-flash` route advertises `Vision ✓` and 1M context, so V3.2 is a text-only, 128K model on both axes where its successor has moved on. Every one of the 50+ provider records agrees on text-only.
- **Pricing (as of 2026-10-05):** No first-party rate exists. Cheapest verified full-rate hosts: **DeepInfra $0.26 in / $0.38 out**, **Novita $0.269 / $0.40**, **SiliconFlow $0.27 / $0.42**, **OpenRouter $0.28 / $0.42**, Zenmux $0.28 / $0.43, Kilo $0.28 / $0.42. Mid-tier: Azure and Vertex $0.56–0.58 / $1.68, Bedrock $0.62 / $1.85, Vercel $0.62 / $1.85, Chutes $1.00 / $1.00. Artificial Analysis is quoted at **$0.134 / $0.202** for a "V3.2 Thinking" route. Alibaba's `alibaba-token-plan` carriers list **$0 / $0**, but that is a subscription token plan rather than a pay-per-token rate. Self-hosting is **$0** under MIT. This folder's `meta.json` pricing note ("~$0.21/$0.31, cached input $0.022") does not correspond to any rate I could verify — its $0.022 cache figure matches DeepSeek-V4-Pro's off-peak cache-hit price, not V3.2 — and should not be relied on.
- **Architecture:** Open-weight **MoE** with RoPE-YARN and **DeepSeek Sparse Attention**. Active parameters **37B**; total parameters are **not officially disclosed** on the model card, and third-party listings variously say "not disclosed" or 685B (this folder's `meta.json` says 685B — plausible by lineage from V3's 671B, but unconfirmed). Trained from the V3.1 checkpoint. Key innovations recorded by the ecosystem: DSA for long-context efficiency, and thinking-with-tools via a new chat template. Tool calling, JSON output and both API surfaces (OpenAI- and Anthropic-format) are supported.

### Raw benchmarks found

**Official figures are from the DeepSeek-V3.2 technical report (arXiv 2512.02556), Table 2**, which evaluates the **thinking** variant and benchmarks it against Claude-4.5-Sonnet (High), GPT-5 (Pro), Gemini-3.0 (Thinking), Kimi-K2 (Thinking) and MiniMax-M2 (Thinking). DeepSeek's own claim is that on SWE-bench Verified and Terminal-Bench 2.0 it "significantly outperforms open-source LLMs." Independent figures come from BenchLM and an Artificial Analysis-sourced price/accuracy table.

Text, reasoning and knowledge:

- GPQA Diamond (Pass@1): **82.4%** (Sonnet 83.4, GPT-5 85.7, Gemini-3.0 91.9, Kimi K2 84.5, MiniMax M2 77.7)
- MMLU-Pro (EM): **85.0%** (Sonnet 88.2, GPT-5 87.5, Gemini-3.0 90.1, Kimi K2 84.6, MiniMax M2 82.0)

- **AIME 2025 (Pass@1): 93.1%** (Sonnet 87.0, GPT-5 94.6, Gemini-3.0 95.0, Kimi K2 94.5, MiniMax M2 78.3)
- HMMT Feb 2025: **92.5%** (Sonnet 79.2, GPT-5 88.3, Gemini-3.0 97.5, Kimi K2 89.4)
- HMMT Nov 2025: **90.2%** (Sonnet 81.7, GPT-5 89.2, Gemini-3.0 93.3, Kimi K2 89.2)

The MMLU figure roughly agrees; **GPQA, LiveCodeBench and especially AIME do not** and are most consistent with the **non-thinking** mode or a different harness, not with the paper's thinking column. Treat 59.0 AIME as a different operating point, not a contradiction.

### Normalized scores (1–100)

- **Tool use: 80/100.** The strongest tool-use profile in this batch, and it clears a methodology frontier marker outright: **τ²-bench at 80.3%** sits far above the `Tau3 ~50%+` frontier reference, ahead of every closed model DeepSeek benchmarks against, and **SWE Multilingual 70.2%** likewise beats Sonnet, GPT-5 and Kimi K2. The interleave-reasoning-with-tools template DeepSeek added in this release is what produces those numbers, and the thinking/non-thinking split shows it is real rather than a settings artifact: **MCP-Mark jumps 26.5% → 38.0%** and Terminal-Bench 37.1% → 46.4%. Backed by native tool calling and JSON output. Held well below the 90–100 band for three specific gaps: the third frontier anchor, **GDPval-AA**, is absent entirely; **Terminal-Bench 2.1 has no figure at all**, and the 46.4% is on the *easier* 2.0 suite, so it does not transfer to the 85% frontier marker; and the independent reads are only moderate — **Claw-Eval 40.2%, Gert Labs 29.57%**, with BenchLM's agentic composite still "Coming soon." Real strength on measured suites, incomplete coverage of the ones that define the top band.
- **Reasoning: 76/100.** Above the 55–65 mid band on measured evidence. **GPQA Diamond 82.4%** clears the top of the methodology's `GPQA 60–80%` mid range, MMLU-Pro 85.0% corroborates, HLE at **25.1%** is well above the `<10%` mid marker though far under the 40% frontier, and the math is near-frontier throughout — **AIME 2025 93.1%, HMMT Feb 92.5%, HMMT Nov 90.2%, IMOAnswerBench 78.3%** — which is a legitimately olympiad-grade result. Held well below 90 because **HLE remains the binding constraint at 25.1%**, there is **no Intelligence Index and no CritPt or Omniscience figure**, and no MRCR/LCR at all, so the model has no measured long-horizon reasoning evidence whatsoever. Independent placement is middling — BenchLM Knowledge lane **41.8 (#91 of 168)** and Reasoning lane 53.6 unranked — which is well below what the vendor's olympiad math would suggest for general reasoning.
- **Context window: 58/100.** The **128K native** window (DeepSeek's own spec, and what BenchLM records) places this in the methodology's 100K–200K band of 50–64; the larger 163,840–164,000 figure most hosts publish is the same band, not a higher one. Mid-band placement, and it cannot be raised on evidence because **no retrieval or needle benchmark exists for this model in any source** — no MRCR, no LCR, no RULER, no AA-LCR. DSA is a genuine long-context mechanism but DeepSeek published no accuracy result for it, so the window is a bare spec claim. Two further reasons not to score higher: max output is wildly inconsistent across hosts (8,000 on Vercel to 164,000 on siliconflow), and DeepSeek's own successor has moved to **1M**, which suggests 128K was already regarded as the ceiling of the generation.
- **Multimodal: 15/100.** **Text-only**, no vision and no audio, on every one of the 50+ provider records — squarely in the methodology's 10–20 text-only band, and the same 15 this repo assigns to other text-only models. This is a hard structural cap on the Overall and the reason a model this strong on tools and code still cannot reach the mid-70s. Worth contrasting with the direction of travel: DeepSeek's current `deepseek-flash` route advertises `Vision ✓`, so the vision gap is a generation gap that DeepSeek has since closed elsewhere. BenchLM's VITA-Bench entry (18.5%) is a text/agentic vision-adjacent suite, not evidence of image input.
- **Coding: 78/100.** Above the 65–75 mid band, with two strong anchors and one conspicuous hole. **LiveCodeBench 83.3%** clears the band's `LiveCode 80%` marker and is within a point of GPT-5's 84.5% and above Kimi K2's and MiniMax's, and **Codeforces 2386** is an elite competitive rating — 906 points above Claude 4.5 Sonnet's 1480. **SWE-bench Verified 73.1%** is solid, essentially GPT-5 Pro territory, and **SWE Multilingual 70.2%** is the best in its comparison class. Capped below 90 because the methodology's mid band is explicitly conditioned on Vibe <10% and SciCode <40%, and **neither SciCode nor Vibe Code Bench nor DeepSWE has any figure for this model** — so the pairing that would certify a mid-band coding score cannot be completed. The independent read is also softer than the vendor's: BenchLM Coding lane **32, #89 of 142**.
- **Cost efficiency: 96/100.** Exceptionally cheap for its quality level, and cheap *nowhere near its own vendor*. With no first-party route left, the scored tier is third-party: **DeepInfra $0.26 / $0.38**, Novita $0.269 / $0.40, SiliconFlow $0.27 / $0.42, OpenRouter $0.28 / $0.42 — all far below the methodology's `~$0.60/$2.20 = ~92` anchor and roughly **6–8× cheaper per output token than Bedrock or Vercel** on the same model. MIT open weights add a $0 self-host path, though 685B-class MoE weights put that out of reach for most self-hosters, so the practical figure is the hosted rate. Not 97–99 because those are calibrated to the `~$0.10/$0.20` band and this is roughly 2.5× that; not 100 because no durable full-rate $0 hosted tier exists — Alibaba's $0/$0 is a subscription token plan, and the $0.134/$0.202 Artificial Analysis quote is a single route I could not confirm as the standard rate. Practical note for this repo: the price is no longer the reason to pick DeepSeek, because OpenCode Zen does not serve it at all.
- **Overall Score: 61/100.** Half-up mean of 80 / 76 / 58 / 15 / 78. Best fit: **the strongest open-weights tool-and-code agent per dollar** — take it when the job is tool orchestration, MCP server work, repo-level patching or multilingual code editing, and you want MIT weights you can host yourself. The realistic ceiling is its **text-only, 128K** interface: the moment a task needs images or a long document set, this is the wrong model and its successor or a multimodal sibling is. Note it is already superseded on its own vendor's platform (DeepSeek now serves V4-Pro and V4.1-Flash, both 1M with vision), so adopting it means adopting third-party hosting.
