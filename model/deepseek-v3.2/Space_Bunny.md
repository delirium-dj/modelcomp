## Model card

- **Name:** DeepSeek V3.2 (thinking / non-thinking modes)
- **Short description:** DeepSeek's December 2025 open-weight MoE flagship that unifies chat and deep reasoning in one model, built around DeepSeek Sparse Attention (DSA) and a large-scale agentic task-synthesis post-training pipeline. **Superseded within its own family:** DeepSeek now ships V4 Pro, V4 Flash and V4.1 Flash, and V3.2 is no longer purchasable first-party. Distinction from neighbours: `DeepSeek-V3.2-Speciale` is a separate high-compute variant whose temporary first-party endpoint expired 2025-12-15, not an alias of the base release.
- **Provider / access:** open weights on Hugging Face (`deepseek-ai/DeepSeek-V3.2`) under a permissive/MIT license; self-hosting; and a long tail of third-party resellers. **First-party access is gone.** DeepSeek's own `deepseek-chat` and `deepseek-reasoner` aliases — the routes that served V3.2 — were retired at **2026-07-24 15:59 UTC**. The catalogue now carries only `deepseek-flash` (DeepSeek-V4.1-Flash-1017) and `deepseek-v4-pro`. Hosted at `opencode/deepseek-v3.2`.
- **Release / knowledge:** released 2025-12-01 (technical report arXiv 2512.02556, same date; evals.report says Dec 1, one aggregator Dec 3). Knowledge cutoff not stated in any reviewed source — still unmeasured.
- **IDs:** `deepseek-ai/DeepSeek-V3.2` (HF); the retired first-party ids were `deepseek-chat` (non-thinking) and `deepseek-reasoner` (thinking); hosted `opencode/deepseek-v3.2`.
- **Context window:** **unresolved conflict.** The technical report states a 128K maximum ("supports a maximum context length of only 128K"). OpenRouter metadata moved 131,072 → **163,840** on 2026-10-07/10-09, with max output 65,536 → **147,456**; Token Barometer lists 163,840 / 147,456; AnotherWrapper lists 131.1K / 65.5K; Volcano Engine serves a 98,304 / 32,768 build; Azure AI Foundry serves 128K. Every figure lands in the 100K–200K band, so the tier is unaffected, but the number is not trustworthy.
- **Modalities:** text in / text out; hybrid thinking and non-thinking modes; tool calls and structured JSON. **No vision, no audio, no PDF.**
- **Pricing (as of 2026-10-17):** **the first-party $0.28/$0.42 no longer exists as a DeepSeek price** — that was the V3.2-era list price on the now-retired first-party route. Current reality: OpenRouter `deepseek/deepseek-v3.2` still lists $0.28/$0.42 (aggregator, not vendor); cheapest live route **GMICloud $0.209/$0.31** (a 28% promo), then NanoGPT and Nous Portal at the same, AtlasCloud / DeepInfra / Venice / Novita / SiliconFlow at $0.26–0.28 in and $0.38–0.42 out; median blended across 35 comparable offers **$0.35**. **Volcano Engine serves it free ($0/$0)** at a 96K context. Premium cloud routes are 2–3× the aggregators: Vertex AI $0.56/$1.68, Azure AI Foundry $0.58/$1.68, Bedrock $0.62/$1.85. SiliconFlow raised output +90.5% on 2026-10-10. Open weights remain, so self-hosting is still free per token.
- **V3.2-Speciale:** the temporary endpoint `api.deepseek.com/v3.2_speciale_expires_on_20251215` expired **2025-12-15 15:59 UTC** (confirmed in DeepSeek's own release note and changelog). It is not fully dead: Azure AI Foundry still sells `deepseek-v3.2-speciale` at $0.58/$1.68 (128K context), and LiteLLM priced it on 2026-10-10/11.
- **Architecture:** MoE, 685B total / 37B active; DeepSeek Sparse Attention reduces main-model attention from O(L²) to O(Lk) via a lightning indexer; scalable RL plus a large-scale agentic task-synthesis pipeline; tool-use in both thinking and non-thinking modes.

**CAUTION — Vibe Code Bench 5.11% is an extreme outlier and should not be read as a pure capability verdict.** It is a *measured* number on the same board where Gemini 3.6 Flash scores 64.00% and Claude Opus 4.6 57.57%, so the board is not broken. But the Vibe Code Bench paper (arXiv 2603.04601v2, §4) discloses that "some provider configurations did not expose usable browser-vision support for GLM-5, MiniMax M2.5, and **DeepSeek V3.2**" — those models still used the browser tool but without browser perception. V3.2 is **text-only**, so it was generated and evaluated in a harness that does not match its modality. The same paper's difficulty breakdown (Easy 10.02 / Medium 1.32 / Hard 0.00) and integration breakdown (None 6.23 / Email 0.00 / Stripe 0.00 / Both 3.57) are consistent with a generation-side failure rather than a reasoning failure. **Recorded as a possible harness failure; flagged for re-test.** It is nevertheless the single largest driver of the Coding cut below, and the coding band the methodology names for exactly this pattern ("LiveCode 80% but Vibe <10% and SciCode <40%") is 65–75, which is where the score was placed.

No MRCR / RULER / GraphWalks retrieval figure exists at any window size. DSA is a serving-efficiency mechanism; the report quantifies token cost vs token position on H800s, not retrieval accuracy.

### Normalized scores (1–100)

- **Tool use: 74/100.** Cut 8 from 82. The first pass leaned on the vendor's headline **Terminal-Bench 2.0 46.4%**, which the report itself obtained under the **Claude Code framework** after admitting its own context-management strategy is incompatible with the standard Terminus harness. The standard-harness number is **39.6%** independent (39.3% by DeepSeek's own non-thinking run) and AA Terminal-Bench Hard is **32.6%** — that is below the methodology's mid band (TB2.1 45–60% → 50–70). Offsetting positives are real but modest: τ²-bench categories 63.8/81.1/96.2 and 78.9% on AA, Berkeley Function Calling Leaderboard 56.73%, GAIA 34.8%. Held well above the floor by BrowseComp 67.6%-with-context-management and SWE-bench Verified 72–74% across four harnesses.
- **Reasoning: 68/100.** Cut 19 from 87 — the largest single correction in this comparison. Every vendor headline in the first pass has a materially lower independent counterpart: **GPQA-D 82.4 → 75.1**, **HLE 25.1 → 11.2**, **LiveCodeBench 83.3 → 59.3**, **MMLU-Pro 85.0 → 83.7**. New independent failures: **ARC-AGI-2 4.03%**, **FrontierMath Tier 4 2.1%**, **SimpleQA Verified 27.5%**, **AA-Omniscience −46.9% with a 93.3% hallucination rate**, **AA Index 16**. That places it below the methodology's named mid band (Index 20–35 → 55–65). It is held at 68 rather than lower because the **math** is independently corroborated and genuinely frontier-adjacent — AIME 2026 94.17%, AIME (OTIS Mock) 87.8%, MathArena HMMT Feb 2026 84.09%, HMMT 92.5/90.2 — and GPQA/HLE in the 70s/low-double-digits are real, if far below the vendor's presentation.
- **Context window: 72/100.** Held. The nominal window is disputed (128K in the report vs 163,840 on OpenRouter vs 98,304 on Volcano Engine) but every candidate sits in the same 100K–200K band, so the tier is unchanged. Behaviour near the ceiling is unmeasured at every length — no MRCR/RULER/GraphWalks exists — and the report itself documents ~20%+ BrowseComp overflow past 128K requiring a context-management technique to move 51.4% → 67.6%. DSA buys speed at that length, not accuracy.
- **Multimodal: 15/100.** Held. Text-only: no vision, no audio, no PDF, confirmed by DeepSeek's own docs (the vision capability in the current DeepSeek API belongs to `deepseek-v4-flash-vision-exp`, a different model). Scored at the text-only floor by the methodology.
- **Coding: 70/100.** Cut 18 from 88. The first pass scored 88 on the vendor table (SWE-bench Verified 73.1%, LiveCodeBench 83.3%, Codeforces 2386). The independent reading is materially lower on every axis: **LiveCodeBench 59.3%** (not 83.3), **SciCode 38.7–38.9%**, **Vibe Code Bench 5.11% measured**, **SWE-bench Pro 15.56%**, **React Native Evals 71.5%**, **Aider Polyglot 74.2%**, BenchLM coding lane **28.5 (#99 of 150)**. That is precisely the methodology's named pattern — "LiveCode 80% but Vibe <10% and SciCode <40% → 65–75" — so 70 sits inside the specified band. Not pushed lower, because the Vibe Code Bench run carries a disclosed browser-vision harness mismatch for a text-only model (§ caution above) and SWE-bench Verified 72–74% holds across four independent harnesses.
- **Cost efficiency: 94/100.** Cut 2 from 96. The anchor moved: there is no first-party V3.2 price any more, so the "$0.28/$0.42 first-party" framing is dead. What replaces it is still excellent — cheapest live route $0.209/$0.31 (GMICloud, promo), median blended $0.35, DeepInfra/AtlasCloud/SiliconFlow $0.26/$0.38–0.42, **free on Volcano Engine**, plus Apache/MIT open weights for self-hosting. Held in the low 90s rather than the high 90s because the premium cloud routes are 2–3× the aggregator floor ($0.56–0.62 in, $1.68–1.85 out), the cheapest quote is explicitly promotional, and SiliconFlow raised output pricing +90.5% on 2026-10-10. **Cost is excluded from Overall.**
- **Overall Score: 59.8/100.** (74 + 68 + 72 + 15 + 70) / 5 = **59.8**, cost excluded. Down from 68.8. The 9-point fall is not a new failure — it is the correction of a scoring basis. The first pass treated a vendor self-evaluation table as if it were a measurement; every independent harness that has since run this model reports materially lower numbers, and the methodology's own bands for those numbers are 5–20 points below where the model was sitting. Best fit is unchanged in kind but narrower: an open-weight text-only reasoning/coding backbone whose value rests on serving economics and the independently-corroborated math result, not on the frontier-agentic claims in the launch report.
