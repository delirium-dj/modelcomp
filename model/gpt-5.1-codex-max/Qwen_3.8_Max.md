## Model card

- **Name:** GPT-5.1-Codex-Max (xhigh)
- **Short description:** OpenAI's **November-2025 frontier coding model** and the **"compaction pioneer" — the first OpenAI model natively trained to work across multiple context windows**, sustaining long-horizon agentic coding (complex refactors) that would otherwise fail at the context limit. At release it **topped SWE-bench Verified at 77.9% (xhigh)**, beating **Claude Opus 4.5 (77.2%)** and **Gemini 3 Pro (76.2%)**, with **SWE-Lancer 79.9%** (+13.6-pt leap) and **~30% fewer thinking tokens** than the plain GPT-5.1-Codex at medium reasoning. **400K context / 128K out**, **text + image in**, **$1.25/$10**. It was **Codex's default for ~a month**. ⚠ **Deprecated and shut down** — succeeded by **GPT-5.2-Codex** (which extended the compaction direction), and the **API id was retired 2026-07-23 in favour of `gpt-5.6-sol`**. **Responses-API-only** and **~3× slower than the plain Codex on SWE-bench**.
- **Provider / access:** **OpenAI Responses API** (`gpt-5.1-codex-max`) at **$1.25/$10.00** per 1M in/out (**$0.125 cached**; Zen price = native); also on **opencode Zen** (`opencode/gpt-5.1-codex-max`). **No free hosted tier id** (`noFreeId: true`). **The id was shut down 2026-07-23** — no longer purchasable.
- **Release / knowledge:** Released **November 18–19, 2025**. **Deprecated** — GPT-5.2 / GPT-5.2-Codex (Dec 2025) continued the compaction lineage; the specific `gpt-5.1-codex-max` id was retired July 23, 2026. **METR** ran an independent dangerous-capability evaluation (Nov 19, 2025).
- **IDs:** `opencode/gpt-5.1-codex-max`; OpenAI `gpt-5.1-codex-max`. **AA page returns 404** (delisted after the API shutdown) — so there is **no current AA Intelligence Index** for this SKU.
- **Context window:** **400,000 (400K) total; 128,000 (128K) max output** — plus **compaction**, which summarizes/compresses the working context so a single task can span **multiple 400K windows** (the model's defining innovation; effective reach exceeds the nominal window, though compaction is lossy).
- **Modalities:** **Text + image in → text out** (meta-confirmed). Vision input for screenshots/diagrams/UI in coding tasks; **no audio or video**.
- **Pricing (as of 2026-10-28):** **$1.25 / $10.00** per 1M in/out ($0.125 cached) — a premium frontier-coding tier when live; **now shut down** (unavailable). ~30% fewer thinking tokens than the plain Codex partly offsets the output cost.
- **Architecture:** **Proprietary reasoning** model (parameters undisclosed), the **xhigh**-effort Codex variant, **natively trained for compaction** (multi-window context management) and on agentic software-engineering tasks. **Responses-API-only**; **~3× slower than the plain GPT-5.1-Codex on SWE-bench** (the compaction/thinking overhead).

- **Tool use: 80/100.** The **compaction pioneer** — natively trained to sustain **long-horizon agentic coding across multiple context windows** (complex refactors that exceed a single window), backed by strong agentic results (**SWE-bench Verified 77.9% xhigh**, **SWE-Lancer 79.9%** freelance-SWE). This is genuine agentic engineering capability and was OpenAI's default Codex for a month. Held below the 82+ verified-agentic leaders by: **no current AA Index** (no AutomationBench/Briefcase anchor), **Responses-API-only**, **~3× slower than the plain Codex**, **vendor-only** benchmark provenance, and **shutdown/deprecation**. Strong-agentic-coder band.
- **Reasoning: 78/100.** A frontier **xhigh reasoning** model whose SWE-bench Verified 77.9% (leaderboard-topping at release) and ~30%-fewer-thinking-tokens efficiency evidence strong, token-efficient reasoning. But there is **no AA Intelligence Index** to anchor it (page delisted), the reasoning is **coding-specialized**, and it is **deprecated/shut down**. Inferred-strong but independently unmeasured; scored a touch above the plain GPT-5.1-Codex (AA 24, below median) for the xhigh effort and efficiency, without over-crediting an absent Index.
- **Context window: 82/100.** **400K nominal (128K out)** — the 400K tier — **plus compaction**, the model's defining innovation, which lets a task span **multiple 400K windows** (effective reach beyond the nominal limit). Credited at the top of the 400K band for the multi-window capability, but **not** at the 1M tier because compaction is **lossy summarization**, not true long-range retrieval, and no MRCR/RULER-at-1M figure exists.
- **Multimodal: 78/100.** **Text + image in → text out** (meta-confirmed). Vision input supports screenshot/diagram/UI-grounded coding, useful for front-end and debugging agents. **No audio or video.** The image-only-verified tier — level with the other text+image coding/agent models scored nearby, and a clear advantage over text-only coders (which floor at 50).
- **Coding: 82/100.** The headline strength: **SWE-bench Verified 77.9% (xhigh) — #1 at its Nov-2025 release**, beating Claude Opus 4.5 (77.2%) and Gemini 3 Pro (76.2%), plus **SWE-Lancer 79.9%** (+13.6) and **compaction** for repo-scale refactors. Genuinely elite coding *at release*. Tempered below the 84–85 independent-Vals leaders (e.g. GLM-5.2's Vals SWE-bench Verified 82.80%) because the numbers are **vendor-reported**, there is **no current independent re-verification or AA Index**, and the model is **deprecated, ~3× slower, and shut down** — surpassed by GPT-5.2-Codex and the current frontier. Strong-vendor, leaderboard-topping-at-release band.
- **Cost efficiency: 58/100.** **$1.25/$10** per 1M was a **premium** frontier-coding price (partly offset by ~30% fewer thinking tokens), but the decisive fact is that the **API id was shut down 2026-07-23** — it is **no longer purchasable at any price**, was **Responses-API-only**, and ran **~3× slower** than the plain Codex. Retired/shut-down band. Not counted toward Overall.
- **Overall Score: 80/100.** Mean of Tool 80 + Reasoning 78 + Context 82 + Multimodal 78 + Coding 82 = 400 / 5 = 80.0 → 80. Best fit: **the compaction-pioneer frontier coder** — OpenAI's Nov-2025 flagship coding model that **topped SWE-bench Verified at 77.9% (xhigh)**, added **SWE-Lancer 79.9%**, and **introduced multi-window compaction** for long-horizon refactors, at 400K context with text+image input — but **Responses-API-only, ~3× slower, vendor-only benchmarks, no current AA Index, deprecated → GPT-5.2-Codex, and the id shut down 2026-07-23**. Ideal historically for **long-horizon, context-exceeding agentic refactors at the frontier of late-2025**; **use GPT-5.2-Codex / GPT-5.6-Sol for the live successors**, or the plain **GPT-5.1-Codex (79)** for the faster middle tier. **Divergence note:** curated queue 73 vs my 80 → **+7.0** (one of my larger gaps).
