## Model card

- **Name:** GLM-5.3-FlashX (high-throughput tier of GLM-5.3-Flash)
- **Short description:** **GLM-5.3-FlashX is the speed tier of GLM-5.3-Flash** — the *same* 320B-total / 18B-active open-weight (MIT) native-multimodal model, served at **~200 tokens/s** for faster responses (FlashX is not yet on the GLM Coding Plan; a separate `glm-5.3-flashx-legal` variant is tuned for legal workflows). It is the first natively multimodal model in the GLM-5 series and the first open-source frontier model to combine **sparse + linear attention**, cutting attention compute 3.0× and KV cache 4.4× vs GLM-5.3 at 1M-token context. Its headline result: it **pushes the Pareto frontier of the Artificial Analysis Intelligence Index** — scoring **57 on AA Index v4.1.1 at ~$0.045/task (promo)**, tying Claude Opus 4.8's intelligence at roughly **1/20th the list cost (1/40th at promo)**, and approaching Opus 4.8 across six coding/agentic benchmarks. It launched stealth as **`ox-alpha`** on OpenRouter/OpenCode (Aug 20–26, 2026), becoming the most-used model on OpenRouter (~23T tokens) before Z.ai revealed it.
- **Provider / access:** Z.ai first-party API (`glm-5.3-flash` / `glm-5.3-flashx` / `glm-5.3-flashx-legal`), OpenRouter (32 providers), OpenCode, and open weights on Hugging Face under **MIT** (commercial use permitted). GLM-5.3-Flash is on the GLM Coding Plan (3× quota vs GLM-5.3); **FlashX is not yet on the plan**. FlashX-Legal is gated to selected enterprise customers by application. Self-host via SGLang/vLLM; Unsloth dynamic GGUF quants (1-bit ~100 GB machine, 3-bit fits a 128 GB Mac / NVIDIA DGX Spark).
- **Release / knowledge:** GLM-5.3-Flash released **2026-08-26** (stealth `ox-alpha` from Aug 20; weights on HF that evening). FlashX is the subsequent high-throughput serving tier. Knowledge cutoff not disclosed in the sources reviewed.
- **IDs:** `glm-5.3-flashx` (siblings `glm-5.3-flash`, `glm-5.3-flashx-legal`; predecessor GLM-5.2; larger sibling GLM-5.3).
- **Context window:** **1M tokens native** (text parameters consistent with GLM-5.3); **128K maximum output tokens**. Hybrid linear+sparse attention with **IndexPool** (compresses four indexer key vectors into one) is purpose-built to keep 1M-token attention latency/memory low — 3.01× less attention compute and 4.44× smaller KV cache than GLM-5.3.
- **Modalities:** **native multimodal — video / image / text / file in → text out** (no audio). Visual intelligence is integrated into the coding loop (observes interfaces/renders/interaction feedback to self-correct), with computer-use (BUA/CUA), frontend/game/Blender-3D/CAD (build123d) workflows, Office deliverables (PPTX/PDF/DOCX/XLSX), financial research and long-form video understanding/editing. Reasoning is **thinking-only** (`thinking.type: enabled`; cannot be disabled), with `reasoning_effort` up to **max**; function calling, structured output, context caching and streaming (`tool_stream`) supported.
- **Pricing (as of 2026-10-23):** Z.ai first-party **~$0.15 / 1M in, ~$0.50 / 1M out** (~10% of GLM-5.3's price); OpenRouter **$0.0052 / 1M in, $0.1985 / 1M out** (32 providers); self-host **$0** (MIT). AA cost-per-task ≈ **$0.09 list / $0.045 promo** — vs Claude Opus 4.8's ~$1.78/task (~1/20th at list, ~1/40th at promo).
- **Architecture:** **MoE, 320B total / 18B activated** (vs GLM-5.3's 355B / 32B), **45 layers** (vs GLM-5.3's 92). First open frontier model to fuse **sparse + linear attention** (linear captures local dependencies via state modeling; sparse retrieves global context via a lightweight indexer + IndexPool). Adds **Manifold-Constrained Hyper-Connections (mHC)** for scaling efficiency; trained on a **30T-token multimodal corpus**. Served via a custom SGLang engine (ReplaySSM, W8A8 quantization, hybrid INT8/FP8/BF16 cache quantization, Layer Split) and an Encode–Prefill–Decode (EPD) disaggregated cluster — Z.ai states the launch traffic ran on ~100,000 Chinese-made AI chips with no NVIDIA hardware.

### Raw benchmarks found

Coding & agent (Z.ai vendor-run; GLM-5.3-Flash, the weights FlashX serves):

- **Z.ai Code Bench v1.0** (run on Claude Code 2.1.207), max effort: **29.0** vs Claude Opus 4.8's **29.5** — *nearly matches* the coding frontier; outperforms GLM-5.2 at every effort level
- **DeepSWE v1.1: 63.4** vs GLM-5.2's 46.2 (+17.2)
- **AutomationBench: 48.8** vs GLM-5.2's 26.2 (+22.6)
- Z.ai states GLM-5.3-Flash "consistently outperforms GLM-5.2, often by a wide margin" and is **"approaching Claude Opus 4.8 overall"** across six coding/agentic benchmarks; GLM-5.3 (the larger sibling) is billed as the most capable open-weights model for coding (+50% over GLM-5.2 on Z.ai Code Bench)
- No SWE-bench Verified / SWE-bench Pro / Terminal-Bench figure was published in the sources reviewed

Reasoning / knowledge:

- **Artificial Analysis Intelligence Index: 57 on v4.1.1** at ~$0.045/task (promo) — ties Claude Opus 4.8's index score at ~1/20th–1/40th the per-task cost; GLM-5.3 (Max) = 60 on the same v4.1.1 basket at ~10× the cost
- ⚠ **Index-version conflict (provenance-critical):** on Artificial Analysis's *current* (later, rebased) basket the same family reads **GLM-5.3-Flash ≈ 42 and GLM-5.3 Max ≈ 45** — ~15 points lower because the basket was made harder, *not* because the model changed. The relative gap (Max ~3 pts above Flash) holds on both baskets. The v4.1.1 "57" and the current "42" are **not interchangeable** and must carry their version.
- No GPQA Diamond / HLE / MMLU-Pro figure published for Flash/FlashX in the sources reviewed
- **GLM-5.3-Flash-Base** remains competitive with GLM-5-Base across most benchmarks (base-model table)

Multimodal:

- Native video/image/text/file understanding wired into an iterative visual-coding + computer-use loop (frontend/game/Blender/CAD reproduction, Office deliverables, long-form video editing with speaker attribution). No MMMU / MMMU-Pro / MathVision figure published in the sources reviewed.

Legal (GLM-5.3-FlashX-Legal variant):

- **Harvey LAB** (legal-agent benchmark): **all-criteria pass rate 19.2%**, **+12.5pp over the base model** — Z.ai claims SOTA among open-source models on this evaluation

> Provenance: All capability figures are **Z.ai vendor-run** (blog "GLM-5.3-Flash: Frontier Intelligence, Flash Cost," 2026-08-26, and the docs.z.ai GLM-5.3-Flash/FlashX overview). The single independent signal is the **Artificial Analysis Intelligence Index**, which is **version-sensitive**: the launch blog cites **57 on v4.1.1** (tying Opus 4.8), while AA's *current* rebased basket shows **~42** for Flash / **~45** for GLM-5.3 Max — both are reported here with their basket version and are not conflated (per the index-version-provenance rule). The "ties Opus 4.8" and "approaching Opus 4.8" claims rest on Z.ai's own Code Bench and on the v4.1.1 index; the six-benchmark coding table and Harvey LAB result are vendor-run with no published task list/sample size for the in-house benches (Z.ai Code Bench, DeepSWE, AutomationBench are Z.ai/affiliated harnesses). **FlashX shares Flash's weights and intelligence** — it is a ~200 tok/s serving tier plus a legal-tuned variant — so Flash's benchmark profile applies to FlashX; no FlashX-specific capability numbers exist separately from speed/throughput. Per methodology, vendor figures are treated as an upper bound and discounted against neutral harnesses. No benchmark was invented.

### Normalized scores (1–100)

- **Tool use: 84/100.** Genuinely strong agentic tooling for an open model — **DeepSWE v1.1 63.4** and **AutomationBench 48.8** (both large jumps over GLM-5.2), native multimodal **computer use (BUA/CUA)** with a self-verifying visual-coding loop, function calling, structured output, context caching and streaming tool calls. Held below the frontier (and just below MiMo V2.6 Flash's 85) because everything is vendor-run, **AutomationBench (48.8) and DeepSWE (63.4) trail MiMo Flash's 52.3/67.9**, no OSWorld/Toolathlon figure is published, and the in-house harnesses lack a public task list.
- **Reasoning: 82/100.** The independent anchor is the **AA Intelligence Index — 57 on v4.1.1 (ties Opus 4.8) but only ~42 on the current rebased basket**, with GLM-5.3 Max ~3 pts above on both. That version spread is the honest picture: frontier-*competitive* on the launch basket, mid-tier on today's harder one. No GPQA/HLE/MMLU-Pro is published for Flash/FlashX, so I score conservatively off the index rather than borrowing the larger GLM-5.3's or siblings' numbers.
- **Context window: 88/100.** A real strength — **1M tokens native** (not a YaRN extension) with **128K output**, and an architecture *specifically engineered* for cheap long-context serving (hybrid linear+sparse attention, IndexPool, 3.01× less attention compute, 4.44× smaller KV cache than GLM-5.3). Matches the native-1M open-weight leaders (MiMo V2.6 Flash 88); discounted below the 89–93 native-1M frontier because **no MRCR-style long-context recall benchmark is published** to verify quality at depth.
- **Multimodal: 85/100.** The **first native-multimodal GLM-5 model** — video/image/text/file input with visual reasoning woven into coding, computer use, Blender/CAD, Office deliverables and long-form video editing/speaker-attribution. Broader practical visual-agentic coverage than most open models. Capped below the fully-omnimodal MiMo V2.6 Flash tier because there is **no audio path** and **no MMMU/MMMU-Pro/MathVision** figure to corroborate visual reasoning against a neutral benchmark.
- **Coding: 86/100.** The standout dimension — on Z.ai Code Bench (max effort) it **nearly matches Claude Opus 4.8 (29.0 vs 29.5)**, DeepSWE v1.1 63.4, and Z.ai reports it "approaching Opus 4.8 overall" across six coding/agentic benchmarks; the GLM-5.3 line is positioned as the most capable open-weights coder. Held below the high-80s/90s because the marquee numbers are on **in-house/affiliated harnesses** (Z.ai Code Bench, DeepSWE), **no SWE-bench Verified/Pro or Terminal-Bench** figure is published, and Opus 4.8 remains the coding frontier it approaches rather than beats.
- **Cost efficiency: 97/100.** Best-in-class Pareto frontier — **ties Claude Opus 4.8's AA Index (v4.1.1) at ~1/20th the list per-task cost ($0.09) and ~1/40th at promo ($0.045)**, OpenRouter $0.0052/$0.1985, Z.ai ~$0.15/$0.50, **MIT open weights ($0 self-host)**, 3-bit quant runs on a 128 GB Mac, and the sparse+linear architecture slashes long-context serving cost. FlashX adds ~200 tok/s throughput. Among the very cheapest ways to reach near-frontier coding/intelligence. Scored but **not** counted in the Overall per methodology.
- **Overall Score: 85/100.** Mean of Tool 84 + Reasoning 82 + Context 88 + Multimodal 85 + Coding 86 = 425/5 = 85.0 → 85. Best fit: **the open-weight value frontier** — a ~200 tok/s, MIT-licensed, native-multimodal 1M-context engine that approaches Claude Opus 4.8 on coding/agentic work at a small fraction of the cost, ideal for high-volume visual coding, computer-use automation, Office/financial/legal document workflows and local/single-Mac deployment where data sovereignty and $/token matter most; escalate the hardest pure-reasoning tasks to a closed frontier model (its current-basket AA Index ~42 is mid-tier). Independent read: my 85 sits **below the queue's curated 88** because I discount the vendor-only/in-house benchmark table, weight the **version-sensitive AA Index honestly (57 on v4.1.1 vs ~42 today)** rather than quoting only the flattering launch number, and note the absence of published SWE-bench/GPQA/HLE/MMMU figures — landing it just below the larger closed flagships but at/above the other open-weight value leaders on coding-per-dollar.
