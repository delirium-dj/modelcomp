## Model card

- **Name:** Muse Wonder (1.0)
- **Short description:** Meta's **2026-10-12 Muse-family frontier agent model** — the base of the two-model Muse Wonder series (Muse Wonder + Muse Wonder Full), positioned as "a frontier model for personal & professional AI agents" and a step on Meta's road to "personal superintelligence." It is a **reasoning-always-on** agent model that pairs **Active Memory** (carries user context across conversations and actively retrieves relevant detail) with **Active Focus** (sustained multi-step effort — tries alternative approaches, works through blockers, asks for clarification, checks in before important actions). On the **independent Artificial Analysis Intelligence Index (v4.3 basket) it scores 52 at max effort**, a material **+4 over Muse Spark 1.3 (max) at 48** but still **below the frontier** (Claude Opus 5.5 ≈ 58, GPT-6 Astra ≈ 53, and its own sibling Muse Wonder Full ≈ 56). Its agentic deltas over Spark 1.3 are large (**AutomationBench-AA 68% from 58%, Terminal-Bench 4.0 52% from 33%, Coding Agents Index 63 from 54**), but it carries a **documented knowledge weakness (AA-Omniscience 25)** and a **premium price** (**$4.52 per AA Index task**, ~2.8× Spark 1.3's $1.60). Trade-off: strong personal/professional agency and breadth ("big model smell"), weaker on pure factual knowledge and cost.
- **Provider / access:** **Meta** — available via the **Meta Model API** and **Muse Code**; will roll out to consumer **Muse** subscribers. **Paid only** (`noFreeId` — no free tier). The stronger sibling **Muse Wonder Full** (AA Index 56) is **Muse Code subscribers only** and is *not* per-token priced — this slug is the base, per-token-priced Muse Wonder.
- **Release / knowledge:** Released **2026-10-12** (14 months after Meta's ground-up stack overhaul; builds on the Muse Spark scaling line). Trained at Meta's **gigawatt-scale Prometheus data center**. Knowledge cutoff not stated in the sources reviewed; the **AA-Omniscience 25** score indicates below-frontier world knowledge.
- **IDs:** `muse-wonder-1.0` / `opencode/muse-wonder-1.0` (series sibling: Muse Wonder Full; predecessor line: Muse Spark 1.1 / 1.2 / 1.3).
- **Context window:** **1,048,576 (1M) tokens total / 131,072 (131K) max output** — top-tier on both axes, matching the 1M/131K leaders. **Active Memory** extends effective cross-conversation context beyond the raw window.
- **Modalities:** **Text, image, video, audio in → text out** (broad multimodal *input*; text-only *output*). Demonstrations show it working across a browser and apps (run planning, custom swag from Instagram photos, wedding seating charts, a playable 3D kitchen game from image inputs).
- **Pricing (as of 2026-10-23):** **$4.00 / $20.00 per 1M in/out; $0.20 cached input; paid only.** Artificial Analysis measures **$4.52 per average Intelligence Index task** (~54k output tokens + ~7.69M input tokens per task). Cost-per-task anchors: **GPT-6.1 Sol $0.72, Gemini 4 Argon $1.99, Astra $3.26, Sonnet 5.5 $5.46, Opus 5.5 $5.98, Fable 5.1 $7.63** — Wonder sits mid-pack on $/task but is **2.8× its own Spark 1.3 ($1.60)**.
- **Architecture:** Undisclosed proprietary (Meta); reasoning always on, scaled via test-time compute (Meta's OOD analysis shows Wonder Full generalizes to unfamiliar tasks better than the Spark 1.3 trend predicts, attributed to a **larger, stronger base model**). Strongest-to-date CBRN + cyber-misuse safeguards per Meta's Superintelligence Scaling Framework, while preserving defensive cyber capability.

### Normalized scores (1–100)

- **Tool use: 84/100.** *(85 → 84 — headline agentic number contested.)* Genuine agentic step-change stands on neutral instruments — **AA Terminal-Bench 4.0 52.0**, **GDPval-AA 1770**, **AA Briefcase 1659**, GDP.pdf 30.6 — but the draft's lead figure **AutomationBench-AA 68%** is contradicted by BenchLM's **AA AutomationBench 39.1** (harness/version difference; both recorded, not averaged), and **Harvey LAB-AA 10.0** plus **MazeBench 0%** are real weak points. The v5.0 **Index 43** also places it a tier below the frontier agentic leaders. Active Focus / browser-app tool use remain qualitative vendor claims.
- **Reasoning: 84/100.** *(83 → 84 — one good gap closed, one ceiling confirmed.)* Reasoning-always-on with scaled test-time compute, now with a solid neutral signal the draft lacked: **AA-HLE 50.1** and excellent honesty (**AA-Omniscience hallucination 20.9%** — among the best in this batch). Held down by the confirmed knowledge ceiling (**Omniscience accuracy 38.0 / Index 25.1**), mid **CritPt 28.3**, and the v5.0 **Index 43** (above the 37 class median, below frontier). The prior v4.3 Index 52 is a different, non-convertible basket and is not read as a regression.
- **Context window: 90/100.** *(88 → 90 — the missing independent figure is now supplied.)* **1M native context with a 131K output cap**, and the draft's stated discount ("no independent long-context-recall figure") is closed by **AA-LCR 80.7** (neutral long-context reasoning). **Active Memory** for cross-conversation recall remains a vendor capability; MLCR-AA 22.2 (medical long-context) is the weak sub-signal.
- **Multimodal: 84/100.** *(82 → 84 — modality now independently verified.)* The draft had the text/image/speech/video input only from `meta.json`; **AA's spec table now confirms it outright**, with **Design Arena Website 1366 (OpenRouter)** as a grounded signal. Still capped because **output is text-only** (no image/audio/video generation) and no MMMU-Pro / video benchmark is transcribed under this slug (coverage is 28 of 724 on BenchLM).
- **Coding: 85/100.** *(held.)* Frontier-*claimed* coding: **AA Terminal-Bench 4.0 52.0** is the neutral anchor, with **AA-SciCode 60.3** corroborating; the headline **DeepSWE 78.8 / sweMarathon 53.1 / ProgramBench 50.0 / Coding-Agents 63** cells are Meta-model-card (vendor) and stay discounted, and **FrontierCode 2.0 24.3 (Cognition)** is only mid. The strongest coding claims in the launch material belong to the *Wonder Full* sibling, not this base slug.
- **Cost efficiency: 52/100.** *(62 → 52 — materially worse than drafted.)* The draft used the v4.3-era **$4.52/task**; AA's current v5.0 measurement is **$6.95 per Intelligence-Index task (#47 of 57)** driven by **110M-token verbosity (#42/57)** — i.e. near the expensive tail, close to Fable 5.1's $7.63 and far dearer than GPT-6.1 Sol ($1.27/task) or Gemini 4 Argon. $4/$20 sticker with 95% cache discount and **paid-only** access (no free tier). Scored but **not** counted in the Overall per methodology.
- **Overall Score: 85/100.** *(holds 85.)* Mean of Tool 84 + Reasoning 84 + Context 90 + Multimodal 84 + Coding 85 = 427/5 = 85.4 → 85. Context +2 (AA-LCR 80.7 closes the retrieval gap) and Multimodal +2 (AA verifies omni input) plus Reasoning +1 (AA-HLE 50.1, 20.9% hallucination) offset Tool −1 (AutomationBench 68 vs 39.1 contest). **Cost's sharp 62 → 52 does not touch the mean by methodology**, so the composite is stable while the *value* story is considerably worse than the draft believed. Independent read: my **85 remains below the queue's curated 89.9**, driven by the v5.0 **AA Index 43** (a tier below frontier), the **Omniscience accuracy 38.0** knowledge ceiling, and **$6.95/task**. Non-scored practical plus: **191.9 tok/s (#17/195)** is genuinely fast for long agent loops. Best fit: personal/professional agents needing sustained multi-step focus, cross-conversation memory, omni-modal input and high throughput where per-task cost is secondary; knowledge-critical and cost-constrained workloads should look elsewhere.
