# Gemini 3 Flash — Independent Research Report

## Summary and evidence

Gemini 3 Flash Preview is Google's December 2025 fast multimodal reasoning model. It accepts text, images, video, audio, and PDFs; provides **1,048,576 input tokens** and **65,536 output tokens**; and supports four thinking levels. Built-in capabilities include Search and Maps grounding, code execution, computer use, file search, URL context, caching, structured outputs, and function calling.

Sources: [Gemini 3 Flash model page](https://ai.google.dev/gemini-api/docs/models/gemini-3-flash-preview), [Gemini 3 developer guide](https://ai.google.dev/gemini-api/docs/gemini-3)

## Cost and limitations

Paid pricing is **$0.50 input and $3 output per million tokens**, with a free tier and Batch support. It outputs text only, lacks Live API and native media generation, has a January 2025 knowledge cutoff, and remains a preview model subject to migration.

## Scores

- **Tool use: 93/100.** Google's unusually broad built-in tool set supports capable grounded agents.
- **Reasoning: 86/100.** Dynamic thinking is strong for a Flash model but below flagship Pro tiers.
- **Context window: 96/100.** One-million-token input and 64K output are excellent.
- **Multimodal: 95/100.** Native text, image, video, audio, and PDF input provide broad understanding.
- **Coding: 88/100.** Code execution, computer use, and strong agent positioning make it capable for development work.
- **Cost efficiency: 97/100.** Low prices, batching, caching, and a free tier are highly competitive.
- **Overall Score: 92/100.** Half-up rounded mean: (93 + 86 + 96 + 95 + 88) / 5 = 91.6.

## Bottom line

Gemini 3 Flash is a highly economical million-context multimodal agent, with preview status and text-only output its main constraints.
