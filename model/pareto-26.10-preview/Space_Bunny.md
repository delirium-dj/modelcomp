## Model card

- **Name:** Pareto 26.10 (released as **Pareto 26.10 Preview** on 2026-10-01; **generally available as Pareto 26.10 on 2026-10-15**)
- **Short description:** Unbiased's blended/composite multimodal model — one request fans out to several upstream LLMs in parallel and the service synthesizes a single answer. Aimed at research, coding and agentic workflows. Not a single upstream checkpoint, so it cannot be compared 1:1 against a base model. It is a new release of the existing Pareto line (previous: Pareto 26.9, still available), not a separate model family.
- **Provider / access:** Unbiased AI platform (run by Circuit & Chisel), Chat Completions- and Responses-compatible endpoints; **OpenRouter** (`unbiased/pareto-26.10`, and `~unbiased/pareto-latest`); Parallel AI's search leaderboard runs it as `unbiased/pareto-26.10`. Third-party BYOK routers (AnyRouter, Puter, NanoGPT) expose it read-only.
- **IDs — LIFECYCLE, the material change this pass:** Unbiased's changelog entry dated **2026-10-15, "Pareto 26.10 is generally available"** states: "The `pareto` model string now points at 26.10; pin with `pareto-26.10`, or keep `pareto-26.9`, which remains available. If you've been on `pareto-26.10-preview`, use `pareto` or `pareto-26.10` for the stable release." Corroborated on OpenRouter: a new `unbiased/pareto-26.10` listing exists (Chat Completions only, **not available through EU in-region routing**), and **`https://openrouter.ai/unbiased/pareto-26.10-preview` now returns HTTP 404** — the preview ID is retiring exactly as the vendor says.
- **Release / knowledge:** preview 2026-10-01 (OpenRouter records 2026-09-30 in one listing, 2026-10-01 in others); GA 2026-10-15. Knowledge cutoff not disclosed in any reviewed first-party material.
- **Context window:** **1,048,576 tokens input; 131,072 tokens max output.** Confirmed at GA — the 2026-10-15 changelog states "with a 1M-token context" as part of the stable release's terms. 4x the 262,144 of Pareto 26.9.
- **Modalities:** text + image in; text out; reasoning yes (reasoning-type model per BenchLM classification); tool calls / `tools` + `tool_choice` supported; `max_tokens`, `temperature`, `top_p` control; **no enforced structured output** — the OpenRouter listing does not support `response_format`, so JSON mode is not guaranteed at the API layer. Unbiased's own October 8 guidance: agents requiring a strict JSON schema must validate responses themselves and handle parse failures.
- **Pricing (as of 2026-10-17) — CONFIRMED PERMANENT:** **$0.80 input / $0.03 cached input / $3.20 output per 1M tokens.** The 2026-10-15 changelog says explicitly: "Pricing is unchanged from the preview: $0.80 input, $0.03 cached input, $3.20 output per 1M tokens." Subscription allowances doubled at the same price (Personal 50M tokens/week, Personal Max 600M). Against Pareto 26.9 ($2.50 / $0.25 / $7.50) that is 68% / 88% / 57% cheaper per token. **Documented inconsistency, unresolved:** Unbiased's general pricing page and BenchLM both still display the **26.9** rate card ($2.50 / $7.50) against this model. The GA changelog is the more authoritative source and is what is scored.
- **Architecture:** proprietary blended composite service — several LLMs run per request and results are combined; no published parameter counts, no downloadable weights. Server-side tools (web search, image generation, patch application, tool discovery) are enabled by default on eligible Messages/Responses traffic — service-layer capabilities, not model features.

### Raw benchmarks found

All four headline figures remain **vendor-run and preliminary by the vendor's own label** (Unbiased model card, 2026-10-01 runs: "may change before final publication"; comparator rows "not independently validated"). Crucially, **Unbiased did not re-run the benchmarks for the 2026-10-15 GA.** The GA changelog entry announces the stable release and the price, and publishes no new evaluation; the model card page still carries the four October 1 preview numbers under a "Pareto 26.10 Preview" heading. **These are therefore preview measurements of the same weights, not an evaluation of the stable release.** BenchLM agrees on the substance: three source-displayable rows (Terminal-Bench 4.0, DeepSWE, GPQA-D), no overall score, "Unranked", and it still describes the listing as `pareto-26-10-preview`.

Agent / tool use:

- Terminal-Bench 4.0: **50.8%** ($0.48/task, Unbiased model card, 2026-10-01). In the same vendor sheet: Fable 5.1 55.1, GPT-6 Astra 59.6, GPT-6.1 Sol 56.1, Claude Sonnet 5.5 70.6, GPT-6 Luna 12.6 — Pareto is below every leader listed, and now sits **below Claude Sonnet 5.5 by 20 points**, a gap that has widened since the first pass because the field moved and Pareto's number did not.
- **New this pass, the first independent capability run of 26.10**: Parallel AI's search-capability leaderboard (`unbiased/pareto-26.10`, updated 2026-10-16) — **Search Intelligence Score 68.6 (#10)**, without-search 34.8, lift from search **+33.8**; cost **$116 per 1K tasks** (#3 on search efficiency); **436s per task**. Suite accuracy: DSQA 84.8 with search / 52.5 without, HLE 43.0 / 37.0, WISER 78.0 / 15.0. Two things matter here and neither is flattering: (a) on Parallel's own composite, **Pareto 26.10 scores 68.6 versus Pareto 26.9's 72.5** — the newer release is *behind* its predecessor on the only independent suite that has run both; (b) the search lift of +33.8 is one of the largest in the field, meaning a very large share of the measured capability is the search tool, not the underlying model.
- Tau3-Banking / Tau2-Bench, GDPval-AA, Claw-Eval / ClawProBench, Toolathon / MCP-Atlas / SWE Atlas Codebase QnA: **no verified public score found** for any 26.10 variant.
- Function-calling spot checks (Recruitly "results by job" harness, 18/18 tasks passed): **100% passed**, judge 42–100 — **provisional proxy**, not a standardized harness.
- Structured-output / classification robustness, independent (QuanticData, 2026-10-02, 134 hand-labelled scraper responses): **125/134 correct (93.3%)**, 9 bad pages accepted at 0.95–1.0 confidence, 0 good pages rejected. Same test: Pareto 26.9 131/134, GPT-6 Luna 134/134.

- HLE text-only: **49.9%** ($0.008/task). Recorded as a conflict, not averaged; it is the strongest single reason the reasoning score is not scored higher.

### Normalized scores (1–100)

- **Tool use: 72/100.** Held. Terminal-Bench 4.0 at 50.8% is still the only standardized agentic score and it is a **preview-era** number that the GA did not refresh; it now trails Claude Sonnet 5.5 by 20 points in the vendor's own table. Function calling demonstrably works (100% on 18 spot-check tasks) but the independent QuanticData run shows overconfident, unrouteable failures (9 false accepts at 0.95–1.0). Capped by a single unreproduced vendor number plus the absence of any Tau-bench / MCP-Atlas evidence. The new Parallel.ai suite is not credited here — it measures search-augmented answer quality, not tool use.
- **Reasoning: 88/100.** Held, and this is the score most exposed to a downward revision. GPQA-Diamond 92.4% is near the top of the field and HLE text-only 49.9% is respectable. Against it now sits the first genuinely independent run: **Parallel AI measures HLE at 43.0% with search and 37.0% without, and Pareto 26.10 (68.6) below Pareto 26.9 (72.5)**. That is not enough to move the number — it is a different harness and a different task set, and Parallel's DSQA/WISER suites are not scored here — but it is the first time an outside runner has touched this model and it did not reproduce the vendor's HLE. Held at 88 because every headline number is still vendor-run, preliminary by the vendor's own admission, and unreproduced; a 3–13 point independent shortfall on one of the two scored benchmarks would justify 84–85 if confirmed on a like-for-like harness.
- **Context window: 95/100.** Held. 1,048,576 in / 131,072 out is the top documented tier and the vendor has now confirmed it as a term of the **stable** release rather than a preview caveat — a genuine improvement in confidence about the window's existence. It still cannot score into the high 90s because **no retrieval benchmark has ever been run on this model at any length**, vendor or otherwise. The 4x bump over 26.9 remains a claim with a number attached and nothing measuring it.
- **Multimodal: 72/100.** Held. Text + image in, text out. Still no 26.10 vision number; the closest remains MMMU-Pro 78 on Pareto 26.9, a provisional proxy. No audio, video or PDF input, and no enforced JSON/structured-output mode.
- **Coding: 76/100.** Held. DeepSWE v1.1 at 69.9% is a genuine agentic-coding result level, level with Fable 5 (70.0) and behind Sol (75.2), at roughly 1/30th of Fable's per-task cost. No SWE-bench, LiveCodeBench, SciCode or Vibe Code Bench figure exists for 26.10 in any of the four searched sources, and the harness caveat that denominators need confirmation has not been addressed by the GA.
- **Cost efficiency: 95/100.** Held, at the ceiling this scale allows. The GA changelog **confirms the preview price is permanent** — $0.80 / $0.03 / $3.20 — which removes the single largest risk attached to a preview release and is a real gain in cost certainty. Measured cost per task ($0.24 DeepSWE, $0.48 Terminal-Bench) is 1–2 orders of magnitude below the comparators, and Parallel's independent $116/1K tasks is #3 on its efficiency board. Not higher because it is a paid model on the Unbiased platform, no free tier exists, and Unbiased's own pricing page still shows the older 26.9 rate card.
- **Overall Score: 80.6/100.** (72 + 88 + 95 + 72 + 76) / 5 = **80.6**, cost excluded — **unchanged from the first pass**. Strong, cheap and unusually long-context composite whose four headline scores are still preview-era vendor numbers; best fit as a low-cost high-volume reasoning/agentic workhorse. What changed this pass is that the release is no longer a preview, and the price is locked — not that anything has been newly demonstrated.
