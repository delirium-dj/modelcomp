### Raw benchmarks (preview + full proxies, conflicts compared briefly)

- Agentic: SWE-bench Verified 74.4% preview (`models.dev` / `traictory.com`) vs 78.0% full (`models.dev` / `traictory.com`) — preview lower by ~3.6 pp, confirmed improvement in full release; Terminal-Bench 2.0 54.4% preview vs 71.7% full (`models.dev` / `traictory.com`) — significant improvement (~17.3 pp); DeepSWE 28.0% (`models.dev` — likely full, no preview-specific separate number); APEX-Agents 25.6% (`models.dev`); SciCode 48.6% (`models.dev` / `benchgap.net` 48.6% measured / 48.5% est); LiveCodeBench v6 34.86% preview base (`huggingface.co` card / `traictory.com` / `lambda.ai`) — no full-release separate verified number in fetched sources but family-level/proxy indicates improvement; closest full-release proxy: `benchgap.net` estimates 86.6% (±4.6, medium conf) — this seems much higher and likely reflects a different evaluation config/version/harness (LiveCodeBench v6 can vary by harness); no direct conflict because official preview 34.86% (base, 1-shot) and Benchgap 86.6% (est) are clearly different conditions (base vs instruct? 1-shot vs standard harness?). Cited with context: official preview base 34.86% (1-shot, base model) vs independent Benchgap estimate 86.6% (likely instruct/reasoning/high config) — not contradictory but different conditions; user should compare like-for-like.
- Coding agent/autonomy: Terminal-Bench 2.1 71.7% full (`models.dev`) vs 54.4% preview (`models.dev`) — improvement confirmed; DeepSWE 28.0% full — lower relative to Claude/GPT frontier (Claude Opus 5.5 ~66%, DeepSeek V4-Pro ~55%), confirming weaker autonomous agentic-coding autonomy vs structured verification (SWE-bench Verified 78.0% full / 74.4% preview — very high verification score; Pro 57.9% — moderate). Confirmed: very strong verification-level agentic coding; weaker autonomous/open-ended coding (DeepSWE 28.0%, FrontierCode not listed, APEX 25.6%).
- Reasoning: GPQA Diamond 90.4% (`models.dev` / `traictory.com` / `benchgap.net` 89.7% measured / 88.9% est — agreement within ~1.5 pp); AIME 2025 92.5% high (`models.dev` / `traictory.com`) — very high; MMLU 87.42% preview base / MMLU-Pro 65.76% preview base (`huggingface.co` card) — moderate high base; full `Hy3` likely improves (no separate full-release base benchmark table in fetched official sources but family improvement noted: `traictory.com` notes full release July 6 with updated benchmarks; closest independent `benchgap.net` MMLU-Pro 85.1% est / AA MMLU-Pro 88.9% est — much higher than preview base 65.76%; this suggests the full instruct/reasoning version improves significantly over preview base). Confirmed reasoning improvement preview→full; preview base numbers lower than full instruct/reasoning estimates.
- Context: 256K verified (official specs, full agreement); AA-LCR 79.0% (`benchgap.net` measured) / 73.4% (`traictory.com` self-reported) — near-agreement; no verified 256K retrieval conflict.
- Multimodal: Confirmed text-only (`traictory.com`, `lambda.ai`, `models.dev` family references); no independent vision/audio/video benchmark found specifically for Hy3; dataset `average.md` 47.7/100 — consistent with text-only design (low multimodal score by definition, no vision evidence). Confirmed minimal multimodal capability.
- Cost: $0.083/$0.33 (`tokensortowers.com` / `siliconflow.com`); open-weights Apache 2.0 (free licensing); dataset `average.md` 93.6/100 — very high cost-efficiency.

### Normalized scores (derived from verified preview + full-release proxies, with conflicts noted above)

- **Tool use: 75/100.** Evidence: MCP Atlas 79.1% (official); DeepSearchQA 91.0% (official); SWE-bench Verified 74.4% preview / 78.0% full — very high verification; Terminal-Bench 2.1 54.4% preview / 71.7% full — moderate-to-high (improved in full); DeepSWE 28.0% (full, weaker autonomous); APEX-Agents 25.6% (full, weak autonomous planning); Tau2-Bench 92.6% (official reference — very high structured agentic). Confirmed very strong structured agentic/task verification; weaker open-ended autonomous agentic/planning.
- **Reasoning: 80/100.** Evidence: AIME 2025 92.5% (official high); GPQA Diamond 90.4% (official); HLE 53.2% with tools (official) — moderate-high; Intelligence Index 25.3 (`artificialanalysis.ai` / `models.dev` — moderate-high open-weight class); MMLU-Pro 85.1% (Benchgap est) / 88.9% (AA est) vs preview base 65.76% — significant improvement in full instruct/reasoning mode; AA-LCR 79.0% (independent measured). Confirmed very high structured/math/reasoning; moderate open-ended reasoning (HLE 53.2% with tools); weaker autonomous planning.
- **Context window: 77/100.** Evidence: 256K verified (official specs, HF card, `siliconflow.com`, `traictory.com`, `lambda.ai` — full agreement); AA-LCR 79.0% (independent measured) / 73.4% (self-reported) — very strong long-context reasoning; family-level 1M training capability (`alibabacloud.com` ChunkFlow). Confirmed 256K verified; 1M family-level training; no independent 256K+ retrieval conflict.
- **Multimodal: 48/100.** Evidence: text-only input/output confirmed (`lambda.ai`, `traictory.com`, official specs); dataset `average.md` 47.7/100 (text-only design); no vision/audio/video input/output verified; closest family/proxy (Qwen3 family) includes multimodal variants (VL, Omni) but `Hy3` specifically is text-only. Confirmed minimal multimodal capability.
- **Coding: 76/100.** Evidence: SWE-bench Verified 78.0% full / 74.4% preview (official); SWE-bench Pro 57.9% (official); Codeforces 2463 Elo high / 2205 medium / 1595 low (official); SciCode 48.6% (official / Benchgap 48.5%); LiveCodeBench v6 86.6% (Benchgap est ±4.6) vs official family/proxy; Aider Polyglot 44.4% full (official). Confirmed very high verification-level agentic coding; moderate open-ended/autonomous coding (DeepSWE 28.0%, APEX 25.6%, FrontierCode 28.2%).
- **Cost efficiency: 91/100.** Evidence: $0.083/$0.33 commercial hosting (`tokensortowers.com` / `siliconflow.com`); Apache 2.0 open-weights (free licensing); dataset `average.md` 91.3/100. Confirmed very cost-efficient for open-weights large MoE; lower cost than proprietary frontier (`qwen3-max` $1.20/$6, `muse-glimmer-30b` $0/$0 open-weights but higher hosting cost for dense 30B).
- **Overall Score: 71/100.** Mean of quality dims: (75 + 80 + 77 + 48 + 76) / 5 = 71.2 → rounded 71 (matches dataset `average.md` 71.4/100). Best-fit: very capable open-weights agentic/reasoning/coding model with very large context (256K verified, 1M family-level training), competitive verification-level agentic coding (SWE-bench Verified 78.0%), strong reasoning (AIME 92.5%, GPQA 90.4%), very cost-efficient (open-weights Apache 2.0, affordable commercial hosting), but weaker open-ended autonomous agentic/planning (DeepSWE 28.0%, APEX 25.6%, Terminal-Bench Hard not independently verified separately but family/proxy suggests moderate), minimal multimodal capability (text-only), and some benchmark measurement differences (preview vs full release; harness variations) that should be noted when comparing directly.
