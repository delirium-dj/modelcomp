- Source: Alibaba / Qwen (`qwen-3.7-flash`; id `qwen/qwen3.7-flash`; no Artificial Analysis page — hard 404)
- Date: 2026-10-30 (UTC)
- Overview and scoring methodology: `../../model-comparison.md`

> **Verdict:** Qwen 3.7 Flash is Alibaba's July-2026 budget-tier native vision-language **reasoning** model — 1M-token context, text+image+video in (the only 3.7-family model that takes video; the flagship Max is text-only), reasoning on by default, from $0.03/$0.13 per 1M tokens. It is a genuine, distinct, shipping artifact with a rich documented tool surface (function calling, structured outputs, and Responses-API server tools: code_interpreter / web_search / web_extractor / image+text search). But the quality evidence is near-nonexistent, and what exists is negative: Alibaba published **no** benchmark table for Flash, Artificial Analysis returns a hard 404 (while Plus returns 200), LMArena has no entry, and the single independent eval (Roboflow Vision Evals) ranks it **22nd of 23** overall (61.7%), 10th on identification (84.4%), and **dead-last on OCR** — while ranking **1st of 23 on cost**. Provider telemetry records an 8.88% tool-call error rate and a P99 end-to-end latency of 90.19s. It is a high-volume perception instrument, not a quality one. Scored Overall 69 (div +2.3 vs curated 66.7).

## Model card

- **Name:** Qwen 3.7 Flash
- **Short description:** Alibaba's budget-tier native vision-language reasoning model (July 2026): 1M-token context, text+image+video input → text output, reasoning on by default, function calling and Responses-API server tools at ultra-low cost ($0.03/$0.13 per 1M at the sub-32K bracket). Positioned in Alibaba's own words as an incremental platform update over 3.6-Flash — not a flagship — and behaving like a listing, not an event.
- **Provider / access:** Closed weights, API-only. Three front doors: **QwenCloud**, **Alibaba Cloud Model Studio**, and **OpenRouter** (slug `qwen/qwen3.7-flash`; dated variant `qwen/qwen3.7-flash-20260727`). OpenRouter has **exactly one provider** behind it — Alibaba Cloud International — with no routing fallback and no second host to fail over to. Served in 4 regions (Beijing, Singapore, Frankfurt, Tokyo) with feature gaps: web search Beijing+Singapore only; batch inference Beijing only; function calling + context caching everywhere; fine-tuning nowhere.
- **Release / knowledge:** QwenCloud changelog dated **25 July 2026**; OpenRouter lists release **27 July 2026**. No knowledge-cutoff published. The only first-party announcement is a single changelog paragraph — no research post, no open weights, no parameter count, no dense/MoE statement, no training-token figure.
- **IDs:** id `qwen/qwen3.7-flash` (OpenRouter); Alibaba Cloud Model Studio model card. **No Artificial Analysis page** (hard 404 on both `qwen-3-7-flash` and `qwen3-7-flash`; the Plus sibling returns 200 — so the absence is real, not a scraping miss). No LMArena entry (seven Qwen 3.7 entries exist, none Flash). No HF repo (closed weights).
- **Context window:** **1,000,000** total; max input **991,808** (thinking-mode **983,616**); max output **65,536**; max chain-of-thought budget **262,144**. (meta.json's "131,072 max output" conflicts with the Model Studio card's 65,536 — flagged below.)
- **Modalities:** Text + image + **video** in → text out. Reasoning **ON by default** with a token budget. The only model in the 3.7 family that accepts video; the flagship Max is text-only, so the perception tier sits at the bottom of the ladder and the reasoning tier at the top.
- **Pricing:** Tiered on prompt length — **<32K input: $0.03/$0.13** per 1M (in/out); **32K–256K: $0.10/$0.40**; **256K–1M: $0.20/$0.80**. Cache **$0.006**. OpenRouter's rolling 30-day customer blend is $0.044 in / $0.149 out at a 51% cache-hit rate. Note: the famous $0.03 rate and the 1M window **cannot both apply in one request** — using the full context costs ~6.7× the budgeted input rate. Alibaba's own card prints the identical three-bracket structure in CNY.
- **Architecture:** **Undisclosed.** No parameter count, no dense/MoE statement, no training-token figure. The only structural fact on the record is the tokenizer family. Closed, API-only; fine-tuning is not supported in any region.

### Raw benchmarks found

> **Provenance:** Almost entirely ABSENT. Alibaba published **no** benchmark table for Flash (the two Qwen 3.7 research posts cover Max and Plus and never mention Flash). Artificial Analysis returns a hard 404. LMArena lists seven Qwen 3.7 entries, none Flash. benchlm.ai covers **1 of 724** benchmarks. The ONLY independent quality eval is Roboflow Vision Evals. Everything else is vendor prose (capability claims with no numbers) or OpenRouter provider telemetry.

- **Agent / tool use:** Documented but NOT benchmarked — function calling + structured outputs are supported; Responses-API server tools include `code_interpreter`, `web_search`, `web_extractor`, and image/text search; prefix completion and context caching (implicit + explicit) work in all regions. BUT no agentic benchmark exists, web search runs in only 2 of 4 regions, and OpenRouter telemetry records an **8.88% tool-call error rate**. Alibaba never claimed GUI/computer-use for Flash (that belongs to 3.7 Plus); OpenRouter's "computer interaction" blurb is OpenRouter's phrasing, widely mis-repeated as a vendor claim.
- **Reasoning / knowledge:** Reasoning is ON by default with a **262,144-token CoT budget** — architecturally a reasoning model. But NO reasoning/knowledge benchmark is published by Qwen; the single covered eval is **FrontierMath v2 (Tiers 1–3) at 19.298%** (benchlm.ai), which is weak. Family context: Plus AA Index 39, Max AA Index 46 — Flash has none.
- **Coding:** "Optimised multimodal coding" is claimed in prose with no number behind it; `code_interpreter` is a documented server tool. NO SWE-bench / LiveCodeBench / Terminal-Bench / HumanEval result exists. Coding is essentially unmeasured.
- **Long context:** 1M window (991,808 max input; 262,144 CoT budget) — genuinely large — but no long-context retrieval/reasoning benchmark (no RULER, no MRCR) is published, and the tiered pricing penalizes long prompts (6.7× the base input rate at the top bracket).
- **Speed / cost:** OpenRouter telemetry — **59 tok/s P50** throughput (fastest of the 3.7 tier; Plus is ~12), **1.20s median latency**, **99.99% uptime**, but a **P99 end-to-end latency of 90.19 seconds** (bad tail) and the 8.88% tool-call error rate. Roboflow ranks it **1st of 23 on cost** (~$0.0001/sample). No AA Speed/Cost page.
- **Vision (the one measured quality axis):** **Roboflow Vision Evals** — **22nd of 23 OVERALL at 61.7%**; 10th of 23 on identification at 84.4%; **dead-last on OCR transcription**; matches ground truth 84.1% on average; 1st of 23 on cost. A fair one-line summary of the model: a volume instrument.

### Normalized scores (1–100)

- **Tool use: 63/100.** A rich, documented tool surface — function calling, structured outputs, and Responses-API server tools (`code_interpreter`, `web_search`, `web_extractor`, image/text search) — but zero agentic benchmark, web search confined to 2 of 4 regions, and a measured 8.88% tool-call error rate temper reliability.
- **Reasoning: 64/100.** Reasoning is on by default with a large 262,144-token CoT budget, so it is architecturally a reasoning model, but no positive reasoning/knowledge benchmark exists — the one covered eval (FrontierMath v2, 19.3%) is weak, and the Plus/Max siblings' AA scores are not Flash's.
- **Context window: 82/100.** A genuine 1M-token window (991,808 max input) with a 262K CoT budget — large and well-documented — held back from the top 1M tier by the absence of any long-context retrieval benchmark and by tiered pricing that makes the full window ~6.7× more expensive.
- **Multimodal: 74/100.** Text + image + video input → text out; video is rare and it is the only 3.7-family model that accepts it. But the one measured vision eval (Roboflow) ranks it 22nd of 23 overall and dead-last on OCR, so modality breadth is real while measured quality is weak.
- **Coding: 63/100.** "Optimised multimodal coding" and a `code_interpreter` tool are claimed/documented, but there is no SWE-bench / LiveCodeBench / Terminal-Bench / HumanEval result — coding is essentially unmeasured.
- **Cost efficiency: 91/100.** $0.03/$0.13 per 1M at the sub-32K bracket is ultra-cheap, Roboflow ranks it 1st of 23 on cost (~$0.0001/sample), and the cache rate is $0.006 — best-in-class; tempered by the tiered long-context rates ($0.20/$0.80), the single-provider / no-fallback risk, and the rework cost of an 8.88% tool-error rate. (Scored but NOT counted toward Overall.)
- **Overall Score: 69/100.** Half-up mean of the five quality dims (63+64+82+74+63)/5 = 69.2 → 69. Divergence **+2.3** vs the curated queue value 66.7 — driven by the genuine 1M context and rare video-input breadth, against a near-total absence of positive quality evidence (AA hard-404, no Qwen benchmark, 22nd/23 vision, last-of-23 OCR, 8.88% tool error, P99 90s). Cost efficiency excluded from the mean per methodology.
