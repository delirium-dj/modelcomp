## Model card

- **Name:** Qwen3.7 Flash. Alibaba's **closed-weights Flash-tier multimodal** model with a 1M context window — text/image/video in, text out — positioned for cheap long-context agent and document work. **A negative finding governs this report: BenchLM carries no `qwen-3-7-flash` page in any spelling** (it 404s), so the 2026-11-06 re-research had no catalog to check against.
- **Short description:** Identified by the repo's meta as Alibaba's **July 2026 Flash at $0.03/$0.13 per 1M (≤32K input) with $0.006 cache** — **the cheapest rate card measured in this research series** — offering reasoning, function calling and web search at ultra-low cost, at a **1M window with 131,072 max output**.
- **Provider / access:** QwenCloud / Alibaba Cloud Model Studio, OpenAI-compatible; also served by 15 providers per models.dev. **The OpenCode Console/Zen catalog does not list this ID.**
- **Release / knowledge:** released **2026-07-15** (models.dev) — but **conflicting dates exist**: OpenRouter's snapshot is `qwen3.7-flash-20260727` and Epoch/Benchable date it 2026-07-27, recorded rather than reconciled. **Knowledge cutoff not disclosed.**
- **IDs:** `alibaba/qwen3.7-flash` (models.dev); `qwen/qwen3.7-flash-20260727` (Openrouter); `opencode/qwen-3.7-flash` (repo id).
- **Context window:** **1,000,000 tokens total.** **Max output is conflicting across three sources: 131,072 (models.dev and qwencloud) vs 65,536 (Alibaba model card per eesel, and Roboflow) vs 128,000 (LLMLearner)** — the models.dev/qwencloud figure is used and the conflict is surfaced. Chain-of-thought budget is separately 262,144; max input 991,808 (983,616 in thinking mode).
- **Modalities:** **multimodal — text, image and video in; text out**, corroborated by qwencloud, epoch.ai, Roboflow, BenchGecko, LLMLearner and Benchable — **six independent sources**, which is unusually strong corroboration for a modality claim. models.dev's input column renders as a non-text icon set and cannot be read as text, so it is not counted as a counter-source. Reasoning model; tool calling and structured output both supported.
- **Pricing (as of 2026-11-06):** **$0.03 input / $0.13 output per 1M (≤32K input) on QwenCloud, with $0.006 cache** (repo meta) — the cheapest rate card measured anywhere in this research series. Note the ≤32K-input qualifier, which means the headline price applies only to short prompts.
- **Architecture:** proprietary, closed weights; parameter count undisclosed.

Recommendation: **the cheapest rate card in this research series, attached to a model with zero measured capability.** $0.03/$0.13 per 1M at a **1M window with 131,072 output**, **three-modality input corroborated by six independent sources**, a **262,144 CoT budget**, and **reasoning + function calling + web search** is a genuinely attractive package on paper for high-volume long-context agent and document work — and the price makes experimentation nearly free. **But note that not one benchmark exists for this model anywhere**: no SWE-bench, no Terminal-Bench, no GPQA, no HLE, no composite, no reliability figure and no visual benchmark.
