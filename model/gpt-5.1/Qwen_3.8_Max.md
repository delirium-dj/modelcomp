## Model card

- **Name:** GPT-5.1 (this dataset maps to Artificial Analysis's **"GPT-5.1 (High)"** — the reasoning/Thinking variant at high effort). Family: **GPT-5.1 Instant**, **Thinking**, **Auto** (router), **Pro**, and the agentic **Codex line** (Codex, Codex-Mini, **Codex-Max**).
- **Short description:** **OpenAI's November-2025 iterative refinement of GPT-5 — warmer tone, adaptive reasoning, dramatically better instruction-following and 30–50% token efficiency — now DEPRECATED and superseded by GPT-5.2 (~1 month later).** Its launch headline numbers were strong: **SWE-bench Verified 76.3%** (+3.5 pts over GPT-5's 72.8%, resolving **381 of 500** real GitHub issues), **AIME 2025 94%**, and **GPT-5.1-Codex-Max 77.9%** on SWE-bench Verified. But the **only current independent anchor** — the **AA Intelligence Index v4.3.2 = 25 (an *estimate*, #124/215, *below* the 27 median)** — places it **below average**, and OpenAI has since **retired SWE-bench Verified itself** ("increasingly contaminated and mismeasures frontier coding progress," Feb 2026), so the signature coding number is now **self-contested**. **METR** found Codex-Max's long-horizon autonomy "**very similar to GPT-5**" (it failed all five attempts at the hardest task tier). ⚠ **Meta correction:** the scaffolded meta's "**SWE-Verified 66.0%**" is **incorrect — the figure OpenAI reports for GPT-5.1 is 76.3%** (corroborated independently); 66.0% matches no published GPT-5.1 variant.
- **Provider / access:** **OpenAI.** First-party API (`gpt-5.1` = Thinking, `gpt-5.1-chat-latest` = Instant, plus `gpt-5.1-codex`, `-codex-mini`, `-codex-max`, `gpt-5.1-pro`) and ChatGPT (Free/Plus/Pro/Team/Enterprise). **Proprietary** (weights/parameters undisclosed). Available via **2 API providers** on AA. `noFreeId: true`. Listed here as `opencode/gpt-5.1`.
- **Release / knowledge:** **ChatGPT 2025-11-12, API 2025-11-13** (High variant dated Nov 13); **GPT-5.1 Pro + Codex-Max 2025-11-19**. ⚠ **Now DEPRECATED** — AA flags it ("**OpenAI has launched a newer release, GPT-5.2. We suggest considering it instead**") and only continues benchmarking the **default 10k-input workload**. **Knowledge cutoff: Sep 30, 2024.**
- **IDs:** `gpt-5.1` (Thinking) / `gpt-5.1-chat-latest` (Instant) / `gpt-5.1-codex-max` / `gpt-5.1-pro` / `gpt-5-1` (Artificial Analysis slug) / `opencode/gpt-5.1` (this dataset).
- **Context window:** **400,000 total = 272,000 input + 128,000 output** (full API). *Verified against the meta's "400,000 total (128,000 out)."* ⚠ Lower on other surfaces: **Instant (`gpt-5.1-chat-latest`) = 128,000**; ChatGPT tiers are smaller still (Free 8K, Plus 32K, Pro/Business 128K Instant / 196K Thinking). The **Codex-Max** variant uses "**compaction technology**" to work across **millions of tokens** (whole-codebase refactors) despite the 400K window. Competitive but trails 1M-context rivals (Claude, DeepSeek V4, Grok).
- **Modalities:** **Text + image in → text out.** *Verified against the meta's "Text, image in; text out."* GPT-5.1 improved **image understanding** (facial consistency in edits, more accurate visual analysis) and **file processing** (PDFs, spreadsheets, documents). **No native video or audio.**
- **Pricing (as of 2026-10-25):** **$1.25 input / $10.00 output per 1M** — **unchanged from GPT-5**; **cached input $0.125 (90% discount)**; **blended $1.34** (AA 7:2:1). *Verified against the meta's "$1.25/$10.00 … $0.125 cached."* **Prompt caching extended to 24 hours.** ⚠ The meta's standout ("a much friendlier price band") is slightly off: the **rate card was NOT cut** vs GPT-5 — the effective-cost gain comes from the **30–50% token-efficiency improvement** (fewer tokens for the same task) plus caching, not a lower price.
- **Architecture:** **Proprietary; parameter count undisclosed.** A **reasoning model with *adaptive reasoning*** — it dynamically allocates thinking tokens to query complexity (the `reasoning_effort` API param; `none` disables extended thinking). **GPT-5.1 Instant is the first non-Thinking model that can decide when to engage deeper analysis**; **Thinking** runs ~2× faster than GPT-5 Thinking on easy tasks but ~2× slower on hard ones. Eight personality presets (Default/Professional/Candid/Quirky/Friendly/Efficient/Nerdy/Cynical).

### Raw benchmarks found

GPT-5.1 is a **deprecated** model whose **strong launch-era vendor numbers** are now shadowed by a **below-median independent estimate** and by OpenAI's own **retirement of its headline coding benchmark**. Provenance and vintage matter here.

**Independent — Artificial Analysis + METR (measured/estimated):**

- **AA Intelligence Index v4.3.2 = 25 (Estimated — "independent evaluation forthcoming"), ranked #124 of 215, *below* the price-class median of 27.** AA's verdict: "**below average in intelligence, but reasonably priced**." Because it is deprecated, AA only re-benchmarks the **default 10k-input workload**; other results are historical. *(Note: this ~25 estimate lands at essentially the same current-basket level as Grok 4.3's measured 24.88.)*
- **AA speed 126.9 tok/s** (#41/186 — "notably fast" vs the 82.3 median); **TTFT 28.45s** (high end vs the 3.90s median — the reasoning model's thinking time).
- **METR (2025-11-19) on GPT-5.1-Codex-Max:** long-horizon autonomous-task performance "**very similar to that of GPT-5**" — it "**failed all five attempts at each task**" on the hardest tier, i.e. Codex-Max did **not** materially extend the autonomous time horizon beyond GPT-5.
- **No Vals SWE-bench-Verified row** (deprecated; predates the current Vals board, which starts at GPT-5.2).

**Vendor — OpenAI (launch-era, Nov 2025):**

- **SWE-bench Verified 76.3%** (vs GPT-5's 72.8%; resolves **381/500** real GitHub issues) — ⚠ this is the meta's headline slot, where the meta incorrectly lists **66.0%**.
- **AIME 2025 94%** · **LiveCodeBench: "among top performers."**
- **GPT-5.1-Codex-Max 77.9% SWE-bench Verified** at medium reasoning (**~30% fewer thinking tokens** than GPT-5.1-Codex); agentic tools `apply_patch` + `shell`; compaction across millions of tokens.
- **Token efficiency: 30–50% fewer tokens** than GPT-5 for similar tasks (the real cost lever, since the rate card was unchanged).
- ⚠ **OpenAI, "Why we no longer evaluate SWE-bench Verified" (2026-02-23):** the benchmark is "**increasingly contaminated and mismeasures frontier coding progress**" — OpenAI retired the very benchmark that produced the 76.3%/77.9% headlines. Independent analysts also noted GPT-5.1's gains over GPT-5 were "**task-specific rather than universal**."

> Provenance: This is a **deprecated (superseded by GPT-5.2 within ~1 month), below-median-on-current-independent-estimate generalist** whose **vendor launch numbers were strong for Nov 2025** (SWE-bench Verified 76.3%, AIME 94%, Codex-Max 77.9%) but whose **only current independent anchor is an AA Index *estimate* of 25 (below the 27 median)**, and whose **signature coding benchmark was retired by OpenAI itself over contamination**. **METR** independently found the agentic Codex-Max long-horizon autonomy "**very similar to GPT-5**." **The scaffolded meta.json required ONE correction** — **"SWE-Verified 66.0%" → 76.3%** (OpenAI's official figure, independently corroborated; 66.0% matches no published GPT-5.1 variant). The rest of the meta is **verified accurate**: `opencode/gpt-5.1`, "Instant/Thinking revision," **400K/128K**, **text+image→text**, **$1.25/$10 with $0.125 cached**, and "Deprecated, superseded by GPT-5.2." The *standout* is flagged (the price band was **not** cut vs GPT-5 — the gain is token-efficiency), and the *tradeoff* ("dominated by 5.2 onward; keep it only for reproducibility") is accurate. Enriched here: the full variant landscape, the AA estimate/speed/TTFT, METR, AIME 94%, Codex-Max, 272K+128K context breakdown, 24h caching, personality presets, adaptive reasoning, and the Sep-2024 knowledge cutoff. **No benchmark was invented; vendor-vs-independent and the SWE-bench retirement are stated.**

### Normalized scores (1–100)

- **Tool use: 80/100.** Real agentic capability — full function/tool calling, and the **Codex-Max** variant's `apply_patch` + `shell` tools with **compaction across millions of tokens** for multi-hour, whole-codebase agent loops. Held to **80** because the **independent** evidence is lukewarm-to-absent: **METR found Codex-Max's long-horizon autonomy "very similar to GPT-5"** (failing the hardest tier), and AA has **no current GDPval-AA / AA-Briefcase / AutomationBench** number for it (deprecated, 10k-workload-only). Scored below grok-4.3 (82, which has measured GDPval-AA 1500 / τ²-Bench 98% / IFBench 81%), above the vendor-only agentic profiles.
- **Reasoning: 78/100.** A **strong vendor math result (AIME 2025 94%)** and adaptive reasoning that calibrates effort to difficulty, but the **independent AA Intelligence Index v4.3.2 is an *estimate* of 25 — *below* the 27 median** ("below average in intelligence"), and OpenAI's own retirement of SWE-bench plus analysts' "task-specific rather than universal" verdict temper the launch hype. Scored **78** — a touch above grok-4.3 (77) on the strength of AIME 94%, but capped by the below-median, deprecated, estimate-only broad composite.
- **Context window: 80/100.** **400,000 total (272,000 in + 128,000 out)** on the full API — adequate and verified, but **well short of the 1M tier** (Grok 4.3, DeepSeek V4 Pro) and even the 500K tier, and **Instant/ChatGPT surfaces drop to 128K/196K/32K/8K**. The **Codex-Max compaction** trick (working across millions of tokens) is a genuine mitigation for whole-repo work but is variant-specific, not the base window. Scored **80** — between the 256K tier (78) and the 500K tier (83).
- **Multimodal: 78/100.** **Text + image in → text out**, with improved visual analysis, facial consistency in image edits, and stronger PDF/spreadsheet/document processing. **No native video or audio**, so it sits at the **image-only** tier. Scored **78** — above the text-only floor (50) but below the native-video models (grok-4.3 82, Seed 2.0 Pro 84).
- **Coding: 79/100.** The **best-evidenced dimension at launch**: **SWE-bench Verified 76.3%** (+3.5 over GPT-5, 381/500 issues), **Codex-Max 77.9%**, and "top performer" on LiveCodeBench — materially better-published than grok-4.3 (which released no coding number at all). Held to **79** (not higher) because **every figure is vendor-reported**, **OpenAI retired SWE-bench Verified over contamination**, there is **no Vals row and no current independent AA coding eval**, and 76.3% is far below the elite independent coders (Claude Opus 5 ~97% / DeepSeek V4 Pro 96.4% on Vals). Scored **79** — just above grok-4.3 (76) and mistral-large-4 (78), below pareto (79≈) and the elite-Vals tier (86+).
- **Cost efficiency: 84/100.** **$1.25/$10 with $0.125 cached (90% discount), 24h prompt caching, and 30–50% token efficiency** make the *effective* cost attractive, and AA calls the input price "very competitive" (median $2.00). But the **$10/M output is mid-tier** (4× grok-4.3's $2.50) and the model is **deprecated** with a below-median index, so intelligence-per-dollar is unremarkable. Scored **84** — below grok-4.3 (87) and GPT-5.6 Luna (93), reflecting solid caching/efficiency against a premium output rate.
- **Overall Score: 79/100.** Mean of the five quality dimensions = (80 Tool + 78 Reasoning + 80 Context + 78 Multimodal + 79 Coding) / 5 = **395/5 = 79.0 → 79** (Cost efficiency 84 is scored but **not** counted, per the v4 formula). **Divergence note:** my independent read is **79 vs the queue's curated 83.9 → −4.9.** This is the same **launch-peak-vs-current** pattern as grok-4.3 (−4.2), gpt-5.2 and gemini-2.5-pro: the curated **83.9** captures GPT-5.1's **Nov-2025 standing as OpenAI's flagship generalist** (76.3% SWE-bench, 94% AIME, adaptive reasoning, warmer tone), whereas my score reflects the **current reality** — **deprecated and superseded by GPT-5.2 within a month, an AA Index v4.3.2 *estimate* of 25 (below the 27 median), OpenAI's own retirement of SWE-bench Verified over contamination, a lukewarm METR long-horizon result, and no current independent coding/agentic eval**. Its genuine strengths — a well-published 76.3%/77.9% coding line, AIME 94%, the Codex-Max compaction agent, strong token efficiency and a fast 126.9 tok/s — keep it at a solid **79** rather than lower.
