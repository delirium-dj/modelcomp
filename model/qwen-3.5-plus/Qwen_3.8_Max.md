## Model card

- **Name:** Qwen 3.5 Plus (**Qwen3.5-Plus**)
- **Short description:** **Alibaba's hosted, production-featured variant of the Qwen3.5-397B-A17B flagship** — the same 397B-total / 17B-active MoE, served via **Alibaba Cloud Model Studio / DashScope** with **1M-token context by default and official built-in tools** (the open-weight Qwen3.5 reaches 1M only via RoPE extension). Released **2026-02-16** as part of the "Native Multimodal Agents" Qwen3.5 generation, it is a **native text+image+video** model (vision trained from scratch on unified weights, not bolted on) with a **hybrid Gated DeltaNet + full-attention (3:1)** architecture. On **Alibaba's own** numbers the generation is formidable — **MathVision 88.6 (beats GPT-5.2's 83.0)**, **BrowseComp 78.6**, **OSWorld-Verified 62.2**, GPQA/MMLU-Pro "top tier / leading," and a claim that it **matches or beats GPT-5.2 and Claude Opus 4.5 on ~80% of tested dimensions**. ⚠ **But the independent evidence is markedly weaker and the model is thoroughly superseded:** on the neutral **Vals AI SWE-bench Verified** ruler it scores **85 / 68 / 36 / 0** by difficulty band — respectable on <15-min tasks (85%) but a **long-horizon collapse (36% at 1–4 hr, 0% at >4 hr)** — and the meta's measured **JobBench 18.5%** confirms weak professional-agent work. There is **no Artificial Analysis Intelligence Index** for it. It has been **superseded by Qwen3.6-Plus, Qwen3.7-Plus and Qwen3.8** — making it, in the meta's own words, "**a migration-compatibility pick**" whose "measured agent work already lagged the leaders." Its enduring draw is **price**: ~**$0.40/$2.40 per 1M** (far cheaper China-region/OpenRouter), **$0.04 cached**, for a 1M-context native-multimodal agent.
- **Provider / access:** **Alibaba Qwen team.** Hosted via **Alibaba Cloud Model Studio / DashScope API** (`qwen-3.5-plus`/`qwen-plus`) with 1M context and built-in tools; also on **OpenRouter** (`qwen/qwen-3.5-plus`). The underlying **Qwen3.5-397B-A17B is open-weight under Apache 2.0** (Hugging Face / ModelScope, self-hostable), but the **Plus** is the managed hosted variant. **No free-id tier** in this dataset (`noFreeId: true`); a Singapore-only free quota exists per Alibaba's pricing page. Listed here as `opencode/qwen-3.5-plus`.
- **Release / knowledge:** **2026-02-16** (Qwen3.5 generation). Knowledge cutoff not stated in the sources reviewed. **Superseded by Qwen3.6-Plus and later.**
- **IDs:** `qwen-3.5-plus` / `qwen-plus` (Model Studio) / `qwen/qwen-3.5-plus` (OpenRouter) / corresponds to open-weight `Qwen/Qwen3.5-397B-A17B` / `opencode/qwen-3.5-plus` (this dataset).
- **Context window:** **1,000,000 (1M) total by default — ~991,808 in / 65,536 out** — confirmed for the hosted Plus (the open Qwen3.5 is 262K native, ~1M via RoPE extension, "which may come with some quality degradation at the edges"; the Plus ships 1M out of the box). Frontier 1M-club membership.
- **Modalities:** **Text, image, video in → text out.** **Native multimodal** — text, images and video "were all part of the training mix from the very beginning… a single unified set of weights handling all three modalities," so cross-modal understanding is learned, not stitched. Strong vendor vision (MathVision 88.6, MMMU-Pro, OCRBench, native video summarization). Plus adds official **built-in tools** (function calling, structured JSON, multi-step tool orchestration, GUI).
- **Pricing (as of 2026-10-24):** **~$0.40 input / $2.40 output per 1M (Model Studio Intl); China region ~$0.115/$0.688; OpenRouter from ~$0.30/$1.80; $0.04 cached.** Among the **cheapest 1M-context native-multimodal APIs** available — the meta's "~$0.26–$0.40/$1.56–$2.40" range is confirmed. Open-weight self-host (Apache 2.0) is free beyond compute.
- **Architecture:** **Qwen3.5-397B-A17B MoE: 397B total parameters, 17B active per token** (512 experts, **10 routed + 1 shared active**). **Hybrid attention: 3 layers Gated DeltaNet (linear, Mamba2-style gated decay + delta rule) to 1 layer full softmax attention (3:1)** — this is what makes the long context practical. **Native FP8** training (50% less activation memory, 10%+ faster). **Vocabulary 248K tokens, 201 languages** (up from 152K/119), encoding non-English text 10–60% more efficiently. **Native text-image-video fusion**; **native agent design** (reasoning, coding, tool use, GUI). The hosted Plus = this model + 1M-default context + built-in tools + production features.

### Raw benchmarks found

The **generation-level (Qwen3.5-397B) vendor benchmarks** are strong; the **Plus-specific independent evidence** is weak on long-horizon/agentic work. There is **no Artificial Analysis Intelligence Index** entry for Qwen3.5-Plus.

**Independent — Vals AI SWE-bench Verified (bash-tool-only neutral harness), the key Plus anchor:**

- **Qwen 3.5 Plus: 85 / 68 / 36 / 0** by difficulty band (<15 min / 15 m–1 h / 1–4 hr / >4 hr) — solid on short tasks (85%) but a **long-horizon collapse (36% at 1–4 hr, 0% at >4 hr)**. For scale on the same ruler: its successor **Qwen 3.6 Plus = 86/71/38/0** (marginally better), **Qwen 3.8 Max = 93/84/64/67**, and the frontier is Claude Opus 5 = 98/97/90/100.
- **Meta's measured JobBench: 18.5%** — corroborates weak professional/agent-task performance.

**Vendor — Qwen3.5 generation (Alibaba's published evals; these are the 397B flagship = the Plus's base, cross-referenced by third parties but not independently reproduced for the hosted Plus):**

- **MathVision: 88.6** — beats GPT-5.2 (83.0); strong native visual math
- **BrowseComp: 78.6** — strong web-browsing agent
- **OSWorld-Verified: 62.2** — competent computer-use / GUI agent
- **GPQA Diamond: "top tier"; MMLU-Pro: "leading"; IFEval: "leading"** (the 9B sibling scores GPQA 81.7, IFEval 91.5, MMMU-Pro 70.1, MathVista 85.7)
- Vendor claim: **matches or beats GPT-5.2 and Claude Opus 4.5 on ~80% of tested dimensions** (Alibaba's own framing, caveated — "model developers tend to emphasize benchmarks where they do well")
- Where competitors still win (per the same third-party guide): **hard math** (GPT-5.2 AIME 2025 100%), **production coding** (Claude Opus 4.5 SWE-bench Verified 80.9%, GPT-5.3 Codex 83%)

> Provenance: This is a **vendor-strong / independent-weak** profile, so I grade it accordingly. The eye-catching numbers (MathVision 88.6 > GPT-5.2, BrowseComp 78.6, OSWorld 62.2, "matches GPT-5.2 on ~80%") are **Alibaba's own generation-level evals** for the 397B flagship; they were **not independently reproduced for the hosted Qwen3.5-Plus**, and there is **no AA Intelligence Index**. The genuinely **independent** signals — **Vals SWE-bench Verified 85/68/36/0** and the meta's **JobBench 18.5%** — show a model that is **fine on short coding tasks but collapses on long-horizon and professional-agent work**. The scaffolded meta.json was **verified rather than inherited** and is **accurate**: 1M-context hosted vision-language model ✓ (confirmed = hosted Qwen3.5-397B-A17B with 1M-by-default + built-in tools, per qwen.ai blog + ModelScope), text+image+video modalities ✓, ~$0.26–$0.40/$1.56–$2.40 pricing + $0.04 cache ✓, "superseded by Qwen3.6 Plus and later" ✓, and the "measured agent work already lagged the leaders / migration-compatibility pick" tradeoff ✓ — **strongly corroborated by the Vals long-horizon collapse and JobBench 18.5%**. The architecture (397B/17B MoE, hybrid Gated DeltaNet 3:1, 512 experts 10+1, native FP8, 248K vocab/201 languages, native multimodal) was **enriched** from the meta's vague "hosted vision-language model." **No benchmark was invented; the vendor-vs-independent split is stated throughout.**

### Normalized scores (1–100)

- **Tool use: 79/100.** Official **built-in tools** (function calling, structured JSON, multi-step orchestration, GUI) and decent **vendor** agentic marks (**BrowseComp 78.6**, **OSWorld-Verified 62.2**), but the **independent** picture is weak: **Vals long-horizon 36% (1–4 hr) / 0% (>4 hr)** and **JobBench 18.5%**. Scored **below Qwen3.8-Flash-Next (83)** and the verified agentic leaders — the browser/GUI vendor numbers are solid, but the model demonstrably cannot sustain long multi-step agent runs, and there is no AA Index to corroborate the vendor claims.
- **Reasoning: 80/100.** Strong **vendor** STEM/reasoning — **GPQA "top tier," MMLU-Pro "leading," MathVision 88.6 (beats GPT-5.2)** — and the generation's efficiency story is real (17B active). But it is **all first-party** (no independent AA Index or replication for the hosted Plus), competitors still win hard math (GPT-5.2 AIME 100%), and the model is **two+ generations superseded**. Scored level with the strong-vendor/unverified tier, **below Kimi K2.6 (85, AA Index 54)** and Qwen3.8-Flash-Next (81, GPQA 91.7).
- **Context window: 85/100.** **1M by default** on the hosted Plus (991,808 in / 65,536 out) — confirmed frontier 1M-club membership, delivered out-of-the-box (unlike the open model's RoPE extension). Scored level with the confirmed-1M models (Inkling, deepseek-v4-vision-exp, 85); just below Qwen3.6-Plus (86) as the earlier generation.
- **Multimodal: 82/100.** **Native text + image + video** (unified weights, trained from scratch — not a bolted-on adapter), with strong vendor vision (**MathVision 88.6 beats GPT-5.2's 83.0**, solid MMMU-Pro/OCRBench/video). Scored **level with the other Qwen video models (Qwen3.8-27B, Qwen3.8-Flash-Next, 82)** and Inkling (82) on 3-modality breadth + strong-but-vendor-only quality; **above Kimi K2.6 (79)** and image-only models. Not higher because the multimodal numbers are first-party and the model is superseded.
- **Coding: 80/100.** The neutral **Vals row 85/68/36/0** is the anchor: respectable short-task coding (85% <15 min) but a **long-horizon collapse (0% at >4 hr)**, and the third-party guide is explicit that **competitors dominate production coding** (Claude Opus 4.5 SWE-V 80.9%, GPT-5.3 Codex 83%). Scored **below Qwen3.8-Flash-Next (83)** and Grok 4.5 (85, elite Vals long-horizon) — marginally below its own successor Qwen3.6-Plus (Vals 86/71/38/0) — reflecting decent quick-fix coding but weak sustained/repo-scale work.
- **Cost efficiency: 89/100.** Excellent: **~$0.40/$2.40 per 1M (Intl), far cheaper China-region (~$0.115/$0.688) and OpenRouter (~$0.30/$1.80), $0.04 cached**, for a **1M-context native-multimodal** agent — plus an **Apache-2.0 open-weight base (Qwen3.5-397B-A17B)** for free self-hosting. Scored **level with Qwen3.6-Plus (89)**, just below the MIT/no-strings leaders (92) because the hosted Plus is a managed paid tier and the open 397B needs a multi-node cluster (~794GB BF16 / ~220GB 4-bit). Scored but **not** counted in the Overall per methodology.
- **Overall Score: 81/100.** Mean of Tool 79 + Reasoning 80 + Context 85 + Multimodal 82 + Coding 80 = 406/5 = 81.2 → 81. Best fit today: **cost-sensitive, short-horizon multimodal agent/coding workloads and migration compatibility** — teams already on the Qwen3.5-Plus API who need a **cheap 1M-context native text+image+video model with built-in tools** for browsing, GUI/OCR, chart/document understanding, and quick coding tasks. **Not** the pick for long-horizon agentic work (Vals 0% at >4 hr, JobBench 18.5%), for production-critical repo-scale coding (competitors dominate; successors are stronger), for anyone who can move to **Qwen3.6/3.7/3.8-Plus** (strictly better on the same ruler), or for verified frontier reasoning (no AA Index; the strong numbers are vendor-only). **Divergence note:** my 81 is **4.1 below the queue's curated 85.1** — a wider-than-usual gap, driven by the **independent long-horizon collapse (Vals 85/68/36/0)**, **weak JobBench (18.5%)**, the fact that its **headline benchmarks are vendor/generation-level and unreplicated for the hosted Plus** (no AA Index), and its status as the **earliest, now two-plus-generations-superseded** Qwen Plus — against genuinely strong native multimodality (MathVision 88.6 > GPT-5.2), confirmed 1M hosted context, Apache-2.0 open weights, and a best-in-class low price.
