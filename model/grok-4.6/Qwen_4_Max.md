## Model card

- **Name:** Grok 4.6 (API ID `grok-4.6`; AA tracks the **high** reasoning variant)
- **Short description:** xAI's **August 12, 2026** incremental frontier release (branded "SpaceXAI" on AA and the launch page) — builds on Grok 4.5 with "a particular focus on long-running agents and more ambitious interactive and visual work." Longer supplemental pretraining, SFT trajectories regenerated by Grok 4.5 across efforts/harnesses/domains, agentic RL in kernel optimization, web development, and CAD environments. **Deprecated** per AA — Grok 4.7 (Sept 21, 2026) succeeded it; docs.x.ai/developers/grok-4-6 now serves the Grok 4.7 page.
- **Provider / access:** xAI API (Responses + Chat Completions), Grok Build, Cursor (all plans; 2× included usage first week), OpenRouter, Vercel, Cloudflare, Modelflare (grok-award/grok-stable groups); **4 API providers** per AA. Proprietary, weights undisclosed. A **Fast variant at 2× token price** exists (launch post); family docs place Fast in Cursor/Grok Build only, not the public API.
- **Release / knowledge:** Released 2026-08-12; **knowledge cutoff February 1, 2026** (official spec per Modelflare's release guide). Reasoning effort **low / medium / high (default) / xhigh** — xhigh newly added vs 4.5.
- **IDs:** `grok-4.6`; predecessor Grok 4.5; successor Grok 4.7; ≠ Grok 4.6 Fast ≠ Grok 4.20 ≠ Grok 4.1 Fast.
- **Context window:** **500,000 tokens; no fixed text-output limit** (official). **≥200K prompt tokens → $4/$12 (cached $1) for ALL tokens in the request** (xAI pricing via Modelflare + OpenCode catalog). AA-LCR **80.3** (strong); no MRCR row. Cache affinity (`prompt_cache_key` / `x-grok-conv-id`) and context compaction recommended for agent loops.
- **Modalities:** **Text + image in, text out** (official + AA). No standard vision benchmark rows published (no MMMU-Pro/CharXiv/ScreenSpot); only Design Arena Website **1,283 Elo** (OpenRouter-carried) — visual capability evidenced mainly by vendor "visual web work" claims and design-arena play.
- **Pricing (as of 2026-11-12):** **$2.00 in / $0.50 cached / $6.00 out per 1M** (<200K); **$4.00/$1.00/$12.00** (≥200K); 75% cache discount; AA blended **$1.35** (7:2:1). Server-side tools (web search, X search, code execution) **$5 per 1,000 calls**. Cached input rose from 4.5's $0.30 to $0.50. Performance (high): **69 tok/s, TTFT 27.04s** (~2× class median 13.48s). Deprecated → 18h benchmark cadence.
- **Architecture:** Proprietary, undisclosed parameters. Tools: function calling, structured outputs, web search, X search, code execution. Encrypted reasoning returned on Responses API (family behavior documented on the 4.7 page).

### Normalized scores (1–100)

- **Tool use: 84/100.** GDPval-AA normalized **55.9%** (elite tier), TB2.1 **88.4** (AA), APEX-Agents 57.5, Tau3 Banking 50.7, EnterpriseOps 48.3, Briefcase 1,577; capped by TB4.1 **19.7**, TB3.0 26.5, ApprenticeBench 13, MazeBench 1, Gray Swan IPI 51.8 (weak injection robustness), and no OSWorld/BrowseComp/Toolathlon rows.
- **Reasoning: 84/100.** GPQA **94.9** (AA; Vals 94.7 confirms — top tier), MMLU-Pro 89.4, Omniscience net **+30.5** (unusually reliable knowledge), ARC-2 67.1, HLE 42.9; capped by FrontierMath v2 **66.0/31.7** (well below GPT-5.4's 78.6/49.0), CritPt 17.1, ARC-3 2.1.
- **Context window: 78/100.** 500K (half the 1M frontier class) with AA-LCR **80.3** and no fixed output limit; deducted for the **≥200K 2× whole-request surcharge** (earlier boundary than OpenAI's 272K), cache-affinity fragility, and no MRCR depth evidence.
- **Multimodal: 72/100.** Image input confirmed (official + AA) and vendor emphasis on visual/interactive web work; Design Arena 1,283 Elo is respectable; capped by **zero standard vision benchmark rows** (no MMMU-Pro/CharXiv/ScreenSpot/Video-MME) and no audio/video support.
- **Coding: 85/100.** SWE-bench **95.6** (Vals), CursorBench 3.2 **70.8** (Cursor-run), FrontierCode 1.1 Extended **61.3**, DeepSWE **65.9**, LCB 88.2, AA Coding Index 76.8, SciCode 56.5, FrontierSWE v2 25.3, VulcanBench 87.0; capped by TB4.1 **19.7**, TB3.0 26.5, CursorBench 4.0 41.4, Bug Hunt 27.0 — strong IDE/agent coding, weak terminal-harness generations.
- **Cost efficiency: 82/100.** $2/$6 with 75% cache (blended $1.35) undercuts GPT-6 Sol's $2/$10 at comparable agentic quality; deducted for the ≥200K 2× surcharge, $5/1K server-tool calls, 2× Fast variant, TTFT 27.04s, and deprecated status.
- **Overall Score: 80.6/100.** Mean of the five quality dims (84+84+78+72+85)/5 = 80.6. Best-fit (historical): Aug–Sept 2026 long-running coding agents in Cursor/Grok Build, GDPval-class knowledge work, and visual first-pass app building at $2/$6; today prefer Grok 4.7 — 4.6 remains notable for GPQA 94.9, Omniscience +30.5, and SWE-bench 95.6 (Vals), but TB4.1 19.7, absent vision evals, and the 500K/200K-surcharge window argue against frontier-terminal or long-document production use.
