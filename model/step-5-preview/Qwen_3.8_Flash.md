## Model card

- **Name:** Step 5 Preview (StepFun API model id **`step-5-preview`**, OpenRouter **`stepfun/step-5-preview`**, Artificial Analysis id **`step-5`**, curated id `opencode/step-5-preview`; flagship of the Step 5 family, succeeding Step 3.7 Flash)
- **Short description:** StepFun's **flagship foundation model for real-world agentic work** — "**a 600B-parameter sparse Mixture-of-Experts model with 27B active parameters, a 1M-token context window, and native support for text, image, and video inputs**", documented as delivering "**frontier-level performance across software engineering and professional knowledge work, with particular strength in finance**". The launch is titled "**Advancing the Pareto Frontier**", and the claim is economics rather than rank: same intelligence tier at a fraction of the price of the models it benchmarked itself against.
- **Provider / access:** **Proprietary today; open weights promised but not shipped.** Live through the **StepFun Open Platform** (`step-5-preview`, OpenAI-compatible Chat Completions **and** an Anthropic-style Messages API), **StepFun's own consumer products** ("available today through our products and API"), and — **as of October 8, 2026** — **OpenRouter**, where it appeared today with **one endpoint, served by StepFun alone (fp8), at the vendor's own list price**; there is **still no independent host**. The vendor states **"The model will be released with open weights on October 15"** — seven days from now — with **no license named anywhere on the announcement or docs** and **no technical report**. Verified against Hugging Face today: **`stepfun-ai/Step-5-Preview` does not exist (401)**, and the StepFun org's newest repository is still Step 3.7 Flash. Agent features are fully documented: **tool calling, parallel tool calling, streaming, JSON Mode and JSON Schema, prompt caching, `reasoning_effort` ∈ {low, medium, high}**, `max_tokens` defaulting to `INF`, and an official **Claude Code integration** page ("Configure Step Plan and enable 1M context"). **No free tier** (`noFreeId` correct).
- **Release / knowledge:** **Released September 20, 2026 at 03:15:13 UTC** (announcement thread + live API and docs the same morning; AA lists "Released September 2026"). **No knowledge cutoff is published** for this ID, and **no training-token count, MoE routing detail or architecture description beyond one paragraph** exists — the absence of a technical report is one of the explicitly-listed open gaps.
- **IDs:** `step-5-preview` (StepFun), `stepfun/step-5-preview` (OpenRouter), `step-5` (AA), `opencode/step-5-preview` (curated). **Aggregator coverage — strong:** **BenchLM has a page** with **Overall 70.17/100, ranked #17 of 888**, **42 of 625 tracks** ("partial coverage … so the overall score is conservative"), classified **Reasoning / 1M context**, official model card linked, and **rows attributed separately to the StepFun launch page and to Artificial Analysis** — an unusually good split of vendor vs independent evidence. **Artificial Analysis has a fully measured live page** (all four units: intelligence 4/4, speed 3/4, cost 2/4, verbosity 4/4) with **18 of 27 intelligence evaluations** run, plus a **Finance & Accounting Index** entry and per-evaluation leaderboards (AA-Briefcase, AutomationBench-AA, Terminal-Bench 4.0, GDP.pdf, EnterpriseOps-Gym, Harvey LAB-AA, ITBench, AA-AnalystAgent, MMMU-Pro, MLCR-AA). Siblings: Step 3.7 Flash (44.11), Step 3.5 Flash (42.41) — so Step 5 roughly **doubles** the family's previous best composite.
- **Context window:** **1,000,000 tokens in / 64,000 out** — confirmed four ways (vendor docs "Context window **1M tokens** … Maximum input **1M** … Maximum output **64k**"; AA "1M ~1500 A4 pages"; BenchLM 1M; OpenRouter's endpoint record 1M context / 64k output). Curated `meta.json` matches exactly — **the only folder in this batch whose curation is fully correct**. The **64 K output** sits precisely on the methodology's output ceiling: it clears the sub-64 K penalty but leaves no headroom for the "emit a whole codebase/deliverable in one call" pattern, and StepFun's own long-horizon demos route around it (a 6-million-token Pokémon run is many calls, not one). **Up to 60 images per request**; video via URL, Base64 or a `stepfile://` Files-API reference, **MP4/QuickTime/Matroska, individual files under 128 MB, under 5 minutes recommended**.
- **Modalities:** **text + image + video in, text out** (vendor docs, per-modality limits and dedicated image/video quickstarts), **reasoning, tool calls and JSON mode** as documented output behaviours. **Artificial Analysis' modality block lists only "text and image" input** — because AA measures MMMU-Pro and does not run a video evaluation, not because video is absent; the curated sheet's "Text, image, video in; text out" is **right and more complete than the aggregator's**. No audio in, no image/video output, no speech.
- **Pricing (as of 2026-10-08):** **$1.00 per 1M input tokens (cache miss), $0.05 cached input, $2.70 per 1M output — reasoning tokens included in the output price**, identical on the vendor's list and on OpenRouter (which launched today at list). AA records the **90 % cache discount**, ranks its **cost #52 of 226** in class (**mediocre $2.00 in / $10.00 out medians**; "well priced … on the lower end of cost for its intelligence index"), and measures **$1.03 per Intelligence-Index task** — reasonable in absolute terms but **≈4× the $0.27 class median**, because the run consumes **160 M Index tokens ("very verbose", median 81 M)**. Curated pricing note **$1.00/$2.70 is correct**. For comparison at the same benchmark table: Kimi K3 sells output at **$15.00**, i.e. Step 5 Preview's row is ~18 % of it.
- **Architecture:** **600 B total / 27 B active per token (~4.5 % sparsity) sparse MoE**, described in the (unofficial) model-card text as a **92-layer "narrow but deep" Transformer**, trained on text, code, mathematics and science, "**multimodal data including screenshots, UI mockups, video tutorials, and screen recordings**", and "**agentic trajectories from simulated and real tool-use environments**", with "**next-token prediction and reinforcement learning from human feedback (RLHF) with a focus on agentic objectives**", data "filtered for quality, safety, and license compliance". **None of this is vendor-verified** — there is **no technical report and no official weight release**, so architecture detail must be treated as second-hand. What is verifiable is behaviour: **three reasoning-effort levels per request**, and three published **long-horizon** demonstrations that describe the architecture's intended use better than any spec — **24 hours optimizing an H100 MLA kernel from scratch to 508 TFLOPS (StepFun quotes Claude Opus 5 at 493)**, **24 hours of automated post-training lifting a Qwen3-30B-A3B base from 53.3 % to 60 % on AIME24**, and **3,000+ turns / 6 M tokens of Pokémon Red reaching three Gym Badges with no game-specific optimization**; plus one agent action coordinating **950 web fetches** for a 1,000-location climate study.
- **Identity flags:** (1) **Weights are promised, not shipped:** "released with open weights on **October 15**", **no license named**, **no `stepfun-ai` Step 5 repository** (checked: 401 on 2026-10-08), **no technical report**. Any registry entry that labels this "open weight" today is wrong. (2) **Unofficial mirrors already exist:** Hugging Face shows `SHSLab/Step-5-Preview-BF16` and `TypeSafeAI/Step-5-Preview-BF16` reproducing StepFun's model card verbatim ("**our** flagship…", "Developer: StepFun", "License: **StepFun Community License**", "Open Weights: BF16 checkpoint **available now**") from **non-StepFun organizations**, ten days before the stated release date. **Treat as unverified uploads, not the release** — do not cite their license or file sizes as fact. (3) **Effort-mode mismatch in the headline table:** StepFun compares its own **High** effort against rivals at **Max**, six rows are **StepFun-internal benchmarks** (StepCodeBench, the FinStepBench suites), and the **HLE-with-tools row mixes a text-only subset against full-dataset runs** — StepFun itself writes those results are "**not directly comparable**". (4) **Document work is a real weakness** even at this tier: **GDP.pdf 14.8 %** vs GPT-6 Astra's 31.0 %, and **MLCR-AA 16.7 %**. (5) **Finance is a real strength**: **FrontierFinance 66.4 %** (beats GLM 5.3, Kimi K3 and GPT-6 Astra; only Opus 5 higher), and AA runs it on the Finance & Accounting Index — relevant to `models_finance/`, which is out of scope for this pass. ### Normalized scores (1–100)

- **Tool use: 82/100.** The strongest agentic *breadth* in this batch by a wide margin, and mostly independently corroborated: **MCP Atlas 85.6**, **Toolathlon-Verified 74.1**, **AutomationBench-AA 51.0 % (AA-run)**, **DRACO 83.3**, **CyberGym 84.7**, **BrowseComp 88.7**, **AA Harvey LAB-AA 93.4 %**, **ITBench 55.6**, **EnterpriseOps-Gym 47.2**, **JobBench 59.0**, plus **GDPval-AA 1,566 Elo** and **AA-Briefcase 1,424 Elo** for economic work, and a documented API surface built for loops (**tools, parallel tool calls, JSON Schema, prompt caching, `reasoning_effort`**) with an official **Claude Code** path. It stops short of the 90+ frontier band on the registry's own anchors: **GDPval ~1,566 vs the ~1,750** that anchors top-tier (Opus 5 posts 1,735 on the same table), **Terminal-Bench 4.0 at 33.3 %** — where Astra runs 57.9 and Opus 5 52.3 — and **no τ²/τ³ or BFCL row at all**, so tool-*call correctness* is asserted (85.6 on MCP Atlas) but not verified by a policy-following harness. **GDP.pdf 14.8 %** is a genuine hole in professional-document agent work.
- **Reasoning: 80/100.** **AA Intelligence Index 43.7, #40/226 against a class median of 26** — comfortably above this methodology's 20–35 mid band and into the tier where the anchors (GPQA 90+, HLE 40+) are actually met: **GPQA Diamond 93.5 %** and **AA-HLE 46.5 %**, with **CritPt 20.9 %** (research-physics reasoning, where most of the registry scores near zero) and **AA-SciCode 58.9 %**. Faithfulness is the best profile in this batch: **AA-Omniscience Index +16.4** — a *positive* reliability index, meaning more right than wrong when it answers — with **41.5 % accuracy and 43.0 % hallucination**; that accuracy figure is still low in absolute terms, which is why this sits at 80 rather than 88. Deductions: **MLCR-AA 16.7 %** shows long-context *medical* reasoning collapses, and there is **no independent lab seconding these numbers** — AA is the only measurement, and StepFun's own table is **High-vs-Max** with six self-authored benchmarks mixed in.
- **Context window: 88/100.** **1,000,000 in / 64,000 out**, quadruple-confirmed (vendor spec table, AA, BenchLM, OpenRouter's served endpoint), which is the registry's top size band and is **actually measured rather than merely advertised**: **AA-LCR v1.1 88.3 %** is one of the strongest long-context-reasoning rows in this whole pass — a second independent signal, since both BenchLM and the vendor table carry it. Held below the 95–100 tier because that band requires **≥98 % retrieval at 512 K+** and what we have is 88.3 % long-context *reasoning*, with **no MRCR / AI-Needle position sweep** and a counter-signal at the harder end (**MLCR-AA 16.7 %**). Output ceiling of **64 K** clears the penalty with no margin, `max_tokens` defaults to `INF` (model decides), and **prompt caching at $0.05/1M** is what makes a 1 M window affordable in practice — 950-fetch research runs are only plausible because of it.
- **Multimodal: 74/100.** Genuinely multimodal in a way most of this batch is not: **native text + image + video input** with documented, bounded support (≤**60 images** per request, `low`/`high` detail, **MP4/MOV/MKV video under 128 MB, ~5 minutes recommended**, `stepfile://` uploads), trained on "screenshots, UI mockups, video tutorials, and screen recordings", with **MMMU-Pro 76.4 % (AA-measured)** and **OfficeQA Pro 60.3 %** proving the visual path works. That is the "+video/PDF" band (75–90), and it lands at its bottom edge for three honest reasons: **AA's own modality block records only text+image** (no video evaluation exists, so the video claim is documented, not measured), **76 % trails the multimodal peers on StepFun's own table** (Kimi K3 81, Opus 5 85, Astra 87), and **professional document handling is weak (GDP.pdf 14.8 %)**. Output is text-only — no image, audio or speech generation, no audio input.
- **Coding: 78/100.** Strong and well-rounded, just short of the frontier band's anchors. **Terminal-Bench 2.1 85.0 %** meets the registry's TB-85+ bar, **AA-SciCode 58.9 %** clears the 55+ bar, **DeepSWE v1.1 67.7 %** is a high absolute figure but **misses the 74+ anchor and trails Astra (74.1) and Opus 5 (74.0)** — StepFun publishes that gap itself — while **SWE-Marathon 72.7 %** is nearly thirteen points behind Opus 5. **ProgramBench 80.5 %**, **Agents' Last Exam 29.5 %** (best of the Chinese pair, behind Astra) and the vendor's own **StepCodeBench 49.0 %** with an admitted "meaningful gap to the frontier" on the longest tasks fill in the picture, and the **24-hour kernel-optimization and automated-post-training runs** are the most interesting coding-agent evidence on the page (though vendor-run, unrepeatable, and best read as *stamina* rather than *quality*). Against that: **no SWE-bench Verified/Pro/Multilingual row, no LiveCodeBench, no AA Coding Index**, and **Terminal-Bench 4.0 at 33.3 %** against a class leader above 50 — the current-generation terminal harness, not the 2.1 one, is where the score is softest.
- **Cost efficiency: 86/100.** This is the dimension the launch was engineered around, and it holds up under independent measurement. **$1.00 per 1M input, $0.05 cached (95 % off on the vendor's figure; AA books a 90 % discount), $2.70 per 1M output — with reasoning tokens included in that output price**, against class medians of **$2.00 in / $10.00 out**, at **27 B active of 600 B total** (the smallest active footprint in its own comparison table), and AA prices it "**well priced … on the lower end of cost for its intelligence index**" with **$1.03 per Index task, #52/226**. Serving speed is **86.8 tok/s (#66/226, "faster than average")**, and OpenRouter took it on day one at the identical list price. Two real deductions, both token-driven: **verbosity 160 M for the Index run (#89/226 vs median 81 M — "very verbose")**, which is why the per-token bargain costs ~4× the class median **per task** ($0.27), and **7.1-minute-class task latencies plus 64 K output caps** on single-call deliverables. Structural risks a reader must price in: **no weights, no license and no second host until October 15**, so today's price is an un-competed list price from a single vendor, and **`reasoning_effort: high` is what all the good numbers were measured at** — the cheap operating point is `low`, and the honest comparison is per-task, not per-token.
- **Overall Score: 80/100.** Mean of the five quality dimensions (82 + 80 + 88 + 74 + 78) / 5 = 402 / 5 = 80.4 → 80; Cost excluded per `RULES.md`. Best fit: **long-horizon agentic work that must also be cheap enough to run all day** — multi-tool research and report production (950-fetch studies, DRACO 83.3, BrowseComp 88.7, MCP Atlas 85.6), **software-engineering agent loops with verification** (TB 2.1 85.0, DeepSWE 67.7, SWE-Marathon 72.7, the 24-hour kernel run), **finance and professional knowledge work** (FrontierFinance 66.4, Harvey LAB 93.4, AA Finance & Accounting Index entry), and **screenshot/chart/video understanding on 1 M context** where the 60-image and 5-minute video limits are accepted. Unfit for **native document/PDF reasoning** (**GDP.pdf 14.8 %**), for **current-generation terminal coding** (TB 4.0 33.3 % vs 50+ for the leaders), and for anyone whose procurement requires **a license, weights on disk, or a second provider** — none exist before **October 15**. Also not a factual answer engine (**Omniscience accuracy 41.5 %**, though its **+16.4 index** means it is at least honest about it). **Curation:** `meta.json` is **correct as written** (1,000,000 / 64,000, `$1.00/$2.70`, text-image-video in, reasoning/tool calls/JSON mode) — the only fix needed is a note that **open weights are pending, not shipped**.
