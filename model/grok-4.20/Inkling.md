## Model card

- **Name:** Grok 4.20 (official xAI display: `Grok 4.20`; vendor-hyphen style; folder slug `grok-4.20` uses version dots per `RULES.md`)
- **Short description:** xAI's February–April 2026 reasoning flagship with a unique multi-agent architecture (leader + 4 or 16 parallel agents inside a single call), a very large context window, industry-leading speed, and the highest non-hallucination rate (Omniscience) at its release. Deprecated in favor of Grok 4.3 (released April 2026) and later Grok 4.7.
- **Provider / access:** xAI API (`x-ai/grok-4.20` — OpenRouter, Google Cloud Vertex AI, Microsoft Foundry); consumer apps `grok.com` / `x.com` (with live-X data access); no open-weights release.
- **Release / knowledge:** Beta 2026-02-17; GA / API 2026-03-10; API route `grok-4.20` released 2026-03-31 (`OpenRouter`). Knowledge cutoff: September 1, 2025 (`LLMLearner`); `meta.json` notes `Nov 2024` for some sources — discrepancy flagged below.
- **IDs:** `opencode/grok-4.20`; `grok-4.20-reasoning` (reasoning mode on); `grok-4.20-non-reasoning` (reasoning off). Aliases listed in official docs (`grok-4.20-reasoning-latest`, `grok-4.20-beta`, etc.). No free tier (`noFreeId: true`).
- **Context window:** **2,000,000 tokens** (official xAI docs `docs.x.ai/developers/models/grok-4.20`; `OpenRouter`; `LLMLearner`). **Conflict:** Some sources list different limits — `Google Cloud Vertex AI` docs list `262k` context (`global endpoint: 200,000` for `grok-4.20-reasoning`) and `OpenRouter` also notes `2.0M`; `meta.json` records the discrepancy: `1,000,000-2,000,000 (xAI docs 1M with 30K max output; OpenRouter, AA and BenchLM list 2M)`. The `Google Cloud` figure (262k / 200K) appears to reflect a hosted endpoint constraint rather than the model's native capacity. Independent aggregator `Epoch AI` confirms 2M context (`LLMLearner` / `TheModelIndex`). **Resolution:** The native model capacity is 2M tokens; hosted endpoints may impose lower limits. The dataset `meta.json` captures this nuance correctly.
- **Modalities:** Text + image input; text output only. File / PDF input supported (`meta.json`: `Text, image, file/PDF in; text out`). No audio/video input or output. Multi-agent reasoning supported (single-agent `SA` or multi-agent `MA` mode per system card).
- **Pricing (as of 2026-11-02, verified from official `docs.x.ai` and `meta.json`):** $1.25 / $2.50 per 1M tokens (under 200K prompt); $2.50 / $5.00 per 1M tokens (>=200K). $0.20 cached. No free tier. Premium tier relative to smaller models; cost increases significantly at the 2M-context tier.
- **Architecture:** Proprietary (xAI), closed weights. Estimated 1.7–3 trillion total parameters (MoE backbone, `HokAI` review, 2026-02-17). Multi-agent design: leader agent (`Grok`) + 4 sub-agents (`Harper` — research, `Benjamin` — math/code, `Lucas` — synthesis/creativity) in standard mode; 16-agent `Heavy` mode available (per `HokAI`). This architecture reduces hallucination rate from ~12% to ~4.2% (internal xAI testing, `HokAI`).
- **Status / deprecation:** **Deprecated** — superseded by `Grok 4.3` (released 2026-04-30, per `TopReviewed.ai`) and later `Grok 4.7` (released 2026-09-21, per `TopReviewed.ai`). The `meta.json` explicitly records: `Deprecated for Grok 4.3.` Independent aggregator `TopReviewed.ai` confirms: `xAI superseded Grok 4.20 with Grok 4.3 (released 2026-04-30), and its models page now recommends Grok 4.7 (released 2026-09-21) for code and chat; Grok 4.20 stays GA.` The model remains available via API (`OpenRouter` lists it as GA with release 2026-03-31) but is no longer the vendor's recommended flagship.

> **Status/deprecation conflict (explicitly cited):** Official xAI docs (`docs.x.ai/developers/models/grok-4.20`) continue to describe the model as active/GA with no explicit shutdown date listed in the docs retrieved; `meta.json` and independent reviews (`TopReviewed.ai`) confirm it is deprecated/replaced by newer generations. There is no single official deprecation notice page equivalent to OpenAI's; the deprecation is communicated via product recommendations (`Grok 4.7` recommended) and dataset `meta.json` notes. **No numerical score conflict** arises from this — the model's benchmarks remain valid historical measurements.

## Raw benchmarks found (independent verification vs vendor / family claims)

> All scores below cite their exact source. Conflicting vendor vs independent values are explicitly flagged.

**Agentic / terminal (verified across sources):**
- Terminal-Bench 2.0 (agentic terminal automation): **57.3%** (official xAI docs / `LLMLearner` / `Epoch AI` / `benchgap.net` / `awesomeagents.ai` — agreement across independent sources; `LLMLearner` confirms 57.3% measured). The vendor does not publish a separate higher figure; the `LLMLearner` figure (57.3%) aligns with independent `Epoch AI` data (`57.3` accuracy, same harness). **No conflict** — independent verification confirms vendor-level figure.
- OSWorld / desktop automation: Not independently evaluated specifically for `grok-4.20` SKU; closest family reference is `Grok 4.20` not listed separately in `Epoch AI`'s OSWorld table. No vendor claim retrieved specifically for `OSWorld` for this SKU.
- APEX-Agents / agentic index: `Epoch AI` reports ECI score **152** (2026-02-17, #51 of 254 tracked models at that time); `TheModelBeat` reports Index score 159, rank 46/205. Independent aggregator `AI IQ` reports composite IQ 111, rank #76/176. These composite indices are not directly comparable to single-benchmark scores but confirm the model is in the upper-mid tier, not leading the field.

**Coding / engineering (independent verification):**
- SWE-bench Verified: **Not independently reproduced** specifically for `grok-4.20`. The dataset `meta.json` notes `SWE-bench 72-77% by harness`, and `LLMLearner` does not list a `SWE-bench Verified` figure for this SKU. Independent `Epoch AI` table (Feb 2026) does not include `SWE-bench Verified` for `Grok 4.20` (only `Terminal-Bench` 57.3%). Independent review `PopularAiTools.ai` (2026-03-15) reports `SWE-Bench (Coding) ~65%` (approximate, aggregated from third-party sources) — significantly below the `meta.json` range (72–77%). **Conflict:** The `meta.json` range (72–77%) appears to reference family-level or best-case harness results; independent `PopularAiTools.ai` reports ~65% for the exact SKU, and `Epoch AI` does not publish a `SWE-bench Verified` figure at all. The `LLMLearner` benchmark list (14 benchmarks) does not include `SWE-bench Verified`. **Resolution:** Coding performance is weaker than agentic/terminal performance; no independent source confirms a `SWE-bench Verified` figure above ~77% for the exact SKU; the independent `PopularAiTools.ai` figure (~65%) is lower.
- LiveCodeBench: `LLMLearner` reports `LiveCodeBench v6` 89.9% (estimated, ±2.4 pp, low confidence) — this appears to be a family-level or estimated figure, not a direct independent measurement for `grok-4.20`. `meta.json` notes `LiveCodeBench 84.3%`. Independent `Epoch AI` does not list `LiveCodeBench` for this SKU. **Conflict:** Independent estimates span 84.3% (`meta.json`) to 89.9% (`LLMLearner`, low confidence, estimated) — a moderate gap, with the lower figure (`meta.json`) being the more conservative reference.
- Vibe Code Bench / other coding: Not independently evaluated for exact SKU; no vendor claim retrieved specifically for `Vibe Code Bench` for `grok-4.20`. `LLMLearner` does not include it.

**Reasoning / knowledge (independent verification — multiple conflicts identified):**
- GPQA Diamond (PhD-level science reasoning): Official xAI launch / `LLMLearner` reports **89.35%** (`Epoch AI`, reproduced); `LLMLearner` reports `AA-GPQA Diamond` 91.5% (`LLMLearner`, measured — this appears to be a different harness/variant). `AwesomeAgents.ai` reports `GPQA Diamond` 89.3% (agreement with `Epoch AI`). `TopReviewed.ai` reports `GPQA Diamond` ~78.5% (`Artificial Analysis`, non-reasoning mode) / 88.9% (`HokAI` review, reasoning mode) — a 10-point spread by reasoning mode. `PopularAiTools.ai` reports `GPQA Diamond` 78.5% (aggregated, matching `Artificial Analysis` non-reasoning). **Conflict:** The `LLMLearner` figure (91.5%, measured) and `Epoch AI` figure (89.35%, reproduced) agree closely; `Artificial Analysis` (78.5%, non-reasoning) and `PopularAiTools.ai` (78.5%) are lower; `HokAI` (88.9%, reasoning mode) aligns with the higher cluster. The spread (78.5% to 91.5%) reflects different evaluation modes (reasoning on/off) and harness variants, not a direct contradiction — but it highlights that reasoning performance is highly mode-dependent.
- HLE (Humanity's Last Exam): `LLMLearner` reports `AA-HLE` 24.5% (non-reasoning) / 32.4% (reasoning) (`Artificial Analysis`); `Epoch AI` does not list `HLE` for `Grok 4.20`. `PopularAiTools.ai` reports `AA Intelligence Index` 48 (before rescaling) — a composite, not `HLE`. The `LLMLearner` figures (24.5–32.4%) are significantly lower than leading reasoning models (e.g., Claude Opus 4.6 reports ~85%+ on similar reasoning axes). **No direct vendor claim for `HLE` retrieved** — the only independent measurements (`LLMLearner` / `Artificial Analysis`) are low, confirming that reasoning is not the model's peak dimension.
- MMLU-Pro (broad knowledge): `LLMLearner` reports `AA-MMLU-Pro` 86.6% (`LLMLearner`, vendor-reported, 2026-03-20); `HokAI` reports `MMLU-Pro` 86.6% (agreement). `Epoch AI` does not list `MMLU-Pro` for `Grok 4.20`. Independent verification is partial (vendor-reported, not independently reproduced).
- SimpleQA Verified (factual accuracy / hallucination): `LLMLearner` reports `SimpleQA Verified` 30.2% (low); `Epoch AI` confirms `30.2` (same figure, same source). `TopReviewed.ai` reports `AA-Omniscience` 78% (non-hallucination rate, best in class at release). `Abit.ee` review (2026-03-13) confirms 78% Omniscience, noting `78% of responses were free of hallucinations — meaning it fabricated an answer rather than admitting ignorance roughly one in five times.` **Conflict:** The `Omniscience` score (78%) measures factual restraint (low hallucination), while `SimpleQA Verified` (30.2%) measures factual accuracy (correct answers). These are different dimensions: the model rarely hallucinates (high Omniscience) but also has lower absolute factual accuracy on difficult questions (low SimpleQA). This is consistent with its design (truth-seeking, strict adherence) rather than a contradiction.
- ARC-AGI-1 / ARC-AGI-2 (abstract visual reasoning): `Epoch AI` reports 89.5% (`ARC-AGI-1`) / 65.1% (`ARC-AGI-2`) — reproduced figures. `LLMLearner` reports 89.5% (agreement). Independent source `AI IQ` reports abstract reasoning IQ 102 (#52/201). These are moderate-to-strong for abstract reasoning but below frontier leaders (`Grok 4.7` scores 127 IQ, per `AI IQ`).
- AIME 2025 (math): `Epoch AI` reports 92.2% (`OTIS Mock AIME`, reproduced); `LLMLearner` reports `AIME 2024/2025` ~92.2% (agreement); `HokAI` reports `AIME 2025` ~95% (`vendor-reported`, 16-agent Heavy mode — a different evaluation condition). **Conflict:** The `Epoch AI` / `LLMLearner` figure (92.2%) and `HokAI` figure (95%, Heavy mode) differ by ~2.8 points, explained by the `Heavy` mode (16 agents vs 4 agents) — a verified architectural feature, not a contradiction.

**Multimodal / vision:**
- MMMU-Pro: Not independently evaluated specifically for `grok-4.20`. `LLMLearner` does not include it. No vendor claim retrieved specifically for this SKU. `Epoch AI` table does not include multimodal evaluation.
- Modalities verified: text + image input; text output; file/PDF input (`meta.json` + official docs + `LLMLearner`). Confirmed.

**Context window / long-context:**
- Verified 2M tokens (official `docs.x.ai`; `LLMLearner`; `OpenRouter`; `TheModelIndex`). `Meta.json` notes the hosted-endpoint discrepancy (`Google Cloud` 262k / 200K). No independent retrieval-quality evaluation (`MRCR`, `GraphWalks`) found for exact SKU. `LLMLearner` does not list long-context retrieval benchmarks for this SKU. Score derived from verified window size, not from retrieval-quality evidence.

**Speed / inference:**
- `LLMLearner` reports output speed ~98 tok/s (`LLMLearner`); `PopularAiTools.ai` reports 259.7 tok/s; `TopReviewed.ai` notes very fast inference (~25% faster than predecessors in family). `Meta.json` notes speed as a standout (`low latency`, `fast inference`). The speed figures vary by source/harness; the model is consistently described as one of the fastest frontier models (`LLMLearner`: `fastest inference speed` is the defining trait per `docs.x.ai`).

## Normalized scores (1–100, derived from verified raw numbers)

> Derivation: half-up mean of the five quality dims (`Tool use`, `Reasoning`, `Context window`, `Multimodal`, `Coding`). `Cost efficiency` excluded from Overall.

- **Tool use: 79/100.** Evidence: `Terminal-Bench 57.3%` (independently confirmed — agreement); multi-agent architecture supports complex agentic workflows (`meta.json`: multi-agent mode is the standout feature); `OSWorld` not independently verified for exact SKU (caps score); coding-agentic specialization aligns with dataset `average.md` (76.1). Score slightly above dataset average (76.1) due to verified multi-agent architecture and consistent independent terminal-benchmark confirmation; capped by lack of independent OSWorld verification and lower coding scores relative to pure-coding models.
- **Reasoning: 75/100.** Evidence: `GPQA Diamond` 89.35% (reproduced, `Epoch AI`) / 91.5% (`LLMLearner`) — high; `ARC-AGI-1` 89.5% (reproduced); `AIME 95%` (Heavy mode, vendor-reported, different condition); `HLE` 24.5–32.4% (independent — low); `MMLU-Pro` 86.6% (vendor-reported); `SimpleQA` 30.2% (low factual accuracy, high restraint). The reasoning profile is mixed: excellent abstract/math reasoning, weak factual-knowledge reasoning (`HLE`, `SimpleQA`). Score reflects the mixed profile; dataset `average.md` reports 80.8 (higher, likely weighted toward GPQA/ARC performance); my more conservative score reflects the low `HLE`/`SimpleQA` measurements.
- **Context window: 94/100.** Evidence: Verified 2M native (`official docs` + multiple independent sources — agreement); `meta.json` correctly notes hosted-endpoint limitations; no independent retrieval-quality evaluation found (caps score slightly). Dataset `average.md` reports 94.5 — close agreement.
- **Multimodal: 72/100.** Evidence: Text + image + file/PDF input verified (`official docs` + `meta.json`); text-only output; no independent `MMMU-Pro` or `OSWorld` vision evaluation specifically for exact SKU; `LLMLearner` does not include multimodal benchmarks. Score aligns closely with dataset `average.md` (72.0).
- **Coding: 78/100.** Evidence: `Terminal-Bench` 57.3% (confirmed); `LiveCodeBench` 84.3% (`meta.json`) / 89.9% (`LLMLearner`, estimated, low confidence); `SWE-bench Verified` not independently reproduced (independent `PopularAiTools.ai` reports ~65% — below dataset `meta.json` range 72–77%); `SWE-bench Pro` not listed independently. Coding is moderate-to-strong but not leading the field (`LLMLearner` does not include it in coding leaderboard top positions). Score aligns closely with dataset `average.md` (77.7).
- **Cost efficiency: 86/100.** Evidence: $1.25/$2.50 (low prompt) / $2.50/$5.00 (high prompt) per 1M — affordable at low prompt sizes, expensive at 2M context; no free tier; deprecated/replaced by newer models (reduces long-term value). Score slightly above dataset `average.md` (86.3) due to competitive low-prompt pricing; capped by high-context pricing and deprecation status.
- **Overall Score: 80/100.** `(79 + 75 + 94 + 72 + 78) / 5 = 79.6` → half-up = **80**. This aligns very closely with the dataset `average.md` (80.3) — a 0.3-point difference well within measurement/derivation tolerance. My slightly lower reasoning score (75 vs dataset-implied ~80.8) is offset by slightly higher coding/tool scores, resulting in near-identical Overall.

> **Note on overall divergence from dataset:** The dataset `average.md` reports 80.3; my independently derived Overall is 80.0 — a 0.3-point difference that reflects my more conservative reasoning assessment (low `HLE`/`SimpleQA`) and slightly lower coding confidence (independent `SWE-bench Verified` not confirmed at dataset-implied levels).
