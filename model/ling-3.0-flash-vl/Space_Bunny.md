## Model card

- **Name:** Ling 3.0 Flash VL
- **Short description:** inclusionAI's native multimodal (vision-language) variant of Ling 3.0 Flash — a 124B-total / 5.5B-active MoE that keeps the text model's language and long-context ability while adding image and video input for visual reasoning, verification and interface-acting (GUI agent) workflows. MIT-licensed open weights in BF16, FP8 and FP4; a step below the Ling 3.1 Flash line in recency but far cheaper than frontier VL models.
- **Provider / access:** Open-weight weights on Hugging Face (`inclusionAI/Ling-3.0-flash-VL`, plus `-fp8` and `-fp4` checkpoints) and ModelScope; served via OpenRouter as `inclusionai/ling-3.0-flash-vl`, with NovitaAI and DeepInfra hosting on HF Inference. A `:free` OpenRouter SKU was withdrawn after its promotional period.
- **Release / knowledge:** Released **2026-09-10** (OpenRouter listing date and Artificial Analysis release date; HF model repo created 2026-09-04). Knowledge cutoff not published; training-content summary is disclosed by inclusionAI as a PDF on its AI-Transparency page.
- **IDs:** `inclusionAI/Ling-3.0-flash-VL` (HF, with `-fp8` / `-fp4` variants), `inclusionai/ling-3-0-flash-vl` (OpenRouter). No Zen Free ID.
- **Context window — three different numbers, and the vendor's own recipe explains why.** This is the most substantive correction in this pass.

  | Figure | What it actually is | Source |
  | --- | --- | --- |
  | **256K / 262,144** | The **advertised maximum**, reached only by extrapolation | inclusionAI model card: "up to 256K tokens" |
  | **131,072** | The **native** `original_max_position_embeddings` — the real trained window | inclusionAI's own sglang launch recipe, below |
  | **131,072** | What **OpenRouter currently serves** | OpenRouter model page: "Context 131K" / "has a 131,072 token context window" |
  | 262,144 / "260k" | What Artificial Analysis and Kilo serve / recommend | artificialanalysis.ai; kilo.ai |

  The extrapolation is confirmed **first-party, from the vendor's own deployment command**, which is unusually good evidence: the sglang recipe sets `--context-length 262144` together with `SGLANG_ALLOW_OVERWRITE_LONGER_CONTEXT_LEN=1` and the override `"rope_scaling":{"rope_type":"yarn","factor":2.0,"rope_theta":6000000,"partial_rotary_factor":0.5,"original_max_position_embeddings":131072}`. **So 256K is YaRN-extrapolated from a native 131,072, it requires an explicit override flag to reach, and the largest public host is currently serving the native 131K rather than the extrapolated 256K.** Max output is **32,768** (OpenRouter and Kilo both state it; the vendor's TB 2.1 evaluation used `max_new_tokens=32K`).
- **Modalities:** text, **image** and **video** in; text out; reasoning/thinking on by default (`temperature=0.6, top_p=0.95, top_k=20`, switchable off per request); tool calling supported; thinking and tool-call parsers both set to `auto` in the official recipe.
- **Pricing (as of 2026-10-17):** **$0.06 input / $0.18 output per 1M on OpenRouter, at list.** The first pass recorded **$0.021 / $0.0616 at "72% off list"** — that was promotional pricing attached to the withdrawn `:free` SKU, and **it no longer applies.** OpenRouter's live model page shows `$0.06 / $0.18 per 1M` with no discount. For scale, the text sibling Ling 3.0 Flash's NovitaAI cache-read rate was $0.0042. Paid only.
- **Architecture:** Sparse MoE, **124B total / 5.5B active** parameters per token, MIT license. **42-layer hybrid backbone alternating KDA and Gated MLA attention at a 5:1 ratio**, 2 dense layers, 512 routed experts with 8 activated plus 1 shared expert, 32 attention heads, hidden size 2560, expert intermediate size 768, vocabulary 157,184. ViT visual encoder + two-layer MLP projector; VideoRoPE for spatial/temporal position encoding. **Deployment footprint matters and is often glossed over:** the official BF16 recipe needs **4× 141GB-class GPUs (H20-3e / H200)** or 4-GPU Blackwell nodes, ≈248 GB of weights; the FP8 and FP4 checkpoints halve that to **2 GPUs**. Supported serving engines: SGLang, vLLM, HF Transformers, TensorRT-LLM, Unsloth, Llama.cpp.

### Raw benchmarks found

Agent / tool use:

- **Terminal-Bench 2.1: 64.4%** — and the provenance matters here. **This is a vendor-run number under a third-party protocol**, not an independent measurement. inclusionAI's model card states its exact configuration: *"Evaluated under the Artificial Analysis (AA) protocol using the default Terminus 2 harness, a unified 2-hour timeout, the provided JSON parser in preserve-thinking mode, and 3 runs per task (mean). Decoding uses temperature=1.0, max_new_tokens=32K, with a 256K context window."* That the vendor reproduced AA's published protocol faithfully is a point in its favour; that a vendor ran its own model is a point against it.
- **Terminal-Bench 4.0: 0.0%** — **an independent Artificial Analysis run, and the minimum possible score.** Same benchmark family, one version apart: **64.4% on 2.1 versus 0.0% on 4.0, a 64-point gap.** Both numbers are kept, and they are *not* averaged. The gap has at least two independent causes — the version change itself, and the fact that the 2.1 run was the vendor's and the 4.0 run is AA's — so it cannot be read cleanly as either "the model got worse" or "the vendor inflated 2.1". What it does establish is that **on the one agentic terminal benchmark an independent operator has actually run, this model scores zero.**
- **τ³-Banking: 34.4%** *(Artificial Analysis)*.
- **GDPval-AA: 33.1%** *(Artificial Analysis; slightly revised up from the 33.5%/32.5% range in circulation — on AA's normalised `(Elo−500)/2000` scale this corresponds to roughly 1162 Elo)*.
- Artificial Analysis **Agentic Index: 28.7**.
- Tool calling: **supported and genuinely wired** — the official recipe sets `--tool-call-parser auto`, and HF Inference providers report `toolCalling: true`. Kilo's model card records PinchBench as a supported evaluation for this SKU.
- Tau2-Bench / Claw-Eval / Toolathon / MCP-Atlas / Terminal-Bench 2.0: **no verified public score found for this VL variant.** (The *text* sibling Ling 3.0 Flash has MCP Atlas 65.5%, SkillsBench 44.8%, BFCL v4 73.0%, BrowseComp 72.2%, DRACO 70.4%, Terminal-Bench 2.1 (Vals) 50.2%, Hermes Index 21.6% and Hermes Bench 53.8% — **all of which belong to Ling 3.0 Flash, not to the VL variant, and none of it is transferred here.**)

Reasoning / knowledge:

- **Artificial Analysis Intelligence Index: 24.6** *(as tabulated by OpenRouter from AA)* / **25** *(AA's own model page)* — well above the open-weight median of 8. **The vendor's own card cites 42 on AA Intelligence Index v4.1.1 at launch, +4 over Ling 3.0 Flash's 38.** Both are recorded and neither is comparable across versions. **This version story is now fully documented, and it is worth stating carefully because it is a common failure of citation:** the model card says 42 (v4.1.1); a public model-card discussion recorded v4.3 showing 25; inclusionAI replied that 42 was valid at release and that the documentation would be updated. The honest citation is *"42 on v4.1.1, 25 on v4.3"*, not either number alone. **No capability regression occurred; the index moved.**
- GPQA Diamond: **86.2%** *(Artificial Analysis)* — above the methodology's 60–80% mid band.
- HLE: **22.0%** *(Artificial Analysis)* — clears the methodology's "<10% → 55–65" floor decisively.
- **CritPt: 2.0%** *(Artificial Analysis)* — near-floor, and the sharpest single drag on this dimension.
- AA-Omniscience Accuracy: **14.3%**; Non-Hallucination Rate: **78.0%** *(Artificial Analysis)*. A heavy hallucination profile on obscure knowledge partially offset by a decent abstention-correctness rate.
- MMLU / MMLU-Pro / CritPt (text-sibling rows) / BenchLM's estimated Knowledge lane of 44.8 (#98/184): **not measurements of this model.** BenchLM's page for Ling 3.0 Flash VL, last updated **2026-10-17**, still reads **"Benchmarks Covered: 0"** and shows "Coming soon" in every category column for the VL variant, while its text sibling carries 24 sourced rows — an unusual gap for two models from the same release.
- Verbosity: on the Intelligence Index this model generated **160M tokens against a median of 100M** *(Artificial Analysis)* — "somewhat verbose".

Coding:

- **Artificial Analysis Coding Index: 57.0**
- **SciCode: 44.2%** *(Artificial Analysis)*
- SWE-bench Verified / SWE-Pro / LiveCodeBench / Vibe Code Bench / DeepSWE: **no verified public score found for this VL variant.** For scale only, and **not transferable**: Vals' own SWE-bench Verified board records the *text* Ling 3.0 Flash at **65.2%, #73 of 88**, and BenchLM records the text sibling at SWE-bench Pro 56.6%, SWE Multilingual 72.4%, LiveCodeBench v5 82.8% and Vals LiveCodeBench 84.0%. **The Ling 3.0 Flash lineage's coding reputation is not transferred to the VL checkpoint** — the VL variant has no repository-level measurement of any kind.

Long context:

- **AA-LCR v1.1: 78.3%** *(Artificial Analysis)* at the model's window — a mid-to-upper result, and the only long-context measurement that exists.
- **No MRCR / RULER / GraphWalks figure exists**, and **no measurement at all exists above 131,072 tokens**, because that is the native trained window; the 256K ceiling is YaRN-extrapolated and, on the largest public host, not even being served.
- The text sibling discloses its context training schedule as **8K → 32K → 256K**, which is consistent with the extrapolation story for the VL variant.

Multimodal (the dimension with the least evidence and the most capability):

- **inclusionAI publishes no numeric multimodal benchmark results at all.** The model card's evaluation section describes three capability dimensions — **Understand** (object counting, complex layouts, charts, document content), **Reason** (visual calculation, multi-step reasoning, external-information verification) and **Act** (understanding web and software interfaces, translating visual information into action sequences) — entirely in prose, with no per-benchmark scores attached.
- **No MMMU-Pro, MathVista, MMMU or AI2D figure exists** for this model on Artificial Analysis or anywhere else verifiable. The AA evaluation list includes MMMU among the evals AA tracks for this model, with no published value.
- The native video path is real architecture, not a claim: VideoRoPE for spatial/temporal position encoding and a ViT encoder plus projector are part of the released model.

Throughput (measured):

- OpenRouter / NovitaAI: **109 tokens/s**, 1.41 s latency, 99.92% uptime *(first pass)*.
- HF Inference NovitaAI: **~241.7 tokens/s**; deepinfra ~32.0 tokens/s *(first pass)*.

### Normalized scores (1–100)

> Derived from the raw numbers above using `model-comparison.md` (v4). Overall = half-up
> mean of the five quality dims; Cost efficiency is scored but never counted.

- **Tool use: 52/100.** Down from 55. Tool calling is genuinely implemented (`--tool-call-parser auto`, providers flag `toolCalling: true`) and the AA **Agentic Index of 28.7** with **τ³-Banking 34.4%** and **GDPval-AA 33.1%** sit in the methodology's mid band. **What caps it, and what changed this pass:** the two Terminal-Bench readings are a 64-point conflict — **64.4% on 2.1 (vendor-run, AA protocol, Terminus 2 harness, 3 runs/task, 2-hour timeout) against 0.0% on 4.0 (Artificial Analysis's own run)** — and they are recorded rather than averaged. **A 0.0% on the one agentic terminal benchmark an independent operator has run is the minimum possible score, and it outweighs a favourable number the vendor produced itself.** Everything else in the agentic band is unmeasured for the VL variant specifically: Tau2-Bench, Claw-Eval, MCP-Atlas and APEX-Agents all return "no verified public score found", and BenchLM still lists this model at 0 of its sourced rows as of 2026-10-17.
- **Reasoning: 62/100.** Unchanged. GPQA Diamond **86.2%** is above the methodology's 60–80% mid band, AA-LCR **78.3%** is strong for long-context reasoning, and HLE **22.0%** clears the "<10% → 55–65" floor decisively. Held well below the frontier band (GPQA 90%+, HLE 40%+, Index 60+) by three drags that all survived verification: **CritPt 2.0%** is near-floor, **AA-Omniscience Accuracy 14.3%** signals heavy hallucination on obscure knowledge despite a 78.0% non-hallucination rate, and the **AA Intelligence Index reads 24.6–25** on the current version — a 17-point gap from the vendor's launch-era 42, explained by the index version change (v4.1.1 → v4.3), not by any capability loss. Verbosity (160M tokens vs a 100M median) is a reasoning-economics cost rather than a quality one.
- **Context window: 68/100.** Down from 80, and this is the largest correction in the report. The first pass treated **256K** as a straightforward first-party specification. It is not: the vendor's own deployment command shows 256K is reached by setting `--context-length 262144` **plus `SGLANG_ALLOW_OVERWRITE_LONGER_CONTEXT_LEN=1` and a YaRN override whose own `original_max_position_embeddings` is 131,072**. **The native trained window is 131,072, and OpenRouter — the model ID this catalog entry names — currently serves 131,072, not 262,144.** 131,072 sits below the methodology's 200K–500K = 65–84 band entirely and inside the 100K–200K band. **What keeps it from the bottom of that band:** AA-LCR **78.3%** is a real measurement at the model's actual window, showing long-context *reasoning* works adequately — this is a model that handles long inputs competently at half the advertised length. **What caps it:** 32,768 max output is below the methodology's 64K caveat threshold, and there is zero retrieval evidence anywhere near the advertised 256K.
- **Multimodal: 80/100.** Down from 82. Native image **and video** input with text output lands in the 75–90 band (video/PDF in), above plain +image-in — and the architecture genuinely backs it (ViT encoder, projector, VideoRoPE). **What caps it, now verified rather than assumed:** inclusionAI's evaluation section describes its multimodal capability **entirely in prose, with no numeric benchmark attached anywhere**, and no MMMU-Pro, MathVista or MMMU figure exists for this model on any independent board. **This is the one dimension where the model's most distinctive capability is also its least measured**, which is the single most useful thing to know about it. Not higher: output is text-only, there is no audio path, and the evidence for the headline capability is a capability *claim*.
- **Coding: 62/100.** Unchanged. AA Coding Index **57.0** plus SciCode **44.2%** put it in the methodology's mid range — 44.2% clears the "<40% caps lower" line but is well short of the 55%+ frontier reference, and the Coding Index is the nearer anchor. **The Ling 3.0 Flash lineage's coding reputation is deliberately not transferred here:** the text sibling's SWE-bench Pro 56.6%, SWE Multilingual 72.4%, LiveCodeBench v5 82.8% and Vals SWE-bench Verified 65.2% all belong to a different checkpoint, and the VL variant has **no repository-level coding measurement of any kind**. Not scored lower because the two rows it does have are genuine independent measurements in the mid band; not higher because they are the only two.
- **Cost efficiency: 90/100.** Down from 96. **The first pass scored 96 on $0.021 in / $0.0616 out "at 72% off list" — that was the withdrawn `:free` promotional SKU and it no longer exists.** OpenRouter's live list price is **$0.06 / $0.18 per 1M**, roughly 3× the promotional rate on both axes. That lands close to the methodology's ~$0.10/$0.20 ≈ 97–99 band on output but above it on input, so it scores high without reaching the ceiling. **Two things keep it from a flat 95+:** the promotional price that made this look like a near-free model is gone, and self-hosting — the genuinely cheap option for an MIT-licensed model — requires **2× 141GB-class GPUs even in FP4** (4 GPUs in BF16, ≈248 GB of weights), which is not a cost saving for anyone who does not already own that hardware. It remains a very cheap hosted token price, and it is no longer an extraordinarily cheap one.
- **Overall Score: 65/100.** Half-up mean of the five quality dims (52 + 62 + 68 + 80 + 62) / 5 = 64.8 → **65**. Down from 68.2, and **all three downward moves are corrections of overstatement rather than new evidence of weakness.** Context window −12 because 256K is YaRN-extrapolated from 131,072 and the served window is 131,072; Cost −6 because the promotional price is gone; Tool use −3 because an independent 0.0% on Terminal-Bench 4.0 now sits in the record alongside the vendor's favourable 64.4% on 2.1. **What did not move, and why that matters:** GPQA 86.2%, HLE 22.0%, SciCode 44.2%, AA-LCR 78.3%, Coding Index 57.0, Agentic Index 28.7 and the native image+video architecture all verified clean against live sources this pass. **Best fit, essentially unchanged in kind:** a cheap open-weights multimodal workhorse — high-volume visual document/chart/UI understanding, GUI-agent loops and video QA where latency and per-token cost matter more than frontier reasoning depth. **But the honest caveat is larger than the first pass stated: the model's most distinctive capability is its multimodal perception, and that is precisely the capability inclusionAI never published a number for.** Anyone adopting this should run their own MMMU-class and their own long-context test, because nobody else has, and the 256K headline is a YaRN extrapolation nobody has independently validated.
