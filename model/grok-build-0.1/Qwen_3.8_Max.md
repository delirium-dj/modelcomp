> **Verdict:** Grok Build 0.1 is **xAI's (now branded SpaceXAI) fast agentic-coding model** — launched on the xAI API in **public beta 2026-05-29** and measured by Artificial Analysis in its **"0616" (June 16, 2026) revision**. It is **"the same model that powers Grok Build"** (xAI's terminal coding agent), **"specifically trained for agentic coding tasks, including web development, debugging, and MCP support,"** and pitched as **"our fastest coding model … also a speedy, economical option for general-purpose agentic and tool-calling use cases."** It is a **reasoning** model with a **256K context**, **text + image → text** I/O, priced aggressively at **$1/$2 per 1M** (AA: *both* "very competitive" vs the $2.00/$10.00 medians; **80 % cache discount**; blended **$0.54**), served via the **Responses API** and best in agentic harnesses (Grok Build, Cursor, Hermes Agent, OpenClaw, Kilo Code, OpenCode; also OpenRouter + Vercel AI Gateway). **Verification is thin:** the model is **deprecated** ("SpaceXAI has launched a newer release, Grok 4.5"), so AA has **delisted its Intelligence Index (N/A on v5.0)** and every capability eval reads "No publicly available API" — AA now confirms **only efficiency: 93.7 tok/s (#76/196), TTFT 1.23 s (very competitive)**. The only capability numbers are **meta-cited historical AA-0616 values I cannot re-verify on the delisted page — Terminal-Bench 2.1 ≈ 52.06 % and GPQA ≈ 89.5 %** — and xAI's own launch post publishes **no benchmarks at all**. **Reattribution guard:** the **70.8 % SWE-bench Verified** in circulation is inherited from the **retired grok-code-fast-1** and was **never measured for this model** — I do **not** credit it. Net: **Overall 76 (divergence +3.6 vs the curated 72.4)** — a genuinely fast, cheap, image-capable dedicated agentic coder whose real (AA-verified) strengths are speed/cost/MCP-tool pedigree, held back by deprecation, a delisted Index and single-source unverifiable capability numbers.

### Normalized scores (1–100)

- **Tool use: 76/100.** A **dedicated agentic tool-use model** — xAI-confirmed **"MCP support,"** "optimized for interactive coding agents, tool use, and multi-step development," powering the **Grok Build** terminal agent and working across Cursor/OpenCode/Kilo/Hermes/OpenClaw. The one agentic benchmark (**Terminal-Bench 2.1 ≈ 52.06 %**) is **moderate** and **single-source/unverifiable** (delisted AA-0616), and there is **no AA AutomationBench/GDPval** — so the strong MCP/agentic *pedigree* is credited, but the *measured* tool-use evidence is thin and mid-pack.
- **Reasoning: 75/100.** It **is** a reasoning model (AA: extended thinking / chain-of-thought). The meta-cited **GPQA ≈ 89.5 %** would be a **strong** graduate-level reasoning result *if accurate* — but it is **single-source and unverifiable** on the delisted AA page, the **AA Intelligence Index is N/A (delisted on v5.0)**, and this is a **fast coding beta, not a reasoning flagship**. I give partial credit for reasoning capability without treating the unconfirmed GPQA as frontier-level.
- **Context window: 78/100.** **256K** native (AA spec table; 230,400 max output) — the standard 256K tier, ample for agentic coding loops, though short of the 1M–2M frontier (Grok 4.1 Fast has 2M) and with **no independent RULER/MRCR long-context figure**. (AA's FAQ "260k" vs spec-table "256k" flagged.)
- **Multimodal: 78/100.** **Text + image input → text output** (AA-confirmed: can analyze/describe/answer questions about images — useful for screenshot-driven UI/debugging work). The verified **image-only** tier: **no video, no audio, text-only output.**
- **Coding: 74/100.** Its stated purpose ("**our fastest coding model** … specifically trained for agentic coding"), but the **measured coding evidence is thin**: only a **moderate, single-source Terminal-Bench 2.1 ≈ 52.06 %**, **no valid SWE-bench of its own** (the circulating **70.8 % belongs to grok-code-fast-1** and is *not* credited), **no LiveCodeBench/FrontierCode**, and xAI published **no coding numbers**. A dedicated coder with a real harness pedigree but weak independent verification, deprecated and superseded by Grok 4.5/4.7.
- **Cost efficiency: 86/100.** *(Not counted in Overall.)* Excellent — **$1/$2** (AA: *both* "very competitive," well under the $2.00/$10.00 medians), **blended $0.54**, **80 % cache discount**, **fast (93.7 tok/s)** and an **ultra-low TTFT (1.23 s)** — a genuinely economical agentic-coding option. Tempered only by **deprecation**, the **2× past-200K** surcharge and **no free tier** (`noFreeId`).
- **Overall Score: 76/100.** Half-up mean of the five quality dims: (76 + 75 + 78 + 78 + 74) / 5 = 381 / 5 = **76.2 → 76**. **Divergence +3.6** vs the curated 72.4. Grok Build 0.1 is a **fast, cheap, image-capable dedicated agentic coder** (MCP support, powers Grok Build, $1/$2, 93.7 tok/s, TTFT 1.23 s, 256K) whose weaknesses are that it is **deprecated/delisted** (AA Index N/A), its **only capability numbers are single-source historical AA-0616 values I cannot re-verify** (Terminal-Bench ≈ 52 %, GPQA ≈ 89.5 %), it has **no valid SWE-bench of its own** (the 70.8 % is grok-code-fast-1's), and it is **superseded by Grok 4.5/4.7**. My **+3.6** above the curator reflects that I credit the **AA-verified speed/cost/TTFT**, the **real MCP/agentic-tool pedigree**, **image multimodality** and **256K context** somewhat more than the curated 72.4 does, while still holding it **below the verified frontier coders** because its capability evidence is thin, moderate and largely unverifiable.
