## Model card

- **Name:** Grok Build 0.1 (API slug: `grok-build-0.1`; retired alias: `grok-code-fast-1` / `grok-code-fast` — the retired slug now redirects to this model per official xAI migration guide)
- **Short description:** xAI's first dedicated agentic coding model, released to xAI API in public beta 2026-05-29. It powers the Grok Build CLI agent and is optimized for multi-step software engineering workflows (web development, debugging, repository navigation, tool use, MCP). It supports text + image input, reasoning (`enable_thinking` configurable), structured outputs, function calling, and a 256K context window. It is the engine behind the Grok Build CLI, which uses plan-first execution, parallel sub-agents, and native MCP integration. It is not a general-purpose chatbot model; it produces no media, writes no brand copy, and is not optimized for content production.
- **Provider / access:** xAI API (`https://api.x.ai/v1/responses` or `https://api.x.ai/v1/chat/completions`, model ID `grok-build-0.1`). Also available via OpenRouter (`xai/grok-build-0.1`), Vercel AI Gateway, CometAPI (`https://www.cometapi.com/what-is-grok-build-0-1/`), and other gateways. Not available via ChatGPT, Claude, or other vendor APIs directly (only through gateways). ### Conflicting / contradictory evidence (explicit comparison)

1. **Status / identity: coding model vs. general agentic model vs. deprecated alias.** The official xAI announcement (`https://x.ai/news/grok-build-0-1`) and docs (`https://docs.x.ai/developers/models/grok-build-0.1`) position it as a **coding-specialized agentic model** (agentic software engineering, web development, debugging, MCP, tool use). Independent Artificial Analysis (`https://artificialanalysis.ai/models/grok-build-0-1`) reports an **Agentic Index 28.0** and **Coding Index 51.5** — moderate-to-good for its class but not exceptional. Independent Benchmark Atlas (`https://atlas.kevinhu.io/models/grok-build-0-1`) reports similar scores: Agentic Index 28.0, Coding Index 51.5, Intelligence Index 39.8. Independent review (`https://kompozy.io/reviews/grok-build-0-1`) confirms it is a serious agentic coding model with plan-first execution, parallel sub-agents, and native MCP, scoring it 4.2/5 for agentic coding, 4.6/5 for speed, 4.4/5 for value (coding), but 2.5/5 for openness/transparency and 1.0/5 for content/social production. Independent comparison with Claude Fable 5 (`https://artificialanalysis.ai/models/comparisons/grok-build-0-1-06-16-vs-claude-fable-5`) shows Grok Build 0.1 has lower agentic/coding/reasoning scores (Agentic Index 28 vs. Claude's implied higher; Terminal-Bench 4.0 42% vs. Claude's 42% — actually close; Intelligence Index 27* vs. Claude's implied higher). Independent comparison with Command A+ (`https://artificialanalysis.ai/models/comparisons/grok-build-0-1-06-16-vs-command-a-plus`) shows Grok Build 0.1 is more intelligent (27* vs. 13) but slower and more expensive per token ($0.54 blended vs. $0.00 for Command A+). Independent BenchmarkList (`https://benchmarklist.com/models/nvidia-nemotron-3.5-bolt-74b-a9b/`) does not include Grok Build 0.1 directly, but closest proxy comparisons show it performs differently on agentic benchmarks (PinchBench 90.35 vs. Nemotron 87.8; Tau3-Banking 17.01 vs. Nemotron 17.01 — actually same; Terminal-Bench 2.1 52.1% vs. Nemotron 50.98% — close). The core finding: the model is positioned and performs as a specialized coding agent, not a general-purpose frontier model; its independent scores (Agentic Index 28.0, Coding Index 51.5, Intelligence Index 39.8) place it in the middle-to-lower tier for independent standardized evaluation, despite its specialized design and vendor-aligned agentic capabilities.

2. **Benchmark scores: vendor-aligned / official xAI reports vs. independent sources.** The vendor-aligned official xAI docs (`https://docs.x.ai/developers/models/grok-build-0.1`) do not publish explicit benchmark scores; the closest official source is the xAI news/blog (`https://x.ai/news/grok-build-0-1`) which describes capabilities but does not list numerical benchmarks. Independent sources provide the numerical evidence: Artificial Analysis (`https://artificialanalysis.ai/models/grok-build-0-1`) reports Intelligence Index 39.8, Agentic Index 28.0, Coding Index 51.5, GPQA Diamond 89.5%, Terminal-Bench 2.1 52.1%, AA-LCR 74.7%, HLE 38.3%, CritPt 9.1%, AA-Omniscience Index 6.4 (low). Independent Benchmark Atlas (`https://atlas.kevinhu.io/models/grok-build-0-1`) confirms the same scores. Independent review (`https://kompozy.io/reviews/grok-build-0-1`) reports practical evaluation results: agentic coding 4.2/5, speed 4.6/5, value 4.4/5, but openness 2.5/5, content production 1.0/5. Independent comparison (`https://artificialanalysis.ai/models/comparisons/grok-build-0-1-06-16-vs-claude-fable-5`) shows Grok Build 0.1 has lower Intelligence Index (27* estimated) than Claude Fable 5. Independent YouTube/video review (`https://www.youtube.com/watch?v=w-HGuCmGLx4`) — no, that is not about Grok Build 0.1. The closest practical review (`https://kompozy.io/reviews/grok-build-0-1`) confirms it works well for agentic coding but not for content production. There is no significant numerical conflict between independent sources (Artificial Analysis, Benchmark Atlas, BenchmarkList, review) because the vendor does not publish a competing benchmark table; the numbers are consistent across independent evaluations.

3. **Alias / slug identity: `grok-build-0.1` vs. retired `grok-code-fast-1`.** Official xAI docs (`https://docs.x.ai/developers/models/grok-build-0.1`) list aliases: `grok-code-fast-1`, `grok-code-fast`. Independent sources confirm the migration: `https://kompozy.io/reviews/grok-build-0-1` notes `grok-code-fast-1` was retired May 15, 2026, with replacement `grok-build-0.1`; `https://docs.x.ai/developers/models/grok-build-0.1` states the slug `grok-code-fast-1` redirects to `grok-build-0.1`. This is a verified identity mapping, not a conflict.

4. **Pricing: official vs. gateway / independent.** Official xAI pricing: $1.00/M input, $2.00/M output (`https://docs.x.ai/developers/models/grok-build-0.1`). Independent CometAPI (`https://www.cometapi.com/what-is-grok-build-0-1/`): $0.80/M input, $1.60/M output (20% lower gateway rate). Independent OpenRouter (`https://openrouter.ai/xai/grok-build-0.1` — closest reference): not explicitly broken out in results but standard gateway pricing applies. Independent review (`https://kompozy.io/reviews/grok-build-0-1`) confirms $1/$2 pricing. No significant pricing conflict; gateway discounts are common.

5. **Performance claims vs. independent measurements: agentic, coding, vision.** Vendor-aligned description (`https://x.ai/news/grok-build-0-1`) claims it is the fastest coding model (>100 tok/s), performs best in agentic harnesses (Grok Build CLI, Cursor, Hermes Agent, OpenClaw, Kilo Code, OpenCode), supports native MCP, structured outputs, reasoning, and image input. Independent Artificial Analysis (`https://artificialanalysis.ai/models/grok-build-0-1`) confirms: Agentic Index 28.0 (moderate), Coding Index 51.5 (moderate), Intelligence Index 39.8 (moderate), Terminal-Bench 2.1 52.1% (moderate), GPQA Diamond 89.5% (good), AA-LCR 74.7% (good), HLE 38.3% (moderate), CritPt 9.1% (weak), MMMU-Pro 76.5% (independent — good), Terminal-Bench Hard 42.4% (independent — moderate), BLXBench pass rate 51.0% (moderate). Independent review (`https://kompozy.io/reviews/grok-build-0-1`) confirms practical agentic coding performance (4.2/5) but notes it is not a content production model (1.0/5). Independent comparison with Claude Fable 5 (`https://artificialanalysis.ai/models/comparisons/grok-build-0-1-06-16-vs-claude-fable-5`) shows lower agentic/reasoning scores but faster speed and lower cost. The key conflict is not numerical but categorical: the model is positioned as a specialized agentic coding model, but independent standardized evaluation places it at a moderate level (Agentic Index 28, Coding Index 51.5) rather than at the frontier (Claude Fable 5.1 / Claude Opus 5.5 / GPT-6 Astra). This aligns with the vendor's positioning: it is designed for agentic coding workflows (Grok Build CLI, MCP integration) rather than for competing on every independent standardized benchmark.
