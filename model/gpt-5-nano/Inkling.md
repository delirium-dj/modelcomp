## Model card

- **Name:** GPT-5 Nano (`gpt-5-nano`) — official OpenAI SKU; dataset label `gpt-5-nano` matches the smallest/fastest GPT-5 variant.
- **Short description:** OpenAI's smallest and fastest GPT-5 variant (released 2025-08-07). Designed for summarization, classification, rapid interaction, and ultra-low-latency developer-tool use. 400K context window; text + image input; text output; reasoning effort `minimal`/`low`/`medium`/`high`; tool-calling and structured-output support. Not intended for frontier-level complex reasoning (significantly lower HLE/Agentic scores vs larger GPT-5 variants) but very cost-efficient ($0.05/$0.40 per 1M) and very fast (~140 tok/s).
- **Provider / access:** OpenAI (`gpt-5-nano`) — available historically via Chat Completions and Responses APIs (official docs confirm both endpoints supported; `Status: Deprecated` as of 2026-10-29). Not open-weights (proprietary; weights: API only; `open_weights = no` per comparison sources).
- **Release / knowledge:** Released 2025-08-07 (`openai.com/index/introducing-gpt-5-for-developers/`, official API docs, AI/TLDR, Benched.ai, TheModelBeat, OpenRouter — full agreement). Knowledge cutoff: May 30, 2024 (official docs state May 31, 2024; Artificial Analysis and Benched.ai confirm May 30, 2024 — near-agreement within 1 day).
- **IDs:** `openai/gpt-5-nano` (OpenAI API model ID); `gpt-5-nano` (dataset slug / OpenRouter / Puter). No separate Free tier (not a free model — priced at $0.05/$0.40, though very cheap relative to frontier models).
- **Context window:** 400,000 tokens total (official docs, AI/TLDR, OpenRouter, Benched.ai, TheModelBeat, Puter — full agreement); maximum input 272,000 tokens; maximum output 128,000 tokens (official docs confirm both). Note: Puter developer card (`developer.puter.com/ai/openai/gpt-5-nano/`) incorrectly lists 128K context / 128K max output — a discrepancy with official docs; official 400K/272K/128K is authoritative. Confirmed very large context for a budget model.
- **Modalities:** Input: text + image (official docs confirm both; comparison cards confirm `input: text, image`; output: `text`). Output: text only (no audio/video/image generation). Reasoning: yes (`reasoning_effort` supports `minimal`, `low`, `medium`, `high` — official docs; note `Status: Deprecated` and lower reasoning scores at `high` vs larger variants). Tool calling: yes (`function_calling` supported per official docs; `structured_outputs` supported). Structured outputs / JSON mode: yes.
- **Pricing (historical, as of dataset date):** Input $0.05 / 1M tokens; Cached input $0.005 / 1M; Cache writes not explicitly listed for Nano in fetched docs but standard OpenAI caching applies; Output $0.40 / 1M tokens (official docs, AI/TLDR, OpenRouter, Puter — full agreement). Very cost-efficient for simple/high-volume tasks but output price ($0.40) is 8x input ($0.05), consistent with reasoning-model pricing structure.
- **Architecture:** Proprietary (OpenAI — no parameter count, architecture type, or weights disclosed; comparison sources confirm proprietary license, weights not available). Part of GPT-5 family; smaller/dense variant optimized for speed/low latency rather than maximum capability.
