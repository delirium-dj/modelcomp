## Model card

- **Name:** GPT-5.2. OpenAI's current documentation labels it the **"previous flagship model for professional work with configurable reasoning effort"** and explicitly **recommends using GPT-6 Astra instead** — so this is a vendor-deprecated entry, still served but no longer recommended. No free API tier (ChatGPT free users get limited access). Variant/alias flag: the GPT-5.2 family has **three variants** — **Instant** (throughput-optimised), **Thinking** (the configurable-reasoning workhorse, which is what the `gpt-5.2` API ID corresponds to) and **Pro** (`gpt-5.2-pro`, maximum compute). Several of the strongest launch figures belong to **Pro**, not to this ID, and are labelled as such below.
- **Short description:** Released **2025-12-11** as OpenAI's most ambitious release since GPT-4, launched amid the Gemini 3 Pro rivalry that reportedly triggered an internal "Code Red". Its defining features were a **400,000-token context window (3x GPT-5's 128K)**, a **128,000-token maximum output** (where previous models capped at 32–64K), three compute-tier variants, and the first crossing of the **90% threshold on ARC-AGI-1**. OpenAI has **never published a GPT-5.2 technical report**.
- **Provider / access:** OpenAI API, ChatGPT and **Azure OpenAI**. Supported on **both Chat Completions and Responses**, plus Batch. Not supported: Realtime, Live, Assistants, fine-tuning, embeddings, image/video/speech generation, moderation, legacy completions. Supported features: streaming, structured outputs, function calling, file search, **file uploads**, image input, web search, prompt caching. Responses-API tools: function calling, web search, file search, image generation, code interpreter, **hosted shell, apply patch, skills, MCP** — note that **`computer_use` and `tool_search` are absent**, both of which GPT-5.5 and later models support. GPT-5.2 Thinking also supports a **Responses/compact endpoint that intelligently compresses prior context rather than truncating it** when a task exceeds the window. ChatGPT tiers: Free (limited), Plus $20/month, **Pro $200/month** (full Pro-variant access), Business $25/user.
- **Release / knowledge:** Released 2025-12-11. **Knowledge cutoff 2025-08-31** — the oldest cutoff of any OpenAI model in this dataset.
- **IDs:** `gpt-5.2`, with a **dated default snapshot `gpt-5.2-2025-12-11`** — pinnable for reproducibility, unlike GPT-5.6 Sol/Terra and GPT-6 Astra. Sibling IDs referenced in launch material: `gpt-5.2-thinking`, `gpt-5.2-pro`. No free-tier ID.
- **Context window:** **400,000 tokens input / 128,000 tokens max output.** Practically assessed at **~350K usable** once system prompts, output buffer and reliability degradation at the edge of context are accounted for. For comparison in its own generation: Gemini 3 Pro 1M/65K (~900K usable), Claude 4.5 Sonnet 200K/64K (~180K usable), GPT-5 128K/32K. **Pricing is flat across the whole window** — there is no long-context repricing cliff, which distinguishes it from every 1M-context OpenAI model in this dataset.
- **Modalities:** Input: **text and image only**. Output: text only. No audio or video in either direction; image generation exists only as a hosted Responses-API tool. Reasoning: yes, with reasoning-token support and five effort levels — **`none` (the default), `low`, `medium`, `high`, `xhigh`**. The `none` default is commercially significant: you do not pay for thinking tokens unless you ask for them. In ChatGPT the equivalent control was exposed as a Light/Medium/Heavy "thinking time" toggle. Tool calls: yes (surface above, minus computer use). JSON mode / structured outputs: yes.
- **Pricing (as of 2026-10-03):** **$1.75 / 1M input, $0.175 / 1M cached input (a 90% discount), $14.00 / 1M output.** Batch API at 50% off both meters: **$0.875 / $7.00**. **No documented long-context surcharge and no data-residency uplift.** Worked cost examples from the launch analysis: code review of a single file ~$0.01; 10-page document summary ~$0.02; **full codebase analysis (200K in, 5K out) ~$0.42**; legal contract review (150K in, 10K out) ~$0.40. Intra-family comparison from OpenAI's own table: GPT-5.4 $2.50 / $0.25 / $15; GPT-5 Mini $0.25 / $0.025 / $2. Versus GPT-5 ($2.50/$10) this was **a price cut on input and a price rise on output**, so input-heavy analysis got cheaper and output-heavy generation got dearer.
- **Rate limits:** Tier 1 begins at 500 RPM / 500K TPM, rising to 15,000 RPM / 40M TPM at Tier 5. **No separate long-context schedule** (unlike GPT-5.5).
- **Architecture:** Proprietary, closed weights, **no technical report published**. Parameter count and topology not disclosed. Inferred from observable behaviour in the launch analysis: the latency gains look like infrastructure rather than architecture — **specialised tensor cores for transformer operations, dynamic routing matching requests to optimal hardware, and improved parallelism across inference clusters** — while the Light/Medium/Heavy toggle implies variable compute allocation in the style of o3-preview's chain-of-thought scaling.

### Raw benchmarks found

> All figures are **OpenAI-reported launch results** unless stated otherwise. **Variant attribution matters here and is marked on every row**: figures labelled **(Pro)** belong to `gpt-5.2-pro`, a higher-compute variant that is a separate model ID, and were *not* used to score this entry's capabilities beyond what the base/Thinking tier demonstrates.

Agent / tool use:

- Terminal-Bench (any version): **no verified public score found**
- Tau3-Banking / Tau2-Bench: **no numeric score found.** OpenAI described "improvements on τ2-bench (customer support tasks with multi-turn tool use)" and on general structured-output reliability **without publishing figures**.
- GDPval: **70.9% win-or-tie rate against human professionals across 44 occupations (Thinking)**, up from GPT-5's 38.8% — a 32.1-point jump, and the largest single improvement in the release. This is a win-rate, **not** the Elo scale the methodology's ~1750+ reference uses.
- Claw-Eval / ClawProBench: no verified public score found
- Toolathon / MCP-Atlas / SWE Atlas Codebase QnA: no verified public score found
- OSWorld / AutomationBench: **no verified public score found**, and `computer_use` is not a supported tool on this model.
- **ScreenSpot-Pro: named as a capability** ("identifies UI elements in professional software screenshots") **with no score published**.

Reasoning / knowledge:

- **GPQA Diamond: 93.2% (Pro)** (GPT-5 ~85%, Claude 4.5 Sonnet 78.4%) — above the methodology's 90%+ frontier reference, but a Pro-variant figure.
- HLE: **no verified public score found**
- LCR / MLCR / MRCR: **no verified public score found**
- CritPt: no verified public score found
- Artificial Analysis Intelligence Index: **no verified index value found.** A third-party composite reports only **15 of 645 tracked benchmark slots have displayable evidence** for this model.
- Omniscience Accuracy / Hallucination Rate: no verified public score found
- **ARC-AGI-1 (Verified): 90%+ (Pro)** — the first model past that threshold (o3-preview 87%, GPT-5 ~75%). Cost footnote worth recording: GPT-5.2 **reached o3-preview's 87% at 390x lower cost**, which is the clearest efficiency datapoint in the release.
- **ARC-AGI-2 (Verified): 52.9% (Thinking)**, 54.2% (Pro) — for context, Gemini 3 Pro scored 31.1% base and 45.1% with Deep Think, and Claude Opus 4.5 37.6%, so **the Thinking tier beat every competitor of its generation on this benchmark**.
- **FrontierMath (Tiers 1–3): 40.3% (Pro)** (GPT-5 26.3%) — a 53% relative improvement.

Coding:

- **SWE-bench Verified: 80.0%** (GPT-5 76.3%, Claude 4.5 Sonnet 76.5%) — **leads its generation**, resolving roughly 4 of 5 real GitHub issues with full repository context. **SWE-bench Pro (public): 55.6%** (GPT-5 50.8%).
- LiveCodeBench: no verified public score found
- SciCode / AA-SciCode: no verified public score found
- Vibe Code Bench: no verified public score found
- DeepSWE / Coding Index: no verified public score found
- Partner-reported (vendor-selected, not independent): integrations with **Windsurf, Warp, JetBrains, Augment Code, Cline and Cognition** reported that **the expanded context window was the bigger practical gain than the benchmark delta** — previously failing patches now succeed because the model can see the full codebase.

Vision / multimodal:

- **CharXiv Reasoning: named as a capability** (interpreting charts from scientific papers, reading values and connecting them to paper content) **with no score published**.
- **ScreenSpot-Pro: named, no score published** (see above).
- No MMMU, document-understanding or any other quantified vision result was found.

Latency (OpenAI-reported, with partner corroboration):

- **Time to first token on complex extraction: 46s → 12s (74% faster)**; response time on analytical queries **19s → 7s (63% faster)**; **overall latency −18%** versus GPT-5. **Box independently corroborated the 46s → 12s figure**, stating it enabled real-time document intelligence that previously required background processing. **Harvey** reported the 400K window allows analysis of complete case files — contracts, exhibits and correspondence — without chunking, reducing hallucination from missing context.

### Normalized scores (1–100)

- **Tool use: 68/100.** This is the weakest-evidenced dimension of any model scored in this pass. **Not one of the methodology's six tool-use references has a published number**: no Terminal-Bench figure at any version, no Tau3-Banking, no GDPval Elo, no Claw-Eval, no OSWorld/AutomationBench, no MCP-Atlas or Toolathon. OpenAI asserted τ2-bench improvements and better structured-output reliability **without publishing a single score**, and ScreenSpot-Pro is named as a capability with no figure attached. Two structural limitations compound it: **`computer_use` and `tool_search` are not supported on this model**, both of which its successors added, so screen-driven agency is not available at all. What holds it at the top of the mid band rather than lower is real: **GDPval at a 70.9% win-or-tie rate against human professionals across 44 occupations, up 32.1 points from GPT-5**, a credible hosted-tool surface (hosted shell, apply patch, skills, code interpreter, MCP), and the 400K flat-rated window that makes multi-step agent context cheap to carry.
- **Reasoning: 87/100.** The strongest dimension, and unusually the headline result belongs to this ID rather than to Pro: **ARC-AGI-2 at 52.9% for the Thinking tier beat every competitor of its generation** — Gemini 3 Pro managed 31.1% base and 45.1% only with its subscription-gated Deep Think mode, and Claude Opus 4.5 37.6% — on a benchmark specifically designed to resist memorisation. The family's **ARC-AGI-1 90%+ was a first**, and **reaching o3-preview's 87% at 390x lower cost** is a genuine economic breakthrough in reasoning. **GPQA Diamond 93.2% clears the 90%+ reference** and **FrontierMath Tiers 1–3 40.3%** is a 53% relative gain, though both are Pro figures. Capped at 87 because the evidence base is narrow and dated: **HLE, MRCR/LCR, CritPt and any Intelligence Index value are all absent**, there is **no hallucination measurement at all**, the knowledge cutoff is 2025-08-31, and OpenAI never published a technical report to substantiate any of it.
- **Context window: 82/100.** **400,000 input tokens places it in the methodology's 200K–500K tier (65–84)**, and it earns near the top of that band on three concrete merits rather than on size alone: a **128,000-token output ceiling** that was 2–4x its generation's norm and enabled single-call book-chapter generation; a **Responses/compact endpoint that compresses prior context rather than truncating it** when tasks exceed the window — a capability no other model in this dataset documents; and **flat pricing across the entire window with no repricing cliff and no separate long-context rate limit**, which is strictly better commercial behaviour than every 1M-context OpenAI model here. Two points below the band ceiling because **no MRCR, RULER or retrieval benchmark exists**, and the launch analysis itself concedes only **~350K is practically usable** once output buffer and edge-of-context reliability degradation are accounted for.
- **Multimodal: 66/100.** Input is **text and images only** with text-only output and no audio or video path, placing it in the methodology's "+image in = 60–70" band. It sits mid-band rather than at the ceiling because the vision evidence is **named but entirely unquantified** — OpenAI described CharXiv Reasoning and ScreenSpot-Pro capabilities without publishing a score for either, and no MMMU or document-understanding figure exists anywhere. Documented `file_uploads` and `file_search` support plus a hosted image-generation tool are real document-pipeline capabilities, and partner evidence (Harvey analysing complete case files with exhibits) suggests the practical vision path works — but suggestion is not measurement, and **the absence of `computer_use` means the screen-understanding capability it advertises cannot be driven agentically**.
- **Coding: 85/100.** **SWE-bench Verified at 80.0% is the strongest verified-harness coding result of its generation** — ahead of GPT-5 (76.3%), Claude 4.5 Sonnet (76.5%) and Gemini 3 Pro (76.2%) — and means roughly four of five real GitHub issues resolved with full repository context. **SWE-bench Pro at 55.6%** is a 4.8-point gain over GPT-5. The partner evidence is unusually specific and points at the right cause: six independent developer-tool vendors reported that **the context window, not the benchmark delta, was the bigger practical gain**, with previously failing patches now succeeding. Deductions: **no Terminal-Bench figure at any version**, so the methodology's 85%+ agentic-coding reference cannot be checked; **DeepSWE, LiveCodeBench, SciCode and Vibe Code Bench are all absent**; and the single strong number is a vendor-reported 2025 figure with no independent replication found.
- **Cost efficiency: 68/100.** Genuinely good value, and better than its own successors on structure. **$1.75 input is well below the $3/$15 anchor** and **$14 output is marginally below it**, with a **90% cached-input discount at $0.175** and **Batch at 50% off both meters ($0.875 / $7.00)**. Four structural advantages the 1M-context OpenAI models lack: **no long-context repricing cliff** — the full 400K window bills flat; **no separate long-context rate limit**; **no data-residency uplift**; and **`none` as the default reasoning effort**, so thinking tokens are opt-in rather than unavoidable. The documented efficiency claim is striking — **o3-preview's 87% ARC-AGI-1 score at 390x lower cost** — and worked examples are concrete (full 200K-token codebase analysis for ~$0.42). Deductions: **output at $14 is 40% dearer than GPT-5's $10**, so output-heavy generation got more expensive, not less; there is **no free API tier**; and the strategic position is poor — **OpenAI itself tells you to move to GPT-6 Astra**, while GPT-5.6 Terra at $2/$12 offers a 1.05M window and higher measured intelligence for a comparable price.
- **Overall Score: 77.6/100.** Mean of the five non-cost dimensions (68 + 87 + 82 + 66 + 85) / 5 = 77.6 — a strong 2025 reasoner and coder whose agentic and multimodal evidence never materialised. Its remaining best fits are specific and real: **full-repository code analysis and refactoring** (SWE-bench Verified 80.0%, leading its generation, plus six developer-tool vendors attributing the gain to the 400K window), **long-document professional work** (GDPval 70.9% win-or-tie against professionals; Harvey analysing complete case files without chunking), **abstract reasoning at low cost** (ARC-AGI-2 52.9% beating every contemporary, and ARC-AGI-1 parity with o3-preview at 390x lower cost), and **input-heavy analysis pipelines** where $1.75 input, a 90% cache discount, a flat-rated 400K window and `none`-by-default reasoning make the economics unusually clean. Do not choose it for agentic or computer-use work — **`computer_use` and `tool_search` are not supported and not one tool-use benchmark was ever published** — nor for multimodal pipelines (two vision benchmarks named, zero scored), nor for contexts beyond ~350K, nor for output-heavy generation where $14/1M is dearer than its own predecessor. And treat it as end-of-life: OpenAI labels it the previous flagship and points to GPT-6 Astra, the knowledge cutoff is August 2025, and no technical report was ever published.
