## Model card

- **Name:** Muse Spark 1.3 with max reasoning
- **Short description:** Meta's then-flagship proprietary agentic model, September 2026, tuned for long-horizon agentic workflows and competitive coding, with particular strength in million-token retrieval. **As of 2026-10-17 this model is no longer Meta's frontier SKU:** Meta shipped **Muse Wonder** (2026-10-12) at AA Intelligence Index **52** and **Muse Wonder Full** at **56**, above this model's **48**, and released **Muse Spark Open** (2026-10-15) as open weights. **Important variant note: "Max" is a reasoning-effort level on the `muse-spark-1.3` model, not a separate checkpoint or a separately priced SKU.** Meta's documentation lists `max` as a requestable reasoning level on the Standard-tier `muse-spark-1.3` endpoint at the same per-token rate as every other effort level. It was **gated at launch** pending additional safety testing — Meta shipped the headline benchmark numbers on `max` while the tier developers could actually call was `xhigh`, and Artificial Analysis initially had no API provider listed for `max` at all.
- **Provider / access:** **Meta Model API** (`muse-spark-1.3`) and **Muse Code** (macOS and Linux installers). Also surfaced as `meta/muse-spark-1.3` on Google Cloud's Gemini Enterprise Agent Platform at **Preview** stage. Artificial Analysis measures it through the Meta provider at 1.05M context, median 138 output tok/s, 53.92 s to first answer token, 71.99 s total response, 14.46 s reasoning time.
- **Release / knowledge:** **2026-09-02** (Meta AI Research announcement and Artificial Analysis launch article, same day). Vals AI and AIEvals record the release as 2026-09-05 — a harness-side date. Knowledge cutoff not published.
- **IDs:** `muse-spark-1.3` on the Meta Model API with reasoning effort set to `max`; `meta/muse-spark-1.3` on Google Cloud; OpenRouter mirrors the Meta standard rates. No Zen ID, and there is a separate, much cheaper `muse-spark-1.3-contributor` endpoint that is **not** this entry.
- **Context window:** **1,000,000 tokens** (Meta's model card and Google's quota documentation; Artificial Analysis lists 1.05M at the provider level). Unchanged from Muse Spark 1.2. **Max output: 131,072 tokens** (Vals AI and AIEvals model records; Vals ran the model at `max` output tokens). **This is the one model in this comparison with a published, near-saturated retrieval measurement at the far end of its own window: MRCR v2 (8-needle) 98.5% at 256K–512K and 98.1% at 512K–1M**, using OpenAI's MRCR v2 data re-binned by o200k_base token count, 100 examples per band, rule-based sequence-matcher grading.
- **Modalities:** **text, image, and video in; text out.** Reasoning yes, with selectable effort levels including `max`. Built-in tool calling with MCP support, structured output, prompt caching. One secondary source (modelpricewatch) describes the input set as text/image/video/audio/PDF; Meta's own card and Artificial Analysis both list **text, image, video** only, and that narrower list is what is scored — the wider claim is not vendor-confirmed. **Note:** the *new* Meta models from October are wider — both Muse Wonder and Muse Spark Open are documented as accepting **speech/audio** as well as image and video — so the modality ceiling has moved up the family even though it has not moved for this entry.
- **Pricing (as of 2026-10-17):** **Standard tier $1.25 input / $4.25 output per 1M, cached input $0.15** (88% cache discount) — unchanged from Muse Spark 1.2 and 1.1, and the same rate for `max` as for `xhigh`. Artificial Analysis's blended rate for Meta at this tier is **$0.78 per 1M (7:2:1 cache/input/output)**, the cheapest in Meta's line-up. A separate **Contributor tier at $0.10 / $0.20 per 1M (cached $0.002)** exists but trades training rights on your prompts and completions plus a much lower rate limit (**100 RPM vs 3,000 RPM** on standard) and, per Meta's docs, **no `max` reasoning level** — so the cheap tier is not a substitute for this entry. Web search grounding bills separately.
- **Architecture:** **proprietary, API-only, no open weights** — the first pass recorded this as a roadmap promise with nothing shipped; that changed on 2026-10-15, see the signature note below. Parameter count for the proprietary 1.3 is still not disclosed by Meta (Artificial Analysis's parameter column is empty).

### Raw benchmarks found

> Three provenance streams are kept separate below: **Meta's own evaluation report** (max reasoning, published methodology), **independent harnesses** (Vals AI and Artificial Analysis, each running the model at `max`), and **aggregators** that re-label or re-rank the two. Where they disagree, both numbers are listed. The single most important change since the first pass is that a full independent harness run now exists and it does **not** reproduce Meta's flagship agentic and coding numbers at Meta's level.

Agent / tool use:

- **Terminal-Bench 2.1 — a three-way conflict, recorded not averaged: 88.8% (Meta report) / 84.3% (Artificial Analysis) / 79.0% (Vals AI, "79.03% ±1.11", ~#11–12 of 25–76 depending on the board).** Meta's own dev.meta.ai table also records that **xhigh scores 89.2 on Terminal-Bench 2.1 versus max's 88.8** — i.e. on this benchmark `max` does *not* beat `xhigh`, and the first pass's "85% for xhigh" is superseded. Meta's methodology states Terminal-Bench 2.1 is 89 tasks run with each model's native coding harness inside Meta's internal agent evaluation framework and an isolated cloud sandbox, graded by the official executable verifier; competitor figures for GPT-5.6 Sol come from OpenAI's own model card. That is a vendor-run, non-reproducible harness — the ~5–10 point gap to the two independent harnesses is the cost of that.
- **Terminal-Bench 4.0 — 24.75% ±0.51 (Vals AI, #21/49) / 33.33% (Artificial Analysis, #15/40).** Both independent harnesses put this model in the **bottom fifth** on the current agentic terminal benchmark, and the two disagree with each other by 8.6 points. This is a serious mark against Meta's Terminal-Bench story and is the single biggest new finding of this pass.
- **τ³-Bench Banking: 50.52% (Artificial Analysis), now #2 — no longer #1, behind Qwen3.8 Max by 0.82 points.** The first pass recorded 52% and "#1 among all models on this evaluation"; on the 2026-10-17 read the score is marginally lower and the rank has dropped. Vals' separate professional-agent rows are strong but domain-specific: **Legal Research Bench 55.29% ±3.46, #1 of 79** (the model's single best result anywhere), **Harvey's Legal Agent 23.75% ±3.55, #2 of 80**, **Finance Agent v2 59.96% ±2.06, #5 of 79**, **Tax Agent Bench 42.44% ±3.51, #6 of 70**.
- **GDPval-AA v2.1: 1,754 Elo (Meta report) / ~1,672 Elo and 59.0% (Artificial Analysis).** Meta's own report has max at 1,754, xhigh at 1,709, Muse Spark 1.2 at 1,615, Opus 5 (max) at 1,824. The independent AA read lands materially lower for max and ranks it around 7th. `AA-Briefcase v1.1` 1,586 (AA) is the companion knowledge-work row.
- OSWorld 2.0: **66.9% (partial) / 32.0% (binary)** for max *(Meta report)* vs GPT-5.6 Sol 62.7% / 27.3% and Opus 5 68.3% / 31.4%. Note Meta now reports **both** a partial-credit and a binary figure — the binary numbers are near-identical across the three models and far less flattering than the partial-credit ones. Vals' independent **CUA-bench is 5.83%, #7 of 9** — bottom two.
- AutomationBench: **49.6% max** *(Meta report)* vs 46.7% GPT-5.6 Sol, 50.3% Opus 5 — **last of the three Meta compared**. Artificial Analysis's independent AutomationBench-AA reads **57.85%, #21 of 40**.
- JobBench: **64.9% max** vs 61.2% xhigh *(Meta report)*, 45.4% GPT-5.6 Sol, 65.7% Opus 5. Vals' independent analogue **ITBench-AA (IT operations) 33.24%, #17 of 18 — second-worst of 18.**
- DeepSearchQA: **90.3% max, tied exactly with xhigh** *(Meta report — revised up from 89.4 in the first pass)*; GPT-5.6 Sol 93.1%, Opus 5 90.4% — **behind Sol**.
- Agentic IF Index (Meta internal): **57.8% max** vs 60.5% GPT-5.6 Sol, 59.1% Opus 5 — **last of the three**.
- **New independent rows, mostly unflattering: SRE Bench 3.82% ±1.19 (#21/35), Terminal-Bench-Science 10.00% ±3.61 (#15/41), ProgramBench 2.50% (#~64), APEX-Agents 47.6%, Bug Hunt Bench 32.2 fixes, Vals RSI Index (autonomous research) 19.64% (#18/25).**
- **Efficiency in agentic operation:** in Meta engineers' internal coding comparisons, Muse Spark 1.3 used **~20% fewer tool calls and ~25% fewer tokens** than Muse Spark 1.2 *(Meta's report — a vendor internal comparison, not a harness benchmark)*.
- Claw-Eval / ClawProBench: **no verified public score found**
- Toolathon / MCP-Atlas / SWE Atlas Codebase QnA: **no verified public score found** (SWEAtlas Codebase QnA is reported below under Coding, where Meta's methodology places it)

Reasoning / knowledge:

Launch-era (2026-09-02) the same model scored **62**; the index, its composition and its comparison set changed. Both figures are recorded so the drop is not misread as a capability regression — but note the direction of travel since: Meta's own October models now score 52 and 56 on the same index, and **Muse Spark Open (xhigh) scores 39**.
- **Index versioning still matters, and the comparison set has also moved.** Meta now sits four points below Muse Wonder and eight below Muse Wonder Full on the index AA uses.
- GPQA Diamond: **93.5% (93.54%)** *(Artificial Analysis)* — essentially unchanged from the first pass's 94%/93.8%.
- HLE: **48.7% (48.70%)** *(Artificial Analysis)* — essentially unchanged from 49%.
- CritPt: **24.86%** *(Artificial Analysis)*.
- SciCode: **58.80%** *(Artificial Analysis)*.
- ProofBench v1.1: **58.00% ±4.96 (#24/50)** *(Vals AI — a 41-point lead over the field leader, GPT-6 Astra at 99%)*.
- MysteryMechanism: **36.04% ±3.23 (#9/27)** *(Vals AI)*.
- MLCR-AA (medical reasoning): **43.33%** *(Artificial Analysis)* — a new row, mid-field.
- FrontierMath: **74.0% Tiers 1–3, 46.3% Tier 4** *(as aggregated by BenchLeader from Meta's evaluation report)* — new, and a notable independent-lab difficulty signal.
- **LCR / MLCR — AA-LCR v1.1 has been revised UP from the first pass's 79% to 83.0%** *(Artificial Analysis)*, which is the one substantive *improvement* found in this pass.
- **AA-Omniscience — resolved, and better than the first pass feared.** AIEvals lists "AA-Omniscience 25" for this model; BenchLeader breaks the same measurement into **accuracy 43.6%** and **non-hallucination 67.1%**. The "25" is the composite (correct answers minus confident wrong answers, scored −100 to +100), not the accuracy. The first pass's **44% accuracy** is therefore correct and unchanged; the composite 25 vs the April-release Muse Spark's 7.2 is the comparison that matters. The first pass's separate claim that Omniscence Accuracy *fell* from 45% to 44% and that the fall was attributed to higher abstention is **not independently re-verified in this pass** — treat the direction of that one-point move as unconfirmed.
- **Harvey LAB-AA v1.1 — aggregator conflict, and the aggregator is wrong.** AIEvals reports **95.48%, #1 of 20, leader: itself**. Artificial Analysis's own figure, carried by both BenchLeader and Ridge with its methodology, is **8.9%, #4 of 18 — with 1.68 material hallucinations per task, and 26.7% *before* the hallucination gate.** The 95.48% figure is a relabelled and garbled reading of a different number on a different model. Recorded here so it is not propagated.
- **Verbosity remains the model's main measured weakness:** on the Intelligence Index, max generated **170M tokens against a median of 85–88M** — "very verbose" in AA's words. This is the direct cause of the $1.60-per-task figure. **Latency has also got worse since the first pass:** AA's time-to-first-answer-token for this model now reads **53.92 s** (total response 71.99 s), against the 37.33 s recorded on 2026-10-02. Vals measures end-to-end latency at **23 min 34 s** with a 0.65% refusal rate and 0.00% fallback rate.

Coding:

- **SWE-bench Verified: still no verified public score for this configuration, and the circulating 74.4% figure is now definitively traced.** Vals AI's SWE-bench Verified board shows **"Muse Spark" (the April 2026 original) at 74.40%, #48 of 88** — *not* Muse Spark 1.3. The same board shows **Muse Spark 1.2 at 86.6% (#14)** and **Muse Spark 1.1 at 82.0% (#21)**, i.e. the 74.4% belongs to the *weakest* member of the family, and the two predecessors both beat it by 8–12 points. Vals states explicitly: *"Since performance on this benchmark has saturated, we no longer run this benchmark on new model releases."* Ridge's live row for this model reads **"SWE-bench Verified — Vals AI hasn't published a row."** BenchLeader's Muse Spark vs Muse Spark 1.3 comparison page does put "SWE-bench (Vals) 74.4%" in the table, but in the **Muse Spark** column, next to its own 74.4% — it is not attributed to 1.3 and must not be.
- DeepSWE v1.1: **75.4%** *(Meta report, mini-swe-agent harness, 113 tasks across 91 repositories in TypeScript/Go/Python/JavaScript/Rust; other models' figures taken from the Datacurve official leaderboard)* vs GPT-5.6 Sol (max) 73.0% and Opus 5 (max) 74.0% — **leads both**. **Provenance caution carried into this pass:** a Meta-oriented analysis (mindstudio.ai, 2026-09-05) noted that Muse Spark 1.3 **does not appear on the public DeepSWE leaderboard** at all, unlike Muse Spark 1.2, making a chart-topping number that is disconnected from the board it supposedly dominates. Meta's own methodology document also states that for third-party models its runs are "best-effort" and "may not reflect their best provider-optimized performance", and that other models' figures are taken from official leaderboards — an asymmetry, not a like-for-like comparison.
- **SWEAtlas Codebase QnA: 59.4%** *(Meta report — 124 tasks over 11 production repositories in Go, Python, C and TypeScript, public QnA split, mini-swe-agent harness, task-specific rubric grading following Scale AI's leaderboard protocol)* vs GPT-5.6 Sol 53.5% and Opus 5 52.7% — **leads both by 6+ points**.

But the **1–100 variant of the same suite reads only 20.46% ±3.85 (#9/25)**, and Vals flags both, so the suite is not internally consistent.
- **Code Migration: 47.41% ±4.26 (#15/78)** *(Vals AI)*.
- **CursorBench 4.0: 41.6%, #9 of 15** *(Cursor, 2026-09-11)*.
- **IOI: 56.56% ±2.52 (#20/44)** *(Vals AI)* — for reference, the field leader scores 100%.
- **SWE-bench Multimodal: 43.13% ±2.26 (#12/20)** *(Vals AI)*.
- **FrontierCode 1.1: 40.6%** and **FrontierSWE 25.8%** *(Artificial Analysis / aggregated)* — both low.
- Arena: Text 1494, Hard Prompts 1515, Coding 1535, WebDev 1658, Vision 1309, **Agent 3.8**, Maths 1504, Instruction Following 1483, Multi-turn 1491, Longer Queries 1496, Document 1468 *(LMArena)*. Agentic arena performance is effectively absent.
- AA Coding Index: not published as a standalone figure in this pass; **SciCode 58.80%** is the nearest AA coding row.
- Coding is where Meta's own chart claims outright leadership on all three benchmarks it selected — and the three it selected are exactly the three it leads. Two and a half months on, **no SWE-bench Verified or Pro figure has been published for `max`**, the most-requested coding row in this comparison, and the two independent harnesses that *do* run agentic coding benchmarks put this model at **79.0% (Vals) / 84.3% (AA) on Terminal-Bench 2.1 against Meta's 88.8%**, and at **24.75% / 33.33% on Terminal-Bench 4.0**.

Long context:

- **MRCR v2 (8-needle), 256K–512K: 98.5%** *(Meta report — 100 examples in band, pure retrieval-from-context with no agent tools, target turn retrieved from among 8 needles distributed across the full context, reproduced via a random-hash-prefixed string and graded by rule-based sequence-matcher ratio)* vs GPT-5.6 Sol 91.5%.
- **MRCR v2 (8-needle), 512K–1M: 98.1%** vs GPT-5.6 Sol **73.8%** — a **24.3-point gap at the far end of the window**, the single largest margin in Meta's report. Opus 5 publishes no MRCR figures, so no three-way comparison is possible.
- **AA-LCR v1.1: 83.0%** *(Artificial Analysis, revised up from the 79% recorded on 2026-10-02)* — the independent long-context number, and now much closer to Meta's own MRCR figures. Worth recording the convergence: Meta's 98%+ pure needle retrieval and AA's 83% broader long-context comprehension suite measure different things, and the gap between them has narrowed but has not closed.

### Normalized scores (1–100)

- **Tool use: 86/100.** Down from 92. **What still holds it up:** τ³-Banking **50.52% (#2 of 30)** remains at the methodology's frontier anchor, **Legal Research Bench 55.29% #1 of 79** is the strongest professional-agent result in this comparison, GDPval-AA v2.1 **1,754 Elo (Meta) / 1,672 (AA)** is at or near the ~1750 anchor, and Meta's own JobBench 64.9% beats GPT-5.6 Sol by ~20 points. **What now caps it, and this is the substance of the change:** a full independent harness run exists for the first time and it does not reproduce the vendor framing. **Terminal-Bench 2.1 reads 84.3% (AA) and 79.0% (Vals) against Meta's 88.8%** — 5 to 10 points below the methodology's ~88% frontier anchor depending on which independent harness you believe; **Terminal-Bench 4.0 reads 33.33% (AA) and 24.75% (Vals), bottom fifth of their fields**; **CUA-bench is 5.83%, #7 of 9**; **ITBench-AA is 33.24%, #17 of 18**; **SRE Bench 3.82%, #21 of 35**; and Arena Agent is effectively 3.8. Meta's own chart still places the model last against its two comparators on AutomationBench, Agentic IF Index and DeepSearchQA. This is a strong model with a real domain strength, not a model that sweeps the agentic board — and the vendor-vs-independent gap on its headline agentic number is exactly the kind of conflict the methodology says to record rather than average away.
- **Reasoning: 88/100.** Down from 90. Anchored on **GPQA Diamond 93.5%** (frontier ref 90%+) and **HLE 48.7%** (frontier ref 40%+), with **SciCode 58.8%**, **CritPt 24.9%**, **ProofBench 58.0%** and **FrontierMath 74.0% / 46.3%**. **What moved it down, modestly:** the AA Intelligence Index still reads **48** (launch-era 62), and it is now four points below Muse Wonder and eight below Muse Wonder Full on the same index — the model has been overtaken inside its own family, by Meta, in five weeks. The composite AA-Omniscience of **25** is mid-field (the April Muse Spark scores 7.2, so the family improved, but 25 is not a strong hallucination profile). **What moved it up, marginally:** AA-LCR rose to **83.0%**, the first genuinely positive movement found in this pass. The 2-point reduction reflects the overtaken index position, not a capability regression on any reasoning benchmark.
- **Context window: 100/100.** Unchanged, and the only model in this comparison that earns the methodology's top mark on the stated condition: **≥1M window AND ≥98% retrieval measured at 512K+**. Both hold — **1,000,000 tokens documented, MRCR v2 98.1% at 512K–1M** (98.5% at 256K–512K) against GPT-5.6 Sol's 73.8% in the same far band — and the independent AA-LCR row has *risen* to 83%, which strengthens rather than weakens the case. This is still Meta's own run on Meta's own methodology, described in enough detail (data source, re-binning, per-band sample size, needle count, grading method) to be checkable, but it is **not** an independent reproduction. 131,072 max output clears the methodology's 64K caveat comfortably. **Caveat added this pass:** Meta has since released Muse Spark Open at the same 1M window under open weights, so this model is no longer the only way to get million-token retrieval from Meta — but for this catalog entry the score stands.
- **Multimodal: 85/100.** Unchanged. Methodology band: text + image + video in, text out = 75–90. Upper-middle of that band, now with actual independent multimodal measurements behind it rather than only Meta's methodology: **MMMU-Pro 82.02%** and **Arena Vision 1309** *(Artificial Analysis / LMArena)*, plus **AA-3D 1037** and **SWE-bench Multimodal 43.13%**. **What caps it:** **no audio input and no non-text output** are documented for this model, so the 90–100 band is out of reach — and that cap is now sharper, because Meta's own October models (Muse Wonder, Muse Spark Open) *do* document audio input, so the gap is one of this checkpoint rather than of the family. The one secondary source adding audio and PDF to 1.3's input set remains unconfirmed by the vendor and is not scored.
- **Coding: 82/100.** Down from 91, and the largest single change in this report. **What still holds it up:** Meta's three published benchmarks (DeepSWE 75.4%, Terminal-Bench 2.1 88.8%, SWEAtlas QnA 59.4%) are at or above the methodology's frontier markers, **Vibe Code Bench v1.1 85.86%** is a genuinely strong *independent* result, SciCode 58.8% clears the 55% frontier reference, and CursorBench 4.0 41.6% places mid-field. **What caps it, decisively:** the independent replays land well below the vendor on precisely the benchmarks that matter. **Terminal-Bench 2.1: 84.3% (AA) / 79.0% (Vals) vs Meta's 88.8%.** **Terminal-Bench 4.0: 33.3% (AA) / 24.8% (Vals) — bottom fifth.** FrontierCode 1.1 at 40.6%, FrontierSWE at 25.8%, Vibe Code Bench 1–100 at 20.5%, Code Migration at 47.4%, IOI at 56.6% against a field leader at 100%, and Arena Agent at 3.8 all point the same way. **And SWE-bench Verified — the most-requested coding row in this comparison — remains absent for this configuration two and a half months after launch**, with the circulating 74.4% definitively traced to the April 2026 original Muse Spark rather than to 1.3. Meta's chart still leads on precisely the three benchmarks it chose to publish. 82 keeps this in the upper part of the methodology's mid band on the strength of the vendor's own frontier numbers plus Vibe Code Bench v1.1, while refusing to extend that credit to the benchmarks that contradict them.
- **Cost efficiency: 82/100.** Down from 87. The Standard tier is **$1.25 / $4.25 per 1M with $0.15 cached input** (88% cache discount), which the methodology's ladder places at ~88; Artificial Analysis's blended rate for Meta at this tier is **$0.78/1M**, the cheapest in Meta's line-up. **What caps it below that anchor is measured cost per task, and it has moved in the wrong direction since the first pass.** AA measures **$1.60 per Intelligence Index task for max** against **$1.37 for xhigh** at the identical token price — note this *corrects* the first pass, which recorded xhigh at $0.55; the live AA figures are max $1.60, xhigh $1.37, Muse Spark 1.2 xhigh $0.97, Muse Spark 1.1 xhigh $1.38, Muse Wonder max $4.52. Vals independently measures **$3.787 per Vals Index test for max**, against $3.376 for xhigh (which scores 53.20% to max's 58.16%) — i.e. **the more capable effort level costs more per completed task on both independent harnesses, by 12% on Vals and 17% on AA.** The headline token rate has been unchanged across three Muse Spark generations while cost per task has not improved. **What would improve it:** Muse Wonder is a more capable model *and* Meta's stated direction, but at $4.00/$20.00 it is not a cheaper route — it is the same or worse economics for anyone optimising cost per task. The **$0.10 / $0.20 Contributor tier is not available for this entry** (no `max` reasoning level, 100 RPM vs 3,000 RPM).
- **Overall Score: 88/100.** Half-up mean of the five quality dims (86 + 88 + 100 + 85 + 82) / 5 = 88.2 → **88**. Down four points from the first pass's 92, and the drop is almost entirely **Coding (−9)** plus **Tool use (−6)**, both driven by the arrival of independent harness numbers rather than by anything the vendor changed. **Best fit, unchanged in kind but narrower in scope:** the strongest published model in this comparison for **million-token work** — whole codebases, long document chains, extended agent traces — where its 98.1% retrieval at 512K–1M against a competitor's 73.8% is the difference between the workload working and not, and the only model here with the AA-LCR to corroborate it. Still the right pick for banking-domain and legal/professional agentic tool use. **But treat the framing carefully, and it is worse than the first pass said:** the launch numbers came from a reasoning level that was gated at the time; the same model reads 48 rather than 62 on the current Artificial Analysis index; **Meta has since shipped Muse Wonder (52) and Muse Wonder Full (56), both scoring above it on that same index, plus Muse Spark Open under open weights**; and where an independent harness has now run this model at `max`, it has landed 5–10 points below Meta on Terminal-Bench 2.1 and in the bottom fifth on Terminal-Bench 4.0. **This is a September model being superseded by its own vendor, with a vendor-vs-independent gap on its flagship numbers.** Not the pick for anyone optimising cost per task at `max`, where xhigh is 17% cheaper per completed task for 3 fewer index points.

It carries **additional modalities (audio) and scores *lower* on the AA index at 39 (xhigh) than proprietary Muse Spark 1.3 does at 45 (xhigh)** — a consequence of that post-training that a buyer of open weights should know about.
