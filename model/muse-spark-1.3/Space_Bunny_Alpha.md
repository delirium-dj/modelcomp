## Model card

- **Name:** Muse Spark 1.3 with max reasoning
- **Short description:** Meta's flagship proprietary agentic model, September 2026, tuned for long-horizon agentic workflows and competitive coding, with particular strength in million-token retrieval. **Important variant note: "Max" is a reasoning-effort level on the `muse-spark-1.3` model, not a separate checkpoint or a separately priced SKU.** Meta's own documentation now lists `max` as a requestable reasoning level on the Standard-tier `muse-spark-1.3` endpoint at the same per-token rate as every other effort level. It was, however, **gated at launch** pending additional safety testing — Meta shipped the headline benchmark numbers on `max` while the tier developers could actually call was `xhigh`, and Artificial Analysis initially had no API provider listed for `max` at all. Most of the benchmark advantage over `xhigh` belongs to `max`.
- **Provider / access:** **Meta Model API** (`muse-spark-1.3`) and **Muse Code** (macOS and Linux installers). Also surfaced as `meta/muse-spark-1.3` on Google Cloud's Gemini Enterprise Agent Platform, where it is listed at **Preview** launch stage with **text input / text output only** and function calling, structured output and reasoning all flagged as preview features. Artificial Analysis lists exactly one provider for the max configuration: Meta, at 1.05M context.
- **Release / knowledge:** **2026-09-02** (Meta AI Research announcement and Artificial Analysis launch article, same day). Google Cloud's partner-model record shows a 2026-09-24 release date for its listing, which is that platform's own availability date, not Meta's release. Knowledge cutoff not published.
- **IDs:** `muse-spark-1.3` on the Meta Model API with reasoning effort set to `max`; `meta/muse-spark-1.3` on Google Cloud; OpenRouter mirrors the Meta standard rates. No Zen ID — Muse Spark has no OpenCode Zen listing, and there is a separate, much cheaper `muse-spark-1.3-contributor` endpoint that is **not** this entry.
- **Context window:** **1,000,000 tokens** (Meta's model card and Google's quota documentation; Artificial Analysis lists 1.05M at the provider level). Unchanged from Muse Spark 1.2. **This is the one model in this comparison with a published, near-saturated retrieval measurement at the far end of its own window: MRCR v2 (8-needle) 98.5% at 256K–512K and 98.1% at 512K–1M**, using OpenAI's MRCR v2 data re-binned by o200k_base token count, 100 examples per band, rule-based sequence-matcher grading.
- **Modalities:** **text, image, and video in; text out.** Reasoning yes, with selectable effort levels including `max`. Built-in tool calling with MCP support, structured output, prompt caching. One secondary source (modelpricewatch) describes the input set as text/image/video/audio/PDF; Meta's own card and Artificial Analysis both list **text, image, video** only, and that narrower list is what is scored — the wider claim is not vendor-confirmed.
- **Pricing (as of 2026-10-02):** **Standard tier $1.25 input / $4.25 output per 1M, cached input $0.15** (88% cache discount) — unchanged from Muse Spark 1.2 and 1.1, and the same rate for `max` as for `xhigh`. A separate **Contributor tier at $0.10 / $0.20 per 1M (cached $0.002)** exists but trades training rights on your prompts and completions plus a much lower rate limit (**100 RPM vs 3,000 RPM** on standard) and, per Meta's docs, **no `max` reasoning level** — so the cheap tier is not a substitute for this entry. Web search grounding bills separately at $2.50 per 1,000 queries. Artificial Analysis measures **$1.60 per Intelligence Index task** for max and $0.55 for xhigh — the same token price, a near-3× cost-per-task difference driven entirely by how many tokens `max` spends.
- **Architecture:** **proprietary, API-only, no open weights** — Meta's roadmap mentions a "Muse Spark open weights release" without a version, date, size or licence, and nothing has shipped. Parameter count not disclosed by Meta (Artificial Analysis's parameter column is empty). Meta trained it on more long-horizon coding tasks and reports it is trained to maintain multiple workflows in a long thread, gather context with tools, detect gaps in its own plans, and ask for clarification before consequential actions.

### Raw benchmarks found

> Two provenance streams are kept separate below: Meta's own evaluation report (max reasoning, published methodology) and Artificial Analysis's independent measurements. Where they disagree — most importantly on the Intelligence Index — both are listed with their index version.

Agent / tool use:

- Terminal-Bench 2.1: **88.8%** for max *(Meta evaluation report)* / **86%** *(Artificial Analysis)* — vs 85% for xhigh, 80% for Muse Spark 1.2. Ties GPT-5.6 Sol (max) at 88.8%; Opus 5 (max) scores 86.7%.
- τ³-Bench Banking: **52%** for max / **47%** for xhigh *(Artificial Analysis)* — **#1 among all models on this evaluation**, up 17 points from Muse Spark 1.2's 35%.
- GDPval-AA v2: **1,754 Elo** for max / **1,709** for xhigh / 1,615 for Muse Spark 1.2 *(Artificial Analysis)*. Opus 5 (max) scores 1,824 — Muse Spark max is **behind Opus here**.
- OSWorld 2.0: **66.9%** max vs 57.2% xhigh *(Meta report)*; GPT-5.6 Sol (max) 62.7%, Opus 5 (max) 68.3%.
- AutomationBench: **49.4%** max *(Meta report)* vs 46.7% GPT-5.6 Sol, 50.3% Opus 5 — **last of the three Meta compared**.
- JobBench: **64.9%** max vs 45.4% GPT-5.6 Sol, 65.7% Opus 5 — beats Sol by ~20 points, just behind Opus.
- DeepSearchQA: **89.4%** max, **tied exactly** with xhigh *(Meta report)*; GPT-5.6 Sol 93.0%, Opus 5 90.4% — **behind both**.
- Agentic IF Index (Meta internal): **57.8%** max vs 60.5% GPT-5.6 Sol, 59.1% Opus 5 — **last of the three**.
- **Efficiency in agentic operation:** in Meta engineers' internal coding comparisons, Muse Spark 1.3 used **~20% fewer tool calls and ~25% fewer tokens** than Muse Spark 1.2, taking fewer turns where none were needed *(Meta's report — a vendor internal comparison, not a harness benchmark)*.
- Claw-Eval / ClawProBench: **no verified public score found**
- Toolathon / MCP-Atlas / SWE Atlas Codebase QnA: **no verified public score found** (SWEAtlas Codebase QnA is reported below under Coding, where Meta's methodology places it)

Reasoning / knowledge:

- GPQA Diamond: **94%** *(Artificial Analysis launch analysis; 93.8% on the AA model record)* — up 4 points from Muse Spark 1.2's 90%. `max` **ties** xhigh here.
- HLE: **49%** *(Artificial Analysis; 49.1% on the AA model record, text-no-tools)* — up 2 points from 1.2's 45%, with `max` gaining a further 2 over xhigh.
- CritPt: **26%** for xhigh, **~25%** for max *(Artificial Analysis)* — the standout non-agentic gain of the release at **+8 points** over Muse Spark 1.2's 18%; `max` gives back one point relative to xhigh.
- SciCode: **59%** *(Artificial Analysis; 57.3% on the AA model record)* — up 2–3 points from 1.2's 56%.
- LCR / MLCR — **AA-LCR v1.1: 79%** *(Artificial Analysis)*, down **4 points** from Muse Spark 1.2's 83%. This is one of only two regressions in the release.
- **Artificial Analysis Intelligence Index: 48** on the current index *(Artificial Analysis model page and release comparison, which ranks max above xhigh's 45)* — "well above average among comparable models (median: 26)", and $1.60 per Index task.
- **Index versioning matters enormously here.** At launch on 2026-09-02 the same model scored **62** on the then-current AA Intelligence Index — second only to Claude's Fable and Opus variants, and level with GPT-5.6 Sol (max) and Grok 4.6 (high). It now reads **48** on the current index version. **The model did not lose 14 points of capability; the index, its composition and its comparison set changed.** Both figures are recorded here so the drop is not misread as a regression.
- Omniscience Accuracy / Hallucination Rate: **AA-Omniscience Accuracy 44%** for max *(down 1 point from 45%; xhigh fell 3 points to 42%)*, with the drop attributed to a **higher abstention rate** — not answering when unsure — which also **lowered the hallucination rate**. Meta separately reports improved adversarial robustness including resistance to prompt injections, and better calibration on what counts as an irreversible action.
- **Verbosity is the model's main measured weakness:** on the Intelligence Index, max generated **170M tokens against a 26-index-tier median of 82M** — "very verbose" in AA's words. This is the direct cause of the $1.60-per-task figure and of the 37.33 s TTFT.

Coding:

- DeepSWE v1.1: **75.4%** *(Meta report, mini-swe-agent harness, 113 tasks across 91 repositories in TypeScript/Go/Python/JavaScript/Rust; other models' figures taken from the Datacurve official leaderboard)* vs GPT-5.6 Sol (max) 73.0% and Opus 5 (max) 74.0% — **leads both**.
- Terminal-Bench 2.1: **88.8%** *(see agentic section — Meta's coding lead)*, tied with GPT-5.6 Sol.
- SWEAtlas Codebase QnA: **59.4%** *(Meta report — 124 tasks over 11 production repositories in Go, Python, C and TypeScript, public QnA split, mini-swe-agent harness, task-specific rubric grading following Scale AI's leaderboard protocol)* vs GPT-5.6 Sol 53.5% and Opus 5 52.7% — **leads both by 6+ points**. This is the codebase-comprehension benchmark that precedes a code change.
- SWE-bench Verified / SWE-Pro: **no verified public score found** for this configuration.
- LiveCodeBench: **no verified public score found**
- Vibe Code Bench: **no verified public score found**
- AA Coding Index: **76.3** *(Artificial Analysis model record)*.
- Coding is where Meta's own chart claims outright leadership on all three benchmarks it selected — and the three it selected are exactly the three it leads. No SWE-bench Verified or Pro figure is published for `max`, which is the most-requested coding row in this comparison and the one absent here.

Long context:

- **MRCR v2 (8-needle), 256K–512K: 98.5%** *(Meta report — 100 examples in band, pure retrieval-from-context with no agent tools, target turn retrieved from among 8 needles distributed across the full context, reproduced via a random-hash-prefixed string and graded by rule-based sequence-matcher ratio)* vs GPT-5.6 Sol 91.5%.
- **MRCR v2 (8-needle), 512K–1M: 98.1%** vs GPT-5.6 Sol **73.8%** — a **24.3-point gap at the far end of the window**, which is the single largest margin in Meta's report and the clearest demonstration of the model's defining property: it does not degrade where its competitors do. Opus 5 publishes no MRCR figures, so no three-way comparison is possible.
- **AA-LCR v1.1: 79%** *(Artificial Analysis)* — the independent long-context number, and a 4-point regression against Muse Spark 1.2. Worth noting alongside the MRCR figures: Meta's own 98%+ MRCR retrieval and AA's 79% LCR are measuring different things (pure needle retrieval vs. a broader long-context comprehension suite), and the gap between them is a reminder not to read "98% at 1M" as universal long-context competence.

### Normalized scores (1–100)

- **Tool use: 92/100.** Every anchor in the methodology's frontier band is met: **Terminal-Bench 2.1 88.8%** (frontier ref ~88%+), **τ³-Bench Banking 52%** (frontier ref ~50%+, and **#1 among all models measured**), **GDPval-AA v2 1,754 Elo** (frontier ref ~1750+). The ~20% fewer tool calls and ~25% fewer tokens than 1.2 is a direct agentic-operations gain on top. **What caps it below the very top:** three of Meta's own agentic rows place it **last** against its two comparators — AutomationBench 49.4% (vs Opus 5's 50.3%), Agentic IF Index 57.8% (vs Sol's 60.5%), and DeepSearchQA 89.4% (behind Sol's 93.0% and Opus's 90.4%) — and **GDPval-AA is behind Opus 5's 1,824**. It is at the frontier, and specifically the strongest published model on banking-domain agentic tool use, but it does not sweep the agentic board.
- **Reasoning: 90/100.** Anchored on **GPQA Diamond 94%** (frontier ref 90%+) and **HLE 49%** (frontier ref 40%+), with **SciCode 59%** and **CritPt ~25%** both above their 1.2 baselines. The methodology's frontier band is 90–100 on exactly this combination. **What caps it below the top of the band:** the current **AA Intelligence Index reads 48** (launch-era: 62), and that index is where the resolution of the change sits — the model is well above the 26 median for its price tier but no longer at the top of the leaderboard it briefly occupied. **AA-LCR fell 4 points to 79%**, and **Omniscience Accuracy fell to 44%**: the abstention behaviour that lowered the hallucination rate is a deliberate trade, and it costs raw accuracy. Measured verbosity (170M tokens vs an 82M median) is a reasoning-economics cost, not a reasoning-quality one.
- **Context window: 100/100.** The only model in this comparison that earns the methodology's top mark, and it earns it on the stated condition: **≥1M window AND ≥98% retrieval measured at 512K+**. Both hold — **1,000,000 tokens documented, MRCR v2 98.1% at 512K–1M** (and 98.5% at 256K–512K), against GPT-5.6 Sol's 73.8% in the same far band. This is Meta's own run on Meta's own methodology, and the harness is described in enough detail (data source, re-binning, per-band sample size, needle count, grading method) to be checkable, but it is **not** an independent reproduction. The independent long-context row, AA-LCR at 79%, is a 4-point regression — recorded, and the reason this is a 100 rather than a claim of unqualified dominance.
- **Multimodal: 85/100.** Methodology band: text + image + video in, text out = 75–90. Upper-middle of that band on Meta's published evaluation methodology, which covers multimodal evaluation explicitly. **What caps it:** **no audio input and no non-text output** are documented, so the 90–100 band is out of reach, and the input set is the narrower of the two claims in circulation (Meta's card and AA list text/image/video; one secondary source adds audio and PDF, which is not vendor-confirmed and is not scored).
- **Coding: 91/100.** The methodology's frontier markers are met or exceeded: **DeepSWE v1.1 75.4%** (frontier ref 74%+), **Terminal-Bench 2.1 88.8%** (frontier ref 85%+), **SciCode 59%** (frontier ref 55%+), with an **AA Coding Index of 76.3**. **SWEAtlas Codebase QnA 59.4%** is a genuine capability lead — 6+ points over both GPT-5.6 Sol and Opus 5 on codebase comprehension, the capability that precedes a code change. **What caps it:** **no SWE-bench Verified or Pro figure exists** for this configuration, which is the single most requested coding row in this comparison and the one real gap; Meta's chart leads on precisely the three benchmarks it chose to publish; and Opus 5 remains competitive on the agentic rows above.
- **Cost efficiency: 87/100.** The Standard tier is **$1.25 / $4.25 per 1M** with **$0.15 cached input** (88% cache discount), which the methodology's ladder places at **~88**. Scored just below that, not above, and the reason is measured rather than assumed: **`max` costs $1.60 per Intelligence Index task against xhigh's $0.55 at the identical token price**, because it generated 170M tokens against xhigh's far lower volume. The headline token rate is unchanged from three Muse Spark generations, but **cost per completed task has risen generation over generation** — Muse Spark 1.2 was $0.40 per task, 1.3 xhigh is $0.55, 1.3 max is $1.60. The **$0.10 / $0.20 Contributor tier is not available for this entry** (no `max` reasoning level, and 100 RPM vs 3,000 RPM). **What caps it:** a $3/$15-style model would score ~60, so 87 is competitive — but a model that is verbose enough to quadruple its own cost per task relative to its own cheaper sibling is not at the Pareto edge its token price suggests.
- **Overall Score: 92/100.** Half-up mean of the five quality dims (92 + 90 + 100 + 85 + 91) / 5 = 91.6 → **92**. **Best fit:** the strongest published model in this comparison for **million-token work** — whole codebases, long document chains, extended agent traces — where its 98.1% retrieval at 512K–1M against a competitor's 73.8% is the difference between the workload working and not. Also the right pick for banking-domain agentic tool use (τ³-Banking 52%, #1 measured) and for codebase comprehension. **Not** the pick for anyone optimizing cost per task at `max` reasoning: xhigh delivers most of the intelligence at roughly a third of the cost per task, and the Contributor tier's headline $0.10/$0.20 does not apply to this configuration at all. And treat the launch framing carefully — the numbers that made headlines were published for a reasoning level that was gated at the time, and the same model reads 48 rather than 62 on the current Artificial Analysis index.
