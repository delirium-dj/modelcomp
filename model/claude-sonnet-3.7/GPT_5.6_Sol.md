# Claude 3.7 Sonnet — Independent Research Report

## Summary and evidence

Claude 3.7 Sonnet is Anthropic's February 2025 hybrid reasoning model and the first Claude with controllable extended thinking. It accepts text and images, offers **200K context**, and allows thinking budgets up to its **128K output limit**. It launched alongside Claude Code and delivered major improvements in real-world coding, front-end work, instruction following, math, science, and tool interaction.

Source: [Anthropic Claude 3.7 Sonnet launch](https://www.anthropic.com/news/claude-3-7-sonnet)

## Cost and limitations

Pricing is **$3 input and $15 output per million tokens**, including thinking tokens. It is a legacy model without modern computer-use performance, million-token standard context, audio/video input, or current Claude platform features.

## Scores

- **Tool use: 83/100.** Claude Code and strong early tool interaction established capable agents.
- **Reasoning: 84/100.** Hybrid extended thinking was innovative but is now dated.
- **Context window: 84/100.** 200K input and 128K output remain useful.
- **Multimodal: 82/100.** Vision is supported, without audio or video.
- **Coding: 87/100.** Real-world coding and front-end development were principal strengths.
- **Cost efficiency: 73/100.** $15 output is costly for a legacy model.
- **Overall Score: 84/100.** Half-up rounded mean: (83 + 84 + 84 + 82 + 87) / 5 = 84.0.

## Bottom line

Claude 3.7 Sonnet is historically important but should generally be migrated to a newer Sonnet release.
