## Model card

- **Name:** Kimi K3. No free API tier; free access is via the Kimi consumer products. **Open weight, not open source** — the full checkpoint is public on Hugging Face under a custom **Kimi K3 License** with usage restrictions that must be reviewed before commercial or derivative deployment.
- **Short description:** Moonshot AI's flagship multimodal reasoning model, launched as a hosted service on **2026-07-16**, with **2.8 trillion total parameters — the first announced open model in the three-trillion class**. It is built for work that unfolds over many steps: navigating large codebases, driving terminals, tool use, reading screenshots, research across large document sets, building spreadsheets and decks, and iterating on visual output. Closer to an agent model than a chat assistant. Variant/alias flag: the model ID differs by surface (`kimi-k3` on the API, `k3` in Kimi Code, `moonshotai/kimi-k3` on resellers) — a documented cause of failed requests. Moonshot is unusually candid in its own launch post that **K3 still trails Claude Fable 5 and GPT-5.6 Sol overall**; its narrower claim is frontier parity on many coding and agentic tasks with a downloadable checkpoint.
- **Provider / access:** Five practical routes — Kimi.com and mobile apps; **Kimi Work** (desktop knowledge-work environment, v3.1.0+ on Windows and Apple silicon); **Kimi Code** (terminal coding agent, select with `/model`, ID `k3`); the **Kimi API — an OpenAI-compatible Chat Completions endpoint at `https://api.moonshot.ai/v1`** with tool calls and structured output; and third-party hosts (OpenRouter, Cloudflare Workers AI) plus downloadable weights. The API is stateless, so conversation history must be resent. Rate limits, media support, latency and data policy all differ by route.
- **Release / knowledge:** Hosted release 2026-07-16; full checkpoint, custom license, deployment recipes (vLLM, SGLang, TokenSpeed) and technical report published subsequently. **Knowledge cutoff: no verified public figure found.**
- **IDs:** `kimi-k3` (Moonshot API), `k3` (Kimi Code), `moonshotai/kimi-k3` (OpenRouter and Cloudflare Workers AI). Weights on Hugging Face. **No free-tier API ID.**
- **Context window:** **1,048,576 tokens**, documented by Moonshot and independently by Cloudflare's model card. Max output: no verified public figure found. Pricing is **flat across the full window** — no long-context tier, which is a real differentiator against GPT-6 Astra and Gemini 3.1 Pro.
- **Modalities:** Input: **text plus native visual understanding** — launch specifications explicitly confirm native vision, and Moonshot demonstrates image- and video-informed workflows, though exact accepted media formats and limits are endpoint-specific and incompletely documented. Output: text only. Reasoning: **always on**, with `low`, `high` and `max` effort and **max as the API default** — reasoning tokens count toward billing. Tool calls: yes. JSON mode / structured output: supported on the general Moonshot API; K3-specific parameter support should be verified against live docs.
- **Pricing (as of 2026-10-03):** **$3.00 / 1M cache-miss input, $0.30 / 1M cache-hit input (a 90% discount), $15.00 / 1M output.** Moonshot's Mooncake disaggregated serving reports **over 90% cache hits in coding workloads**, which makes that discount unusually real rather than theoretical. Worked list-price examples: 100K in + 10K out = $0.45 (cache-miss) or $0.18 (cached); 1M in + 20K out = $3.30 or $0.60. Important internal comparison: this is a **large step up from Kimi K2.6** ($0.95 / $0.16 / $4.00), so K3 is not the value option within its own family — the recommended pattern is routing only the hardest, longest or most visual work to it.
- **Architecture:** **93-layer sparse Mixture of Experts, 2.8T total / 104B activated parameters, routing each token through 16 of 896 routed experts plus 2 shared experts.** Four disclosed components: **Kimi Delta Attention (KDA)**, a hybrid linear-attention design for long-range state; **Attention Residuals (AttnRes)**, where layers learn which earlier representations to retrieve rather than accumulating all previous outputs uniformly; **Stable LatentMoE** for balanced routing at extreme scale; and **MXFP4/MXFP8 quantization-aware training** begun during supervised fine-tuning (4-bit weights, 8-bit activations). Moonshot has published separate research on Kimi Linear/KDA and on Attention Residuals, and the public K3 technical report documents how the 2.8T model combines them. **Independent reproduction at this scale remains the missing proof.** Self-hosting is a datacenter project: 4-bit weights alone imply roughly **1.4 TB** before runtime overhead, and Moonshot recommends a **supernode with 64+ accelerators**.

### Raw benchmarks found

> Provenance is separated. **Independent** = Arena blind preference testing and Artificial Analysis's live indices from the hosted API. **Vendor-reported** = Moonshot's launch evaluation table, run at maximum reasoning with temperature 1.0 and top-p 1.0 — and explicitly *not* a clean league table: harnesses vary (KimiCode, Claude Code, Codex and others), some competitor scores come from those competitors' own vendors, Fable 5 sometimes fell back to another model, and a few evaluations used modified hardware or tasks.

Agent / tool use:

- **Terminal-Bench 2.1: 88.3** (vendor; Claude Fable 5 84.6, GPT-5.6 Sol 88.8, Claude Opus 4.8 84.6) — within half a point of the best displayed score and above the methodology's ~88% frontier anchor
- Tau3-Banking / Tau2-Bench: no verified public score found
- **GDPval-AA v2 (Elo): 1,686** (vendor; Fable 5 1,760, Sol 1,748, Opus 4.8 1,600) — beats Opus 4.8, trails the two leaders, just under the ~1750+ frontier reference
- Claw-Eval / ClawProBench: no verified public score found
- **MCP Atlas: 84.2** (vendor; Fable 5 84.7, Sol 83.6, Opus 4.8 83.6) — effectively tied with the top group on a genuine tool-use benchmark. Toolathon and SWE Atlas Codebase QnA: no verified public score found
- **BrowseComp: 91.2** (vendor; Fable 5 88.0, Sol 90.4, Opus 4.8 84.3) — leads the comparison table. **Revealing footnote:** 91.2 was achieved with context compaction triggered at 300K, while the full 1M window with no context management scored **90.4** — the model can operate at a million tokens but deliberate context management still helps.
- **SpreadsheetBench 2: 34.8** (vendor; Fable 5 34.7, Sol 32.4, Opus 4.8 31.55) — narrow lead on knowledge work
- **Artificial Analysis Agentic Index: 54.3** (independent, 2026-08-28) — notably weaker than its coding index and the key independent caveat on this dimension

- SciCode / AA-SciCode: no verified public score found

- **Artificial Analysis Coding Index: 76.2** (independent) — above the methodology's 70%+ frontier reference

This is the strongest independent signal for the model, and its scope is narrow: it measures user preference for generated interfaces, not backend reliability, long-running repository maintenance, factual research or production latency.

The only directional evidence is the BrowseComp compaction footnote above, which is mildly negative for unmanaged million-token use.

### Normalized scores (1–100)

- **Tool use: 89/100.** **Terminal-Bench 2.1 at 88.3 clears the methodology's ~88% frontier anchor** and lands within half a point of the best score in its own comparison; **MCP Atlas 84.2 is frontier parity on a dedicated tool-use benchmark**; **BrowseComp 91.2 leads the table**; GDPval-AA v2 at 1,686 Elo beats Claude Opus 4.8 and sits just under the ~1750+ reference; SpreadsheetBench 2 edges the field. Three things prevent a 90+ placement: the independent read is markedly cooler than the vendor table — **Artificial Analysis measures the Agentic Index at only 54.3** against a Coding Index of 76.2, which says the agentic strength is narrower than the vendor rows imply; **Tau3-Banking, Claw-Eval and OSWorld are all unreported** (explicit methodology penalty); and the vendor table's harnesses are mixed by Moonshot's own admission, with competitor figures sourced from competitors.
- **Reasoning: 88/100.** **GPQA Diamond 93.5** clears the 90%+ reference and **HLE Full 43.5** clears the 40%+ reference, while the independent **Intelligence Index of 59.7 sits just under the 60+ frontier marker** — a coherent near-frontier picture. It cannot go higher because the HLE result is the weakest row in Moonshot's own table (behind Fable 5 by 9.8 points and Opus 4.8 by 6.3), **MRCR/LCR and CritPt are unreported**, no hallucination measurement exists at all, and **Moonshot itself states K3 trails Claude Fable 5 and GPT-5.6 Sol overall** — a vendor conceding second place is strong evidence against scoring it in the top band.
- **Context window: 95/100.** A verified **1,048,576-token window**, confirmed independently by Cloudflare, places it in the ≥1M tier (95–100), and two structural details make it more usable than most peers: **pricing is flat across the whole window** with no long-context cliff, and the 90% cache-hit discount with >90% measured hit rates makes repeated large prefixes genuinely cheap. It stays at the tier floor because the 100 condition (≥98% retrieval at 512K+) has **no supporting evidence** — no MRCR/RULER/GraphWalks figure exists, independent long-context reliability is explicitly unresolved, and Moonshot's own BrowseComp footnote shows the managed-300K configuration scoring *higher* (91.2) than the unmanaged 1M configuration (90.4). Max output tokens are undocumented, which is a real planning gap.
- **Multimodal: 85/100.** This dimension has the best *measured* evidence of any model scored so far: **OmniDocBench 91.1 leads its entire comparison field** and **MMMU-Pro 81.6 edges Claude Fable 5** — document and chart understanding are not just claimed but benchmarked at frontier level. Native vision is confirmed in the launch specifications, and image- plus video-informed workflows are demonstrated, which places it in the methodology's "+video/PDF in = 75–90" band. It is held to 85 rather than the band top because **video support is demonstrated rather than documented** (accepted formats and limits are endpoint-specific and incomplete), there is **no audio input**, and output is text-only with no non-text modality.
- **Coding: 92/100.** The strongest dimension, and uniquely for this dataset the strongest evidence is **independent rather than vendor-reported**: **Artificial Analysis Coding Index 76.2 clears the methodology's 70%+ frontier reference**, and **Arena's blind frontend ranking put K3 at #1 with 1,679, ahead of Claude Fable 5, winning six of seven domains** — real users preferring its generated interfaces under blind conditions. The vendor rows corroborate: **Terminal-Bench 2.1 88.3** (above the 85%+ coding reference), **Program Bench 77.8** and **SWE Marathon 42.0** both leading their displayed fields. Deductions: **DeepSWE 67.5 falls short of the 74%+ reference** and loses to both Fable 5 and GPT-5.6 Sol, **SWE-bench Verified/Pro, LiveCodeBench and SciCode are entirely absent**, and the Arena result measures frontend preference, not backend reliability or long-horizon repository maintenance.
- **Cost efficiency: 68/100.** $3 / $15 sits exactly on the methodology's ~60 anchor, and three factors push it meaningfully above that: **$0.30 cached input is a 90% discount that Moonshot's serving architecture actually delivers (>90% cache hits in coding workloads)**, pricing is **flat across the full 1M window** rather than cliff-tiered like its proprietary peers, and uniquely here, **public weights mean the per-token cost structure is escapable entirely** for organisations able to self-host. Four deductions keep it below 70: reasoning is **always on with `max` as the API default**, so output tokens — the expensive side at $15/1M — balloon by construction; it is over **three times K2.6's output price**, making it the wrong default for routine traffic by its own vendor's framing; there is **no free API tier**; and self-hosting is not a real escape for most teams at ~1.4 TB of 4-bit weights and 64+ recommended accelerators.
- **Overall Score: 89.8/100.** Mean of the five non-cost dimensions (89 + 88 + 95 + 85 + 92) / 5 = 89.8 — the best choice in this dataset for **frontend and UI generation** (independently #1 on Arena's blind ranking), **document-heavy multimodal agents** (OmniDocBench 91.1, MMMU-Pro 81.6), **very large repository context at flat pricing**, and any workload where **owning the checkpoint matters** — no proprietary peer offers a frontier-band model you can download. Treat it as a specialist escalation tier, not a default: route the hardest, longest and most visual work to it and keep Kimi K2.6 or another cheaper model underneath, because output is $15/1M with max-effort reasoning on by default. Do not choose it over Claude Fable 5 or GPT-5.6 Sol for hard general reasoning (last on HLE in Moonshot's own table, DeepSWE below the frontier reference), do not assume million-token recall without testing it at the beginning, middle and end of your own prompts, and read the custom Kimi K3 License before building a product on the weights.
