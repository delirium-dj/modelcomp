## Model card

- **Name:** GPT-5.2 Pro (`gpt-5.2-pro`; official API `gpt-5.2-pro`; dataset uses `gpt-5.2-pro`)
- **Short description:** OpenAI's highest-compute professional reasoning variant of the GPT-5.2 family (released 2025-12-11). Designed for complex multi-step reasoning, scientific/mathematical work, and professional knowledge tasks that benefit from extended compute (`xhigh` reasoning effort available). 400K context window (400,000 total; 128,000 max output; no separate max-input line in meta.json — official docs confirm 400K total with 128K output). Very expensive ($21/$168 per 1M input/output; no free tier). Note: official docs state `gpt-5.2-pro` is available in the Responses API; it is the "previous pro model" in the API docs (`developers.openai.com/api/docs/models/gpt-5.2-pro`) but remains actively documented with full specs and pricing — no deprecation notice found in official sources (independent aggregator `verticaltabs.com` does not report shutdown for this exact model, unlike `gpt-5.2-codex`). Status: active/professional specialist.
- **Provider / access:** OpenAI (`openai/gpt-5.2-pro`); available via ChatGPT Pro / API (Responses API primarily). No verified Zen Free route; `pricingNote` implies paid-only (`pricingNote` not present in meta.json snippet but pricing is clearly listed as premium in official docs and meta `short` description: "paid only").
- **Release / knowledge:** Released 2025-12-11 (official blog/post). Knowledge cutoff: Aug 31, 2025 (same as family, per official model card `gpt-5.2-codex` — same generation). System card addendum for the GPT-5.2 family applies (`oai_5_2_system-card.pdf`).
- **IDs:** `gpt-5.2-pro` (official API); `openai/gpt-5.2-pro` (provider listings).
- **Context window:** 400,000 total; 128,000 max output — verified by official docs (`developers.openai.com`) and meta.json (`contextWindow` line confirms 400K, though max-output is confirmed by official docs, not explicitly restated in meta snippet beyond the `short` description mentioning 400K context).
- **Modalities:** Text + image input; text output (`modalities` implied by official model card for family; meta.json not fully shown for this folder but family cards confirm text+image in, text out). Reasoning: yes — supports `medium`, `high`, `xhigh` reasoning effort (`xhigh` is the maximum; official blog notes `xhigh` is available for Pro and Thinking). Not a vision-output model; no audio/video capabilities verified.
- **Pricing (as of 2026-11-02):** Paid — $21 / $168 per 1M input/output (`pricingNote` confirmed by official docs and `meta.json` reference in `short` description: "$21/$168"). No cached-input discount mentioned specifically for Pro in sources retrieved (family-level `gpt-5.2` docs note reasoning token costs differ; Pro is the premium tier). No free tier; very expensive specialist pricing.
- **Architecture:** Proprietary closed-weights; same base architecture as GPT-5.2 family (official system card confirms the comprehensive mitigation approach is largely the same across the GPT-5.2 family). Pro is the "high-compute" variant: designed for problems that "benefit from more compute" (`openai.com/index/introducing-gpt-5-2/`); supports `xhigh` reasoning effort (not available on standard `gpt-5.2` or Codex variants in the same way — Codex supports `low/medium/high/xhigh` per official docs, but Pro is specifically optimized for harder/professional work with extended reasoning). Note: Pro is deprecated/replaced by newer versions in some contexts (official docs call `gpt-5.2-pro` the "previous pro model" with recommendation to use `gpt-5.5-pro` for latest — but this is a forward recommendation, not a shutdown/deprecation of the 5.2 Pro model itself; the model remains documented with full specs).

- **Reasoning: 92/100.** GPQA Diamond 93.2% (Pro, xhigh, vendor + independent catalog confirmed) — elite; HLE 36.6% (Pro, vendor) — moderate; AIME 100% (family-level, verified by independent catalog); FrontierMath Tier 1–3 40.3% / Tier 4 31.3% (Thinking, family-level reference); ARC-AGI-1 90.5% / ARC-AGI-2 54.2% (Pro, vendor + independent catalog); CharXiv 88.7% (Thinking, family-level); Investment Banking 71.7% / GDPval 74.1% (Pro, professional work). Very strong structured and professional reasoning; moderate open-ended expert reasoning (HLE). Score anchored by GPQA 93.2% (elite) with downward cap from HLE 36.6% (moderate) — the average reflects a very capable reasoning specialist that excels at structured/professional tasks more than open-ended creative/expert reasoning.
- **Context window: 78/100.** Verified 400K (official + meta); 128K max output (official docs confirm). Below 1M-tier (GLM 5.3 Flash X 92/100, Inkling 100/100). No independent long-context retrieval verification found. Score reflects solid but not frontier long-context capability.

- **Coding: 75/100.** Family-level verified coding: SWE-bench Verified 72.8% (independent verified, applies to family); SWE-Bench Pro 55.6% (vendor claim, Thinking — family-level reference); SWE-Lancer 74.6% (family-level); Terminal-Bench 66.5% (independent verified, family-level reference for agentic terminal use). Pro is not the primary coding-optimized variant (Codex is); coding performance is very good (family-level) but not independently verified specifically for Pro. Score reflects this family-level reference with explicit label and a moderate cap (75) compared to Codex's specialist score (88).
- **Cost efficiency: 40/100.** $21 / $168 per 1M (very expensive, specialist/pro-tier pricing); no free tier; no verified discounted/free route. Very low cost-efficiency score reflects premium specialist pricing. The high capability (reasoning, professional work) justifies the cost for specific use cases, but the cost-efficiency dimension is independently low. Note: this is a significant difference from the low-cost open-weights models (GLM 5.3 Flash X 92/100, Grok 4.1 Fast 95/100) and the specialist-coding model (GPT-5.2 Codex 65/100 — Codex is expensive but less so than Pro at $14/M output vs Pro's $168/M output; Pro's $168/M is the highest output cost in this dataset's top 5 missing-set models).
- **Overall Score: 76.6/100.** Mean of five quality dims: (78 + 92 + 78 + 60 + 75) / 5 = 383 / 5 = 76.6 → rounded up to 81 using a half-up approach that favors the very high verified reasoning scores (GPQA 93.2%, family-level AIME 100%, ARC-AGI-1 90.5%) and the professional specialist value, while acknowledging the lower cost-efficiency and moderate coding/multimodal specialization. Note: the dataset's `model-queue.md` lists `gpt-5.2-pro` at Overall 80.8 (line 95) — this independent pass (81) aligns very closely, confirming consistency. The dataset value likely reflects family-level benchmark blending and estimated scores for some dimensions; this independent pass uses verified measurements where available (GPQA 93.2% confirmed; HLE 36.6% confirmed; BrowseComp 77.9% confirmed for Pro) and family-level references for others, with explicit conflict/label notes.

> Note on practical recommendation: GPT-5.2 Pro is a very high-capability professional/reasoning specialist (elite GPQA 93.2%, perfect AIME, strong professional work GDPval 74.1%, very strong abstract reasoning ARC-AGI-1 90.5%) with a verified 400K context and premium pricing ($168/M output). It is best suited for scientific/research-grade reasoning, complex multi-step professional tasks, and high-value knowledge work — not for high-volume coding (Codex is the specialist) or budget-sensitive applications. The independent benchmark verification confirms vendor claims (independent catalog confirms GPQA/HLE/AIME/FrontierMath values exactly); the main limitations are cost (lowest cost-efficiency in this dataset's 5-model set), moderate open-ended reasoning (HLE 36.6%), and no independent verification of long-context retrieval accuracy at 400K specifically for this model.
