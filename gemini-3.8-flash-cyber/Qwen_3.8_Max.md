## Model card

- **Name:** Gemini 3.8 Flash Cyber
- **Short description:** Google DeepMind's **cybersecurity fine-tune of Gemini 3.8 Flash** (released 2026-09-02, same day as the base model) — "our most capable cybersecurity model with frontier-level performance in vulnerability detection and automated patching." It shares the base 3.8 Flash foundation (which Google calls "our best reasoning and coding model yet," AA Index 59) but is **tuned for defensive security** and bundled with the **CodeMender** harness for finding/verifying/fixing vulnerabilities at agentic scale. In its specialty it is **frontier-leading**: **CyberGym 86.2% pass@1** (autonomous vuln discovery — ahead of GPT-5.5 Cyber 85.6%, Claude Mythos 5 83.8%, GPT-5.6 Sol 83.6%), **CWE-Bench 47.2%** patching (Pareto-optimal vs a frontier model's 47.8% at ~3× the cost), and **71.0%** on an internal 20-language vuln-discovery benchmark. Trade-offs: it is **hard-gated** (Fairwind Program — vetted government/critical-infrastructure/software-maintainer defenders only, **no public pricing**), it is a **code/text specialist** (no documented vision/audio, unlike the strongly-multimodal base 3.8 Flash), general long-horizon agency is weak (inherited Terminal-bench 4.0 19.1%), and **every Cyber figure is Google vendor-run or partner-reported** (no independent harness has evaluated the gated variant).
- **Provider / access:** **Fairwind Program only** — prioritized access for trusted government authorities, critical-infrastructure operators and software maintainers (roster includes Armadin, Menlo Security, Palo Alto Networks, Snowflake, Wiz). **Not** a public API; no checkout, `noFreeId`. Bundled with Google's **CodeMender** harness. Base 3.8 Flash (the general twin) is public via the Gemini API / AI Studio / Antigravity / Gemini Enterprise.
- **Release / knowledge:** Released **2026-09-02** (third Flash release in six weeks, after 3.6 Flash Jul 21 and 3.7 Flash Aug 13). Announced by Tulsee Doshi (Sr. Dir. PM) and **Raluca Ada Popa (Gemini Security Lead, Google DeepMind)**. Knowledge cutoff not stated in the sources reviewed.
- **IDs:** `gemini-3.8-flash-cyber` / `google/gemini-3-8-flash-cyber` (variant of Gemini 3.8 Flash; predecessor Gemini 3.5 Flash Cyber).
- **Context window:** **1,048,576 (1M) tokens / 65,536 (65K) max output** (same spec as base 3.8 Flash; three thinking levels, default medium). The 65K output cap is below the 128–131K leaders. Base 3.8 Flash "works harder" (~30% more output tokens/task at higher effort).
- **Modalities:** **Text + code in → text + code out** (per the folder's meta.json). ⚠ **No image/video/audio documented for the Cyber product surface and no Cyber-specific multimodal benchmark was published** — this is a code/security specialist. Note the *base* 3.8 Flash core is strongly multimodal (CharXiv 86.2%, LVBench 87.8%), so latent vision may exist in the shared foundation, but it is neither surfaced nor benchmarked for Cyber.
- **Pricing (as of 2026-10-23):** **No public price** — Fairwind-gated. Google argues it is **Pareto-optimal**: on CWE-Bench the leading frontier model's point sits at ~**3× Cyber's cost per rollout**; **Wiz measured 2.3–5.2× lower cost** than other leading frontier models on its internal pen-test benchmark. (The base 3.8 Flash twin is cheap: $0.75/$3.75 intro through 2026-12-31, then $1.50/$7.50; cached $0.075.)
- **Architecture:** Undisclosed proprietary (Google DeepMind); the base 3.8 Flash core runs ~**305 output tok/s** (fastest AA has measured). Cyber is the security-tuned variant with **more permissive cyber mitigations** (hence the gating) and top-tier prompt-injection robustness (**Gray Swan IPI 6.0%** attack-success, vs Opus 5's 4.8%, 3.7 Flash's 9.2%, GPT-5.6 Sol's 27.0%).

### Raw benchmarks found

Security / coding — Cyber-specific (Google **vendor-run** unless noted):

- **CyberGym (autonomous vulnerability discovery, C/C++): 86.2% pass@1** — **#1**, ahead of GPT-5.5 Cyber (85.6%), Claude Mythos 5 (83.8%), GPT-5.6 Sol (83.6%), Gemini 3.5 Flash Cyber (77.5%)
- **Google internal 20-language vuln-discovery benchmark: 71.0%** — vs Gemini 3.7 Flash 58.9%, Gemini 3.5 Flash Cyber 46.6% ("success rate exceeding 70%")
- **CWE-Bench (patching; run externally by Collinear AI): 47.2% pass@1** — vs "a leading frontier model at 47.8%"; **Pareto-optimal** (frontier model ~3× the cost per rollout)
- **Chrome Security (partner-reported): 2.6× more correct vulnerability patches** than the best commercial (much larger) models
- **Wiz (partner-reported): +7.5–9.7% higher recall** on internal pen-testing at **2.3–5.2× lower cost**
- **Google Cloud Vulnerability Research:** found a critical foundational vulnerability in **<2 hours** (usually months)

General coding / reasoning — inherited base 3.8 Flash core (Google **vendor-run**; AA **independent** for the Index):

- **AA Intelligence Index: 59 (high effort)** — independent; base 3.8 Flash (Cyber not separately AA-indexed)
- **DeepSWE v1.1 (long-horizon SWE): 73.7%** — within 0.3 of Claude Opus 5's 74.0%; ahead of GPT-5.6 Sol 72.7%
- **Terminal-bench 2.1 (agentic terminal): 89.4%** — **leads the launch table** (Opus 5 89.1%, Sol 88.8%)
- **HLE-Verified (multidisciplinary expert reasoning): 54.9%** — **best in table** (Sol 54.5%, Opus 5 54.4%)
- **Terminal-bench 4.0 (general long-horizon agent): 19.1%** — ⚠ far behind Opus 5's 51.8% (Sol 37.3%); **OSWorld-2.0: 59.0%** vs Opus 5's 75.4%; **GDPVal-AA v2: 1545** vs Opus 5's 1824

> Provenance: **All Cyber-specific capability figures are Google vendor-run** (launch blog "Introducing Gemini 3.8 Flash and 3.8 Flash Cyber," 2026-09-02, and the Gemini 3.8 Flash Cyber evals-methodology page), transcribed by Vellum's benchmark walk (2026-09-03). **CWE-Bench is an external benchmark (Collinear AI)** and the **Chrome/Wiz/Cloud-Vuln-Research results are partner-reported** (semi-independent), but Google is the reporting party for all of them; because the model is **Fairwind-gated, no neutral harness (AA/Vals/LiveBench) has independently evaluated Cyber** — AA's Index 59 is for the *base* 3.8 Flash, not the Cyber variant. Per methodology the vendor/partner cells are treated as an **upper bound and discounted**. The base-3.8-Flash general numbers (DeepSWE 73.7, Terminal-bench 2.1 89.4 / 4.0 19.1, HLE-Verified 54.9, OSWorld 59.0, GDPVal 1545) come from Google's launch table and apply to the shared core; I do **not** assume Cyber inherits the base's *multimodal* results (CharXiv/LVBench), since Cyber is documented text/code-only and unbenchmarked for vision. No benchmark was invented.

### Normalized scores (1–100)

- **Tool use: 85/100.** Frontier **autonomous security agency** — CyberGym 86.2% (#1), the CodeMender find/verify/fix harness, a <2-hour real critical-vuln discovery, and inherited **Terminal-bench 2.1 89.4%** (leads the launch table). Held below the frontier because **general long-horizon agency is weak** (inherited Terminal-bench 4.0 19.1% vs Opus 5's 51.8%; OSWorld-2.0 59.0% vs 75.4%) and every Cyber agentic figure is vendor/partner-reported.
- **Reasoning: 86/100.** Strong — inherited **HLE-Verified 54.9% (best in the launch table)** and **AA Index 59 (high effort, independent)** for the shared core, plus top-tier adversarial multi-step reasoning (71.0% vuln discovery across 20 languages) and best-in-class prompt-injection robustness (Gray Swan 6.0%). Capped by the general knowledge-work ceiling (**GDPVal-AA v2 1545**, 279 Elo behind Opus 5) and the absence of any Cyber-specific independent reasoning eval.
- **Context window: 87/100.** A **1M-token native window**, ample for large codebases. Discounted below the 89–93 leaders because the **65K output cap** is modest and the "works-harder" core burns ~30% more output tokens/task, and no long-context-recall figure was published.
- **Multimodal: 52/100.** The structural weakness of this specialist: it is documented **text + code only** (no image/video/audio for the Cyber surface) and **no Cyber multimodal benchmark exists**. Scored well below the multimodal leaders and below the base 3.8 Flash (CharXiv 86.2%, LVBench 87.8%) because that vision is not surfaced or verified for Cyber; held above rock-bottom only because the shared foundation is multimodal-capable, so latent vision may exist. ⚠ If Google later confirms/benchmarks Cyber vision, this dimension (and the Overall) would rise materially.
- **Coding: 89/100.** The standout — **frontier-leading security coding** (CyberGym 86.2% #1; CWE-Bench 47.2% Pareto-optimal on an *external* harness; 71.0% across 20 languages; Chrome's 2.6× more correct patches) **plus top-tier inherited general coding** (DeepSWE v1.1 73.7% ≈ Opus 5's 74.0%; Terminal-bench 2.1 89.4%, best in table). Discounted from the low-90s because the general long-horizon coding-agency row (**Terminal-bench 4.0 19.1%**) is weak and the security margins are vendor/partner-reported without independent replication.
- **Cost efficiency: 85/100.** Genuinely strong *for its capability* — **Pareto-optimal on CWE-Bench** (~1/3 a frontier model's cost per rollout), **Wiz-measured 2.3–5.2× lower cost**, built on the cheap Flash core ($0.75/$3.75). Tempered because there is **no public Cyber price** (Fairwind-gated), so $/token cannot be independently verified. Scored but **not** counted in the Overall per methodology.
- **Overall Score: 80/100.** Mean of Tool 85 + Reasoning 86 + Context 87 + Multimodal 52 + Coding 89 = 399/5 = 79.8 → 80. Best fit: **vetted defensive-security teams** — autonomous vulnerability discovery and automated patching at agentic scale across many languages (via Fairwind + CodeMender), where frontier security coding, Flash speed, prompt-injection robustness and Pareto cost matter; it is **not** a general-purpose or multimodal API, and general long-horizon agency should route to Opus 5 / a frontier model. Independent read: my 80 sits **well below the queue's curated 87.4** — the gap is almost entirely the **code-only Multimodal score (52)** plus the **Fairwind gating / no public pricing** and the **vendor-only, independently-unverified** Cyber benchmarks. On its specialty it is genuinely frontier (#1 CyberGym), and its inherited core is strong (AA Index 59), so this is a case where the honest general-composite mean understates a world-class *specialist*: I score the model as documented (text/code, gated, vendor-reported) rather than crediting unbenchmarked inherited vision or discounting the real security-coding lead.
